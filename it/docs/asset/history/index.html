Cronologia Asset

La cronologia degli asset rappresenta il record delle query degli asset. Nella cronologia degli asset, è possibile controllare l'ora della query e l'utente che l'ha eseguita, navigare verso una cronologia desiderata o eliminare una cronologia.

  1. Fare clic sul Pulsante Visualizza cronologia registro asset per visualizzare la cronologia degli asset.

  2. Fare clic sulla cronologia degli asset desiderata per visualizzarne i dettagli. Le date più recenti appaiono in alto.

 

Elimina cronologia​

Fare clic sull'Icona del cestino sulla cronologia che si desidera eliminare.
