# Come si effettua la distribuzione del canvas?

<hr />
<br />

1. La distribuzione del canvas avviene eseguendo un controllo preliminare tramite il menu `Gestione della distribuzione` e cliccando su `Distribuire` dopo il superamento del controllo.
2. Seleziona `Gestione della distribuzione` > `Controllo della validità` nel menu principale del canvas.
3. Nel modulo di controllo della validità, seleziona le credenziali e clicca sul pulsante `Esegui controllo`.
4. Nel menu di controllo della validità a sinistra, esegui il test di distribuzione e visualizza i risultati.
5. Dopo aver completato il test di distribuzione, seleziona l'ambiente di destinazione e clicca su `Distribuire` per eseguire la distribuzione sul CSP.

:::tip

Per distribuire l'infrastruttura cloud disegnata nel canvas su un CSP, è necessario che le credenziali siano registrate.

:::
