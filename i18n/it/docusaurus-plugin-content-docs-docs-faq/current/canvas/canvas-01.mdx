# La differenza tra salvare e salvataggio della versione

<hr />
<br />

<Tabs>
    <TabItem value="save" label="Salva" default>
        Il salvataggio conserva lo stato attuale del canvas. Salvando non sarà possibile tornare
        alla versione precedente del canvas. Se desideri ripristinare lo stato precedente del canvas,
        dovrai utilizzare la funzione di salvataggio versione.
    </TabItem>
    <TabItem value="versionSave" label="Salvataggio Versione">
        Il salvataggio della versione permette di ripristinare il canvas a uno stato desiderato in un determinato momento.
        Salvando una versione, è possibile successivamente caricare lo stato del canvas a quel punto nel tempo.
    </TabItem>
</Tabs>
