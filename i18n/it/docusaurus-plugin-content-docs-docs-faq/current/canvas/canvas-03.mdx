# È possibile caricare un'infrastruttura esistente nel canvas?

<hr />
<br />

È possibile caricare l'infrastruttura cloud tramite credenziali e file.

1. Seleziona nel menu principale del canvas `File > Carica`.
2. Scegli `Carica da infrastruttura` o `Carica da file`.

<Tabs>
    <TabItem value="infraImport" label="Carica da Infrastruttura" default>
        Seleziona le credenziali registrate e visualizza i gruppi di risorse (per Azure) 
        per caricare a livello di gruppo di risorse.
    </TabItem>
    <TabItem value="fileImport" label="Carica da File">
        Carica un file Terraform e verrà convertito 
        per essere utilizzato correttamente in CloudStudio.
    </TabItem>
</Tabs>

:::tip

Per caricare l'infrastruttura cloud distribuita, è necessario che le credenziali siano registrate.

:::
