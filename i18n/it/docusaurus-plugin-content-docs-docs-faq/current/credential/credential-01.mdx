# Registrare le credenziali

<hr />
<br />

## Registrare le credenziali Azure

Per registrare le credenziali di Azure, è necessario creare un'applicazione (di seguito chiamata app) nel `Microsoft Azure Portal`.

1. Accedi a https://portal.azure.com e seleziona `Azure Active Directory`, quindi scegli `Registrazioni delle app` dal menu a sinistra.

2. Nella pagina `Registrazioni delle app`, clicca sul primo pulsante in alto `Nuova registrazione` per creare una nuova app.

3. Vai alla pagina dell'app appena creata.

4. L'`ID del directory (tenant)` dell'app creata corrisponde al `Tenant ID` delle credenziali di CloudStudio. `Copia` l'ID del directory (tenant) e incollalo nel campo Tenant ID.

5. L'`ID dell'applicazione (client)` corrisponde al `Service Principal ID` delle credenziali di CloudStudio. `Copia` l'ID dell'applicazione (client) e incollalo nel campo Service Principal ID.

6. Nel menu a sinistra dell'app creata, seleziona `Certificati e segreti`, quindi crea una nuova chiave client.

7. Il `valore` della chiave client appena creata corrisponde al `Service Principal Key` delle credenziali di CloudStudio.

:::caution

Fai attenzione, poiché la password del client può essere visualizzata solo una volta al momento della generazione.

:::

8. Successivamente, seleziona `Sottoscrizione` nel menu a sinistra. Verifica l'`ID della sottoscrizione` che desideri utilizzare.

9. L'`ID della sottoscrizione` nel menu della sottoscrizione corrisponde al `Subscription ID` delle credenziali di CloudStudio.

10. Registra ciascun valore attraverso la `registrazione delle credenziali` in CloudStudio.

11. Successivamente, puoi eseguire la visualizzazione e la distribuzione tramite l'app del tenant.
