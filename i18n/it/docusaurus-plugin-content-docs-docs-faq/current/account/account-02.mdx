# Voglio eliminare il mio account.

<hr />
<br />

1. Seleziona il menu `Le mie informazioni` a sinistra nella schermata principale di Cloud Studio.
2. In Gestione account, clicca su `Elimina account` per eliminare l'account.

:::caution

Dopo l'eliminazione dell'account, i progetti non possono essere recuperati.

:::
