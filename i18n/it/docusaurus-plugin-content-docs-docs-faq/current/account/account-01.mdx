# Voglio cambiare il mio profilo.

<hr />
<br />

1. Clicca sul menu `Le mie informazioni` a sinistra nella schermata principale di Cloud Studio.
2. In Gestione account, clicca su `Cambia immagine` e seleziona l'immagine del profilo desiderata.
3. Regola bene le dimensioni dell'immagine e clicca su `Modifica` per cambiare il profilo.
