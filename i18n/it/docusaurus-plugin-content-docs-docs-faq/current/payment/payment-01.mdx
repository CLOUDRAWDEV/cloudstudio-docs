# Voglio aggiornare la sottoscrizione che sto utilizzando

<hr />
<br />

1. Nella schermata principale di CloudStudio, seleziona il menu `Le mie informazioni` sulla sinistra.

2. Clicca su `Gestione della sottoscrizione` per andare alla pagina dei piani di sottoscrizione.

3. Puoi aggiornare la tua sottoscrizione al piano `PRO`.

:::info

L'aggiornamento della sottoscrizione comporta l'addebito (pagamento ricorrente).

:::
