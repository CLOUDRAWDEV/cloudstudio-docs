#### Sono state aggiunte nuove risorse di intelligenza artificiale.

<div className={styles.releaseWrap} >
<div className={styles.tag} data-type="feature">
    Feature
</div>

1. Sono state aggiunte nuove risorse di intelligenza artificiale basate su AWS e Azure.

    - Risorse di IA di AWS

        - Bedrock Agent
        - Bedrock Knowledge Base
        - Bedrock Action Group
        - Bedrock Guardrail

    - Risorse di IA di Azure

        - Content Safety
        - AI Service
        - Search Service

    - Gli utenti ora possono progettare e gestire in modo più intuitivo le risorse di intelligenza artificiale fornite dai principali servizi cloud.

2. È stata aggiunta una funzione per mostrare o nascondere gli errori di configurazione.
    - Anche se nei resource rimangono errori non risolti, è possibile scegliere se mostrare o nascondere le indicazioni di errore.
