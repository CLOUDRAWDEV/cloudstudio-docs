#### Vengono forniti servizi per Azure, AWS, Naver Cloud, Kubernetes.

<div className={styles.releaseWrap} >
<div className={styles.tag} data-type="new">
    New
</div>
<div>

1. Diagramma dell'infrastruttura cloud
    - È possibile progettare l'infrastruttura cloud tramite Drag & Drop.
    - Durante la progettazione dell'infrastruttura, vengono mostrati in tempo reale gli errori relativi a configurazioni errate.
    - L'infrastruttura disegnata può essere convertita in IaC.
2. Gestione delle versioni
    - Viene fornita una funzione di salvataggio delle versioni per l'infrastruttura basata su IaC, che consente di tornare a una versione specifica.
3. Calcolo dei costi
    - Viene fornito il costo di mantenimento mensile, giornaliero e orario dell'infrastruttura disegnata (KRW, USD).
4. Diagnosi delle vulnerabilità
    - Viene fornita una diagnosi delle vulnerabilità per l'infrastruttura disegnata, con linee guida per la risoluzione delle vulnerabilità.
5. Gestione delle distribuzioni
    - L'infrastruttura disegnata viene validata tramite un test di distribuzione preliminare, e può essere configurata effettivamente in base alle credenziali CSP.

</div>
