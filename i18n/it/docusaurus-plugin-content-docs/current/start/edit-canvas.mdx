Il Canvas è il <highlight color="#206FD6">servizio principale della Cloud Studio</highlight>, dove è possibile disegnare un'infrastruttura cloud utilizzando le risorse con il metodo `Drag & Drop`, gestire le versioni e distribuirle.
L'infrastruttura creata con il Canvas può essere utilizzata come un'architettura visiva e anche distribuita direttamente ai CSP desiderati.

✂️ Modifica liberamente il Canvas!

<p>&nbsp;</p>

## Drag & Drop delle risorse {#drag-drop}

`Drag & Drop` è la funzionalità più semplice per configurare il Canvas.
Trascina la risorsa desiderata dalla `Lista Risorse` e rilasciala nel Canvas!
Le risorse che non possono essere collegate tra loro rimbalzeranno con una linea rossa.

<div className={styles.imgWrap}>
    <img src={dragDrop} alt="Immagine Drag and Drop" width={800} />
</div>

<br />

:::info

La `Lista Risorse` è il pannello che raccoglie tutte le risorse a sinistra del Canvas.

:::

## Modifica delle opzioni delle risorse {#option-edit}

Fai `doppio clic` su una risorsa per aprire la `finestra di modifica` e cambiare le impostazioni della risorsa.
Clicca sull'icona `Vedi Dettagli` per visualizzare la descrizione della risorsa.
❓ Passa il mouse sull'`icona del punto di domanda` per visualizzare la descrizione delle singole opzioni. Configura i valori desiderati in base alla descrizione.

## Correzione degli errori {#error-correction}

🔴 Un punto rosso indica che c'è un errore in quella risorsa. <highlight color="#FF7272">Se ci sono errori, non sarà possibile salvare o distribuire il Canvas.</highlight>
Per correggere l'errore, fai doppio clic sulla risorsa che ha generato l'errore per aprire la finestra degli errori del Canvas.
Nella finestra degli errori, fai doppio clic sull'errore specifico per essere portato direttamente al punto dell'errore. Correggi l'errore seguendo le indicazioni.

<div className={styles.imgWrap}>
    <img src={error} alt="Immagine correzione errore" width={800} />
</div>

<p>&nbsp;</p>

### Tipi di errore

| Tipo  | Descrizione                                                  |
| ----- | ----------------------------------------------------- |
| value | Errore causato da un valore di input errato                    |
| group | Errore causato dalla risorsa che non appartiene a nessun gruppo       |
| line  | Errore causato dalla mancanza di una connessione necessaria tra risorse |

## Utilizzo del Toolbox {#toolbox}

Il Toolbox in alto offre una varietà di funzionalità per personalizzare il Canvas.

| Immagine                                                       | Azione          | Funzione                                                   |
| ------------------------------------------------------------ | ------------- | ------------------------------------------------------ |
| <img width="40px" src={ undo } alt="Immagine annullamento" />     | Annulla     | Annulla l'operazione precedente.                           |
| <img width="40px" src={ redo } alt="Immagine ripetizione" />     | Ripeti     | Ripete l'operazione annullata.                             |
| <img width="40px" src={ front } alt="Immagine" />              | Invia indietro   | Quando due risorse si sovrappongono, invia la risorsa selezionata dietro.   |
| <img width="40px" src={ back } alt="Immagine" />               | Invia avanti | Quando due risorse si sovrappongono, invia la risorsa selezionata avanti. |
| <img width="40px" src={ list } alt="Immagine lista risorse" /> | Lista risorse | Pulsante per mostrare/nascondere la lista delle risorse.                  |
| <img width="100px" src={ ratio } alt="Immagine rapporto schermo" />   | Rapporto schermo     | Regola il rapporto di visualizzazione del Canvas.                          |
| <img width="100px" src={ grid } alt="Immagine griglia" />       | Griglia        | Disabilita la visualizzazione della griglia del Canvas.                   |
