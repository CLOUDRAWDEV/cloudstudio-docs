Cloud Studio non consente l'accesso come ospite. Prima di effettuare il login, devi prima completare la `registrazione`.

🔗  [Link per la registrazione a Cloud Studio](https://cstudio.app/signup)

✏️  <Link to="/docs/start/sign-up">Come registrarsi</Link>

Una volta completata la registrazione, accedi alla [pagina di login di Cloud Studio](https://cstudio.app/signin).

<p>&nbsp;</p>

1. Verifica l'ID e la password temporanea attraverso l'indirizzo email che hai fornito durante la registrazione.

<div className={styles.imgWrap}>
    <img width="100%" src={login01} width="450px" alt="img" />
</div>

<p>&nbsp;</p>

2. Nella pagina di login di Cloud Studio, `inserisci l'ID e la password temporanea`.

<img width="100%" src={login02} alt="img" />

<p>&nbsp;</p>

3. Imposta una nuova password.

<img width="100%" src={otp06} alt="otp img" />

<p>&nbsp;</p>

:::info
Al primo login, dovrai reimpostare la password.

:::
