Ecco le `scorciatoie` che puoi utilizzare nel Canvas di Cloud Studio.

| Scorciatoia                       | Descrizione                 |
| --------------------------------- | --------------------------- |
| Ctrl + Scroll del mouse           | Zoom in e zoom out          |
| Space + Clic del mouse + Trascina | Spostamento della schermata |
| Delete                            | Elimina                     |
| Ctrl + Z                          | Annulla                     |
| Ctrl + C                          | Copia                       |
| Ctrl + V                          | Incolla                     |
