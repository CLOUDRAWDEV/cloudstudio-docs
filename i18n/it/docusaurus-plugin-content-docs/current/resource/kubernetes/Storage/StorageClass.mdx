## Panoramica della risorsa

Risorsa Kubernetes che definisce il provisioning dinamico dello storage, operando insieme a uno specifico Storage Provisioner.

-   [**Cluster**](https://docs.cstudio.app/it/docs/resource/kubernetes/Base/Cluster)

-   [**PersistentVolume**](https://docs.cstudio.app/it/docs/resource/kubernetes/Core/PersistentVolume)

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `annotations` : Metadati key-value utilizzati per visualizzare le informazioni necessarie al sistema Kubernetes
-   `labels` : Etichette definite dall’utente per distinguere l’oggetto StorageClass
-   `storage_provisioner` : Tipo di storage provisioner che crea effettivamente lo storage
-   `reclaim_policy` : Politica di recupero applicata alla liberazione del volume - `Retain`, `Delete`
-   `volume_binding_mode` : Momento in cui avviene il binding del volume e il provisioning dinamico - `Immediate`, `WaitForFirstConsumer`
-   `allow_volume_expansion` : Indica se è consentita l’espansione della dimensione del volume creato
-   `parameters` : Parametri aggiuntivi passati allo storage provisioner
-   `mount_options` : Opzioni di mount applicate ai PersistentVolume creati dinamicamente
