## Panoramica della risorsa

Risorsa di Kubernetes che definisce il provisioning dinamico dello storage che lavora con un particolare Storage Provisioner.

## Impostazioni della risorsa

-   `service_name` : Nome della risorsa StorageClass
-   `annotations` : Coppie chiave-valore utilizzate per visualizzare informazioni necessarie nel sistema Kubernetes
-   `labels` : Valori definiti dall'utente per distinguere gli oggetti
-   `storage_Provisioner` : Tipo di fornitore di storage
-   `reclaim_policy` : Politica di recupero da utilizzare – se non specificato, il valore predefinito è Delete
-   `volume_binding_mode` : Quando deve avvenire il binding del volume e la creazione dinamica - `Immediate`, `WaitForFirstConsumer`
-   `allow_volume_expansion` : Se la classe di storage consente l'espansione del volume - `False`, `True`
-   `parameters` : Parametri per il fornitore di storage che deve creare il volume della classe di storage
-   `mount_options` : Opzioni di mount per i volumi permanenti creati dinamicamente dalla classe di storage
