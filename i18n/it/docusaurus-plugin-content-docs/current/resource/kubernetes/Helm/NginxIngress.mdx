## Valori di configurazione della risorsa

#### Impostazioni di base

-   `namespace` : Namespace in cui verrà distribuita la risorsa Helm Chart di Nginx Ingress
-   `version` : Versione del Helm Chart di Nginx Ingress da utilizzare
-   `replica_count` : Numero di repliche del Deployment del controller Ingress
-   `external_traffic_policy` : Modalità di gestione del traffico esterno - `Cluster `, `Local`
-   `ingress_class_name` : Nome della Ingress Class gestita da questo Ingress Controller
-   `set` : Impostazioni key-value per modificare dinamicamente i valori del Helm Chart di base del controller Nginx Ingress
