## Panoramica della risorsa

È il chart Helm per installare il Nginx Ingress Controller.

## Impostazioni della risorsa

-   `service_name` : Nome del rilascio del chart Helm di Nginx Ingress-Controller
-   `namespace` : Namespace in cui verrà distribuito il chart Helm di Nginx Ingress-Controller
-   `version` : Versione del chart Helm di Nginx Ingress-Controller da utilizzare
-   `replica_count` : Numero di repliche del Deployment dell'Ingress Controller
-   `external_traffic_policy` : Impostazione della politica di risposta al traffico esterno - `Cluster`,`Local`
-   `ingress_class_name` : Nome della classe di ingress che specifica quale Ingress Controller gestirà l'Ingress
-   `set` : Modifica dinamica dei valori del chart di base di Nginx Ingress Controller
