## Impostazioni della risorsa

-   `service_name` : Nome del rilascio del chart Helm di Istio
-   `namespace` : Namespace in cui verrà distribuito il chart Helm di Istio - specificato come `istio-system`
-   `version` : Versione del chart Helm di Istio da utilizzare
-   `set` : Modifica dinamica dei valori del chart di base di Istio
