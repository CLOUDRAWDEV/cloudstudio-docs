## Impostazioni della risorsa

-   `service_name` : Nome del rilascio del chart Helm di Istio Gateway
-   `namespace` : Namespace in cui verrà distribuito il chart Helm di Istio Gateway
-   `version` : Versione del chart Helm di Istio Gateway da utilizzare
-   `set` : Modifica dinamica dei valori del chart di base di Istio Gateway
