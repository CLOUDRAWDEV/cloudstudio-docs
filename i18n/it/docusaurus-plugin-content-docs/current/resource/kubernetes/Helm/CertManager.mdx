## Impostazioni della risorsa

-   `service_name` : Nome del rilascio del chart Helm di Cert-Manager
-   `namespace` : Namespace in cui verrà distribuito il chart Helm di Cert-Manager
-   `version` : Versione del chart Helm di CertManager da utilizzare
-   `installCRDs` : Verifica se i Custom Resource Definitions relativi a certmanager devono essere installati
