## Valori di configurazione della risorsa

#### Impostazioni di base

-   `namespace` : Namespace in cui verrà distribuito il Helm Chart di Cert Manager
-   `version` : Versione del Helm Chart di Cert Manager da utilizzare
-   `installCRDs` : Indica se installare le Custom Resource Definition(CRD) utilizzate da Cert Manager
