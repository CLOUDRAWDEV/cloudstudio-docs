## Valori di configurazione della risorsa

#### Impostazioni di base

-   `namespace` : Namespace in cui verrà distribuita la risorsa Helm Chart di Hashicorp Vault
-   `version` : Versione del Helm Chart di Hashicorp Vault da utilizzare
-   `set` : Impostazioni key-value per modificare dinamicamente i valori del Helm Chart di base di Hashicorp Vault
