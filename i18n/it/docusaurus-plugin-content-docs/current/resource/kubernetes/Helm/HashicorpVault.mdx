## Impostazioni della risorsa

-   `service_name` : Nome del rilascio del chart Helm di HashiCorp Vault
-   `namespace` : Namespace in cui verrà distribuito il chart Helm di HashiCorp Vault
-   `version` : Versione del chart Helm di HashiCorp Vault da utilizzare
-   `set` : Modifica dinamica dei valori del chart di base di HashiCorp Vault
