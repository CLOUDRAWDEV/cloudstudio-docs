## Panoramica della risorsa

Risorsa Kubernetes che associa ruoli applicabili a uno specifico namespace agli utenti.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `namespace` : Namespace a cui si applica la risorsa RoleBinding
-   `annotations` : Metadati key-value della risorsa RoleBinding
-   `labels` : Etichette personalizzate per distinguere l’oggetto RoleBinding
-   `role_type` : Tipo di ruolo da associare - `Role`, `ClusterRole`
