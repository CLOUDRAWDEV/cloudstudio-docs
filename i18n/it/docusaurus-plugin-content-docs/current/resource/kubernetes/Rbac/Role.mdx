## Panoramica della risorsa

Una risorsa di Kubernetes che crea un ruolo applicabile solo al namespace specificato.

## Impostazioni della risorsa

-   `service_name` : Nome della risorsa Role
-   `namespace` : Namespace in cui la risorsa Role sarà distribuita
-   `annotations` : Key-value utilizzato per visualizzare le informazioni necessarie al sistema Kubernetes
-   `labels` : Valori arbitrari definiti dall'utente per distinguere gli oggetti
-   `rule` : Politica di ruolo associata a questo Role
    -   `name` : Nome della politica di ruolo
    -   `api_groups` : Gruppo API che contiene le risorse su cui il ruolo può operare
    -   `resources` : Elenco delle risorse su cui si applicano queste regole
    -   `resource_names` : Se si desidera selezionare istanze individuali delle risorse, specificare i nomi; se vuoto, include tutte le risorse di quel tipo
    -   `verbs` : Elenco dei verbi (azioni) che possono essere applicati a tutte le risorse elencate nelle regole
