## Panoramica della risorsa

Una risorsa di Kubernetes che crea un ruolo applicabile a livello di cluster e in tutti i namespace.

## Impostazioni della risorsa

-   `service_name` : Nome della risorsa ClusterRole
-   `annotations` : Key-value utilizzato per visualizzare le informazioni necessarie al sistema Kubernetes
-   `labels` : Valori arbitrari definiti dall'utente per distinguere gli oggetti
-   `rule` : Ruolo di politica per il clusterrole specificato
    -   `name` : Nome del ruolo di politica
    -   `api_groups` : Gruppo API che contiene le risorse per le quali è consentita l'operazione
    -   `resources` : Elenco delle risorse a cui si applica questa regola
    -   `resource_names` : Specifica le istanze individuali di una risorsa se selezionate - se vuoto, include tutte le risorse di quel tipo
    -   `non_resource_urls` : Usato per specificare una regola in formato URL per risorse non legate a Kubernetes - utile per configurare URL come endpoint di health check
    -   `verbs` : Elenco dei verbi che si applicano a tutte le risorse incluse nella regola
