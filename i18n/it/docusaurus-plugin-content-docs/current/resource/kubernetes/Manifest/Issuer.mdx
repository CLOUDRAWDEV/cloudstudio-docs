## Panoramica della risorsa

È una risorsa di Kubernetes che accetta una richiesta di firma del certificato e può generare un certificato firmato da una autorità di certificazione (CA).

## Impostazioni della risorsa

-   `service_name` : Nome delle risorse dell'Issuer
-   `acme` : Definisce l'account registrato nel server ACME (Automatic Certificate Management Environment)
    -   `acme.server` : Indirizzo dell'endpoint del server ACME
    -   `acme.email` : Indirizzo email per il contatto da parte di Let's Encrypt riguardo a problemi o scadenze dei certificati
    -   `acme.private_key_secret_ref` : Nome del Kubernetes Secret che memorizza la chiave cliente utilizzata per comunicare con il server ACME
-   `solver_type` : Definisce il metodo di risoluzione per il Challenge relativo al rilascio del certificato - `DNS`,`HTTP`

**Solver-Type : DNS**
-   `dns_solvers` : Definisce le configurazioni relative al solver se è impostato su DNS
-   `name` : Nome della configurazione del dns_solver
    -   `provider` : Seleziona il tipo di challenge DNS-01 - `AzureDNS`,`Route53`,`ACMEDNS` 

    ***AzureDNS***
    -   `azure_dns` : Configurazioni quando viene selezionato AzureDNS come tipo di challenge DNS-01
        -   `name` : Nome della configurazione AzureDNS
            -   `client_id` : ID del client dell'applicazione Azure Service Principal
            -   `client_secret_name` : Nome del Kubernetes Secret che memorizza il client secret dell'applicazione Azure Service Principal
            -   `client_secret_key` : Nome della chiave del Secret da usare
            -   `subscription_id` : ID dell'abbonamento Azure
            -   `tenant_id` : ID del tenant dell'abbonamento Azure
            -   `resource_group_name` : Nome del gruppo di risorse in cui si trova la zona DNS Azure
            -   `hosted_zone_name` : Nome della zona DNS ospitata su Azure

    ***Route53***        
    -   `route_53` : Configurazioni quando viene selezionato Route53 come tipo di challenge DNS-01
        -   `name` : Nome della configurazione Route53
            -   `region` : Regione AWS in cui viene utilizzato il servizio Route 53
            -   `access_key_id` : ID della chiave di accesso AWS
            -   `access_key_secret_name` : Nome del Kubernetes Secret che memorizza l'ID della chiave di accesso AWS (da omettere se è specificato access_key_id)
            -   `access_key_secret_key` : Nome della chiave del Secret da utilizzare (da omettere se è specificato access_key_id)
            -   `access_key_secret_key` : Nome del Secret che memorizza la chiave di accesso segreta AWS
            -   `secret_access_key_secret_key` : Nome della chiave del Secret che memorizza la chiave segreta di accesso AWS
            -   `role` : Nome del ruolo AWS IAM per la gestione di Route53 DNS

    ***ACMEDNS***          
    -   `acme_dns` : Configurazioni quando viene selezionato ACMEDNS come tipo di challenge DNS-01
        -   `name` : Nome della configurazione ACMEDNS
            -   `host` : Indirizzo dell'endpoint del server acme-dns
            -   `account_secret_ref_name` : Nome del Kubernetes Secret che memorizza le informazioni dell'account per il server acme-dns
            -   `account_secret_ref_key` : Nome della chiave del Secret da usare per memorizzare le informazioni dell'account del server acme-dns

**Solver-Type : HTTP-01**
-   `http_solvers` : Definisce le configurazioni relative al solver se è impostato su HTTP
-   `name` : Nome della configurazione http_solver
    -   `provider` : Seleziona il tipo di challenge HTTP-01 - `Ingress`,`Gateway`

    ***Ingress***
    -   `ingress` : Configurazioni quando viene selezionato Ingress come tipo di risoluzione del challenge HTTP-01
        -   `name` : Nome della configurazione Ingress per il challenge HTTP-01
            -   `ingress_class_name` : Nome della classe Ingress da usare
    ***Gateway***
    -   `Gateway` : Configurazioni quando viene utilizzato Gateway per risolvere il challenge HTTP-01
        -   `name` : Nome della configurazione Gateway per il challenge HTTP-01
            -   `namespace` : Namespace a cui appartiene la risorsa Gateway da collegare
