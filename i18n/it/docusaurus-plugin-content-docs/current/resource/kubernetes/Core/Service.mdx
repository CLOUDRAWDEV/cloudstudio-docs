## Panoramica della risorsa

È una risorsa astratta di Kubernetes che fornisce un singolo punto di ingresso per un Pod e gestisce la comunicazione tra quei Pod.

## Impostazioni della risorsa

-   `service_name` : Nome delle risorse del Service
-   `namespace` : Namespace in cui verranno distribuite le risorse del Service
-   `annotations` : Pair chiave-valore utilizzato per visualizzare le informazioni necessarie nel sistema Kubernetes
-   `labels` : Valori che l'utente può definire arbitrariamente per distinguere gli oggetti
-   `selector` : Usa le coppie chiave-valore delle etichette che corrispondono al selector per indirizzare il traffico del servizio ai Pod
-   `type` : Tipo di servizio - `ClusterIP`,`NodePort`,`LoadBalancer`
-   `session_affinity` : Politica che mantiene le richieste del client indirizzate sempre allo stesso Pod - `None`,`clientIP`
-   `port` : Elenco delle porte esposte dal servizio
    -   `name` : Nome della configurazione della porta 
        -   `protocol` : Protocollo IP della porta - `TCP`,`UDP`
        -   `port` : Numero della porta esposta dal servizio
        -   `target_port` : Numero della porta del Pod di destinazione a cui il servizio accede
