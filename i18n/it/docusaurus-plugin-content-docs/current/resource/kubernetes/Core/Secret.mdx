## Panoramica della risorsa

È una risorsa di Kubernetes utilizzata per memorizzare informazioni importanti come attributi individuali, file completi o JSON Blob.

## Impostazioni della risorsa

-   `service_name` : Nome delle risorse del Secret
-   `namespace` : Namespace in cui verranno distribuite le risorse del Secret
-   `annotations` : Pair chiave-valore utilizzato per visualizzare le informazioni necessarie nel sistema Kubernetes
-   `labels` : Valori che l'utente può definire arbitrariamente per distinguere gli oggetti
-   `type` : Tipo di Secret - `Opaque`,`kubernetes.io/basic-auth`,`kubernetes.io/service-account-token`,`kubernetes.io/dockerconfigjson`
-   `immutable` : Imposta se i dati memorizzati nel secret non possono essere aggiornati (solo i metadati dell'oggetto possono essere modificati) - `false`,`true`

-   `data` : Dati da inserire nel secret
    -   `data.name` : Nome dei dati da inserire nel secret - `Opaque`,`kubernetes.io/asic-auth` 
        -   `data.secret` : Valore dei dati da inserire nel secret - `Opaque`,`kubernetes.io/basic-auth`         
    -   `data.name` : Nome del registry Docker privato - `kubernetes.io/dockerconfigjson`
        -   `data.username` : Nome utente per l'autenticazione al registry Docker privato - `kubernetes.io/dockerconfigjson`
        -   `data.password` : Password dell'utente per l'autenticazione al registry Docker privato - `kubernetes.io/dockerconfigjson`
