## Panoramica della risorsa

Risorsa Kubernetes utilizzata per archiviare informazioni sensibili sotto forma di singole proprietà o elementi approssimativi come file completi o JSON Blob.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `namespace` : Namespace in cui verrà distribuita la risorsa Secret
-   `annotations` : Metadati di sistema Kubernetes
-   `labels` : Etichette personalizzate per identificazione e classificazione del Secret
-   `type` : Tipo di Secret - `Opaque`, `kubernetes.io/basic-auth`, `kubernetes.io/service-account-token`, `kubernetes.io/dockerconfigjson`, `helm.sh/release.v1`, `kubernetes.io/tls`, `kubernetes.io/ssh-auth`, `istio.io/ca-root`
-   `immutable` : Impostazione per rendere i dati del Secret non modificabili
-   `data` : Dati secret codificati in Base64 in formato key-value
