## Panoramica della risorsa

ServiceAccount predefinito che concede ai Pod le autorizzazioni per accedere al server API e alle risorse del cluster Kubernetes.

## Risorse correlate

### Risorsa principale

-   [**Namespace**](https://docs.cstudio.app/if/docs/resource/kubernetes/Core/Namespace)

### Risorse collegate

-   [**Secret**](https://docs.cstudio.app/if/docs/resource/kubernetes/Core/Secret)

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `namespace` : Namespace in cui verrà distribuita la risorsa ServiceAccount
-   `annotations` : Metadati di sistema Kubernetes
-   `labels` : Etichette personalizzate per identificazione e classificazione della risorsa
-   `secret` : Elenco dei Secret referenziabili dai Pod che utilizzano questo ServiceAccount
-   `image_pull_secrets` : Elenco dei Secret utilizzati dai Pod per il pull delle immagini
-   `automount_service_account_token` : Montaggio automatico del token ServiceAccount nel Pod
