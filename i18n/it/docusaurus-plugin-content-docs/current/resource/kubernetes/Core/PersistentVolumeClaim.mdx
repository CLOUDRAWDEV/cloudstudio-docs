## Panoramica della risorsa

È una risorsa Kubernetes utilizzata per richiedere un Persistent Volume (PV).

## Impostazioni della risorsa

-   `service_name` : Nome della risorsa PersistentVolumeClaim
-   `namespace` : Namespace in cui la risorsa PersistentVolume sarà distribuita
-   `annotations` : Coppie chiave-valore utilizzate per visualizzare informazioni necessarie nel sistema Kubernetes
-   `labels` : Valori personalizzati definiti dall'utente per distinguere gli oggetti
-   `spec` : Definisce le specifiche dettagliate del PVC (PersistentVolumeClaim)
    -   `spec.storage_class_name` : Nome della storage class da utilizzare
    -   `spec.volume_name` : Nome del PersistentVolume (PV) a cui il PVC sarà associato
    -   `spec.request_storage` : Capacità di storage richiesta per il PV
    -   `spec.access_modes` : Modalità di accesso richieste per il PV - (Deve corrispondere o includere le modalità di accesso del PV) - `ReadOnlyMany`,`ReadWriteMany`,`ReadWriteOnce`
