## Valori di configurazione della risorsa

#### Impostazioni di base

-   `namespace` : Namespace in cui verrà creata la risorsa PVC
-   `annotations` : Metadati di sistema Kubernetes
-   `labels` : Etichette personalizzate per identificazione e classificazione del PVC
-   `spec.storage_class_name` : Nome dello StorageClass da utilizzare
-   `spec.volume_name` : Nome del PersistentVolume da associare
-   `spec.volume_mode` : Modalità di fornitura dello storage -`Filesystem / Block`
-   `spec.request_storage` : Capacità di storage richiesta
-   `spec.access_modes` : Modalità di accesso al volume richieste - `ReadOnlyMany, ReadWriteOnce, ReadWriteMany`
-   `wait_until_bound` : Attesa fino al binding del PVC con il PV
