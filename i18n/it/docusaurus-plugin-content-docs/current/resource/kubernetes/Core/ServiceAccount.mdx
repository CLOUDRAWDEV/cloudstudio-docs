## Panoramica della risorsa

Account che concede ad applicazioni e servizi le autorizzazioni per accedere e utilizzare le risorse del cluster Kubernetes.

## Risorse correlate

### Risorsa principale

-   [**Namespace**](https://docs.cstudio.app/it/docs/resource/kubernetes/Core/Namespace)

### Risorse collegate

-   [**Secret**](https://docs.cstudio.app/it/docs/resource/kubernetes/Core/Secret)

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `namespace` : Namespace in cui verrà distribuita la risorsa ServiceAccount
-   `annotations` : Metadati di sistema Kubernetes
-   `labels` : Etichette per identificazione e classificazione del ServiceAccount
-   `secret` : Elenco dei Secret consentiti per i Pod che fanno riferimento a questo ServiceAccount
-   `image_pull_secrets` : Elenco dei Secret utilizzati dai Pod per il pull delle immagini
-   `automount_service_account_token` : Se montare automaticamente il token del ServiceAccount nel Pod
