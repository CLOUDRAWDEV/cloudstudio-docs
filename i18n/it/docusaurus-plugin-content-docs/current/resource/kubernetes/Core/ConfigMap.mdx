## Panoramica della risorsa

È una risorsa Kubernetes utilizzata per separare e memorizzare le informazioni di configurazione dell'applicazione e per trasferirle ai contenitori all'interno del pod.

## Impostazioni della risorsa

-   `service_name` : Nome della risorsa ConfigMap
-   `namespace` : Namespace in cui la risorsa ConfigMap sarà distribuita
-   `annotations` : Coppie chiave-valore utilizzate per visualizzare informazioni necessarie nel sistema Kubernetes
-   `labels` : Valori personalizzati definiti dall'utente per distinguere gli oggetti
-   `data` : Dati generali in formato coppia chiave-valore - Utilizzato per memorizzare configurazioni in formato testo come file di configurazione, variabili di ambiente, ecc.
    -   `data.name` : Valore key dei dati
    -   `data.value` : Valore value dei dati
-   `binary_data` : Dati binari per una determinata chiave - Utilizzato per memorizzare file binari o altri dati in formato binario
    -   `data.name` : Valore key dei binary data
    -   `data.value` : Valore value dei binary data
