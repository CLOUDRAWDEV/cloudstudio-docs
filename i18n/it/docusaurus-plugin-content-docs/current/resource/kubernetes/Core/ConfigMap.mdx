## Panoramica della risorsa

Risorsa Kubernetes utilizzata per separare e archiviare le informazioni di configurazione dell’applicazione e fornirle ai container all’interno dei Pod.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `namespace` : Namespace in cui verrà distribuita la risorsa ConfigMap
-   `annotations` : Metadati di sistema Kubernetes
-   `data` : Archiviazione dei dati di configurazione testuali in formato key-value
-   `labels` : Etichette personalizzate per identificazione e classificazione della risorsa
-   `binary_data` : Archiviazione di dati in formato binario in formato key-value
