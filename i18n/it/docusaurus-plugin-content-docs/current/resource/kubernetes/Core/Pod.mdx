## Panoramica della risorsa

Servizio Kubernetes che rappresenta la più piccola unità di deploy, in grado di eseguire uno o più container insieme.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `namespace` : Namespace in cui verrà distribuita la risorsa Pod
-   `annotations` : Metadati di sistema Kubernetes
-   `labels` : Etichette personalizzate per identificazione e classificazione del Pod
-   `pod_security_context` : Configurazione di sicurezza e privilegi a livello di Pod
-   `init_containers` : Definizione dei container di inizializzazione eseguiti prima del container principale
-   `containers` : Definizione dello spec dei container eseguiti nel Pod
-   `containers.image` : Immagine del container
-   `containers.resources` : Richieste e limiti di CPU / Memoria
-   `containers.probe` : Configurazione delle probe startup, liveness e readiness
-   `containers.env` : Definizione delle variabili d’ambiente
-   `containers.env_from` : Iniezione delle variabili d’ambiente basata su ConfigMap / Secret
-   `containers.command` : Comando di esecuzione del container
-   `containers.args` : Argomenti di esecuzione del container
-   `containers.port` : Porte esposte dal container
-   `containers.volume_mount` : Percorsi dei volumi montati nel container
-   `volume` : Definizione dei volumi utilizzati dal Pod
-   `dns_policy` : Configurazione della policy DNS
-   `enable_service_links` : Iniezione automatica delle variabili d’ambiente dei servizi
-   `host_network` : Utilizzo della rete host
-   `image_pull_secrets` : Elenco dei Secret utilizzati per il pull delle immagini
