## Panoramica della risorsa

La più piccola unità di distribuzione di Kubernetes che esegue più di un contenitore insieme.

## Impostazioni della risorsa

-   `service_name` : Nome delle risorse del Pod
-   `namespace` : Namespace in cui verranno distribuite le risorse del Pod
-   `annotations` : Pair chiave-valore utilizzato per visualizzare le informazioni necessarie nel sistema Kubernetes
-   `labels` : Valori che l'utente può definire arbitrariamente per distinguere gli oggetti
-   `containers` : Definisce il template per i contenitori all'interno del Pod - dopo aver configurato i valori di default, è possibile configurare i valori specifici.
    -   `containers.name` : Definisce il nome del contenitore
        -   `image` : Nome dell'immagine Docker da utilizzare
        -   `args` : Comando da eseguire all'interno del contenitore
        -   `command` : Comando da eseguire all'interno del contenitore
        -   `port` : Elenco delle porte da esporre nel contenitore

        -   `resources` : Definisce la quantità di risorse computazionali per il contenitore - configurazioni avanzate
            -   `name` : Definisce la quantità minima/massima delle risorse computazionali - `Limits`, `requests`     
            -   `cpu` : Definisce la quantità di CPU  
            -   `memory` : Definisce la quantità di memoria

        -   `probe` : Definisce il metodo per diagnosticare lo stato del Pod - configurazioni avanzate
            -   `name` : Sceglie il metodo di Probe - `startup`,`liveness`,`readiness`
            -   `http_get_path` : Percorso per accedere al server HTTP
            -   `http_get_port` : Numero della porta per accedere al contenitore
            -   `http_header` : Intestazioni personalizzate da impostare nella richiesta
            -   `initial_delay_seconds` : Tempo (in secondi) prima che inizi il probe dopo l'avvio del contenitore
            -   `period_seconds` : Frequenza (in secondi) con cui viene eseguito il probe

        -   `env` : Blocco di coppie chiave-valore da impostare nell'ambiente del contenitore - configurazioni avanzate
            -   `name` : Imposta il nome della variabile env
            -   `value` : Imposta il valore della variabile env

        -   `volume_mount` : Volume del Pod da montare nel filesystem del contenitore - configurazioni avanzate
            -   `name` : Imposta il nome del volume montato
            -   `path` 
                -   `mount_path` : Percorso all'interno del contenitore dove montare il volume
                -   `sub_path` : Percorso all'interno del contenitore dove montare il volume
            
-   `volume` : Elenco dei volumi che i contenitori del Pod possono montare
    -   `name` : Nome del volume
        -   `type` : Tipo di volume da montare - `EmptyDir`,`ConfigMap`,`PersistentVolumeClaim`
        -   `target_name` : Nome del PersistentVolumeClaim
        -   `default_mode` : Modalità di accesso ai file creati - tra 0 e 0777, il valore predefinito è 0644
        -   `read_only` : Se true, il volume sarà montato in modalità sola lettura, altrimenti sarà montato in modalità lettura/scrittura

-   `image_pull_secrets` : Secret nel medesimo namespace contenente le credenziali necessarie per scaricare l'immagine utilizzata dal contenitore
