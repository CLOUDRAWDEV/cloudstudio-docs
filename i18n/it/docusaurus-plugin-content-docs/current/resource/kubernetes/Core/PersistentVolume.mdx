Risorsa Kubernetes che fornisce storage collegato in rete al cluster.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `annotations` : Metadati di sistema Kubernetes
-   `labels` : Etichette personalizzate per identificazione e classificazione del PV
-   `spec.storage_class_name` : Nome dello StorageClass da utilizzare
-   `spec.storage_capacity` : Capacità di storage
-   `spec.volume_driver` : Driver di volume basato su CSI
-   `spec.volume_handle` : Identificatore della risorsa di storage reale
-   `spec.persistent_volume_reclaim_policy` : Politica di gestione del volume al rilascio del claim -`Retain / Delete / Recycle`
-   `spec.read_only` : Modalità di sola lettura del volume
-   `spec.volume_attributes` : Attributi aggiuntivi del volume specifici del driver
-   `spec.access_modes` : Modalità di accesso al volume - `ReadOnlyMany, ReadWriteOnce, ReadWriteMany`
-   `spec.mount_options` : Opzioni di mount aggiuntive
-   `node_stage_secret_ref` : Riferimento al Secret contenente le credenziali di accesso allo storage
