## Panoramica della risorsa

È una risorsa Kubernetes utilizzata per fornire uno storage connesso in rete al cluster.

## Impostazioni della risorsa

-   `service_name` : Nome della risorsa PersistentVolume
-   `annotations` : Coppie chiave-valore utilizzate per visualizzare informazioni necessarie nel sistema Kubernetes
-   `labels` : Valori personalizzati definiti dall'utente per distinguere gli oggetti
-   `spec` : Definisce le specifiche dettagliate del Persistent Volume
    -   `spec.storage_class_name` : Nome della storage class da utilizzare
    -   `spec.storage_capacity` : Capacità di storage da utilizzare
    -   `spec.volume_driver` : Driver del volume da utilizzare
    -   `spec.volume_handle` : Identificatore che collega il PV alle risorse di storage effettive
    -   `spec.persistent_volume_reclaim_policy` : Politica di recupero del volume quando viene rimosso da una claim - `retain`,`delete`,`recycle`
    -   `spec.read_only` : Specifica se forzare la modalità di sola lettura sui mount del volume - `false`,`true`
    -   `spec.volume_attributes` : Attributi del volume da utilizzare
    -   `spec.access_modes` : Modalità di accesso per il volume - `ReadOnlyMany`,`ReadWriteOnce`,`ReadWriteMany`
    -   `spec.mount_options` : Opzioni di montaggio aggiuntive
-   `node_stage_secret_ref` : Specifica il secret Kubernetes contenente l'autenticazione per accedere allo storage
    -   `node_stage_secret_ref.name` : Nome del secret
    -   `node_stage_secret_ref.namespace` : Namespace del secret
