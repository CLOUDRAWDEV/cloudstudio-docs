## Panoramica della risorsa

È una risorsa Kubernetes utilizzata per eseguire lavori una tantum.

## Impostazioni della risorsa

-   `service_name` : Nome della risorsa Job
-   `namespace` : Namespace in cui la risorsa Job sarà distribuita
-   `annotations` : Coppie chiave-valore utilizzate per visualizzare informazioni necessarie nel sistema Kubernetes
-   `labels` : Valori personalizzati definiti dall'utente per distinguere gli oggetti
-   `template_labels` : Etichette da impostare per i pod (Pod) generati su ciascun nodo
-   `restart_policy` : Definisce cosa fare quando un contenitore all'interno di un pod fallisce o quando il lavoro è completato
-   `backoff_limit` : Numero di tentativi di riesecuzione prima di segnare il lavoro come fallito - il valore predefinito è 6
-   `wait_for_completion` : Blocca la creazione o l'aggiornamento del lavoro fino a quando lo stato del lavoro non raggiunge la condizione di completamento o fallimento - il valore predefinito è True

-   `timeouts` : Tempo consentito prima che il lavoro sia considerato fallito
    -   `create` : Tempo per creare un nuovo lavoro e attendere che venga completato con successo - valore predefinito 1m  
    -   `update` : Tempo per aggiornare un lavoro esistente e attendere che venga completato con successo - valore predefinito 1m

-   `containers` : Definisce il template per i contenitori all'interno del pod (Pod) - dopo aver impostato e applicato la configurazione di base, è possibile configurare i dettagli successivamente.
    -   `name` : Nome del contenitore
        -   `image` : Nome dell'immagine Docker da utilizzare
        -   `args` : Comandi da eseguire all'interno del contenitore
        -   `command` : Comando da eseguire all'interno del contenitore
        -   `port` : Elenco delle porte da esporre dal contenitore

        -   `resources` : Quantità di risorse computazionali assegnate al contenitore - configurazione dettagliata
            -   `name` : Quantità minima/massima di risorse computazionali - `limits`, `requests`     
            -   `cpu` : Quantità di CPU da assegnare   
            -   `memory` : Quantità di memoria da assegnare

        -   `probe` : Metodo per diagnosticare lo stato del pod (Pod) - configurazione dettagliata
            -   `name` : Tipo di probe - `startup`,`liveness`,`readiness`
            -   `http_get_path` : Percorso per accedere al server HTTP
            -   `http_get_port` : Numero di porta per accedere al contenitore
            -   `http_header` : Header personalizzati da impostare per la richiesta
            -   `initial_delay_seconds` : Tempo (in secondi) prima che la probe inizi dopo l'avvio del contenitore
            -   `period_seconds` : Frequenza con cui eseguire la probe (in secondi)

        -   `env` : Blocchi di coppie chiave-valore da impostare come variabili di ambiente per il contenitore - configurazione dettagliata
            -   `name` : Nome della variabile di ambiente
            -   `value` : Valore da assegnare alla variabile di ambiente

        -   `volume_mount` : Volumi del pod (Pod) da montare nel sistema file del contenitore - configurazione dettagliata
            -   `name` : Nome del volume da montare
            -   `path` 
                -   `mount_path` : Percorso del contenitore dove montare il volume
                -   `sub_path` : Sottopercorso nel contenitore dove montare il volume
            
-   `volume` : Elenco dei volumi che i contenitori del pod (Pod) possono montare
    -   `name` : Nome del volume
        -   `type` : Tipo di volume da montare - `EmptyDir`,`ConfigMap`,`PersistentVolumeClaim`
        -   `target_name` : Nome del Persistent Volume Claim
        -   `default_mode` : Modalità per i file creati - tra 0 e 0777, valore predefinito 0644
        -   `read_only` : Se true, il volume sarà montato in sola lettura, altrimenti sarà montato in modalità lettura/scrittura

-   `image_pull_secrets` : Segreti nel medesimo namespace contenenti i permessi necessari per scaricare l'immagine utilizzata dal contenitore
