## Panoramica della risorsa

Servizio Kubernetes che garantisce che un numero specificato di repliche di Pod venga eseguito in qualsiasi momento.

## Impostazioni della risorsa

-   `service_name` : Nome delle risorse Deployment
-   `namespace` : Namespace in cui verrà distribuito il servizio Deployment
-   `annotations` : Key-value utilizzati per visualizzare le informazioni necessarie nel sistema Kubernetes
-   `labels` : Valori personalizzati assegnati dall'utente per distinguere gli oggetti
-   `template_labels` : Etichetta (Label) che verrà impostata per i Pod creati su ciascun nodo
-   `replicas` : Numero di repliche desiderate del Pod - il valore predefinito è 1

-   `containers` : Definisce il template per i container appartenenti al Pod - le impostazioni predefinite vengono configurate e successivamente si possono definire i dettagli specifici.
    -   `containers.name` : Definisce il nome del container
        -   `image` : Nome dell'immagine Docker da utilizzare
        -   `args` : Comandi da eseguire all'interno del container
        -   `command` : Comandi da eseguire all'interno del container
        -   `port` : Elenco delle porte che il container esporrà

        -   `resources` : Definisce la quantità di risorse computazionali per il container - Impostazioni dettagliate
            -   `resources.name` : Definisce la quantità minima/massima delle risorse computazionali - `Limits`, `requests`     
            -   `resources.cpu` : Quantità di CPU da assegnare  
            -   `resources.memory` : Quantità di memoria da assegnare

        -   `probe` : Metodo per diagnosticare lo stato del Pod - Impostazioni dettagliate
            -   `probe.name` : Selezione del metodo Probe - `startup`,`liveness`,`readiness`
            -   `probe.http_get_path` : Percorso per accedere al server HTTP
            -   `probe.http_get_port` : Numero di porta da cui il container accederà
            -   `probe.http_header` : Header personalizzati da impostare nella richiesta
            -   `probe.initial_delay_seconds` : Tempo (in secondi) prima che il probe inizi, dopo che il container è stato avviato
            -   `probe.period_seconds` : Frequenza con cui viene eseguito il probe (in secondi)

        -   `env` : Blocco di coppie key-value da configurare nell'ambiente del container - Impostazioni dettagliate
            -   `env.name` : Nome della variabile di ambiente
            -   `env.value` : Valore da assegnare alla variabile di ambiente

        -   `volume_mount` : Volume del Pod da montare nel file system del container - Impostazioni dettagliate
            -   `volume_mount.name` : Nome del volume da montare
            -   `volume_mount.path` 
                -   `volume_mount.path.mount_path` : Percorso nel container in cui montare il volume
                -   `volume_mount.path.sub_path` : Percorso nel container in cui montare il volume
            
-   `volume` : Elenco dei volumi che i container nel Pod possono montare
    -   `volume.name` : Nome del volume
        -   `volume.type` : Tipo di volume da montare - `EmptyDir`,`ConfigMap`,`PersistentVolumeClaim`
        -   `volume.target_name` : Nome del PersistentVolumeClaim
        -   `volume.default_mode` : Modalità da usare sui file creati - tra 0 e 0777, valore predefinito è 0644
        -   `volume.read_only` : Se impostato su true, il volume sarà montato in modalità sola lettura, altrimenti sarà montato in modalità lettura/scrittura

-   `image_pull_secrets` : Secret che contiene i permessi necessari per recuperare le immagini dal container nel namespace corrente
