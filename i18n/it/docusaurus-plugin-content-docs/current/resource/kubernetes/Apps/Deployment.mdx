## Panoramica della risorsa

Deployment è una risorsa Kubernetes che garantisce che un numero specificato di repliche di Pod sia sempre in esecuzione.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `namespace` : Namespace in cui verrà distribuita la risorsa Deployment
-   `annotations` : Metadati key-value del sistema Kubernetes
-   `labels` : Etichette per identificare la risorsa Deployment
-   `template_labels` : Etichette applicate ai Pod che verranno creati
-   `replicas` : Numero di repliche di Pod da mantenere
-   `pod_security_context` : Impostazioni di sicurezza e autorizzazioni a livello di Pod
-   `init_containers` : Definizione dei container di inizializzazione eseguiti prima del container principale
-   `containers` : Definizione dei container inclusi nel Pod
-   `volume` : Definizione dei volumi utilizzati dal Pod
-   `dns_policy` : Policy DNS del Pod
-   `enable_service_links` : Abilitazione dell’iniezione automatica delle variabili di ambiente dei servizi
-   `host_network` : Abilitazione dell’uso della rete host
-   `image_pull_secrets` : Elenco dei Secret utilizzati per il pull delle immagini
