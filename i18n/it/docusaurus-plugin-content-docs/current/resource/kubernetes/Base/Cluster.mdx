## Valori di configurazione della risorsa

#### Impostazioni di base

-   `target_cluster` : Selezione del cluster Kubernetes Ncloud da collegare
-   `token` : Token di autenticazione utilizzato per la connessione al servizio Ncloud Kubernetes
