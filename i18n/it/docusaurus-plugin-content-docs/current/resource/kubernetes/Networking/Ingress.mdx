## Panoramica della Risorse

È una risorsa di Kubernetes che definisce le regole per consentire a una connessione in ingresso di raggiungere un endpoint definito nel backend.

## Impostazioni della risorsa

-   `service_name` : Nome della risorsa Ingress
-   `namespace` : Namespace in cui verrà distribuita la risorsa Ingress
-   `annotations` : Key-value utilizzato per visualizzare le informazioni necessarie al sistema Kubernetes
-   `labels` : Valori arbitrari definiti dall'utente per distinguere gli oggetti
-   `tls` : Abilita il TLS (Transport Layer Security)
    -   `hosts` : Elenco degli host inclusi nel certificato TLS
    -   `secret_name` : Nome del Kubernetes Secret relativo al certificato TLS
-   `ingress_class_name` : Nome della classe Ingress a cui connettersi
-   `host` : Indirizzo hostname su cui applicare le regole di routing
-   `backend` : Informazioni sul backend per il routing
    -   `name` : Nome della regola di routing
        -   `path` : Percorso per la connessione con il backend
        -   `path_type` : Determina come interpretare la corrispondenza del percorso - `Prefix`, `ImplementationSpecific`, `Exact`
        -   `port` : Numero di porta del servizio - `1~65535`
