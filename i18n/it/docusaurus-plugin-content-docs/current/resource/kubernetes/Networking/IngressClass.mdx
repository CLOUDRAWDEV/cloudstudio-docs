## Panoramica della risorsa

Risorsa Kubernetes utilizzata per selezionare il controller Ingress da utilizzare.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `annotations` : Metadati key-value necessari al funzionamento di IngressClass nel sistema Kubernetes
-   `labels` : Etichette personalizzate per identificare l’oggetto IngressClass
-   `controller` : Identificatore del controller Ingress che gestirà questa IngressClass

#### Configurazione parametri (parameters)

-   `parameters.kind` : Tipo di risorsa parametro da referenziare - `IngressParameter`, `ClusterIngressParameter`
-   `parameters.namespace` : Namespace della risorsa parametro referenziata
-   `parameters.api_group` : API Group a cui appartiene la risorsa parametro referenziata
