## Panoramica della risorsa

È una risorsa Kubernetes che scala automaticamente il numero di pod (Pod) di Deployment, ReplicaSet e StatefulSet in base all'utilizzo osservato della CPU.

## Impostazioni della risorsa

-   `service_name` : Nome della risorsa HPA
-   `namespace` : Namespace in cui la risorsa HPA sarà distribuita
-   `annotations` : Coppie chiave-valore utilizzate per visualizzare informazioni necessarie nel sistema Kubernetes
-   `labels` : Valori personalizzati definiti dall'utente per distinguere gli oggetti
-   `min_replicas` : Numero minimo di pod che può essere configurato nell'HPA - il valore predefinito è 1
-   `max_replicas` : Numero massimo di pod che può essere configurato nell'HPA
-   `target_cpu_utilization_percentage` : Percentuale di utilizzo medio della CPU obiettivo per i pod (espressa come percentuale della CPU richiesta)
-   `scale_target_ref` : Riferimento alla risorsa da espandere
    -   `name` : Nome della risorsa a cui fare riferimento
    -   `kind` : Tipo di risorsa a cui fare riferimento - `Deployment`, `StatefulSet`
