## Panoramica della risorsa

HorizontalPodAutoscaler è una risorsa Kubernetes che scala automaticamente il numero di Pod di Deployment, ReplicaSet e StatefulSet in base all’utilizzo osservato della CPU.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `namespace` : Namespace in cui verrà distribuita la risorsa HPA
-   `annotations` : Metadati key-value del sistema Kubernetes
-   `labels` : Etichette per identificare la risorsa HPA
-   `min_replicas` : Numero minimo di Pod da mantenere durante lo scaling automatico
-   `max_replicas` : Numero massimo di Pod da mantenere durante lo scaling automatico
-   `target_cpu_utilization_percentage` : Valore target medio di utilizzo CPU dei Pod
-   `scale_target_ref` : Riferimento al controller di destinazione per lo scaling (Deployment, StatefulSet)
