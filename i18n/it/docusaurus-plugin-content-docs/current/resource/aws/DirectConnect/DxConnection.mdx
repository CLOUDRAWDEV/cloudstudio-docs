## Panoramica della risorsa

Con AWS Direct Connect, puoi connettere la tua rete interna alla posizione di AWS Direct Connect tramite un cavo in fibra ottica Ethernet standard. Un'estremità del cavo viene collegata al router dell'utente e l'altra estremità al router di AWS Direct Connect. Questa connessione consente di creare interfacce virtuali, bypassando il percorso di rete pubblico di AWS e ISP per il trasferimento di servizi (ad esempio, Amazon S3) o per la comunicazione con Amazon VPC. AWS Direct Connect fornisce l'accesso ai servizi nelle regioni pubbliche di AWS tramite una connessione singola, sia per la regione pubblica di AWS sia per AWS GovCloud (US), nonché per tutti gli altri servizi di altre regioni pubbliche di AWS.
