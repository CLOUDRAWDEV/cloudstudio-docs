## Panoramica della risorsa

Amazon Elastic Container Registry (Amazon ECR) è un servizio di registro di immagini per container sicuro, scalabile e affidabile gestito da AWS. Amazon ECR supporta i repository privati con autorizzazioni basate su risorse utilizzando AWS IAM. Pertanto, gli utenti o le istanze Amazon EC2 specificate possono accedere ai repository di container e alle immagini. È possibile utilizzare la CLI desiderata per eseguire il push, il pull e la gestione di immagini Docker, immagini Open Container Initiative (OCI) e artefatti compatibili con OCI.

## Impostazioni della risorsa

-   `image_tag_mutability` : Impostazione della modificabilità del tag nel repository - `IMMUTABLE`, `MUTABLE`
-   `scan_on_push` : Impostazione se l'immagine viene scansionata dopo essere stata spinta nel repository - `true`, `false`
-   `encryption_type` : Tipo di crittografia da utilizzare nel repository - `KMS`, `AES256`
-   `kms_key_name` : Nome ARN della KMS Key da utilizzare
-   `target_principal_arn` : ARN del destinatario a cui applicare la Policy
