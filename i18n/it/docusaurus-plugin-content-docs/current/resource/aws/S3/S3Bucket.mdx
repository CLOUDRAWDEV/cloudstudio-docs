## Panoramica della risorsa

Amazon Simple Storage Service (Amazon S3) è un servizio di archiviazione oggetti che offre la migliore scalabilità, disponibilità dei dati, sicurezza e performance del settore. Clienti di tutte le dimensioni e settori possono utilizzare Amazon S3 per archiviare e proteggere grandi quantità di dati in una varietà di casi d'uso, tra cui data lake, siti web, applicazioni mobili, backup e ripristino, archiviazione, applicazioni aziendali, dispositivi IoT e analisi di big data. Amazon S3 fornisce funzionalità di gestione che consentono di ottimizzare, strutturare e configurare l'accesso ai dati in base alle esigenze aziendali, organizzative e normative.

## Impostazioni della risorsa

-   `versioning_status` : Stato della gestione delle versioni del bucket - `Enabled`, `Suspended`
-   `logging_target_prefix` : Prefisso per la chiave di tutti gli oggetti di log
-   `sse_algorithm` : Algoritmo di crittografia lato server da utilizzare - `aws:kms`, `AES256
-   `kms_key_name` : Nome della chiave master AWS KMS utilizzata per la crittografia SSE-KMS
-   `public_access_block` : Nome del blocco dell'accesso pubblico S3

    -   `block_public_acls` : Se Amazon S3 deve bloccare gli ACL pubblici per il bucket - `true`, `false`
    -   `block_public_policy` : ASe Amazon S3 deve bloccare la policy pubblica del bucket - `true`, `false`
    -   `ignore_public_acls` : Se Amazon S3 deve ignorare gli ACL pubblici per il bucket - `true`, `false`
    -   `restrict_public_buckets` : Se Amazon S3 deve limitare la policy pubblica per il bucket - `true`, `false`

-   `ownership_control`
    -   `acl_enabled` : Abilitazione dell'uso del controllo delle ACL e della proprietà degli oggetti nel bucket S3 - `true`, `false`
    -   `object_ownership` : Metodo di proprietà degli oggetti nel bucket S3 - `BucketOwnerEnforced`, `BucketOwnerPreferred`, `ObjectWriter`
