## Valori di configurazione della risorsa

#### Impostazioni di base

-   `display_name` : Nome visualizzato del topic SNS
-   `type` : Tipo di topic SNS (`FIFO`, `Standard`)
-   `kms_key_name` : Nome della chiave KMS utilizzata dal topic SNS

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
