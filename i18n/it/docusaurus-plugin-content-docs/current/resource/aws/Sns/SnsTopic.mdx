## Impostazioni della risorsa

-   `display_name` : Nome visualizzato del SNS Topic
-   `type` : Tipo di SNS Topic - `FIFO`, `Standard`
-   `kms_key_name` : Nome della KMS Key da utilizzare per il SNS Topic
