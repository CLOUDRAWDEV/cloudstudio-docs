## Panoramica della risorsa

L'IPSet di AWS WAF è un elenco di indirizzi IP utilizzato dal Web Application Firewall di Amazon Web Services. Consente agli utenti di creare e gestire regole di accesso per gli indirizzi IP definiti. Utilizzando l'IPSet, è possibile consentire o bloccare le richieste provenienti da specifici indirizzi IP, migliorando così la sicurezza delle applicazioni web.

## Impostazioni della risorsa

-   `scope` : Specifica se è per una distribuzione AWS CloudFront o per un'applicazione regionale - `REGIONAL`, `CLOUDFRONT`
-   `ip_address_version` : Specifica se utilizzare IPV4 o IPV6 - `IPV4`, `IPV6`
-   `addresses` : Array di stringhe che specificano uno o più indirizzi IP o blocchi di indirizzi IP in notazione CIDR.
