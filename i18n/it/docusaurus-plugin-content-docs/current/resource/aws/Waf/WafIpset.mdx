## Panoramica della risorsa

AWS WAF IP Set è una risorsa che raggruppa uno o più indirizzi IP o blocchi CIDR per essere utilizzata nelle regole di una Web ACL, permettendo di definire politiche di autorizzazione o blocco per specifici intervalli IP.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `scope` : Ambito di applicazione dell’IP Set - `REGIONAL`, `CLOUDFRONT`
-   `ip_address_version` : Versione dell’indirizzo IP - `IPV4`, `IPV6`
-   `addresses` : Elenco di indirizzi IP o blocchi IP in notazione CIDR

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
