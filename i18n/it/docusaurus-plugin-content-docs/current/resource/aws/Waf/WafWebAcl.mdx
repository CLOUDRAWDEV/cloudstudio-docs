## Panoramica della risorsa

AWS WAF Rule Group è un insieme di regole utilizzate dal Web Application Firewall.  
Consente di raggruppare più regole da applicare alle applicazioni web, migliorando la riutilizzabilità e l’efficienza di gestione.  
I rule group controllano aspetti fondamentali della sicurezza delle applicazioni web e determinano se una richiesta deve essere consentita, bloccata o conteggiata.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `scope` : Ambito di applicazione del Rule Group - `REGIONAL`, `CLOUDFRONT`
-   `capacity` : Capacità WCU (Web ACL Capacity Units) richiesta dal Rule Group
-   `cloudwatch_metrics_enabled` : Abilitazione dell’invio delle metriche a CloudWatch - `true`, `false`
-   `metric_name` : Nome della metrica CloudWatch, solo lettere maiuscole/minuscole, trattini e underscore, lunghezza `1` ~ `128`
-   `sampled_requests_enabled` : Salvataggio dei campioni delle richieste web che corrispondono alle regole - `true`, `false`

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
