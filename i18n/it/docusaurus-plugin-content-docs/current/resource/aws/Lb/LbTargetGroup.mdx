## Panoramica della risorsa

Servizio che instrada le richieste verso una o più destinazioni registrate, come istanze EC2, utilizzando il protocollo e la porta specificati.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `target_type` : Tipo di destinazione del load balancer - `instance`, `ip`, `lambda`, `alb`
-   `protocol` : Protocollo utilizzato per instradare il traffico verso le destinazioni - `HTTP`, `HTTPS`, `TCP`, `TCP_UDP`, `TLS`, `UDP`, `GENEVE`
-   `port` : Porta su cui viene ricevuto il traffico - `1` ~ `65535`
-   `included_vpc_name` : Nome del VPC in cui creare il target group
-   `linked_instance_names` : Elenco dei nomi delle istanze di destinazione
-   `ips` : Elenco degli IP di destinazione
-   `linked_lambda_name` : Nome della funzione Lambda di destinazione
-   `linked_application_lb_name` : Nome dell’Application Load Balancer di destinazione

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria - massimo 512 caratteri, `key`:`value`
