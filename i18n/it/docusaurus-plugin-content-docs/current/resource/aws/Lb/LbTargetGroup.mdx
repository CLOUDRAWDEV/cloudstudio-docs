## Panoramica della risorsa

Un servizio che instrada le richieste a uno o più target registrati utilizzando il protocollo e il numero di porta specificati, come per esempio un'istanza EC2

## Impostazioni della risorsa

-   `target_type` : Tipo di target del LB - `Instance`, `Ip`, `Lambda`, `Alb`
-   `protocol` : Protocollo utilizzato per instradare il traffico verso il target - `HTTP`,`HTTPS`,`TCP`,`TCP_UDP`,`TLS`
-   `port` : Porta che riceve il traffico - `1~65535`
-   `included_vpc_name` : Nome della VPC in cui creare il gruppo di target
-   `linked_instance_names` : Elenco nomi delle Target Instance
