## Valori di configurazione della risorsa

#### Impostazioni di base

-   `billing_mode` : Modalità di fatturazione e gestione della capacità di lettura e scrittura di DynamoDB - `PROVISIONED`, `PAY_PER_REQUEST`
-   `read_capacity` : Numero di unità di lettura della tabella DynamoDB
-   `write_capacity` : Numero di unità di scrittura della tabella DynamoDB
-   `hash_key` : Attributo utilizzato come chiave hash (partizione)
-   `hash_key_type` : Tipo dell’attributo della chiave hash - `S`, `N`, `B`
-   `range_key` : Attributo utilizzato come chiave di range (ordinamento)
-   `range_key_type` : Tipo dell’attributo della chiave di range - `S`, `N`, `B`
-   `point_in_time_recovery_enabled` : Abilitazione del ripristino a un punto temporale specifico - `true`, `false`

#### Crittografia lato server (`server_side_encryption`)

-   `server_side_encryption.encryption_enabled` : Abilitazione della crittografia dei dati a riposo tramite chiave KMS gestita da AWS - `true`, `false`
-   `server_side_encryption.kms_key_name` : Nome della CMK AWS KMS utilizzata per la crittografia

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
