## Panoramica della risorsa

Amazon DynamoDB è un servizio di database NoSQL completamente gestito che offre prestazioni veloci e prevedibili con scalabilità senza interruzioni. Utilizzando Amazon DynamoDB, è possibile creare tabelle di database per archiviare o recuperare qualsiasi quantità di dati e gestire qualsiasi livello di traffico di richieste. Amazon DynamoDB distribuisce automaticamente i dati e il traffico delle tabelle su un numero sufficiente di server, mantenendo prestazioni coerenti e rapide mentre gestisce la capacità di richiesta e la quantità di dati archiviati specificate dal cliente.

## Impostazioni della risorsa

-   `billing_mode` : Il metodo di addebito per la capacità di lettura e scrittura di DynamoDB e come vengono gestiti i costi - `PROVISIONED`,`PAY_PER_REQUEST`
-   `read_capacity` : Numero di unità di lettura per la tabella DynamoDB
-   `write_capacity` : Numero di unità di scrittura per la tabella DynamoDB
-   `hash_key` : Attributo da utilizzare come chiave di hash (partizione)
-   `hash_key_type` : Tipo di chiave di hash (partizione) - `S`, `N`, `B`
-   `range_key` : Attributo da utilizzare come chiave di intervallo (ordinamento)s
-   `range_key_type` : Tipo di chiave di intervallo (ordinamento) - `S`, `N`, `B`
-   `point_in_time_recovery_enabled` : Attivazione della funzione di recupero a un punto nel tempo - `true`, `false`
-   `server_side_encryption` : Nome della Server Side Encryption
    -   `encryption_enabled` : Abilitazione della crittografia dei dati memorizzati utilizzando la chiave cliente KMS gestita da AWS - `true`, `false`
