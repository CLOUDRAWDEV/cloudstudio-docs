## Panoramica della risorsa

Virtual Private Cloud (VPC) è una rete virtuale dedicata esclusivamente all'account AWS dell'utente. Il VPC è logicamente separato da altre reti virtuali nell'AWS Cloud. Puoi avviare risorse AWS, come istanze Amazon EC2, all'interno di un VPC.

La connessione di VPC Peering è una connessione di rete tra due VPC che consente di instradare il traffico utilizzando indirizzi IPv4 privati o IPv6. Questo consente alle istanze dei VPC di comunicare come se appartenessero alla stessa rete. È possibile creare una connessione di peering tra il proprio VPC o il VPC di un altro account AWS. 
I VPC possono trovarsi in regioni diverse (questa è nota come connessione di peering tra regioni).

## Impostazioni della risorsa

-   `linked_vpc_name_01` : Nome del VPC per fare il peering
-   `linked_vpc_name_02` : Nome del VPC per fare il peering
-   `auto_accept` : Se accettare automaticamente la connessione di peering - `true`, `false`
