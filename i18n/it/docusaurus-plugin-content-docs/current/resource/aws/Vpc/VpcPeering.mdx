## Panoramica della risorsa

Virtual Private Cloud (VPC) è una rete virtuale dedicata all’account AWS dell’utente ed è logicamente isolata dalle altre reti virtuali presenti nel cloud AWS.  
È possibile avviare risorse AWS, come istanze Amazon EC2, all’interno di un VPC.

Una connessione di VPC Peering è una connessione di rete tra due VPC che consente di instradare il traffico utilizzando indirizzi IPv4 o IPv6 privati. Le istanze nei VPC possono comunicare tra loro come se fossero nella stessa rete.  
È possibile creare una connessione di peering tra il proprio VPC o con un VPC appartenente a un altro account AWS. I VPC possono trovarsi in regioni diverse (peering VPC inter-regionale).

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `linked_vpc_name_01` : Nome del VPC che richiede la connessione di peering
-   `linked_vpc_name_02` : Nome del VPC di destinazione per la connessione di peering
-   `auto_accept` : Accettazione automatica della connessione di peering - `true`, `false`

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
