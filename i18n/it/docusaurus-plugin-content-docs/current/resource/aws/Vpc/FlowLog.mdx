## Panoramica della risorsa

I VPC Flow Log consentono di acquisire informazioni sul traffico IP inviato e ricevuto dalle interfacce di rete di un VPC.  
I dati dei Flow Log possono essere pubblicati su Amazon CloudWatch Logs, Amazon S3 o Amazon Kinesis Data Firehose.  
Una volta creati, è possibile cercare e visualizzare i record dei Flow Log nel log group, bucket o stream di consegna configurato.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `linked_log_destination_type` : Tipo di destinazione dei log (S3, CloudWatch Logs)
-   `linked_log_destination_name` : Nome della destinazione dei log
-   `traffic_type` : Tipo di traffico da raccogliere - `ALL`, `ACCEPT`, `REJECT`
-   `included_vpc_name` : Nome del VPC a cui collegare il Flow Log

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
