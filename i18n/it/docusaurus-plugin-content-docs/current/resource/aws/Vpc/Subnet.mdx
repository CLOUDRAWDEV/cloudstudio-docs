## Panoramica della risorsa

Una subnet è un intervallo di indirizzi IP all’interno di un VPC.  
È possibile creare risorse AWS, come le istanze EC2, all’interno di una specifica subnet.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `included_vpc_name` : Nome del VPC in cui distribuire la subnet
-   `cidr_block` : Blocco CIDR degli indirizzi IP della subnet
-   `availability_zone` : Zona di disponibilità in cui distribuire la subnet
-   `pip_enable` : Abilitazione dell’assegnazione automatica di IP pubblici - `true`, `false`

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
