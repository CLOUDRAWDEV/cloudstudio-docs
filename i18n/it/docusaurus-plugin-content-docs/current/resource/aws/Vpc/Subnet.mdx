## Panoramica della risorsa

Il subnet è un intervallo di indirizzi IP all'interno di un VPC. Puoi creare risorse AWS, come ad esempio un'istanza EC2, in un subnet specifico.

## Impostazioni della risorsa

-   `included_vpc_name` : Nome del VPC in cui verrà distribuito il subnet
-   `cidr_block` : Intervallo IP (CIDR) del subnet
-   `availability_zone` : Zona di disponibilità in cui verrà distribuito il subnet
-   `pip_enable` : Assegnazione di un IP pubblico (abilitazione)
