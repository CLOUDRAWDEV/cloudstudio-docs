## Panoramica della risorsa

Servizio che consente connessioni private ai servizi AWS supportati e ai servizi VPC Endpoint

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `acceptance_required` : Necessità di accettazione della richiesta di connessione da parte del proprietario del servizio - `true`, `false`
-   `load_balancer_type` : Tipo di Load Balancer collegato - `network`, `gateway`
-   `linked_lb_names` : Elenco dei nomi dei Load Balancer collegati
-   `manual_lb_arns` : Elenco degli ARN dei Load Balancer collegati
-   `supported_ip_address_types` : Tipi di indirizzi IP supportati - `ipv4`
-   `activate_private_dns_name` : Nome DNS privato associato al servizio

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
