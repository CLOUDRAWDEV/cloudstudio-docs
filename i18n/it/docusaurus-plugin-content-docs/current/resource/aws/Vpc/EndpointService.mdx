## Panoramica della risorsa

Servizio che consente di connettersi privatamente ai servizi AWS supportati e ai servizi VPC endpoint

## Impostazioni della risorsa

-   `acceptance_required` : Se il proprietario del servizio deve accettare la richiesta di connessione dell'endpoint VPC al servizio - `false`,`true`
-   `loadbalancer_type` : Tipo di load balancer da collegare al servizio endpoint - `network`, `gateway`
-   `linked_lb_names` : Nomi di una o più risorse Lb collegate al servizio endpoint
-   `manual_lb_arns` : Nome delle risorse Amazon (ARN) di uno o più dispositivi di bilanciamento del carico per il servizio endpoint
-   `supported_ip_address_types` : Tipi di indirizzi IP supportati - `ipv4`
-   `activate_private_dns_name` : Nome DNS privato del servizio
