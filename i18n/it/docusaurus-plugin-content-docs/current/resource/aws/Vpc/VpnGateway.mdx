## Panoramica della risorsa

Il Virtual Private Gateway è il dispositivo di terminazione VPN lato Amazon per una connessione Site-to-Site VPN. Puoi creare un Virtual Private Gateway e collegarlo al VPC in cui desideri creare la connessione Site-to-Site VPN.

## Risorse correlate

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Risorse collegate

-   [**Vpc**](https://docs.cstudio.app/docs/resource/aws/Vpc/)

-   [**Vpc Customer Gateway**](https://docs.cstudio.app/docs/resource/aws/Vpc/CustomerGateway)

## Impostazioni della risorsa

-   `linked_vpc_name` : Nome del VPC in cui sarà incluso il VPN Gateway
-   `vpn_connection` : Nome della connessione VPN
    -   `linked_customer_gateway` : Nome del Customer Gateway da collegare al VPN Gateway
    -   `static_routes_only` : Se utilizzare solo il routing statico tra i gateway - `true`, `false`
