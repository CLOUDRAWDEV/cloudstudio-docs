## Panoramica della risorsa

Un Virtual Private Gateway è il concentratore VPN sul lato Amazon di una connessione Site-to-Site VPN.  
Creando un Virtual Private Gateway, è possibile collegarlo al VPC in cui verrà stabilita la connessione Site-to-Site VPN.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `linked_vpc_name` : Nome del VPC a cui collegare il VPN Gateway
-   `dx_gateway` : Impostazioni di integrazione con Direct Connect Gateway
-   `dx_gateway.linked_dx_gateway` : Nome del Dx Gateway da collegare
-   `dx_gateway.allowed_prefixes` : Elenco dei prefissi CIDR da pubblicizzare verso la rete on-premise

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
