## Panoramica della risorsa

Un NAT Gateway è un servizio di Network Address Translation (NAT).  
Consente alle istanze presenti in subnet private di connettersi a servizi esterni al VPC, impedendo però ai servizi esterni di avviare connessioni verso tali istanze.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `included_subnet_name` : Nome della subnet a cui collegare il NAT Gateway
-   `connectivity_type` : Tipo di connettività del NAT Gateway - `public`, `private`
-   `linked_eip_name` : Nome dell’Elastic IP da associare

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
