## Panoramica della risorsa

Il NAT Gateway è un servizio di Network Address Translation (NAT). Può essere utilizzato per consentire alle istanze in una sottorete privata di connettersi ai servizi esterni al VPC, pur impedendo che i servizi esterni possano iniziare una connessione con queste istanze.

## Impostazioni della risorsa

-   `included_subnet_name` : Nome del subnet a cui collegare il NAT Gateway
-   `connectivity_type` : Tipo di connessione del NAT Gateway - `public`, `private`
-   `eip_name` : ENome dell'EIP
