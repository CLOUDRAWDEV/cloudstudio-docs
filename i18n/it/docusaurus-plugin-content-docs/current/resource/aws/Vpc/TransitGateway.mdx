## Panoramica della risorsa

Un Transit Gateway è un hub di trasporto di rete che consente di interconnettere Virtual Private Cloud (VPC) e reti on-premise.  
Con l’espansione globale dell’infrastruttura cloud, il peering tra regioni collega i Transit Gateway utilizzando l’infrastruttura globale di AWS.

I dati vengono automaticamente crittografati e non transitano attraverso Internet pubblico.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `dns_support` : Abilitazione della risoluzione DNS per i VPC collegati - `enable`, `disable`
-   `vpn_ecmp_support` : Supporto al routing ECMP (multipath) per VPN collegate - `enable`, `disable`
-   `default_route_table_association` : Associazione automatica degli attachment alla route table predefinita - `enable`, `disable`
-   `default_route_table_propagation` : Propagazione automatica degli attachment alla route table predefinita - `enable`, `disable`
-   `multicast_support` : Abilitazione della creazione di domini multicast - `enable`, `disable`
-   `transit_gateway_cidr_blocks` : Elenco dei blocchi CIDR assegnati al Transit Gateway

#### Impostazioni Direct Connect Gateway (`dx_gateway`)

-   `dx_gateway.linked_dx_gateway` : Nome del Direct Connect Gateway da collegare
-   `dx_gateway.allowed_prefixes` : Elenco dei prefix VPC (CIDR) annunciati verso la rete on-premise

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
