## Panoramica della risorsa

Il Transit Gateway è un hub di trasporto di rete che può essere utilizzato per connettere una Virtual Private Cloud (VPC) con una rete on-premises. Con l'espansione globale dell'infrastruttura cloud, il peer tra regioni collega insieme i Transit Gateway utilizzando l'infrastruttura globale di AWS. I dati sono automaticamente criptati e non vengono trasmessi tramite internet pubblico.

## Impostazioni della risorsa

-   `dns_support` : Abilitazione della risoluzione del sistema di nomi di dominio per il VPC connesso - `enable`, `disable`
-   `vpn_ecmp_support` : Supporto per il routing ECMP (Equal-Cost Multi-Path) per la VPN connessa - `enable`, `disable`
-   `default_route_table_association` : Associazione automatica dell'Attachment alla tabella di routing predefinita - `enable`, `disable`
-   `default_route_table_propagation` :  Propagazione automatica dell'Attachment alla tabella di routing predefinita - `enable`, `disable`
-   `multicast_support` : Abilitazione della creazione di domini multicast - `enable`, `disable`
-   `transit_gateway_cidr_blocks` : Blocchi CIDR del Transit Gateway
-   `vpc_attachment`
