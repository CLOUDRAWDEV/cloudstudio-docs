## Panoramica della risorsa

Un Internet Gateway è un componente VPC ridondante, altamente disponibile e scalabile orizzontalmente, che consente la comunicazione tra un VPC e Internet. Supporta il traffico IPv4 e IPv6 senza introdurre rischi di disponibilità o limitazioni di larghezza di banda.

Quando una risorsa dispone di un indirizzo IPv4 pubblico o IPv6, l’uso di un Internet Gateway consente alle risorse nelle subnet pubbliche (ad esempio istanze EC2) di accedere a Internet. Allo stesso modo, le risorse su Internet possono avviare connessioni verso le risorse nella subnet utilizzando indirizzi IPv4 pubblici o IPv6.  
Ad esempio, un Internet Gateway consente di collegarsi a un’istanza EC2 su AWS da un computer locale.

Un Internet Gateway fornisce una destinazione per il traffico instradabile verso Internet nelle tabelle di routing del VPC.  
Per le comunicazioni IPv4, l’Internet Gateway esegue anche la Network Address Translation (NAT).  
Per le comunicazioni IPv6, non è necessario il NAT poiché gli indirizzi IPv6 sono pubblici.
