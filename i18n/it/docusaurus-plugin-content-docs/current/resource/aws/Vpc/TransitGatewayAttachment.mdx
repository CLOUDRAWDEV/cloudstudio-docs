## Panoramica della risorsa

Servizio utilizzato per collegare un VPC a un Transit Gateway o a una rete on-premise.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `linked_transit_gateway_name` : Nome del Transit Gateway da collegare al VPC
-   `is_manual` : Inserimento manuale dell’ID del VPC da collegare - `true`, `false`
-   `linked_vpc_name` : Nome del VPC da collegare al Transit Gateway
-   `subnet_names` : Elenco dei nomi delle subnet da collegare al Transit Gateway

#### Impostazioni di collegamento manuale (`manual`)

-   `vpc_id` : ID del VPC da collegare al Transit Gateway
-   `subnet_ids` : Elenco degli ID delle subnet all’interno del VPC specificato da `vpc_id`

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
