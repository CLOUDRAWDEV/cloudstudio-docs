## Panoramica della risorsa

Risorsa che rappresenta il gateway del cliente utilizzato per connettere una rete on-premise a AWS tramite VPN o Transit Gateway

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `bgp_asn` : Valore ASN BGP del gateway - `1` ~ `2147483647`
-   `ip_address` : Indirizzo IP pubblico statico dell’interfaccia esterna del gateway
-   `private_certificate_arn` : ARN del certificato AWS Private Certificate Manager

#### Impostazioni connessione VPN (`vpn_connection`)

-   `vpn_connection.resource_type` : Tipo di risorsa da collegare al Customer Gateway - `none`, `transit_gateway`, `vpn_gateway`
-   `vpn_connection.linked_resource_name` : Nome della risorsa da collegare
-   `vpn_connection.static_routes_only` : Utilizzo esclusivo di routing statico - `true`, `false`
-   `vpn_connection.outside_ip_address_type` : Tipo di indirizzo IP esterno - `PublicIpv4`, `PrivateIpv4`
-   `vpn_connection.dx_gateway_name` : Nome dell’attachment del Transit Gateway per VPN con IP privato

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
