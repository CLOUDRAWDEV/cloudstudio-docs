## Panoramica della risorsa

AWS Transit Gateway collega l'Amazon Virtual Private Cloud (VPC) e la rete on-premise tramite un hub centrale. Questa connessione semplifica la rete eliminando relazioni di peering complesse. Transit Gateway funge da router cloud altamente scalabile.

## Impostazioni della risorsa

-   `bgp_asn` : ASN (Autonomous System Number) BGP (Border Gateway Protocol) del gateway
-   `ip_address` : Indirizzo IP dell'interfaccia esterna del gateway, routable su Internet
