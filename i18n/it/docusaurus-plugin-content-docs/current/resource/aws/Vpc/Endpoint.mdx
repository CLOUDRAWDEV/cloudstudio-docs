## Valori di configurazione della risorsa

#### Impostazioni di base

-   `service_range` : Categoria del servizio Endpoint - `awsService`, `endpointService`
-   `aws_service_name` : Nome del servizio AWS da utilizzare
-   `vpc_endpoint_type` : Tipo di endpoint - `Gateway`, `Interface`, `GatewayLoadBalancer`
-   `included_vpc_name` : Nome del VPC in cui creare l’endpoint
-   `enabled_private_dns` : Abilitazione del DNS privato - `true`, `false`
-   `enable_private_dns_only_for_inbound_resolver_endpoint` : Abilitazione esclusiva del DNS privato per richieste inbound - `true`, `false`
-   `dns_record_ip_type` : Tipo di IP per i record DNS - `ipv4`, `dualstack`, `servicedefined`, `ipv6`
-   `ip_address_type` : Tipo di indirizzo IP dell’endpoint - `ipv4`, `ipv6`, `dualstack`
-   `policy_access` : Ambito di accesso della policy - `Full`, `Custom`
-   `custom_policy` : Policy personalizzata per il controllo degli accessi

#### Impostazioni Endpoint Service (`endpoint_service`)

-   `endpoint_service.is_manual` : Inserimento manuale dell’ARN del servizio - `true`, `false`
-   `endpoint_service.service_name` : Nome del servizio Endpoint
-   `endpoint_service.linked_endpoint_service_name` : Nome del servizio Endpoint collegato

#### Impostazioni di rete

-   `linked_security_group_names` : Elenco dei gruppi di sicurezza collegati
-   `linked_subnet_names` : Elenco delle subnet per la creazione delle interfacce di rete
-   `route_table_names` : Elenco delle route table collegate

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
