## Impostazioni della risorsa

-   `service_range` : Categoria del servizio da utilizzare con il servizio endpoint - `awsService`,`endpointService`
-   `aws_service_name` : Nome del servizio AWS da utilizzare con il servizio endpoint
-   `vpc_endpoint_type` : Tipo di endpoint del servizio da utilizzare con altri endpoint - `gateway`, `interface`, `gatewayloadbalancer`
-   `included_vpc_name` : Nome del VPC in cui creare l'endpoint
-   `route_table_names` : ID di una o più tabelle di routing da collegare all'endpoint
-   `policy_access` : Intervallo di accesso della politica da collegare all'endpoint per controllare l'accesso al servizio - `Full`, `Custom`
