## Panoramica della risorsa

Risorsa utilizzata per accettare o rifiutare la condivisione di risorse provenienti da altri account AWS.

## Risorse correlate

### Risorse principali

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Risorse collegate

-   [**TransitGatewayAttachment**](https://docs.cstudio.app/docs/resource/aws/Vpc/TransitGatewayAttachment)

---

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `is_manual` : Inserimento manuale dell’ID del Transit Gateway Attachment da accettare - `true`, `false`
-   `transit_gateway_attachment_id` : ID del Transit Gateway Attachment da accettare
-   `linked_transit_gateway_attachment_name` : Nome del Transit Gateway Attachment da accettare

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
