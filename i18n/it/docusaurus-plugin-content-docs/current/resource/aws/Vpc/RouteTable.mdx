## Panoramica della risorsa

La Route Table di AWS VPC (Virtual Private Cloud) è una risorsa AWS che definisce verso quali destinazioni deve essere instradato il traffico delle subnet all’interno di un VPC.  
Ogni subnet in un VPC è associata a una o più route table, che specificano le regole di instradamento verso destinazioni come Internet Gateway, NAT Gateway, VPC Endpoint o connessioni VPN.

Le route table instradano il traffico in base all’ordine delle regole configurate e tutto il traffico generato dalle subnet viene inoltrato alla destinazione tramite la route table associata.  
In questo modo, le subnet all’interno del VPC possono comunicare in modo sicuro con Internet o con altri VPC.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `included_vpc_name` : Nome del VPC in cui è inclusa la Route Table
-   `subnet_names` : Elenco dei nomi delle subnet da associare alla Route Table

#### Percorsi di routing (`linked_route`)

-   `linked_route.cidr_block` : Blocco CIDR della destinazione da instradare
-   `linked_route.resource_type` : Tipo di risorsa di destinazione - `internet_gateway`, `ec2_instance`, `nat_gateway`, `transit_gateway`, `vpc_peering`
-   `linked_route.linked_resource_name` : Nome della risorsa di destinazione

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
