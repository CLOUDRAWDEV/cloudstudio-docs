## Panoramica della risorsa

La Route Table di AWS VPC (Virtual Private Cloud) è una risorsa AWS che definisce a quale destinazione deve essere inviato il traffico per i subnet all'interno del VPC. Ogni subnet nel VPC è collegata a una o più tabelle di routing, che specificano le regole di routing per destinazioni come Internet Gateway, NAT Gateway, VPC Endpoint o VPN Connection. La Route Table instrada il traffico secondo l'ordine delle regole di routing, e tutto il traffico generato in una subnet viene inviato alla destinazione tramite la Route Table collegata. Ciò consente alle subnet nel VPC di comunicare in modo sicuro con Internet o altri VPC.

## Impostazioni della risorsa

-   `included_vpc_name` : Nome del VPC che contiene la Route Table
-   `subnet_names` : Descrizione della Route Table
-   `linked_route` : Nome del percorso di routing
    -   `cidr_block` : CIDR del Target Resource da instradare
    -   `internet_gateway_name` : Nome dell'Internet Gateway per cui specificare il percorso di routing
    -   `ec2_instance_name` : Nome dell'EC2 Instance per cui specificare il percorso di routing
    -   `nat_gateway_name` : Nome del NAT Gateway per cui specificare il percorso di routing
    -   `vpc_peering_name` : Nome del VPC Peering per cui specificare il percorso di routing
