## Panoramica della risorsa

Amazon Virtual Private Cloud (Amazon VPC) consente di controllare completamente l’ambiente di rete virtuale, inclusi il posizionamento delle risorse, la connettività e la sicurezza.  
Per iniziare, configura un VPC dalla console dei servizi AWS. Successivamente, aggiungi risorse come istanze Amazon Elastic Compute Cloud (EC2) e Amazon Relational Database Service (RDS) al VPC.  
Infine, definisci come i VPC comunicano tra loro all’interno dell’account, delle zone di disponibilità o delle regioni AWS. Nell’esempio seguente, il traffico di rete viene condiviso tra due VPC all’interno di ciascuna regione.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `cidr_block` : Blocco di indirizzi IP del VPC (CIDR)
-   `enabled_dns_support` : Abilitazione del supporto alla risoluzione DNS - `true`, `false`
-   `enabled_dns_hostnames` : Abilitazione dell’assegnazione dei nomi host DNS - `true`, `false`

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
