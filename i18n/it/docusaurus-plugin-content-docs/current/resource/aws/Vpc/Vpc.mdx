## Panoramica della risorsa

Utilizzando Amazon Virtual Private Cloud (Amazon VPC), puoi controllare completamente l'ambiente di rete virtuale, inclusi il posizionamento delle risorse, le connessioni e la sicurezza. Inizia configurando il VPC tramite la console dei servizi AWS. Successivamente, aggiungi risorse come istanze Amazon Elastic Compute Cloud (EC2) e Amazon Relational Database Service (RDS) al tuo VPC. Infine, definisci come i VPC comunicano tra loro all'interno di un account, una zona di disponibilità o una regione AWS. Nell'esempio sottostante, il traffico di rete viene condiviso tra due VPC all'interno della stessa regione.
