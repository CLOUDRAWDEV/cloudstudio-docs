## Panoramica della risorsa

Le Network Access Control List (ACL) consentono o rifiutano determinati traffici in entrata o in uscita a livello di sottorete. Puoi utilizzare la Network ACL predefinita per il VPC o creare una Network ACL personalizzata per il VPC utilizzando regole simili a quelle dei gruppi di sicurezza per aggiungere un ulteriore livello di sicurezza al VPC. 
L'utilizzo delle Network ACL non comporta costi aggiuntivi.

## Impostazioni della risorsa

-   `included_vpc_name` : Nome del VPC che include la Network ACL
-   `linked_subnet_names` : Nomi dei subnet a cui applicare la Network ACL
-   `ingress` : Nome della regola Ingress della Network ACL
    -   `protocol` : Protocollo della regola Ingress - `tcp`, `udp`, `ssh`, `icmp`, `all`
    -   `action` : Azione da applicare al protocollo della regola Ingress - `allow`, `deny`
    -   `cidr_block` : CIDR a cui applicare la regola Ingress
    -   `from_port` : Numero della porta in entrata per la regola Ingress
    -   `to_port` : Numero della porta in uscita per la regola Ingress
-   `egress` : Nome della regola Egress della Network ACL
    -   `protocol` : Protocollo della regola Egress - `tcp`, `udp`, `ssh`, `icmp`, `all`
    -   `action` : Azione da applicare al protocollo della regola Egress - `allow`, `deny`
    -   `cidr_block` : CIDR a cui applicare la regola Egress
    -   `from_port` : Numero della porta in entrata per la regola Egress
    -   `to_port` : Numero della porta in uscita per la regola Egress
