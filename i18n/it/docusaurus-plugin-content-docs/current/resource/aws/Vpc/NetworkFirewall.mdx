## Panoramica della risorsa

Servizio AWS che consente di configurare la protezione su account e risorse AWS all'interno dell'organizzazione

## Impostazioni della risorsa

-   `description` : Descrizione del firewall
-   `included_vpc_name` : Nome del VPC in cui si trova il firewall
-   `linked_subnet_names` : Sottoreti pubbliche dedicate agli endpoint del firewall
-   `linked_network_firewall_policy_name` : Nome della policy del firewall da collegare
-   `enabled_delete_protection` : Attivazione della protezione contro la cancellazione del firewall - `false`,`true`
-   `enabled_subnet_change_protection` : Attivazione della protezione contro la modifica delle connessioni subnet - `false`,`true`
-   `encryption_configuration.enabled_custom_configuration` : Abilitazione della crittografia dei dati utilizzando una chiave gestita da AWS - `false`,`true`
