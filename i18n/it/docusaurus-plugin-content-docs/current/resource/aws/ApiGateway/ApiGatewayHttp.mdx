## Panoramica della risorsa

In API Gateway, HTTP API è un tipo di API Gateway progettato per creare API semplici e leggere basate sul protocollo HTTP.
Le HTTP API sono più semplici e convenienti rispetto alle REST API tradizionali e sono particolarmente adatte per applicazioni web serverless e microservizi semplici.

## Valori di configurazione della risorsa

#### Impostazioni di base

#### Impostazioni Integration (`integration`)

-   `integration.integration_type` : Tipo di integrazione di API Gateway - `Http`, `Lambda`
-   `integration.integration_method` : Metodo HTTP dell’integrazione API Gateway - `ANY`, `GET`, `POST`, `PUT`, `PATCH`, `HEAD`, `OPTIONS`, `DELETE`
-   `integration.integration_uri` : Specifica dell’URL completamente qualificato per l’integrazione HTTP
-   `integration.linked_lambda_name` : Nome della funzione Lambda per l’integrazione proxy Lambda

#### Impostazioni Route (`route`)

-   `route.route_method` : Metodo HTTP per l’HTTP API - `ANY`, `GET`, `POST`, `PUT`, `PATCH`, `HEAD`, `OPTIONS`, `DELETE`
-   `route.route_path` : Percorso della risorsa per l’HTTP API
-   `route.target_integration` : Nome dell’integrazione API Gateway da collegare alla route

#### Impostazioni Deployment (`deployment`)

-   `deployment.description` : Descrizione del Deployment di API Gateway

#### Impostazioni Stage (`stage`)

-   `stage.auto_deployment` : Abilitazione del deployment automatico - `true`, `false`
-   `stage.deployment_name` : Nome del Deployment di API Gateway da collegare
