## Panoramica della risorsa

È un’espressione di policy che definisce quando e come eseguire il backup delle risorse AWS. Le risorse possono essere assegnate a un Backup Plan e AWS Backup esegue e conserva automaticamente i backup delle risorse in base al Backup Plan.

## Valori di configurazione della risorsa

#### Impostazioni di base

#### Regola (`rule`)

-   `rule.rule_name` : Nome della regola di backup, stringa alfanumerica da 1 a 50 caratteri che può includere -, \_, .
-   `rule.backup_vault_name` : Nome del contenitore logico utilizzato per l’archiviazione dei backup
-   `rule.frequency_type` : Tipo di pianificazione del backup - `Hourly`, `Weekly`, `Monthly`, `Custom`
-   `rule.frequency_hour` : Ora di inizializzazione del piano di backup - minimo `1`
-   `rule.frequency_days` : Giorno di inizializzazione del piano di backup - `Sunday`, `Monday`, `Tuesday`, `Wednesday`, `Thursday`, `Friday`, `Saturday`
-   `rule.frequency_date` : Giorno del mese per l’inizializzazione del piano di backup - `1` ~ `31`
-   `rule.start_time` : Ora di inizio del piano di backup
-   `rule.custom_cron_expression` : Espressione personalizzata per definire l’orario di avvio del piano di backup
-   `rule.start_after_minutes` : Tempo totale prima dell’avvio del backup - minimo `60`
-   `rule.complete_after_minutes` : Tempo (in minuti) durante il quale AWS Backup tenta il backup prima di annullare il processo e restituire un errore
-   `rule.enabled_use_cold_storage` : Abilitazione dell’uso del cold storage - `true`, `false`
-   `rule.warm_storage_retention_days` : Numero di giorni dopo la creazione prima di spostare il punto di ripristino nel cold storage - `1` ~ `36410`
-   `rule.total_retention_days` : Numero di giorni dopo la creazione prima di eliminare il punto di ripristino - `1` ~ `36500`

#### Assegnazione delle risorse (`resource_assignment`)

-   `resource_assignment.iam_role_arn` : ARN del ruolo IAM utilizzato da AWS Backup per l’autenticazione durante il backup e il ripristino delle risorse
-   `resource_assignment.enabled_contain_all` : Indica se includere tutte le risorse - `true`, `false`
-   `resource_assignment.contain_arn_or_pattern` : Array di stringhe che includono Amazon Resource Name o corrispondono a pattern di risorse da assegnare al piano di backup
-   `resource_assignment.exclude_arn_or_pattern` : Array di stringhe che includono ARN o corrispondono a pattern di risorse da escludere dal piano di backup

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria - massimo 512 caratteri, `key`:`value`
