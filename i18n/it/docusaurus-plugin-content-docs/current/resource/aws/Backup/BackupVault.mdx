## Panoramica della risorsa

In AWS Backup, il Backup Vault è un contenitore utilizzato per archiviare e configurare i backup.
Quando si crea un Backup Vault, è necessario specificare una chiave di crittografia AWS KMS per crittografare alcuni backup all'interno di questo vault.

## Impostazioni della risorsa

-   `kms_key_name` : Chiave di crittografia lato server utilizzata per proteggere il backup
-   `lock_configuration` : Configurazione del lock del Backup Vault di AWS
    -   `lock_configuration.enabled_lock` : Se utilizzare il lock del vault - `false`, `true`
        -   `lock_configuration.enabled_lock.lock_mode` : Tipo di lock del vault - `Governance`, `Compliance`
        -   `lock_configuration.enabled_lock.min_retention_days` : Periodo minimo di conservazione dei punti di ripristino nel vault - `1~36500`
        -   `lock_configuration.enabled_lock.max_retention_days` : Periodo massimo di conservazione dei punti di ripristino nel vault - `1~36500`
