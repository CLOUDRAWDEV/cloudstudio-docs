## Panoramica della risorsa

In AWS Backup, Backup Vault è un contenitore utilizzato per archiviare e gestire i backup.
Durante la creazione di un Backup Vault, è necessario specificare una chiave di crittografia AWS KMS per crittografare alcuni backup presenti nel vault.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `kms_key_name` : Chiave di crittografia lato server utilizzata per proteggere i backup

#### Impostazioni Vault Lock (`lock_configuration`)

-   `lock_configuration.enabled_lock` : Abilitazione del vault lock - `true`, `false`
-   `lock_configuration.lock_mode` : Tipo di vault lock - `Governance`, `Compliance`
-   `lock_configuration.min_retention_days` : Periodo minimo di conservazione dei punti di ripristino nel vault - `1` ~ `36500`
-   `lock_configuration.max_retention_days` : Periodo massimo di conservazione dei punti di ripristino nel vault - `1` ~ `36500`
-   `lock_configuration.changeable_for_days` : Numero di giorni prima della scadenza del lock - `3` ~ `36500`

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria - massimo 512 caratteri, `key`:`value`
