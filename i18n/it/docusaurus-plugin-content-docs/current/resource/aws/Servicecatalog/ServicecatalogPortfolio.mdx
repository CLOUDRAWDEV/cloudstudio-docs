## Panoramica della risorsa

AWS Service Catalog consente agli amministratori IT di creare, gestire e distribuire portafogli di prodotti approvati agli utenti finali, che possono accedere ai prodotti necessari tramite un portale personalizzato.  
I prodotti tipici includono server, database, siti web o applicazioni distribuiti utilizzando risorse AWS (ad esempio istanze Amazon EC2 o database Amazon RDS).  
È possibile controllare quali utenti possono accedere a determinati prodotti per applicare gli standard aziendali, gestire il ciclo di vita dei prodotti e consentire agli utenti di individuare e avviare i prodotti con sicurezza.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `description` : Descrizione del portafoglio
-   `provider_name` : Nome della persona o dell’organizzazione proprietaria del portafoglio

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
