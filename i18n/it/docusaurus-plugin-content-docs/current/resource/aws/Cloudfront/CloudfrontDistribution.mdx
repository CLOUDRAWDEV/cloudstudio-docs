## Panoramica della risorsa

Amazon CloudFront accelera la distribuzione di contenuti web statici e dinamici, come file .html, .css, .php, immagini e file multimediali. Quando un utente richiede un contenuto, CloudFront lo fornisce attraverso una rete di posizioni edge globali che offre bassa latenza e alte prestazioni.

## Impostazioni della risorsa

-   `enabled` : Indica se la distribuzione è attivata per accettare le richieste degli utenti finali per il contenuto - `true`, `false`
-   `origin` : Identificatore dell'origin
-   `cache_policy` : Nome della Cache Policy
    -   `min_ttl` : Tempo minimo (in secondi) che un oggetto deve rimanere nella cache di CloudFront
    -   `max_ttl` : Tempo massimo (in secondi) che un oggetto può rimanere nella cache di CloudFront
    -   `default_ttl` : Tempo predefinito (in secondi) che un oggetto deve rimanere nella cache di CloudFront
    -   `cookie_behavior` : Determina se i cookie delle richieste degli utenti finali sono inclusi nella chiave di cache e automaticamente inviati da CloudFront all'origin - `whitelist`, `all`, `none`, `allExcept`
    -   `cookies_items` : Elenco dei nomi dei Cookie Items
    -   `header_behavior` : Determina se gli header HTTP sono inclusi nella chiave di cache e automaticamente inviati da CloudFront all'origin - `whitelist`, `none`
    -   `headers_items` : Elenco dei nomi dei Header Items
    -   `query_string_behavior` : 최종 사용자 요청의 URL 쿼리 문자열이 캐시 키에 포함되고 Determina se la stringa di query dell'URL delle richieste degli utenti finali è inclusa nella chiave di cache e automaticamente inviata da CloudFront all'origin - `whitelist`, `all`, `none`, `allExcept`
    -   `query_strings_items` : Elenco dei nomi dei query items
-   `cache_behavior`

    -   `path_pattern` : Modello di richiesta da applicare al Cache Behavior
    -   `compress` : Se CloudFront deve comprimere automaticamente il contenuto delle richieste web - `true`, `false`
    -   `viewer_protocol_policy` : Specifica il protocollo che può essere utilizzato per accedere ai file dell'origine indicata da TargetOriginId quando il percorso della richiesta corrisponde al pattern del PathPattern - `allow-all`, `https-only`, `redirect-to-https`
    -   `allowed_methods` : Controlla i metodi HTTP che CloudFront gestirà e passerà al bucket Amazon S3 o all'origine personalizzata - `GET`, `HEAD`, `OPTIONS`, `PATCH`, `POST`,`PUT`, `DELETE`
    -   `cached_methods` : Controlla se CloudFront deve memorizzare nella cache la risposta per le richieste con i metodi HTTP specificati - `GET`, `HEAD`, `OPTIONS`, `PATCH`, `POST`, `PUT`, `DELETE`
    -   `origin_name` : 경로 패턴이 일치할 Nome dell'origine a cui CloudFront instraderà la richiesta quando il pattern del percorso corrisponde
    -   `linked_cache_policy_name` : ID della Cache Policy da collegare al Cache Behavior

-   `restriction`

    -   `type` : Metodo utilizzato per limitare la distribuzione del contenuto per paese - `whitelist`, `blacklist`, `none`
    -   `locations` : Codici ISO 3166-1-alpha-2 dei paesi per i quali si desidera distribuire o non distribuire contenuti tramite CloudFront

-   `viewer_certificate`

    -   `default_certificate_enabled` : Se l'utente finale deve richiedere oggetti tramite HTTPS e se viene utilizzato il nome di dominio CloudFront per la distribuzione - `true`, `false`

-   `price_class` : Classe di prezzo per la distribuzione CloudFront - `PriceClass_100`, `PriceClass_200`, `PriceClass_All`
-   `http_version` : Versione massima di HTTP supportata dalla distribuzione CloudFront - `http1.1`, `http2`
-   `is_ipv6_enabled` : Se la distribuzione CloudFront supporta IPv6 - `true`, `false`

-   `logging`

    -   `logging_enabled` : Attivazione del logging - `true`, `false`

-   `linked_waf_web_acl_name` : Nome del WAF WEB ACL da utilizzare quando si attiva la protezione di sicurezza
