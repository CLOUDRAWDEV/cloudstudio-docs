## Panoramica della risorsa

Cloudfront Cache Policy è una policy di caching che consente di configurare le personalizzazioni di CloudFront collegandosi al comportamento di cache di una distribuzione Cloudfront.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `min_ttl` : Tempo minimo (in secondi) durante il quale un oggetto rimane nella cache
-   `default_ttl` : Tempo predefinito (in secondi) durante il quale un oggetto rimane nella cache
-   `max_ttl` : Tempo massimo (in secondi) durante il quale un oggetto rimane nella cache

#### Impostazioni dei cookie (`cookie_config`)

-   `cookie_behavior` : Modalità di inoltro dei cookie - `whitelist`, `all`, `none`, `allExcept`
-   `cookies_items` : Elenco dei cookie da inoltrare all’origine

#### Impostazioni degli header (`header_config`)

-   `header_behavior` : Metodo di caching basato sugli header - `whitelist`, `none`
-   `headers_items` : Elenco degli header da utilizzare per il caching

#### Impostazioni della query string (`query_string_config`)

-   `query_string_behavior` : Modalità di gestione delle query string - `whitelist`, `all`, `none`, `allExcept`
-   `query_strings_items` : Elenco dei parametri di query string da utilizzare per il caching
