## Panoramica della risorsa

La Cloudfront Cache Policy è una politica di cache che configura la personalizzazione di CloudFront collegandosi al comportamento di cache della distribuzione CloudFront.

## Risorse correlate

### Risorse superiori

-   [**Base**](https://docs.cstudio.app/docs/resource/aws/Base)

### Risorse collegate

-   [**CloudfrontDistribution**](https://docs.cstudio.app/docs/resource/aws/Cloudfront/CloudfrontDistribution)

## Impostazioni della risorsa

-   `min_ttl` : Tempo minimo (in secondi) che un oggetto deve rimanere nella cache di CloudFront
-   `max_ttl` : Tempo massimo (in secondi) che un oggetto può rimanere nella cache di CloudFront
-   `default_ttl` : Tempo predefinito (in secondi) che un oggetto deve rimanere nella cache di CloudFront
-   `cookie_behavior` : Se i cookie devono essere inviati al server di origine - `whitelist`, `all`, `none`, `allExcept`
-   `header_behavior` : Se l'oggetto deve essere memorizzato nella cache in base ai valori degli header specificati - `whitelist`, `none`
-   `query_string_behavior` : Se devono essere memorizzate versioni diverse del contenuto in base ai parametri della stringa di query - `whitelist`, `all`, `none`, `allExcept`
