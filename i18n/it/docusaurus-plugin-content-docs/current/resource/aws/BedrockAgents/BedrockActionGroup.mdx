## Panoramica della risorsa

Risorsa che definisce e gestisce azioni specifiche che un agente AWS Bedrock può eseguire.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `target_bedrock_agent` : Agente Bedrock di destinazione a cui collegare l’action group
-   `enable_action_group_state` : Abilitazione della conservazione dello stato dell’Action Group - `ENABLED`, `DISABLED`
-   `custom_control_method` : Metodo di controllo del comportamento dell’agente - `custom_control`, `lambda_function`
-   `target_lambda_function` : Funzione AWS Lambda da invocare durante l’esecuzione dell’azione

#### Definizione delle funzioni (`functions`)

-   `functions.description` : Descrizione dello scopo o della funzionalità eseguita dalla funzione (massimo 5000 caratteri)

##### Parametri della funzione (`functions.parameters`)

-   `functions.parameters.type` : Tipo di dato del parametro - `string`, `number`, `integer`, `boolean`, `array`
-   `functions.parameters.description` : Significato o utilizzo del parametro
-   `functions.parameters.required` : Indica se il parametro è obbligatorio - `true`, `false`
