## Panoramica della risorsa

Servizio di endpoint per le query DNS in entrata e in uscita con Amazon VPC.

### Risorse superiori

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Risorse collegate

-   [**Vpc**](https://docs.cstudio.app/docs/resource/aws/Vpc/Vpc)
-   [**SecurityGroup**](https://docs.cstudio.app/docs/resource/aws/Vpc/SecurityGroup)
-   [**ResolverRule**](https://docs.cstudio.app/docs/resource/aws/Route53/ResolverRule)

## Impostazioni della risorsa

-   `direction` : Direzione della query DNS - `INBOUND`, `OUTBOUND`
-   `linked_vpc_name` : Nome del VPC da collegare all'endpoint
-   `linked_security_group_names` : Nomi dei gruppi di sicurezza per l'endpoint
-   `ip_address` : Nome associato all'indirizzo IP
