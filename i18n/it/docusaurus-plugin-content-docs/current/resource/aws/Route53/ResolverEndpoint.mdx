## Panoramica della risorsa

Servizio di endpoint per le query DNS in ingresso e in uscita tra Amazon VPC

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `direction` : Direzione delle query DNS - `INBOUND`, `OUTBOUND`
-   `linked_vpc_name` : Nome del VPC da collegare all’endpoint
-   `linked_security_group_names` : Elenco dei nomi dei gruppi di sicurezza applicati all’endpoint
-   `ip_address.subnet_name` : Nome della subnet da utilizzare
-   `ip_address.ip` : Indirizzo IP disponibile all’interno della subnet

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
