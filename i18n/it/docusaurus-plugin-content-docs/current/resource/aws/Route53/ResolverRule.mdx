## Panoramica della risorsa

Regola utilizzata dal resolver per inoltrare le query di un nome di dominio specificato verso la rete

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `rule_type` : Tipo di regola - `FORWARD`, `SYSTEM`
-   `domain_name` : Nome di dominio verso cui vengono inoltrate le query DNS
-   `linked_vpc_names` : Elenco dei nomi dei VPC che utilizzano la regola
-   `linked_resolver_endpoint_name` : Nome dell’endpoint outbound utilizzato dal resolver
-   `target_ip.ip` : Indirizzo IP di destinazione
-   `target_ip.port` : Porta dell’indirizzo IP di destinazione

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
