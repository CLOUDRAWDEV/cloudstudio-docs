## Valori di configurazione della risorsa

#### Impostazioni di base

-   `routing_type` : Tipo di routing della zona Route53 - `PRIVATE`, `PUBLIC`
-   `linked_vpc_names` : Elenco dei nomi dei VPC collegati alla zona Route53

#### Record (`record`)

-   `record.type` : Tipo di record - `A`, `AAAA`, `CAA`, `CNAME`, `DS`, `MX`, `NAPTR`, `NS`, `PTR`, `SOA`, `SPF`, `SRV`, `TXT`
-   `record.ttl` : TTL del record
-   `record.records` : Elenco delle stringhe del record

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
