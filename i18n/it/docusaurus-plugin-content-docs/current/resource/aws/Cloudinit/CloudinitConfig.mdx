## Valori di configurazione della risorsa

#### Impostazioni di base

-   `gzip` : Indica se utilizzare l’algoritmo di compressione dei dati - `true`, `false`

#### Impostazioni delle parti (`part`)

-   `part.content_type` : Tipo di dati da inserire - `text/cloud-config`, `text/x-shellscript`, `text/cloud-boothook`, `multipart/mixed`, `text/cloud-config-archive`, `text/jinja`, `text/x-include-url`, `text/part-handler`
-   `part.content` : Contenuto effettivo dei dati da inserire

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
