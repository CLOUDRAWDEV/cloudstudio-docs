## Panoramica della risorsa

AWS ElastiCache Cluster è un datastore in-memory basato su cloud che fornisce una soluzione di caching rapida e scalabile. Può essere eseguito in modalità cluster o a nodo singolo utilizzando i motori Redis o Memcached. ElastiCache Cluster migliora le prestazioni delle applicazioni consentendo un accesso e un’elaborazione dei dati più rapidi. Offre funzionalità di backup automatico, ripristino, scalabilità e monitoraggio.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `engine` : Tipo di motore di cache - `redis`, `memcached`
-   `engine_version` : Versione del motore di cache
-   `port` : Porta di connessione del nodo cache (Redis: 6379, Memcached: 11211)
-   `parameter_group_name` : Nome del parameter group da collegare
-   `node_type` : Tipo di istanza del nodo cache
-   `num_cache_nodes` : Numero di nodi cache
-   `az_mode` : Modalità di configurazione delle zone di disponibilità - `single-az`, `cross-az`
-   `included_subnet_names` : Elenco dei nomi delle subnet incluse nel Subnet Group
-   `subnet_group_name` : Nome del Subnet Group da utilizzare
-   `snapshot_retention_limit` : Periodo di conservazione degli snapshot automatici (giorni)

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
