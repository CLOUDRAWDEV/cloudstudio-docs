## Panoramica della risorsa

AWS Elasticache Cluster는 클라우드 기반의 인 메모리 데이터 스토어이며, 빠르고 확장 가능한 캐싱 솔루션을 제공합니다. Elasticache Cluster는 Redis 또는 Memcached 엔진을 사용하여 클러스터 모드 또는 단일 노드 모드에서 실행할 수 있습니다. Elasticache Cluster는 애플리케이션의 성능을 향상시키는 데 사용되며, 데이터를 더 빠르게 검색하고 처리할 수 있습니다. Elasticache Cluster는 자동 백업, 복구, 확장 및 모니터링 기능을 제공하여 사용자가 안심하고 데이터를 저장할 수 있도록 도와줍니다.

## Impostazioni della risorsa

-   `engine` : Nome del Cache Engine da utilizzare nel Cache Cluster - `redis`, `memcached`
-   `engine_version` : Versione del Cache Engine
-   `port` : Numero di porta da utilizzare per connettersi a ciascun Cache Node. Memcached utilizza la porta 11211, Redis utilizza la porta 6379 come valore predefinito
-   `parameter_group_name` : Nome del gruppo di parametri da associare al Cache Cluster
-   `node_type` : Classe di istanza utilizzata nel Cache Cluster
-   `num_cache_nodes` : Numero iniziale di Cache Nodes nel Cache Cluster - `1`~`40`
-   `az_mode` : Se i nodi del gruppo Memcached sono creati in una singola zona di disponibilità o distribuiti su più zone di disponibilità nella regione del cluster - `single-az`, `cross-az`
-   `included_subnet_names` : Nomi delle subnet da includere nel Subnet Group per il deployment dell'Elasticache Cluster
-   `snapshot_retention_limit` : Periodo di conservazione degli snapshot automatici del Cache Cluster prima che ElastiCache li elimini
