## Panoramica della risorsa

AWS Elasticache User è un utente IAM necessario per utilizzare i cluster Elasticache. Elasticache User dispone delle autorizzazioni per creare, modificare ed eliminare cluster Elasticache. Elasticache User viene creato in AWS IAM ed è generalmente assegnato ad applicazioni o sviluppatori che utilizzano Elasticache. Elasticache User è responsabile della sicurezza e del controllo degli accessi ai cluster Elasticache e, tramite ciò, consente di proteggere applicazioni e dati. Elasticache User può essere utilizzato insieme ad altre risorse all’interno dell’account AWS.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `user_id` : ID univoco di ciascun utente
-   `access_string` : stringa che specifica le autorizzazioni da applicare all’utente
-   `authentication_type` : Metodo di autenticazione utilizzato dall’utente per accedere al cluster - `iam`, `password`, `no-password-required`
-   `passwords` : Password dell’utente (è possibile configurarne fino a un massimo di 2)

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
