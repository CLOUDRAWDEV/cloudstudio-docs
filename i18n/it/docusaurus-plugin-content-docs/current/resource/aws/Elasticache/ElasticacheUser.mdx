## Panoramica della risorsa

L'AWS Elasticache User è un utente IAM necessario per utilizzare un Elasticache cluster. L'Elasticache User ha i permessi per creare, modificare e eliminare un Elasticache cluster. L'Elasticache User viene creato tramite AWS IAM e viene generalmente assegnato alle applicazioni o agli sviluppatori che utilizzano Elasticache. L'Elasticache User è responsabile della sicurezza e del controllo dell'accesso al Elasticache cluster, proteggendo così le applicazioni e i dati. L'Elasticache User può essere utilizzato insieme ad altre risorse nell'account AWS.

## Impostazioni della risorsa

-   `user_id` : ID dell'utente, consentiti caratteri alfanumerici e trattini (-), deve iniziare con una lettera, non può terminare con un trattino né contenere due trattini consecutivi, massimo 40 caratteri
-   `access_string` : Stringa che specifica i permessi da applicare all'utente
-   `authentication_type` : Tipo di autenticazione utilizzata dall'utente per accedere al cluster
