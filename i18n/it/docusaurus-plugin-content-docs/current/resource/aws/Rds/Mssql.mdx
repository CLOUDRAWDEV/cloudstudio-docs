## Panoramica della risorsa

SQL Server è un sistema di gestione di database relazionali sviluppato da Microsoft. Utilizzando Amazon RDS for SQL Server, è possibile configurare, gestire e scalare facilmente una distribuzione di SQL Server nel cloud. Con Amazon RDS, è possibile distribuire in pochi minuti diverse versioni di SQL Server (2014, 2016, 2017 e 2019), come Express, Web, Standard ed Enterprise, con potenza di calcolo economica e scalabile. Inoltre, Amazon RDS si occupa di attività di gestione del database che richiedono tempo, come provisioning, backup, patching del software, monitoraggio e ridimensionamento hardware, consentendo ai clienti di concentrarsi esclusivamente sullo sviluppo delle applicazioni.

## Impostazioni della risorsa

-   `engine` : Tipo di MsSQL Engine da utilizzare su RDS - `sqlserver-ex`, `sqlserver-ee`, `sqlserver-web`, `sqlserver-se`
-   `engine_version` : Versione di MsSQL da utilizzare su RDS
-   `instance_class` : Livello di prezzo per il DB RDS
-   `storage_type` : Tipo di storage per l'istanza RDS
-   `allocated_storage` : Capacità di storage per l'istanza RDS (in Gigabyte)
-   `max_allocated_storage` : Limite superiore per l'espansione automatica dello storage dell'istanza DB da parte di Amazon RDS
-   `multi_az_enabled` : Abilitazione della distribuzione Multi-AZ - `true`, `false`
-   `username` : Nome utente per RDS
-   `password` : Password dell'utente per RDS
-   `included_subnet_names` : Nomi delle Subnet da collegare al gruppo di Subnet RDS
-   `publicly_accessible` : Se l'istanza è accessibile pubblicamente - `true`, `false`
-   `subnet_group_name` : Nome del gruppo di Subnet da utilizzare su RDS

-   `monitoring`
    -   `performance_insights_enabled` : Abilitazione delle performance insights
-   `encryption`
    -   `storage_encrypted` : Specifica se l'istanza DB è criptata - `true`, `false`
    -   `kms_key_name` : Nome della chiave KMS da utilizzare per la crittografia
-   `backup`
    -   `backup_retention_period` : Periodo di conservazione dei backup - `1`~`35`
    -   `final_snapshot_enabled` : Se creare uno snapshot finale prima della cancellazione dell'istanza DB - `true`, `false`
    -   `final_snapshot_name` : Nome dello snapshot finale
