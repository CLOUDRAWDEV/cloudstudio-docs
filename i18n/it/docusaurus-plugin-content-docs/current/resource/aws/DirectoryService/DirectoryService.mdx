## Panoramica della risorsa

AWS Directory Service fornisce diversi metodi per utilizzare Microsoft Active Directory (AD) con altri servizi AWS. Una directory memorizza informazioni su utenti, gruppi e dispositivi, consentendo agli amministratori di gestire l’accesso alle informazioni e alle risorse. AWS Directory Service offre varie opzioni di directory ai clienti che desiderano utilizzare applicazioni esistenti compatibili con Microsoft AD o LDAP (Lightweight Directory Access Protocol) nel cloud. Le stesse opzioni sono disponibili anche per gli sviluppatori che necessitano di una directory per gestire utenti, gruppi, dispositivi e autorizzazioni di accesso.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `password` : Password dell’amministratore della directory o dell’utente del connettore
-   `type` : Tipo di directory - `SimpleAD`, `MicrosoftAD`
-   `size` : Dimensione della directory - `Small`, `Large`
-   `edition` : Edizione di MicrosoftAD - `Standard`, `Enterprise`
-   `included_vpc_name` : Nome del VPC in cui risiede la directory
-   `included_subnet_names` : Nomi delle subnet dei server di directory

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
