## Panoramica della risorsa

AWS Directory Service offre diversi modi per utilizzare Microsoft Active Directory (AD) con altri servizi AWS. Il directory memorizza informazioni su utenti, gruppi e dispositivi, e gli amministratori lo utilizzano per gestire l'accesso alle informazioni e alle risorse. AWS Directory Service offre diverse opzioni di directory per i clienti che desiderano utilizzare un Microsoft AD esistente nel cloud o applicazioni compatibili con LDAP (Lightweight Directory Access Protocol). Offre anche le stesse opzioni di scelta per gli sviluppatori che necessitano di un directory per gestire utenti, gruppi, dispositivi e privilegi di accesso.

## Impostazioni della risorsa

-   `password` : La password dell'amministratore del directory o dell'utente del connettore
-   `type` : `SimpleAD`,`MicrosoftAD`
-   `size` : La dimensione del directory - `Small`,`Large`
-   `included_vpc_name` : Il nome della VPC in cui si trova il directory
-   `included_subnet_names` : I nomi delle subnet del server di directory (le subnet devono essere distribuite in due AZ diverse)
