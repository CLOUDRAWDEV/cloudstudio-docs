## Panoramica della risorsa

Insieme di credenziali di sicurezza utilizzate per l’autenticazione durante la connessione alle istanze AWS EC2.

## Risorse correlate

### Risorsa padre

-   [**Region**](https://docs.cstudio.app/if/docs/resource/aws/Base/Region)

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `public_key` : Chiave pubblica della Key Pair creata dall’utente

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
