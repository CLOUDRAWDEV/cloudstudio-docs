## Panoramica della risorsa

Componente di rete logico che rappresenta una scheda di rete virtuale all’interno di un VPC.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `included_subnet_name` : Nome della subnet in cui risiede l’interfaccia di rete
-   `private_ips` : Elenco degli indirizzi IP privati
-   `linked_security_group_names` : Nomi dei Security Group associati all’interfaccia di rete
-   `linked_eip_names` : Nomi degli Elastic IP da associare

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
