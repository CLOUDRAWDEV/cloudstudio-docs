## Panoramica della risorsa

Componente di rete logica che rappresenta una scheda di rete virtuale in una VPC.

## Risorse correlate

### Risorse superiori

-   [**Subnet**](https://docs.cstudio.app/docs/resource/aws/Vpc/Subnet)

### Risorse collegate

-   [**Eip**](https://docs.cstudio.app/docs/resource/aws/Ec2/Eip)

## Impostazioni della risorsa

-   `private_ips` : Elenco di private ips
-   `linked_security_group_names` : Nome del Security Group da utilizzare per l'interfaccia di rete
-   `linked_eip_names` : Nome dell'Elastic IP da utilizzare
