## Panoramica della risorsa

Amazon Elastic Compute Cloud (Amazon EC2) fornisce capacità di calcolo scalabile nel cloud Amazon Web Services (AWS). Utilizzando Amazon EC2 non è necessario investire anticipatamente in hardware, consentendo uno sviluppo e una distribuzione più rapidi delle applicazioni. È possibile creare il numero desiderato di server virtuali, configurare sicurezza e networking e gestire lo storage. Amazon EC2 permette inoltre di gestire variazioni dei requisiti o picchi di utilizzo tramite scaling orizzontale o verticale, riducendo la necessità di prevedere il traffico.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `ami` : Immagine contenente le informazioni necessarie per avviare l’istanza
-   `instance_type` : Tipo di istanza EC2
-   `key_pair_name` : Nome della Key Pair utilizzata dall’istanza EC2
-   `linked_network_interface_names` : Elenco dei nomi delle interfacce di rete da utilizzare
-   `http_endpoint` : Abilitazione del servizio di metadati - `enabled`, `disabled`
-   `http_tokens` : Impostazione dei token di sessione per il servizio di metadati - `required`, `optional`
-   `cloudinit_config` : Script eseguiti automaticamente alla creazione del server

#### Volume root (`root_volume`)

-   `root_volume.volume_type` : Tipo del volume root - `gp2`, `gp3`, `io1`, `io2`, `sc1`, `st1`, `standard`
-   `root_volume.volume_size` : Dimensione del volume root (GiB)
-   `root_volume.enabled_volume_encryption` : Abilitazione della crittografia del volume root - `true`, `false`

#### Dispositivo a blocchi EBS (`ebs_block_device`)

-   `ebs_block_device.volume_type` : Tipo del volume EBS - `gp2`, `gp3`, `io1`, `io2`, `sc1`, `st1`, `standard`
-   `ebs_block_device.volume_size` : Dimensione del volume EBS (GiB)
-   `ebs_block_device.enabled_volume_encryption` : Abilitazione della crittografia del volume EBS - `true`, `false`

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
