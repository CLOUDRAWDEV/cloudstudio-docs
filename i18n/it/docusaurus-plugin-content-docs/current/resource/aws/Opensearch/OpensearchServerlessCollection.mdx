## Panoramica della risorsa

Gruppo di indici OpenSearch in modalità serverless che consente di archiviare e cercare dati in un ambiente OpenSearch che si scala automaticamente senza la necessità di gestire l’infrastruttura.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `shared_resource_types` : Elenco dei tipi di risorse da condividere
-   `transit_gateway_names` : Elenco dei nomi dei Transit Gateway da condividere
-   `resource_arns` : Elenco degli ARN delle risorse da condividere
-   `enabled_allow_external_principals` : Consente la condivisione con account AWS esterni - `true`, `false`
-   `principal_arns` : Elenco degli ARN dei principal o degli ID degli account AWS autorizzati alla condivisione

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria - massimo 512 caratteri, `key`:`value`
