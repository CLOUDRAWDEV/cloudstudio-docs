## Panoramica della risorsa

AWS CloudWatch OAM Source Account configura gli account sorgente che condividono dati con l’account di monitoraggio centrale.

## Risorse correlate

### Risorsa padre

-   [**Region**](https://docs.cstudio.app/if/docs/resource/aws/Base/Region)

### Risorse collegate

-   [**OamMonitoringAccount**](https://docs.cstudio.app/if/docs/resource/aws/CloudWatch/OamMonitoringAccount)

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `is_manual` : Indica se inserire manualmente l’ARN dell’OAM Source Account da collegare - `true`, `false`
-   `linked_oam_monitoring_account_name` : Nome dell’OAM Monitoring Account da collegare
-   `oam_monitoring_account_arn` : ARN dell’account di monitoraggio con cui condividere i dati
-   `resource_types` : Tipologie di dati da condividere con l’account di monitoraggio - `AWS::Logs::LogGroup`, `AWS::CloudWatch::Metric`, `AWS::XRay::Trace`, `AWS::ApplicationInsights::Application`
-   `label_template` : Etichetta utile per identificare l’account sorgente - `$AccountName`, `$AccountEmail`, `$AccountEmailNoDomain`

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria
