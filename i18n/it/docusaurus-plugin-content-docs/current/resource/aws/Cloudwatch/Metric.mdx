## Panoramica della risorsa

AWS CloudWatch Metric rappresenta una coppia nome-valore che descrive una misurazione raccolta dalle risorse monitorate. Ad esempio, è possibile raccogliere metriche come l’utilizzo della CPU, il traffico di rete in ingresso e in uscita dalle istanze EC2. Queste metriche vengono archiviate come CloudWatch Metric e utilizzate per dashboard, allarmi e analisi. È inoltre possibile creare metriche personalizzate per monitorare dati raccolti da applicazioni e servizi. CloudWatch Metric si integra con numerosi servizi AWS.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `comparison_operator` : Operatore di confronto tra il valore della metrica e la soglia - `GreaterThanOrEqualToThreshold`, `GreaterThanThreshold`, `LessThanThreshold`, `LessThanOrEqualToThreshold`, `LessThanLowerOrGreaterThanUpperThreshold`, `LessThanLowerThreshold`
-   `evaluation_periods` : Numero di periodi di valutazione per il confronto con la soglia
-   `metric_name` : Nome della metrica CloudWatch associata all’allarme
-   `namespace` : Namespace della metrica CloudWatch associata all’allarme
-   `period` : Intervallo di aggregazione della metrica (secondi)
-   `statistic` : Metodo statistico applicato alla metrica - `Average`, `SampleCount`, `Sum`, `Minimum`, `Maximum`
-   `threshold` : Valore di soglia che attiva l’allarme
-   `alarm_description` : Descrizione dell’allarme
-   `linked_sns_names` : Elenco dei topic SNS collegati alla metrica
-   `alarm_sns_names` : Elenco dei topic SNS a cui inviare notifiche quando la soglia viene superata
-   `ok_sns_names` : Elenco dei topic SNS a cui inviare notifiche quando la metrica torna allo stato normale
-   `insufficient_data_sns_names` : Elenco dei topic SNS a cui inviare notifiche in caso di dati insufficienti

#### Tag

-   `tag` : Elenco dei tag per classificare la risorsa
