## Panoramica della risorsa

AWS CloudWatch OAM Monitoring Accounts è un servizio che consente di configurare un account di monitoraggio centrale per monitorare le applicazioni di più account.

## Risorse correlate

### Risorse superiori

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Risorse collegate

-   [**Oam Source Account**](https://docs.cstudio.app/docs/resource/aws/Cloudwatch/OamSourceAccount)

## Impostazioni della risorsa

-   `oam_source_accounts` : Account, percorso dell'organizzazione o ID dell'organizzazione degli account con cui condividere i dati di monitoraggio
-   `resource_types` : Tipo di dati che si desidera condividere
    -   `AWS::Logs::LogGroup`
    -   `AWS::Cloudwatch::LogGroup`
    -   `AWS::Logs::LogGroup`
    -   `AWS::Logs::LogGroup`
