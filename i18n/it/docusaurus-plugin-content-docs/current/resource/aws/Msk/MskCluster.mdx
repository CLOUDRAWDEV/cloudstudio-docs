## Valori di configurazione della risorsa

#### Impostazioni di base

-   `cluster_type` : Tipo di cluster - `provisioned`, `serverless`
-   `kafka_version` : Versione di Apache Kafka da utilizzare nel cluster MSK
-   `kms_key_name` : Nome della chiave KMS utilizzata per la crittografia dei dati
-   `unauthenticated_access` : Consente l’accesso agli utenti non autenticati - `true`, `false`
-   `iam_role_based_authentication` : Abilitazione dell’autenticazione basata su ruoli IAM - `true`, `false`
-   `scram_authentication` : Abilitazione dell’autenticazione basata su SCRAM - `true`, `false`
-   `cloudwatch_metrics` : Ambito di raccolta delle metriche CloudWatch - `DEFAULT`, `PER_BROKER`, `PER_TOPIC_PER_BROKER`, `PER_TOPIC_PER_PARTITION`

#### Configurazione dei broker (`broker`)

-   `broker.instance_type` : Tipo di istanza del broker
-   `broker.broker_count_per_zone` : Numero di broker per zona di disponibilità (AZ)

#### Configurazione dello storage (`storage`)

-   `storage.ebs_volume_size` : Dimensione del volume EBS assegnato ai nodi broker (GB) - `1` ~ `16384`
-   `storage.enable_provisioned_throughput` : Abilitazione del throughput provisioned - `true`, `false`
-   `storage.provisioned_throughput_per_broker` : Throughput provisioned per broker (MiB/s) - minimo `250`

#### Configurazione di rete (`network`)

-   `network.linked_vpc_name` : Nome del VPC a cui il cluster sarà collegato
-   `network.subnet_names` : Elenco dei nomi delle subnet collegate al cluster MSK
-   `network.security_group_names` : Elenco dei nomi dei Security Group applicati al cluster MSK

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria - massimo 512 caratteri, `key`:`value`
