## 리소스 개요

Amazon ECS Cluster è una risorsa logica che consente di eseguire e gestire container Docker su un insieme di risorse di calcolo, come Amazon EC2 o AWS Fargate.

## 리소스 설정 값

#### 기본 설정

-   `set_container_insights` : Imposta se abilitare Container Insights sul cluster - `enabled`, `disabled`
-   `kms_key_name` : Nome della chiave AWS Key Management Service utilizzata per crittografare i dati tra client locali e container
-   `logging` : Impostazione dei log utilizzata per il reindirizzamento dei risultati dei comandi di esecuzione - `OVERRIDE`, `NONE`, `DEFAULT`
-   `cloud_watch_encryption_enabled` : Abilitazione della crittografia per i log CloudWatch - `true`, `false`
-   `cloud_watch_log_group_name` : Nome del gruppo di log CloudWatch a cui inviare i log
-   `capacity_providers` : Insieme di capacity provider associati al cluster

#### 서비스 (`service`)

-   `service.computing_option` : Metodo di distribuzione dei task del Service - `capacity_provider_strategy`, `launch_type`
-   `service.capacity_provider_strategy.capacity_provider` : Capacity provider applicato al Service - `FARGATE`, `FARGATE_SPOT`
-   `service.capacity_provider_strategy.base` : Numero minimo di task da eseguire
-   `service.capacity_provider_strategy.weight` : Percentuale relativa del numero totale di task eseguiti
-   `service.launch_type` : Tipo di avvio del Service - `EC2`, `FARGATE`, `EXTERNAL`
-   `service.task_definition_name` : Nome della ECS Task Definition utilizzata dal Service
-   `service.desired_count` : Numero di istanze della task definition da eseguire
-   `service.linked_security_group_names` : Elenco dei nomi dei Security Group da utilizzare
-   `service.subnet_names` : Elenco dei nomi delle subnet in cui eseguire il Service
-   `service.enabled_public_ip` : Abilitazione dell’uso di un Public IP - `true`, `false`

#### 태그

-   `tag` : Tag per classificare la risorsa per categoria
