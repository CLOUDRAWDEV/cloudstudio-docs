## Resource Overview

SourceCommit is a private Git repository service for securely storing source code and various files.  
By creating repositories in SourceCommit, teams can efficiently manage projects and easily store source code and related data.

## Resource Setting Values

#### Basic Settings

-   `enable_file_safer` : Whether to use File Safer - `true`, `false`
-   `description` : Repository description (up to 500 characters)
