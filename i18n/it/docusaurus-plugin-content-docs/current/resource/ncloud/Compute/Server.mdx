## Panoramica della risorsa

Risorsa di calcolo che fornisce flessibilità grazie alla virtualizzazione, consentendo di creare server nel cloud in modo efficiente in termini di tempo e costi, ideale per carichi variabili o temporanei.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `included_subnet_name` : Nome della subnet in cui risiede il server
-   `server_image_product_code` : Codice dell’immagine OS da utilizzare
-   `server_product_code` : Codice della configurazione hardware del server
-   `login_key_name` : Nome della login key
-   `init_script` : Nome dell’Init Script da utilizzare
-   `is_encrypted_base_block_storage_volume` : Abilitazione della crittografia del block storage
-   `linked_network_interface_names` : Interfacce di rete assegnate al server
