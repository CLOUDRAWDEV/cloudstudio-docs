## Panoramica della risorsa

Init Script è una funzionalità che consente di eseguire automaticamente uno script pre-scritto al momento della creazione del server. Può essere utilizzata in vari casi, come la creazione in batch di più server per lo stesso scopo, la creazione periodica di server con la stessa configurazione o la gestione dell'ambiente iniziale del server per scopi specifici.

## Impostazioni della risorsa

-   `OS_type` : Tipo di istanza del server da utilizzare - `LNX`, `WND`
-   `Content` : Contenuto dello script da eseguire automaticamente quando il server viene creato, ad esempio #!/bin/bash yum install -y httpd && systemctl start httpd
