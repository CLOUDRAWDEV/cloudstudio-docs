## Panoramica della risorsa

Init Script consente di eseguire automaticamente script predefiniti durante la creazione dei server, utile per creare più server con la stessa configurazione o per gestire ambienti iniziali standardizzati.

## Risorse correlate

### Risorsa principale

-   [**Region**](https://docs.cstudio.app/it/docs/resource/ncloud/Base/Region)

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `os_type` : Tipo di sistema operativo del server - `LNX`, `WND`
-   `content` : Contenuto dello script da eseguire automaticamente
-   `description` : Descrizione dell’Init Script
