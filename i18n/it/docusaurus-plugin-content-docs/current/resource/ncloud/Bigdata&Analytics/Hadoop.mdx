## Panoramica della risorsa

Hadoop è una **piattaforma Big Data di Ncloud** progettata per l’elaborazione distribuita di grandi volumi di dati.  
Consente di creare facilmente cluster composti da nodi edge, master e worker, gestibili tramite la console Ambari, e di aggiungere opzionalmente componenti come Spark, HBase e Impala.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `included_vpc_name` : Nome della VPC in cui verrà creato il cluster Hadoop
-   `cluster_name` : Nome del cluster
-   `cluster_type_code` : Codice del tipo di cluster (ad esempio con Spark incluso)
-   `admin_user_name` : Nome dell’account amministratore Ambari
-   `admin_user_password` : Password dell’amministratore Ambari
-   `login_key_name` : Nome della login key (per l’accesso basato su chiave pubblica)
-   `edge_node_subnet_no` : ID della subnet del nodo edge
-   `master_node_subnet_no` : ID della subnet del nodo master
-   `worker_node_subnet_no` : ID della subnet del nodo worker
-   `bucket_name` : Nome del bucket Object Storage per la memorizzazione dei dati
-   `master_node_data_storage_type` : Tipo di storage del nodo master (`SSD`, `HDD`)
-   `worker_node_data_storage_type` : Tipo di storage del nodo worker (`SSD`, `HDD`)
-   `master_node_data_storage_size` : Capacità di storage del nodo master
-   `worker_node_data_storage_size` : Capacità di storage del nodo worker
-   `image_product_code` : Codice prodotto dell’immagine server Hadoop
-   `engine_version_code` : Versione del motore Hadoop (`HADOOP2.2`, `HADOOP2.3`)
-   `edge_node_product_code` : Codice prodotto del nodo edge
-   `master_node_product_code` : Codice prodotto del nodo master
-   `worker_node_product_code` : Codice prodotto del nodo worker
-   `add_on_code_list` : Elenco degli add-on da installare (`HBASE`, `IMPALA`, `KUDU`, `TRINO`, `NIFI`)
-   `worker_node_count` : Numero di nodi worker (`2~8`)
-   `use_kdc` : Utilizzo dell’autenticazione KDC (`true`, `false`)
-   `kdc_realm` : Nome del realm KDC
-   `kdc_password` : Password KDC
-   `use_bootstrap_script` : Utilizzo dello script di bootstrap
-   `bootstrap_script` : Percorso dello script di bootstrap da eseguire
-   `use_data_catalog` : Utilizzo del data catalog
