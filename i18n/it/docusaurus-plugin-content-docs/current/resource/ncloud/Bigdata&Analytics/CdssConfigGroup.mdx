## Panoramica della risorsa

Cdss Config Group è un servizio che gestisce i file di configurazione Kafka applicati a un cluster CDSS.

## Risorse correlate

### Risorsa principale

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### Risorse collegate

-   [**CdssCluster**](https://docs.cstudio.app/docs/resource/ncloud/Bigdata&Analytics/CdssCluster)

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `kafka_version_code` : Versione di Kafka da utilizzare nel CDSS Config Group - `kafkaVersionCode`
-   `description` : Descrizione del config group
