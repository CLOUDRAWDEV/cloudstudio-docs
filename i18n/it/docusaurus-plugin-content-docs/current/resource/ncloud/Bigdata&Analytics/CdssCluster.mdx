## Panoramica della risorsa

È un servizio che consente di distribuire, proteggere, gestire e scalare facilmente un cluster Apache Kafka, una piattaforma open source per la creazione di pipeline di dati in streaming in tempo reale e applicazioni.

## Impostazioni della risorsa

-   `kafka_version_code` : Versione di Kafka da utilizzare in CDSS
-   `linked_config_group_name` : Nome del gruppo di configurazione CDSS da utilizzare
-   `os_image` : Tipo di immagine del sistema operativo da utilizzare
-   `cmak` : Informazioni di configurazione di CMAK (Cluster Manager for Apache Kafka)
    -   `user_name` : ID di accesso CMAK
    -   `user_password` : Password dell'ID di accesso CMAK
-   `manager_node` : Informazioni di configurazione del nodo che gestisce il cluster Apache Kafka tramite CMAK
    -   `manager_node_subnet_name` : Nome del subnet in cui si trova il nodo manager
    -   `manager_node_product_name` : Codice prodotto dell'hardware del nodo manager
-   `broker_node` : Informazioni di configurazione del nodo server dove i dati reali vengono memorizzati
    -   `broker_node_subnet_name` : Nome del subnet in cui si trova il nodo broker
    -   `broker_node_product_code` : Codice prodotto dell'hardware del nodo broker
    -   `broker_node_count` : Numero di nodi broker
    -   `broker_node_storage_size` : Capacità di archiviazione del nodo broker - `100~2000`
