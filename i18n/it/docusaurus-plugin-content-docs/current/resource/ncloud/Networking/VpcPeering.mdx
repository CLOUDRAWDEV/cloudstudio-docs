## Resource Overview

A resource used to configure VPC peering for communication between VPCs.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/it/docs/resource/ncloud/Base/Region)

### Connected Resources

-   [**Vpc**](https://docs.cstudio.app/it/docs/resource/ncloud/Networking/Vpc)

## Resource Setting Values

#### Basic Settings

-   `linked_vpc_name_01` : Name of the VPC sending the peering request (read-only)
-   `linked_vpc_name_02` : Name of the VPC receiving the peering request (read-only)
