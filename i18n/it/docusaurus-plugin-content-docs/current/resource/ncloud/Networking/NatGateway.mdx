## Panoramica della risorsa

Servizio che collega più server a un singolo IP pubblico e impedisce l'accesso diretto dall'esterno. Consente a server con indirizzi IP privati di comunicare con server esterni, mentre blocca l'accesso diretto dall'esterno per mantenere la sicurezza.

## Impostazioni della risorsa

-   `included_vpc_name` : Nome della VPC in cui verrà creato il Nat gateway
-   `zone` : Regione fisica in cui si troverà il Nat gateway
