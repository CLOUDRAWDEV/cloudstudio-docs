## Resource Overview

A service for creating network interfaces that can be attached to servers.  
Servers with assigned network interfaces can perform isolated network communication through Subnets.

## Associated Resources

### Parent Resource

-   [**Subnet**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Subnet)

### Connected Resources

-   [**AccessControlGroup**](https://docs.cstudio.app/docs/resource/ncloud/Networking/AccessControlGroup)
-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## Resource Setting Values

#### Basic Settings

-   `included_subnet_name` : Name of the Subnet in which the Network Interface will be included
-   `linked_acg_names` : List of Access Control Group names to apply to the Network Interface
