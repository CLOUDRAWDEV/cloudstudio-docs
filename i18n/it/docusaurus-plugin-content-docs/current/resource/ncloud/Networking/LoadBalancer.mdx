## Panoramica della risorsa

Dispositivo che distribuisce il traffico di rete su più server considerando le prestazioni e il carico del server. Può ottimizzare la disponibilità del server e i tempi di risposta distribuendo il carico su un server specifico, garantendo così un servizio senza interruzioni.

## Impostazioni della risorsa

-   `network_type` : Tipo di rete, pubblico o privato - `PUBLIC`, `PRIVATE`
-   `type` : Tipo di load balancer da creare, applicazione/rete/proxy di rete - `NETWORK`, `NETWORK_PROXY`, `APPLICATION`
-   `throughput_type` : Prestazioni di gestione del carico, numero di connessioni per secondo 30.000/60.000/90.000 - `SMALL`, `MEDIUM`, `LARGE`
-   `included_vpc_name` : Nome della VPC in cui verrà creato il gruppo di destinazione
-   `subnet_config`
    -   `cidr`
    -   `linked_nacl_name`
    -   `zone`
-   `target_group`
    -   `protocol` : Tipo di protocollo da applicare per il routing del traffico - `TCP`, `PROXY_TCP`, `HTTP`, `HTTPS`
    -   `port` : Numero della porta per ricevere il traffico
    -   `algorithm_type` : Tipo di algoritmo da utilizzare per il bilanciamento del carico, RR/SIPHS/LC - `RR`, `SIPHS`, `LC`, `MH`
    -   `health_check_protocol` : Protocollo da utilizzare per il controllo dello stato del target - `TCP`, `HTTP`, `HTTPS`
    -   `health_check_http_method` : Metodo HTTP da utilizzare per il controllo dello stato del target, se il protocollo di controllo è HTTP/HTTPS - `HEAD`, `GET`
    -   `health_check_port` : Numero di porta per il controllo dello stato del target
    -   `health_check_cycle` : Ciclo di controllo dello stato del target (in secondi), intervallo tra 5 e 300 secondi
    -   `health_check_up_threshold` : Soglia di stato normale, numero di controlli necessari affinché un target non normale venga considerato normale
    -   `health_check_down_threshold` : Soglia di errore, numero di controlli necessari affinché un target normale venga considerato non normale
-   `listener`
    -   `target_group_name` : Nome del gruppo di destinazione a cui connettersi
    -   `protocol` : Tipo di protocollo che il listener utilizzerà, applicazione-HTTP o HTTPS/rete-TCP/proxy di rete-TCP o TLS - `APPLICATION`, `HTTP`, `HTTPS`, `TCP`, `TLS`
    -   `port` : Numero di porta su cui il listener si lega al load balancer
-   `target_group_attachment`
    -   `target_group_name` : Nome del gruppo di destinazione a cui connettersi
    -   `linked_server_names` : Elenco dei nomi dei server a cui connettersi
