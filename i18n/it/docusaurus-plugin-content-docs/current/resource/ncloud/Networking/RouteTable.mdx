## Resource Overview

A service that defines network routing paths for resources within a VPC.

## Associated Resources

### Parent Resource

-   [**Vpc**](https://docs.cstudio.app/it/docs/resource/ncloud/Networking/Vpc)

### Connected Resources

-   [**Subnet**](https://docs.cstudio.app/it/docs/resource/ncloud/Networking/Subnet)

## Resource Setting Values

#### Basic Settings

-   `included_vpc_name` : Name of the VPC to which the Route Table will be attached
-   `supported_subnet_type` : Supported Subnet type (`PUBLIC`, `PRIVATE`)
-   `route_table_description` : Description of the Route Table
-   `linked_subnet_names` : List of Subnet names to associate with the Route Table

#### Routing Settings (`route`)

-   `target_type` : Destination type (`NATGW`, `VPCPEERING`)
-   `target_name` : Name of the destination resource
-   `destination_cidr_block` : Destination IP range in CIDR format
