## Panoramica della risorsa

Servizio che definisce il percorso di rete delle risorse all'interno della VPC.

## Risorse correlate

### Risorse superiori

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

### Risorse collegate

-   [**Subnet**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Subnet)

## Impostazioni della risorsa

-   `included_vpc_name` : Nome della VPC da connettere
-   `supported_subnet_type` : Tipo di subnet supportata, pubblico o privato - `PUBLIC`, `PRIVATE`
-   `route_table_description` : Descrizione della Route Table
-   `linked_subnet_names` : Elenco dei nomi delle subnet da connettere
-   `route`
    -   `target_type` : Tipo di destinazione, Nat gateway o VPC peering - `NATGW`, `VPCPEERING`, `VGW`
    -   `target_name` : Nome della destinazione
    -   `destination_cidr_block` : Intervallo IP di destinazione in formato CIDR
