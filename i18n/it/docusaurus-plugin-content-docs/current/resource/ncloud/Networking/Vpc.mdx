## Resource Overview

A virtual private network environment provided in the cloud, allowing users to configure isolated network spaces.  
You can define IP address ranges, Subnets, routing tables, and gateways to securely operate cloud resources.

## Valori di configurazione della risorsa

#### Basic Settings

-   `ipv4_cidr_block` : IPv4 CIDR block to assign to the VPC
-   `vpc_name` : Name of the VPC
