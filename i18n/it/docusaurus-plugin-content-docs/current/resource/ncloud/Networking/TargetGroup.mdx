## Resource Overview

A resource that represents a group of targets responsible for handling requests from a Load Balancer.

## Associated Resources

### Parent Resource

-   [**Vpc**](https://docs.cstudio.app/it/docs/resource/ncloud/Networking/Vpc)

### Connected Resources

-   [**Server**](https://docs.cstudio.app/it/docs/resource/ncloud/Compute/Server)
-   [**LoadBalancer**](https://docs.cstudio.app/it/docs/resource/ncloud/Networking/LoadBalancer)
-   [**AutoScaling**](https://docs.cstudio.app/it/docs/resource/ncloud/Compute/AutoScaling)

## Resource Setting Values

#### Basic Settings

-   `included_vpc_name` : Name of the VPC in which the Target Group will be created
-   `target_group_name` : Name of the Target Group
-   `target_type` : Target type (`SERVER`, `AUTO_SCALING_GROUP`)
-   `protocol` : Protocol type (`HTTP`, `HTTPS`, `TCP`)
-   `port` : Target port number
