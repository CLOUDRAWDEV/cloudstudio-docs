## Panoramica della risorsa

Subnet della VPC che consente una suddivisione dettagliata in base agli scopi della rete.

## Impostazioni della risorsa

-   `subnet_cidr` : Intervallo di indirizzi IP della subnet all'interno dell'intervallo di indirizzi della VPC
-   `zone` : Regione fisica in cui si trova la subnet - `KR-1`, `KR-2`
-   `subnet_type` : Tipo di subnet, pubblico o privato - `PUBLIC`, `PRIVATE`
-   `usage_type` : Impostazione per l'uso del load balancer  - `GEN`, `BM`
-   `included_vpc_name` : Nome della VPC in cui si trova la subnet
-   `linked_nacl_name` : Lista di controllo degli accessi alla rete (NACL) per il controllo dell'accesso alla subnet
