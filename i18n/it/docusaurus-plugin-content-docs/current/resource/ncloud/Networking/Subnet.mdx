## Resource Overview

A VPC sub-network that allows network segmentation by usage purpose.

## Resource Setting Values

#### Basic Settings

-   `subnet` : IPv4 CIDR block of the Subnet
-   `subnet_name` : Name of the Subnet
-   `zone` : Physical zone where the Subnet will be created
-   `subnet_type` : Subnet type (`PUBLIC`, `PRIVATE`)
-   `usage_type` : Usage type of the Subnet (`GEN`, `LOADB`, `NATGW`)
