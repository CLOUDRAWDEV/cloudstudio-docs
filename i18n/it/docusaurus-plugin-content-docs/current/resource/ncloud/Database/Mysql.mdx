## Resource Overview

Mysql is a fully managed cloud database service based on the relational database MySQL, enabling easy deployment, stable operation, and automatic recovery in case of failures.

## Resource Setting Values

#### Basic Settings

-   `server_name_prefix` : MySQL server name (lowercase letters, numbers, hyphens allowed; must start with a lowercase letter and end with a lowercase letter or number; 3–30 characters)
-   `users` : User configuration (`password`, `host_ip`, `authority` - `DDL | CRUD | READ`)
-   `databases` : List of database names to create
-   `included_subnet_names` : List of subnet names where MySQL is located
-   `image_product_code` : MySQL server image product code
-   `product_code` : MySQL instance server product code
-   `data_storage_type` : Data storage type - `SSD`, `HDD`
-   `enable_high_availability` : Whether to enable high availability - `true`, `false`
-   `enable_storage_encryption` : Whether to enable storage encryption - `true`, `false`
-   `enable_backup` : Whether to enable backup - `true`, `false`
-   `backup_file_retention_period` : Backup retention period in days - `1` ~ `30`
-   `enable_automatic_backup` : Whether to enable automatic backup - `true`, `false`
-   `backup_time` : User-defined backup time
-   `port` : MySQL access port - `3306` ~ `20000`
