## Panoramica della risorsa

Cloud DB for Redis è un servizio di cache cloud completamente gestito che consente di creare facilmente una cache Redis con poche impostazioni e clic. Grazie alle impostazioni ottimizzate di Naver, offre un'operazione stabile e si recupera automaticamente in caso di guasto.

## Impostazioni della risorsa

-   `server_name_prefix` : Nome del server Redis Cache
-   `redis_mode` : Tipo di modalità di configurazione di Redis - `CLUSTER`, `SIMPLE`
-   `image_product_code` : Codice del prodotto dell'immagine del server Redis con le specifiche dell'istanza di Redis da creare
-   `target_config_group_name` : Nome del Config Group a cui collegarsi
-   `product_code` : Codice del prodotto che determina le specifiche hardware del server Redis da creare
-   `data_storage_type` : Tipo di storage dei dati - `SSD`, `HDD`
-   `shard_count` : Numero di shard da creare. Numero di nodi master - `3~10`
-   `shard_copy_count` : Numero di repliche per ogni shard in un cluster Redis costituito da nodi master e slave. Per alta disponibilità (HA), è necessario un nodo slave. Quando si aggiungono repliche, a ciascun nodo master viene assegnato un nodo slave
-   `enable_high_availability` : Se abilitare la funzionalità di alta disponibilità
-   `enable_backup` : Se abilitare la funzionalità di backup. Se la funzionalità di alta disponibilità è abilitata, il backup è obbligatoriamente attivato
-   `port` : Porta di accesso Redis - `6379`
