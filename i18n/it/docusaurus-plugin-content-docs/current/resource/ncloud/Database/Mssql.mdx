## Panoramica della risorsa

Cloud DB for MSSQL è un servizio che consente di creare facilmente un database MSSQL e di gestirlo automaticamente. Grazie alle impostazioni ottimizzate di Naver, offre un'operazione stabile e si recupera automaticamente in caso di guasto, essendo un servizio di database cloud completamente gestito.

## Impostazioni della risorsa

-   `enable_high_availability` : Se abilitare la funzionalità di alta disponibilità
-   `user_name` : ID di accesso dell'utente MSSQL
-   `user_password` : Password dell'utente MSSQL
-   `image_product_code` : Codice del prodotto dell'immagine per le specifiche del server istanza MSSQL da creare
-   `product_code` : Codice del prodotto per le specifiche del server istanza MSSQL da creare
-   `data_storage_type` : Tipo di storage dei dati - `SSD`, `HDD`
-   `backup_file_retention_period` : Periodo di conservazione dei file di backup, il backup viene effettuato quotidianamente e i file di backup sono memorizzati su uno storage separato - `1~30`
-   `enable_automatic_backup` : Se abilitare la funzionalità di backup automatico
-   `port` : Porta di accesso MySQL - `3306~20000`
-   `character_set_name` : Set di caratteri del DB. È possibile scegliere tra una combinazione di coreano e inglese
