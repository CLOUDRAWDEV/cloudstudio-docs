## Resource Overview

Cloud DB for MSSQL is a fully managed cloud database service that enables easy deployment and automatic management of MSSQL databases.  
It operates stably with Naver’s optimized settings and provides automatic recovery in case of failures.

## Associated Resources

### Parent Resource

-   [**Subnet**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Subnet)

## Resource Setting Values

#### Basic Settings

-   `included_subnet_name` : Name of the Subnet where MSSQL is located
-   `enable_high_availability` : Whether to enable high availability - `true`, `false`
-   `user_name` : MSSQL user access ID
-   `user_password` : MSSQL user password
-   `image_product_code` : MSSQL instance server image product code
-   `product_code` : MSSQL instance server product code
-   `data_storage_type` : Data storage type - `SSD`, `HDD`
-   `backup_file_retention_period` : Backup retention period in days - `1` ~ `30`
-   `enable_automatic_backup` : Whether to enable automatic backup - `true`, `false`
-   `backup_time` : User-defined backup time
-   `port` : TCP port for MSSQL access (default: `1433`)
-   `character_set_name` : Database character set - `characterSetName`
