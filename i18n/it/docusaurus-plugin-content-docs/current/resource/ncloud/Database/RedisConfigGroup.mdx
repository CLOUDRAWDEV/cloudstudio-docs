## Resource Overview

Redis Config Group allows you to group Redis servers and apply identical configuration values to all servers in the group for efficient management.

## Associated Resources

## Valori di configurazione della risorsa

#### Basic Settings

-   `redis_version` : Redis Config Group version and mode
-   `description` : Description of the Redis Config Group
