## Panoramica della risorsa

Servizio di storage che collega più server alla rete per consentire la condivisione dei dati tra numerosi utenti. È uno spazio di archiviazione connesso tramite rete, ideale per la condivisione dei dati tra più utenti.

## Impostazioni della risorsa

-   `volume_name_postfix` : Nome del volume NAS, consentiti caratteri alfanumerici, intervallo da 3 a 20 caratteri
-   `volume_size` : Dimensione del volume (100GB), intervallo da 500 a 10.000
-   `volume_allotment_protocol_type` : Tipo di protocollo, server che possono essere montati: NFS per Linux / CIFS per Windows - `NFS`, `CIFS`
