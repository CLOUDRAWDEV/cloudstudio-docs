## Resource Overview

An additional HDD or SSD storage service provided separately from a server’s base storage.  
It can be created and attached to a server immediately, and can be returned when no longer needed.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/it/docs/resource/ncloud/Base/Region)

### Connected Resources

-   [**Server**](https://docs.cstudio.app/it/docs/resource/ncloud/Compute/Server)

## Resource Setting Values

#### Basic Settings

-   `zone` : Physical zone where the Block Storage is located - `KR-1`, `KR-2`
-   `linked_server_name` : Name of the server to which the block storage will be attached
-   `storage_size` : Block storage size (GB) - `10` ~ `16380`
-   `storage_disk_type` : Block storage disk type - `SSD`, `HDD`
