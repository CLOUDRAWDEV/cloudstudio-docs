## Resource Overview

Object Storage is an object-based storage service that allows storing and retrieving all types of data over the internet.  
Access permissions for buckets and objects can be configured through access policies (rules).

## Associated Resources

## Valori di configurazione della risorsa

#### Basic Settings

-   `rule` : Object Storage access policy - `private`, `public-read`, `public-read-write`, `authenticated-read`
