## Panoramica della risorsa

API Management è un servizio che supporta in modo integrato la creazione, la distribuzione, la sicurezza, il monitoraggio e la gestione delle API.  
Espone le API chiamate da client interni ed esterni tramite un unico endpoint e consente un funzionamento stabile delle API applicando politiche di autenticazione e autorizzazione, trasformazioni di richieste e risposte, limitazione delle chiamate (throttling), logging e monitoraggio.  
Inoltre, le API possono essere pubblicate sotto forma di portale, consentendo di gestire congiuntamente la documentazione e gli abbonati.

## Configurazione della risorsa

-   `publisher_name` : Nome del publisher del servizio API Management

-   `publisher_email` : Indirizzo email del publisher

-   `sku_name` : Nome dello SKU (piano tariffario) del servizio API Management – `Consumption`, `Developer`, `Basic`, `BasicV2`, `Standard`, `StandardV2`, `Premium`, `PremiumV2`

-   `sku_capacity` : Impostazione della capacità (numero di istanze) per lo SKU selezionato

-   `virtual_network_type` : Modalità con cui API Management si connette a una rete virtuale – `None`, `External`, `Internal`

-   `target_subnet_name` : Nome della subnet in cui verrà distribuito API Management

-   `apis` : Opzione per specificare l’elenco delle API da registrare o gestire nel servizio API Management
    -   `revision` : Numero di revisione dell’API
    -   `api_type` : Tipo di API – `http`, `soap`, `graphql`
    -   `display_name` : Nome dell’API visualizzato nel portale
    -   `path` : Percorso utilizzato per accedere all’endpoint dell’API
    -   `protocols` : Protocolli di comunicazione supportati dall’API – `http`, `https`, `ws`, `wss`
