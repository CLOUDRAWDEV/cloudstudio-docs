## Panoramica della risorsa

Una Private DNS Zone è un’area utilizzata per gestire i record DNS per nomi di dominio privati utilizzati esclusivamente all’interno di una rete virtuale di Azure.  
Collegandola a una rete virtuale (VNet Link), è possibile eseguire in modo sicuro la risoluzione dei nomi tra le risorse interne.

## Valori di configurazione della risorsa

#### Record A (`private_dns_a_record`)

-   `private_dns_a_record.ttl` : Time To Live del record DNS (secondi) - `0` ~ `2147483647`
-   `private_dns_a_record.records` : Elenco degli indirizzi IPv4

#### Record AAAA (`private_dns_aaaa_record`)

-   `private_dns_aaaa_record.ttl` : Time To Live del record DNS (secondi) - `0` ~ `2147483647`
-   `private_dns_aaaa_record.records` : Elenco degli indirizzi IPv6

#### Record CNAME (`private_dns_cname_record`)

-   `private_dns_cname_record.ttl` : Time To Live del record DNS (secondi) - `0` ~ `2147483647`
-   `private_dns_cname_record.record` : Alias per collegare un sottodominio a un altro record

#### Record PTR (`private_dns_ptr_record`)

-   `private_dns_ptr_record.ttl` : Time To Live del record DNS (secondi) - `0` ~ `2147483647`
-   `private_dns_ptr_record.records` : Elenco dei nomi di dominio per i record di tipo puntatore

#### Record TXT (`private_dns_txt_record`)

-   `private_dns_txt_record.ttl` : Time To Live del record DNS (secondi) - `0` ~ `2147483647`
-   `private_dns_txt_record.records` : Elenco dei record di tipo testo

#### Collegamento della rete virtuale (`vnet_link`)

-   `vnet_link.linked_vnet_name` : Nome della rete virtuale collegata alla Private DNS Zone

#### Tag

-   `tag` : Tag per classificare la risorsa - massimo 512 caratteri, `key`:`value`
