## Panoramica della risorsa

Azure Container Registry è un servizio di registro di container privato progettato per archiviare e gestire in modo sicuro  
immagini di container e artefatti OCI.  
Si integra strettamente con carichi di lavoro basati su Docker e Kubernetes e consente una configurazione dettagliata  
di sicurezza, prestazioni e controllo degli accessi di rete.

## Valori di configurazione della risorsa

-   `sku` :  
    Tipo di SKU per le prestazioni e la scalabilità del Container Registry

    -   `Basic`
    -   `Standard`
    -   `Premium`

-   `admin_enabled` :  
    Abilitazione dell’account amministratore – `true`, `false`

-   `public_network_access_enabled` :  
    Abilitazione dell’accesso alla rete pubblica – `true`, `false`

### Impostazioni delle regole di rete (`network_rule_set`)

> Configurabile solo quando lo SKU è impostato su `Premium`.

-   `network_rule_set.default_action` :  
    Azione predefinita per le richieste che non corrispondono ad alcuna regola

    -   `Allow`
    -   `Deny`

-   `network_rule_set.ip_ranges` :  
    Elenco degli indirizzi IP CIDR per le richieste che corrispondono alle regole

### Tag

-   `tag` :  
    Tag per classificare la risorsa per categoria – massimo 512 caratteri, `key`:`value`
