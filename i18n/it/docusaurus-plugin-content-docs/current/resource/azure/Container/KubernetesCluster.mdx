## Panoramica della risorsa

Azure Kubernetes Service (AKS) è un servizio gestito che consente di distribuire e gestire facilmente cluster Kubernetes.  
È possibile operare workload basati su container configurando le impostazioni di base del cluster, l’autenticazione/autorizzazione (RBAC), le policy di rete, la configurazione dei node pool e il controllo degli accessi al server API.

## Valori di configurazione della risorsa

-   `dns_prefix` : Prefisso DNS da utilizzare insieme all’FQDN del server API Kubernetes ospitato

-   `sku_tier` : Livello di prezzo per l’utilizzo del cluster Kubernetes – `Free`, `Standard`

-   `enable_public_network_access` : Abilitazione dell’accesso dalla rete pubblica – `true`, `false`

-   `api_server_authorized_ip_ranges` : Elenco degli intervalli di indirizzi IP autorizzati per proteggere l’accesso al server API

-   `authentication_authorization` : Metodo di autorizzazione per limitare l’accesso alle risorse del cluster – `local_accounts`, `azure_rbac`, `kubernetes_rbac`

-   `admin_group_object_ids` : Elenco degli ID oggetto dei gruppi Azure Active Directory che devono avere il ruolo di amministratore del cluster

-   `network_policy` : Policy di rete per limitare l’accesso a specifici Pod – `calico`, `azure`, `none`

-   `load_balancer_sku` : Livello di prezzo del Load Balancer – `standard`, `basic`

-   `network_plugin` : Metodo di configurazione della rete virtuale di base – `kubenet`, `azure`

-   `included_subnet_name` : Nome della Subnet in cui verrà distribuito il cluster Kubernetes

-   `pod_cidr` : CIDR per l’assegnazione degli indirizzi IP ai Pod

-   `service_cidr` : Intervallo CIDR per l’assegnazione degli IP di servizio del cluster

-   `dns_service_ip` : Indirizzo IP assegnato al servizio DNS di Kubernetes

-   `outbound_type` : Tipo di routing in uscita – `loadBalancer`, `userDefinedRouting`

### Impostazioni del node pool predefinito (`default_node_pool`)

-   `default_node_pool.node_pool_name` : Nome del Node Pool – Linux `1` ~ `12` caratteri, Windows `1` ~ `6` caratteri

-   `default_node_pool.enable_auto_scaling` : Abilitazione dell’auto-scaling del cluster – `true`, `false`

-   `default_node_pool.node_count` : Numero di nodi nel Node Pool – `0` ~ `1000`

-   `default_node_pool.min_node_count` : Numero minimo di nodi nel Node Pool – `1` ~ `1000`

-   `default_node_pool.max_node_count` : Numero massimo di nodi nel Node Pool – `1` ~ `1000`

-   `default_node_pool.vm_size` : Dimensione delle macchine virtuali che compongono i nodi del Node Pool

-   `default_node_pool.os_disk_size_gb` : Dimensione del disco OS della macchina virtuale (GB) – `30` ~ `2048`

-   `default_node_pool.max_pods` : Numero massimo di Pod eseguibili su un nodo – `10` ~ `250`

-   `default_node_pool.enable_node_public_ip` : Abilitazione dell’uso di un indirizzo IP pubblico per nodo – `true`, `false`

-   `default_node_pool.public_ip_prefix_name` : ID risorsa del prefisso di indirizzi IP pubblici per i nodi di questo Node Pool

-   `default_node_pool.temporary_name_for_rotation` : Nome temporaneo del Node Pool da specificare obbligatoriamente in caso di modifica di determinati valori

### Impostazioni dei node pool aggiuntivi (`cluster_node_pool`)

-   `cluster_node_pool.node_mode` : Modalità del Node Pool – `User`, `System`

-   `cluster_node_pool.node_os_type` : Tipo di sistema operativo delle VM nel Node Pool – `Linux`, `Windows`

-   `cluster_node_pool.enable_auto_scaling` : Abilitazione dell’auto-scaling – `true`, `false`

-   `cluster_node_pool.node_count` : Numero di nodi nel Node Pool

-   `cluster_node_pool.max_node_count` : Numero massimo di nodi nel Node Pool

-   `cluster_node_pool.min_node_count` : Numero minimo di nodi nel Node Pool

-   `cluster_node_pool.vm_size` : Dimensione delle macchine virtuali che compongono i nodi del Node Pool

-   `cluster_node_pool.os_disk_size_gb` : Dimensione del disco OS della macchina virtuale (GB) – `30` ~ `2048`

-   `cluster_node_pool.max_pods` : Numero massimo di Pod eseguibili su un nodo – `10` ~ `250`

-   `cluster_node_pool.enable_node_public_ip` : Abilitazione dell’uso di un indirizzo IP pubblico per nodo – `true`, `false`

-   `cluster_node_pool.public_ip_prefix_name` : ID risorsa del prefisso di indirizzi IP pubblici per i nodi di questo Node Pool

### Tag

-   `tag` : Tag per classificare la risorsa per categoria – massimo 512 caratteri, `key`:`value`
