## Panoramica della risorsa

Azure Virtual WAN è un **servizio di hub di rete globale** progettato per connettere e gestire in modo centralizzato risorse di rete distribuite in più aree geografiche.  
Consente la gestione unificata delle connessioni Site-to-Site VPN, Point-to-Site VPN ed ExpressRoute da un unico punto di controllo, risultando ideale per architetture di rete multi-regione su larga scala.
