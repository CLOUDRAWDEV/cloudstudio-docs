## Panoramica della risorsa

Public IP Prefix è una risorsa di rete in Azure che consente di riservare e gestire in anticipo un **intervallo contiguo di indirizzi IP pubblici**.  
Assegnando più Public IP da un blocco di indirizzi coerente, offre prevedibilità e semplicità operativa nella gestione delle regole del firewall o nell’integrazione con sistemi esterni.

## Valori di configurazione della risorsa

-   `prefix_length` : Lunghezza in bit del Public IP Prefix - `28` ~ `31`
-   `tag` : Tag per classificare la risorsa - fino a 512 caratteri, `key`:`value`
