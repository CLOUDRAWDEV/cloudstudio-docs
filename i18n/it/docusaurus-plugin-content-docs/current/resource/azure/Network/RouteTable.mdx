## Panoramica della risorsa

Route Table è una risorsa di rete di Azure applicata ai Subnet all’interno di una Virtual Network per **controllare in modo personalizzato i percorsi del traffico di rete**.  
Oltre alle route di sistema predefinite, è possibile specificare esplicitamente i flussi di traffico verso destinazioni come appliance virtuali, Internet o gateway.

## Valori di configurazione della risorsa

-   `enable_bgp_route_propagation` : Indica se abilitare la propagazione delle route del gateway - `true`, `false`
-   `linked_subnet_names` : Elenco dei nomi dei Subnet da associare alla Route Table
-   `tag` : Tag per classificare la risorsa - fino a 512 caratteri, `key`:`value`

#### Configurazione delle route (`route`)

-   `route.route_address_prefix` : Prefisso di indirizzo IP (CIDR) che rappresenta la route
-   `route.next_hop_type` : Tipo di hop successivo
    -   `VirtualNetworkGateway`
    -   `VnetLocal`
    -   `Internet`
    -   `VirtualAppliance`
    -   `None`
