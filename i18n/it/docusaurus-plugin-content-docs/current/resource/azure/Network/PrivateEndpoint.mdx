## Panoramica della risorsa

Private Endpoint è una risorsa di rete che fornisce **connettività privata (Private Link)** ai servizi di Azure all’interno di una Virtual Network senza utilizzare un indirizzo IP pubblico.  
L’endpoint del servizio viene esposto tramite una Private IP assegnata a un Subnet, consentendo di configurare un percorso di comunicazione sicuro che non transita da Internet.  
Integrandosi con una Private DNS Zone, è possibile risolvere in modo naturale l’FQDN del servizio all’interno della rete interna.

## Valori di configurazione della risorsa

-   `included_subnet_name` : Nome del Subnet che contiene la Private IP assegnata al Private Endpoint
-   `connection_name` : Nome della connessione tra il Private Endpoint e la risorsa
-   `linked_connection_resource_name` : Nome della risorsa a cui il Private Endpoint verrà collegato
-   `subresource_name` : Nome della sottorisorsa a cui il Private Endpoint verrà collegato
-   `dns_zone_group_name` : Nome del gruppo di Private DNS Zone da associare al Private Endpoint
-   `private_dns_zone_names` : Elenco dei nomi delle Private DNS Zone da associare al Private Endpoint
-   `manual_connection` : Indica se è richiesta l’approvazione manuale da parte del proprietario della risorsa esterna - `true`, `false`
-   `tag` : Tag per classificare la risorsa - fino a 512 caratteri, `key`:`value`
