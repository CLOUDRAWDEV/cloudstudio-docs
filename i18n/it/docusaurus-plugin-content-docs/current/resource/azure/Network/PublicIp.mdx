## Panoramica della risorsa

Public IP è una risorsa di rete che fornisce un indirizzo IP pubblico, consentendo alle risorse di Azure di effettuare **comunicazioni dirette in ingresso e in uscita** con Internet.  
Si integra con servizi come Load Balancer, Virtual Machine e NAT Gateway per fungere da punto di ingresso del traffico esterno o da uscita per il traffico in uscita; la disponibilità e il comportamento variano in base allo SKU e al metodo di allocazione.

## Valori di configurazione della risorsa

-   `sku` : Livello di prezzo della Public IP - `Standard`, `Basic`
-   `allocation_method` : Metodo di allocazione dell’indirizzo Public IP - `Static`, `Dynamic`
-   `tag` : Tag per classificare la risorsa - fino a 512 caratteri, `key`:`value`
