## Panoramica della risorsa

Azure VpnSite è una **risorsa di definizione del sito VPN utilizzata per collegare reti on-premises a un ambiente Virtual WAN**.  
Definisce il target logico di una connessione VPN Site-to-Site sulla base delle informazioni del dispositivo VPN on-premises, degli spazi di indirizzamento e dei dettagli del collegamento.

## Valori di configurazione della risorsa

-   `linked_virtual_wan_name` : Nome del Virtual WAN a cui è collegato il VPN Site
-   `device_vendor` : Produttore del dispositivo VPN on-premises
-   `address_cidrs` : Elenco degli intervalli di indirizzi IP (CIDR) utilizzati dal VPN Site

#### Link (`link`)

-   `link.speed_in_mbps` : Velocità massima del collegamento (Mbps)
-   `link.ip_address` : Indirizzo IP pubblico assegnato al dispositivo VPN
-   `link.provider_name` : Nome del fornitore del servizio
-   `link.autonomous_system_number` : ASN del router on-premises quando si utilizza BGP
-   `link.peering_address` : Indirizzo IP del router locale utilizzato per il peering BGP
