## Valori di configurazione della risorsa

-   `included_vnet_name` : Nome della Virtual Network che include il Subnet
-   `address_prefixes` : Intervallo di indirizzi IP utilizzato dal Subnet, un intervallo di indirizzi univoco specificato in formato CIDR all’interno dello spazio di indirizzi della Virtual Network
-   `private_link_endpoint_enabled` : Indica se collegare un Private Endpoint al Subnet - `true`, `false`

#### Impostazioni di delega (`delegation`)

-   `delegation.service_name` : Nome del servizio da delegare
-   `delegation.actions` : Elenco delle azioni da delegare
