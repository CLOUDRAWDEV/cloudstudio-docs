## Panoramica della risorsa

Network DDoS Protection Plan è un servizio di sicurezza progettato per proteggere le risorse di Azure Virtual Network da attacchi di Distributed Denial of Service (DDoS) su larga scala.  
Attraverso l’analisi del traffico e funzionalità di mitigazione automatica, aiuta a mantenere la disponibilità delle applicazioni e fornisce ulteriori funzioni di protezione quando si verificano attacchi.
