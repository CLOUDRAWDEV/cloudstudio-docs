## Panoramica della risorsa

Virtual Network Gateway è un gateway di rete che fornisce **percorsi di comunicazione del traffico crittografati** tra una Azure Virtual Network e una rete on-premises oppure un’altra Virtual Network.  
Può essere connesso tramite VPN o ExpressRoute ed è un componente chiave per configurazioni di rete ibride e connessioni dedicate sicure.

## Valori di configurazione della risorsa

-   `included_subnet_name` : Nome del Subnet tramite il quale il Virtual Network Gateway invia e riceve traffico
-   `gateway_type` : Tipo di Virtual Network Gateway - `Vpn`, `ExpressRoute`
-   `vpn_type` : Tipo di connessione VPN - `RouteBased`, `PolicyBased`
-   `sku` : Livello di prezzo del Virtual Network Gateway
-   `generation` : Generazione del Virtual Network Gateway - `Generation1`, `Generation2`
-   `enabled_active_active_mode` : Indica se la modalità Active-Active è abilitata
-   `enabled_configure_bgp` : Indica se BGP è abilitato
-   `tag` : Tag per classificare la risorsa - fino a 512 caratteri, `key`:`value`

#### Configurazione IP (`ip_configuration`)

-   `ip_configuration.linked_public_ip_name` : Nome della Public IP da associare al Virtual Network Gateway
