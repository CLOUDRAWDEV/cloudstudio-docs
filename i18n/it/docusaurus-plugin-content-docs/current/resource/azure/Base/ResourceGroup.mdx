## Panoramica della risorsa

Un gruppo di risorse è un contenitore che include le risorse correlate per una soluzione Azure.
Un gruppo di risorse può includere tutte le risorse della soluzione oppure solo le risorse che si desidera gestire come gruppo.
La modalità di assegnazione delle risorse ai gruppi di risorse dipende da ciò che è più adatto alla propria organizzazione.
In genere, si aggiungono allo stesso gruppo di risorse le risorse che condividono lo stesso ciclo di vita, in modo da poterle distribuire, aggiornare ed eliminare facilmente come gruppo.
