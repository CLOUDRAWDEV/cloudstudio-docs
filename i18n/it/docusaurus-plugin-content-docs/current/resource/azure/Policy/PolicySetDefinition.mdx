## Panoramica della risorsa

Azure PolicySetDefinition è una **risorsa di definizione di set di criteri che consente di raggruppare più Policy Definition in un unico insieme logico per la gestione centralizzata**.  
Organizzando criteri con un obiettivo comune in un’unica unità, permette di applicare e gestire le policy in modo coerente anche in ambienti di grandi dimensioni.

## Valori di configurazione della risorsa

-   `type` : Tipo di definizione del set di policy - `Custom`, `BuiltIn`
-   `display_name` : Nome visualizzato del set di policy
-   `definition_names` : Elenco dei nomi delle Policy Definition incluse nel set
