## Valori di configurazione della risorsa

Log Analytics è uno strumento utilizzato nel Azure Portal per modificare ed eseguire query sui dati nel repository di log di Azure Monitor.
Puoi scrivere una query semplice che restituisce un set di record e poi utilizzare le funzionalità di Log Analytics per ordinare, filtrare e analizzare i dati. Oppure, puoi scrivere query avanzate per eseguire analisi statistiche e visualizzare i risultati in grafici per identificare tendenze specifiche.
Indipendentemente che tu stia trattando i risultati delle query in modo interattivo o utilizzando altre funzionalità di Azure Monitor come avvisi su query o log di fogli di calcolo, Log Analytics viene utilizzato per scrivere e testare le query.

## Impostazioni della risorsa

-   `retention_in_days` : Numero di giorni di conservazione dei dati nel Workspace - `30`~ `730`

-   `internet_query_enabled` : Attivazione delle query tramite internet pubblico - `true`, `false`

-   `internet_ingestion_enabled` : Attivazione della raccolta dei dati tramite internet pubblico - `true`, `false`

-   `tag` : g per classificare le risorse in categorie - massimo 512 caratteri, `key`:`value`
