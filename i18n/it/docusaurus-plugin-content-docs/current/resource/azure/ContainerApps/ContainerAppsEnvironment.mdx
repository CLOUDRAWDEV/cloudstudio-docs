## Panoramica della risorsa

Azure Container Apps Environment è una risorsa che definisce l’ambiente di rete e di monitoraggio in cui vengono eseguite le Azure Container Apps.  
Collegando ambienti operativi come il Log Analytics Workspace utilizzato durante la creazione e l’esecuzione delle Container Apps, è possibile applicare in modo coerente la configurazione di raccolta dei log e di monitoraggio.
