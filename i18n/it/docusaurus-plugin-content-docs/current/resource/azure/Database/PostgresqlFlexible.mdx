## Panoramica della risorsa

Azure PostgreSQL Flexible Server è un servizio di database relazionale basato sul motore di database open source PostgreSQL.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `version` : Versione di PostgreSQL da utilizzare – `11`, `12`, `13`, `14`
-   `sku_name` : Nome del livello di prezzo di PostgreSQL, combinazione di Tier + generazione di calcolo + numero di core
-   `storage_mb` : Capacità massima del PostgreSQL Flexible Server (MB)
-   `admin_username` : Nome utente amministratore del server quando la modalità di creazione è `default`, solo alfanumerico, senza parole riservate, `1` ~ `16` caratteri
-   `admin_password` : Password di accesso dell’amministratore del server quando la modalità di creazione è `default`, deve includere almeno 3 tra lettere minuscole, maiuscole, numeri e caratteri speciali, non può contenere più di 3 caratteri alfanumerici consecutivi del nome utente, `8` ~ `128` caratteri
-   `availability_zone` : Zona di disponibilità da utilizzare. Valori possibili `1`, `2`, `3` – `1` ~ `3`
-   `enable_high_availability` : Abilitazione dell’alta disponibilità del PostgreSQL Flexible Server – `true`, `false`
-   `high_availability_mode` : Modalità di alta disponibilità del PostgreSQL Flexible Server – `SameZone`, `ZoneRedundant`
-   `standby_availability_zone` : Zona di disponibilità del server di standby. Valori possibili `1`, `2`, `3`. Non può coincidere con la zona di disponibilità primaria – `1` ~ `3`
-   `backup_retention_days` : Numero di giorni di conservazione dei backup del PostgreSQL Flexible Server – `7` ~ `35`
-   `geo_redundant_backup_enabled` : Stato di abilitazione del backup con ridondanza geografica – `true`, `false`
-   `public_network_access_enabled` : Consente l’accesso alla rete pubblica per il server – `true`, `false`
-   `delegated_subnet_name` : Nome della subnet per la delega della rete virtuale
-   `private_dns_zone_name` : Zona DNS privata per la creazione del PostgreSQL Flexible Server

#### Configurazione del server (`configuration`)

-   `configuration.name` : Nome del parametro di configurazione del server PostgreSQL
-   `configuration.param_value` : Valore del parametro di configurazione del PostgreSQL Flexible Server

#### Database (`database`)

-   `database.charset` : Set di caratteri del database PostgreSQL
-   `database.collation` : Metodo di ordinamento dei dati del database PostgreSQL

#### Regole firewall (`firewall_rule`)

-   `firewall_rule.start_ip_address` : Indirizzo IP iniziale associato alla regola firewall
-   `firewall_rule.end_ip_address` : Indirizzo IP finale associato alla regola firewall

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria – massimo 512 caratteri, `key`:`value`
