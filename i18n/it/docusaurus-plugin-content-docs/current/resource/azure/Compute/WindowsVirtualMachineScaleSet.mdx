## Panoramica della risorsa

Azure Windows Virtual Machine Scale Set è una risorsa che consente di creare più istanze di macchine virtuali Windows e di aumentare o ridurre automaticamente il numero di istanze in base alla domanda o a pianificazioni definite.
Configurando la dimensione della VM (SKU), l’immagine del sistema operativo, le informazioni dell’account amministratore, la configurazione del disco del sistema operativo e la configurazione delle interfacce di rete, è possibile gestire in modo scalabile macchine virtuali Windows con configurazione uniforme.

## Valori di configurazione della risorsa

-   `included_vnet_name` : Nome della Virtual Network a cui appartiene il Virtual Machine Scale Set

-   `orchestration_mode` : Modalità di orchestrazione che determina come le VM vengono gestite dallo Scale Set – `Uniform`, `Flexible`

-   `platform_fault_domain_count` : Numero di gruppi di VM che condividono la stessa alimentazione elettrica e gli stessi switch di rete

-   `vmss_sku` : Livello di prezzo del Virtual Machine Scale Set

-   `instances` : Numero di macchine virtuali nello Scale Set – `1` ~ `1000`

-   `computer_name_prefix` : Prefisso da utilizzare per i nomi delle Virtual Machines

-   `admin_username` : Nome utente amministratore per le VM – 1 ~ 64 caratteri

-   `admin_password` : Password amministratore per le VM – 12 ~ 72 caratteri

-   `os_disk_caching` : Tipo di caching per l’utilizzo del disco del sistema operativo interno – `ReadWrite`, `ReadOnly`, `None`

-   `storage_account_type` : Tipo di storage per il backup del disco del sistema operativo interno – `Standard_LRS`, `StandardSSD_LRS`, `Premium_LRS`

-   `disk_size_gb` : Dimensione del disco del sistema operativo interno (GB) – `32` ~ `11400`

-   `tag` : Tag per classificare la risorsa per categoria – massimo 512 caratteri, `key`:`value`

### Impostazioni dell’immagine (`source_image`)

-   `source_image.type` : Utilizzo di un ID immagine personalizzato – `recommended`, `custom_id`, `custom_input`

-   `source_image.image_id` : ID dell’immagine utilizzata per la creazione delle VM

-   `source_image.image` : Immagine utilizzata per la creazione delle VM

-   `source_image.publisher` : Fornitore dell’immagine utilizzata per la creazione delle VM

-   `source_image.offer` : Offer dell’immagine utilizzata per la creazione delle VM

-   `source_image.sku` : SKU dell’immagine utilizzata per la creazione delle VM

### Impostazioni di rete (`network_interface`)

-   `network_interface.is_primary` : Impostazione come configurazione IP primaria – `true`, `false`

-   `network_interface.subnet_name` : Nome della subnet in cui verrà posizionata l’interfaccia di rete

### Configurazione IP (`network_interface.ip_configuration`)

-   `network_interface.ip_configuration.is_primary` : Impostazione come configurazione IP primaria dell’interfaccia di rete – `true`, `false`

-   `network_interface.ip_configuration.enabled_public_ip` : Abilitazione dell’uso di un IP pubblico – `true`, `false`

-   `network_interface.ip_configuration.public_ip_name` : Nome dell’IP pubblico da utilizzare
