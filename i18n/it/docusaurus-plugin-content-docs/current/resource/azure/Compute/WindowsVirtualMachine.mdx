## Panoramica della risorsa

Azure Windows Server Virtual Machine è una macchina virtuale (VM) che esegue il sistema operativo Windows Server sulla piattaforma di cloud computing Microsoft Azure.  
Eseguendo macchine virtuali Windows Server su Azure, gli utenti possono sfruttare la scalabilità, l’affidabilità e la portata globale della piattaforma cloud Microsoft.

## Valori di configurazione della risorsa

-   `included_vnet_name` : Nome della Virtual Network a cui appartiene la Virtual Machine

-   `linked_availability_set_name` : Nome dell’Availability Set applicato alla Virtual Machine

-   `size` : Dimensione della Virtual Machine per l’esecuzione dei carichi di lavoro

-   `computer_name` : Nome host della Virtual Machine

-   `admin_username` : Nome utente amministratore della VM

    -   1 ~ 64 caratteri

-   `admin_password` : Password amministratore della VM

    -   12 ~ 72 caratteri

-   `os_disk_caching` : Tipo di caching del disco OS interno

    -   `ReadWrite`, `ReadOnly`, `None`

-   `storage_account_type` : Tipo di storage del disco OS interno

    -   `Standard_LRS`, `StandardSSD_LRS`, `Premium_LRS`

-   `disk_size_gb` : Dimensione del disco OS interno (GB)

    -   `32` ~ `32767`

-   `linked_network_interface_names` : Elenco dei nomi delle Network Interface

-   `primary_network_interface_name` : Nome della Network Interface primaria

-   `tag` : Tag utilizzati per classificare la risorsa
    -   Massimo 512 caratteri, `key`:`value`

### Impostazioni dell’immagine (`source_image`)

-   `source_image.type` : Indica se utilizzare un ID immagine personalizzato

    -   `recommended`, `custom_id`, `custom_input`

-   `source_image.image_id` : ID dell’immagine utilizzata per creare la VM

-   `source_image.image` : Immagine utilizzata per creare la VM

-   `source_image.publisher` : Editore dell’immagine utilizzata per creare la VM

-   `source_image.offer` : Offer dell’immagine utilizzata per creare la VM

-   `source_image.sku` : SKU dell’immagine utilizzata per creare la VM

### Collegamento di dischi aggiuntivi (`disk_attachment`)

-   `disk_attachment.lun` : Numero di unità logica (LUN) del disco

-   `disk_attachment.host_caching` : Impostazione del caching del disco

    -   `None`, `ReadOnly`, `ReadWrite`
