## Panoramica della risorsa

Azure Linux Virtual Machine è una macchina virtuale (VM) che esegue un sistema operativo Linux sulla piattaforma di cloud computing Microsoft Azure.  
È possibile configurare la dimensione della VM (SKU), l’immagine del sistema operativo, i metodi di autenticazione (password/chiave SSH), la configurazione dei dischi, le connessioni delle interfacce di rete e gli script di inizializzazione Cloud-init per eseguire i carichi di lavoro del server.

## Valori di configurazione della risorsa

-   `included_vnet_name` : Nome della Virtual Network a cui appartiene la Virtual Machine

-   `linked_availability_set_name` : Nome dell’Availability Set applicato alla Virtual Machine

-   `size` : Configurazione della dimensione della Virtual Machine per l’esecuzione dei carichi di lavoro

### Configurazione dell’immagine (`source_image`)

-   `source_image.type` : Utilizzo di un ID immagine personalizzato - `recommended`, `custom_id`, `custom_input`

-   `source_image.image_id` : ID dell’immagine utilizzata per creare la VM

-   `source_image.image` : Immagine utilizzata per creare la VM

-   `source_image.publisher` : Editore dell’immagine utilizzata per creare la VM

-   `source_image.offer` : ID dell’offerta dell’immagine utilizzata per creare la VM

-   `source_image.sku` : Livello di prezzo (SKU) dell’immagine utilizzata per creare la VM

### Impostazioni di autenticazione

-   `enable_ssh_key_authentication` : Indica se utilizzare una chiave SSH per l’autenticazione dell’amministratore - `true`, `false`

-   `admin_username` : Nome utente amministratore della VM - da 1 a 64 caratteri

-   `admin_password` : Password dell’amministratore della VM - da 12 a 72 caratteri

-   `ssh_public_key` : Chiave pubblica SSH per la VM - fino a 600 caratteri

### Impostazioni del disco del sistema operativo

-   `os_disk_caching` : Tipo di caching del disco del sistema operativo - `ReadWrite`, `ReadOnly`, `None`

-   `storage_account_type` : Tipo di archiviazione del disco del sistema operativo - `Standard_LRS`, `StandardSSD_LRS`, `Premium_LRS`

-   `disk_size_gb` : Dimensione del disco del sistema operativo (GB) - `32` ~ `32767`

### Collegamento di dischi aggiuntivi (`disk_attachment`)

-   `disk_attachment.lun` : Numero di unità logica (LUN) del disco

-   `disk_attachment.host_caching` : Impostazione del caching del disco - `None`, `ReadOnly`, `ReadWrite`

### Impostazioni di rete

-   `linked_network_interface_names` : Elenco dei nomi delle Network Interface

-   `primary_network_interface_name` : Nome della Network Interface collegata alla Virtual Machine

### Script di inizializzazione

-   `cloudinit_config` : Contenuto dello script eseguito automaticamente alla creazione del server

### Tag

-   `tag` : Tag per classificare la risorsa - massimo 512 caratteri, `key`:`value`
