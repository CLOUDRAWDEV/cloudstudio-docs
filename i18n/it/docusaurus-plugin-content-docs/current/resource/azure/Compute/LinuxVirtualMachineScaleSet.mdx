## Panoramica della risorsa

Azure Linux Virtual Machine Scale Set è una risorsa di calcolo che consente di creare più istanze di macchine virtuali Linux con configurazione identica e di scalare automaticamente il numero di istanze in base alla domanda o a criteri definiti.
Configurando la connessione alla rete virtuale, lo SKU della VM, il numero di istanze, le impostazioni dell’immagine, i metodi di autenticazione, la configurazione dei dischi e delle interfacce di rete, è possibile gestire in modo efficiente carichi di lavoro su larga scala.

## Valori di configurazione della risorsa

-   `included_vnet_name` : Nome della Virtual Network a cui appartiene il Virtual Machine Scale Set

-   `orchestration_mode` : Modalità di orchestrazione che determina come le VM vengono gestite dallo Scale Set – `Uniform`, `Flexible`

-   `platform_fault_domain_count` : Numero di gruppi di VM che condividono la stessa alimentazione e gli stessi switch di rete

-   `vmss_sku` : Livello di prezzo del Virtual Machine Scale Set

-   `instances` : Numero di macchine virtuali nello Scale Set – `1` ~ `1000`

### Impostazioni dell’immagine (`source_image`)

-   `source_image.type` : Utilizzo di un ID immagine personalizzato – `recommended`, `custom_id`, `custom_input`

-   `source_image.image_id` : ID dell’immagine utilizzata per la creazione della VM

-   `source_image.image` : Immagine utilizzata per la creazione della VM

-   `source_image.publisher` : Editore dell’immagine utilizzata per la creazione della VM

-   `source_image.offer` : Offerta dell’immagine utilizzata per la creazione della VM

-   `source_image.sku` : SKU dell’immagine utilizzata per la creazione della VM

-   `enable_ssh_key_authentication` : Utilizzo di una chiave SSH per l’autenticazione dell’account amministratore – `true`, `false`

-   `ssh_public_key` : Chiave SSH pubblica per la VM – massimo 600 caratteri

-   `admin_username` : Nome utente amministratore della VM – 1 ~ 64 caratteri

-   `admin_password` : Password amministratore della VM – 12 ~ 72 caratteri

-   `os_disk_caching` : Tipo di caching per l’utilizzo del disco del sistema operativo interno – `ReadWrite`, `ReadOnly`, `None`

-   `storage_account_type` : Tipo di archiviazione per il backup del disco del sistema operativo interno – `Standard_LRS`, `StandardSSD_LRS`, `Premium_LRS`

-   `disk_size_gb` : Dimensione del disco del sistema operativo interno (GB) – `32` ~ `11400`

### Impostazioni dell’interfaccia di rete (`network_interface`)

-   `network_interface.is_primary` : Impostazione come interfaccia di rete primaria – `true`, `false`

-   `network_interface.subnet_name` : Nome della subnet in cui verrà posizionata l’interfaccia di rete

### Impostazioni di configurazione IP (`network_interface.ip_configuration`)

-   `network_interface.ip_configuration.is_primary` : Impostazione come configurazione IP primaria dell’interfaccia di rete – `true`, `false`

-   `network_interface.ip_configuration.enabled_public_ip` : Abilitazione dell’uso di un IP pubblico – `true`, `false`

-   `network_interface.ip_configuration.public_ip_name` : Nome dell’IP pubblico da utilizzare

-   `cloudinit_config` : Contenuto dello script eseguito automaticamente alla creazione del server

-   `tag` : Tag per classificare la risorsa per categoria
