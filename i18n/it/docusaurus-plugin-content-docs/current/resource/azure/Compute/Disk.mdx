## Panoramica della risorsa

Azure Disk è una risorsa di archiviazione a blocchi gestita utilizzata dalle macchine virtuali di Azure.  
Può essere utilizzata come disco del sistema operativo (OS Disk) o come disco dati (Data Disk)  
e consente di scegliere diversi tipi di storage in base ai requisiti di prestazioni e di costo.

## Valori di configurazione della risorsa

-   `storage_type` :  
    Tipo di storage utilizzato per il backup del disco

    -   `Standard_LRS`
    -   `StandardSSD_LRS`
    -   `Premium_LRS`

-   `size_gb` :  
    Dimensione del disco (GB) – `1` ~ `32767`

-   `enabled_public_network_access` :  
    Indica se consentire l’accesso alla rete pubblica per il disco – `true`, `false`

-   `tag` :  
    Tag utilizzati per classificare la risorsa per categoria – massimo 512 caratteri, `key`:`value`
