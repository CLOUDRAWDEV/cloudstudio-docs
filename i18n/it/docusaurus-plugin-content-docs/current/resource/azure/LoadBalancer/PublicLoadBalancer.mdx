## Panoramica della risorsa

Un Public Load Balancer è un servizio di bilanciamento del carico che riceve il traffico in ingresso da fonti esterne (Internet) sul frontend e lo distribuisce alle istanze del backend pool per prevenire il sovraccarico del traffico.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `sku` : Livello di prezzo per selezionare la scala e le funzionalità di Azure Load Balancer - `Standard`, `Basic`
-   `virtual_network_name` : Nome della Virtual Network a cui il Load Balancer inoltra il traffico

#### Configurazione IP frontend (`public_lb_frontend_ip_config`)

-   `public_lb_frontend_ip_config.linked_public_ip_name` : Nome dell’indirizzo IP pubblico da utilizzare

#### Backend pool (`backend_pool`)

-   `backend_pool` : Nome del backend pool del Load Balancer
-   `backend_pool.linked_virtual_machine_names` : Nomi delle Virtual Machines a cui il Load Balancer inoltra il traffico (devono appartenere alla Virtual Network selezionata)

#### Sonda di stato (`health_probe`)

-   `health_probe.protocol` : Tipo di protocollo dell’endpoint backend utilizzato dalla sonda di stato - `Http`, `Https`, `Tcp`
-   `health_probe.port` : Porta sulla quale la sonda di stato verifica l’endpoint backend - `0` ~ `65535`
-   `health_probe.request_path` : Percorso utilizzato per le richieste GET quando si utilizzano sonde Http(s)
-   `health_probe.interval_in_seconds` : Intervallo (in secondi) con cui la sonda di stato verifica la risposta delle istanze del backend pool - `5` ~ `2147483646`

#### Regola di bilanciamento del carico (`rule`)

-   `rule.protocol` : Protocollo di trasporto per l’endpoint esterno - `Tcp`, `Udp`, `All`
-   `rule.frontend_port` : Porta dell’endpoint esterno - `0` ~ `65534`
-   `rule.backend_port` : Porta utilizzata per le connessioni interne - `0` ~ `65535`
-   `rule.disable_outbound_snat` : Abilita SNAT per la regola per le connessioni in uscita - `true`, `false`
-   `rule.frontend_ip_config_name` : Nome della configurazione IP frontend del Public Load Balancer
-   `rule.backend_pool_name` : Nome del backend address pool a cui il Load Balancer inoltra il traffico

#### Regola NAT (`nat_rule`)

-   `nat_rule.protocol` : Protocollo di trasporto per l’endpoint esterno - `Tcp`, `Udp`, `All`
-   `nat_rule.frontend_port` : Porta dell’endpoint esterno - `0` ~ `65534`
-   `nat_rule.backend_port` : Porta utilizzata per le connessioni interne - `0` ~ `65535`
-   `nat_rule.frontend_ip_config_name` : Nome della configurazione IP frontend del Public Load Balancer

#### Regola di uscita (`outbound_rule`)

-   `outbound_rule.protocol` : Protocollo di trasporto per l’endpoint esterno - `Tcp`, `Udp`, `All`
-   `outbound_rule.frontend_ip_config_name` : Nome della configurazione IP frontend del Public Load Balancer
-   `outbound_rule.backend_pool_name` : Nome del backend address pool a cui il Load Balancer inoltra il traffico

#### Tag

-   `tag` : Tag per classificare la risorsa - massimo 512 caratteri, `key`:`value`
