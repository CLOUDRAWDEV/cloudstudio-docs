## Modalità di esecuzione

1. Fare clic sulla scheda `Ispezione > Gestione ispezioni > Ispezione remota` per accedere.
2. Selezionare il `gruppo che si desidera ispezionare` dall'elenco dei gruppi.

:::info

Le ispezioni remote vengono condotte in base al gruppo selezionato. Si prega di `creare prima un gruppo` prima di avviare le ispezioni remote.
[Come creare un gruppo](/docs/compliance/group)

:::

3. Fare clic sulla scheda `Ispezione remota`.

<img width="400" src={remoteInspect2} alt="img" />

4. Fare clic sul `Pulsante Ispezione`.

    <img width="200" src={remoteInspect3} alt="img" />

5. Inserire un titolo per l'ispezione (per specificare l'oggetto della stessa) e fare clic sul `Pulsante Avanti`.

    <img width="400" src={remoteInspect5} alt="img" />

    5-1. Se si utilizza un server esistente, inserire le informazioni del server che si desidera utilizzare.

    <img width="400" src={remoteInspect7} alt="Immagine" />

6. Inserire un titolo per l'ispezione (indicando l'oggetto dell'ispezione), quindi fare clic sul `Pulsante Avvia ispezione`.

    <img width="400" src={remoteInspect4} alt="Immagine" />

<p>&nbsp;</p>

## Generazione report

Una volta completata l'ispezione, è possibile visualizzare i risultati in una tabella. La tabella include sei colonne: `Ambito, Nome voce, Criteri di ispezione, Priorità, Risultato ispezione e Dettagli risultato`.
Per informazioni più dettagliate sui `Criteri di ispezione`, fare riferimento a [qui](/docs/compliance/result).
CS Checker fornisce due tipi di report: Excel e Word.
