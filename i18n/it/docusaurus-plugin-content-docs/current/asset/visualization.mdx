# Visualizzazione Asset

La visualizzazione degli asset `mostra gli asset interrogati in un diagramma`.
È possibile selezionare ogni asset per visualizzarne i dettagli.

1. La visualizzazione degli asset viene generata in base al `Registro asset`.

    <img width="800" src={assetview} alt="img" />

2. Gli asset possono essere visualizzati per `Gruppo`.

    <img width="400" src={assetcategory} alt="img" />

3. Selezionare un asset per visualizzarne i dettagli.

    <img width="400" src={assetdetail} alt="img" />
