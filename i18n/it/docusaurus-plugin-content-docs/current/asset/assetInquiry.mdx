# Consultazione e Modifica Asset

Per consultare o modificare gli asset, fare clic su `Asset > Registro asset`.

## Ispezione permessi registro asset

Per consultare i permessi del registro asset, fare clic sul `Pulsante ⓘ`.

## Consultazione Asset

1. Fare clic sul `Pulsante Consultazione asset` in alto a destra.

    <img width="400" src={inquiry11} alt="Asset Inquire button image" />

2. Gli asset vengono recuperati in base alle `credenziali possedute`. Dopo aver controllato l'elenco delle credenziali, fare clic sul `Pulsante Visualizza` per caricare gli asset. (`Autorizzato` indica il permesso di recuperare le credenziali).

    <img width="400" src={inquiry2} alt="Query img" />

<p>&nbsp;</p>

## Modifica Asset

Gli asset sono divisi in sei categorie: `Server, Storage, Sistema di sicurezza delle informazioni, Rete, DBMS, Non categorizzato`.
"Non categorizzato" è una categoria che raggruppa gli asset che non rientrano nelle altre categorie.
Gli asset possono essere modificati all'interno di ogni categoria.

1. Fare clic sulla scheda per navigare alla categoria di asset desiderata.
2. Dopo aver interrogato gli asset, `fare clic sulle celle vuote nella tabella` per inserire le informazioni.

    <img width="400" src={inquiry4} alt="Query img" />

3. Dopo aver inserito tutti i valori, fare clic sul `Pulsante icona Salva`. Se si desidera tornare ai valori precedenti, fare clic sul `Pulsante icona Indietro`.

    <img width="200" src={inquiry5} alt="Query img" />

<p>&nbsp;</p>

### Input batch

1. Selezionare gli asset per l'inserimento batch e fare clic sul `Pulsante Input batch`.

    <img width="300" src={inquiry3} alt="Query img" />

2. Selezionare il nome della colonna da modificare in batch (es. Numero di gestione, Descrizione asset, Dominio, Dipartimento proprietario, Amministratore, Responsabile). <br /> Dopo aver inserito il valore, fare clic sul pulsante Input batch per completare.

    <img width="400" src={inquiry6} alt="Query img" />

<p>&nbsp;</p>

### Movimento Asset

1. Selezionare gli asset da spostare e fare clic sul `Pulsante Movimento asset`.

    <img width="300" src={inquiry3} alt="Query img" />

2. Nella scheda corrente, selezionare la scheda in cui si desidera spostare gli asset e controllare l'elenco.

    <img width="400" src={inquiry7} alt="Query img" />

3. Fare clic sul `Pulsante Sposta` per completare il movimento degli asset.

<p>&nbsp;</p>

### Esportazione Excel

CS Checker fornisce un registro asset. È possibile esportare le stesse informazioni visualizzate sul web in un file Excel.

1. Fare clic sul `Pulsante Download` per scaricare il file Excel.

    <img width="200" src={inquiry8} alt="Query img" />

2. In Excel, è possibile visualizzare gli asset di tutte le categorie: `Server, Storage, Sistema di sicurezza delle informazioni, Rete, DBMS, Non categorizzato`.
    <img width="700" src={inquiry10} alt="Query img" />
