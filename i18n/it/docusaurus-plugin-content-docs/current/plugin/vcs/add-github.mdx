## Registrare GitHub

Per gestire le versioni del canvas in Cloud Studio, è necessaria l'integrazione con un VCS (Version Control System).<br/> 
Inoltre, per l'integrazione con il conto Terraform Cloud per la convalida del progetto e la distribuzione, 
è necessario prima collegare l'account VCS.<br/> 
In questa pagina verrà spiegato come collegare un account GitHub tra i VCS.

<br />

<details>
    <summary>Github ?</summary>
    <h5>
        GitHub è una piattaforma che consente di ospitare e gestire progetti di sviluppo software.
    </h5>
</details>

<p>&nbsp;</p>

1. [Github](https://github.com/) Dopo esserti registrato e aver effettuato il login su Github, clicca sull'`icona del profilo in alto a destra - Impostazioni`.

<img width="100%" src={github01} alt="otp img" />

<p>&nbsp;</p>

2. Clicca su `Developer settings` nella parte inferiore della barra laterale sinistra.

<img width="100%" src={github02} alt="otp img" />

<p>&nbsp;</p>

3. Nella barra laterale sinistra, clicca su `Personal access tokens - Tokens (classic)`, 
quindi seleziona `Generate new token - Generate new token (classic)` sulla destra.

<img width="100%" src={github03} alt="otp img" />

<p>&nbsp;</p>

4. Nella sezione in basso, sotto l'opzione Select scopes, seleziona i permessi a cui il token di GitHub dovrà avere accesso, tra cui `repo`. Dopo aver selezionato le opzioni desiderate, clicca sul pulsante `Generate token` per generare il token.

<img width="100%" src={github04} alt="otp img" />

<p>&nbsp;</p>

:::caution

Il token emesso non può essere visualizzato di nuovo, quindi assicurati di salvarlo separatamente.

:::

<p>&nbsp;</p>

5. In Cloud Studio, clicca su `Le mie informazioni - Gestione plugin`, quindi clicca sul pulsante `+` per l'integrazione dell'account VCS.

<img width="100%" src={github05} alt="otp img" />

<p>&nbsp;</p>

6. Seleziona `Github` come VCS, quindi inserisci il `UserName` del tuo account Github e il `Token` che hai generato. Infine, clicca sul pulsante `Registrati`.

<img width="100%" src={github06} alt="otp img" />

<p>&nbsp;</p>

7. Una volta che l'inserimento del `UserName` di un account Github valido e del `Token` generato è completato, l'integrazione con Github sarà correttamente completata.

<img width="100%" src={github07} alt="otp img" />

<p>&nbsp;</p>

:::caution

Per integrare la versione Github Enterprise, è necessario inserire anche l'`Http Url` e l'`API Url` del server ospitato.

:::
