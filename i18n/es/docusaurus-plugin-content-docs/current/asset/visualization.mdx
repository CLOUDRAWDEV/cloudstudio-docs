# Visualización de Activos

La visualización de activos `muestra los activos consultados en un diagrama`.
Puede seleccionar cada activo para ver sus detalles.

1. La visualización de activos se genera en función del `Registro de activos`.

    <img width="800" src={assetview} alt="img" />

2. Los activos se pueden visualizar por `Grupo`.

    <img width="400" src={assetcategory} alt="img" />

3. Seleccione un activo para ver sus detalles.
