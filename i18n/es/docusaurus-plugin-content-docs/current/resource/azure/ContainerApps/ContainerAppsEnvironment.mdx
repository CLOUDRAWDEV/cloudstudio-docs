## Descripción general del recurso

Azure Container Apps Environment es un recurso que define el entorno de redes y monitoreo donde se ejecutan las Azure Container Apps.
Al conectar entornos operativos como los espacios de trabajo de Log Analytics utilizados cuando se crean y ejecutan las Container Apps, se pueden aplicar configuraciones de recopilación de registros y monitoreo de manera consistente.
