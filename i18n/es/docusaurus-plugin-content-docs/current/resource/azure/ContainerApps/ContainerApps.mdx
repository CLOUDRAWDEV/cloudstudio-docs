## Descripción general del recurso

Azure Container Apps Environment es un recurso que define el entorno de red y supervisión en el que se ejecutan Azure Container Apps.  
Al vincular entornos operativos como un espacio de trabajo de Log Analytics que se utiliza cuando se crean y ejecutan las Container Apps, es posible aplicar de forma coherente configuraciones de recopilación de registros y monitoreo.
