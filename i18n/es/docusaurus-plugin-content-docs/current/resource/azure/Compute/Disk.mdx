## Descripción general del recurso

Azure Disk es un recurso de almacenamiento en bloques administrado que se utiliza en Azure Virtual Machines.  
Puede utilizarse como disco del sistema operativo (OS Disk) o como disco de datos (Data Disk),  
y permite seleccionar distintos tipos de almacenamiento según los requisitos de rendimiento y costo.

## Valores de configuración del recurso

-   `storage_type` :  
    Tipo de almacenamiento utilizado para el disco

    -   `Standard_LRS`
    -   `StandardSSD_LRS`
    -   `Premium_LRS`

-   `size_gb` :  
    Tamaño del disco (GB) – `1` ~ `32767`

-   `enabled_public_network_access` :  
    Indica si se permite el acceso a la red pública para el disco – `true`, `false`

-   `tag` :  
    Etiquetas para clasificar el recurso por categorías – máximo 512 caracteres, `key`:`value`
