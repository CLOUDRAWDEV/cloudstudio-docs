## Descripción general del recurso

Azure Availability Set es un grupo lógico de máquinas virtuales diseñado para mejorar la disponibilidad de las aplicaciones,  
distribuyendo las máquinas virtuales entre múltiples dominios de error (Fault Domains) y dominios de actualización (Update Domains).  
Las máquinas virtuales incluidas en el mismo Availability Set se implementan en infraestructuras físicamente separadas,  
lo que evita puntos únicos de fallo (SPOF).

## Valores de configuración del recurso

-   `update_domain_count` :  
    Número de dominios de actualización utilizados para reiniciar simultáneamente grupos de máquinas virtuales – `1` ~ `20`

-   `enabled_managed_disks` :  
    Indica si se permite la creación de máquinas virtuales en el Availability Set utilizando discos administrados (Managed Disks) – `true`, `false`

-   `fault_domain_count` :  
    Número de dominios de error configurados para compartir la misma alimentación eléctrica y los mismos switches de red físicos – `1` ~ `3`

-   `tag` :  
    Etiquetas para clasificar el recurso por categorías – máximo 512 caracteres, `key`:`value`
