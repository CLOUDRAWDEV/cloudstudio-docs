## Descripción general del recurso

Azure Windows Server Virtual Machine es una máquina virtual (VM) que ejecuta el sistema operativo Windows Server en la plataforma de computación en la nube Microsoft Azure.  
Al ejecutar máquinas virtuales de Windows Server en Azure, los usuarios pueden aprovechar la escalabilidad, la fiabilidad y el alcance global de la plataforma en la nube de Microsoft.

## Valores de configuración del recurso

-   `included_vnet_name` : Nombre de la Virtual Network a la que pertenece la Virtual Machine

-   `linked_availability_set_name` : Nombre del Availability Set aplicado a la Virtual Machine

-   `size` : Tamaño de la Virtual Machine para la ejecución de cargas de trabajo

-   `computer_name` : Nombre de host de la Virtual Machine

-   `admin_username` : Nombre de usuario administrador de la VM

    -   1 ~ 64 caracteres

-   `admin_password` : Contraseña de administrador de la VM

    -   12 ~ 72 caracteres

-   `os_disk_caching` : Tipo de caché para el disco del sistema operativo interno

    -   `ReadWrite`, `ReadOnly`, `None`

-   `storage_account_type` : Tipo de almacenamiento del disco del sistema operativo interno

    -   `Standard_LRS`, `StandardSSD_LRS`, `Premium_LRS`

-   `disk_size_gb` : Tamaño del disco del sistema operativo interno (GB)

    -   `32` ~ `32767`

-   `linked_network_interface_names` : Lista de nombres de Network Interface

-   `primary_network_interface_name` : Nombre de la Network Interface principal

-   `tag` : Etiquetas para clasificar el recurso por categoría
    -   Máximo 512 caracteres, `key`:`value`

### Configuración de imagen (`source_image`)

-   `source_image.type` : Indica si se utiliza un ID de imagen personalizado

    -   `recommended`, `custom_id`, `custom_input`

-   `source_image.image_id` : ID de la imagen utilizada para crear la VM

-   `source_image.image` : Imagen utilizada para crear la VM

-   `source_image.publisher` : Proveedor de la imagen utilizada para crear la VM

-   `source_image.offer` : Offer de la imagen utilizada para crear la VM

-   `source_image.sku` : SKU de la imagen utilizada para crear la VM

### Conexión de disco adicional (`disk_attachment`)

-   `disk_attachment.lun` : Número de unidad lógica (LUN) del disco

-   `disk_attachment.host_caching` : Configuración de caché del disco

    -   `None`, `ReadOnly`, `ReadWrite`
