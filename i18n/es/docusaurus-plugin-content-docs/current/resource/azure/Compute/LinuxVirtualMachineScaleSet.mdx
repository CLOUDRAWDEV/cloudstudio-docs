## Descripción general del recurso

Azure Linux Virtual Machine Scale Set es un recurso de computación que permite crear múltiples instancias de máquinas virtuales Linux con una configuración idéntica y escalar automáticamente el número de instancias según la demanda o las políticas definidas.
Mediante la configuración de la conexión a redes virtuales, SKU de la VM, número de instancias, ajustes de imagen, métodos de autenticación, configuración de discos y de interfaces de red, es posible operar cargas de trabajo a gran escala de forma eficiente.

## Valores de configuración del recurso

-   `included_vnet_name` : Nombre de la Virtual Network a la que pertenece el Virtual Machine Scale Set

-   `orchestration_mode` : Modo de orquestación que determina cómo el Scale Set administra las máquinas virtuales – `Uniform`, `Flexible`

-   `platform_fault_domain_count` : Número de grupos de máquinas virtuales que comparten la misma alimentación eléctrica y los mismos switches de red

-   `vmss_sku` : Nivel de precios del Virtual Machine Scale Set

-   `instances` : Número de máquinas virtuales del Scale Set – `1` ~ `1000`

### Configuración de imagen (`source_image`)

-   `source_image.type` : Uso de un ID de imagen personalizado – `recommended`, `custom_id`, `custom_input`

-   `source_image.image_id` : ID de la imagen utilizada para crear la máquina virtual

-   `source_image.image` : Imagen utilizada para crear la máquina virtual

-   `source_image.publisher` : Proveedor de la imagen utilizada para crear la máquina virtual

-   `source_image.offer` : Oferta de la imagen utilizada para crear la máquina virtual

-   `source_image.sku` : SKU de la imagen utilizada para crear la máquina virtual

-   `enable_ssh_key_authentication` : Uso de una clave SSH para autenticar la cuenta de administrador – `true`, `false`

-   `ssh_public_key` : Clave SSH pública para la máquina virtual – máximo 600 caracteres

-   `admin_username` : Nombre de usuario administrador de la máquina virtual – 1 ~ 64 caracteres

-   `admin_password` : Contraseña de administrador de la máquina virtual – 12 ~ 72 caracteres

-   `os_disk_caching` : Tipo de caché para el uso del disco del sistema operativo interno – `ReadWrite`, `ReadOnly`, `None`

-   `storage_account_type` : Tipo de almacenamiento para el respaldo del disco del sistema operativo interno – `Standard_LRS`, `StandardSSD_LRS`, `Premium_LRS`

-   `disk_size_gb` : Tamaño del disco del sistema operativo interno (GB) – `32` ~ `11400`

### Configuración de la interfaz de red (`network_interface`)

-   `network_interface.is_primary` : Establecer como interfaz de red principal – `true`, `false`

-   `network_interface.subnet_name` : Nombre de la subred donde se ubicará la interfaz de red

### Configuración de IP (`network_interface.ip_configuration`)

-   `network_interface.ip_configuration.is_primary` : Establecer como configuración IP principal de la interfaz de red – `true`, `false`

-   `network_interface.ip_configuration.enabled_public_ip` : Habilitar el uso de una IP pública – `true`, `false`

-   `network_interface.ip_configuration.public_ip_name` : Nombre de la IP pública a utilizar

-   `cloudinit_config` : Contenido del script que se ejecuta automáticamente al crear el servidor

-   `tag` : Etiquetas para clasificar el recurso por categorías
