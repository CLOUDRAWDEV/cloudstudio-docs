## Descripción general del recurso

Una Private DNS Zone es un área destinada a administrar registros DNS para nombres de dominio privados que se utilizan únicamente dentro de una red virtual de Azure.  
Al vincularla con una red virtual (VNet Link), se puede realizar de forma segura la resolución de nombres entre recursos internos.

## Valores de configuración del recurso

#### Registro A (`private_dns_a_record`)

-   `private_dns_a_record.ttl` : Time To Live del registro DNS (segundos) - `0` ~ `2147483647`
-   `private_dns_a_record.records` : Lista de direcciones IPv4

#### Registro AAAA (`private_dns_aaaa_record`)

-   `private_dns_aaaa_record.ttl` : Time To Live del registro DNS (segundos) - `0` ~ `2147483647`
-   `private_dns_aaaa_record.records` : Lista de direcciones IPv6

#### Registro CNAME (`private_dns_cname_record`)

-   `private_dns_cname_record.ttl` : Time To Live del registro DNS (segundos) - `0` ~ `2147483647`
-   `private_dns_cname_record.record` : Alias para conectar un subdominio a otro registro

#### Registro PTR (`private_dns_ptr_record`)

-   `private_dns_ptr_record.ttl` : Time To Live del registro DNS (segundos) - `0` ~ `2147483647`
-   `private_dns_ptr_record.records` : Lista de nombres de dominio para tipos de registros de puntero

#### Registro TXT (`private_dns_txt_record`)

-   `private_dns_txt_record.ttl` : Time To Live del registro DNS (segundos) - `0` ~ `2147483647`
-   `private_dns_txt_record.records` : Lista de registros de tipo texto

#### Enlace de red virtual (`vnet_link`)

-   `vnet_link.linked_vnet_name` : Nombre de la red virtual vinculada a la Private DNS Zone

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso - hasta 512 caracteres, `key`:`value`
