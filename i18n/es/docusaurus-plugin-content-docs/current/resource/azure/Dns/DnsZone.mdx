## Descripción general del recurso

Una DNS Zone es un área que aloja registros DNS para un dominio específico, lo que permite crear y administrar cada registro DNS.

## Valores de configuración del recurso

#### Registro A (`dns_a_record`)

-   `dns_a_record.ttl` : Time To Live del registro DNS (segundos) - `0` ~ `2147483647`
-   `dns_a_record.records` : Lista de direcciones IPv4

#### Registro AAAA (`dns_aaaa_record`)

-   `dns_aaaa_record.ttl` : Time To Live del registro DNS (segundos) - `0` ~ `2147483647`
-   `dns_aaaa_record.records` : Lista de direcciones IPv6

#### Registro CNAME (`dns_cname_record`)

-   `dns_cname_record.ttl` : Time To Live del registro DNS (segundos) - `0` ~ `2147483647`
-   `dns_cname_record.record` : Alias para conectar un subdominio a otro registro

#### Registro NS (`dns_ns_record`)

-   `dns_ns_record.ttl` : Time To Live del registro DNS (segundos) - `0` ~ `2147483647`
-   `dns_ns_record.records` : Lista de registros de servidores de nombres

#### Registro PTR (`dns_ptr_record`)

-   `dns_ptr_record.ttl` : Time To Live del registro DNS (segundos) - `0` ~ `2147483647`
-   `dns_ptr_record.records` : Lista de nombres de dominio para tipos de registros de puntero

#### Registro TXT (`dns_txt_record`)

-   `dns_txt_record.ttl` : Time To Live del registro DNS (segundos) - `0` ~ `2147483647`
-   `dns_txt_record.records` : Lista de registros de tipo texto

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso - hasta 512 caracteres, `key`:`value`
