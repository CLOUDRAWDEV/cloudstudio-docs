## Panoramica della risorsa

Azure MySQL Flexible Server è un servizio di database relazionale basato su MySQL Community Edition.

## Valori di configurazione della risorsa

#### Impostazioni di base

-   `version` : Versione di MySQL da utilizzare – `5.7`, `8.0.21`
-   `sku_name` : Nome del livello di prezzo MySQL, combinazione di Tier + generazione di calcolo + numero di core
-   `storage_gb` : Capacità del server MySQL (GB)
-   `iops` : IOPS di archiviazione del MySQL Flexible Server – `360` ~ `20000`
-   `admin_username` : Nome utente amministratore del server quando la modalità di creazione è `default`, solo alfanumerico, senza parole riservate, `1` ~ `16` caratteri
-   `admin_password` : Password di accesso dell’amministratore del server quando la modalità di creazione è `default`, deve includere almeno 3 tra lettere minuscole, maiuscole, numeri e caratteri speciali, non può contenere 3 o più caratteri alfanumerici consecutivi del nome di accesso, `8` ~ `128` caratteri
-   `auto_grow_enabled` : Abilitazione della crescita automatica dello storage – `true`, `false`
-   `availability_zone` : Specifica la zona di disponibilità. Valori possibili: `1`, `2`, `3` – `1` ~ `3`
-   `enable_high_availability` : Abilitazione dell’alta disponibilità per MySQL Flexible Server – `true`, `false`
-   `high_availability_mode` : Modalità di alta disponibilità del MySQL Flexible Server – `SameZone`, `ZoneRedundant`
-   `standby_availability_zone` : Specifica la zona di disponibilità del server di standby. Valori possibili: `1`, `2`, `3`. Non può coincidere con la zona primaria – `1` ~ `3`
-   `backup_retention_days` : Numero di giorni di conservazione dei backup del MySQL Flexible Server. Valori possibili: `1` ~ `35` giorni
-   `public_network_access_enabled` : Consente l’accesso alla rete pubblica al server – `true`, `false`
-   `delegated_subnet_name` : Nome della subnet per la delega della rete virtuale
-   `private_dns_zone_name` : Zona DNS privata per la creazione del MySQL Flexible Server

#### Configurazione del server (`configuration`)

-   `configuration.param_value` : Valore della configurazione del MySQL Flexible Server

#### Database (`database`)

-   `database.charset` : Set di caratteri del database MySQL
-   `database.collation` : Metodo di confronto (collation) del database MySQL

#### Regole firewall (`firewall_rule`)

-   `firewall_rule.start_ip_address` : Indirizzo IP iniziale associato alla regola del firewall
-   `firewall_rule.end_ip_address` : Indirizzo IP finale associato alla regola del firewall

#### Tag

-   `tag` : Tag per classificare la risorsa per categoria – massimo 512 caratteri, `key`:`value`
