## Descripción del recurso

Azure Search Service es un servicio de búsqueda totalmente administrado que proporciona funciones como búsqueda, filtrado y clasificación sobre grandes volúmenes de texto, documentos y datos.  
Basado en índices de búsqueda, ofrece un procesamiento de consultas rápido y un rendimiento escalable, y permite controlar el alcance de acceso al servicio mediante políticas de seguridad y de acceso a la red.

## Valores de configuración del recurso

-   `sku_name` : Nivel de precios para usar Search Service - `basic`, `free`, `standard`, `standard2`, `standard3`, `storage_optimized_l1`, `storage_optimized_l2`
-   `public_network_access_enabled` : Si se permite el acceso al recurso a través de Internet público - `true`, `false`
-   `allowed_ips` : Lista de IP permitidas que autoriza el acceso a Search Service desde IPs específicas o rangos CIDR
-   `local_authentication_enabled` : Si se utiliza autenticación local mediante claves de API - `true`, `false`
-   `authentication_failure_mode` : Modo de comportamiento que determina si se bloquean las solicitudes o se permiten de forma limitada cuando falla la autenticación del cliente - `http401WithBearerChallenge`, `http403`
-   `partition_count` : Número de particiones para distribuir y almacenar los datos del índice - `1`, `2`, `3`, `4`, `6`, `12`
-   `replica_count` : Número de réplicas para procesar consultas de búsqueda

#### Enlace privado (`private_link`)

-   `private_link.target_ai_service_name` : Nombre del recurso de AI Service de destino para el que se crea una conexión de Private Link
-   `private_link.request_message` : Descripción o mensaje que se envía al aprobador al solicitar una conexión de Private Link
