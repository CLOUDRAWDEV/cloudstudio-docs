## Descripción general del recurso

Firewall Policy es un **recurso centralizado de administración de políticas de firewall** utilizado por Azure Firewall.  
Al definir reglas de red, reglas de aplicación y reglas NAT en una única política, puede aplicarse de manera coherente a múltiples instancias de Firewall, mejorando la reutilización de las políticas de seguridad y la eficiencia operativa.
