## Descripción general del recurso

Public IP Prefix es un recurso de red en Azure que permite reservar y administrar previamente un **rango continuo de direcciones IP públicas**.  
Al asignar múltiples Public IP desde un bloque de direcciones coherente, proporciona previsibilidad y facilidad operativa al gestionar reglas de firewall o al integrar sistemas externos.

## Valores de configuración del recurso

-   `prefix_length` : Longitud en bits del Public IP Prefix - `28` ~ `31`
-   `tag` : Etiquetas para clasificar el recurso - hasta 512 caracteres, `key`:`value`
