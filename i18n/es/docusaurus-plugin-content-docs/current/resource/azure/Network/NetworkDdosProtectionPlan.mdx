## Descripción general del recurso

Network DDoS Protection Plan es un servicio de seguridad diseñado para proteger los recursos de Azure Virtual Network frente a ataques de denegación de servicio distribuido (DDoS) a gran escala.  
Mediante el análisis del tráfico y capacidades de mitigación automática, ayuda a mantener la disponibilidad de las aplicaciones y proporciona funciones de protección adicionales cuando se producen ataques.
