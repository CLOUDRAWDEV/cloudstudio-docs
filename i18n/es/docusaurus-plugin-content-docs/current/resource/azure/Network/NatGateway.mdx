## Descripción general del recurso

NAT Gateway es un recurso que proporciona **conectividad a Internet saliente (Outbound)** para uno o más Subnets dentro de una Virtual Network.  
Cuando se asocia a un Subnet, los recursos de ese Subnet se comunican hacia el exterior a través de la Public IP especificada y no exponen endpoints públicos de entrada (Inbound).  
Al configurar el tiempo de espera de las conexiones inactivas (Idle), es posible mantener conexiones de larga duración o eliminar rápidamente conexiones innecesarias.

## Valores de configuración del recurso

-   `linked_subnet_names` : Nombres de los Subnets que se asociarán al NAT Gateway
-   `linked_public_ip_name` : Nombre de la Public IP que se asociará al NAT Gateway
-   `idle_timeout_in_minutes` : Tiempo de espera (en minutos) para eliminar flujos inactivos en el NAT Gateway - `4` ~ `120`
-   `tag` : Etiquetas para clasificar el recurso - hasta 512 caracteres, `key`:`value`
