## Descripción general del recurso

Route Table es un recurso de red de Azure que se aplica a Subnets dentro de una Virtual Network para **controlar de forma personalizada las rutas del tráfico de red**.  
Además de las rutas predeterminadas del sistema, es posible definir explícitamente los flujos de tráfico hacia destinos como dispositivos virtuales, Internet o gateways.

## Valores de configuración del recurso

-   `enable_bgp_route_propagation` : Indica si se habilita la propagación de rutas del gateway - `true`, `false`
-   `linked_subnet_names` : Lista de nombres de Subnets que se asociarán a la Route Table
-   `tag` : Etiquetas para clasificar el recurso - hasta 512 caracteres, `key`:`value`

#### Configuración de rutas (`route`)

-   `route.route_address_prefix` : Prefijo de dirección IP (CIDR) que representa la ruta
-   `route.next_hop_type` : Tipo del siguiente salto
    -   `VirtualNetworkGateway`
    -   `VnetLocal`
    -   `Internet`
    -   `VirtualAppliance`
    -   `None`
