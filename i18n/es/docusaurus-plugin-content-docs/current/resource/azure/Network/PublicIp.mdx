## Descripción general del recurso

Public IP es un recurso de red que proporciona una dirección IP pública, lo que permite a los recursos de Azure realizar **comunicación directa de entrada y salida** con Internet.  
Se integra con servicios como Load Balancer, Virtual Machine y NAT Gateway para actuar como punto de entrada del tráfico externo o como salida para el tráfico saliente, y su disponibilidad y comportamiento varían según el SKU y el método de asignación.

## Valores de configuración del recurso

-   `sku` : Nivel de precios de la Public IP - `Standard`, `Basic`
-   `allocation_method` : Método de asignación de la dirección Public IP - `Static`, `Dynamic`
-   `tag` : Etiquetas para clasificar el recurso - hasta 512 caracteres, `key`:`value`
