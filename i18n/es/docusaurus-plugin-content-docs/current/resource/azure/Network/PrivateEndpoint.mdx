## Descripción general del recurso

Private Endpoint es un recurso de red que proporciona **conectividad privada (Private Link)** a los servicios de Azure dentro de una Virtual Network sin utilizar una dirección IP pública.  
El endpoint del servicio se expone a través de una Private IP asignada a un Subnet, lo que permite establecer una ruta de comunicación segura sin pasar por Internet.  
Al integrarse con una Private DNS Zone, el FQDN del servicio puede resolverse de forma natural dentro de la red interna.

## Valores de configuración del recurso

-   `included_subnet_name` : Nombre del Subnet que contiene la Private IP asignada al Private Endpoint
-   `connection_name` : Nombre de la conexión entre el Private Endpoint y el recurso
-   `linked_connection_resource_name` : Nombre del recurso al que se conectará el Private Endpoint
-   `subresource_name` : Nombre del subrecurso al que se conectará el Private Endpoint
-   `dns_zone_group_name` : Nombre del grupo de Private DNS Zone que se asociará al Private Endpoint
-   `private_dns_zone_names` : Lista de nombres de Private DNS Zone que se asociarán al Private Endpoint
-   `manual_connection` : Indica si se requiere aprobación manual por parte del propietario del recurso externo - `true`, `false`
-   `tag` : Etiquetas para clasificar el recurso - hasta 512 caracteres, `key`:`value`
