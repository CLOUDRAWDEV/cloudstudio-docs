## Descripción general del recurso

Bastion Host es un servicio de red PaaS de Azure que proporciona **acceso seguro mediante RDP y SSH** a máquinas virtuales dentro de una Virtual Network sin exponer directamente direcciones IP públicas en las VM.  
Admite acceso basado en navegador y permite configurar un punto de acceso centralizado sin abrir puertos de administración, lo que garantiza tanto una mayor seguridad como comodidad operativa.

## Valores de configuración del recurso

-   `included_subnet_name` : Nombre del Subnet donde se ubicará el Bastion Host
-   `sku` : SKU del Bastion Host - `Basic`, `Standard`
-   `linked_public_ip_name` : Nombre de la Public IP que se asociará al Bastion Host
-   `ip_config_name` : Nombre de la configuración de IP utilizada por el Bastion Host
-   `tag` : Etiquetas para clasificar el recurso - hasta 512 caracteres, `key`:`value`
