## Descripción general del recurso

Azure Virtual WAN es un **servicio de concentrador de red global** diseñado para conectar y administrar de forma centralizada recursos de red distribuidos en múltiples regiones.  
Permite la administración unificada de conexiones Site-to-Site VPN, Point-to-Site VPN y ExpressRoute desde un único punto de control, lo que lo hace adecuado para arquitecturas de red de gran escala y múltiples regiones.
