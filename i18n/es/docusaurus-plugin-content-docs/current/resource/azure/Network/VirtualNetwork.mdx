## Descripción general del recurso

Virtual Network es un **recurso de red virtual** que permite la comunicación entre recursos de Azure y configura la conectividad con Internet o con redes locales (on-premises).  
A partir del espacio de direcciones IP (Address Space), es posible definir subredes, políticas de seguridad y emparejamientos para establecer la arquitectura de red del entorno de Azure.

## Valores de configuración del recurso

-   `vnet_address_space` : Espacio de direcciones IP que utilizará la Virtual Network

    -   Se puede especificar una o más direcciones en formato CIDR

-   `enable_ddos_protection` : Indica si se aplica un DDoS Protection Plan a la Virtual Network
    -   `true`, `false`
-   `ddos_protection_plan_name` : Nombre del DDoS Protection Plan que se asociará a la Virtual Network

#### Emparejamiento de VNet (`peering`)

Define la configuración de conexión con otras Virtual Networks.

-   `peering.linked_vnet_name` : Nombre de la Virtual Network de destino para la conexión (solo lectura)
-   `peering.allow_access_to_remote_vnet` : Indica si se permite el acceso a la Virtual Network remota
-   `peering.allow_receive_forwarded_traffic` : Indica si se permite recibir tráfico reenviado
-   `peering.allow_forward_traffic_to_remote_vnet` : Indica si se permite reenviar tráfico a la Virtual Network remota
-   `peering.allow_use_remote_gateway` : Indica si se permite usar la puerta de enlace de la Virtual Network remota
    -   Valores para cada opción: `true`, `false`

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso
    -   Hasta 512 caracteres, en formato `key`:`value`
