## Descripción general del recurso

Subnet es una red que se crea dentro de una Virtual Network para implementar recursos de Azure en la Virtual Network.

## Valores de configuración del recurso

-   `included_vnet_name` : Nombre de la Virtual Network que contiene el Subnet
-   `address_prefixes` : Rango de direcciones IP utilizado por el Subnet, un rango de direcciones único especificado en formato CIDR dentro del espacio de direcciones de la Virtual Network
-   `private_link_endpoint_enabled` : Indica si se conectará un Private Endpoint al Subnet - `true`, `false`

#### Configuración de delegación (`delegation`)

-   `delegation.service_name` : Nombre del servicio que se va a delegar
-   `delegation.actions` : Lista de acciones que se van a delegar
