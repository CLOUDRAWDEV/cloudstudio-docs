## Descripción general del recurso

Azure Virtual Hub es un **recurso de concentrador regional responsable del enrutamiento centralizado y la conectividad de red dentro de un entorno de Virtual WAN**.  
Agrupa conexiones VPN, ExpressRoute y VNet para controlar el flujo de tráfico y se utiliza como un componente central de una topología de red global.

## Valores de configuración del recurso

-   `included_virtual_wan_name` : Nombre del Virtual WAN principal al que se conecta el Virtual Hub
-   `address_prefix` : Espacio de direcciones (bloque CIDR) utilizado dentro del Virtual Hub
-   `hub_routing_preference` : Prioridad para seleccionar la ruta de Internet al enrutar el tráfico
    -   `ExpressRoute`
    -   `ASPath`
    -   `VpnGateway`

#### Connection (`connection`)

-   `connection.target_virtual_network_name` : Nombre de la Virtual Network (VNet) de destino que se conectará al Virtual Hub
