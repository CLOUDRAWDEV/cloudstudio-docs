## Descripción general del recurso

Network Interface es un recurso de conectividad de red que permite que una Virtual Machine se comunique con recursos dentro de una Virtual Network, con Internet y con redes locales (on-premises).  
Pertenece a un Subnet y se le asigna una dirección IP; según sea necesario, se puede asociar una Public IP para habilitar la comunicación externa.  
Una única Network Interface puede definir múltiples configuraciones de IP, lo que permite admitir diversos escenarios de red.

## Valores de configuración del recurso

-   `included_subnet_name` : Nombre del Subnet que incluye la Network Interface

#### Configuración de IP (`ip_configuration`)

-   `ip_configuration.is_primary` : Indica si la configuración de IP principal está habilitada - `true`, `false`
-   `ip_configuration.private_ip_address_allocation` : Método de asignación de la dirección IP privada - `Dynamic`, `Static`
-   `ip_configuration.private_ip_address` : Dirección IP privada
-   `ip_configuration.enabled_public_ip` : Indica si se utiliza una Public IP - `true`, `false`
-   `ip_configuration.linked_public_ip_name` : Nombre de la Public IP que se utilizará

-   `tag` : Etiquetas para clasificar el recurso - hasta 512 caracteres, `key`:`value`
