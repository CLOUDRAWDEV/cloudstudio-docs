## Descripción del Recurso

Azure Application Insights es un servicio basado en la nube proporcionado por Microsoft que ayuda a los desarrolladores a monitorear y analizar aplicaciones en vivo.
Con él, los desarrolladores pueden detectar y diagnosticar problemas en sus aplicaciones y obtener información en tiempo real sobre el rendimiento de las aplicaciones.
Con Application Insights, los desarrolladores pueden rastrear el rendimiento y el uso de la aplicación, incluyendo solicitudes por segundo, tiempos de respuesta y tasas de error.
También pueden obtener visibilidad de las dependencias y servicios externos que utiliza la aplicación. Esto permite resolver problemas de manera rápida y eficiente.

## Configuración del Recurso

-   `type` : Tipo de plataforma para crear Application Insights - `ios`, `java`, `Node.js`, `other`, `MobileCenter`, `phone`, `store`, `web`
-   `retention_in_days` : Número de días para la retención de datos - `30`, `60`, `90`, `120`, `180`, `270`, `365`, `550`, `730`
-   `linked_workspace_name` : Nombre del Log Analytics Workspace donde se almacenarán los datos recopilados por Application Insights
-   `tag` : Etiquetas para clasificar el recurso en categorías - máximo 512 caracteres, `clave`:`valor`
