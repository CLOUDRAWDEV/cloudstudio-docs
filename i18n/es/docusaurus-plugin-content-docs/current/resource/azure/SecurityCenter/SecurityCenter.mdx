## Descripción del recurso

Azure Security Center es un servicio integrado de administración de seguridad diseñado para evaluar continuamente el estado de seguridad de los recursos en la nube y detectar y prevenir amenazas.  
Al integrarse con los planes de Microsoft Defender, permite la gestión centralizada de evaluaciones de vulnerabilidades, recomendaciones de seguridad y protección contra amenazas.

## Valores de configuración del recurso

-   `linked_log_analytics_workspace` : Nombre del Log Analytics Workspace utilizado para almacenar datos de seguridad

#### Política de evaluación (`assessment_policy`)

-   `assessment_policy.display_name` : Nombre visible de la evaluación de Security Center
-   `assessment_policy.severity` : Nivel de gravedad de la evaluación de Security Center - `Low`, `Medium`, `High`
-   `assessment_policy.description` : Descripción de la evaluación de Security Center

#### Evaluación (`assessment`)

-   `assessment.policy_name` : Nombre de la política de evaluación de seguridad aplicada al recurso
-   `assessment.status_code` : Código de estado de la evaluación - `Healthy`, `Unhealthy`, `NotApplicable`

#### Precios de la suscripción (`subscription_pricing`)

-   `subscription_pricing.pricing_tier` : Si se habilitan funciones de seguridad avanzadas - `Free`, `Standard`
-   `subscription_pricing.pricing_resource_type` : Tipo de recurso al que se aplican las funciones de seguridad avanzadas
