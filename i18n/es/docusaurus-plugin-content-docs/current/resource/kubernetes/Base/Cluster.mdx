## Descripción general del recurso

Selecciona un clúster vinculado a las credenciales del usuario.

## Valores de configuración del recurso

#### Configuración básica

-   `target_cluster` : Selección del clúster de Kubernetes de Ncloud al que se conectará
-   `token` : Token de autenticación utilizado para conectarse al servicio Ncloud Kubernetes
