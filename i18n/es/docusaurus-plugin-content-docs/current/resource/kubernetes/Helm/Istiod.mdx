## Descripción general del recurso

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el Helm Chart de Istiod
-   `version` : Versión del Helm Chart de Istiod a utilizar
-   `set` : Configuración key-value para modificar dinámicamente los valores del Helm Chart base de Istiod
