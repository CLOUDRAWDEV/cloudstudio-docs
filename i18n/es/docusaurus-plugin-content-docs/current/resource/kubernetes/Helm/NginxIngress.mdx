## Descripción general del recurso

Chart de Helm para instalar el controlador de Ingress Nginx

## Recursos relacionados

### Recurso superior

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)

### Recursos conectados

-   [**Ingress**](https://docs.cstudio.app/docs/resource/kubernetes/Networking/Ingress)


## Valores de configuración del recurso

-   `service_name` : Nombre del release del chart de Helm del Nginx Ingress Controller
-   `namespace` : Namespace donde se desplegará el chart de Helm del Nginx Ingress Controller
-   `version` : Versión del chart de Helm del Nginx Ingress Controller que se utilizará
-   `replica_count` : Número de réplicas del Deployment del Ingress Controller
-   `external_traffic_policy` : Política para manejar el tráfico externo - `Cluster`,`Local`
-   `ingress_class_name` : Nombre de la clase de Ingress que define qué controlador de Ingress gestionará el recurso
-   `set` : Modificación dinámica de valores por defecto del chart del Nginx Ingress Controller
