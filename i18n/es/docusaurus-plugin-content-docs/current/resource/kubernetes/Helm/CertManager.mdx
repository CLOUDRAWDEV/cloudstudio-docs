## Valores de configuración del recurso

-   `service_name` : Nombre del release del chart de Helm de Cert-Manager
-   `namespace` : Namespace donde se desplegará el chart de Helm de Cert-Manager
-   `version` : Versión del chart de Helm de CertManager que se utilizará
-   `installCRDs` : Indica si se deben instalar las Custom Resource Definitions relacionadas con cert-manager
