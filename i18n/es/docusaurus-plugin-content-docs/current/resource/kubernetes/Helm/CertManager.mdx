## Descripción general del recurso

Helm Chart para instalar Cert-Manager.

## Recursos relacionados

### Recurso principal

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el Helm Chart de Cert Manager
-   `version` : Versión del Helm Chart de Cert Manager a utilizar
-   `installCRDs` : Indica si se deben instalar las Custom Resource Definitions (CRD) utilizadas por Cert Manager
