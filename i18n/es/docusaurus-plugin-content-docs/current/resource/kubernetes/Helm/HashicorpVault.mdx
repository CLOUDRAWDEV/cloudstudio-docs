## Valores de configuración del recurso

-   `service_name` : Nombre del release del chart de Helm de Hashicorp Vault
-   `namespace` : Namespace donde se desplegará el chart de Helm de Hashicorp Vault
-   `version` : Versión del chart de Helm de Hashicorp Vault que se utilizará
-   `set` : Modificación dinámica de valores por defecto del chart de Hashicorp Vault
