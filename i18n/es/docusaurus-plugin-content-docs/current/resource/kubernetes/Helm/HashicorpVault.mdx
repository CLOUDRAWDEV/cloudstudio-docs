## Descripción general del recurso

Helm Chart para instalar Hashicorp Vault.

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el Helm Chart de Hashicorp Vault
-   `version` : Versión del Helm Chart de Hashicorp Vault a utilizar
-   `set` : Configuración key-value para modificar dinámicamente los valores del Helm Chart base de Hashicorp Vault
