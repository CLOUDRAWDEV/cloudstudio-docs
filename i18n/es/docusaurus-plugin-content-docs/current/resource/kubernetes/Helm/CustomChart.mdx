## Descripción general del recurso

Recurso que permite desplegar un Helm Chart configurándolo con los valores definidos por el usuario.

## Recursos relacionados

### Recurso principal

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el recurso Custom Helm Chart
-   `repository` : Dirección del repositorio donde se almacena el Helm Chart a personalizar
-   `chart` : Nombre del Helm Chart a personalizar
-   `version` : Versión del Helm Chart a personalizar
-   `set` : Configuración key-value para modificar dinámicamente los valores del Helm Chart base
