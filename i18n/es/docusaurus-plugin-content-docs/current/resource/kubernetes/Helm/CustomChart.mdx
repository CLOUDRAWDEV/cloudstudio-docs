## Descripción general del recurso

Recurso que permite desplegar un chart de Helm básico configurado con valores personalizados por el usuario

## Recursos relacionados

### Recurso superior

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)

### Recursos conectados



## Valores de configuración del recurso

-   `service_name` : Nombre del release del chart personalizado de Helm
-   `namespace` : Namespace donde se desplegará el Helm Custom
-   `repository` : Repositorio utilizado para almacenar y compartir charts de Helm (especifica el repositorio donde se encuentra el chart personalizado)
-   `chart` : Nombre del chart de Helm que se desea personalizar
-   `version` : Versión del chart de Helm que se desea personalizar
-   `set` : Modificación dinámica de valores por defecto del chart
