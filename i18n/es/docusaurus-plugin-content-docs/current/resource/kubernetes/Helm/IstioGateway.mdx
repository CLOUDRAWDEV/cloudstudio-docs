## Valores de configuración del recurso

-   `service_name` : Nombre del release del chart de Helm del Istio Gateway
-   `namespace` : Namespace donde se desplegará el chart de Helm del Istio Gateway
-   `version` : Versión del chart de Helm del Istio Gateway que se utilizará
-   `set` : Modificación dinámica de valores por defecto del chart del Istio Gateway
