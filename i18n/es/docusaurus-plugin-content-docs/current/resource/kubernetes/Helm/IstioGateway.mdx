## Descripción general del recurso

Helm Chart de Istio Gateway.

## Recursos relacionados

### Recurso principal

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el Helm Chart de Istio Gateway
-   `version` : Versión del Helm Chart de Istio Ingress a utilizar
-   `set` : Configuración key-value para modificar dinámicamente los valores del Helm Chart base de Istio Ingress
