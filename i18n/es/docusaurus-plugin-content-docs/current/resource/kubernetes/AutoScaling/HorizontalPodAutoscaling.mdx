## Descripción general del recurso

Recurso de Kubernetes que ajusta automáticamente el número de Pods de Deployment, ReplicaSet y StatefulSet en función del uso observado de CPU.

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el recurso HPA
-   `annotations` : Metadatos key-value del sistema Kubernetes
-   `labels` : Etiquetas para identificar el recurso HPA
-   `min_replicas` : Número mínimo de Pods a mantener durante el autoescalado
-   `max_replicas` : Número máximo de Pods a mantener durante el autoescalado
-   `target_cpu_utilization_percentage` : Valor objetivo del uso promedio de CPU del Pod
-   `scale_target_ref` : Referencia al recurso controlador objetivo del escalado (Deployment, StatefulSet)
