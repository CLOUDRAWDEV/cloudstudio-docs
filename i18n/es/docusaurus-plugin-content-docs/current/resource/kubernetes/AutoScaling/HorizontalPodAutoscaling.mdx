## Descripción general del recurso

Recurso de Kubernetes que escala automáticamente el número de Pods en un Deployment, ReplicaSet o StatefulSet en función del uso observado de CPU.

## Valores de configuración del recurso

-   `service_name` : Nombre del recurso HPA
-   `namespace` : Namespace donde se desplegará el recurso HPA
-   `annotations` : Key-value utilizado para mostrar información necesaria dentro del sistema Kubernetes
-   `labels` : Valores definidos por el usuario utilizados para distinguir objetos
-   `min_replicas` : Número mínimo de Pods permitido por el HPA - valor por defecto: 1
-   `max_replicas` : Número máximo de Pods permitido por el HPA
-   `target_cpu_utilization_percentage` : Porcentaje promedio objetivo de uso de CPU para los Pods (basado en la CPU solicitada)
-   `scale_target_ref` : Referencia al recurso que se va a escalar
    -   `name` : Nombre del recurso de destino
    -   `kind` : Tipo del recurso de destino - `Deployment`, `StatefulSet`
