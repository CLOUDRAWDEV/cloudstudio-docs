## Descripción general del recurso

Recurso de Kubernetes que define reglas para permitir que las conexiones entrantes alcancen los endpoints definidos en el backend.

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el recurso Ingress
-   `annotations` : Metadatos key-value utilizados por el sistema Kubernetes
-   `labels` : Etiquetas definidas por el usuario para identificar el objeto
-   `ingress_class_name` : Nombre de la clase Ingress a asociar

#### Configuración TLS (`tls`)

-   `tls.hosts` : Lista de hosts incluidos en el certificado TLS
-   `tls.secret_name` : Nombre del Secret de Kubernetes asociado al certificado TLS

#### Reglas de enrutamiento (`rule`)

-   `rule.host` : Nombre de host al que se aplicará la regla de enrutamiento

#### Configuración backend (`rule.backend`)

-   `rule.backend.target_service` : Servicio backend de destino
-   `rule.backend.path` : Ruta que se conectará al backend
-   `rule.backend.port` : Número de puerto del servicio
-   `rule.backend.path_type` : Tipo de coincidencia de la ruta - `ImplementationSpecific`, `Prefix`, `Exact`
