## Descripción general del recurso

Recurso de Kubernetes relacionado con reglas que permiten que conexiones entrantes lleguen a endpoints definidos en el backend

## Valores de configuración del recurso

-   `service_name` : Nombre del recurso Ingress
-   `namespace` : Namespace en el que se desplegará el recurso Ingress
-   `annotations` : Key-value utilizado para mostrar información necesaria dentro del sistema Kubernetes
-   `labels` : Valores definidos por el usuario utilizados para distinguir objetos
-   `tls` : Aplicación de TLS
    -   `hosts` : Lista de hosts incluidos en el certificado TLS
    -   `secret_name` : Nombre del Secret de Kubernetes relacionado con el certificado TLS
-   `ingress_class_name` : Nombre de la clase de Ingress a conectar
-   `host` : Dirección del hostname al que se aplicarán las reglas de enrutamiento
-   `backend` : Información del backend al que se enruta
    -   `name` : Nombre de la regla de enrutamiento
        -   `path` : Ruta que se conectará al backend
        -   `path_type` : Determina cómo se interpreta la coincidencia de ruta - `Prefix`, `ImplementationSpecific`, `Exact`
        -   `port` : Número de puerto del servicio - `1~65535`
