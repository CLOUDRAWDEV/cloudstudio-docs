## Descripción general del recurso

Recurso de Kubernetes para seleccionar el controlador de Ingress que será utilizado por un Ingress

## Recursos relacionados

### Recurso superior

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)



### Recursos conectados

-   [**Ingress**](https://docs.cstudio.app/docs/resource/kubernetes/Networking/Ingress)



## Valores de configuración del recurso

-   `service_name` : Nombre del recurso IngressClass
-   `annotations` : Key-value utilizado para mostrar información necesaria dentro del sistema Kubernetes
-   `labels` : Valores definidos por el usuario utilizados para distinguir objetos
-   `controller` : Nombre del controlador que debe manejar esta clase de Ingress
-   `parameters` : Información del recurso referenciado
    -   `name` : Nombre del recurso referenciado
    -   `kind` : Tipo del recurso referenciado
    -   `namespace` : Namespace del recurso referenciado
    -   `scope` : Indica el alcance del recurso - cluster o namespace
    -   `api_group` : API Group del recurso referenciado
