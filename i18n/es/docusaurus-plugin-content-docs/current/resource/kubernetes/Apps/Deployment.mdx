## Descripción general del recurso

Servicio de Kubernetes que garantiza que un número especificado de réplicas de Pod estén siempre en ejecución.

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el recurso Deployment
-   `annotations` : Metadatos key-value del sistema Kubernetes
-   `labels` : Etiquetas para identificar el recurso Deployment
-   `template_labels` : Etiquetas aplicadas a los Pods creados
-   `replicas` : Número de réplicas de Pod a mantener
-   `pod_security_context` : Configuración de seguridad y privilegios a nivel de Pod
-   `init_containers` : Definición de contenedores de inicialización
-   `containers` : Definición de contenedores incluidos en el Pod
-   `volume` : Definición de volúmenes utilizados por el Pod
-   `dns_policy` : Política DNS del Pod
-   `enable_service_links` : Habilitar inyección automática de variables de entorno de servicios
-   `host_network` : Habilitar el uso de la red del host
-   `image_pull_secrets` : Lista de Secrets utilizados para extraer imágenes
