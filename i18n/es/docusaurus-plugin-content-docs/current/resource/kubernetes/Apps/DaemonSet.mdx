## Descripción general del recurso

DaemonSet es un recurso de Kubernetes que garantiza que todos (o algunos) los nodos ejecuten una copia de un Pod.  
Cuando se añade un nodo al clúster, se agrega automáticamente un Pod a ese nodo.

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el recurso DaemonSet
-   `annotations` : Metadatos key-value utilizados por el sistema de Kubernetes
-   `labels` : Etiquetas definidas por el usuario para identificar el recurso DaemonSet
-   `template_labels` : Etiquetas aplicadas a los Pods que se crearán
-   `pod_security_context` : Configuración de seguridad y privilegios a nivel de Pod
-   `init_containers` : Definición de contenedores de inicialización que se ejecutan antes del contenedor principal
-   `containers` : Definición de los contenedores incluidos en el Pod
-   `volume` : Definición de los volúmenes que utilizará el Pod
-   `dns_policy` : Política DNS del Pod
-   `enable_service_links` : Habilitar la inyección automática de variables de entorno de servicios
-   `host_network` : Habilitar el uso de la red del host
-   `image_pull_secrets` : Lista de Secrets utilizados para extraer imágenes
