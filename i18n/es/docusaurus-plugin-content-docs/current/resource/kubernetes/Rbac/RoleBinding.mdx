## Descripción general del recurso

Recurso de Kubernetes que vincula roles aplicables dentro de un namespace específico con usuarios o cuentas de servicio.

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se aplicará el recurso RoleBinding
-   `annotations` : Metadatos key-value del recurso RoleBinding
-   `labels` : Etiquetas definidas por el usuario para identificar el objeto
-   `role_type` : Tipo de rol a vincular - `Role`, `ClusterRole`
-   `role_name` : Nombre del Role o ClusterRole a vincular

#### Configuración del sujeto (`subject`)

-   `subject.kind` : Tipo de sujeto a vincular - `ServiceAccount`, `User`, `Group`
-   `subject.namespace` : Namespace al que pertenece el sujeto
-   `subject.api_group` : API Group responsable de las decisiones de autorización - `rbac.authorization.k8s.io`
