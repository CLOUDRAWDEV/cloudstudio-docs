## Descripción general del recurso

Recurso de Kubernetes que hace referencia a un rol aplicado dentro de un namespace específico para un usuario

## Recursos relacionados

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)

### Recursos conectados

-   [**Role**](https://docs.cstudio.app/docs/resource/kubernetes/Rbac/Role)



## Valores de configuración del recurso

-   `service_name` : Nombre del recurso RoleBinding
-   `namespace` : Namespace en el que se desplegará el recurso RoleBinding
-   `annotations` : Key-value utilizado para mostrar información necesaria dentro del sistema Kubernetes
-   `labels` : Valores definidos por el usuario utilizados para distinguir objetos
-   `role_name` : Nombre del Role al que se vinculará el sujeto
-   `subject` : Configuración del sujeto al que se otorgará el Role 
    -   `name` : Nombre del sujeto a vincular
    -   `namespace` : Namespace del sujeto a vincular
    -   `api_group` : API Group que toma la decisión de autorización - `rbac.authorization.k8s.io`,`User`,`Group`
    -   `kind` : Tipo de sujeto a vincular - `ServiceAccount`,`User`,`Group`
