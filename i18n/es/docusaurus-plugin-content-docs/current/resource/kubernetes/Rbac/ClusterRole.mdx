## Descripción general del recurso

Recurso de Kubernetes que crea roles aplicables a nivel de clúster y en todos los namespaces.

## Valores de configuración del recurso

#### Configuración básica

-   `annotations` : Metadatos key-value utilizados por el sistema Kubernetes
-   `labels` : Etiquetas definidas por el usuario para identificar el objeto

#### Reglas de política (`rule`)

-   `rule.rule_type` : Tipo de regla del ClusterRole - `ApiGroup`, `ResourceUrl`
-   `rule.api_groups` : API Groups que contienen los recursos permitidos
-   `rule.resources` : Lista de recursos a los que se aplica esta regla
-   `rule.resource_names` : Especificación de instancias individuales de recursos
-   `rule.non_resource_urls` : Uso de reglas basadas en URLs no asociadas a recursos
-   `rule.verbs` : Lista de verbos aplicables a los recursos - `get`, `list`, `create`, `update`, `patch`, `watch`, `delete`, `deletecollection`
