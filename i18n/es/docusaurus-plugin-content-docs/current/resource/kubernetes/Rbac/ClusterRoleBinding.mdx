## Descripción general del recurso

Recurso de Kubernetes que vincula roles aplicables a nivel de clúster con usuarios en todos los namespaces.

## Valores de configuración del recurso

#### Configuración básica

-   `annotations` : Metadatos key-value del recurso ClusterRoleBinding
-   `labels` : Etiquetas definidas por el usuario para identificar el objeto
-   `role_name` : Nombre del ClusterRole a vincular
-   `subject` : Sujeto al que se le asigna el ClusterRole, incluyendo kind - `ServiceAccount`, `User`, `Group`, namespace y api_group - `rbac.authorization.k8s.io`
