## Descripción general del recurso

Recurso de Kubernetes que crea trabajos de forma periódica según un horario definido.

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el CronJob
-   `schedule` : Frecuencia de ejecución del trabajo definida mediante una expresión cron
-   `timezone` : Zona horaria base utilizada para interpretar el horario
-   `concurrency_policy` : Política de ejecución concurrente de trabajos (Allow / Forbid / Replace)
-   `starting_deadline_seconds` : Tiempo límite permitido para iniciar un trabajo cuando se pierde una programación
-   `successful_jobs_history_limit` : Número de Jobs exitosos que se conservarán
-   `failed_jobs_history_limit` : Número de Jobs fallidos que se conservarán
-   `containers` : Definición del contenedor que se ejecutará
-   `init_containers` : Definición de tareas previas a la ejecución del contenedor principal
-   `volume` : Configuración de volúmenes que se montarán en el contenedor
-   `pod_security_context` : Configuración del contexto de seguridad a nivel de Pod
-   `image_pull_secrets` : Referencias a Secrets para extraer imágenes
