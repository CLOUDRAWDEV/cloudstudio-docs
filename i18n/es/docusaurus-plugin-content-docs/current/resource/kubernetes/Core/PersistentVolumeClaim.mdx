## Descripción general del recurso

Recurso de Kubernetes que solicita un PersistentVolume (PV).

## Valores de configuración del recurso

-   `service_name` : Nombre del recurso PersistentVolumeClaim
-   `namespace` : Namespace donde se desplegará el recurso PersistentVolume
-   `annotations` : Key-value utilizado para mostrar información necesaria dentro del sistema Kubernetes
-   `labels` : Valores definidos por el usuario utilizados para distinguir objetos
-   `spec` : Define las especificaciones del PVC
    -   `spec.storage_class_name` : Nombre del storageClass a utilizar
    -   `spec.volume_name` : Nombre del PV que se conectará con el PVC
    -   `spec.request_storage` : Cantidad de almacenamiento solicitada al PV
    -   `spec.access_modes` : Modos de acceso requeridos para el PV - (deben coincidir o incluir los modos del PV) - `ReadOnlyMany`,`ReadWriteMany`,`ReadWriteOnce`
