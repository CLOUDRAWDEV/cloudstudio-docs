## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se creará el recurso PVC
-   `annotations` : Metadatos del sistema Kubernetes
-   `labels` : Etiquetas definidas por el usuario para identificar y clasificar el PVC
-   `spec.storage_class_name` : Nombre del StorageClass a utilizar
-   `spec.volume_name` : Nombre del PersistentVolume a vincular
-   `spec.volume_mode` : Modo de provisión del almacenamiento - `Filesystem / Block`
-   `spec.request_storage` : Capacidad de almacenamiento solicitada
-   `spec.access_modes` : Modos de acceso solicitados - `ReadOnlyMany, ReadWriteOnce, ReadWriteMany`
-   `wait_until_bound` : Indica si se debe esperar hasta que el PVC se vincule con un PV
