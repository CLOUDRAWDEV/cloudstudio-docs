## Descripción general del recurso

Servicio de Kubernetes que representa la unidad de despliegue más pequeña, en la que se ejecutan uno o más contenedores juntos.

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el recurso Pod
-   `annotations` : Metadatos del sistema Kubernetes
-   `labels` : Etiquetas definidas por el usuario para identificar y clasificar el Pod
-   `pod_security_context` : Configuración de seguridad y permisos a nivel de Pod
-   `init_containers` : Definición de contenedores de inicialización antes del contenedor principal
-   `containers` : Definición del contenedor que se ejecutará en el Pod
-   `containers.image` : Imagen del contenedor
-   `containers.resources` : Solicitudes y límites de CPU / memoria
-   `containers.probe` : Configuración de probes startup, liveness y readiness
-   `containers.env` : Definición de variables de entorno
-   `containers.env_from` : Inyección de variables desde ConfigMap / Secret
-   `containers.command` : Comando de ejecución del contenedor
-   `containers.args` : Argumentos de ejecución del contenedor
-   `containers.port` : Puertos expuestos por el contenedor
-   `containers.volume_mount` : Rutas de montaje de volúmenes en el contenedor
-   `volume` : Definición de volúmenes utilizados por el Pod
-   `dns_policy` : Configuración de política DNS
-   `enable_service_links` : Inyección automática de variables de entorno de Service
-   `host_network` : Uso de red del host
-   `image_pull_secrets` : Lista de Secrets utilizados para extraer imágenes
