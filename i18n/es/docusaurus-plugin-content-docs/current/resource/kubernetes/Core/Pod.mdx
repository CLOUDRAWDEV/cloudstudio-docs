## Descripción general del recurso

Servicio de Kubernetes que representa la unidad de despliegue más pequeña, que ejecuta uno o más contenedores juntos.

## Valores de configuración del recurso

-   `service_name` : Nombre del recurso Pod
-   `namespace` : Namespace donde se desplegará el recurso Pod
-   `annotations` : Key-value utilizado para mostrar información necesaria dentro del sistema Kubernetes
-   `labels` : Valores definidos por el usuario utilizados para distinguir objetos
-   `containers` : Define una plantilla para los contenedores incluidos en el Pod - se configuran los valores por defecto antes de ajustar las configuraciones específicas
    -   `containers.name` : Nombre del contenedor
        -   `image` : Nombre de la imagen Docker a utilizar
        -   `args` : Comandos a ejecutar dentro del contenedor
        -   `command` : Comandos a ejecutar dentro del contenedor
        -   `port` : Lista de puertos expuestos por el contenedor 

        -   `resources` : Cantidad de recursos de computación asignados al contenedor - configuración detallada
            -   `name` : Define los límites o solicitudes mínimas de recursos - `Limits`, `requests`     
            -   `cpu` : Cantidad de CPU asignada    
            -   `memory` : Cantidad de memoria asignada

        -   `probe` : Define los métodos de diagnóstico del estado del Pod - configuración detallada
            -   `name` : Tipo de Probe - `startup`,`liveness`,`readiness`
            -   `http_get_path` : Ruta para acceder al servidor HTTP
            -   `http_get_port` : Puerto del contenedor a acceder
            -   `http_header` : Encabezados personalizados de la solicitud
            -   `initial_delay_seconds` : Tiempo (en segundos) que debe pasar tras el arranque antes de iniciar el probe
            -   `period_seconds` : Frecuencia (en segundos) con la que se realiza el probe

        -   `env` : Bloque de pares key-value para configurar variables de entorno del contenedor - configuración detallada
            -   `name` : Nombre de la variable de entorno
            -   `value` : Valor asignado a la variable de entorno

        -   `volume_mount` : Volumen del Pod que será montado en el sistema de archivos del contenedor - configuración detallada
            -   `name` : Nombre del volumen montado
            -   `path` 
                -   `mount_path` : Ruta dentro del contenedor donde se montará el volumen
                -   `sub_path` : Ruta dentro del contenedor donde se montará el subdirectorio del volumen
            
-   `volume` : Lista de volúmenes que pueden ser montados por los contenedores del Pod
    -   `name` : Nombre del volumen
        -   `type` : Tipo del volumen a montar - `EmptyDir`,`ConfigMap`,`PersistentVolumeClaim`
        -   `target_name` : Nombre del Persistent Volume Claim
        -   `default_mode` : Modo para los archivos generados - entre 0 y 0777, valor por defecto 0644
        -   `read_only` : Si es `true`, se monta como solo lectura; de lo contrario, se permite lectura/escritura

-   `image_pull_secrets` : Secret dentro del mismo namespace que contiene los permisos necesarios para descargar imágenes utilizadas por el contenedor
