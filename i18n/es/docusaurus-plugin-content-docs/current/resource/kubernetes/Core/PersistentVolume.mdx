## Descripción general del recurso

Recurso de Kubernetes que proporciona almacenamiento conectado por red al clúster.

## Valores de configuración del recurso

#### Configuración básica

-   `annotations` : Metadatos del sistema Kubernetes
-   `labels` : Etiquetas definidas por el usuario para identificar y clasificar el PV
-   `spec.storage_class_name` : Nombre del StorageClass a utilizar
-   `spec.storage_capacity` : Capacidad de almacenamiento
-   `spec.volume_driver` : Controlador de volumen basado en CSI
-   `spec.volume_handle` : Identificador del recurso de almacenamiento real
-   `spec.persistent_volume_reclaim_policy` : Política de manejo del volumen al liberar el claim - `Retain / Delete / Recycle`
-   `spec.read_only` : Indica si el volumen es de solo lectura
-   `spec.volume_attributes` : Atributos adicionales del volumen según el driver
-   `spec.access_modes` : Modos de acceso al volumen - `ReadOnlyMany, ReadWriteOnce, ReadWriteMany`
-   `spec.mount_options` : Opciones adicionales de montaje
-   `node_stage_secret_ref` : Referencia a Secret que contiene credenciales de acceso al almacenamiento
