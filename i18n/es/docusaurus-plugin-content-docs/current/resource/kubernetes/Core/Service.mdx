## Descripción general del recurso

Recurso de Kubernetes abstraído que proporciona un punto de entrada único para los Pods y gestiona la comunicación entre ellos.

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el recurso Service
-   `annotations` : Metadatos del sistema Kubernetes
-   `labels` : Etiquetas para identificar y clasificar el Service
-   `selector` : Selector de etiquetas para determinar los Pods destino del tráfico
-   `type` : Tipo de Service - `ClusterIP`, `NodePort`, `LoadBalancer`
-   `session_affinity` : Afinidad de sesión para fijar solicitudes del mismo cliente - `None`, `ClientIP`

#### Configuración de puertos (`port`)

-   `port.protocol` : Protocolo utilizado en el puerto del Service - `TCP`, `UDP`
-   `port.port` : Número de puerto expuesto por el Service
-   `port.target_port` : Puerto real del Pod que recibe el tráfico
