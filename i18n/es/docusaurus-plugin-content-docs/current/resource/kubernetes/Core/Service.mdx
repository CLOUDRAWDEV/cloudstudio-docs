## Descripción general del recurso

Recurso abstracto de Kubernetes que proporciona un único punto de entrada para los Pods y gestiona la comunicación entre ellos.

## Valores de configuración del recurso

-   `service_name` : Nombre del recurso Service
-   `namespace` : Namespace donde se desplegará el recurso Service
-   `annotations` : Key-value utilizado para mostrar información necesaria dentro del sistema Kubernetes
-   `labels` : Valores definidos por el usuario utilizados para distinguir objetos
-   `selector` : Redirecciona el tráfico del servicio a Pods utilizando key-value labels que coincidan con el selector
-   `type` : Tipo de servicio - `ClusterIP`,`NodePort`,`LoadBalancer`
-   `session_affinity` : Política para mantener las solicitudes del cliente dirigidas a un Pod específico - `None`,`clientIP`
-   `port` : Lista de puertos expuestos por el servicio
    -   `name` : Nombre de la configuración del puerto  
        -   `protocol` : Protocolo IP del puerto - `TCP`,`UDP`
        -   `port` : Número del puerto expuesto por el servicio
        -   `target_port` : Número del puerto al que se accederá en el Pod destino del servicio
