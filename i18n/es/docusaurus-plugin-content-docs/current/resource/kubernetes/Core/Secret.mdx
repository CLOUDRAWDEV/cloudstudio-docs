## Descripción general del recurso

Recurso de Kubernetes utilizado para almacenar información sensible en forma de atributos individuales, archivos completos o blobs JSON.

## Valores de configuración del recurso

-   `service_name` : Nombre del recurso Secret
-   `namespace` : Namespace donde se desplegará el recurso Secret
-   `annotations` : Key-value utilizado para mostrar información necesaria dentro del sistema Kubernetes
-   `labels` : Valores definidos por el usuario utilizados para distinguir objetos
-   `type` : Tipo de Secret - `Opaque`,`kubernetes.io/basic-auth`,`kubernetes.io/service-account-token`,`kubernetes.io/dockerconfigjson`
-   `immutable` : Configura si los datos almacenados en el Secret no pueden ser modificados (solo se puede modificar la metadata del objeto) - `false`,`true`

-   `data` : Datos que se almacenarán en el Secret
    -   `data.name` : Nombre del dato almacenado en el Secret - `Opaque`,`kubernetes.io/basic-auth` 
        -   `data.secret` : Valor del dato almacenado en el Secret - `Opaque`,`kubernetes.io/basic-auth`         
    -   `data.name` : Nombre del registro privado de Docker - `kubernetes.io/dockerconfigjson`
        -   `data.username` : Nombre de usuario para autenticarse en el registro privado de Docker - `kubernetes.io/dockerconfigjson`
        -   `data.password` : Contraseña para autenticarse en el registro privado de Docker - `kubernetes.io/dockerconfigjson`
