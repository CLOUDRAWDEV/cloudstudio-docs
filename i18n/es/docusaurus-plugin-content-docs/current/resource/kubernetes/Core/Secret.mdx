## Descripción general del recurso

Recurso de Kubernetes utilizado para almacenar información sensible como propiedades individuales, archivos completos o blobs JSON.

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el recurso Secret
-   `annotations` : Metadatos del sistema Kubernetes
-   `labels` : Etiquetas definidas por el usuario para identificar y clasificar el Secret
-   `type` : Tipo de Secret - `Opaque`, `kubernetes.io/basic-auth`, `kubernetes.io/service-account-token`, `kubernetes.io/dockerconfigjson`, `helm.sh/release.v1`, `kubernetes.io/tls`, `kubernetes.io/ssh-auth`, `istio.io/ca-root`
-   `immutable` : Indica si los datos del Secret pueden modificarse
-   `data` : Datos secretos codificados en Base64 en formato key-value
