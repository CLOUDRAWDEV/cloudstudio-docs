## Descripción general del recurso

Recurso de Kubernetes utilizado para agrupar y aislar objetos dentro de un clúster.

## Valores de configuración del recurso

#### Configuración básica

-   `annotations` : Metadatos del sistema Kubernetes
-   `labels` : Etiquetas definidas por el usuario para identificar y clasificar el Namespace
