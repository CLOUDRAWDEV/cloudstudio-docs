## Descripción general del recurso

Recurso de Kubernetes utilizado para almacenar configuraciones de la aplicación de forma separada y entregarlas a los contenedores dentro de los Pods.

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el recurso ConfigMap
-   `annotations` : Metadatos del sistema Kubernetes
-   `data` : Datos de configuración en formato texto almacenados como key-value
-   `labels` : Etiquetas definidas por el usuario para identificación y clasificación del recurso
-   `binary_data` : Datos en formato binario almacenados como key-value
