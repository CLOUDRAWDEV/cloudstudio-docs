## Descripción general del recurso

Recurso de Kubernetes utilizado para almacenar la configuración de una aplicación por separado y proporcionarla a los contenedores dentro del Pod.

## Valores de configuración del recurso

-   `service_name` : Nombre del recurso ConfigMap
-   `namespace` : Namespace donde se desplegará el recurso ConfigMap
-   `annotations` : Key-value utilizado para mostrar información necesaria dentro del sistema Kubernetes
-   `labels` : Valores definidos por el usuario utilizados para distinguir objetos
-   `data` : Datos en formato key-value usados para almacenar configuraciones en texto, como archivos de configuración o variables de entorno
    -   `data.name` : Clave de los datos
    -   `data.value` : Valor de los datos
-   `binary_data` : Datos binarios asociados a una clave específica - se utiliza para almacenar archivos binarios u otros formatos binarios
    -   `data.name` : Clave de los datos binarios
    -   `data.value` : Valor de los datos binarios
