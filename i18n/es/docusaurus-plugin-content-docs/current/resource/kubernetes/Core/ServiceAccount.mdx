## Descripción general del recurso

Cuenta que otorga permisos a aplicaciones y servicios para acceder y utilizar recursos dentro del clúster de Kubernetes.

## Recursos relacionados

### Recurso principal

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

### Recursos conectados

-   [**Secret**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Secret)

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el recurso ServiceAccount
-   `annotations` : Metadatos del sistema Kubernetes
-   `labels` : Etiquetas para identificar y clasificar el ServiceAccount
-   `secret` : Lista de Secrets permitidos para Pods que referencian este ServiceAccount
-   `image_pull_secrets` : Lista de Secrets utilizados para extraer imágenes
-   `automount_service_account_token` : Montaje automático del token del ServiceAccount en los Pods
