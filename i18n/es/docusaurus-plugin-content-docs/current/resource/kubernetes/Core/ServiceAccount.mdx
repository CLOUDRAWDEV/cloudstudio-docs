## Descripción general del recurso

Cuenta que otorga permisos a aplicaciones y servicios dentro del clúster de Kubernetes para acceder y utilizar recursos del clúster.

## Valores de configuración del recurso

-   `service_name` : Nombre del recurso ServiceAccount
-   `namespace` : Namespace donde se desplegará el recurso ServiceAccount
-   `annotations` : Key-value utilizado para mostrar información necesaria dentro del sistema Kubernetes
-   `labels` : Valores definidos por el usuario utilizados para distinguir objetos
-   `secret` : Lista de Secrets permitidos para ser utilizados por los Pods que hacen referencia a esta cuenta de servicio
-   `image_pull_secrets` : Lista de Secrets en el mismo namespace utilizados para obtener imágenes en los Pods que hacen referencia a esta cuenta de servicio
