## Descripción general del recurso

ServiceAccount predeterminado que otorga permisos a los Pods para acceder al API Server y a los recursos del clúster de Kubernetes.

## Valores de configuración del recurso

#### Configuración básica

-   `namespace` : Namespace donde se desplegará el recurso ServiceAccount
-   `annotations` : Metadatos del sistema Kubernetes
-   `labels` : Etiquetas definidas por el usuario para identificación y clasificación del recurso
-   `secret` : Lista de Secrets accesibles por los Pods que utilizan este ServiceAccount
-   `image_pull_secrets` : Lista de Secrets utilizados por los Pods para extraer imágenes
-   `automount_service_account_token` : Montaje automático del token de ServiceAccount en los Pods
