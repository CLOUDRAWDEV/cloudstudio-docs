## Descripción general del recurso

Recurso de Kubernetes que define el aprovisionamiento dinámico de almacenamiento que funciona junto con un Storage Provisioner específico.

## Recursos relacionados

### Recurso principal

-   [**Cluster**](https://docs.cstudio.app/es/docs/resource/kubernetes/Base/Cluster)

### Recursos conectados

-   [**PersistentVolume**](https://docs.cstudio.app/es/docs/resource/kubernetes/Core/PersistentVolume)

## Valores de configuración del recurso

#### Configuración básica

-   `annotations` : Metadatos key-value utilizados para mostrar la información necesaria en el sistema Kubernetes
-   `labels` : Etiquetas definidas por el usuario para identificar el objeto StorageClass
-   `storage_provisioner` : Tipo de Storage Provisioner que crea realmente el almacenamiento
-   `reclaim_policy` : Política de recuperación aplicada al liberar el volumen - `Retain`, `Delete`
-   `volume_binding_mode` : Momento en el que se produce la vinculación del volumen y el aprovisionamiento dinámico - `Immediate`, `WaitForFirstConsumer`
-   `allow_volume_expansion` : Indica si se permite la expansión del tamaño del volumen creado
-   `parameters` : Parámetros adicionales transmitidos al Storage Provisioner
-   `mount_options` : Opciones de montaje que se aplicarán al PersistentVolume creado dinámicamente
