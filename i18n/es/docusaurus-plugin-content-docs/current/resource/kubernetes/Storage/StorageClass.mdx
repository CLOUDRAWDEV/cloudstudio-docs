## Descripción general del recurso

Recurso de Kubernetes que define el aprovisionamiento dinámico de almacenamiento que funciona junto con un aprovisionador de almacenamiento (Storage Provisioner) específico

## Valores de configuración del recurso

-   `service_name` : Nombre del recurso StorageClass
-   `annotations` : Key-value utilizado para mostrar información necesaria dentro del sistema Kubernetes
-   `labels` : Valores definidos por el usuario utilizados para distinguir objetos
-   `storage_Provisioner` : Tipo de proveedor de almacenamiento
-   `reclaim_policy` : Política de recuperación a usar - si no se especifica, el valor por defecto es Delete
-   `volume_binding_mode` : Momento en el que debe ocurrir el enlace de volumen y el aprovisionamiento dinámico - `Immediate`, `WaitForFirstConsumer`
-   `allow_volume_expansion` : Indica si la clase de almacenamiento permite la expansión del volumen - `False`, `True`
-   `parameters` : Parámetros para el aprovisionador encargado de crear volúmenes para la clase de almacenamiento
-   `mount_options` : Opciones de montaje especificadas para los volúmenes persistentes creados dinámicamente por la clase de almacenamiento
