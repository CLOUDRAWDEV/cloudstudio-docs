## Descripción general del recurso

Es un servicio que define las rutas de red de los recursos dentro del VPC.

## Recursos relacionados

### Recurso superior

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

### Recursos conectados

-   [**Subnet**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Subnet)

## Valores de configuración del recurso

-   `included_vpc_name` : Nombre del VPC a conectar
-   `supported_subnet_type` : Configuración de subnet compatible, pública o privada - `PUBLIC`, `PRIVATE`
-   `route_table_description` : Descripción de la Route Table
-   `linked_subnet_names` : Lista de nombres de subnets a conectar
-   `route`
    -   `target_type` : Tipo de destino, Nat gateway o VPC Peering - `NATGW`, `VPCPEERING`, `VGW`
    -   `target_name` : Nombre del destino
    -   `destination_cidr_block` : Rango de IP de destino en formato CIDR
