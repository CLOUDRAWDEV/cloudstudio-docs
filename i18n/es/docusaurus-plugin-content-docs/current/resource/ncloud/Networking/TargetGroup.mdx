## Descripción general del recurso

Es un recurso que representa un conjunto de targets que manejarán las solicitudes del Load Balancer.

## Valores de configuración del recurso

-   `included_vpc_name` : Nombre del VPC en el que existirá el Target Group
-   `protocol` : Tipo de protocolo a aplicar para enrutar el tráfico - `TCP`, `PROXY_TCP`, `HTTP`, `HTTPS`
-   `port` : Número del puerto que recibirá el tráfico 
-   `algorithm_type` : Tipo de algoritmo a usar para load balancing, RR/SIPHS/LC - `RR`, `SIPHS`, `LC`, `MH`
-   `health_check_protocol` : Tipo de protocolo para la verificación de estado del target - `TCP`, `HTTP`, `HTTPS`
-   `health_check_http_method` : Método HTTP a usar si el protocolo de verificación es HTTP/HTTPS, HEAD o GET - `HEAD`, `GET`
-   `health_check_port` : Número de puerto a usar para la verificación del estado del target
-   `health_check_cycle` : Ciclo de verificación del estado del target (segundos), en el rango de 5 ~ 300
-   `health_check_up_threshold` : Umbral de estado normal, número de verificaciones necesarias para que un target anormal se considere normal, en el rango de 2 ~ 10
-   `health_check_down_threshold` : Umbral de fallo, número de verificaciones para considerar que un target normal ha fallado, en el rango de 2 ~ 10 
-   `linked_server_names` : Lista de nombres de servidores a conectar
