## Descripción general del recurso

Es un servicio que ayuda a utilizar el servidor con fines de servicio o a conectarse al servidor creado.

## Recursos relacionados

### Recurso superior

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### Recursos conectados

-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## Valores de configuración del recurso

-   `target_server_name` : Nombre de la instancia del servidor al que se aplicará la Public IP
