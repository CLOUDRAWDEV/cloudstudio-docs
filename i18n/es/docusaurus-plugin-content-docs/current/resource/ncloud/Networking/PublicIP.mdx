## Descripción general del recurso

Servicio que permite acceder a servidores creados o utilizarlos con fines de servicio mediante una IP pública.

## Recursos relacionados

### Recurso principal

-   [**Region**](https://docs.cstudio.app/es/docs/resource/ncloud/Base/Region)

### Recursos conectados

-   [**Server**](https://docs.cstudio.app/es/docs/resource/ncloud/Compute/Server)

## Valores de configuración del recurso

#### Configuración básica

-   `target_server_name` : Nombre del servidor al que se asignará la IP pública
