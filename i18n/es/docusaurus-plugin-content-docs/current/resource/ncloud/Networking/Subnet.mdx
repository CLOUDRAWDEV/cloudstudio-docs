## Descripción general del recurso

Es una subred subordinada al VPC que permite segmentación según el propósito de red.

## Valores de configuración del recurso

-   `subnet_cidr` : Rango de direcciones IP del subnet dentro del rango de direcciones del VPC
-   `zone` : Región física donde se ubicará el subnet - `KR-1`, `KR-2`
-   `subnet_type` : Configuración de subnet pública o privada - `PUBLIC`, `PRIVATE`
-   `usage_type` : Configuración de uso con load balancer - `GEN`, `BM`
-   `included_vpc_name` : Nombre del VPC donde se ubicará el subnet
-   `linked_nacl_name` : Lista de control de acceso a red para controlar el acceso al subnet
