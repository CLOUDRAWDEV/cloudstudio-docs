## Descripción general del recurso

Red secundaria dentro de un VPC que permite la segmentación según el propósito del tráfico de red.

## Valores de configuración del recurso

#### Configuración básica

-   `subnet_cidr` : Rango IP del Subnet dentro del CIDR del VPC
-   `zone` : Zona de disponibilidad del Subnet (`KR-1`, `KR-2`)
-   `subnet_type` : Tipo de Subnet (`PUBLIC`, `PRIVATE`)
-   `usage_type` : Uso del Subnet (`General`, `LoadBalancer`, `BareMetal`, `NatGateway`)
-   `included_vpc_name` : Nombre del VPC al que pertenece (solo lectura)
-   `linked_nacl_name` : Nombre del Network ACL aplicado (solo lectura)
