## Descripción general del recurso

Es un recurso que configura el VPC Peering para la comunicación entre VPCs.

## Recursos relacionados

### Recurso superior

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### Recursos conectados

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

## Valores de configuración del recurso

-   `linked_vpc_name_01` : Nombre del VPC que envía la solicitud
-   `linked_vpc_name_02` : Nombre del VPC que recibe la solicitud
