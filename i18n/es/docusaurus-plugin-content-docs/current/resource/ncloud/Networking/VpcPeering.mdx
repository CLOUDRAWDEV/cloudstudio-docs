## Descripción general del recurso

Recurso para configurar VPC Peering con el fin de permitir la comunicación entre VPCs.

## Recursos relacionados

### Recurso principal

-   [**Region**](https://docs.cstudio.app/es/docs/resource/ncloud/Base/Region)

### Recursos conectados

-   [**Vpc**](https://docs.cstudio.app/es/docs/resource/ncloud/Networking/Vpc)

## Valores de configuración del recurso

#### Configuración básica

-   `linked_vpc_name_01` : Nombre del VPC que envía la solicitud de peering (solo lectura)
-   `linked_vpc_name_02` : Nombre del VPC que recibe la solicitud de peering (solo lectura)
