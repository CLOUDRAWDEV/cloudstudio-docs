## Descripción general del recurso

Servicio que permite conectar múltiples servidores mediante una única IP pública y bloquear el acceso directo desde el exterior.  
Facilita la comunicación de servidores con IP privada hacia servidores externos manteniendo la seguridad.

## Recursos relacionados

### Recurso principal

-   [**Subnet**](https://docs.cstudio.app/es/docs/resource/ncloud/Networking/Subnet)

## Valores de configuración del recurso

#### Configuración básica

-   `included_vpc_name` : Nombre del VPC donde se creará el NAT Gateway
-   `included_subnet_name` : Nombre del Subnet donde se creará el NAT Gateway
