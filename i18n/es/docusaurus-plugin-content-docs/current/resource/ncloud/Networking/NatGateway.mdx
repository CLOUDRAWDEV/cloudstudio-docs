## Descripción general del recurso

Es un servicio que permite conectar múltiples servidores mediante una única IP pública y bloquea el acceso directo desde el exterior. Permite que varios servidores con IP privada se comuniquen con servidores externos, manteniendo la seguridad al bloquear el acceso externo directo.

## Valores de configuración del recurso

-   `included_vpc_name` : Nombre del VPC donde se creará el Nat Gateway
-   `zone` : Zona física donde se ubicará el Nat Gateway - `KR-1`, `KR-2`
