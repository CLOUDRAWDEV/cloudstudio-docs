## Descripción general del recurso

Servicio que permite crear interfaces de red asignables a servidores.  
Los servidores con Network Interface pueden comunicarse de forma independiente utilizando Subnets.

## Recursos relacionados

### Recurso principal

-   [**Subnet**](https://docs.cstudio.app/es/docs/resource/ncloud/Networking/Subnet)

### Recursos conectados

-   [**AccessControlGroup**](https://docs.cstudio.app/es/docs/resource/ncloud/Networking/AccessControlGroup)
-   [**Server**](https://docs.cstudio.app/es/docs/resource/ncloud/Compute/Server)

## Valores de configuración del recurso

#### Configuración básica

-   `included_subnet_name` : Nombre del Subnet donde se incluirá la Network Interface
-   `linked_acg_names` : Lista de nombres de Access Control Group a aplicar
