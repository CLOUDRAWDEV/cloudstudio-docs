## Descripción general del recurso

Es un servicio que crea interfaces de red que se pueden asignar a los servidores. Los servidores con una interfaz de red aplicada pueden comunicarse en una red independiente utilizando Subnet.

## Recursos relacionados

-   [**Subnet**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Subnet)

### Recursos conectados

-   [**Access Control Group**](https://docs.cstudio.app/docs/resource/ncloud/Security/AccessControlGroup)
-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## Valores de configuración del recurso

-   `included_subnet_name` : Nombre del subnet que incluirá la Network Interface
-   `linked_acg_names` : Lista de nombres de ACG a aplicar a la interfaz de red
