## Descripción general del recurso

Es un componente que distribuye el tráfico de red entre múltiples servidores, considerando el rendimiento y la carga de cada uno. Al distribuir las cargas concentradas en un servidor, se optimizan la disponibilidad y el tiempo de respuesta del servicio, posibilitando un servicio sin interrupciones.

## Valores de configuración del recurso

-   `network_type` : Tipo de red, pública o privada - `PUBLIC`, `PRIVATE`
-   `type` : Tipo de Load Balancer a crear, aplicación / red / proxy de red - `NETWORK`, `NETWORK_PROXY`, `APPLICATION`
-   `throughput_type` : Capacidad de procesamiento (número de conexiones por segundo) - `SMALL`, `MEDIUM`, `LARGE`
-   `included_vpc_name` : Nombre del VPC donde se creará el Target Group
-   `subnet_config`
    -   `cidr`
    -   `linked_nacl_name`
    -   `zone`
-   `target_group`
    -   `protocol` : Tipo de protocolo para enrutar el tráfico - `TCP`, `PROXY_TCP`, `HTTP`, `HTTPS`
    -   `port` : Puerto que recibirá el tráfico
    -   `algorithm_type` : Tipo de algoritmo de balanceo de carga - `RR`, `SIPHS`, `LC`, `MH`
    -   `health_check_protocol` : Protocolo para verificar el estado de los targets - `TCP`, `HTTP`, `HTTPS`
    -   `health_check_http_method` : Método HTTP a usar para el health check cuando se use HTTP/HTTPS - `HEAD`, `GET`
    -   `health_check_port` : Puerto a usar para la verificación del estado
    -   `health_check_cycle` : Intervalo entre chequeos de estado (en segundos), entre 5 y 300
    -   `health_check_up_threshold` : Umbral de éxito, número de chequeos requeridos para considerar un target como saludable
    -   `health_check_down_threshold` : Umbral de fallo, número de chequeos requeridos para considerar un target como no saludable
-   `listener`
    -   `target_group_name` : Nombre del Target Group a conectar
    -   `protocol` : Tipo de protocolo para el listener - `APPLICATION`, `HTTP`, `HTTPS`, `TCP`, `TLS`
    -   `port` : Puerto del Load Balancer que será enlazado al listener
-   `target_group_attachment`
    -   `target_group_name` : Nombre del Target Group a conectar
    -   `linked_server_names` : Lista de nombres de servidores a vincular
