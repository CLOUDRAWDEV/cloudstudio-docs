## Descripción general del recurso

Cloud DB for MongoDB permite construir y gestionar automáticamente bases de datos MongoDB de forma sencilla. Es un servicio de base de datos en la nube totalmente gestionado, con configuración optimizada por Naver que garantiza una operación estable y recuperación automática en caso de fallos.

## Valores de configuración del recurso

-   `server_name_prefix` : Nombre del servidor MongoDB
-   `user_name` : ID de acceso del usuario a MongoDB
-   `user_password` : Contraseña del usuario de MongoDB
-   `cluster_type_code` : Código del tipo de clúster de MongoDB - `Stand Alone`, `Stand Replica Set`, `Shared Cluster`
-   `image_product_code` : Código del producto de la imagen de versión de MongoDB
-   `member_port` : Puerto TCP para acceder al servidor MongoDB Member - `10000-65535`
-   `member_server_count` : Número de servidores Member de MongoDB; depende del tipo de réplica - `3-7`
-   `mongos_server_count` : Número de servidores Mongos de MongoDB - `2-5`
-   `backup_file_retention_period` : Período de retención de archivos de backup, realizado diariamente y almacenado en almacenamiento separado - `1~30`
-   `data_storage_type` : Tipo de almacenamiento de datos - `SSD`, `HDD`
-   `compress_code` : Código del algoritmo de compresión de datos en MongoDB - `SNPP`, `ZLIB`, `ZSTD`, `NONE`
