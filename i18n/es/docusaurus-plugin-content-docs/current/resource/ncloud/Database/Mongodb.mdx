## Descripción general del recurso

Cloud DB for MongoDB permite construir y gestionar automáticamente bases de datos MongoDB de forma sencilla.  
Es un servicio de base de datos en la nube completamente gestionado que opera de manera estable mediante configuraciones optimizadas de Ncloud y se recupera automáticamente en caso de fallos.

## Valores de configuración del recurso

#### Configuración básica

-   `server_name_prefix` : Nombre del servidor MongoDB; se permiten letras minúsculas, números y guiones (-); debe comenzar con una letra minúscula y terminar con letra minúscula o número; longitud de 3 a 15 caracteres
-   `user_name` : ID de acceso del usuario MongoDB
-   `user_password` : Contraseña del usuario MongoDB
-   `included_vpc_name` : Nombre del VPC que incluye MongoDB
-   `included_subnet_name` : Nombre del Subnet que incluye MongoDB
-   `cluster_type_code` : Código que determina el tipo de clúster MongoDB - `clusterTypeCode`
-   `shard_count` : Número de shards de MongoDB - `2`, `3`
-   `image_product_code` : Código del producto de la imagen de versión MongoDB - `imageProductCode`
-   `backup_file_retention_period` : Periodo de retención de archivos de respaldo; los respaldos se realizan diariamente y se almacenan en un almacenamiento separado - `1` ~ `30`
-   `backup_time` : Hora de respaldo definida por el usuario
-   `data_storage_type` : Tipo de almacenamiento de datos - `SSD`, `HDD`
-   `compress_code` : Código del algoritmo de compresión de datos MongoDB - `SNPP`, `ZLIB`, `ZSTD`, `NONE`

#### Configuración de MongoDB Member (`member`)

-   `member.member_port` : Puerto TCP para acceder al servidor MongoDB Member - `10000` ~ `65535`
-   `member.member_product_code` : Código del producto del servidor MongoDB Member - `memberProductCode`
-   `member.member_server_count` : Número de servidores MongoDB Member - `3` ~ `7`

#### Configuración de MongoDB Arbiter (`arbiter`)

-   `arbiter.arbiter_server_count` : Número de servidores MongoDB Arbiter - `0`, `1`
-   `arbiter.arbiter_product_code` : Código del producto del servidor MongoDB Arbiter - `arbiterProducCode`

#### Configuración de MongoDB Mongos (`mongos`)

-   `mongos.mongos_port` : Puerto TCP para acceder al servidor MongoDB Mongos - `10000` ~ `65535`
-   `mongos.mongos_product_code` : Código del producto MongoDB Mongos - `mongosProductCode`
-   `mongos.mongos_server_count` : Número de servidores MongoDB Mongos - `2` ~ `5`

#### Configuración de MongoDB Config (`config`)

-   `config.config_port` : Puerto TCP para acceder al servidor MongoDB Config - `10000` ~ `65535`
-   `config.config_product_code` : Código del producto del servidor MongoDB Config - `configProductCode`
-   `config.config_server_count` : Número de servidores MongoDB Config - `3` ~ `7`
