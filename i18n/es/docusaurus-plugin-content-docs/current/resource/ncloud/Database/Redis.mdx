## Descripción general del recurso

Cloud DB for Redis es un servicio de caché en la nube totalmente administrado que permite construir fácilmente Redis Cache con solo algunas configuraciones y clics.  
Funciona de manera estable mediante configuraciones optimizadas de Ncloud y proporciona recuperación automática en caso de fallos.

## Valores de configuración del recurso

#### Configuración básica

-   `server_name_prefix` : Nombre del servidor Redis (se permiten letras minúsculas/números/guion, debe comenzar con letra minúscula, terminar con letra minúscula o número, 3~15 caracteres)
-   `included_vpc_name` : Nombre del VPC que incluye Redis
-   `included_subnet_name` : Nombre del Subnet que incluye Redis
-   `redis_mode` : Modo de configuración de Redis - `CLUSTER`, `SIMPLE`
-   `engine_version_code` : Versión del motor Redis
-   `image_product_code` : Código del producto de la imagen del servidor Redis
-   `product_code` : Código del producto de especificación del servidor Redis
-   `target_config_group_name` : Nombre del Redis Config Group a conectar
-   `shard_count` : Número de shards a crear (basado en master node) - `3` ~ `10`
-   `shard_copy_count` : Número de réplicas por shard (número de slave nodes) - `0` ~ `4`
-   `enable_high_availability` : Uso de la función de alta disponibilidad - `true`, `false`
-   `enable_backup` : Uso de la función de backup (se activa automáticamente al usar alta disponibilidad) - `true`, `false`
-   `backup_file_retention_period` : Período de retención de archivos de backup (días) - `1` ~ `7`
-   `enable_automatic_backup` : Uso de backup automático - `true`, `false`
-   `backup_time` : Hora de backup definida por el usuario
-   `port` : Puerto de conexión Redis - `6379` ~ `20000`
