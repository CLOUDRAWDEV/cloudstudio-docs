## Descripción general del recurso

Mysql es un servicio de base de datos en la nube totalmente gestionado que utiliza la base de datos relacional MySQL. Permite construir bases de datos fácilmente, operarlas de forma estable y recuperarse automáticamente en caso de fallos.

## Valores de configuración del recurso

-   `server_name_prefix` : Nombre del servidor MySQL
-   `user_name` : ID de acceso del usuario de MySQL
-   `user_password` : Contraseña del usuario de MySQL
-   `host_ip` : Dirección IP del cliente que se desea conectar
-   `database_name` : Nombre de la base de datos que se desea crear
-   `image_product_code` : Código del producto de imagen del servidor MySQL que define la especificación de la instancia
-   `product_code` : Código del producto que determina la especificación del servidor de instancia MySQL a crear
-   `data_storage_type` : Tipo de almacenamiento de datos - `SSD`, `HDD`
-   `enable_high_availability` : Indica si se habilita la función de alta disponibilidad
-   `enable_backup` : Indica si se habilita la función de backup
-   `backup_file_retention_period` : Período de retención de archivos de backup, ejecutado diariamente y almacenado en almacenamiento separado - `1~30`
-   `enable_automatic_backup` : Indica si se habilita la automatización del backup
-   `port` : Puerto de conexión a MySQL - `3306~20000`
