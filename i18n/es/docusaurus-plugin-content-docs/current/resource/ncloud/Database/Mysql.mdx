## Descripción general del recurso

Mysql es un servicio de base de datos en la nube completamente gestionado basado en MySQL, que permite construir bases de datos de forma sencilla, operarlas de manera estable y recuperarlas automáticamente en caso de fallos.

## Valores de configuración del recurso

#### Configuración básica

-   `server_name_prefix` : Nombre del servidor MySQL (se permiten letras minúsculas, números y guiones; comienza con letra minúscula y termina con letra minúscula o número; 3~30 caracteres)
-   `users` : Información de configuración de usuarios (`password` : contraseña, `host_ip` : IP permitida `% | 1.1.1.1 | 1.1.1.%`, `authority` : permisos `DDL | CRUD | READ`)
-   `databases` : Lista de nombres de bases de datos a crear
-   `included_subnet_names` : Lista de nombres de Subnets que incluyen MySQL
-   `image_product_code` : Código del producto de imagen del servidor MySQL
-   `product_code` : Código del producto del servidor MySQL
-   `data_storage_type` : Tipo de almacenamiento de datos - `SSD`, `HDD`
-   `enable_high_availability` : Uso de alta disponibilidad - `true`, `false`
-   `enable_storage_encryption` : Uso de cifrado de almacenamiento - `true`, `false`
-   `enable_backup` : Uso de la función de respaldo - `true`, `false`
-   `backup_file_retention_period` : Periodo de retención de archivos de respaldo (en días) - `1` ~ `30`
-   `enable_automatic_backup` : Uso de respaldo automático - `true`, `false`
-   `backup_time` : Hora de respaldo definida por el usuario
-   `port` : Puerto de acceso MySQL - `3306` ~ `20000`
