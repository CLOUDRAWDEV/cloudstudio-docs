## Descripción general del recurso

Redis Config Group permite agrupar los servidores Redis creados y aplicar los mismos valores de configuración a todos los servidores del grupo para una gestión eficiente.

## Valores de configuración del recurso

#### Configuración básica

-   `redis_version` : Versión y modo del Redis config group -  
    `5.0.14-cluster`, `5.0.14-simple`, `7.0.13-cluster`, `7.0.13-simple`,  
    `7.0.15-cluster`, `7.0.15-simple`, `7.2.6-cluster`, `7.2.6-simple`,  
    `7.2.8-cluster`, `7.2.8-simple`
-   `description` : Descripción del Redis config group
