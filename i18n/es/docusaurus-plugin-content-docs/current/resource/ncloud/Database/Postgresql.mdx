## Descripción general del recurso

PostgreSQL es una **base de datos relacional de código abierto (RDBMS)**.  
En Ncloud se ofrece como un servicio de base de datos completamente gestionado que incluye alta disponibilidad (HA), automatización de respaldos y cifrado de almacenamiento.  
Permite construir fácilmente entornos PostgreSQL sin configuraciones de infraestructura complejas.

## Valores de configuración del recurso

#### Configuración básica

-   `server_name_prefix` : Nombre del servidor PostgreSQL (letras minúsculas, números y guiones permitidos; comienza con letra minúscula y termina con letra minúscula o número; 3~30 caracteres)
-   `included_vpc_name` : Nombre del VPC que incluye PostgreSQL
-   `included_subnet_name` : Nombre del Subnet que incluye PostgreSQL
-   `enable_high_availability` : Uso de alta disponibilidad - `true`, `false`
-   `user_name` : ID de acceso del usuario PostgreSQL
-   `user_password` : Contraseña del usuario PostgreSQL
-   `image_product_code` : Código del producto de imagen del servidor PostgreSQL
-   `product_code` : Código del producto del servidor PostgreSQL
-   `data_storage_type` : Tipo de almacenamiento de datos - `SSD`, `HDD`
-   `is_backup` : Uso de respaldo - `true`, `false`
-   `backup_file_retention_period` : Periodo de retención de archivos de respaldo (en días) - `1` ~ `30`
-   `enable_automatic_backup` : Uso de respaldo automático - `true`, `false`
-   `backup_time` : Hora de respaldo definida por el usuario
-   `port` : Puerto de acceso PostgreSQL
-   `client_cidr` : Rango de direcciones IP asignadas a clientes
-   `database_name` : Nombre de la base de datos inicial
-   `enable_storage_encryption` : Uso de cifrado de almacenamiento - `true`, `false`
