## Descripción general del recurso

Cloud DB for MSSQL permite construir y gestionar automáticamente bases de datos MSSQL de forma sencilla. Es un servicio de base de datos en la nube totalmente gestionado que funciona de manera estable gracias a configuraciones optimizadas por Naver y permite recuperación automática ante fallos.

## Valores de configuración del recurso

-   `enable_high_availability` : Indica si se habilita la función de alta disponibilidad
-   `user_name` : ID de acceso del usuario de MSSQL
-   `user_password` : Contraseña del usuario de MSSQL
-   `image_product_code` : Código del producto de la imagen para el servidor de instancia MSSQL a crear
-   `product_code` : Código del producto para la configuración del servidor de instancia MSSQL a crear
-   `data_storage_type` : Tipo de almacenamiento de datos - `SSD`, `HDD`
-   `backup_file_retention_period` : Período de retención de archivos de backup, realizado diariamente y almacenado en almacenamiento separado - `1~30`
-   `enable_automatic_backup` : Indica si se habilita la automatización de backups
-   `port` : Puerto de conexión MSSQL - `3306~20000`
-   `character_set_name` : Conjunto de caracteres de la base de datos. Se puede elegir entre combinaciones de coreano e inglés
