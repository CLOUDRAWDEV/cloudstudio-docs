## Descripción general del recurso

SourceDeploy es un servicio de automatización de despliegue que implementa y aplica automáticamente código nuevo o actualizado en los servidores. 
Con SourceDeploy, puedes automatizar el despliegue, ejecución y validación del código mediante comandos definidos por el usuario, minimizando al mismo tiempo el tiempo de inactividad del servicio durante el despliegue.
