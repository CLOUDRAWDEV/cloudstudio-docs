## Descripción general del recurso

SourceCommit es un servicio de repositorio Git privado que permite almacenar de forma segura código fuente y diversos archivos.  
Permite crear repositorios para gestionar eficientemente proyectos en equipo y almacenar datos como código fuente de manera sencilla.

## Valores de configuración del recurso

#### Configuración básica

-   `enable_file_safer` : Uso de File Safer - `true`, `false`
-   `description` : Descripción del repositorio - máximo 500 caracteres
