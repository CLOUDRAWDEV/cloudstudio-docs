## Descripción general del recurso

Servicio de firewall basado en filtrado por IP/Port que permite controlar y administrar el acceso de red entre servidores.

## Valores de configuración del recurso

#### Configuración básica

-   `included_vpc_name` : Nombre del VPC donde se creará el ACG
-   `acg_description` : Descripción del ACG

#### Reglas de entrada (`inbound_rule`)

-   `inbound_rule.protocol` : Protocolo del tráfico entrante - `TCP`, `UDP`, `ICMP`
-   `inbound_rule.rule_apply_method` : Método de aplicación de reglas - `ip_block`, `source_name`
-   `inbound_rule.ip_block` : Rango IP de destino del tráfico entrante (formato CIDR)
-   `inbound_rule.source_access_control_group_name` : Nombre del ACG origen
-   `inbound_rule.port_range` : Rango de puertos - `1` ~ `65535`
-   `inbound_rule.description` : Descripción de la regla de entrada

#### Reglas de salida (`outbound_rule`)

-   `outbound_rule.protocol` : Protocolo del tráfico saliente - `TCP`, `UDP`, `ICMP`
-   `outbound_rule.rule_apply_method` : Método de aplicación de reglas - `ip_block`, `source_name`
-   `outbound_rule.ip_block` : Rango IP de destino del tráfico saliente (formato CIDR)
-   `outbound_rule.source_access_control_group_name` : Nombre del ACG origen
-   `outbound_rule.port_range` : Rango de puertos - `1` ~ `65535`
-   `outbound_rule.description` : Descripción de la regla de salida
