## Descripción general del recurso

Recurso de cómputo que proporciona la flexibilidad de la virtualización sin necesidad de gestionar hardware físico. Permite crear servidores en entornos cloud de manera eficiente en términos de tiempo y costes, ideal para quienes no desean encargarse de la operación de infraestructura o necesitan recursos de servidor temporalmente en gran cantidad.

## Valores de configuración del recurso

-   `include_subnet_name` : Nombre del Subnet donde se ubicará el servidor
-   `server_image_product_code` : Código de la imagen del sistema operativo a utilizar
-   `server_product_code` : Código de la configuración de hardware del servidor
-   `login_key_name` : Nombre de la login_key a utilizar
-   `init_script` : Nombre del init_script a utilizar
-   `is_encrypted_base_block_storage_volume` : Indica si el almacenamiento base estará cifrado
-   `linked_network_interface_name` : Interfaz de red asignada al servidor
