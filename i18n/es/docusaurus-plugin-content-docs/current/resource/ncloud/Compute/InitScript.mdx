## Descripción general del recurso

Init Script es una función que permite ejecutar automáticamente scripts previamente definidos al crear un servidor. Es útil para crear múltiples servidores con el mismo propósito, generar servidores periódicamente con el mismo entorno o gestionar configuraciones iniciales según el uso.

## Valores de configuración del recurso

#### Configuración básica

-   `os_type` : Tipo de instancia del servidor a utilizar - `LNX`, `WND`
-   `content` : Contenido del script que se ejecutará automáticamente al crear el servidor
-   `description` : Descripción del Init script a crear
