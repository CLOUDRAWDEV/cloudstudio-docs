## Descripción general del recurso

Init Script es una funcionalidad que permite ejecutar automáticamente scripts predefinidos al momento de crear un servidor. Es útil en situaciones como la creación masiva de servidores con el mismo propósito, la generación periódica de servidores con entornos similares o la gestión del entorno inicial de los servidores según su uso.

## Valores de configuración del recurso

-   `OS_type` : Tipo de instancia de servidor a utilizar - `LNX`, `WND`
-   `Content` : Contenido del script que se ejecutará automáticamente al crear el servidor, por ejemplo: `#!/bin/bash yum install -y httpd && systemctl start httpd`
