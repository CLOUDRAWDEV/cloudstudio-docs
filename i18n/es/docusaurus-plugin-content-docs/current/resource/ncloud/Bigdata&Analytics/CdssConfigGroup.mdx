## Descripción general del recurso

Cdss Config Group es un servicio que gestiona los archivos de configuración de Kafka aplicados a un clúster CDSS.

## Recursos relacionados

### Recurso principal

-   [**Region**](https://docs.cstudio.app/es/docs/resource/ncloud/Base/Region)

### Recursos conectados

-   [**CdssCluster**](https://docs.cstudio.app/es/docs/resource/ncloud/Bigdata&Analytics/CdssCluster)

## Valores de configuración del recurso

#### Configuración básica

-   `kafka_version_code` : Versión de Kafka que se utilizará en el CDSS config group - `kafkaVersionCode`
-   `description` : Descripción del grupo de configuración
