## Descripción general del recurso

Servicio de almacenamiento conectado en red que permite a múltiples usuarios compartir datos entre varios servidores.

## Valores de configuración del recurso

#### Configuración básica

-   `volume_name_postfix` : Sufijo del nombre del volumen NAS (alfanumérico, 3 ~ 20 caracteres)
-   `volume_size` : Tamaño del volumen (en unidades de 100GB) - `500` ~ `10000`
-   `volume_allotment_protocol_type` : Tipo de protocolo - `NFS`, `CIFS`
-   `cifs_user_name` : ID de usuario para autenticación CIFS
-   `cifs_user_password` : Contraseña para autenticación CIFS
-   `linked_instances` : Lista de nombres de servidores a conectar
-   `is_encrypted` : Cifrado a nivel de volumen basado en AES-256
