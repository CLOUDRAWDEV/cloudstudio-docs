## Descripción general del recurso

Es un servicio de almacenamiento conectado a red que permite a múltiples usuarios compartir datos, conectando varios servidores a la red. Es adecuado para compartir datos entre múltiples usuarios mediante un espacio de almacenamiento conectado a través de red.

## Valores de configuración del recurso

-   `volume_name_postfix` : Nombre del volumen NAS, permite alfanuméricos, entre 3 ~ 20 caracteres
-   `volume_size` : Tamaño del volumen (100GB), en el rango de 500 ~ 10,000
-   `volume_allotment_protocol_type` : Tipo de protocolo, servidores montables: NFS-Linux/CIFS-Windows - `NFS`, `CIFS`
