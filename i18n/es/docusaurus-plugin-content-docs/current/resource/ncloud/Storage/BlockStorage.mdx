## Descripción general del recurso

Servicio de almacenamiento HDD o SSD adicional proporcionado además del almacenamiento base del servidor.  
Puede crearse rápidamente y conectarse de inmediato, y devolverse cuando ya no sea necesario.

## Valores de configuración del recurso

#### Configuración básica

-   `zone` : Zona física donde se ubicará el Block Storage - `KR-1`, `KR-2`
-   `linked_server_name` : Nombre del servidor al que se conectará el Block Storage
-   `storage_size` : Tamaño del almacenamiento (GB) - `10` ~ `16380`
-   `storage_disk_type` : Tipo de disco - `SSD`, `HDD`
