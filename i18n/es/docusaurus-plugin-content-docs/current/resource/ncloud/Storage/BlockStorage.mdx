## Descripción general del recurso

Es un servicio de almacenamiento HDD o SSD adicional al almacenamiento básico del servidor. Puede crearse en poco tiempo, conectarse inmediatamente al servidor y devolverse fácilmente si ya no es necesario.

## Recursos relacionados

### Recurso superior

-   [**Subnet**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Subnet)

### Recursos conectados

-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## Valores de configuración del recurso

-   `linked_server_name` : Nombre del servidor al que se conectará el block storage
-   `storage_size` : Tamaño del block storage (GB), en el rango de 10 ~ 2000
-   `storage_disk_type` : Tipo de disco del block storage, SSD o HDD - `SSD`, `HDD`
-   `snapshot_name` : Nombre del snapshot a crear
