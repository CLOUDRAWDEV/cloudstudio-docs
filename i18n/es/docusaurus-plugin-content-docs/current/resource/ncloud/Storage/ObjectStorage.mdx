## Descripción general del recurso

Object Storage es un servicio de almacenamiento de objetos que permite guardar y recuperar todo tipo de datos a través de Internet.  
Mediante políticas de acceso (rule) se pueden configurar permisos para buckets y objetos.

## Valores de configuración del recurso

#### Configuración básica

-   `rule` : Configuración de políticas de acceso de Object Storage - `private`, `public-read`, `public-read-write`, `authenticated-read`
