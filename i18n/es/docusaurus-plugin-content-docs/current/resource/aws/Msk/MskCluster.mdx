## Descripción general del recurso

Servicio de plataforma de mensajería distribuida que procesa transmisión de datos en tiempo real.

## Valores de configuración del recurso

#### Configuración básica

-   `cluster_type` : Tipo de clúster - `provisioned`, `serverless`
-   `kafka_version` : Versión de Apache Kafka utilizada por el clúster MSK
-   `kms_key_name` : Nombre de la clave KMS utilizada para el cifrado de datos
-   `unauthenticated_access` : Indica si se permite el acceso de usuarios no autenticados - `true`, `false`
-   `iam_role_based_authentication` : Indica si se permite la autenticación basada en roles IAM - `true`, `false`
-   `scram_authentication` : Indica si se permite la autenticación basada en SCRAM - `true`, `false`
-   `cloudwatch_metrics` : Alcance de recopilación de métricas en CloudWatch - `DEFAULT`, `PER_BROKER`, `PER_TOPIC_PER_BROKER`, `PER_TOPIC_PER_PARTITION`

#### Configuración de brokers (`broker`)

-   `broker.instance_type` : Tipo de instancia del broker
-   `broker.broker_count_per_zone` : Número de brokers por zona de disponibilidad(AZ)

#### Configuración de almacenamiento (`storage`)

-   `storage.ebs_volume_size` : Tamaño del volumen EBS asignado a cada broker (GB) - `1` ~ `16384`
-   `storage.enable_provisioned_throughput` : Habilita el throughput provisionado - `true`, `false`
-   `storage.provisioned_throughput_per_broker` : Throughput provisionado por broker (MiB/s) - mínimo `250`

#### Configuración de red (`network`)

-   `network.linked_vpc_name` : Nombre del VPC al que se conectará el clúster
-   `network.subnet_names` : Lista de nombres de Subnet asociadas al clúster MSK
-   `network.security_group_names` : Lista de nombres de Security Group aplicados al clúster MSK

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría - máximo 512 caracteres, `key`:`value`
