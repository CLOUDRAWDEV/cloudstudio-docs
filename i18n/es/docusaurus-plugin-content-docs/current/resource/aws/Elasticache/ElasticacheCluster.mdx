## Descripción general del recurso

ElastiCache Cluster de AWS es un almacén de datos en memoria basado en la nube que proporciona una solución de caché rápida y escalable. ElastiCache Cluster puede ejecutarse en modo clúster o modo de un solo nodo utilizando el motor Redis o Memcached. ElastiCache Cluster se utiliza para mejorar el rendimiento de las aplicaciones, permitiendo recuperar y procesar datos más rápidamente. ElastiCache Cluster proporciona funciones de copias de seguridad automáticas, recuperación, escalabilidad y monitoreo, lo que ayuda a los usuarios a almacenar datos con confianza.

## Valores de configuración del recurso

-   `engine` : Nombre del motor de caché que se utilizará en el clúster de caché – `redis`, `memcached`  
-   `engine_version` : Versión del motor de caché  
-   `port` : Número de puerto utilizado para conectar cada nodo de caché. Memcached usa el puerto 11211 y Redis usa el puerto 6379 por defecto  
-   `parameter_group_name` : Nombre del grupo de parámetros que se conectará al clúster de caché  
-   `node_type` : Clase de instancia utilizada en el clúster de caché  
-   `num_cache_nodes` : Número inicial de nodos de caché en el clúster – `1`~`40`  
-   `az_mode` : Indica si los nodos del grupo Memcached se crean en una única zona de disponibilidad o en varias zonas de disponibilidad de la región del clúster – `single-az`, `cross-az`  
-   `included_subnet_names` : Nombres de las subredes que se incluirán en el grupo de subredes para desplegar el ElastiCache Cluster  
-   `snapshot_retention_limit` : Período de retención de las instantáneas automáticas del clúster de caché antes de que ElastiCache las elimine
