## Descripción general del recurso

AWS Elasticache User es un usuario IAM necesario para utilizar un clúster de Elasticache.  
Elasticache User tiene permisos para crear, modificar y eliminar clústeres de Elasticache.  
Se crea en AWS IAM y generalmente se asigna a aplicaciones o desarrolladores que utilizan Elasticache.  
Elasticache User es responsable de la seguridad y el control de acceso al clúster de Elasticache, protegiendo así las aplicaciones y los datos.  
Puede utilizarse junto con otros recursos dentro de la cuenta AWS.

## Valores de configuración del recurso

#### Configuración básica

-   `user_id` : ID único de cada usuario
-   `access_string` : String que define los permisos aplicados al usuario
-   `authentication_type` : Método de autenticación para acceder al clúster - `iam`, `password`, `no-password-required`
-   `passwords` : Contraseñas del usuario (máximo 2)

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
