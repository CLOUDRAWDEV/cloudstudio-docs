## Descripción general del recurso

DxGateway permite acceder a VPCs en regiones de AWS a través de una conexión Direct Connect.

## Recursos relacionados

## Valores de configuración del recurso

#### Configuración básica

-   `side_asn` : ASN(Autonomous System Number) del lado de Amazon
