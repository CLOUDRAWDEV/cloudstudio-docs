## Valores de configuración del recurso

#### Configuración básica

-   `billing_mode` : Modo de facturación y gestión de capacidad de DynamoDB - `PROVISIONED`, `PAY_PER_REQUEST`
-   `read_capacity` : Unidades de lectura de la tabla DynamoDB
-   `write_capacity` : Unidades de escritura de la tabla DynamoDB
-   `hash_key` : Atributo utilizado como clave hash(partición)
-   `hash_key_type` : Tipo del atributo hash - `S`, `N`, `B`
-   `range_key` : Atributo utilizado como clave de rango(ordenación)
-   `range_key_type` : Tipo del atributo de rango - `S`, `N`, `B`
-   `point_in_time_recovery_enabled` : Habilita la recuperación a un punto en el tiempo - `true`, `false`

#### Cifrado del lado del servidor (`server_side_encryption`)

-   `server_side_encryption.encryption_enabled` : Habilita el cifrado de datos en reposo usando una CMK administrada por AWS - `true`, `false`
-   `server_side_encryption.kms_key_name` : Nombre de la CMK utilizada para el cifrado

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
