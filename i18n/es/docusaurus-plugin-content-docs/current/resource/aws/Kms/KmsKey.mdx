## Descripción general del recurso

AWS Key Management Service (AWS KMS) es un servicio de gestión de claves y cifrado adaptado para la nube. Las claves y funcionalidades de AWS KMS se utilizan en otros servicios de AWS, y los usuarios pueden usar estas claves y funcionalidades de AWS KMS para proteger los datos en sus propias aplicaciones que utilizan AWS.

## Valores de configuración del recurso

-   `description` : Descripción de la clave que aparece en la consola de AWS  
-   `key_usage` : Especifica cómo se utilizará la clave – `ENCRYPT_DECRYPT`  
-   `multi_region` : Configura si la clave KMS se utilizará en múltiples regiones – `true`, `false`  
-   `deletion_window_in_days` : Período de validez de las claves KMS  
-   `enable_key_rotation` : Activar la rotación de claves – `true`, `false`  
-   `grant_list` : Nombre de la concesión KMS  
    -   `operations` : Operaciones permitidas con la clave KMS – `Decrypt`, `Encrypt`, `GenerateDataKey`, `GenerateDataKeyWithoutPlaintext`, `ReEncryptFrom`, `ReEncryptTo`, `Sign`, `Verify`, `CreateGrant`, `RetireGrant`, `DescribeKey`
