## Descripción general del recurso

Amazon Simple Storage Service (Amazon S3) es un servicio de almacenamiento de objetos que ofrece escalabilidad líder en la industria, alta disponibilidad de datos, seguridad y rendimiento. Clientes de todos los tamaños e industrias utilizan Amazon S3 para almacenar y proteger cualquier cantidad de datos para casos de uso como data lakes, sitios web, aplicaciones móviles, copias de seguridad y restauración, archivado, aplicaciones empresariales, dispositivos IoT y análisis de big data. Amazon S3 proporciona funciones de administración que permiten optimizar, estructurar y configurar el acceso a los datos según necesidades empresariales, organizativas y de cumplimiento específicas.

## Valores de configuración del recurso

-   `versioning_status` : Estado de gestión de versiones del bucket - `Enabled`, `Suspended`
-   `logging_target_prefix` : Prefijo para todas las claves de objetos de registro
-   `sse_algorithm` : Algoritmo de cifrado del lado del servidor a utilizar - `aws:kms`, `AES256`
-   `kms_key_name` : Nombre de la clave maestra de AWS KMS utilizada para el cifrado SSE-KMS
-   `public_access_block` : Nombre del Public Access Block de S3

    -   `block_public_acls` : Indica si Amazon S3 debe bloquear los ACL públicos del bucket - `true`, `false`
    -   `block_public_policy` : Indica si Amazon S3 debe bloquear las políticas públicas del bucket - `true`, `false`
    -   `ignore_public_acls` : Indica si Amazon S3 debe ignorar los ACL públicos del bucket - `true`, `false`
    -   `restrict_public_buckets` : Indica si Amazon S3 debe restringir las políticas públicas del bucket - `true`, `false`

-   `ownership_control`
    -   `acl_enabled` : Habilita el uso de ACLs y propiedad de los objetos escritos en el bucket S3 - `true`, `false`
    -   `object_ownership` : Modo de propiedad de objetos escritos en el bucket S3 - `BucketOwnerEnforced`, `BucketOwnerPreferred`, `ObjectWriter`
