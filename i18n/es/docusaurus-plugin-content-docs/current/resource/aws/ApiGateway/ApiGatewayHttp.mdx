## Descripción del recurso

En API Gateway, HTTP API es un tipo de API Gateway diseñado para crear APIs simples y ligeras basadas en el protocolo HTTP.  
HTTP API es más simple y rentable que la API REST tradicional, y es especialmente adecuada para aplicaciones web sin servidor y microservicios simples.

## Valores de configuración del recurso

#### Configuración básica

#### Configuración de integración (`integration`)

-   `integration.integration_type` : Tipo de integración de API Gateway - `Http`, `Lambda`
-   `integration.integration_method` : Método HTTP de la integración de API Gateway - `ANY`, `GET`, `POST`, `PUT`, `PATCH`, `HEAD`, `OPTIONS`, `DELETE`
-   `integration.integration_uri` : URL completamente calificada para la integración HTTP
-   `integration.linked_lambda_name` : Nombre de la función Lambda para la integración de proxy Lambda

#### Configuración de ruta (`route`)

-   `route.route_method` : Método HTTP para la HTTP API - `ANY`, `GET`, `POST`, `PUT`, `PATCH`, `HEAD`, `OPTIONS`, `DELETE`
-   `route.route_path` : Ruta del recurso para la HTTP API
-   `route.target_integration` : Nombre de la integración de API Gateway que se conectará a la ruta

#### Configuración de despliegue (`deployment`)

-   `deployment.description` : Descripción del despliegue de API Gateway

#### Configuración de etapa (`stage`)

-   `stage.auto_deployment` : Habilitación del despliegue automático - `true`, `false`
-   `stage.deployment_name` : Nombre del despliegue de API Gateway a conectar
