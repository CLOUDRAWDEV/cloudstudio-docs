## Descripción general del recurso

Punto de acceso lógico que actúa como canal de comunicación en AWS SNS

## Valores de configuración del recurso

#### Configuración básica

-   `display_name` : Nombre visible del SNS Topic
-   `type` : Tipo de SNS Topic (`FIFO`, `Standard`)
-   `kms_key_name` : Nombre de la clave KMS a utilizar en el SNS Topic

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
