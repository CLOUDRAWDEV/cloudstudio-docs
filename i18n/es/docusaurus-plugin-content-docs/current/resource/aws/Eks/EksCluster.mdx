## Descripción general del recurso

Amazon Elastic Kubernetes Service(Amazon EKS) es un servicio administrado que permite ejecutar Kubernetes fácilmente en AWS sin necesidad de instalar ni operar clústeres de Kubernetes.

## Valores de configuración del recurso

#### Configuración básica

-   `version` : Versión de Kubernetes del EKS Cluster
-   `cluster_role_arn` : Rol IAM utilizado por el control plane de Kubernetes para administrar recursos AWS
-   `enabled_encryption` : Indica si se habilita el cifrado del clúster - `true`, `false`
-   `kms_key_name` : Nombre de la clave KMS utilizada por el clúster
-   `included_subnet_names` : Lista de nombres de Subnet incluidos en el Subnet Group del EKS Cluster
-   `linked_security_group_names` : Lista de nombres de grupos de seguridad asociados al EKS Cluster
-   `endpoint_access_type` : Tipo de acceso al endpoint del servidor API de EKS - `Public`, `Public and Private`, `Private`
-   `public_access_cidrs` : Lista de bloques CIDR permitidos para acceder al endpoint público de la API

#### Logging del Control Plane

-   `enabled_cluster_log_types` : Tipos de logs del Control Plane a habilitar - `api`, `authenticator`, `audit`, `scheduler`, `controllerManager`

#### Configuración de add-ons (`add_ons`)

-   `add_ons.kube_proxy_version` : Versión de kube-proxy que se ejecuta en cada nodo
-   `add_ons.vpc_cni_version` : Versión del plugin Amazon Vpc CNI
-   `add_ons.core_dns_version` : Versión de CoreDNS proporcionada por el clúster

#### Grupo de nodos (`node_group`)

-   `node_group.node_role_name` : Rol IAM utilizado por los nodos worker
-   `node_group.enabled_launch_template` : Indica si se utiliza un launch template - `true`, `false`
-   `node_group.launch_template_name` : Nombre del launch template utilizado por el grupo de nodos
-   `node_group.launch_template_version` : Versión del launch template
-   `node_group.min_node_count` : Número mínimo de nodos worker
-   `node_group.max_node_count` : Número máximo de nodos worker
-   `node_group.desired_node_count` : Número deseado de nodos worker
-   `node_group.max_node_unavailable` : Número máximo de nodos no disponibles durante una actualización
-   `node_group.max_percentage_unavailable` : Porcentaje máximo de nodos no disponibles durante una actualización
-   `node_group.disk_size` : Tamaño del volumen EBS adjunto a cada nodo(GB) - `1` ~ `16384`
