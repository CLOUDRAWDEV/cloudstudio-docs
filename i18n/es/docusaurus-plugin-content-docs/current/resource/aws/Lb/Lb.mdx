## Descripción general del recurso

Elastic Load Balancing distribuye automáticamente el tráfico de aplicaciones entrantes entre varios destinos, como instancias EC2. Además, monitorea el estado de los destinos registrados y enruta el tráfico solo a los destinos que están en buen estado. Elastic Load Balancing admite los siguientes tres tipos de balanceadores de carga: Application Load Balancer, Network Load Balancer y Classic Load Balancer.

## Valores de configuración del recurso

-   `load_balancer_type` : Tipo de ELB – `application`, `network`, `gateway`  
-   `internal` : Configura si el ELB se despliega como público o privado – `true`, `false`  
-   `included_vpc_name` : Nombre del VPC donde se creará el grupo de destinos  

-   `linked_subnet_names` : Lista de nombres de subredes a las que se conectará el LB  
-   `security_group_names` : Lista de nombres de grupos de seguridad asignados al LB, válido solo para el balanceador de carga tipo aplicación  

-   `drop_invalid_header` : Configura si los encabezados HTTP inválidos serán eliminados por el balanceador de carga o si serán dirigidos a los destinos – `true`, `false`  
-   `target_group` : Nombre del grupo de destino, se permiten caracteres alfanuméricos y hasta 32 caracteres, pero no puede comenzar ni terminar con un guion (-)  

    -   `protocol` : Protocolo para enrutar el tráfico a los destinos – `HTTP`, `HTTPS`, `TCP`, `TCP_UDP`, `TLS`, `UDP`  
    -   `port` : Puerto que recibe el tráfico  
    -   `instance_names` : Lista de nombres de las instancias de destino  

-   `listener` : Nombre del listener del ELB  
    -   `protocol` : Protocolo para enrutar el tráfico a los destinos – `HTTP`, `HTTPS`, `TCP`, `TCP_UDP`, `TLS`, `UDP`  
    -   `port` : Puerto que recibe el tráfico  
    -   `default_action_type` : Tipo de acción de enrutamiento – `forward`, `redirect`, `fixed-response`  
    -   `target_group_name` : Nombre del grupo de destino al que se enviará el tráfico
