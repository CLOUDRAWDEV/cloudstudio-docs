## Descripción general del recurso

Servicio que enruta solicitudes a uno o más destinos registrados, como instancias EC2, utilizando el protocolo y número de puerto especificados.

## Valores de configuración del recurso

#### Configuración básica

-   `target_type` : Tipo de destino del LB - `instance`, `ip`, `lambda`, `alb`
-   `protocol` : Protocolo utilizado para enrutar el tráfico - `HTTP`, `HTTPS`, `TCP`, `TCP_UDP`, `TLS`, `UDP`, `GENEVE`
-   `port` : Puerto que recibe el tráfico - `1` ~ `65535`
-   `included_vpc_name` : Nombre del VPC donde se creará el Target Group
-   `linked_instance_names` : Lista de nombres de instancias objetivo
-   `ips` : Lista de IPs objetivo
-   `linked_lambda_name` : Nombre de la Lambda objetivo
-   `linked_application_lb_name` : Nombre del ALB objetivo

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría - máximo 512 caracteres, `key`:`value`
