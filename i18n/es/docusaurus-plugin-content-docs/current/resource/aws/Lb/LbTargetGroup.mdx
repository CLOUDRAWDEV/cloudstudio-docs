## Descripción general del recurso

Servicio que enruta las solicitudes a uno o más destinos registrados, como instancias EC2, utilizando el protocolo y el número de puerto especificados.

## Valores de configuración del recurso

-   `target_type` : Tipo de destino del LB – `Instance`, `Ip`, `Lambda`, `Alb`  
-   `protocol` : Protocolo utilizado para enrutar el tráfico al destino – `HTTP`, `HTTPS`, `TCP`, `TCP_UDP`, `TLS`  
-   `port` : Puerto que recibe el tráfico – `1~65535`  
-   `included_vpc_name` : Nombre del VPC donde se creará el grupo de destinos  
-   `linked_instance_names` : Lista de nombres de las instancias de destino
