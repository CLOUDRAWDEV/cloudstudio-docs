## Descripción general del recurso

AWS WAF IP Set es un recurso que agrupa una o más direcciones IP o bloques CIDR para que puedan ser referenciados en reglas de Web ACL, y se utiliza para configurar políticas de permiso o bloqueo para rangos de IP específicos.

## Valores de configuración del recurso

#### Configuración básica

-   `scope` : Alcance donde se aplicará el IP Set - `REGIONAL`, `CLOUDFRONT`
-   `ip_address_version` : Versión de dirección IP - `IPV4`, `IPV6`
-   `addresses` : Lista de direcciones IP o bloques IP especificados en notación CIDR

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
