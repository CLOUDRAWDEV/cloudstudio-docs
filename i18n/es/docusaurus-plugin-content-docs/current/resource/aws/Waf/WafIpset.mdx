## Descripción general del recurso

AWS WAF IPSet es una lista de direcciones IP utilizada por el Web Application Firewall de Amazon Web Services. Permite a los usuarios crear y gestionar reglas de acceso basadas en direcciones IP definidas. Utilizando un IPSet, se puede permitir o bloquear solicitudes desde direcciones IP específicas, mejorando así la seguridad de la aplicación web.

## Valores de configuración del recurso

-   `scope` : Especifica si es para una distribución de AWS CloudFront o una aplicación regional - `REGIONAL`, `CLOUDFRONT`
-   `ip_address_version` : Especificar si se trata de IPV4 o IPV6 - `IPV4`, `IPV6`
-   `addresses` : Arreglo de cadenas que especifican una o más direcciones IP o bloques de direcciones IP en notación CIDR
