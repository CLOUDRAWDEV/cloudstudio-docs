## Descripción general del recurso

AWS WAF Web ACL es la capa superior de un conjunto de reglas que se aplica a aplicaciones web.  
Permite combinar múltiples Rule Groups y reglas, y definir el orden de procesamiento de solicitudes para aplicaciones web.  
Con ello, se refuerza la seguridad de las aplicaciones web y se pueden implementar acciones de permitir, bloquear o contabilizar solicitudes.

## Valores de configuración del recurso

#### Configuración básica

-   `scope` : Alcance de aplicación del Web ACL - `REGIONAL`, `CLOUDFRONT`
-   `cloudwatch_metrics_enabled` : Habilitar envío de métricas a CloudWatch - `true`, `false`
-   `metric_name` : Nombre de la métrica de CloudWatch; solo se permiten letras mayúsculas/minúsculas, guiones y guiones bajos, `1` ~ `128` caracteres
-   `sampled_requests_enabled` : Habilitar almacenamiento de muestras de solicitudes web que coincidan con las reglas - `true`, `false`

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
