## Descripción general del recurso

AWS WAF Web ACL (Access Control List) es la capa superior de un conjunto de reglas aplicadas a una aplicación web. Utilizando una Web ACL, puedes combinar múltiples Rule Groups y reglas individuales, y definir el orden en que se procesan las solicitudes hacia la aplicación web. Esto permite fortalecer la seguridad de la aplicación y aplicar acciones como permitir, bloquear o contar solicitudes.

## Valores de configuración del recurso

-   `scope` : Especifica si es para una distribución de AWS CloudFront o una aplicación regional - `REGIONAL`, `CLOUDFRONT`
-   `cloudwatch_metrics_enabled` : Indica si los recursos asociados deben enviar métricas a CloudWatch - `true`, `false`
-   `metric_name` : Nombre de la métrica en CloudWatch. Solo puede contener letras mayúsculas, minúsculas, guiones (-) y guiones bajos (_), con una longitud de 1 a 128 caracteres.
-   `sampled_requests_enabled` : Indica si AWS WAF debe almacenar muestras de solicitudes web que coincidan con las reglas - `true`, `false`
