## Descripción general del recurso

Cloud-init es una herramienta que inicializa y configura instancias de máquinas virtuales.

## Valores de configuración del recurso

#### Configuración básica

-   `gzip` : Indica si se utiliza compresión de datos - `true`, `false`

#### Configuración de partes (`part`)

-   `part.content_type` : Tipo de datos que se insertarán - `text/cloud-config`, `text/x-shellscript`, `text/cloud-boothook`, `multipart/mixed`, `text/cloud-config-archive`, `text/jinja`, `text/x-include-url`, `text/part-handler`
-   `part.content` : Contenido real de los datos que se insertarán

#### Etiquetas

-   `tag` : Etiqueta para clasificar el recurso por categoría
