## Descripción general del recurso

Permite crear un sistema de archivos, montarlo en instancias EC2, leer datos desde la instancia EC2, escribir en el sistema de archivos o compartir archivos.

## Valores de configuración del recurso

-   `create_token` : Nombre único utilizado como referencia para garantizar la creación del sistema de archivos Elastic  
-   `availability_zone_name` : Zona de disponibilidad de AWS donde se creará el sistema de archivos  
-   `enabled_encrypted` : Indica si el sistema de archivos estará cifrado – `false`, `true`  
-   `throughput_mode` : Modo de rendimiento del sistema de archivos – `provisioned`, `elastic`, `bursting`  
-   `provisioned_throughput_in_mibps` : Rendimiento aprovisionado para el sistema de archivos (en MiB/s) – `1-3414`  
-   `performance_mode` : Modo de rendimiento del sistema de archivos – `generalPurpose`, `maxIO`  
-   `lifecycle_policy` : Gestión del ciclo de vida para reducir costos automáticamente según los patrones de acceso  
    -   `transition_to_ia` : Tiempo necesario para trasladar archivos a la clase de almacenamiento IA – `1`, `7`, `14`, `30`, `60`  
    -   `ransition_to_primary_storage_class` : Política utilizada para devolver los archivos desde el almacenamiento de acceso al almacenamiento principal – `None`, `FirstAccess`  
-   `mount_target_subnets` : Lista de subredes donde se agregarán destinos de montaje  
-   `file_system_policy` : Política del sistema de archivos en formato JSON para EFS  
-   `enable_backup_policy` : Indica si se activa la política de backup – `false`, `true`  
-   `enable_replica` : Indica si se habilita la creación de réplica – `false`, `true`  
-   `access_point` : Punto de entrada específico para aplicaciones al sistema de archivos EFS, que facilita la gestión de acceso a conjuntos de datos compartidos  
    -   `root_directory_path` : Ruta del sistema de archivos EFS que se expone como directorio raíz a los clientes NFS que usan el punto de acceso  
    -   `posix_user_uid` : UID POSIX utilizado para todas las operaciones del sistema de archivos que usen este punto de acceso – hasta `4294967295`  
    -   `posix_user_gid` : GID POSIX utilizado para todas las operaciones del sistema de archivos que usen este punto de acceso – hasta `4294967295`  
    -   `posix_user_secondary_gids` : IDs de grupos POSIX secundarios usados en operaciones del sistema de archivos con este punto de acceso  
    -   `root_owner_uid` : UID POSIX aplicado al directorio raíz – hasta `4294967295`  
    -   `root_owner_gid` : GID POSIX aplicado al directorio raíz – hasta `4294967295`  
    -   `root_permissions` : Permisos POSIX aplicables al directorio raíz, expresados en formato octal (modo de bits del archivo)
