## Descripción general del recurso

Componente lógico de red que representa una tarjeta de red virtual dentro de un VPC.

## Valores de configuración del recurso

#### Configuración básica

-   `included_subnet_name` : Nombre del Subnet donde se encuentra la interfaz de red
-   `private_ips` : Lista de direcciones IP privadas
-   `linked_security_group_names` : Nombres de los Security Groups utilizados por la interfaz de red
-   `linked_eip_names` : Nombres de las Elastic Ip a utilizar

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
