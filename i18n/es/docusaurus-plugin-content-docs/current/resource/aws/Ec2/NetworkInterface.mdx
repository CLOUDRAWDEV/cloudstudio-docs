## Descripción general del recurso

Componente lógico de red que representa una tarjeta de red virtual dentro de un VPC.

## Recursos relacionados

### Recurso superior

-   [**Subnet**](https://docs.cstudio.app/docs/resource/aws/Vpc/Subnet)

### Recurso conectado

-   [**Eip**](https://docs.cstudio.app/docs/resource/aws/Ec2/Eip)

## Valores de configuración del recurso

-   `private_ips` : Lista de direcciones IP privadas  
-   `linked_security_group_names` : Nombres de los Security Groups a usar con la interfaz de red  
-   `linked_eip_names` : Nombre del Elastic IP a utilizar
