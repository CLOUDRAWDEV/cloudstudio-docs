## Descripción general del recurso

Amazon Elastic Compute Cloud(Amazon EC2) proporciona capacidad informática escalable en la nube de Amazon Web Services(AWS).  
Con Amazon EC2, no es necesario realizar inversiones iniciales en hardware, lo que permite desarrollar y desplegar aplicaciones más rápidamente.  
Amazon EC2 permite crear la cantidad deseada de servidores virtuales, configurar seguridad y redes, y gestionar el almacenamiento.  
Además, EC2 permite escalar hacia arriba o hacia abajo para manejar cambios en los requisitos o picos de uso, reduciendo la necesidad de predecir el tráfico.

## Valores de configuración del recurso

#### Configuración básica

-   `ami` : Imagen que contiene la información necesaria para ejecutar una instancia(proporcionada y compatible con AWS)
-   `instance_type` : Tipo de instancia EC2
-   `key_pair_name` : Nombre del Key Pair utilizado por la instancia EC2
-   `linked_network_interface_names` : Lista de nombres de interfaces de red utilizadas por la instancia EC2
-   `http_endpoint` : Configura si el servicio de metadatos está habilitado - `enabled`, `disabled`
-   `http_tokens` : Configura si se requieren tokens de sesión para el servicio de metadatos - `required`, `optional`
-   `cloudinit_config` : Contenido del script que se ejecutará automáticamente al crear el servidor

#### Volumen raíz (`root_volume`)

-   `root_volume.volume_type` : Tipo del Root Volume - `gp2`, `gp3`, `io1`, `io2`, `sc1`, `st1`, `standard`
-   `root_volume.volume_size` : Tamaño del Root Volume (GiB)
-   `root_volume.enabled_volume_encryption` : Indica si el Root Volume está cifrado - `true`, `false`

#### Dispositivo de bloques EBS (`ebs_block_device`)

-   `ebs_block_device.volume_type` : Tipo del EBS Volume - `gp2`, `gp3`, `io1`, `io2`, `sc1`, `st1`, `standard`
-   `ebs_block_device.volume_size` : Tamaño del EBS Volume (GiB)
-   `ebs_block_device.enabled_volume_encryption` : Indica si el EBS Volume está cifrado - `true`, `false`

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
