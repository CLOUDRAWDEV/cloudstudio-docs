## Descripción general del recurso

Servicio que permite compartir de forma segura recursos compatibles entre cuentas de AWS dentro de una organización o unidad organizativa (OU).

## Valores de configuración del recurso

#### Configuración básica

-   `shared_resource_types` : Lista de tipos de recursos a compartir
-   `transit_gateway_names` : Lista de nombres de Transit Gateway a compartir
-   `resource_arns` : Lista de ARN de recursos a compartir
-   `enabled_allow_external_principals` : Indica si se permite compartir con cuentas externas de AWS - `true`, `false`
-   `principal_arns` : Lista de ARN de entidades de seguridad o ID de cuentas AWS autorizadas

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría - máximo 512 caracteres, `key`:`value`
