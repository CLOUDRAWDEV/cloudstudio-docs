## Descripción general del recurso

Recurso que determina si se acepta o no un recurso compartido (Resource Share) proveniente de otra cuenta.

## Recursos relacionados

-   [**Region**](https://docs.cstudio.app/es/docs/resource/aws/Base/Region)

### Recursos conectados

-   [**ResourceShare**](https://docs.cstudio.app/es/docs/resource/aws/RAM/ResourceShare)

---

## Valores de configuración del recurso

#### Configuración básica

-   `is_manual` : Indica si el ARN del Resource Share se introduce manualmente - `true`, `false`
-   `linked_resource_share_name` : Nombre del Resource Share a conectar
-   `resource_share_arn` : ARN del Resource Share que se aceptará

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría - máximo 512 caracteres, `key`:`value`
