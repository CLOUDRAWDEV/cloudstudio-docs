## Descripción general del recurso

Con AWS Service Catalog, los administradores de TI pueden crear y gestionar portfolios de productos aprobados y distribuirlos a los usuarios finales, quienes pueden acceder a los productos necesarios a través de un portal personalizado. Los productos típicos incluyen servidores, bases de datos, sitios web o aplicaciones implementadas utilizando recursos de AWS (por ejemplo, instancias de Amazon EC2 o bases de datos de Amazon RDS). Se puede controlar qué usuarios tienen acceso a productos específicos para aplicar el cumplimiento de los estándares empresariales de la organización, gestionar el ciclo de vida de los productos y permitir que los usuarios los encuentren e inicien con confianza.
