## Descripción general del recurso

AWS Service Catalog permite a los administradores de TI crear y administrar portafolios de productos aprobados y ponerlos a disposición de los usuarios finales, quienes pueden acceder a los productos necesarios a través de un portal personalizado.  
Los productos típicos incluyen servidores, bases de datos, sitios web o aplicaciones implementadas mediante recursos de AWS (por ejemplo, instancias de Amazon EC2 o bases de datos de Amazon RDS).  
Al controlar qué usuarios pueden acceder a productos específicos, se puede aplicar el cumplimiento de los estándares empresariales de la organización, gestionar el ciclo de vida de los productos y permitir que los usuarios encuentren y lancen productos con confianza.

## Valores de configuración del recurso

#### Configuración básica

-   `description` : Descripción del portafolio
-   `provider_name` : Nombre de la persona u organización propietaria del portafolio

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
