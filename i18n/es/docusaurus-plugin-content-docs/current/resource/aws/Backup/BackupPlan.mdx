## Descripción general del recurso

Es una expresión de política que define cuándo y cómo se deben realizar las copias de seguridad de los recursos de AWS. Puedes asignar recursos a un Backup Plan, y AWS Backup realizará y conservará automáticamente copias de seguridad de esos recursos según el plan establecido.

## Valores de configuración del recurso

- `rule`
  - `rule_name` : Nombre de la regla de copia de seguridad
  - `backup_vault_name` : Nombre del contenedor lógico utilizado para almacenar las copias de seguridad
  - `frequency_type` : Frecuencia de la copia de seguridad
  - `frequency_hour` : Hora de inicio del plan de copia de seguridad – `1 o superior`
  - `start_time` : Hora de inicio del plan de copia de seguridad
  - `start_after_minutes` : Tiempo total de espera antes de iniciar la copia de seguridad – `60 o superior`
  - `complete_after_minutes` : Tiempo (en minutos) durante el cual AWS Backup intenta realizar una copia de seguridad antes de cancelar la tarea y devolver un error – `121 o superior`
  - `enabled_use_cold_storage` : Indica si se utiliza almacenamiento en frío
  - `warm_storage_retention_days` : Días después de los cuales el punto de restauración se mueve al almacenamiento en frío – `1 ~ 36410`
  - `cold_retention_days` : Días después de los cuales se elimina el punto de restauración – `91 ~ 36500`

- `resource_assignment`
  - `name`
  - `iam_role_arn` : ARN del rol IAM utilizado por AWS Backup para autenticar la restauración y copia de seguridad de los recursos objetivo
  - `enabled_contain_all` : Incluir todos los recursos – `false`, `true`
