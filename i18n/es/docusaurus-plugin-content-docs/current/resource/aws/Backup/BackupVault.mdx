## Descripción del recurso

En AWS Backup, Backup Vault es un contenedor que almacena y gestiona copias de seguridad.  
Al crear un Backup Vault, se debe especificar una clave de cifrado de AWS KMS para cifrar algunos de los respaldos almacenados en este vault.

## Valores de configuración del recurso

#### Configuración básica

-   `kms_key_name` : Clave de cifrado del lado del servidor utilizada para proteger los respaldos

#### Configuración de Vault Lock (`lock_configuration`)

-   `lock_configuration.enabled_lock` : Indica si se utiliza Vault Lock - `true`, `false`
-   `lock_configuration.lock_mode` : Tipo de Vault Lock - `Governance`, `Compliance`
-   `lock_configuration.min_retention_days` : Período mínimo de retención de puntos de recuperación - `1` ~ `36500`
-   `lock_configuration.max_retention_days` : Período máximo de retención de puntos de recuperación - `1` ~ `36500`
-   `lock_configuration.changeable_for_days` : Número de días antes de que el lock sea inmutable - `3` ~ `36500`

#### Etiquetas

-   `tag` : Etiqueta para clasificar el recurso por categoría - máximo 512 caracteres, `key`:`value`
