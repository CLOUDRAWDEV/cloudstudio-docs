## Descripción general del recurso

Servicio de endpoint para consultas DNS entrantes y salientes entre Amazon VPC y otros entornos.

## Valores de configuración del recurso

#### Configuración básica

-   `direction` : Dirección de las consultas DNS - `INBOUND`, `OUTBOUND`
-   `linked_vpc_name` : Nombre del VPC a conectar con el endpoint
-   `linked_security_group_names` : Lista de nombres de Security Group aplicados al endpoint
-   `ip_address.subnet_name` : Nombre del Subnet a utilizar
-   `ip_address.ip` : Dirección IP disponible dentro del Subnet

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
