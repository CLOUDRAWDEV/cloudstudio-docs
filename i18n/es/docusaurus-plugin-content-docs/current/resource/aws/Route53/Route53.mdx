## Descripción general del recurso

Amazon Route 53 es un servicio web de sistema de nombres de dominio (DNS) altamente disponible y escalable.

## Valores de configuración del recurso

#### Configuración básica

-   `routing_type` : Tipo de enrutamiento de la zona Route53 - `PRIVATE`, `PUBLIC`
-   `linked_vpc_names` : Lista de nombres de VPC a conectar con la zona Route53

#### Registro (`record`)

-   `record.type` : Tipo de registro - `A`, `AAAA`, `CAA`, `CNAME`, `DS`, `MX`, `NAPTR`, `NS`, `PTR`, `SOA`, `SPF`, `SRV`, `TXT`
-   `record.ttl` : TTL del registro
-   `record.records` : Lista de valores de cadena del registro

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
