## Descripción general del recurso

Amazon Route 53 es un servicio web de sistema de nombres de dominio (DNS) altamente disponible y escalable.

### Recurso superior

-   [**Base**](https://docs.cstudio.app/docs/resource/aws/Base/)

### Recurso conectado

-   [**Vpc**](https://docs.cstudio.app/docs/resource/aws/Vpc/Vpc)

## Valores de configuración del recurso

-   `linked_vpc_names` : Nombre del VPC que se conectará a la zona Route53
-   `record` : Nombre del Record que se creará en la zona Route53
    -   `type` : Tipo del Record - `A`, `CAA`, `CNAME`, `DS`, `NAPTR`, `NS`, `PTR`, `SOA`, `SPF`, `SRV`, `TXT`
    -   `ttl` : TTL del Record
    -   `records` : Lista de cadenas del Record
