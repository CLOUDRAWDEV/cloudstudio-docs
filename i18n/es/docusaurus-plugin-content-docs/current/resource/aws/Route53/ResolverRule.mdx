## Descripción general del recurso

Regla utilizada por el Resolver para reenviar consultas de un nombre de dominio específico a la red.

## Valores de configuración del recurso

#### Configuración básica

-   `rule_type` : Tipo de regla - `FORWARD`, `SYSTEM`
-   `domain_name` : Nombre de dominio al que se reenviarán las consultas DNS
-   `linked_vpc_names` : Lista de nombres de VPC que utilizan la regla
-   `linked_resolver_endpoint_name` : Nombre del endpoint de salida utilizado por el Resolver
-   `target_ip.ip` : Dirección IP de destino
-   `target_ip.port` : Puerto de la dirección IP de destino

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
