## Descripción general del recurso

Regla utilizada por el Resolver para enviar consultas de nombres de dominio específicos a través de la red.

### Recurso superior

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Recurso conectado

-   [**Vpc**](https://docs.cstudio.app/docs/resource/aws/Vpc/Vpc)
-   [**ResolverEndpoint**](https://docs.cstudio.app/docs/resource/aws/Route53/ResolverEndpoint)

## Valores de configuración del recurso

-   `rule_type` : Tipo de regla - `Forward`, `system`
-   `domain_name` : Nombre de dominio al que se envían las consultas DNS
-   `linked_vpc_names` : Nombres de los VPC que utilizan la regla
-   `linked_resolver_endpoint_name` : Nombre del endpoint outbound que utiliza el Resolver
-   `target_ip` : Dirección IP de destino
-   `target_ip.name`
-   `target_ip.ip` : Dirección IP del destino
-   `target_ip.port` : Puerto de la dirección IP de destino - `1~65535`
