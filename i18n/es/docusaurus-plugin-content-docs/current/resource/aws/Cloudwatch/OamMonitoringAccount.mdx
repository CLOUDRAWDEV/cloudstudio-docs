## Descripción general del recurso

AWS CloudWatch Oam Monitoring Account es un servicio que permite configurar una cuenta de monitoreo centralizada para supervisar aplicaciones de múltiples cuentas.

## Recursos relacionados

### Recursos conectados

-   [**OamSourceAccount**](https://docs.cstudio.app/es/docs/resource/aws/CloudWatch/OamSourceAccount)

---

## Valores de configuración del recurso

#### Configuración básica

-   `oam_source_accounts` : Lista de cuentas de origen con las que se compartirán los datos de monitoreo
-   `resource_types` : Tipos de datos que se compartirán desde las cuentas de origen

#### Configuración de etiquetas

-   `tag` : Lista de etiquetas para clasificar el recurso
