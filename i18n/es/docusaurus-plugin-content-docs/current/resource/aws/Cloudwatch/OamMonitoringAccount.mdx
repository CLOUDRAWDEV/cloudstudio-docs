## Descripción general del recurso

Las cuentas de monitoreo OAM de AWS CloudWatch permiten establecer una cuenta centralizada para supervisar aplicaciones distribuidas en múltiples cuentas.

## Recursos relacionados

### Recurso superior

-   [**Región**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Recurso conectado

-   [**Oam Source Account**](https://docs.cstudio.app/docs/resource/aws/Cloudwatch/OamSourceAccount)

## Valores de configuración del recurso

-   `oam_source_accounts` : Cuenta, ruta de organización o ID de organización con la que se compartirá la cuenta de monitoreo  
-   `resource_types` : Tipos de datos que se desean compartir  
    -   `AWS::Logs::LogGroup`  
    -   `AWS::Cloudwatch::LogGroup`  
    -   `AWS::Logs::LogGroup`  
    -   `AWS::Logs::LogGroup`
