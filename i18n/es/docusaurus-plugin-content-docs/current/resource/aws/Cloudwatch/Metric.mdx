## Descripción general del recurso

AWS CloudWatch Metric es un par nombre-valor que representa mediciones recopiladas de los recursos supervisados.  
Por ejemplo, se pueden recopilar métricas como el uso de CPU, el tráfico de red de entrada y salida desde instancias EC2.  
Estas mediciones se almacenan como CloudWatch Metric y se utilizan en dashboards, alarmas y análisis.  
Además, es posible crear métricas personalizadas para supervisar datos recopilados desde aplicaciones y servicios.  
CloudWatch Metric se integra con una amplia variedad de servicios proporcionados por AWS.

## Valores de configuración del recurso

#### Configuración básica

-   `comparison_operator` : Operador de comparación utilizado para comparar el valor del metric con el umbral
-   `evaluation_periods` : Número de períodos de evaluación para comparar el metric con el umbral
-   `metric_name` : Nombre del CloudWatch Metric asociado a la alarma
-   `namespace` : Namespace del CloudWatch Metric asociado a la alarma
-   `period` : Intervalo(en segundos) en el que se agregan los datos del metric
-   `statistic` : Tipo de estadística aplicada al metric - `Average`, `SampleCount`, `Sum`, `Minimum`, `Maximum`
-   `threshold` : Valor umbral que activa la alarma
-   `alarm_description` : Descripción de la alarma
-   `linked_sns_names` : Lista de SNS Topic vinculados para su uso con el metric
-   `alarm_sns_names` : Lista de SNS Topic a los que se enviarán notificaciones cuando el metric supere el umbral
-   `ok_sns_names` : Lista de SNS Topic a los que se enviarán notificaciones cuando el metric vuelva a un estado normal
-   `insufficient_data_sns_names` : Lista de SNS Topic a los que se enviarán notificaciones cuando haya datos insuficientes

#### Etiquetas

-   `tag` : Lista de etiquetas para clasificar el recurso
