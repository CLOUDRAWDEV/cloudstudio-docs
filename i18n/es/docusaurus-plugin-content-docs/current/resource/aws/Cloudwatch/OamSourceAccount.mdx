## Descripción general del recurso

Las cuentas fuente de AWS CloudWatch OAM configuran las cuentas que serán compartidas con la cuenta de monitoreo centralizada.

## Recursos relacionados

### Recurso superior

-   [**Región**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Recurso conectado

-   [**Oam Monitoring Account**](https://docs.cstudio.app/docs/resource/aws/Cloudwatch/OamMonitoringAccount)

## Valores de configuración del recurso

-   `is_manual` : Indica si el ARN de la cuenta fuente OAM se introducirá manualmente – `false`, `true`  
-   `linked_oam_monitoring_account_name` : Nombre de la cuenta de monitoreo OAM a la que se conectará  
-   `resource_types` : Tipos de datos que se desean compartir con la cuenta de monitoreo  
    -   `AWS::Logs::LogGroup`  
    -   `AWS::Cloudwatch::LogGroup`  
    -   `AWS::Logs::LogGroup`  
    -   `AWS::Logs::LogGroup`  
    -   `AWS::Logs::LogGroup`  
-   `label_template` : Etiqueta útil para identificar la cuenta fuente
