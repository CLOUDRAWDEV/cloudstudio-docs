## Descripción general del recurso

Un Virtual Private Gateway es el concentrador de VPN en el lado de Amazon para una conexión VPN Site-to-Site. Se crea un Virtual Private Gateway y se conecta al VPC donde se establecerá la conexión VPN Site-to-Site.

## Valores de configuración del recurso

-   `linked_vpc_name` : Nombre del VPC al que se asociará el VPN Gateway
-   `vpn_connection` : Nombre de la conexión VPN
    -   `linked_customer_gateway` : Nombre del Customer Gateway que se conectará al VPN Gateway
    -   `static_routes_only` : Indicar si se deben usar solo rutas estáticas para el enrutamiento entre gateways - `true`, `false`
