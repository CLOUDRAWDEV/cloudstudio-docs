## Descripción general del recurso

Virtual Private Gateway es el concentrador VPN del lado de Amazon para una conexión Site-to-Site VPN.  
Se crea un Virtual Private Gateway y se conecta al VPC donde se establecerá la conexión Site-to-Site VPN.

## Valores de configuración del recurso

#### Configuración básica

-   `linked_vpc_name` : Nombre del VPC al que se conectará el VPN Gateway
-   `dx_gateway` : Configuración de integración con Direct Connect Gateway
-   `dx_gateway.linked_dx_gateway` : Nombre del Dx Gateway a conectar
-   `dx_gateway.allowed_prefixes` : Lista de prefijos CIDR anunciados a la red on-premise

-   `tag` : Etiquetas para clasificar el recurso por categoría
