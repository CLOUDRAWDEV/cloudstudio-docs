## Descripción general del recurso

Servicio que permite conectarse de forma privada a servicios de AWS compatibles y servicios de endpoint de VPC.

## Valores de configuración del recurso

-   `service_range` : Categoría del servicio que utilizará el endpoint - `awsService`, `endpointService`
-   `aws_service_name` : Nombre del servicio de AWS que usará el endpoint
-   `vpc_endpoint_type` : Tipo de endpoint a utilizar para el servicio - `gateway`, `interface`, `gatewayloadbalancer`
-   `included_vpc_name` : Nombre del VPC en el que se creará el endpoint
-   `route_table_names` : Una o más ID de tablas de rutas a conectar con el endpoint
-   `policy_access` : Alcance de la política que controla el acceso al servicio del endpoint - `Full`, `Custom`
