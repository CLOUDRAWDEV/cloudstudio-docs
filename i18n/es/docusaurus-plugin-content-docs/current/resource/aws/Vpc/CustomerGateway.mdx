## Descripción general del recurso

AWS Transit Gateway conecta Amazon Virtual Private Cloud (VPC) con redes on-premise a través de un hub central. Esta conexión elimina relaciones de peering complejas y simplifica la red. Transit Gateway actúa como un router en la nube altamente escalable.

## Valores de configuración del recurso

-   `bgp_asn` : ASN (Número de Sistema Autónomo) del protocolo BGP (Border Gateway Protocol) del gateway
-   `ip_address` : Dirección IP de la interfaz externa con capacidad de enrutamiento por Internet del gateway
