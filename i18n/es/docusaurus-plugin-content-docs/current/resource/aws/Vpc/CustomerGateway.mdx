## Descripción general del recurso

AWS Transit Gateway conecta Amazon Virtual Private Cloud (VPC) y redes on-premises a través de un hub central.  
Esta conexión elimina relaciones de peering complejas y simplifica la arquitectura de red.  
Transit Gateway actúa como un router en la nube altamente escalable.

## Valores de configuración del recurso

#### Configuración básica

-   `bgp_asn` : Valor ASN BGP del gateway - `1` ~ `2147483647`
-   `ip_address` : Dirección IP pública fija de la interfaz externa del gateway
-   `private_certificate_arn` : ARN del certificado de AWS Private Certificate Manager

#### Configuración de conexión VPN (`vpn_connection`)

-   `vpn_connection.resource_type` : Tipo de recurso a conectar con el Customer Gateway - `none`, `transit_gateway`, `vpn_gateway`
-   `vpn_connection.linked_resource_name` : Nombre del recurso a conectar
-   `vpn_connection.static_routes_only` : Indica si solo se utilizan rutas estáticas - `true`, `false`
-   `vpn_connection.outside_ip_address_type` : Tipo de dirección IP externa - `PublicIpv4`, `PrivateIpv4`
-   `vpn_connection.dx_gateway_name` : Nombre del Transit Gateway Attachment para VPN con IP privada
