## Descripción general del recurso

Servicio que se utiliza para conectar un VPC con una red on-premise.

## Valores de configuración del recurso

#### Configuración básica

-   `linked_transit_gateway_name` : Nombre del Transit Gateway a conectar con el VPC
-   `is_manual` : Indica si se ingresará manualmente el ID del VPC a conectar - `true`, `false`
-   `linked_vpc_name` : Nombre del VPC a conectar al Transit Gateway
-   `subnet_names` : Lista de nombres de Subnet a conectar al Transit Gateway

#### Configuración de conexión manual (`manual`)

-   `vpc_id` : ID del VPC a conectar al Transit Gateway
-   `subnet_ids` : Lista de IDs de Subnet dentro del VPC especificado por `vpc_id`

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
