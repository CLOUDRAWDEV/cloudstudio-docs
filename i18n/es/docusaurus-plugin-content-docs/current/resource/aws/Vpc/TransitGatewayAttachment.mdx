## Descripción general del recurso

Servicio que se puede utilizar para conectar un VPC con una red on-premise.

## Recursos relacionados

-   [**TransitGatewayAttachmentAccepter**](https://docs.cstudio.app/docs/resource/aws/Vpc/TransitGatewayAttachmentAccepter)


## Valores de configuración del recurso

-   `linked_tranit_gateway_name` : Nombre del Transit Gateway conectado al VPC
-   `is_manual` : Indica si se debe introducir manualmente el ID del VPC a conectar - `false`, `true`
-   `linked_vpc_name` : Nombre del VPC que se conectará al Transit Gateway
-   `subnet_names` : Nombres de las Subnet que se conectarán al Transit Gateway
