## Descripción general del recurso

Recurso que determina si se permite compartir recursos desde otra cuenta.

## Recursos relacionados

### Recurso superior

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Recurso conectado

-   [**TransitGatewayAttachment**](https://docs.cstudio.app/docs/resource/aws/Vpc/TransitGatewayAttachment)

## Valores de configuración del recurso

-   `is_manual` : Indica si se debe introducir manualmente el ID del Transit Gateway Attachment a conectar - `false`, `true`
-   `linked_transit_gateway_attachment_name` : Nombre del otro Transit Gateway Attachment al que se permitirá el uso compartido
