## Descripción general del recurso

Recurso que determina si se acepta o no el uso compartido de recursos de otra cuenta.

## Recursos relacionados

### Recurso principal

-   [**Region**](https://docs.cstudio.app/es/docs/resource/aws/Base/Region)

### Recursos conectados

-   [**TransitGatewayAttachment**](https://docs.cstudio.app/es/docs/resource/aws/Vpc/TransitGatewayAttachment)

## Valores de configuración del recurso

#### Configuración básica

-   `is_manual` : Indica si se ingresará manualmente el ID del Transit Gateway Attachment - `true`, `false`
-   `transit_gateway_attachment_id` : ID del Transit Gateway Attachment que se permitirá compartir
-   `linked_transit_gateway_attachment_name` : Nombre del Transit Gateway Attachment que se permitirá compartir

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
