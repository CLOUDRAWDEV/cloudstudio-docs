## Descripción general del recurso

Una Subnet es un rango de direcciones IP dentro de un VPC. Puedes lanzar recursos de AWS como instancias EC2 dentro de una Subnet específica.

## Valores de configuración del recurso

-   `included_vpc_name` : Nombre del VPC donde se desplegará la Subnet
-   `cidr_block` : Rango de direcciones IP (CIDR) de la Subnet
-   `availability_zone` : Zona de disponibilidad donde se desplegará la Subnet
-   `pip_enable` : Asignación de IP pública
