## Descripción general del recurso

Subnet es un rango de direcciones IP dentro de un VPC.  
En una Subnet se pueden crear recursos de AWS como instancias EC2.

## Valores de configuración del recurso

#### Configuración básica

-   `included_vpc_name` : Nombre del VPC donde se desplegará la Subnet
-   `cidr_block` : Rango IP de la Subnet (CIDR)
-   `availability_zone` : Zona de disponibilidad donde se desplegará la Subnet
-   `pip_enable` : Asignación automática de IP pública - `true`, `false`

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
