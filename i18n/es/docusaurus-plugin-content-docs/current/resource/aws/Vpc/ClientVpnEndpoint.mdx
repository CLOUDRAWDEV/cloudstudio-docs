## Descripción general del recurso

Servicio VPN gestionado basado en cliente que permite el acceso seguro a recursos en AWS y redes on-premise.

## Valores de configuración del recurso

-   `description` : Breve descripción del endpoint Client VPN
-   `client_cidr_block` : Rango de direcciones IP asignadas a los clientes
-   `serer_acm_certificate_name` : Nombre del certificado del servidor
-   `authentication` : Método de autenticación a utilizar
-   `authentication.option_types` : Método de autenticación - `certificate-authentication`, `directory-service-authentication`, `federated-authentication`
-   `connection_logging.enalbed` : Activar detalles de logs de conexión de cliente - `false`, `true`
-   `transport_protocol` : Protocolo de transporte utilizado en la sesión TLS - `tcp`, `udp`
-   `enabled_split_tunnel` : Activar túnel dividido - `false`, `true`
-   `vpn_port` : Puerto VPN
-   `enabled_self_service_portal` : Activar portal de autoservicio - `false`, `true`
-   `session_timeout_hours` : Tiempo de espera de la sesión - `8`, `10`, `12`, `24`
-   `included_vpc_name` : Nombre del VPC
-   `linked_security_group_names` : Nombres de los grupos de seguridad aplicados al endpoint
-   `linked_subnet_names` : Nombres de los Subnet a conectar
