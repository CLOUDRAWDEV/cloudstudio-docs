## Descripción general del recurso

NAT Gateway es un servicio de NAT (Network Address Translation).  
Puede utilizarse para permitir que las instancias en una subred privada se conecten a servicios fuera del VPC, mientras se evita que los servicios externos inicien conexiones hacia dichas instancias.

## Valores de configuración del recurso

#### Configuración básica

-   `included_subnet_name` : Nombre de la Subnet a la que se conectará el NAT Gateway
-   `connectivity_type` : Tipo de conectividad del NAT Gateway - `public`, `private`
-   `linked_eip_name` : Nombre del Elastic IP a conectar

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
