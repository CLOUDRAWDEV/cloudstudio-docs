## Descripción general del recurso

Un NAT Gateway es un servicio de traducción de direcciones de red (NAT). Permite que las instancias en subredes privadas se conecten a servicios fuera del VPC, mientras evita que esos servicios externos inicien conexiones hacia las instancias internas.

## Valores de configuración del recurso

-   `included_subnet_name` : Nombre de la subred a la que se conectará el NAT Gateway
-   `connectivity_type` : Tipo de conectividad del NAT Gateway - `public`, `private`
-   `eip_name` : Nombre del EIP
