## Descripción general del recurso

Security Group controla el tráfico que puede entrar y salir de los recursos asociados.  
Por ejemplo, cuando se asocia un Security Group a una instancia EC2, controla el tráfico entrante y saliente de dicha instancia.  
Un Security Group solo puede asociarse a recursos dentro del VPC donde fue creado.

Al crear un VPC, este incluye un Security Group predeterminado.  
Se pueden crear Security Groups adicionales para cada VPC.  
El uso de Security Group no genera cargos adicionales.

## Valores de configuración del recurso

#### Configuración básica

-   `description` : Descripción del Security Group
-   `included_vpc_name` : Nombre del VPC al que pertenece el Security Group

#### Reglas de entrada (`ingress`)

-   `ingress.rule_name` : Nombre de la regla Ingress
-   `ingress.description` : Descripción de la regla Ingress
-   `ingress.from_port` : Puerto inicial permitido
-   `ingress.to_port` : Puerto final permitido
-   `ingress.protocol` : Protocolo - `tcp`, `udp`, `icmp`, `all`
-   `ingress.cidr_block` : Bloque CIDR de origen permitido

#### Reglas de salida (`egress`)

-   `egress.rule_name` : Nombre de la regla Egress
-   `egress.description` : Descripción de la regla Egress
-   `egress.from_port` : Puerto inicial permitido
-   `egress.to_port` : Puerto final permitido
-   `egress.protocol` : Protocolo - `tcp`, `udp`, `icmp`, `icmpv6`, `all`
-   `egress.cidr_block` : Bloque CIDR de destino permitido

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
