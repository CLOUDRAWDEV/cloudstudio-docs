## Descripción general del recurso

Flow Log de VPC es una función que permite capturar información sobre el tráfico IP que entra y sale de las interfaces de red dentro de una VPC. Los datos del Flow Log pueden publicarse en Amazon CloudWatch Logs, Amazon S3 o Amazon Kinesis Data Firehose. Al crear un Flow Log, se puede buscar y visualizar registros del flujo en el grupo de logs, bucket o flujo de transmisión configurado.

## Valores de configuración del recurso

-   `linked_log_destination_type` : Tipo de almacenamiento donde se guardarán los datos del log
-   `linked_log_destination_name` : Nombre del almacenamiento donde se guardarán los datos del log
-   `traffic_type` : Tipo de tráfico que se va a capturar
-   `included_vpc_name` : Nombre del VPC al que se conectará el Flow Log
