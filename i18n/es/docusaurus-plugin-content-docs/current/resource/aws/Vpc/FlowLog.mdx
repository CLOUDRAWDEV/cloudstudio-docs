## Descripción general del recurso

Los VPC Flow Logs permiten recopilar información sobre el tráfico IP enviado y recibido por las interfaces de red dentro de un VPC.  
Los datos de Flow Logs pueden publicarse en Amazon CloudWatch Logs, Amazon S3 o Amazon Kinesis Data Firehose.  
Una vez creados, es posible buscar y visualizar los registros de flujo en el grupo de logs, bucket o stream configurado.

## Valores de configuración del recurso

#### Configuración básica

-   `linked_log_destination_type` : Tipo de destino donde se almacenan los logs (S3, CloudWatch Logs)
-   `linked_log_destination_name` : Nombre del destino donde se almacenan los logs
-   `traffic_type` : Tipo de tráfico a recopilar - `ALL`, `ACCEPT`, `REJECT`
-   `traffic_type` : `ALL`
-   `included_vpc_name` : Nombre del VPC al que se conecta el Flow Log

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
