## Descripción general del recurso

Amazon Virtual Private Cloud (Amazon VPC) permite controlar completamente el entorno de red virtual, incluyendo la colocación de recursos, conectividad y seguridad.  
Comience configurando un VPC desde la consola de servicios de AWS.  
Luego, agregue recursos como instancias de Amazon Elastic Compute Cloud (EC2) y Amazon Relational Database Service (RDS) al VPC.  
Finalmente, defina cómo los VPC se comunican entre sí a nivel de cuenta, zona de disponibilidad o región de AWS.  
En el ejemplo siguiente, el tráfico de red se comparte entre dos VPC dentro de cada región.

## Valores de configuración del recurso

#### Configuración básica

-   `cidr_block` : Rango IP del VPC (CIDR)
-   `enabled_dns_support` : Habilitar resolución DNS - `true`, `false`
-   `enabled_dns_hostnames` : Habilitar asignación de nombres de host DNS - `true`, `false`

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
