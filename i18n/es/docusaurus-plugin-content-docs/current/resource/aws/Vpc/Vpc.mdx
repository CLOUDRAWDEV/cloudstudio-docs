## Descripción general del recurso

Amazon Virtual Private Cloud (Amazon VPC) te permite tener un control total sobre tu entorno de red virtual, incluida la colocación, conectividad y seguridad de los recursos. Comienza configurando un VPC desde la consola de servicios de AWS. Luego, añade recursos como instancias de Amazon Elastic Compute Cloud (EC2) e instancias de Amazon Relational Database Service (RDS) dentro del VPC. Finalmente, define cómo se comunican los VPC dentro de una misma cuenta, zona de disponibilidad o región de AWS. En el siguiente ejemplo, el tráfico de red se comparte entre dos VPC dentro de la misma región.
