## Descripción general del recurso

Route Table de AWS VPC (Virtual Private Cloud) es un recurso de AWS que define a qué destino se debe enviar el tráfico de las subredes dentro de un VPC.  
Todas las subredes de un VPC están asociadas a una o más tablas de ruteo, y estas tablas especifican reglas de ruteo hacia destinos como Internet Gateway, NAT Gateway, VPC Endpoint o conexiones VPN.  
La tabla de ruteo reenvía el tráfico según el orden de las reglas, y todo el tráfico generado desde una subred se envía a su destino a través de la tabla de ruteo asociada.  
De esta manera, las subredes dentro del VPC pueden comunicarse de forma segura con Internet u otros VPC.

## Valores de configuración del recurso

#### Configuración básica

-   `included_vpc_name` : Nombre del VPC al que pertenece la Route Table
-   `subnet_names` : Lista de nombres de Subnet a asociar con la Route Table

#### Rutas (`linked_route`)

-   `linked_route.cidr_block` : Bloque CIDR del destino de ruteo
-   `linked_route.resource_type` : Tipo de recurso de destino - `internet_gateway`, `ec2_instance`, `nat_gateway`, `transit_gateway`, `vpc_peering`
-   `linked_route.linked_resource_name` : Nombre del recurso de destino

#### Etiquetas

-   `tag` : Etiquetas para clasificar el recurso por categoría
