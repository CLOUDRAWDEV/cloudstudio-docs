## Descripción general del recurso

La política de AWS Network Firewall define el comportamiento de monitoreo y protección para el Network Firewall.

## Valores de configuración del recurso

-   `description` : Descripción de la política del firewall
-   `stream_exception_policy` : Cómo manejar tráfico con flujos interrumpidos - `drop`, `continue`, `reject`
-   `stateless_default_action` : Configuración de la acción predeterminada sin estado
    -   `enabled_fragment_packet_action` : Activar acción para paquetes fragmentados - `false`, `true`
    -   `default_action` : Lista de acciones a realizar si el paquete no coincide con ninguna regla sin estado de la política - `aws:drop`, `aws:pass`, `aws:forward_to_sfe`
-   `stateless_rule_group_names` : Grupos de reglas sin estado usados en la política
-   `stateful_default_action` : Configuración de la acción predeterminada con estado
    -   `rule_evaluation_order` : Método para gestionar el orden de evaluación de reglas con estado
    -   `default_actions` : Lista de acciones si el paquete no coincide con ninguna regla con estado - `aws:drop_strict`, `aws:drop_established`, `aws:alert_strict`, `aws:alert_established`
-   `strict_stateful_rule_group_names` : Grupos de reglas con estado usados cuando no hay coincidencias con reglas previas
-   `rule_variables` : Variables que pueden usarse para sobrescribir configuraciones de datos predeterminadas en la política
-   `encryption_configuration.
    -   `enabled_custom_configuration` : Cifrado de datos usando claves administradas por AWS - `false`, `true`
