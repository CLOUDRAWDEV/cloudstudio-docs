## Descripción general del recurso

Virtual Private Cloud (VPC) es una red virtual dedicada a la cuenta del usuario en AWS.  
Un VPC está lógicamente aislado de otras redes virtuales en la nube de AWS.  
Los recursos de AWS (por ejemplo, instancias Amazon EC2) pueden iniciarse dentro de un VPC.

Una conexión de VPC Peering es una conexión de red entre dos VPC que permite enrutar tráfico utilizando direcciones IPv4 privadas o direcciones IPv6.  
Permite que las instancias de VPC se comuniquen entre sí como si pertenecieran a la misma red.  
Se puede crear una conexión de VPC Peering con el propio VPC o con un VPC de otra cuenta de AWS.  
Los VPC pueden estar en diferentes regiones (también conocido como VPC Peering entre regiones).

## Valores de configuración del recurso

#### Configuración básica

-   `linked_vpc_name_01` : Nombre del VPC que solicita la conexión de Peering
-   `linked_vpc_name_02` : Nombre del VPC destino de la conexión de Peering
-   `auto_accept` : Aceptación automática de la conexión de Peering - `true`, `false`
