## Descripción general del recurso

Virtual Private Cloud (VPC) es una red virtual dedicada a la cuenta de AWS del usuario. El VPC está lógicamente aislado de otras redes virtuales dentro de la nube de AWS. Puedes lanzar recursos de AWS (como instancias de Amazon EC2) dentro del VPC.
Una conexión de VPC Peering es una conexión de red entre dos VPC que permite enrutar tráfico utilizando direcciones IPv4 o IPv6 privadas. Las instancias en los VPC pueden comunicarse entre sí como si pertenecieran a la misma red. Puedes establecer una conexión de VPC Peering entre tu propio VPC o el VPC de otra cuenta de AWS. Los VPC pueden estar en diferentes regiones (también conocido como VPC Peering entre regiones).

## Valores de configuración del recurso

-   `linked_vpc_name_01` : Nombre del primer VPC a emparejar
-   `linked_vpc_name_02` : Nombre del segundo VPC a emparejar
-   `auto_accept` : Aceptación automática de la conexión de Peering - `true`, `false`
