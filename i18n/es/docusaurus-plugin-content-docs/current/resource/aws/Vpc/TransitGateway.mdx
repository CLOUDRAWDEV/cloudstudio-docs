## Descripción general del recurso

Transit Gateway es un hub de transporte de red que se puede utilizar para interconectar VPC (Virtual Private Cloud) y redes on-premise. A medida que la infraestructura en la nube se expande globalmente, el emparejamiento entre regiones permite conectar Transit Gateway a través de la infraestructura global de AWS. Los datos se cifran automáticamente y no se transmiten a través de Internet público.

## Valores de configuración del recurso

-   `dns_support` : Activar resolución DNS para VPC conectadas - `enable`, `disable`
-   `vpn_ecmp_support` : Soporte de enrutamiento ECMP (camino múltiple) para VPN conectadas - `enable`, `disable`
-   `default_route_table_association` : Asociar automáticamente attachments con la tabla de rutas predeterminada - `enable`, `disable`
-   `default_route_table_propagation` : Propagar automáticamente attachments a la tabla de rutas predeterminada - `enable`, `disable`
-   `multicast_support` : Activar la creación de dominio multicast - `enable`, `disable`
-   `transit_gateway_cidr_blocks` : Bloques CIDR del Transit Gateway
-   `vpc_attachment`
