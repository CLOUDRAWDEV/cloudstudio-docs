## Descripción general del recurso

Internet Gateway es un componente redundante de VPC altamente disponible y escalable horizontalmente que permite la comunicación entre un VPC e Internet.  
Admite tráfico IPv4 e IPv6 y no introduce riesgos de disponibilidad ni limitaciones de ancho de banda en el tráfico de red.

Cuando un recurso tiene una dirección IPv4 pública o una dirección IPv6, el uso de un Internet Gateway permite que los recursos de una subred pública (por ejemplo, instancias EC2) se conecten a Internet.  
Del mismo modo, los recursos en Internet pueden iniciar conexiones hacia los recursos de la subred utilizando direcciones IPv4 públicas o IPv6.  
Por ejemplo, mediante un Internet Gateway es posible conectarse desde un equipo local a una instancia EC2 en AWS.

Internet Gateway proporciona un destino para el tráfico enrutable hacia Internet en las tablas de enrutamiento del VPC.  
En el caso de comunicación IPv4, Internet Gateway también realiza Network Address Translation (NAT).  
Para la comunicación que utiliza IPv6, no se requiere NAT ya que las direcciones IPv6 son públicas.
