## Descripción general del recurso

Amazon Elastic Container Registry (Amazon ECR) es un servicio de registro de imágenes de contenedores gestionado por AWS, seguro, escalable y confiable. Amazon ECR admite repositorios privados con políticas basadas en recursos mediante AWS IAM, lo que permite que usuarios específicos o instancias de Amazon EC2 accedan a repositorios e imágenes de contenedores. Puedes usar la CLI que prefieras para enviar (push), obtener (pull) y administrar imágenes Docker, imágenes OCI (Open Container Initiative) y artefactos compatibles con OCI.

## Valores de configuración del recurso

-   `image_tag_mutability` : Configuración de mutabilidad de etiquetas en el repositorio – `IMMUTABLE`, `MUTABLE`  
-   `scan_on_push` : Indica si las imágenes serán escaneadas al ser subidas al repositorio – `true`, `false`  
-   `encryption_type` : Tipo de cifrado a usar en el repositorio – `KMS`, `AES256`  
-   `kms_key_name` : Nombre del ARN de la clave KMS a utilizar  
-   `target_principal_arn` : ARN del recurso al cual aplicar la política
