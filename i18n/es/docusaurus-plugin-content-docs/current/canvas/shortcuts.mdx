Estos son los `atajos de teclado` que puedes usar en el canvas de Cloud Studio.

| Atajo                         | Descripción             |
| ---------------------------- | ----------------------- |
| Ctrl + rueda del ratón       | Acercar y alejar vista  |
| Espacio + clic + arrastrar   | Mover la vista          |
| Delete                       | Eliminar                |
| Ctrl + Z                     | Deshacer                |
| Ctrl + C                     | Copiar                  |
| Ctrl + V                     | Pegar                   |
