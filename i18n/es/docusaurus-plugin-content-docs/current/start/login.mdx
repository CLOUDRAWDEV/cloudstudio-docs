No es posible acceder a Cloud Studio sin una cuenta. Antes de iniciar sesión, debe completar el proceso de **registro**.

🔗  [Enlace para registrarse en Cloud Studio](https://cstudio.app/signup)

✏️  <Link to="/docs/start/sign-up">Cómo registrarse</Link>

Una vez completado el registro, ingrese a la [página de inicio de sesión de Cloud Studio](https://cstudio.app/signin).

<p>&nbsp;</p>

1. Verifique el ID y la contraseña temporal enviados a su correo electrónico registrado durante el proceso de registro.

<div className={styles.imgWrap}>
    <img width="100%" src={login01} width="450px" alt="imagen" />
</div>

<p>&nbsp;</p>

2. En la página de inicio de sesión de Cloud Studio, ingrese su **ID y contraseña temporal**.

<img width="100%" src={login02} alt="imagen" />

<p>&nbsp;</p>

3. Configure una nueva contraseña.

<img width="100%" src={otp06} alt="imagen otp" />

<p>&nbsp;</p>

:::info
La primera vez que inicie sesión, deberá restablecer su contraseña.

:::
