El lienzo es el <highlight color="#206FD6">servicio principal de Cloud Studio</highlight> que permite dibujar infraestructura en la nube, gestionar versiones y desplegarla, utilizando recursos mediante `Drag & Drop`. 
La infraestructura construida en el lienzo puede ser utilizada como una simple arquitectura visual o desplegada directamente en el CSP deseado.

✂️ ¡Edita libremente el lienzo!

<p>&nbsp;</p>

## Arrastrar y Soltar recursos {#drag-drop}

`Arrastrar y soltar` es la función más simple para configurar el lienzo.
Desde la `lista de recursos` a la izquierda, simplemente arrastra y suelta el recurso deseado en el lienzo.
Los recursos que no puedan conectarse entre sí serán rechazados con una línea roja.

<div className={styles.imgWrap}>
    <img src={dragDrop} alt="imagen de drag and drop" width={800} />
</div>

<br />

:::info

La `lista de recursos` es un panel a la izquierda del lienzo donde se agrupan los recursos disponibles.

:::

## Conectar recursos {#resource-connect}

## Editar opciones de recursos {#option-edit}

Haz `doble clic` en un recurso para abrir el `panel de edición` y cambiar la configuración de ese recurso.
Haz clic en el `icono de ver detalles` para ver la descripción del recurso.
❓ Si pasas el ratón sobre el `icono de interrogación`, podrás ver la descripción de cada opción. Consulta la descripción para ajustar los valores según sea necesario.

    <img src={edit} alt="imagen de edición de opciones" width={800} />
</div>

## Corregir errores {#error-correction}

🔴 El punto rojo indica que hay un error en el recurso. <highlight color="#FF7272">Si hay errores, no podrás guardar ni desplegar el lienzo.</highlight>
Para solucionar el error, haz `doble clic` en el recurso con error para abrir la ventana de errores del lienzo.
En la ventana de errores, haz doble clic en un error específico para ser dirigido al lugar del error. Revisa la causa del error y corrígelo.

<div className={styles.imgWrap}>
    <img src={error} alt="imagen de corrección de errores" width={800} />
</div>

<p>&nbsp;</p>

### Tipos de errores

| Tipo  | Descripción                                              |
| ----- | -------------------------------------------------------- |
| value | Error que ocurre cuando el valor de entrada es incorrecto |
| group | Error que ocurre cuando no se pertenece a un grupo       |
| line  | Error que ocurre cuando un recurso necesario no está conectado |

## Uso de la Caja de Herramientas {#toolbox}

La caja de herramientas ubicada en la parte superior ofrece diversas funciones para personalizar el lienzo.

| Imagen                                                       | Acción        | Función                                               |
| ------------------------------------------------------------ | ------------- | ---------------------------------------------------- |
| <img width="40px" src={ undo } alt="Imagen de deshacer" />   | Deshacer      | Retrocede un paso.                                   |
| <img width="40px" src={ redo } alt="Imagen de rehacer" />    | Rehacer       | Avanza un paso.                                      |
| <img width="40px" src={ front } alt="Imagen" />              | Enviar atrás  | Si dos recursos se superponen, envía el recurso seleccionado atrás. |
| <img width="40px" src={ back } alt="Imagen" />               | Enviar al frente | Si dos recursos se superponen, envía el recurso seleccionado al frente. |
| <img width="40px" src={ list } alt="Imagen de lista de recursos" /> | Lista de recursos | Botón para mostrar u ocultar la lista de recursos. |
| <img width="100px" src={ ratio } alt="Imagen de proporción de pantalla" />   | Proporción de pantalla | Ajusta la proporción de la pantalla del lienzo. |
| <img width="100px" src={ grid } alt="Imagen de la cuadrícula" />       | Cuadrícula    | Permite desactivar la cuadrícula del lienzo.         |                    |
