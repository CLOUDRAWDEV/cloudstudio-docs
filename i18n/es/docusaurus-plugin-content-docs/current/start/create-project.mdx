En Cloud Studio, cada lienzo se llama 📄 proyecto.
Para crear un proyecto, primero debe existir una 📁 carpeta en la que puedas gestionarlo.

Consulta cómo crear una carpeta [aquí](/docs/start/create-folder).

<p>&nbsp;</p>

## Tres formas de crear un proyecto

Existen `tres` maneras de crear un proyecto en Cloud Studio:

-   [Crear con una plantilla proporcionada](#create-template)
-   [Crear un proyecto vacío](#create-empty)
-   [Importar infraestructura existente](#create-import)

Si usas una **plantilla**, puedes crear rápidamente la infraestructura en la nube en la categoría que desees, como Landing Zone, MSA, Load Balancer, Ubuntu Virtual Machine, CDN, etc. Para más detalles sobre las plantillas, consulta <Link to="">aquí</Link>.

Si prefieres **configurar el lienzo manualmente sin plantilla**, utiliza la opción de crear un proyecto vacío. En este lienzo vacío, puedes arrastrar y soltar los recursos que desees para construir tu infraestructura en la nube.

Si quieres **importar infraestructura existente** al lienzo, accede al lienzo y haz clic en `Archivo > Importar` para cargar la infraestructura.

<p>&nbsp;</p>

### Importar infraestructura existente (Importar) {#create-import}

Para importar infraestructura existente, primero debes acceder al lienzo. Crea un `proyecto vacío` primero. Consulta cómo crear un proyecto vacío [aquí](#create-empty).

<br />

<div className={styles.imgWrap}>
    <img src={import01} width={800} alt="import 이미지" />
</div>

<br />

1. Haz clic en `Proyecto vacío` para acceder a la página del lienzo.
2. Haz clic en `Archivo > Importar`.
3. Aparecerá una ventana emergente donde debes seleccionar el `credencial` deseada entre las registradas.
4. Haz clic en el botón `Consultar recursos` y selecciona el `grupo de recursos` que deseas desde la lista.
5. Haz clic en el botón `Importar` para completar la importación de la infraestructura existente.

<p>&nbsp;</p>

:::caution

Para importar infraestructura, es necesario que las credenciales estén registradas.

:::
