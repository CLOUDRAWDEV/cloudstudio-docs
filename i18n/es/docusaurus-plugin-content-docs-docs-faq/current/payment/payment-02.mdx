# Quiero cancelar la suscripción

<hr />
<br />

1. En la pantalla principal de CloudStudio, selecciona el menú `Mi información` a la izquierda.

2. Haz clic en `Gestión de suscripciones` para ir a la página de planes de suscripción.

3. Puedes cancelar la suscripción cambiando tu plan actual a `Plan GRATUITO`.

:::info

La cancelación de la suscripción se aplicará a partir del siguiente mes.

:::
