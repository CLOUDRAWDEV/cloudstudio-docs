# Quiero eliminar mi cuenta.

<hr />
<br />

1. Selecciona el menú `Mi información` a la izquierda en la pantalla principal de Cloud Studio.

2. En Gestión de cuenta, haz clic en `Eliminar cuenta` para eliminar la cuenta.

:::caution

Después de eliminar la cuenta, los proyectos no se pueden recuperar.

:::
