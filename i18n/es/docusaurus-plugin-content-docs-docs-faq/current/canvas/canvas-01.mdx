# Diferencia entre Guardar y Guardado de Versión

<hr />
<br />

<Tabs>
    <TabItem value="save" label="Guardar" default>
        Guardar conserva el estado actual del canvas. Al guardar, no será posible regresar
        al canvas de una versión anterior. Si deseas volver al estado previo del canvas,
        deberás utilizar la función de guardar versión.
    </TabItem>
    <TabItem value="versionSave" label="Guardar Versión">
        Guardar versión permite restaurar el canvas a un estado deseado en un momento específico.
        Al guardar una versión, podrás cargar el estado del canvas en ese momento más adelante.
    </TabItem>
</Tabs>
