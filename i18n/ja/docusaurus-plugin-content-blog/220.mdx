#### AI リソースが新たに追加されました。

<div className={styles.releaseWrap} >
<div className={styles.tag} data-type="feature">
    Feature
</div>

1. AWS および Azure ベースの AI リソースが新たに追加されました。

    - AWS AI リソース

        - Bedrock Agent
        - Bedrock Knowledge Base
        - Bedrock Action Group
        - Bedrock Guardrail

    - Azure AI リソース

        - Content Safety
        - AI Service
        - Search Service

    - これにより、ユーザーは主要なクラウドサービスが提供する AI 関連リソースを、より直感的に設計および管理できるようになりました。

2. 構成エラーの表示／非表示機能が追加されました。
    - リソースに未解決のエラーが残っていても、エラー表示を選択して表示または非表示にできます。
