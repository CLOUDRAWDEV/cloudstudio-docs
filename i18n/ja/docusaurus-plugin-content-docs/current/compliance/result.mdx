# 점검 기준 (Inspection Criteria)

<table>
    <tr>
        <th colspan="1">カテゴリ (Scope)</th>
        <th colspan="1">項目名</th>
        <th colspan="1">点検基準</th>
    </tr>
    <tr>
        <td rowspan="9">アカウント管理</td>
        <td>ADユーザーアカウント管理</td>
        <td>
            <strong>良好基準:</strong>{" "}
            管理者権限を持つアカウントが複数存在せず、不要なアカウントが存在しない。
            <br />
            <strong>脆弱基準:</strong>{" "}
            管理者権限を持つアカウントが複数存在するか、不要なアカウントが存在する。
        </td>
    </tr>
    <tr>
        <td>ADユーザープロファイルおよびディレクトリ識別管理</td>
        <td>
            <strong>良好基準:</strong>{" "}
            必須のプロファイル項目（ID、勤務情報、連絡先など）が入力されている。
            <br />
            <strong>脆弱基準:</strong>{" "}
            必須のプロファイル項目（ID、勤務情報、連絡先など）が入力されていない。
        </td>
    </tr>
    <tr>
        <td>ADグループ所有者およびメンバー管理</td>
        <td>
            <strong>良好基準:</strong>{" "}
            グループに所有者およびメンバーが割り当てられている。
            <br />
            <strong>脆弱基準:</strong>{" "}
            グループに所有者またはメンバーが割り当てられていない。
        </td>
    </tr>
    <tr>
        <td>ADゲストユーザー</td>
        <td>
            <strong>良好基準:</strong>{" "}

            <br />
            <strong>脆弱基準:</strong>{" "}
            ゲストユーザーアカウント（使用期限が切れた不要なアカウントを含む）が使用されている。
        </td>
    </tr>
    <tr>
        <td>ADパスワードリセットポリシー管理</td>

            <strong>良好基準:</strong>{" "}

            <br />
            <strong>脆弱基準:</strong>{" "}
            パスワードリセットポリシーが必須設定基準に従って設定されていない。
        </td>
    </tr>
    <tr>
        <td>SSHキーアクセス管理</td>
        <td>
            <strong>良好基準:</strong>{" "}
            SSHキーの作成、修正、削除が管理者および所有者アカウントのみに制限されている。
            <br />
            <strong>脆弱基準:</strong>{" "}
            SSHキーの作成、修正、削除が管理者および所有者アカウントのみに制限されていない。
        </td>
    </tr>
    <tr>
        <td>MFA（多要素認証）設定</td>
        <td>
            <strong>良好基準:</strong>{" "}
            ADユーザーアカウントに対してMFAが有効化され、使用されている。
            <br />
            <strong>脆弱基準:</strong>{" "}
            ADユーザーアカウントに対してMFAが有効化されていないか、使用されていない。
        </td>
    </tr>
    <tr>
        <td>MFAアカウントロックポリシー管理</td>
        <td>
            <strong>良好基準:</strong>{" "}

            <br />
            <strong>脆弱基準:</strong>{" "}
            アカウントロック設定がポリシーに従って設定されていない。
        </td>
    </tr>
    <tr>
        <td>Azureパスワードポリシー管理</td>
        <td>
            <strong>良好基準:</strong>{" "}
            パスワード保護ポリシーがポリシーに従って適用され、使用されている。
            <br />
            <strong>脆弱基準:</strong>{" "}
            パスワード保護ポリシーがポリシーに従って適用されていないか、使用されていない。

    <tr>
        <td rowspan="6">権限管理</td>
        <td>サブスクリプションアクセス制御 (IAM) ロール管理</td>
        <td>
            <strong>良好基準:</strong>{" "}
            サブスクリプションに設定されたアクセス制御ロールが、各サービスに対して一意の権限（読み取り専用）として付与されている。
            <br />
            <strong>脆弱基準:</strong>{" "}
            サブスクリプションに設定されたアクセス制御ロールが、サービスのフル権限（所有者、寄稿者、ユーザーアクセス管理者、閲覧者）で付与されている。
        </td>
    </tr>
    <tr>
        <td>リソースグループアクセス制御 (IAM) ロール割り当て</td>

            <br />
            <strong>脆弱基準:</strong>{" "}
            AZUREユーザー権限/グループに対して、目的に応じて適切にロールが割り当てられていない。
        </td>
    </tr>

        </td>
