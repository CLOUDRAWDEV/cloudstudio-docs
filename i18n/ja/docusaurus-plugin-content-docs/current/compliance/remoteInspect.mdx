# リ모ート点検

## リ모ート点検権限照会

コンソール点検の権限を照会するには、`ⓘ ボタン`をクリックします。

<img width="200" src={remoteInspect29} alt="照会イメージ" />
<p></p>
<img width="400" src={remoteInspect30} alt="照会イメージ" />
<p></p>

## 実行方法

1. `点検 > 点検管理 > リモート点検`タブをクリックして、リモート点検にアクセスします。
2. グループリストから`点検したいグループ`を選択します。

:::info

リモート点検は選択したグループに基づいて実施されます。リモート点検を開始する前に、まず`グループを作成`してください。
[グループの作成方法](/docs/compliance/group)

:::

3. `リモート点検タブ`をクリックします。

<img width="400" src={remoteInspect2} alt="img" />

4. `点検ボタン`をクリックします。

    <img width="200" src={remoteInspect3} alt="img" />

5. 点検タイトル（点検内容を特定するため）を入力し、`次へボタン`をクリックします。

    <img width="400" src={remoteInspect5} alt="img" />

    5-1. 既存のサーバーを使用する場合は、使用したいサーバーの情報を入力します。

    <img width="400" src={remoteInspect7} alt="イメージ" />

6. 点検タイトル（点検内容を示すもの）を入力し、`点検開始ボタン`をクリックします。

    <img width="400" src={remoteInspect4} alt="イメージ" />

<p>&nbsp;</p>

## レポート作成

点検が完了すると、結果をテーブルで確認できます。テーブルには、`範囲、項目名、点検基準、優先度、点検結果、点検結果の詳細`の6つの列が含まれます。
`点検基準`の詳細については[こちら](/docs/compliance/result)を参照してください。
CS Checkerは、ExcelとWordの2種類のレポートを提供します。
