📁 フォルダは、複数のプロジェクトを体系的に管理するための構造です。 <br />
CloudStudio では、フォルダを作成した後、そのフォルダ内にプロジェクトを構成して管理することができます。

<br />
<br />

<div className={styles.imgWrap}>
    <img src={createFolder} alt="createFolder" />
</div>

<br />

1. 新しいフォルダを作成するには、CloudStudio のテンプレートページで `フォルダ追加アイコン` をクリックします。
2. フォルダ追加ポップアップが表示されたら、`フォルダ名` と `フォルダ説明` を入力します。<br/>フォルダ説明は省略できます。<br/>
   フォルダ名およびフォルダ説明は、`以下の条件` を満たす必要があります。

> フォルダ名

-   英字で始まること
-   英字、数字、ハイフン (-)、アンダースコア (\_) のみ使用可能
-   英字または数字で終わること
-   全体の長さは 2 ～ 12 文字
-   空白は使用不可

> フォルダ説明

-   最大 100 文字まで入力可能

3. ポップアップウィンドウの内容の作成が終わったら、`作成する`ボタンをクリックします。
4. 生成されたフォルダのリストは`テンプレート > マイフォルダ`で確認することができます。
