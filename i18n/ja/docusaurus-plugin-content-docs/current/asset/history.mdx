# 資産履歴

資産履歴は`資産照会の記録`を表します。
資産履歴では、照会時刻や照会を実行したユーザーの確認、特定の履歴への移動、または履歴の削除が可能です。

1. `資産台帳照会履歴ボタン`をクリックして、資産履歴を表示します。

    <img width="200" src={assethistory1} alt="img" />

2. 詳細を確認したい資産履歴をクリックします。最新の日付が一番上に表示されます。

    <img width="400" src={assethistory2} alt="img" />

<p>&nbsp;</p>

## 履歴の削除

削除したい履歴の`ゴミ箱アイコン`をクリックします。
