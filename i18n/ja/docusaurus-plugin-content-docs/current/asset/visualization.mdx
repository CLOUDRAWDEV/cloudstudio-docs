# 資産の視覚化

資産の視覚化は、`照会された資産をダイアグラムで表示`します。
各資産を選択して詳細を確認できます。

1. 資産の視覚化は`「資産台帳」`に基づいて生成されます。

    <img width="800" src={assetview} alt="img" />

2. 資産は`「グループ」`ごとに視覚化できます。

    <img width="400" src={assetcategory} alt="img" />

3. 資産を選択して詳細を表示します。

    <img width="400" src={assetdetail} alt="img" />
