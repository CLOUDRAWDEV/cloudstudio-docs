## リソース概要

特定のストレージプロビジョナーと連携し、動的ストレージプロビジョニングを定義する Kubernetes リソースです。

### 接続リソース

-   [**PersistentVolume**](https://docs.cstudio.app/ja/docs/resource/kubernetes/Core/PersistentVolume)

## リソース設定値

#### 基本設定

-   `annotations` : Kubernetes システムメタデータ
-   `labels` : StorageClass 識別用ラベル
-   `storage_provisioner` : 実際にストレージを作成するプロビジョナー
-   `reclaim_policy` : ボリューム解放時のポリシー - `Retain`, `Delete`
-   `volume_binding_mode` : バインディングタイミング - `Immediate`, `WaitForFirstConsumer`
-   `allow_volume_expansion` : ボリュームサイズ拡張可否
-   `parameters` : プロビジョナーに渡す追加パラメータ
-   `mount_options` : 動的生成 PV に適用するマウントオプション
