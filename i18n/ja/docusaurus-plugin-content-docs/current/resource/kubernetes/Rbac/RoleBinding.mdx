## リソース概要

特定のネームスペース内で Role または ClusterRole を主体に関連付ける Kubernetes リソースです。

## 関連リソース

### 親リソース

-   [**Namespace**](https://docs.cstudio.app/ja/docs/resource/kubernetes/Core/Namespace)

### 接続リソース

-   [**ServiceAccount**](https://docs.cstudio.app/ja/docs/resource/kubernetes/Core/ServiceAccount)
-   [**Role**](https://docs.cstudio.app/ja/docs/resource/kubernetes/RBAC/Role)
-   [**ClusterRole**](https://docs.cstudio.app/ja/docs/resource/kubernetes/RBAC/ClusterRole)

## リソース設定値

#### 基本設定

-   `namespace` : RoleBinding が適用されるネームスペース
-   `annotations` : RoleBinding リソースのメタデータ key-value
-   `labels` : RoleBinding オブジェクト識別用ラベル
-   `role_type` : バインド対象の Role 種別 - `Role`, `ClusterRole`
-   `role_name` : バインドする Role / ClusterRole 名

#### 主体設定 (`subject`)

-   `subject.kind` : 主体の種類 - `ServiceAccount`, `User`, `Group`
-   `subject.namespace` : 主体が属するネームスペース
-   `subject.api_group` : 認可判定を行う API Group - `rbac.authorization.k8s.io`
