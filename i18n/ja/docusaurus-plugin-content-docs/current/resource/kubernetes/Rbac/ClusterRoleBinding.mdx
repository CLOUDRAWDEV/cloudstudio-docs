## リソース概要

クラスターレベルおよびすべてのネームスペースに適用される Role を、ユーザーやサービスアカウントなどの主体に関連付ける Kubernetes リソースです。

### 親リソース

-   [**Cluster**](https://docs.cstudio.app/ja/docs/resource/kubernetes/Base/Cluster)

### 接続リソース

-   [**ClusterRole**](https://docs.cstudio.app/ja/docs/resource/kubernetes/RBAC/ClusterRole)

---

## リソース設定値

#### 基本設定

-   `annotations` : ClusterRoleBinding リソースのメタデータ key-value
-   `labels` : ClusterRoleBinding オブジェクト識別用のユーザー定義ラベル
-   `role_name` : バインド対象となる ClusterRole 名
-   `subject` : ClusterRole を付与する主体。kind（`ServiceAccount`, `User`, `Group`）、namespace（主体が属するネームスペース）、api_group（`rbac.authorization.k8s.io`）を含む
