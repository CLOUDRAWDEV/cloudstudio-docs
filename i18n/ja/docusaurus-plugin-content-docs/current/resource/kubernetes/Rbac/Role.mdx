## リソース概要

特定のネームスペース内にのみ適用される Role を定義する Kubernetes リソースです。

## 関連リソース

-   [**Namespace**](https://docs.cstudio.app/ja/docs/resource/kubernetes/Core/Namespace)

### 接続リソース

-   [**RoleBinding**](https://docs.cstudio.app/ja/docs/resource/kubernetes/RBAC/RoleBinding)

## リソース設定値

#### 基本設定

-   `namespace` : Role リソースがデプロイされるネームスペース
-   `annotations` : Kubernetes システムメタデータ key-value
-   `labels` : オブジェクト識別用のユーザー定義ラベル

#### ポリシールール (`rule`)

-   `rule.api_groups` : 操作を許可するリソースが属する API Group
-   `rule.resources` : このルールが適用されるリソース一覧
-   `rule.resource_names` : 特定リソースインスタンスを指定する場合に使用
-   `rule.verbs` : 許可される操作 - `get`, `list`, `create`, `update`, `patch`, `watch`, `delete`, `deletecollection`
