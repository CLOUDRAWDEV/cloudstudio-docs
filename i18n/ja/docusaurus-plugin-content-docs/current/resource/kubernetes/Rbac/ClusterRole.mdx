## リソース概要

クラスター全体およびすべての Namespace に適用される RBAC ロールを定義する Kubernetes リソースです。

## 関連リソース

### 上位リソース

-   [**Cluster**](https://docs.cstudio.app/ja/docs/resource/kubernetes/Base/Cluster)

### 接続リソース

-   [**ClusterRoleBinding**](https://docs.cstudio.app/ja/docs/resource/kubernetes/Rbac/ClusterRoleBinding)

## リソース設定値

#### 基本設定

-   `annotations` : メタデータ
-   `labels` : ユーザー定義ラベル

#### ポリシールール (`rule`)

-   `rule.rule_type` : ルール種別 - `ApiGroup`, `ResourceUrl`
-   `rule.api_groups` : API Group
-   `rule.resources` : 対象リソース
-   `rule.resource_names` : 個別リソース指定
-   `rule.non_resource_urls` : URL ベース指定
-   `rule.verbs` : 許可動作 - `get`, `list`, `create`, `update`, `patch`, `watch`, `delete`, `deletecollection`
