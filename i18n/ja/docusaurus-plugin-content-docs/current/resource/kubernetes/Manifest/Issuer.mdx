## リソース概要

証明書署名要求を受け取り、認証局（CA）から署名済み証明書を生成する Kubernetes リソースです。

## リソース設定値

#### 基本設定

-   `namespace` : Issuer リソースをデプロイする Namespace

#### ACME 設定 (`acme`)

-   `acme.server` : ACME サーバーのエンドポイント
-   `acme.email` : 証明書の問題や期限切れ時の連絡先メールアドレス
-   `acme.private_key_secret_ref` : クライアントキーを保存する Secret 名

#### DNS Solver 設定 (`dns_solvers`)

-   `dns_solvers.provider` : DNS-01 チャレンジ方式 - `AzureDNS`, `Route53`, `ACMEDNS`

##### ACMEDNS 設定

-   `dns_solvers.acme_dns.host` : acme-dns サーバー URL
-   `dns_solvers.acme_dns.account_secret_ref_name` : アカウント情報 Secret 名
-   `dns_solvers.acme_dns.account_secret_ref_key` : Secret 内のキー名

##### AzureDNS 設定

-   `dns_solvers.azure_dns.client_id` : Azure クライアント ID
-   `dns_solvers.azure_dns.client_secret_name` : client secret Secret 名
-   `dns_solvers.azure_dns.client_secret_key` : Secret 内キー
-   `dns_solvers.azure_dns.subscription_id` : サブスクリプション ID
-   `dns_solvers.azure_dns.tenant_id` : テナント ID
-   `dns_solvers.azure_dns.resource_group_name` : DNS Zone のリソースグループ
-   `dns_solvers.azure_dns.hosted_zone_name` : DNS Zone 名

##### Route53 設定

-   `dns_solvers.route53.region` : AWS リージョン
-   `dns_solvers.route53.access_key_id` : AWS アクセスキー ID
-   `dns_solvers.route53.access_key_secret_name` : Secret 名
-   `dns_solvers.route53.access_key_secret_key` : キー名
-   `dns_solvers.route53.secret_access_key_secret_name` : Secret 名
-   `dns_solvers.route53.secret_access_key_secret_key` : キー名
-   `dns_solvers.route53.role` : IAM Role

#### HTTP Solver 設定 (`http_solvers`)

-   `http_solvers.provider` : チャレンジ方式 - `Ingress`, `Gateway`
-   `http_solvers.ingress_class_name` : Ingress クラス名

##### Gateway 設定

-   `http_solvers.gateway_parent_refs.name` : Gateway 名
-   `http_solvers.gateway_parent_refs.namespace` : Namespace
