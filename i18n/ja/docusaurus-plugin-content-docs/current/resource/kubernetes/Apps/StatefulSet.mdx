## リソース概要

Pod 集合のデプロイおよびスケーリングを管理し、各 Pod の順序性と一意性を保証する Kubernetes リソース。

## リソース設定値

#### 基本設定

-   `namespace` : StatefulSet リソースをデプロイするネームスペース
-   `annotations` : Kubernetes システムメタデータの key-value
-   `labels` : StatefulSet リソース識別用ラベル
-   `template_labels` : 生成される Pod に適用されるラベル
-   `pod_management_policy` : Pod 作成・削除順序制御方式 (`Parallel`, `OrderedReady`)
-   `revision_history_limit` : 保持するリビジョン履歴数
-   `linked_service_name` : StatefulSet を管理する Headless Service 名
-   `replicas` : 維持する Pod レプリカ数
-   `pod_security_context` : Pod 単位のセキュリティおよび権限設定
-   `init_containers` : 初期化コンテナ定義
-   `containers` : Pod コンテナ定義
-   `volume` : 使用ボリューム定義
-   `dns_policy` : DNS ポリシー
-   `enable_service_links` : サービスリンク有効化有無
-   `host_network` : ホストネットワーク使用有無
-   `image_pull_secrets` : イメージ取得用 Secret 一覧
