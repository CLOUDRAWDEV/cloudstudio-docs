## リソース概要

指定された数の Pod レプリカが常に実行される状態を保証する Kubernetes リソース。

## リソース設定値

#### 基本設定

-   `namespace` : Deployment リソースをデプロイするネームスペース
-   `annotations` : Kubernetes システムメタデータの key-value
-   `labels` : Deployment リソース識別用ラベル
-   `template_labels` : 生成される Pod に適用されるラベル
-   `replicas` : 維持する Pod レプリカ数
-   `pod_security_context` : Pod 単位のセキュリティおよび権限設定
-   `init_containers` : メインコンテナ起動前の初期化コンテナ定義
-   `containers` : Pod に含まれるコンテナ定義
-   `volume` : Pod で使用するボリューム定義
-   `dns_policy` : Pod の DNS ポリシー
-   `enable_service_links` : サービス環境変数自動注入有無
-   `host_network` : ホストネットワーク使用有無
-   `image_pull_secrets` : イメージ取得用 Secret 一覧
