## リソース概要

DaemonSet は、すべて（または一部）のノードで Pod のレプリカが実行されることを保証する Kubernetes リソース。  
クラスターにノードが追加されると、該当ノードに Pod が自動的に追加される。

## リソース設定値

#### 基本設定

-   `namespace` : DaemonSet リソースをデプロイするネームスペース
-   `annotations` : Kubernetes システムで使用されるメタデータの key-value
-   `labels` : DaemonSet リソース識別用のカスタムラベル
-   `template_labels` : 生成される Pod に適用されるラベル
-   `pod_security_context` : Pod 単位のセキュリティおよび権限設定
-   `init_containers` : メインコンテナ起動前に実行される初期化コンテナ定義
-   `containers` : Pod に含まれるコンテナ定義
-   `volume` : Pod で使用するボリューム定義
-   `dns_policy` : Pod の DNS ポリシー
-   `enable_service_links` : サービス環境変数の自動注入有無
-   `host_network` : ホストネットワーク使用有無
-   `image_pull_secrets` : イメージ取得時に使用する Secret 一覧
