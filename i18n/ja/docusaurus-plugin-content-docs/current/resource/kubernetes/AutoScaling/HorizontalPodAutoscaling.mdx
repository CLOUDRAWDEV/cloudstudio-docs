## リソース概要

観測された CPU 使用率を基準として、Deployment、ReplicaSet、StatefulSet の Pod 数を自動的にスケーリングする Kubernetes リソース。

## リソース設定値

#### 基本設定

-   `namespace` : HPA リソースをデプロイするネームスペース
-   `annotations` : Kubernetes システムメタデータ key-value
-   `labels` : HPA リソース識別用ラベル
-   `min_replicas` : 自動スケーリング時の最小 Pod 数
-   `max_replicas` : 自動スケーリング時の最大 Pod 数
-   `target_cpu_utilization_percentage` : Pod 平均 CPU 使用率目標値
-   `scale_target_ref` : スケーリング対象コントローラ参照（Deployment, StatefulSet）
