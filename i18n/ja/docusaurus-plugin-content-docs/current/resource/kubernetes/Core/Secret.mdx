## リソース概要

パスワードやトークン、キーなどの機密情報を安全に保存する Kubernetes リソース。

## リソース設定値

#### 基本設定

-   `namespace` : Secret を配置する Namespace
-   `annotations` : Kubernetes システムメタデータ
-   `labels` : Secret 識別用ラベル
-   `type` : Secret タイプ
-   `immutable` : データ変更不可 여부
-   `data` : Base64 エンコード된データ
