## リソース概要

Pod やサービスがクラスターリソースへアクセスするための Kubernetes アカウント。

## 関連リソース

### 上位リソース

-   [**Namespace**](https://docs.cstudio.app/ja/docs/resource/kubernetes/Core/Namespace)

### 接続リソース

-   [**Secret**](https://docs.cstudio.app/ja/docs/resource/kubernetes/Core/Secret)

## リソース設定値

#### 基本設定

-   `namespace` : ServiceAccount を配置する Namespace
-   `annotations` : Kubernetes システムメタデータ
-   `labels` : 識別・分類用ラベル
-   `secret` : 使用可能な Secret 一覧
-   `image_pull_secrets` : Image Pull 用 Secret
-   `automount_service_account_token` : トークン自動マウント 여부
