## リソース概要

1 つ以上のコンテナをまとめて実行する、最小単位の Kubernetes デプロイメント。

## リソース設定値

#### 基本設定

-   `namespace` : Pod を配置する Namespace
-   `annotations` : Kubernetes システムメタデータ
-   `labels` : Pod 識別・分類用ラベル
-   `pod_security_context` : Pod 単位セキュリティ設定
-   `init_containers` : 初期化コンテナ定義
-   `containers` : 実行コンテナ仕様
-   `volume` : 使用するボリューム
-   `dns_policy` : DNS ポリシー
-   `enable_service_links` : Service 環境変数自動注入 여부
-   `host_network` : ホストネットワーク使用 여부
-   `image_pull_secrets` : Image Pull 用 Secret
