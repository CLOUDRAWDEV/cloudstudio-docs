## リソース概要

クラスターにネットワーク接続されたストレージを提供する Kubernetes リソース。

## リソース設定値

#### 基本設定

-   `annotations` : Kubernetes システムメタデータ
-   `labels` : PV 識別および分類用ユーザー定義ラベル
-   `spec.storage_class_name` : 使用する StorageClass 名
-   `spec.storage_capacity` : ストレージ容量
-   `spec.volume_driver` : CSI ベースのボリュームドライバ
-   `spec.volume_handle` : 実際のストレージリソース識別子
-   `spec.persistent_volume_reclaim_policy` : クレーム解放時の処理ポリシー - `Retain / Delete / Recycle`
-   `spec.read_only` : 読み取り専用 여부
-   `spec.volume_attributes` : ドライバ固有の追加属性
-   `spec.access_modes` : アクセスモード - `ReadOnlyMany, ReadWriteOnce, ReadWriteMany`
-   `spec.mount_options` : 追加マウントオプション
-   `node_stage_secret_ref` : ストレージ認証用 Secret 参照
