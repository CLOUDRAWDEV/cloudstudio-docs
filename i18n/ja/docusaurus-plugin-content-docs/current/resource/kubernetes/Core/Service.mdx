## リソース設定値

#### 基本設定

-   `namespace` : Service を配置する Namespace
-   `annotations` : Kubernetes システムメタデータ
-   `labels` : Service 識別用ラベル
-   `selector` : 対象 Pod 選択用ラベル
-   `type` : Service タイプ - `ClusterIP`, `NodePort`, `LoadBalancer`
-   `session_affinity` : セッション固定 여부
