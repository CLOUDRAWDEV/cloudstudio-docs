## リソース概要

Pod が API Server や Cluster Resource にアクセスするための権限を付与する 기본 ServiceAccount Resource。

### 接続対象

-   [**Secret**](https://docs.cstudio.app/ja/docs/resource/kubernetes/Core/Secret)

## リソース設定値

#### 基本設定

-   `namespace` : ServiceAccount を配置する Namespace
-   `annotations` : Kubernetes システムメタデータ
-   `labels` : Resource 識別・分類用ラベル
-   `secret` : Pod から参照可能な Secret 一覧
-   `image_pull_secrets` : Image Pull 用 Secret 一覧
-   `automount_service_account_token` : ServiceAccount Token 自動マウント 여부
