## リソース設定値

#### 基本設定

-   `namespace` : PVC を作成する Namespace
-   `annotations` : Kubernetes システムメタデータ
-   `labels` : PVC 識別・分類用ラベル
-   `spec.storage_class_name` : 使用する StorageClass 名
-   `spec.volume_name` : バインドする PersistentVolume 名
-   `spec.volume_mode` : 提供方式 - `Filesystem / Block`
-   `spec.request_storage` : 要求ストレージ容量
-   `spec.access_modes` : アクセスモード
-   `wait_until_bound` : PV バインド完了まで待機 여부
