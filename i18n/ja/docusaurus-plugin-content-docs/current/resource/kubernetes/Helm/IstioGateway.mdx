## リソース設定値

#### 基本設定

-   `namespace` : Istio Gateway Helm Chart をデプロイする Namespace
-   `version` : 使用する Istio Ingress Helm Chart のバージョン
-   `set` : Ingress の既定値を動的に変更する key-value 設定
