## リソース概要

Istio 用 Custom Resource Definitions (CRDs) の Helm チャートです。

## 関連リソース

### 上位リソース

-   [**Namespace**](https://docs.cstudio.app/ja/docs/resource/kubernetes/Core/Namespace)

## リソース設定値

#### 基本設定

-   `namespace` : Istio CRDs Helm Chart をデプロイする Namespace
-   `version` : 使用する Istio CRDs Helm Chart のバージョン
-   `set` : CRDs の既定値を動的に変更する key-value 設定
