## リソース概要

Cert-Manager をインストールするための Helm チャートです。

## リソース設定値

#### 基本設定

-   `namespace` : Cert Manager Helm Chart をデプロイする Namespace
-   `version` : 使用する Cert Manager Helm Chart のバージョン
-   `installCRDs` : Cert Manager が使用する CRD のインストール有無
