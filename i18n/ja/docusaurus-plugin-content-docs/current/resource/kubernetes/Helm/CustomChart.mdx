## リソース概要

既存の Helm チャートをユーザー指定の値で設定し、デプロイできるリソースです。

## 関連リソース

### 上位リソース

-   [**Namespace**](https://docs.cstudio.app/ja/docs/resource/kubernetes/Core/Namespace)

## リソース設定値

#### 基本設定

-   `namespace` : Custom Helm Chart リソースをデプロイする Namespace
-   `repository` : Helm Chart が保存されているリポジトリ URL
-   `chart` : Helm Chart 名
-   `version` : Helm Chart バージョン
-   `set` : Chart の値を動的に変更する key-value 設定
