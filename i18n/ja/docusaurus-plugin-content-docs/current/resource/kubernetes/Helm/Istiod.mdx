## リソース概要

Istio コントロールプレーン (Istiod) の Helm チャートです。

## リソース設定値

#### 基本設定

-   `namespace` : Istiod Helm Chart をデプロイする Namespace
-   `version` : 使用する Istiod Helm Chart のバージョン
-   `set` : Istiod の既定値を動的に変更する key-value 設定
