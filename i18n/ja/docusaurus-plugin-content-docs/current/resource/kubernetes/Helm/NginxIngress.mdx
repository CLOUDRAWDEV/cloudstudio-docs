## リソース概要

NGINX Ingress Controller をインストールするための Helm チャートです。

## リソース設定値

#### 基本設定

-   `namespace` : NGINX Ingress Helm Chart をデプロイする Namespace
-   `version` : 使用する NGINX Ingress Helm Chart のバージョン
-   `replica_count` : Ingress Controller Deployment のレプリカ数
-   `external_traffic_policy` : 外部トラフィック処理方式 - `Cluster`, `Local`
-   `ingress_class_name` : 管理対象となる Ingress Class 名
-   `set` : NGINX Ingress の既定値を動的に変更する key-value 設定
