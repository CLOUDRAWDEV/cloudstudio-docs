## リソース設定値

#### 基本設定

-   `namespace` : HashiCorp Vault Helm Chart をデプロイする Namespace
-   `version` : 使用する HashiCorp Vault Helm Chart のバージョン
-   `set` : Vault の既定値を動的に変更する key-value 設定
