## リソース設定値

#### 基本設定

-   `namespace` : Job Resource を配置する Namespace
-   `annotations` : Kubernetes システムメタデータ
-   `labels` : Resource 識別用ラベル
-   `enable_manual_selector` : 手動セレクター使用可否 - `true`, `false`
-   `template_labels` : Pod に設定されるラベル
-   `restart_policy` : コンテナ終了時の処理方式 - `Never`, `OnFailure`
-   `backoff_limit` : 失敗と判断するまでの再試行回数
-   `wait_for_completion` : 完了まで作成/更新を待機するか 여부 - `true`, `false`
-   `dns_policy` : DNS ポリシー
-   `enable_service_links` : Service Link 有効化 여부
-   `host_network` : ホストネットワーク使用 여부
-   `image_pull_secrets` : Image Pull 用 Secret 一覧
