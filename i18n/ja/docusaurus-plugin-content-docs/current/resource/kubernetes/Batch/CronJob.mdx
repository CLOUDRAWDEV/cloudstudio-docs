## リソース概要

スケジュールに基づき定期的にジョブを生成する Kubernetes Resource。

## リソース設定値

#### 基本設定

-   `namespace` : CronJob を配置する Namespace
-   `schedule` : Cron 式で定義する実行スケジュール
-   `timezone` : スケジュール解釈基準タイムゾーン
-   `concurrency_policy` : ジョブ同時実行制御方式 (Allow / Forbid / Replace)
-   `starting_deadline_seconds` : スケジュール遅延時の実行許容時間
-   `successful_jobs_history_limit` : 成功 Job の保持数
-   `failed_jobs_history_limit` : 失敗 Job の保持数
-   `containers` : 実行コンテナ仕様
-   `init_containers` : メイン実行前の初期処理
-   `volume` : マウントするボリューム設定
-   `pod_security_context` : Pod 単位セキュリティ設定
-   `image_pull_secrets` : Image Pull 用 Secret 参照
