## リソース概要

インバウンド接続をバックエンドで定義されたエンドポイントへルーティングするルールを定義する Kubernetes リソースです。

## リソース設定値

#### 基本設定

-   `namespace` : Ingress をデプロイする Namespace
-   `annotations` : Kubernetes メタデータ
-   `labels` : ユーザー定義ラベル
-   `ingress_class_name` : 使用する Ingress クラス名

#### TLS 設定

-   `tls.hosts` : TLS 証明書に含まれるホスト名
-   `tls.secret_name` : TLS 証明書 Secret 名

#### ルーティングルール

-   `rule.host` : ホスト名

#### バックエンド設定

-   `rule.backend.target_service` : 対象 Service
-   `rule.backend.path` : パス
-   `rule.backend.port` : Service ポート
-   `rule.backend.path_type` : パスマッチ方式 - `ImplementationSpecific`, `Prefix`, `Exact`
