## Resource 設定値

#### Basic Settings

-   `set_container_insights` : Container Insightsをクラスターに有効化するかどうか - `enabled`, `disabled`
-   `kms_key_name` : ローカルクライアントとコンテナ間のデータ暗号化に使用するKMSキー名
-   `logging` : 実行コマンド結果のログリダイレクト設定 - `OVERRIDE`, `NONE`, `DEFAULT`
-   `cloud_watch_encryption_enabled` : CloudWatchログ暗号化有効化可否 - `true`, `false`
-   `cloud_watch_log_group_name` : ログ送信先のCloudWatchロググループ名
-   `capacity_providers` : クラスターに関連付けるCapacity Provider一覧

#### サービス (`service`)

-   `service.computing_option` : サービスのタスク分散方式 - `capacity_provider_strategy`, `launch_type`
-   `service.capacity_provider_strategy.capacity_provider` : 使用するCapacity Provider - `FARGATE`, `FARGATE_SPOT`
-   `service.capacity_provider_strategy.base` : 最小実行タスク数
-   `service.capacity_provider_strategy.weight` : 実行タスク数の相対比率
-   `service.launch_type` : サービス起動方式 - `EC2`, `FARGATE`, `EXTERNAL`
-   `service.task_definition_name` : 使用するECS Task Definition名
-   `service.desired_count` : 実行するタスク数
-   `service.linked_security_group_names` : 使用するSecurity Group名一覧
-   `service.subnet_names` : サービスを実行するSubnet名一覧
-   `service.enabled_public_ip` : Public IP使用可否 - `true`, `false`

#### タグ

-   `tag` : Resourceを分類するためのタグ
