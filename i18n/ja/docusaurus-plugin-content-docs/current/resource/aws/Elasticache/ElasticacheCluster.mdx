## リソース概要

AWS ElastiCache Cluster は、クラウドベースのインメモリデータストアであり、高速かつスケーラブルなキャッシュソリューションを提供します。  
Redis または Memcached エンジンを使用して動作し、アプリケーション性能の向上に利用されます。

## リソース設定値

#### 基本設定

-   `engine` : キャッシュエンジン - `redis`, `memcached`
-   `engine_version` : エンジンバージョン
-   `port` : 接続ポート
-   `parameter_group_name` : パラメータグループ名
-   `node_type` : ノードインスタンスタイプ
-   `num_cache_nodes` : ノード数
-   `az_mode` : AZ 構成方式
-   `included_subnet_names` : Subnet 一覧
-   `subnet_group_name` : Subnet Group 名
-   `snapshot_retention_limit` : スナップショット保持期間（日）

#### タグ

-   `tag` : Resource を分類するためのタグ
