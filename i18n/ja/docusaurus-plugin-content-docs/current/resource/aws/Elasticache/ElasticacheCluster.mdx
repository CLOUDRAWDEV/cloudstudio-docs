## Resource Overview

AWS ElastiCache Clusterは、クラウドベースのインメモリデータストアであり、高速かつスケーラブルなキャッシュソリューションを提供します。  
RedisまたはMemcachedエンジンを使用して動作し、アプリケーション性能の向上に利用されます。

## Resource 設定値

#### Basic Settings

-   `engine` : キャッシュエンジン - `redis`, `memcached`
-   `engine_version` : エンジンバージョン
-   `port` : 接続ポート
-   `parameter_group_name` : パラメータグループ名
-   `node_type` : ノードインスタンスタイプ
-   `num_cache_nodes` : ノード数
-   `az_mode` : AZ構成方式
-   `included_subnet_names` : Subnet一覧
-   `subnet_group_name` : Subnet Group名
-   `snapshot_retention_limit` : スナップショット保持期間（日）

#### タグ

-   `tag` : Resourceを分類するためのタグ
