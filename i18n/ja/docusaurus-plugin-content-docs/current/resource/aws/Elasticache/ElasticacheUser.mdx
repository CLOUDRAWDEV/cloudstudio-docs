## Resource Overview

AWS ElastiCache Userは、ElastiCacheクラスターを利用するためのユーザーです。  
クラスターの作成・変更・削除権限を持ち、アプリケーションや開発者に割り当てられます。

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/ja/docs/resource/aws/Base/Region)

## Resource 設定値

#### Basic Settings

-   `user_id` : 各ユーザーの一意なID
-   `access_string` : 適用する権限文字列
-   `authentication_type` : 認証方式 - `iam`, `password`, `no-password-required`
-   `passwords` : ユーザーのパスワード（最大2件）

#### タグ

-   `tag` : Resourceを分類するためのタグ
