## リソース概要

AWS ElastiCache User は、ElastiCache クラスターを利用するためのユーザーです。  
クラスターの作成・変更・削除権限を持ち、アプリケーションや開発者に割り当てられます。

## リソース設定値

#### 基本設定

-   `user_id` : 各ユーザーの一意な ID
-   `access_string` : 適用する権限文字列
-   `authentication_type` : 認証方式 - `iam`, `password`, `no-password-required`
-   `passwords` : ユーザーのパスワード（最大 2 件）

#### タグ

-   `tag` : Resource を分類するためのタグ
