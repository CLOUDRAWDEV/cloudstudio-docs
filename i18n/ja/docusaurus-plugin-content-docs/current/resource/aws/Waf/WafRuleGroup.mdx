## リソース概要

AWS WAF Rule Group は Web Application Firewall で使用するルール集合。  
複数ルールをグループ化して再利用性および管理効率を向上させ、リクエストの許可・拒否・カウントを制御。

## リソース設定値

#### 基本設定

-   `scope` : Rule Group 適用範囲 - `REGIONAL`, `CLOUDFRONT`
-   `capacity` : Rule Group に必要な Web ACL 容量単位（WCU）
-   `cloudwatch_metrics_enabled` : CloudWatch メトリクス送信可否 - `true`, `false`
-   `metric_name` : CloudWatch メトリクス名（英字大小・ハイフン・アンダースコアのみ、`1` ~ `128` 文字）
-   `sampled_requests_enabled` : 一致リクエストのサンプリング保存可否 - `true`, `false`

#### タグ

-   `tag` : リソース分類用タグ
