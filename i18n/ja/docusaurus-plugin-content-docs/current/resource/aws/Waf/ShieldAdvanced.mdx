## リソース概要

AWS Shield Advanced を使用して DDoS 攻撃から AWS リソースを保護し、Protection Group に含まれるリソースの集計方式およびヘルスチェック設定を構成可能。

## リソース設定値

#### 基本設定

-   `aggregation` : グループ内リソースデータの結合方式（イベント検知・緩和・報告）- `MAX`, `MEAN`, `BY_RESOURCE_TYPE`
-   `pattern` : Protection Group に含める保護対象リソースの選択基準 - `ALL`, `ARBITRARY`, `SUM`
-   `resource_type` : Protection Group に含めるリソース種別

#### ヘルスチェック設定

-   `health_check_ip_address` : 監視対象エンドポイントの IP アドレス
-   `health_check_fqdn` : 監視対象エンドポイントの完全修飾ドメイン名
-   `health_check_type` : 使用プロトコル - `HTTP`, `HTTPS`, `HTTP_STR_MATCH`, `HTTPS_STR_MATCH`, `TCP`, `CALCULATED`, `CLOUDWATCH_METRIC`, `RECOVERY_CONTROL`
-   `health_check_request_interval` : ヘルスチェック間隔（秒）- `10`, `30`

#### タグ

-   `tag` : リソース分類用タグ
