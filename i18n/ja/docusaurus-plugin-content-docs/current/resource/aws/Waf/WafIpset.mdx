## リソース概要

AWS WAF IP Set は、Web ACL ルールから参照可能な IP アドレスまたは CIDR ブロックをグループ化したリソース。  
特定 IP 帯域に対する許可または拒否ポリシー構成に使用。

## リソース設定値

#### 基本設定

-   `scope` : IP Set 適用範囲 - `REGIONAL`, `CLOUDFRONT`
-   `ip_address_version` : IP アドレスバージョン - `IPV4`, `IPV6`
-   `addresses` : CIDR 表記による IP アドレスまたは IP ブロック一覧

#### タグ

-   `tag` : リソース分類用タグ
