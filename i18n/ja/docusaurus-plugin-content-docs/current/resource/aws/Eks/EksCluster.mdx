## リソース概要

Amazon EKS は、Kubernetes クラスターをインストール・運用することなく、AWS 上で Kubernetes を簡単に実行できるマネージドサービスです。

## リソース設定値

#### 基本設定

-   `version` : Kubernetes バージョン
-   `cluster_role_arn` : コントロールプレーン用 IAM ロール
-   `enabled_encryption` : クラスター暗号化有効化可否 - `true`, `false`
-   `kms_key_name` : 使用する KMS キー名
-   `included_subnet_names` : 使用する Subnet 一覧
-   `linked_security_group_names` : 使用する Security Group 一覧
-   `endpoint_access_type` : API エンドポイント公開方式
-   `public_access_cidrs` : API アクセスを許可する CIDR 一覧

#### Control Plane ログ

-   `enabled_cluster_log_types` : 有効化するログタイプ

#### アドオン (`add_ons`)

-   `add_ons.kube_proxy_version` : kube-proxy バージョン
-   `add_ons.vpc_cni_version` : VPC CNI バージョン
-   `add_ons.core_dns_version` : CoreDNS バージョン

#### ノードグループ (`node_group`)

-   `node_group.node_role_name` : ノード IAM ロール
-   `node_group.enabled_launch_template` : Launch Template 使用可否
-   `node_group.launch_template_name` : Launch Template 名
-   `node_group.launch_template_version` : Launch Template バージョン
-   `node_group.min_node_count` : 最小ノード数
-   `node_group.max_node_count` : 最大ノード数
-   `node_group.desired_node_count` : 希望ノード数
-   `node_group.max_node_unavailable` : 更新時の最大非稼働ノード数
-   `node_group.max_percentage_unavailable` : 更新時の最大非稼働率
-   `node_group.disk_size` : ノード EBS サイズ（GB）

#### タグ

-   `tag` : Resource を分類するためのタグ
