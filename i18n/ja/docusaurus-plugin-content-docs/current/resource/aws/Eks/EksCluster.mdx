## Resource Overview

Amazon EKSは、Kubernetesクラスターをインストール・運用することなく、AWS上でKubernetesを簡単に実行できるマネージドサービスです。

## Resource 設定値

#### Basic Settings

-   `version` : Kubernetesバージョン
-   `cluster_role_arn` : コントロールプレーン用IAMロール
-   `enabled_encryption` : クラスター暗号化有効化可否 - `true`, `false`
-   `kms_key_name` : 使用するKMSキー名
-   `included_subnet_names` : 使用するSubnet一覧
-   `linked_security_group_names` : 使用するSecurity Group一覧
-   `endpoint_access_type` : APIエンドポイント公開方式
-   `public_access_cidrs` : APIアクセスを許可するCIDR一覧

#### Control Plane ログ

-   `enabled_cluster_log_types` : 有効化するログタイプ

#### アドオン (`add_ons`)

-   `add_ons.kube_proxy_version` : kube-proxyバージョン
-   `add_ons.vpc_cni_version` : VPC CNIバージョン
-   `add_ons.core_dns_version` : CoreDNSバージョン

#### ノードグループ (`node_group`)

-   `node_group.node_role_name` : ノードIAMロール
-   `node_group.enabled_launch_template` : Launch Template使用可否
-   `node_group.launch_template_name` : Launch Template名
-   `node_group.launch_template_version` : Launch Templateバージョン
-   `node_group.min_node_count` : 最小ノード数
-   `node_group.max_node_count` : 最大ノード数
-   `node_group.desired_node_count` : 希望ノード数
-   `node_group.max_node_unavailable` : 更新時の最大非稼働ノード数
-   `node_group.max_percentage_unavailable` : 更新時の最大非稼働率
-   `node_group.disk_size` : ノードEBSサイズ（GB）

#### タグ

-   `tag` : Resourceを分類するためのタグ
