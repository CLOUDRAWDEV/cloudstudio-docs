## Resource Overview

AWS SNS において、コミュニケーションチャネルとして機能する論理的アクセスポイントです。

## Associated Resources

-   [**Metric**](https://docs.cstudio.app/ja/docs/resource/aws/Cloudwatch/Metric)

## Resource Setting Values

#### Basic Settings

-   `display_name` : SNS Topic の表示名
-   `type` : SNS Topic のタイプ (`FIFO`, `Standard`)
-   `kms_key_name` : SNS Topic に使用する KMS Key 名

#### タグ

-   `tag` : Resource をカテゴリ別に分類するためのタグ
