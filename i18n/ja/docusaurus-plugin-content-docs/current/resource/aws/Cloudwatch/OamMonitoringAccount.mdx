## リソース概要

AWS CloudWatch OAM Monitoring Accounts は、中央モニタリングアカウントを設定し、複数アカウントのアプリケーションを監視するサービスです。

## リソース設定値

#### 基本設定

-   `oam_source_accounts` : モニタリングアカウントとデータを共有するソースアカウント一覧（アカウント ID、組織パス、または組織 ID）
-   `resource_types` : ソースアカウントから共有されるデータ種別 - `AWS::Logs::LogGroup`, `AWS::CloudWatch::Metric`, `AWS::XRay::Trace`, `AWS::ApplicationInsights::Application`

#### タグ設定

-   `tag` : Resource を分類するためのタグ一覧
