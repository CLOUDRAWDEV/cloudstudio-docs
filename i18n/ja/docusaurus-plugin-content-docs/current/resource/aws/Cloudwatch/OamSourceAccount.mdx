## リソース概要

AWS CloudWatch OAM Source Accounts は、中央モニタリングアカウントと共有されるソースアカウントを構成します。

## 関連リソース

### 上位リソース

-   [**Region**](https://docs.cstudio.app/ja/docs/resource/aws/Base/Region)

### Connected Resources

-   [**OamMonitoringAccount**](https://docs.cstudio.app/ja/docs/resource/aws/CloudWatch/OamMonitoringAccount)

## リソース設定値

#### 基本設定

-   `is_manual` : 接続する OAM Source Account ARN を手動入力するかどうか - `true`, `false`
-   `linked_oam_monitoring_account_name` : 接続する OAM Monitoring Account 名
-   `oam_monitoring_account_arn` : データを共有するモニタリングアカウントの ARN
-   `resource_types` : モニタリングアカウントと共有するデータ種別 - `AWS::Logs::LogGroup`, `AWS::CloudWatch::Metric`, `AWS::XRay::Trace`, `AWS::ApplicationInsights::Application`
-   `label_template` : ソースアカウント識別用ラベル - `$AccountName`, `$AccountEmail`, `$AccountEmailNoDomain`

#### タグ

-   `tag` : Resource をカテゴリ別に分類するためのタグ
