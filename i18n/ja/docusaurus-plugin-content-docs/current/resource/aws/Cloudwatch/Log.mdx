## Resource Overview

Amazon CloudWatch Logsを使用すると、Amazon EC2、AWS CloudTrail、Route 53など、さまざまなソースからのシステム・アプリケーション・カスタムログを監視、保存、アクセスできます。  
CloudWatch Logsは高いスケーラビリティを備え、すべてのAWSサービスやアプリケーションのログを一元管理できます。  
ログの検索、フィルタリング、分析、可視化を行い、時系列で一貫したイベントストリームとして確認できます。

## Resource 設定値

#### Basic Settings

-   `retention_in_days` : ロググループでログを保持する日数
-   `kms_key_name` : ログ暗号化に使用するKMS Key名
-   `log_stream_names` : ロググループ内に作成するログストリーム名一覧

#### Metric Filter 設定 (`metric_filter`)

-   `metric_filter.pattern` : メトリクス抽出用CloudWatch Logsフィルターパターン
-   `metric_filter.metric_name` : 発行されるCloudWatch Metric名
-   `metric_filter.metric_namespace` : CloudWatch Metricネームスペース
-   `metric_filter.metric_value` : Metricに発行する値
    -   数値、数値フィールド識別子、`$requestSize`, `$.status` など参照可能

#### タグ設定 (`tag`)

-   `tag` : Resource分類用タグ一覧
