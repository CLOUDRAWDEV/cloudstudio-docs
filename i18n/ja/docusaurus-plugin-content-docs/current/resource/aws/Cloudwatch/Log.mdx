## リソース概要

Amazon CloudWatch Logs を使用すると、Amazon EC2、AWS CloudTrail、Route 53 など、さまざまなソースからのシステム・アプリケーション・カスタムログを監視、保存、アクセスできます。  
CloudWatch Logs は高いスケーラビリティを備え、すべての AWS サービスやアプリケーションのログを一元管理できます。  
ログの検索、フィルタリング、分析、可視化を行い、時系列で一貫したイベントストリームとして確認できます。

## リソース設定値

#### 基本設定

-   `retention_in_days` : ロググループでログを保持する日数
-   `kms_key_name` : ログ暗号化に使用する KMS Key 名
-   `log_stream_names` : ロググループ内に作成するログストリーム名一覧

#### Metric Filter 設定 (`metric_filter`)

-   `metric_filter.pattern` : メトリクス抽出用 CloudWatch Logs フィルターパターン
-   `metric_filter.metric_name` : 発行される CloudWatch Metric 名
-   `metric_filter.metric_namespace` : CloudWatch Metric ネームスペース
-   `metric_filter.metric_value` : Metric に発行する値
    -   数値、数値フィールド識別子、`$requestSize`, `$.status` など参照可能

#### タグ設定 (`tag`)

-   `tag` : Resource 分類用タグ一覧
