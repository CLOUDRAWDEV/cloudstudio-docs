## リソース概要

MariaDB は MySQL の元開発者によって作成された、人気のあるオープンソースのリレーショナルデータベースです。  
Amazon RDS を使用することで、クラウド上で MariaDB サーバーのデプロイ、運用、スケーリングを容易に行えます。
