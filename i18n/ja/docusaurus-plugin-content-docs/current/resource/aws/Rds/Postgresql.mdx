## リソース概要

AWS 上で PostgreSQL を使用した RDS を構築することで、データベースの運用と管理が容易になり、高い拡張性を実現できます。  
自動バックアップおよび復元機能により、データ損失を防止し、AWS が提供するセキュリティ機能で安全性を確保できます。
