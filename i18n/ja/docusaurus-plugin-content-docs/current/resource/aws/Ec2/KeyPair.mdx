## Resource Overview

AWS EC2インスタンスに接続する際、認証情報の検証に使用されるセキュリティ認証情報のセットです。

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/ja/docs/resource/aws/Base/Region)

## Resource 設定値

#### Basic Settings

-   `public_key` : ユーザーが生成したキーペアのPublic Key

#### タグ

-   `tag` : Resourceを分類するためのタグ
