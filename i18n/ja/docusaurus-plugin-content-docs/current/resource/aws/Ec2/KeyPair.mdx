## リソース概要

AWS EC2 インスタンスに接続する際、認証情報の検証に使用されるセキュリティ認証情報のセットです。

## 関連リソース

## リソース設定値

#### 基本設定

-   `public_key` : ユーザーが生成したキーペアの Public Key

#### タグ

-   `tag` : Resource を分類するためのタグ
