## リソース概要

VPC 内で仮想ネットワークカードを表す論理的ネットワークコンポーネントです。

## リソース設定値

#### 基本設定

-   `included_subnet_name` : Network Interface が配置される Subnet 名
-   `private_ips` : Private IP 一覧
-   `linked_security_group_names` : 使用する Security Group 名
-   `linked_eip_names` : 使用する Elastic IP 名

#### タグ

-   `tag` : Resource を分類するためのタグ
