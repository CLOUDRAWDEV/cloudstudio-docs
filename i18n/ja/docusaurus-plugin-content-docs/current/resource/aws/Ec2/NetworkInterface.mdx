## Resource Overview

VPC内で仮想ネットワークカードを表す論理的ネットワークコンポーネントです。

## Associated Resources

### Parent Resource

-   [**Subnet**](https://docs.cstudio.app/ja/docs/resource/aws/Vpc/Subnet)

### Connected Resources

-   [**Eip**](https://docs.cstudio.app/ja/docs/resource/aws/Ec2/Eip)
-   [**Instance**](https://docs.cstudio.app/ja/docs/resource/aws/Ec2/Instance)
-   [**SecurityGroup**](https://docs.cstudio.app/ja/docs/resource/aws/Vpc/SecurityGroup)

## Resource 設定値

#### Basic Settings

-   `included_subnet_name` : Network Interfaceが配置されるSubnet名
-   `private_ips` : Private IP一覧
-   `linked_security_group_names` : 使用するSecurity Group名
-   `linked_eip_names` : 使用するElastic IP名

#### タグ

-   `tag` : Resourceを分類するためのタグ
