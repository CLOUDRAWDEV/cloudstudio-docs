## リソース概要

Amazon Simple Storage Service（Amazon S3）は、業界最高水準のスケーラビリティ、データ可用性、セキュリティ、パフォーマンスを提供するオブジェクトストレージサービスです。  
あらゆる規模・業種の顧客が、データレイク、Web サイト、モバイルアプリケーション、バックアップと復元、アーカイブ、エンタープライズアプリケーション、IoT デバイス、ビッグデータ分析など、さまざまなユースケースで必要な量のデータを保存・保護できます。  
Amazon S3 は、ビジネス、組織、コンプライアンス要件に合わせてデータアクセスを最適化・構造化・管理する機能を提供します。

## Resource Setting Values

#### 基本設定

-   `versioning_status` : バケットのバージョニング状態 - `Enabled`, `Suspended`
-   `enabled_logging` : ロギング有効化可否 - `true`, `false`
-   `logging_target_prefix` : すべてのログオブジェクトキーに使用するプレフィックス
-   `sse_algorithm` : サーバーサイド暗号化アルゴリズム - `aws:kms`, `AES256`
-   `kms_key_name` : SSE-KMS 暗号化に使用する KMS キー名

#### パブリックアクセスブロック (`public_access_block`)

-   `public_access_block.block_public_acls` : パブリック ACL ブロック可否 - `true`, `false`
-   `public_access_block.block_public_policy` : パブリックバケットポリシーブロック可否 - `true`, `false`
-   `public_access_block.ignore_public_acls` : パブリック ACL 無視可否 - `true`, `false`
-   `public_access_block.restrict_public_buckets` : パブリックバケットポリシー制限可否 - `true`, `false`

#### オブジェクト所有権設定 (`ownership_control`)

-   `ownership_control.acl_enabled` : オブジェクト ACL 使用可否 - `true`, `false`
-   `ownership_control.object_ownership` : オブジェクト所有権方式 - `BucketOwnerEnforced`, `BucketOwnerPreferred`, `ObjectWriter`

#### タグ

-   `tag` : Resource をカテゴリ別に分類するためのタグ
