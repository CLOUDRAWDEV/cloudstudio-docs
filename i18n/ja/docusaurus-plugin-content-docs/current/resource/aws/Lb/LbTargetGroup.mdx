## リソース概要

指定したプロトコルとポートを使用して、EC2 インスタンスなどの対象にリクエストをルーティングするサービスです。

## リソース設定値

#### 基本設定

-   `target_type` : 対象タイプ
-   `protocol` : 使用プロトコル
-   `port` : ポート番号
-   `included_vpc_name` : VPC 名
-   `linked_instance_names` : Instance 名一覧
-   `ips` : Target IP 一覧
-   `linked_lambda_name` : Lambda 名
-   `linked_application_lb_name` : ALB 名

#### タグ

-   `tag` : リソースを分類するためのタグ
