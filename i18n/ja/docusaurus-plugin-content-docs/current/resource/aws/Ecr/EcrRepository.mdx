## リソース概要

Amazon Elastic Container Registry（Amazon ECR）は、安全でスケーラブルかつ信頼性の高い AWS マネージド型コンテナイメージレジストリサービスです。  
Amazon ECR は、AWS IAM を使用した Resource ベースの権限を持つプライベートリポジトリをサポートします。  
これにより、指定されたユーザーまたは Amazon EC2 インスタンスがコンテナリポジトリおよびイメージにアクセスできます。  
任意の CLI を使用して、Docker イメージ、OCI（Open Container Initiative）イメージ、OCI 互換アーティファクトのプッシュ、プル、管理が可能です。

## リソース設定値

#### 基本設定

-   `image_tag_mutability` : リポジトリタグの変更可否設定 - `IMMUTABLE`, `MUTABLE`
-   `scan_on_push` : イメージがプッシュされた後にスキャンを実行するかどうか - `true`, `false`
-   `encryption_type` : リポジトリに使用する暗号化方式 - `KMS`, `AES256`
-   `kms_key_name` : 使用する KMS Key の ARN 名

#### ポリシー (`policy`)

-   `policy.effect` : ポリシーステートメントの許可可否 - `Allow`, `Deny`
-   `policy.principal_arn` : ポリシーを適用する対象の ARN
-   `policy.enabled_not_actions` : 指定されたアクションを除外するかどうか - `true`, `false`
-   `policy.actions` : 指定するアクション一覧

#### タグ

-   `tag` : Resource を分類するためのタグ
