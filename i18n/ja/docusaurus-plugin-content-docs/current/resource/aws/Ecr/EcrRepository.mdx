## Resource Overview

Amazon Elastic Container Registry（Amazon ECR）は、安全でスケーラブルかつ信頼性の高いAWSマネージド型コンテナイメージレジストリサービスです。  
Amazon ECRは、AWS IAMを使用したResourceベースの権限を持つプライベートリポジトリをサポートします。  
これにより、指定されたユーザーまたはAmazon EC2インスタンスがコンテナリポジトリおよびイメージにアクセスできます。  
任意のCLIを使用して、Dockerイメージ、OCI（Open Container Initiative）イメージ、OCI互換アーティファクトのプッシュ、プル、管理が可能です。

## Resource 設定値

#### Basic Settings

-   `image_tag_mutability` : リポジトリタグの変更可否設定 - `IMMUTABLE`, `MUTABLE`
-   `scan_on_push` : イメージがプッシュされた後にスキャンを実行するかどうか - `true`, `false`
-   `encryption_type` : リポジトリに使用する暗号化方式 - `KMS`, `AES256`
-   `kms_key_name` : 使用するKMS KeyのARN名

#### ポリシー (`policy`)

-   `policy.effect` : ポリシーステートメントの許可可否 - `Allow`, `Deny`
-   `policy.principal_arn` : ポリシーを適用する対象のARN
-   `policy.enabled_not_actions` : 指定されたアクションを除外するかどうか - `true`, `false`
-   `policy.actions` : 指定するアクション一覧

#### タグ

-   `tag` : Resourceを分類するためのタグ
