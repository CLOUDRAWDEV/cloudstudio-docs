## リソース概要

他アカウントからのリソース共有（Resource Share）を受諾（accept）するかどうかを決定するリソースです。

-   [**ResourceShare**](https://docs.cstudio.app/ja/docs/resource/aws/RAM/ResourceShare)

---

## リソース設定値

#### 基本設定

-   `is_manual` : 接続する Resource Share ARN を直接入力するかどうか - `true`, `false`
-   `linked_resource_share_name` : 接続する Resource Share 名
-   `resource_share_arn` : 共有を許可する Resource Share の ARN

#### タグ

-   `tag` : リソースを分類するためのタグ
