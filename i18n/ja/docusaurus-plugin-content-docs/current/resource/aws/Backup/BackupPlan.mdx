## Resource Overview

AWS Resourceをバックアップする時期と方法を定義するポリシー表現です。  
Backup PlanにResourceを割り当てることができ、AWS BackupはBackup Planに基づいて該当Resourceのバックアップを自動的に実行し、保持します。

## Resource 設定値

#### Basic Settings

#### ルール (`rule`)

-   `rule.rule_name` : バックアップルール名、1〜50文字以内の英数字または `-`, `_`, `.` を含む文字
-   `rule.backup_vault_name` : バックアップ保存に使用される論理コンテナ名
-   `rule.frequency_type` : バックアップの周期タイミング - `Hourly`, `Weekly`, `Monthly`, `Custom`
-   `rule.frequency_hour` : バックアップ計画を初期化する時間 - 最小 `1`
-   `rule.frequency_days` : バックアップ計画を初期化する曜日 - `Sunday`, `Monday`, `Tuesday`, `Wednesday`, `Thursday`, `Friday`, `Saturday`
-   `rule.frequency_date` : バックアップ計画を初期化する日付 - `1` ~ `31`
-   `rule.start_time` : バックアップ計画の開始時間
-   `rule.custom_cron_expression` : バックアップ計画を開始する時期に対するユーザー定義表現
-   `rule.start_after_minutes` : バックアップ開始までにかかる総時間 - 最小 `60`
-   `rule.complete_after_minutes` : 作業をキャンセルしてエラーを返す前までにAWS Backupがバックアップを試行する時間（分）
-   `rule.enabled_use_cold_storage` : コールドストレージ使用可否 - `true`, `false`
-   `rule.warm_storage_retention_days` : 作成後、復旧ポイントをコールドストレージへ移行する指定日数 - `1` ~ `36410`
-   `rule.total_retention_days` : 復旧ポイント作成後、削除するまでの指定日数 - `1` ~ `36500`

#### Resource 割り当て (`resource_assignment`)

-   `resource_assignment.iam_role_arn` : 対象Resourceを復元およびバックアップする際にAWS Backupが認証に使用するIAMロールのARN
-   `resource_assignment.enabled_contain_all` : すべてのResourceを含めるかどうか - `true`, `false`
-   `resource_assignment.contain_arn_or_pattern` : Amazon Resource Nameを含む、またはバックアップ計画に割り当てるResourceパターンと一致する文字列配列
-   `resource_assignment.exclude_arn_or_pattern` : バックアップ計画から除外するResourceパターンと一致する、またはAmazon Resource Name（ARN）を含む文字列配列

#### タグ

-   `tag` : Resourceをカテゴリ別に分類するためのタグ - 最大 512文字, `key`:`value`
