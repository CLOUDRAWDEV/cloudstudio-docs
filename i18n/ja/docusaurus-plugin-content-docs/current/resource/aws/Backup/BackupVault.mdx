## リソース概要

AWS Backup において、Backup Vault はバックアップを保存および構成するコンテナです。  
Backup Vault を作成する際、この Vault 内の一部バックアップを暗号化するための AWS KMS 暗号化キーを指定する必要があります。

## リソース設定値

#### 基本設定

-   `kms_key_name` : バックアップを保護するために使用されるサーバー側暗号化キー

#### Vault Lock 設定 (`lock_configuration`)

-   `lock_configuration.enabled_lock` : Vault Lock 使用可否 - `true`, `false`
-   `lock_configuration.lock_mode` : Vault Lock の種類 - `Governance`, `Compliance`
-   `lock_configuration.min_retention_days` : Vault が復旧ポイントを保持する最小保持期間 - `1` ~ `36500`
-   `lock_configuration.max_retention_days` : Vault が復旧ポイントを保持する最大保持期間 - `1` ~ `36500`
-   `lock_configuration.changeable_for_days` : Lock 期限までの日数 - `3` ~ `36500`

#### タグ

-   `tag` : Resource をカテゴリ別に分類するためのタグ - 最大 512 文字, `key`:`value`
