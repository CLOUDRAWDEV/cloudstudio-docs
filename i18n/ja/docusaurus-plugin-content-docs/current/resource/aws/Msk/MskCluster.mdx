## リソース概要

リアルタイムデータストリーミングを処理する分散型メッセージブローカープラットフォームサービスです。

## リソース設定値

#### 基本設定

-   `cluster_type` : クラスタータイプ - `provisioned`, `serverless`
-   `kafka_version` : MSK クラスターで使用する Apache Kafka バージョン
-   `kms_key_name` : データ暗号化に使用する KMS キー名
-   `unauthenticated_access` : 未認証ユーザーのアクセス許可可否 - `true`, `false`
-   `iam_role_based_authentication` : IAM ロールベース認証許可可否 - `true`, `false`
-   `scram_authentication` : SCRAM ベース認証許可可否 - `true`, `false`
-   `cloudwatch_metrics` : CloudWatch メトリクス収集範囲 - `DEFAULT`, `PER_BROKER`, `PER_TOPIC_PER_BROKER`, `PER_TOPIC_PER_PARTITION`

#### ブローカー設定 (`broker`)

-   `broker.instance_type` : ブローカーインスタンスタイプ
-   `broker.broker_count_per_zone` : 可用性ゾーン（AZ）あたりのブローカー数

#### ストレージ設定 (`storage`)

-   `storage.ebs_volume_size` : ブローカーノードに割り当てる EBS ボリュームサイズ（GB）
-   `storage.enable_provisioned_throughput` : プロビジョンドスループット有効化可否 - `true`, `false`
-   `storage.provisioned_throughput_per_broker` : ブローカーあたりのプロビジョンドスループット（MiB/s）

#### ネットワーク設定 (`network`)

-   `network.linked_vpc_name` : クラスターが接続される VPC 名
-   `network.subnet_names` : MSK クラスターに接続する Subnet 名一覧
-   `network.security_group_names` : MSK クラスターに適用する Security Group 名一覧

#### タグ

-   `tag` : リソースを分類するためのタグ
