## Resource Overview

CloudFront Cache Policyは、CloudFrontディストリビューションのキャッシュ動作に関連付けて、CloudFrontのカスタマイズを設定するキャッシュポリシーです。

## Resource 設定値

#### Basic Settings

-   `min_ttl` : オブジェクトがキャッシュに保持される最小時間（秒）
-   `default_ttl` : オブジェクトがキャッシュに保持されるデフォルト時間（秒）
-   `max_ttl` : オブジェクトがキャッシュに保持される最大時間（秒）

#### Cookie 設定 (`cookie_config`)

-   `cookie_behavior` : Cookie転送方式 - `whitelist`, `all`, `none`, `allExcept`
-   `cookies_items` : オリジンへ転送するCookie一覧

#### Header 設定 (`header_config`)

-   `header_behavior` : ヘッダーベースのキャッシュ方式 - `whitelist`, `none`
-   `headers_items` : キャッシュに使用するヘッダー一覧

#### Query String 設定 (`query_string_config`)

-   `query_string_behavior` : クエリ文字列の処理方式 - `whitelist`, `all`, `none`, `allExcept`
-   `query_strings_items` : キャッシュに使用するクエリパラメータ一覧
