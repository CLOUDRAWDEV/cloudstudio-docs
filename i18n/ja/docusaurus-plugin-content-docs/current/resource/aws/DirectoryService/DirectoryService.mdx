## リソース概要

AWS Directory Service は、他の AWS サービスで Microsoft Active Directory（AD）を利用するための複数の方法を提供します。  
ディレクトリはユーザー、グループ、デバイスに関する情報を保存し、管理者はそれを使用して情報および Resource へのアクセスを管理します。  
AWS Directory Service は、クラウド上で既存の Microsoft AD または LDAP（Lightweight Directory Access Protocol）対応アプリケーションを利用したい顧客に対し、さまざまなディレクトリ選択肢を提供します。  
また、ユーザー、グループ、デバイス、およびアクセス権限を管理するためにディレクトリを必要とする開発者にも同様の選択肢を提供します。

## リソース設定値

#### 基本設定

-   `password` : ディレクトリ管理者またはコネクタユーザーのパスワード
-   `type` : ディレクトリのタイプ - `SimpleAD`, `MicrosoftAD`
-   `size` : ディレクトリのサイズ - `Small`, `Large`
-   `edition` : MicrosoftAD のエディション - `Standard`, `Enterprise`
-   `included_vpc_name` : ディレクトリが存在する VPC 名
-   `included_subnet_names` : ディレクトリサーバーのサブネット名

#### タグ

-   `tag` : Resource を分類するためのタグ
