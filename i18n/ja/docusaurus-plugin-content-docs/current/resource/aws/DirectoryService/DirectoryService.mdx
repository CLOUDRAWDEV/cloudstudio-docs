## Resource Overview

AWS Directory Serviceは、他のAWSサービスでMicrosoft Active Directory（AD）を利用するための複数の方法を提供します。  
ディレクトリはユーザー、グループ、デバイスに関する情報を保存し、管理者はそれを使用して情報およびResourceへのアクセスを管理します。  
AWS Directory Serviceは、クラウド上で既存のMicrosoft ADまたはLDAP（Lightweight Directory Access Protocol）対応アプリケーションを利用したい顧客に対し、さまざまなディレクトリ選択肢を提供します。  
また、ユーザー、グループ、デバイス、およびアクセス権限を管理するためにディレクトリを必要とする開発者にも同様の選択肢を提供します。

## Resource 設定値

#### Basic Settings

-   `password` : ディレクトリ管理者またはコネクタユーザーのパスワード
-   `type` : ディレクトリのタイプ - `SimpleAD`, `MicrosoftAD`
-   `size` : ディレクトリのサイズ - `Small`, `Large`
-   `edition` : MicrosoftADのエディション - `Standard`, `Enterprise`
-   `included_vpc_name` : ディレクトリが存在するVPC名
-   `included_subnet_names` : ディレクトリサーバーのサブネット名

#### タグ

-   `tag` : Resourceを分類するためのタグ
