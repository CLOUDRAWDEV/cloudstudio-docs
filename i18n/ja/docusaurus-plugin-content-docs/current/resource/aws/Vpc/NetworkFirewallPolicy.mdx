## リソース概要

AWS Network Firewall に適用する監視および保護動作を定義するポリシー。

## 関連リソース

### 上位リソース

-   [**Region**](https://docs.cstudio.app/ja/docs/resource/aws/Base/Region)

### 接続リソース

-   [**NetworkFirewallRuleGroup**](https://docs.cstudio.app/ja/docs/resource/aws/Vpc/NetworkFirewallRuleGroup)
-   [**NetworkFirewall**](https://docs.cstudio.app/ja/docs/resource/aws/Vpc/NetworkFirewall)

## リソース設定値

#### 基本設定

-   `description` : ポリシー説明（最大 256 文字）
-   `stream_exception_policy` : ストリーム中断時の処理 - `DROP`, `CONTINUE`, `REJECT`

#### タグ

-   `tag` : リソース分類用タグ
