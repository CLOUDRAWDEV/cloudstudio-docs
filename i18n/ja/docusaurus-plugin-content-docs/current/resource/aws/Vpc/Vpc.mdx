## リソース概要

Amazon Virtual Private Cloud(Amazon VPC) を使用することで、Resource 配置、接続、セキュリティを含む仮想ネットワーク環境を完全に制御可能。  
AWS 管理コンソールから VPC を設定後、EC2 や RDS などの Resource を VPC に追加する。  
さらに、アカウント・アベイラビリティゾーン・AWS リージョン間での通信方法を定義可能。  
下記例では、各リージョン内の 2 つの VPC 間でネットワークトラフィックが共有される。

## リソース設定値

#### 基本設定

-   `cidr_block` : VPC の IP アドレス範囲(CIDR)
-   `enabled_dns_support` : DNS 解決有効化 여부 - `true`, `false`
-   `enabled_dns_hostnames` : DNS ホスト名割り当て有効化 여부 - `true`, `false`

#### タグ

-   `tag` : Resource をカテゴリ別に分類するためのタグ
