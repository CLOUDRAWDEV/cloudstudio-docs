## リソース概要

Virtual Private Gateway は Site-to-Site VPN 接続における Amazon 側の VPN 集約装置。  
Virtual Private Gateway を作成し、Site-to-Site VPN 接続を作成する VPC に接続する。

## リソース設定値

#### 基本設定

-   `linked_vpc_name` : VPN Gateway を接続する VPC 名
-   `dx_gateway` : Direct Connect Gateway 連携設定
-   `dx_gateway.linked_dx_gateway` : 接続する Dx Gateway 名
-   `dx_gateway.allowed_prefixes` : オンプレミスネットワークへ広告する CIDR Prefix 一覧

#### タグ

-   `tag` : Resource をカテゴリ別に分類するためのタグ
