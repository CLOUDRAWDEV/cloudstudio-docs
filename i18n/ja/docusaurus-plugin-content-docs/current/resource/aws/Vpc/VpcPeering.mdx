## リソース概要

VPC は AWS アカウント専用の仮想ネットワーク。  
VPC ピアリング接続は、プライベート IPv4 または IPv6 アドレスを使用して 2 つの VPC 間でトラフィックをルーティングするためのネットワーク接続。  
同一ネットワーク内にあるかのように VPC 内インスタンス同士の通信が可能。  
同一アカウントまたは他アカウントの VPC 間でピアリング接続を作成可能。  
VPC は異なるリージョン間でも接続可能（リージョン間 VPC ピアリング）。

## リソース設定値

#### 基本設定

-   `linked_vpc_name_01` : ピアリング接続を要求する VPC 名
-   `linked_vpc_name_02` : ピアリング接続対象 VPC 名
-   `auto_accept` : ピアリング接続自動承認 여부 - `true`, `false`

#### タグ

-   `tag` : Resource をカテゴリ別に分類するためのタグ
