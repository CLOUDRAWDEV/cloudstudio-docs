## リソース概要

インターネットゲートウェイは、水平方向にスケール可能で高可用性を備えた冗長な VPC コンポーネント。  
VPC とインターネット間の通信を可能にし、IPv4 および IPv6 トラフィックをサポート。  
可用性リスクや帯域幅制約を発生させない設計。

パブリック IPv4 または IPv6 アドレスを持つリソースは、インターネットゲートウェイ経由でインターネット接続が可能。  
インターネット側リソースからも、パブリック IP アドレスを使用してサブネット内リソースへの接続開始が可能。  
VPC ルートテーブルにおいて、インターネット向けトラフィックの宛先として機能。

IPv4 通信では NAT を実行。  
IPv6 通信ではアドレスがパブリックであるため NAT は不要。
