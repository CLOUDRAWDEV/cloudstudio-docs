## リソース概要

他アカウントの Resource 共有に対する許可可否を決定する Resource。

## 関連リソース

### 上位リソース

-   [**Region**](https://docs.cstudio.app/ja/docs/resource/aws/Base/Region)

### 接続リソース

-   [**TransitGatewayAttachment**](https://docs.cstudio.app/ja/docs/resource/aws/Vpc/TransitGatewayAttachment)

## リソース設定値

#### 基本設定

-   `is_manual` : Transit Gateway Attachment ID を直接入力するか 여부 - `true`, `false`
-   `transit_gateway_attachment_id` : 共有を許可する Transit Gateway Attachment ID
-   `linked_transit_gateway_attachment_name` : 共有を許可する Transit Gateway Attachment 名

#### タグ

-   `tag` : Resource をカテゴリ別に分類するためのタグ
