## リソース概要

VPC とオンプレミスネットワークを接続するために使用されるサービス。

## リソース設定値

#### 基本設定

-   `linked_transit_gateway_name` : VPC と接続する Transit Gateway 名
-   `is_manual` : 接続する VPC ID を手動入力するか 여부 - `true`, `false`
-   `linked_vpc_name` : Transit Gateway を接続する VPC 名
-   `subnet_names` : Transit Gateway と接続する Subnet 名一覧

#### 手動接続設定 (`manual`)

-   `vpc_id` : Transit Gateway を接続する VPC ID
-   `subnet_ids` : 指定した VPC 内の Subnet ID 一覧

#### タグ

-   `tag` : Resource をカテゴリ別に分類するためのタグ
