## リソース概要

NAT ゲートウェイは Network Address Translation（NAT）サービス。  
プライベートサブネット内インスタンスが VPC 外部サービスへ通信可能とし、外部からの接続開始は不可とする構成を提供。

## リソース設定値

#### 基本設定

-   `included_subnet_name` : NAT Gateway を接続する Subnet 名
-   `connectivity_type` : 接続タイプ - `public`, `private`
-   `linked_eip_name` : 接続する Elastic IP 名

#### タグ

-   `tag` : リソース分類用タグ
