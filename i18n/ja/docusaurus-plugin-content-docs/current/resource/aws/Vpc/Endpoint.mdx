## リソース概要

サポート対象の AWS サービスおよび VPC エンドポイントサービスへプライベート接続を提供するサービス

## リソース設定値

#### 基本設定

-   `service_range` : Endpoint サービス利用範囲 - `awsService`, `endpointService`
-   `aws_service_name` : 使用する AWS サービス名
-   `vpc_endpoint_type` : Endpoint 種別 - `Gateway`, `Interface`, `GatewayLoadBalancer`
-   `included_vpc_name` : Endpoint を作成する VPC 名
-   `enabled_private_dns` : プライベート DNS 有効化可否 - `true`, `false`
-   `enable_private_dns_only_for_inbound_resolver_endpoint` : インバウンド要求に対するプライベート DNS のみ有効化可否 - `true`, `false`
-   `dns_record_ip_type` : DNS レコード IP 種別 - `ipv4`, `dualstack`, `servicedefined`, `ipv6`
-   `ip_address_type` : Endpoint IP アドレス種別 - `ipv4`, `ipv6`, `dualstack`
-   `policy_access` : Endpoint ポリシーアクセス範囲 - `Full`, `Custom`
-   `custom_policy` : サービスアクセス制御用カスタムポリシー

#### Endpoint Service 設定 (`endpoint_service`)

-   `endpoint_service.is_manual` : Endpoint Service ARN 直接入力可否 - `true`, `false`
-   `endpoint_service.service_name` : Endpoint Service 名
-   `endpoint_service.linked_endpoint_service_name` : 接続する Endpoint Service 名

#### ネットワーク設定

-   `linked_security_group_names` : 接続する Security Group 一覧
-   `linked_subnet_names` : ネットワークインターフェース作成 Subnet 一覧
-   `route_table_names` : 接続する Route Table 一覧

#### タグ

-   `tag` : リソースをカテゴリ別に分類するためのタグ
