## リソース概要

Transit Gateway は、VPC とオンプレミスネットワークを相互接続するためのネットワーク転送ハブ。  
クラウドインフラがグローバルに拡張されるにつれ、リージョン間ピアリングは AWS グローバルインフラを使用して Transit Gateway 同士を接続する。  
データは自動的に暗号化され、パブリックインターネットを経由しない。

## リソース設定値

#### 基本設定

-   `dns_support` : 接続された VPC に対する DNS 解決有効化 여부 - `enable`, `disable`
-   `vpn_ecmp_support` : 接続 VPN に対する ECMP ルーティング対応 여부 - `enable`, `disable`
-   `default_route_table_association` : Attachment をデフォルトルートテーブルに自動関連付け - `enable`, `disable`
-   `default_route_table_propagation` : Attachment をデフォルトルートテーブルへ自動伝播 - `enable`, `disable`
-   `multicast_support` : マルチキャストドメイン生成有効化 여부 - `enable`, `disable`
-   `transit_gateway_cidr_blocks` : Transit Gateway に割り当てる CIDR ブロック一覧

#### Direct Connect Gateway 設定 (`dx_gateway`)

-   `dx_gateway.linked_dx_gateway` : 接続する Direct Connect Gateway 名
-   `dx_gateway.allowed_prefixes` : オンプレミスネットワークへ広告する VPC Prefix(CIDR) 一覧

#### タグ

-   `tag` : Resource をカテゴリ別に分類するためのタグ
