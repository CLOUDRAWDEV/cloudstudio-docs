## リソース概要

AWS Transit Gateway は中央ハブを通じて Amazon VPC とオンプレミスネットワークを接続し、複雑なピアリング構成を排除してネットワーク構成を簡素化する。  
高い拡張性を持つクラウドルーターとして機能する。

## リソース設定値

#### 基本設定

-   `bgp_asn` : ゲートウェイの BGP ASN 値 - `1` ~ `2147483647`
-   `ip_address` : ゲートウェイ外部インターフェースの固定パブリック IP アドレス
-   `private_certificate_arn` : AWS Private Certificate Manager 証明書 ARN

#### VPN 接続設定 (`vpn_connection`)

-   `vpn_connection.resource_type` : Customer Gateway と接続するリソース種別 - `none`, `transit_gateway`, `vpn_gateway`
-   `vpn_connection.linked_resource_name` : 接続対象リソース名
-   `vpn_connection.static_routes_only` : スタティックルーティングのみ使用可否 - `true`, `false`
-   `vpn_connection.outside_ip_address_type` : 外部 IP アドレス種別 - `PublicIpv4`, `PrivateIpv4`
-   `vpn_connection.dx_gateway_name` : プライベート IP VPN 接続に使用する Transit Gateway Attachment 名

#### タグ

-   `tag` : リソースをカテゴリ別に分類するためのタグ
