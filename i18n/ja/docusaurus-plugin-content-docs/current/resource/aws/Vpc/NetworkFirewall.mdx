## リソース概要

AWS アカウントおよびリソース全体に対してネットワーク保護を構成可能なマネージド型ファイアウォールサービス。

## 関連リソース

## リソース設定値

#### 基本設定

-   `description` : ファイアウォール説明（最大 256 文字）
-   `included_vpc_name` : 配置 VPC 名（読み取り専用）
-   `linked_subnet_names` : ファイアウォールエンドポイント専用サブネット
-   `linked_network_firewall_policy_name` : 適用ポリシー名（読み取り専用）
-   `enabled_delete_protection` : 削除保護 - `true`, `false`
-   `enabled_subnet_change_protection` : サブネット変更保護 - `true`, `false`

#### 暗号化設定 (`encryption_configuration`)

-   `encryption_configuration.enabled_custom_configuration` : AWS 管理キー暗号化 - `true`, `false`
-   `encryption_configuration.kms_key_name` : 使用 KMS Key 名

#### タグ

-   `tag` : リソース分類用タグ
