## リソース概要

VPC フローログは、VPC ネットワークインターフェースを通過する送受信 IP トラフィック情報を収集する機能。  
収集データは Amazon CloudWatch Logs、Amazon S3、Amazon Kinesis Data Firehose に出力可能。

## リソース設定値

#### 基本設定

-   `linked_log_destination_type` : ログ保存先種別（S3, CloudWatch Logs）
-   `linked_log_destination_name` : ログ保存先名
-   `traffic_type` : 収集対象トラフィック種別 - `ALL`, `ACCEPT`, `REJECT`
-   `included_vpc_name` : Flow Log を接続する VPC 名

#### タグ

-   `tag` : リソースをカテゴリ別に分類するためのタグ
