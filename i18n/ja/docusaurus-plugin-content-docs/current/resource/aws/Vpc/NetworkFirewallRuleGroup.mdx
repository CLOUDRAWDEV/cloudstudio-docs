## リソース概要

ネットワークトラフィックを検査・処理するための再利用可能なルールセット。

### 接続リソース

## リソース設定値

#### 基本設定

-   `description` : ルールグループ説明（最大 256 文字）
-   `rule_group_type` : タイプ - `STATEFUL`, `STATELESS`
-   `generated_rules_type` : 形式 - `StandardStatefulRules`, `DomainList`, `SuricataRuleStrings`
-   `rule_evaluation_order` : 評価順序 - `STRICT_ORDER`, `DEFAULT_ACTION_ORDER`
-   `capacity` : ルール容量（WCU）- `1` ~ `30000`

#### タグ

-   `tag` : リソース分類用タグ
