## リソース概要

サポート対象の AWS サービスおよび VPC Endpoint へのプライベート接続を提供するサービス

-   [**Endpoint**](https://docs.cstudio.app/ja/docs/resource/aws/Vpc/Endpoint)

## リソース設定値

#### 基本設定

-   `acceptance_required` : Endpoint 接続要求に対するサービス所有者承認要否 - `true`, `false`
-   `load_balancer_type` : 接続する Load Balancer 種別 - `network`, `gateway`
-   `linked_lb_names` : 接続する Load Balancer 名一覧
-   `manual_lb_arns` : 接続する Load Balancer ARN 一覧
-   `supported_ip_address_types` : サポート対象 IP アドレス種別 - `ipv4`
-   `activate_private_dns_name` : サービスに設定するプライベート DNS 名

#### タグ

-   `tag` : リソースをカテゴリ別に分類するためのタグ
