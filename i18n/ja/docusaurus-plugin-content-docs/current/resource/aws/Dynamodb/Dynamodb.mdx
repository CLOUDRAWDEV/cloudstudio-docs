## Resource 設定値

#### Basic Settings

-   `billing_mode` : DynamoDBの読み取り／書き込みスループットに対する課金および容量管理方式 - `PROVISIONED`, `PAY_PER_REQUEST`
-   `read_capacity` : DynamoDBテーブルの読み取りキャパシティユニット数
-   `write_capacity` : DynamoDBテーブルの書き込みキャパシティユニット数
-   `hash_key` : ハッシュ（パーティション）キーとして使用する属性
-   `hash_key_type` : ハッシュ（パーティション）キーの属性型 - `S`, `N`, `B`
-   `range_key` : レンジ（ソート）キーとして使用する属性
-   `range_key_type` : レンジ（ソート）キーの属性型 - `S`, `N`, `B`
-   `point_in_time_recovery_enabled` : 特定時点復旧（PITR）有効化可否 - `true`, `false`

#### サーバー側暗号化 (`server_side_encryption`)

-   `server_side_encryption.encryption_enabled` : AWS管理KMSキーによる保存データ暗号化有効化可否 - `true`, `false`
-   `server_side_encryption.kms_key_name` : 使用するAWS KMS CMK名

#### タグ

-   `tag` : Resourceを分類するためのタグ
