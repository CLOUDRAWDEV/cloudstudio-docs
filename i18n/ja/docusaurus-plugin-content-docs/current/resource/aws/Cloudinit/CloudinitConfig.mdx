## リソース設定値

#### 基本設定

-   `gzip` : データ圧縮アルゴリズム使用可否 - `true`, `false`

#### Part 設定 (`part`)

-   `part.content_type` : 挿入するデータ形式 - `text/cloud-config`, `text/x-shellscript`, `text/cloud-boothook`, `multipart/mixed`, `text/cloud-config-archive`, `text/jinja`, `text/x-include-url`, `text/part-handler`
-   `part.content` : 挿入する実データ内容

#### タグ

-   `tag` : Resource を分類するためのタグ
