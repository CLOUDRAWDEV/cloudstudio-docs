## リソース概要

AWS Lambda は、サーバーをプロビジョニングや管理することなくコードを実行できるコンピューティングサービスです。  
高可用性インフラ上でコードを実行し、サーバーや OS の管理、キャパシティ調整、パッチ適用、ロギングなどを自動で処理します。  
対応する言語でコードを提供するだけで、ほぼすべてのアプリケーションやバックエンドサービスを実行できます。

## リソース設定値

#### 基本設定

-   `architectures` : 命令セットアーキテクチャ - `x86_64`, `arm64`
-   `runtime` : Lambda ランタイム識別子
-   `memory_size` : 使用可能メモリ（MB）
-   `handler` : 関数エントリポイント
-   `s3_bucket_name` : 配布パッケージを格納する S3 Bucket 名
-   `file_directory` : S3 内のパッケージパス
-   `role_name` : 適用する IAM Role 名
-   `included_subnet_names` : 接続する Subnet 名一覧
-   `linked_security_group_names` : 接続する Security Group 名一覧
-   `tracing_mode` : X-Ray トレース方式

#### 環境変数 (`environment_variable`)

-   `environment_variable` : 実行時に使用する環境変数

#### タグ

-   `tag` : リソースを分類するためのタグ
