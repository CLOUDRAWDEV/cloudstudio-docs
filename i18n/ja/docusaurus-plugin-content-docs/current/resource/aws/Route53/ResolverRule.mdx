## リソース概要

指定されたドメイン名のクエリをネットワークへ転送する際に Resolver が使用するルールです。

## リソース設定値

#### 基本設定

-   `rule_type` : ルールタイプ - `FORWARD`, `SYSTEM`
-   `domain_name` : DNS クエリが転送されるドメイン名
-   `linked_vpc_names` : ルールを使用する VPC 名一覧
-   `linked_resolver_endpoint_name` : Resolver が使用するアウトバウンドエンドポイント名
-   `target_ip.ip` : Target IP アドレス
-   `target_ip.port` : Target IP アドレスのポート

#### タグ

-   `tag` : Resource をカテゴリ別に分類するためのタグ
