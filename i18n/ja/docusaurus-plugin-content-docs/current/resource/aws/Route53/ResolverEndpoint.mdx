## リソース概要

Amazon VPC と送受信される DNS クエリに対するエンドポイントサービスです。

## 関連リソース

-   [**ResolverRule**](https://docs.cstudio.app/ja/docs/resource/aws/Route53/ResolverRule)

## Resource Setting Values

#### 基本設定

-   `direction` : DNS クエリの方向 - `INBOUND`, `OUTBOUND`
-   `linked_vpc_name` : エンドポイントと接続する VPC 名
-   `linked_security_group_names` : エンドポイントに適用するセキュリティグループ名一覧
-   `ip_address.subnet_name` : 使用する Subnet 名
-   `ip_address.ip` : Subnet 内で使用可能な IP アドレス

#### タグ

-   `tag` : Resource をカテゴリ別に分類するためのタグ
