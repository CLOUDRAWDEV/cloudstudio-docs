## Resource Overview

AWS Bedrockエージェントが実行できる特定のアクションを定義および管理するResourceです。

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/ja/docs/resource/aws/Base/Region)

---

## Resource 設定値

#### Basic Settings

-   `target_bedrock_agent` : アクショングループが接続される対象のBedrockエージェント
-   `enable_action_group_state` : Action Groupの状態保持機能を有効化するかどうか - `ENABLED`, `DISABLED`
-   `custom_control_method` : エージェントの動作制御方式 - `custom_control`, `lambda_function`
-   `target_lambda_function` : アクション実行時に呼び出されるAWS Lambda関数

#### 関数定義 (`functions`)

-   `functions.description` : 関数が実行する処理の目的または機能の説明（最大5000文字）

##### 関数パラメータ (`functions.parameters`)

-   `functions.parameters.type` : パラメータのデータ型 - `string`, `number`, `integer`, `boolean`, `array`
-   `functions.parameters.description` : パラメータの意味または用途
-   `functions.parameters.required` : 必須入力かどうか - `true`, `false`
