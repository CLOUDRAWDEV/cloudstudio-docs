## Resource 設定値

#### Basic Settings

-   `foundation_model` : Bedrockで使用する基本LLM（基盤モデル）を指定するオプション - `amazon.titan-text-express-v1`, `amazon.nova-pro-v1`, `amazon.nova-lite-v1`, `amazon.nova-micro-v1`, `anthropic.claude-sonnet-4-20250514-v1:0`, `anthropic.claude-sonnet-4-5-20250929-v1:0`, `anthropic.claude-haiku-4-5-20251001-v1:0`, `anthropic.claude-3-sonnet-20240229-v1:0`, `anthropic.claude-3-opus-20240229-v1:0`, `anthropic.claude-3-haiku-20240307-v1:0`, `anthropic.claude-3-5-sonnet-20240620-v1:0`, `anthropic.claude-3-5-sonnet-20241022-v2:0`, `anthropic.claude-3-5-haiku-20241022-v1:0`, `anthropic.claude-3-7-sonnet-20250219-v1:0`, `deepseek.r1-v1`, `openai.gpt-oss-120b-1`, `openai.gpt-oss-20b-1`, `qwen.qwen3-coder-30b-a3b-v1`, `qwen.qwen3-32b-v1`
-   `description` : 該当エージェントに関する説明
-   `idle_session_ttl_in_seconds` : セッションがアイドル状態の際に自動終了されるまでの時間（秒）
-   `instruction` : エージェントが従う基本指示文（システムプロンプト）
-   `customer_encryption_key_arn` : 指定したKMSキー（ARN）でBedrock Resourceデータを暗号化する設定
-   `target_bedrock_knowledge_base` : 知識ベースと接続するBedrockエージェントのARN
-   `knowledge_base_association_description` : 知識ベースとエージェント間の関連付けに関する説明
-   `knowledge_base_state` : 知識ベースの現在の状態 - `ENABLED`, `DISABLED`

#### ガードレール設定 (`guardrail_configuration`)

-   `guardrail_configuration.guardrail_use_method` : ガードレール適用方式の指定 - `already_exists`, `create_new`
-   `guardrail_configuration.guardrail_identifier` : 使用するガードレールの一意識別子（ID）
-   `guardrail_configuration.target_bedrock_guardrail` : 接続するBedrockガードレールResource
-   `guardrail_configuration.guardrail_version` : 使用するガードレールResourceのバージョン

#### プロンプトオーバーライド設定 (`prompt_override_configuration`)

#### プロンプト設定 (`prompt_override_configuration.prompt_configurations`)

-   `prompt_override_configuration.prompt_configurations.prompt_creation_mode` : プロンプトを自動生成するか手動指定するか - `DEFAULT`, `OVERRIDDEN`
-   `prompt_override_configuration.prompt_configurations.prompt_type` : プロンプトの種類 - `PRE_PROCESSING`, `ORCHESTRATION`, `POST_PROCESSING`, `KNOWLEDGE_BASE_RESPONSE_GENERATION`
-   `prompt_override_configuration.prompt_configurations.base_prompt_template` : プロンプトの基本文構造（テンプレート）
-   `prompt_override_configuration.prompt_configurations.prompt_state` : プロンプトの現在状態 - `ENABLED`, `DISABLED`
-   `prompt_override_configuration.prompt_configurations.parser_mode` : モデル出力形式の解析方式 - `DEFAULT`, `OVERRIDDEN`
-   `prompt_override_configuration.prompt_configurations.max_length` : モデル応答の最大長
-   `prompt_override_configuration.prompt_configurations.stop_sequences` : テキスト生成を停止する文字列シーケンス
-   `prompt_override_configuration.prompt_configurations.temperature` : 生成結果の創造性（ランダム性）
-   `prompt_override_configuration.prompt_configurations.top_p` : 確率累積値による語彙選択制限
-   `prompt_override_configuration.prompt_configurations.top_k` : 上位K個の高確率単語のみを候補にする設定

-   `prompt_override_configuration.override_lambda` : 基本プロンプト動作をカスタマイズするために呼び出すAWS Lambda関数
