## リソース概要

AWS Service Catalog を使用すると、IT 管理者は承認済み製品で構成されたポートフォリオを作成・管理し、エンドユーザーに配布できます。  
エンドユーザーはパーソナライズされたポータルから必要な製品にアクセスできます。  
一般的な製品には、Amazon EC2 インスタンスや Amazon RDS データベースなど、AWS リソースを使用してデプロイされるサーバー、データベース、Web サイト、アプリケーションが含まれます。  
特定の製品にアクセスできるユーザーを制御することで、組織のビジネス標準およびコンプライアンスを適用し、製品ライフサイクルを管理できます。

## リソース設定値

#### 基本設定

-   `description` : ポートフォリオの説明
-   `provider_name` : ポートフォリオを所有する個人または組織の名前

#### タグ

-   `tag` : Resource をカテゴリ別に分類するためのタグ
