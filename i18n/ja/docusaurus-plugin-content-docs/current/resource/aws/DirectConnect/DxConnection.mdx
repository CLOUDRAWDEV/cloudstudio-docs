## リソース概要

AWS Direct Connect は、標準的なイーサネット光ファイバーケーブルを使用して、オンプレミスネットワークを AWS Direct Connect ロケーションに接続します。  
この接続により、インターネットサービスプロバイダーを経由せず、Amazon S3 や Amazon VPC などの AWS サービスへ直接通信できます。

## リソース設定値

#### 基本設定

-   `bandwidth` : Direct Connection の帯域幅 - `1Gbps`, `2Gbps`, `5Gbps`, `10Gbps`, `100Gbps`
-   `location` : 接続される AWS Direct Connect ロケーション
-   `service_provider` : 接続を提供するサービスプロバイダー

#### タグ

-   `tag` : Resource 分類用タグ
