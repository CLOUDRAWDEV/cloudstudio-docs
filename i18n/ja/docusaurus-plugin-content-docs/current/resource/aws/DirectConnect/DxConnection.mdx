## Resource Overview

AWS Direct Connectは、標準的なイーサネット光ファイバーケーブルを使用して、オンプレミスネットワークをAWS Direct Connectロケーションに接続します。  
この接続により、インターネットサービスプロバイダーを経由せず、Amazon S3やAmazon VPCなどのAWSサービスへ直接通信できます。

## Associated Resources

## Resource 設定値

#### Basic Settings

-   `bandwidth` : Direct Connectionの帯域幅 - `1Gbps`, `2Gbps`, `5Gbps`, `10Gbps`, `100Gbps`
-   `location` : 接続されるAWS Direct Connectロケーション
-   `service_provider` : 接続を提供するサービスプロバイダー

#### タグ

-   `tag` : Resource分類用タグ
