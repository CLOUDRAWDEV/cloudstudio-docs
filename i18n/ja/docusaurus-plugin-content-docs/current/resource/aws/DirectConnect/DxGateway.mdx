## リソース概要

Direct Connect 接続を通じて、AWS リージョン内の VPC へアクセスできるようにする DxGateway です。

## 関連リソース

-   [**VpnGateway**](https://docs.cstudio.app/ja/docs/resource/aws/Vpc/VpnGateway)

## リソース設定値

#### 基本設定

-   `side_asn` : Amazon 側 ASN（自律システム番号）
