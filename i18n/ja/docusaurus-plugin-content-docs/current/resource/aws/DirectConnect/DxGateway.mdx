## Resource Overview

Direct Connect接続を通じて、AWSリージョン内のVPCへアクセスできるようにするDxGatewayです。

## Associated Resources

### Parent Resource

-   [**Base**](https://docs.cstudio.app/ja/docs/resource/aws/Base/Base)

### Connected Resources

-   [**TransitGateway**](https://docs.cstudio.app/ja/docs/resource/aws/Vpc/TransitGateway)
-   [**VpnGateway**](https://docs.cstudio.app/ja/docs/resource/aws/Vpc/VpnGateway)

## Resource 設定値

#### Basic Settings

-   `side_asn` : Amazon側ASN（自律システム番号）
