## リソース概要

Azure SQL Server（Microsoft SQL Server）は、アップグレード、パッチ適用、バックアップ、監視など、  
ほとんどのデータベース管理機能をユーザーの介入なしで処理する、完全に管理された PaaS データベースエンジンです。

## リソース設定値

#### 基本設定

-   `version` : 使用する Microsoft SQL Server のバージョン - `2.0`, `12.0`
-   `admin_username` : サーバーの管理者ユーザー名。英数字のみ使用可能、英字で開始する必要があり、予約語は使用不可
-   `admin_password` : サーバー管理者のログインパスワード。小文字／大文字／数字／特殊文字のうち 3 種類以上を含める必要があり、ログイン名に含まれる 3 文字以上の連続した英数字は使用不可、`8` ～ `128` 文字
-   `minimum_tls_version` : サーバーでサポートされる最小 TLS バージョン - `1.2`, `Disabled`
-   `public_network_access_enabled` : サーバーへのパブリックネットワークアクセスを許可するかどうか - `true`, `false`

#### ファイアウォールルール（`firewall_rule`）

-   `firewall_rule.start_ip_address` : ファイアウォールルールに関連付けられた開始 IP アドレス
-   `firewall_rule.end_ip_address` : ファイアウォールルールに関連付けられた終了 IP アドレス

#### セキュリティ警告ポリシー（`security_alert_policy`）

-   `security_alert_policy.alert_policy_state` : 適用するポリシーの有効化状態 - `Enabled`, `Disabled`
-   `security_alert_policy.disabled_alerts` : 無効化するセキュリティ警告の一覧
-   `security_alert_policy.alert_retention_days` : 脅威検出監査ログの保持日数 - `0` ～ `3265`
-   `security_alert_policy.alert_email_account_admins` : 管理者アカウントへセキュリティ警告メールを送信するかどうか - `true`, `false`
-   `security_alert_policy.alert_email_addresses` : セキュリティ警告を受信するメールアドレスの一覧

#### 監査ポリシー（`auditing_policy`）

-   `auditing_policy.enable_storage_destination` : Storage アカウントへの監査ログ保存を有効にするかどうか - `true`, `false`
-   `auditing_policy.linked_storage_account_name` : 使用する Storage アカウント名
-   `auditing_policy.storage_access_key_is_second` : 監査に使用するアクセスキーとしてセカンダリキーを有効化するかどうか - `true`, `false`
-   `auditing_policy.storage_retention_days` : Storage アカウントにおけるログ保持日数
-   `auditing_policy.enable_log_analytics_destination` : Log Analytics Workspace への監査ログ送信を有効化するかどうか - `true`, `false`
-   `auditing_policy.linked_log_analytics_workspace_name` : 監査に使用する Log Analytics Workspace 名
-   `auditing_policy.log_analytics_diagnostic_setting_name` : Log Analytics の診断設定名

#### タグ

-   `tag` : リソースをカテゴリ別に分類するためのタグ - 最大 512 文字、`key`:`value`
