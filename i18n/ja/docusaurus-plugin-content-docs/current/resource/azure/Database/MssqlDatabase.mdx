## リソース概要

Azure SQL Database（Microsoft SQL Database）は、アップグレード、パッチ適用、バックアップ、監視などのデータベース管理作業の大部分をユーザーの介入なしで実行できる、完全に管理された PaaS 型データベースエンジンです。

## リソース設定値

#### 基本設定

-   `included_mssql_server_name` : データベースが作成される Microsoft SQL Server の名前
-   `sku_name` : Microsoft SQL Database の価格およびパフォーマンスレベル
-   `max_size_gb` : データベースの最大サイズ（GB）– `1` ～ `1024`
-   `collation` : Microsoft SQL Database の照合順序および比較ルール
-   `license_type` : データベースに適用されるライセンス種別 – `LicenseIncluded`、`BasePrice`
-   `min_capacity` : 自動スケーリングにおける最小 vCore 数 – 最小 `0.5`
-   `auto_pause_delay_in_minutes` : 非アクティブ時にデータベースを自動的に一時停止するまでの待機時間（分）– `60` ～ `10080`
-   `read_scale` : 読み取り専用ワークロードを読み取り専用レプリカにオフロードするかどうか – `true`、`false`
-   `zone_redundant` : データベースのメンテナンス操作に対するゾーン冗長性を有効化 – `true`、`false`

#### 監査ポリシー（`auditing_policy`）

-   `auditing_policy.enable_storage_destination` : 監査用 Storage Account の有効化 – `true`、`false`
-   `auditing_policy.linked_storage_account_name` : Storage Account の名前
-   `auditing_policy.storage_access_key_is_second` : 監査用 Storage Account にセカンダリアクセスキーを使用 – `true`、`false`
-   `auditing_policy.storage_retention_days` : Storage Account にログを保持する日数
-   `auditing_policy.enable_log_analytics_destination` : Log Analytics Workspace を使用した監査の有効化 – `true`、`false`
-   `auditing_policy.linked_log_analytics_workspace_name` : Log Analytics Workspace における監査ポリシー名
-   `auditing_policy.log_analytics_diagnostic_setting_name` : Log Analytics Workspace の診断設定名

#### タグ

-   `tag` : リソースを分類するためのタグ – 最大 512 文字、`key`:`value`
