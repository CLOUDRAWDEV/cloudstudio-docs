## リソース概要

Azure MySQL Flexible Server は、MySQL Community Edition を基盤としたリレーショナルデータベースサービスです。

## リソース設定値

#### 基本設定

-   `version` : 使用する MySQL バージョン - `5.7`, `8.0.21`
-   `sku_name` : MySQL の価格レベル名（Tier + コンピューティング世代 + コア数の組み合わせ）
-   `storage_gb` : MySQL Server のストレージ容量（GB）
-   `iops` : MySQL Flexible Server のストレージ IOPS - `360` ~ `20000`
-   `admin_username` : 作成モードが default の場合のサーバー管理者ユーザー名。英数字のみ使用可能、予約語不可 - `1` ~ `16` 文字
-   `admin_password` : 作成モードが default の場合のサーバー管理者パスワード。小文字・大文字・数字・特殊文字のうち 3 種類以上を含む必要があり、ログイン名に含まれる 3 文字以上の連続した英数字を含めることは不可 - `8` ~ `128` 文字
-   `auto_grow_enabled` : ストレージ自動拡張の有効化 - `true`, `false`
-   `availability_zone` : 使用する可用性ゾーン。指定可能な値は `1`, `2`, `3` - `1` ~ `3`
-   `enable_high_availability` : MySQL Flexible Server の高可用性有効化 - `true`, `false`
-   `high_availability_mode` : MySQL Flexible Server の高可用性モード - `SameZone`, `ZoneRedundant`
-   `standby_availability_zone` : スタンバイサーバーの可用性ゾーン。`1`, `2`, `3` のいずれかで、プライマリゾーンと重複不可 - `1` ~ `3`
-   `backup_retention_days` : MySQL Flexible Server のバックアップ保持日数 - `1` ~ `35`
-   `public_network_access_enabled` : サーバーへのパブリックネットワークアクセス許可 - `true`, `false`
-   `delegated_subnet_name` : 仮想ネットワーク委任に使用する Subnet 名
-   `private_dns_zone_name` : MySQL Flexible Server 作成時に使用するプライベート DNS ゾーン

#### サーバー構成 (`configuration`)

-   `configuration.param_value` : MySQL Flexible Server の構成パラメータ値

#### データベース (`database`)

-   `database.charset` : MySQL データベースの文字セット
-   `database.collation` : MySQL データベースの照合順序

#### ファイアウォール規則 (`firewall_rule`)

-   `firewall_rule.start_ip_address` : ファイアウォールルールに設定する開始 IP アドレス
-   `firewall_rule.end_ip_address` : ファイアウォールルールに設定する終了 IP アドレス

#### タグ

-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`
