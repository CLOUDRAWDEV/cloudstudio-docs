## リソース概要

Azure PostgreSQL Flexible Server は、オープンソースの Postgres データベースエンジンを基盤としたリレーショナルデータベースサービスです。

## リソース設定値

#### 基本設定

-   `version` : 使用する PostgreSQL のバージョン - `11`, `12`, `13`, `14`
-   `sku_name` : PostgreSQL の価格レベル名（Tier + コンピューティング世代 + コア数の組み合わせ）
-   `storage_mb` : PostgreSQL Flexible Server の最大容量（MB）
-   `admin_username` : 作成モードが default の場合のサーバー管理者ユーザー名（英数字可、予約語不可、`1` ~ `16` 文字）
-   `admin_password` : 作成モードが default の場合のサーバー管理者ログインパスワード（小文字／大文字／数字／特殊文字のうち 3 種類以上を含む。ログイン名の連続する英数字を 3 文字以上含めることは不可、`8` ~ `128` 文字）
-   `availability_zone` : 可用性ゾーンの指定。使用可能な値は `1`, `2`, `3` - `1` ~ `3`
-   `enable_high_availability` : PostgreSQL Flexible Server の高可用性を有効化するかどうか - `true`, `false`
-   `high_availability_mode` : PostgreSQL Flexible Server の高可用性モード - `SameZone`, `ZoneRedundant`
-   `standby_availability_zone` : スタンバイサーバーの可用性ゾーン。使用可能な値は `1`, `2`, `3`（可用性ゾーンと重複不可）- `1` ~ `3`
-   `backup_retention_days` : PostgreSQL Flexible Server のバックアップ保持日数。使用可能な値は `1` ~ `35` 日 - `7` ~ `35`
-   `geo_redundant_backup_enabled` : 地域冗長バックアップの有効化状態 - `true`, `false`
-   `public_network_access_enabled` : サーバーへのパブリックネットワークアクセスを許可するかどうか - `true`, `false`
-   `delegated_subnet_name` : 仮想ネットワーク委任のための Subnet 名
-   `private_dns_zone_name` : PostgreSQL Flexible Server を作成するためのプライベート DNS ゾーン

#### サーバー構成（`configuration`）

-   `configuration.name` : PostgreSQL サーバーのパラメーター設定名
-   `configuration.param_value` : PostgreSQL Flexible Server 構成の値

#### データベース（`database`）

-   `database.charset` : PostgreSQL データベースの文字セット
-   `database.collation` : PostgreSQL データベースの照合順序

#### ファイアウォール規則（`firewall_rule`）

-   `firewall_rule.start_ip_address` : ファイアウォール規則に関連付ける開始 IP アドレス
-   `firewall_rule.end_ip_address` : ファイアウォール規則に関連付ける終了 IP アドレス

#### タグ

-   `tag` : リソースをカテゴリ別に分類するためのタグ - 最大 512 文字、`key`:`value`
