## リソース概要

Azure Security Center は、クラウドリソース全体のセキュリティ状態を継続的に評価し、脅威を検知・防止するための統合セキュリティ管理サービスです。  
Microsoft Defender プランと連携することで、脆弱性評価、セキュリティ推奨事項、脅威保護を中央で管理できます。

## リソース設定値

-   `linked_log_analytics_workspace` : セキュリティデータを保存する Log Analytics Workspace の名前

#### Assessment Policy (`assessment_policy`)

-   `assessment_policy.display_name` : Security Center 評価の表示名
-   `assessment_policy.severity` : Security Center 評価の重大度 - `Low`, `Medium`, `High`
-   `assessment_policy.description` : Security Center 評価の説明

#### Assessment (`assessment`)

-   `assessment.policy_name` : リソースに適用されるセキュリティ評価ポリシー名
-   `assessment.status_code` : 評価ステータスコード - `Healthy`, `Unhealthy`, `NotApplicable`

#### Subscription Pricing (`subscription_pricing`)

-   `subscription_pricing.pricing_tier` : 高度なセキュリティ機能を有効にするかどうか - `Free`, `Standard`
-   `subscription_pricing.pricing_resource_type` : 高度なセキュリティ機能を適用するリソースの種類
