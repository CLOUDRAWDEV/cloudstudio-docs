## リソース概要

Azure Backup は、**IaaS VM や Azure SQL データベースなど、さまざまな Azure サービスのバックアップ データを保管し、復旧を支援する Recovery Services ベースのバックアップ ストレージ エンティティ**です。  
バックアップ ポリシーを使用して、バックアップの頻度、実行時間、保持期間を定義し、仮想マシンやファイル共有を保護対象として登録することでバックアップを実行できます。

## リソース設定値

-   `sku` : Recovery Services Vault 利用時の価格レベル - `Standard`, `RS0`
-   `soft_delete_enabled` : Vault のソフト削除有効化 여부 - `true`, `false`
-   `tag` : リソースを分類するためのタグ

#### VM バックアップ ポリシー (`vm_backup_policy`)

-   `vm_backup_policy.backup_frequency` : バックアップ頻度 - `Daily`, `Weekly`
-   `vm_backup_policy.backup_time` : バックアップ実行時刻
-   `vm_backup_policy.weekly_backup_days` : バックアップを実行する曜日 - `Sunday`, `Monday`, `Tuesday`, `Wednesday`, `Thursday`, `Friday`, `Saturday`
-   `vm_backup_policy.timezone` : バックアップ時間のタイムゾーン
-   `vm_backup_policy.retention_count` : 日次バックアップの保持数 - `7` ~ `9999`

#### 保護対象 VM (`protected_vm`)

-   `protected_vm.backup_policy_name` : 適用するバックアップ ポリシー名

#### ファイル共有バックアップ ポリシー (`share_backup_policy`)

-   `share_backup_policy.backup_frequency` : バックアップ頻度 - `Daily`, `Hourly`
-   `share_backup_policy.backup_time` : バックアップ実行時刻
-   `share_backup_policy.hourly_schedule` : 時間単位バックアップ間隔 - `4`, `6`, `8`, `12`
-   `share_backup_policy.hourly_duration` : 時間単位バックアップ継続時間 - `4` ~ `23`
-   `share_backup_policy.timezone` : バックアップ時間のタイムゾーン
-   `share_backup_policy.daily_retention_count` : 日次バックアップ保持数 - `1` ~ `200`
-   `share_backup_policy.enabled_weekly_backup` : 週次バックアップ有効化 - `true`, `false`
-   `share_backup_policy.weekly_backup_days` : 週次バックアップ曜日 - `Sunday`, `Monday`, `Tuesday`, `Wednesday`, `Thursday`, `Friday`, `Saturday`
-   `share_backup_policy.weekly_retention_count` : 週次バックアップ保持数 - `1` ~ `200`

#### 保護対象ファイル共有 (`protected_share`)

-   `protected_share.source_storage_account_name` : バックアップ対象ファイル共有が属する Storage Account 名
-   `protected_share.source_share_name` : バックアップ対象のファイル共有名
-   `protected_share.backup_policy_name` : 適用するバックアップ ポリシー名
