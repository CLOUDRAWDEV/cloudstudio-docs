## リソース概要

Linux App Service は、Linux ベースの環境で Web アプリケーション、REST API、モバイルバックエンドをホスティングできる HTTP ベースのサービスです。  
App Service Plan と連携して実行され、認証設定、ログ管理、ネットワーク統合、セキュリティプロトコル設定などを通じて、安定性と拡張性に優れたアプリケーション運用環境を提供します。

## リソース設定値

-   `linked_service_plan_name` : App Service に適用する Service Plan の名前

-   `delegated_subnet_name` : 仮想ネットワークの委任に使用する Subnet の名前

-   `auth_settings_enabled` : アプリで発生するすべての通信に対して認証を必須とするための Authentication 有効化 여부 - `true`, `false`

-   `detailed_error_messages_enabled` : HTTP エラー発生時に、エラーページへ詳細なエラーメッセージを表示するかどうか - `true`, `false`

-   `failed_request_tracing_enabled` : 失敗したリクエストに対する詳細なトレース情報のログ記録を有効にするかどうか - `true`, `false`

-   `retention_in_days` : HTTP リクエストに関連するログの保存日数（日） - `0` ~ `99999`

-   `retention_in_mb` : HTTP リクエストに関連するログの保存容量（MB） - `25` ~ `100`

-   `ftps_state` : FTP 使用時に TLS/SSL を適用するかどうか - `Disabled`, `FtpsOnly`, `AllAllowed`

-   `http2_enabled` : 最新の HTTP プロトコル（HTTP/2）を使用するかどうか - `true`, `false`

-   `tag` : リソースをカテゴリ別に分類するためのタグ - 最大 512 文字、`key`:`value`
