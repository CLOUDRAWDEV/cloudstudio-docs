## リソース概要

Windows Function App は、イベント駆動型のサーバーレスコードを Windows 環境で実行できるように提供される、フルマネージドの Function App サービスです。  
HTTP リクエスト、タイマー、メッセージキュー、イベントストリームなど、さまざまなトリガーに基づいてコードを実行でき、インフラ管理を行うことなくアプリケーションロジックに集中できるよう支援します。

## リソース設定値

-   `linked_service_plan_name` : Function App が実行される Service Plan の名前

-   `delegated_subnet_name` : 仮想ネットワークの委任に使用する Subnet の名前

-   `target_storage_account_name` : Function App の実行に必要なファイル、ログ、メタデータを保存するストレージアカウントの名前

-   `https_only` : 暗号化および認証された安全な接続のため、HTTPS アクセスのみを許可するかどうか – `true`, `false`

-   `auth_settings_enabled` : Function App に対する認証／認可機能を有効にするかどうか – `true`, `false`

-   `http2_enabled` : HTTP/2 プロトコルを使用するかどうか – `true`, `false`

-   `target_content_safety_name` : 連携する Azure Content Safety リソースの名前

-   `target_ai_service_name` : 連携する Azure AI Service リソースの名前

-   `target_search_service_name` : 連携する Azure Search Service リソースの名前
