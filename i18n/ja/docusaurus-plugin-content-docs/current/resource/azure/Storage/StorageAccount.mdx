## リソース概要

Azure Storage Account は、Blob、File、Queue、Table などのストレージ サービスを単一のアカウントで提供する基本的なストレージ リソースです。  
スケーラブルなデータ保存、高可用性、セキュアなネットワーク アクセス制御により、さまざまなアプリケーション ワークロードをサポートします。

## リソース設定値

-   `account_kind` : Storage Account の種類 - `StorageV2`, `Storage`
-   `account_tier` : Storage Account のパフォーマンス階層 - `Standard`, `Premium`
-   `account_replication_type` : Storage Account のデータ レプリケーション タイプ - `LRS`, `GRS`, `RAGRS`, `ZRS`, `GZRS`, `RAGZRS`
-   `access_tier` : データ使用パターンの階層 - `Hot`, `Cool`
-   `min_tls_version` : Storage Account でサポートされる最小 TLS バージョン - `TLS1_0`, `TLS1_1`, `TLS1_2`
-   `enable_https_traffic_only` : HTTPS 経由のアクセスのみを許可するかどうか - `true`, `false`
-   `tag` : リソースを分類するためのタグ

#### Networking (`networking`)

-   `networking.public_network_access` : パブリック ネットワーク アクセス ポリシー - `All`, `Selected`, `Disabled`
-   `networking.ip_rules` : ネットワーク ルールを適用する IP アドレス範囲の一覧
-   `networking.bypass` : トラフィックのバイパス対象 - `AzureServices`, `Logging`, `Metrics`

#### Storage Container (`storage_container`)

-   `storage_container.container_access_type` : Storage Container のアクセス レベル - `private`, `blob`, `container`

#### Storage Queue (`storage_queue`)

-   `storage_queue.name` : Queue 名

#### Storage Share (`storage_share`)

-   `storage_share.quota` : ファイル共有の最大容量（GB）

#### Storage Table (`storage_table`)

-   `storage_table.name` : Table 名
