## リソース概要

Private DNS Zone は、Azure 仮想ネットワーク内部でのみ使用されるプライベートドメイン名に対する DNS レコードを管理するための領域です。  
仮想ネットワークとリンク（VNet Link）することで、内部リソース間の名前解決を安全に実行できます。

## リソース設定値

#### A レコード (`private_dns_a_record`)

-   `private_dns_a_record.ttl` : DNS レコードの Time To Live（秒） - `0` ~ `2147483647`
-   `private_dns_a_record.records` : IPv4 アドレスの一覧

#### AAAA レコード (`private_dns_aaaa_record`)

-   `private_dns_aaaa_record.ttl` : DNS レコードの Time To Live（秒） - `0` ~ `2147483647`
-   `private_dns_aaaa_record.records` : IPv6 アドレスの一覧

#### CNAME レコード (`private_dns_cname_record`)

-   `private_dns_cname_record.ttl` : DNS レコードの Time To Live（秒） - `0` ~ `2147483647`
-   `private_dns_cname_record.record` : サブドメインを他のレコードに接続するためのエイリアス

#### PTR レコード (`private_dns_ptr_record`)

-   `private_dns_ptr_record.ttl` : DNS レコードの Time To Live（秒） - `0` ~ `2147483647`
-   `private_dns_ptr_record.records` : ポインターレコードタイプのドメイン名一覧

#### TXT レコード (`private_dns_txt_record`)

-   `private_dns_txt_record.ttl` : DNS レコードの Time To Live（秒） - `0` ~ `2147483647`
-   `private_dns_txt_record.records` : テキストタイプのレコード一覧

#### 仮想ネットワークリンク (`vnet_link`)

-   `vnet_link.linked_vnet_name` : Private DNS Zone にリンクされた仮想ネットワーク名

#### タグ

-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`
