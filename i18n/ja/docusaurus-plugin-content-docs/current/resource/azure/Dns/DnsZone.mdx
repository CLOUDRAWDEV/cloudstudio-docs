## リソース概要

DNS Zone は、特定のドメインに対する DNS レコードをホストし、各 DNS レコードを作成および管理できる領域です。

## 関連リソース

### 上位リソース

-   [**Resource Group**](https://docs.cstudio.app/ja/docs/resource/azure/Base/ResourceGroup)

## リソース設定値

#### A レコード (`dns_a_record`)

-   `dns_a_record.ttl` : DNS レコードの Time To Live（秒） - `0` ~ `2147483647`
-   `dns_a_record.records` : IPv4 アドレスの一覧

#### AAAA レコード (`dns_aaaa_record`)

-   `dns_aaaa_record.ttl` : DNS レコードの Time To Live（秒） - `0` ~ `2147483647`
-   `dns_aaaa_record.records` : IPv6 アドレスの一覧

#### CNAME レコード (`dns_cname_record`)

-   `dns_cname_record.ttl` : DNS レコードの Time To Live（秒） - `0` ~ `2147483647`
-   `dns_cname_record.record` : サブドメインを他のレコードに接続するためのエイリアス

#### NS レコード (`dns_ns_record`)

-   `dns_ns_record.ttl` : DNS レコードの Time To Live（秒） - `0` ~ `2147483647`
-   `dns_ns_record.records` : ネームサーバーレコードの一覧

#### PTR レコード (`dns_ptr_record`)

-   `dns_ptr_record.ttl` : DNS レコードの Time To Live（秒） - `0` ~ `2147483647`
-   `dns_ptr_record.records` : ポインターレコードタイプのドメイン名一覧

#### TXT レコード (`dns_txt_record`)

-   `dns_txt_record.ttl` : DNS レコードの Time To Live（秒） - `0` ~ `2147483647`
-   `dns_txt_record.records` : テキストタイプのレコード一覧

#### タグ

-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`
