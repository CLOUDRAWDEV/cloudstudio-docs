## リソース概要

Azure Redis Cache は、アプリケーションで頻繁にアクセスされるデータをメモリにキャッシュすることで、高いスループットと低レイテンシを提供するマネージド型インメモリデータストレージサービスです。  
セッション管理、キャッシュレイヤー、リアルタイムデータ処理などのシナリオで、バックエンドの負荷を軽減し、アプリケーションの応答速度を向上させるために使用されます。

## リソース設定値

-   `sku_name` : Redis キャッシュの価格レベル - `Basic`, `Standard`, `Premium`, `Enterprise`
-   `cache_type` : Redis キャッシュのサイズおよびパフォーマンス階層（SKU 詳細タイプ）
-   `version` : Redis のバージョン - `6`
-   `enable_non_ssl_port` : Non-SSL ポートの使用可否 - `true`, `false`
-   `minimum_tls_version` : Redis に適用される最小 TLS バージョン - `1.0`, `1.1`, `1.2`
-   `public_network_access_enabled` : パブリックネットワーク経由の Redis アクセスを許可するかどうか - `true`, `false`
-   `tag` : リソースを分類するためのタグ

#### Redis Firewall Rule (`redis_firewall_rule`)

-   `redis_firewall_rule.start_ip` : アクセスを許可する開始 IP アドレス
-   `redis_firewall_rule.end_ip` : アクセスを許可する終了 IP アドレス
