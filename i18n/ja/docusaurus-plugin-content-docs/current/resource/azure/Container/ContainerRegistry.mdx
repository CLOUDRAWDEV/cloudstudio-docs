## リソース概要

Azure Container Registry は、コンテナイメージおよび OCI アーティファクトを安全に保存・管理するための  
プライベートコンテナレジストリサービスです。  
Docker および Kubernetes ベースのワークロードと密接に連携し、  
セキュリティ、パフォーマンス、ネットワークアクセス制御をきめ細かく設定できます。

## リソース設定値

-   `sku` :  
    Container Registry のパフォーマンスおよびスケーラビリティのための SKU タイプ

    -   `Basic`
    -   `Standard`
    -   `Premium`

-   `admin_enabled` :  
    管理者アカウントの使用可否 – `true`, `false`

-   `public_network_access_enabled` :  
    パブリックネットワークアクセスの許可可否 – `true`, `false`

### ネットワークルール設定（`network_rule_set`）

> SKU が `Premium` の場合のみ設定可能です。

-   `network_rule_set.default_action` :  
    ルールに一致しないリクエストに対する既定の動作

    -   `Allow`
    -   `Deny`

-   `network_rule_set.ip_ranges` :  
    ルールに一致するリクエストの IP アドレス CIDR 一覧

### タグ

-   `tag` :  
    リソースをカテゴリ分けするためのタグ – 最大 512 文字、`key`:`value`
