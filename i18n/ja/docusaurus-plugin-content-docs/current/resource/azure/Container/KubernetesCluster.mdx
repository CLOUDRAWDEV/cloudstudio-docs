## リソース概要

Azure Kubernetes Service（AKS）は、Kubernetes クラスターを容易にデプロイおよび運用できるようにするマネージドサービスです。  
クラスターの基本設定、認証／認可（RBAC）、ネットワークポリシー、ノードプール構成、API サーバーのアクセス制御などを設定することで、コンテナベースのワークロードを運用できます。

## リソース設定値

-   `dns_prefix` : ホストされた Kubernetes API サーバーの FQDN とともに使用する DNS プレフィックス

-   `sku_tier` : Kubernetes クラスター利用のための価格レベル - `Free`, `Standard`

-   `enable_public_network_access` : パブリックネットワークからのアクセス許可 - `true`, `false`

-   `api_server_authorized_ip_ranges` : API サーバーへのアクセスを保護するための許可済み IP アドレス範囲の一覧

-   `authentication_authorization` : クラスターリソースへのアクセスを制限するための認可方式 - `local_accounts`, `azure_rbac`, `kubernetes_rbac`

-   `admin_group_object_ids` : クラスター管理者ロールを持つ必要がある Azure Active Directory グループのオブジェクト ID 一覧

-   `network_policy` : 特定の Pod へのアクセス制限のためのネットワークポリシー - `calico`, `azure`, `none`

-   `load_balancer_sku` : Load Balancer の価格レベル - `standard`, `basic`

-   `network_plugin` : 基本の仮想ネットワーク構成方式 - `kubenet`, `azure`

-   `included_subnet_name` : Kubernetes クラスターがデプロイされる Subnet 名

-   `pod_cidr` : Pod の IP アドレスに使用する CIDR

-   `service_cidr` : サービスのクラスター IP を割り当てる CIDR 範囲

-   `dns_service_ip` : Kubernetes DNS サービスに割り当てられる IP アドレス

-   `outbound_type` : アウトバウンドルーティングのタイプ - `loadBalancer`, `userDefinedRouting`

### 既定ノードプール設定（`default_node_pool`）

-   `default_node_pool.node_pool_name` : Node Pool 名 - Linux `1` ～ `12` 文字、Windows `1` ～ `6` 文字

-   `default_node_pool.enable_auto_scaling` : クラスターの自動スケーリング有効化 - `true`, `false`

-   `default_node_pool.node_count` : Node Pool のノード数 - `0` ～ `1000`

-   `default_node_pool.min_node_count` : Node Pool の最小ノード数 - `1` ～ `1000`

-   `default_node_pool.max_node_count` : Node Pool の最大ノード数 - `1` ～ `1000`

-   `default_node_pool.vm_size` : Node Pool を構成する仮想マシンのサイズ

-   `default_node_pool.os_disk_size_gb` : 仮想マシンの OS ディスクサイズ（GB） - `30` ～ `2048`

-   `default_node_pool.max_pods` : ノードで実行可能な Pod の最大数 - `10` ～ `250`

-   `default_node_pool.enable_node_public_ip` : ノードごとのパブリック IP アドレス使用の有効化 - `true`, `false`

-   `default_node_pool.public_ip_prefix_name` : このノードプールのノードに対するパブリック IP アドレスプレフィックスのリソース ID

-   `default_node_pool.temporary_name_for_rotation` : 特定の値変更時に必須となる一時的な Node Pool 名

### 追加ノードプール設定（`cluster_node_pool`）

-   `cluster_node_pool.node_mode` : Node Pool モード - `User`, `System`

-   `cluster_node_pool.node_os_type` : Node Pool 内 VM の OS タイプ - `Linux`, `Windows`

-   `cluster_node_pool.enable_auto_scaling` : 自動スケーリング有効化 - `true`, `false`

-   `cluster_node_pool.node_count` : Node Pool のノード数

-   `cluster_node_pool.max_node_count` : Node Pool の最大ノード数

-   `cluster_node_pool.min_node_count` : Node Pool の最小ノード数

-   `cluster_node_pool.vm_size` : Node Pool を構成する仮想マシンのサイズ

-   `cluster_node_pool.os_disk_size_gb` : 仮想マシンの OS ディスクサイズ（GB） - `30` ～ `2048`

-   `cluster_node_pool.max_pods` : ノードで実行可能な Pod の最大数 - `10` ～ `250`

-   `cluster_node_pool.enable_node_public_ip` : ノードごとのパブリック IP アドレス使用の有効化 - `true`, `false`

-   `cluster_node_pool.public_ip_prefix_name` : 該当 Node Pool のノードに対するパブリック IP アドレスプレフィックスのリソース ID

### タグ

-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`
