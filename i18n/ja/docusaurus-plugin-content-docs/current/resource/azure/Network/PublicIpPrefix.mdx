## リソース概要

Public IP Prefix は、Azure において **連続したパブリック IP アドレス範囲** を事前に予約して管理できるネットワークリソースです。  
複数の Public IP を一貫したアドレスブロックから割り当てることができるため、ファイアウォール ルールの管理や外部連携システムの構成時に、予測可能性と運用のしやすさを提供します。

## リソース設定値

-   `prefix_length` : Public IP Prefix のビット長 - `28` ~ `31`
-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`
