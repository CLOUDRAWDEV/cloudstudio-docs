## リソース概要

Private Endpoint は、パブリック IP アドレスを使用せずに、Virtual Network 内から Azure サービスへ **プライベート接続（Private Link）** を提供するネットワークリソースです。  
サービス エンドポイントは Subnet に割り当てられた Private IP を通じて公開され、インターネットを経由しない安全な通信経路を構成できます。  
Private DNS Zone と連携することで、サービスの FQDN を内部ネットワーク内で自然に名前解決できるように構成できます。

## リソース設定値

-   `included_subnet_name` : Private Endpoint に割り当てられる Private IP アドレスを持つ Subnet の名前
-   `connection_name` : Private Endpoint とリソース間の接続名
-   `linked_connection_resource_name` : Private Endpoint が接続されるリソースの名前
-   `subresource_name` : Private Endpoint が接続されるサブリソースの名前
-   `dns_zone_group_name` : Private Endpoint に関連付ける Private DNS Zone グループの名前
-   `private_dns_zone_names` : Private Endpoint に関連付ける Private DNS Zone 名の一覧
-   `manual_connection` : 外部リソース所有者による手動承認が必要かどうか - `true`, `false`
-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`
