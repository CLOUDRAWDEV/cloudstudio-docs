## リソース概要

Azure Virtual Hub は、Virtual WAN 環境において **中央集約型のルーティングおよびネットワーク接続を担うリージョン単位のハブリソース** です。  
VPN、ExpressRoute、VNet 接続を集約してトラフィックフローを制御し、グローバルネットワークトポロジの中核コンポーネントとして使用されます。

## リソース設定値

-   `included_virtual_wan_name` : Virtual Hub が接続される上位 Virtual WAN の名前
-   `address_prefix` : Virtual Hub 内で使用されるアドレス空間（CIDR ブロック）
-   `hub_routing_preference` : トラフィックのルーティング時におけるインターネット経路選択の優先順位
    -   `ExpressRoute`
    -   `ASPath`
    -   `VpnGateway`

#### Connection (`connection`)

-   `connection.target_virtual_network_name` : Virtual Hub に接続する対象 Virtual Network（VNet）の名前
