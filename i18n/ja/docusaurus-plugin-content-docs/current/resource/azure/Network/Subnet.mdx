## リソース概要

Subnet は、Azure リソースを Virtual Network にデプロイするために、Virtual Network 内に作成されるネットワークです。

## リソース設定値

-   `included_vnet_name` : Subnet が含まれる Virtual Network の名前
-   `address_prefixes` : Subnet で使用する IP アドレス範囲。Virtual Network のアドレス空間内で、CIDR 形式で指定された一意のアドレス範囲
-   `private_link_endpoint_enabled` : Subnet に Private Endpoint を接続するかどうかの設定 - `true`, `false`

#### 委任設定 (`delegation`)

-   `delegation.service_name` : 委任するサービスの名前
-   `delegation.actions` : 委任するアクションの一覧
