## リソース概要

Network DDoS Protection Plan は、大規模な分散型サービス拒否（DDoS）攻撃から Azure 仮想ネットワーク リソースを保護するためのセキュリティ サービスです。  
トラフィック分析および自動緩和機能により、アプリケーションの可用性を維持し、攻撃発生時には追加の保護機能を提供します。
