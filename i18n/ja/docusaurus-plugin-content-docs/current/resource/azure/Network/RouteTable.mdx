## リソース概要

Route Table は、Virtual Network 内の Subnet に適用され、**ネットワーク トラフィックの経路をユーザー定義で制御**できる Azure のネットワークリソースです。  
既定のシステム ルーティングに加えて、仮想アプライアンス、インターネット、ゲートウェイなどへのトラフィック フローを明示的に指定できます。

## リソース設定値

-   `enable_bgp_route_propagation` : ゲートウェイ ルートの伝播を有効にするかどうか - `true`, `false`
-   `linked_subnet_names` : Route Table を関連付ける Subnet 名のリスト
-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`

#### ルート設定 (`route`)

-   `route.route_address_prefix` : ルートを表す IP アドレス プレフィックス（CIDR）
-   `route.next_hop_type` : 次のホップの種類
    -   `VirtualNetworkGateway`
    -   `VnetLocal`
    -   `Internet`
    -   `VirtualAppliance`
    -   `None`
