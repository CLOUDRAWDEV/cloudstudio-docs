## リソース概要

Public IP は、Azure リソースがインターネットと **直接インバウンド／アウトバウンド通信** を行えるように、公用 IP アドレスを提供するネットワークリソースです。  
Load Balancer、Virtual Machine、NAT Gateway などと連携して、外部トラフィックの受信ポイントまたはアウトバウンドの出口として機能し、SKU や割り当て方式に応じて可用性や動作特性が異なります。

## リソース設定値

-   `sku` : Public IP の価格レベル - `Standard`, `Basic`
-   `allocation_method` : Public IP アドレスの割り当て方式 - `Static`, `Dynamic`
-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`
