## リソース概要

Traffic Manager は DNS ベースで動作するグローバル トラフィック分散サービスで、**ユーザーの要求を最も適切なサービス エンドポイントへルーティング**します。  
遅延、優先度、地理的な位置など、さまざまなルーティング方式をサポートしており、高可用性とパフォーマンス最適化を同時に実現できます。

## リソース設定値

-   `traffic_routing_method` : クライアント要求をエンドポイントに分散するルーティング方式
    -   `Geographic`, `MultiValue`, `Performance`, `Priority`, `Subnet`, `Weighted`
-   `relative_domain_name` : Traffic Manager で使用するドメイン名
-   `ttl` : DNS レコードの Time To Live 値
-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`

#### エンドポイント監視設定 (`endpoint_monitor_setting`)

-   `endpoint_monitor_setting.protocol` : 監視に使用するプロトコル - `HTTP`, `HTTPS`, `TCP`
-   `endpoint_monitor_setting.port` : 監視に使用するポート番号 - `0` ~ `65535`
-   `endpoint_monitor_setting.path` : HTTP/HTTPS 使用時の監視パス

#### Azure エンドポイント (`azure_endpoint`)

-   `azure_endpoint.linked_resource_type` : Azure エンドポイントの種類
-   `azure_endpoint.linked_target_name` : 接続する Azure リソース名
-   `azure_endpoint.weight` : エンドポイントに分散されるトラフィックの比重
-   `azure_endpoint.priority` : エンドポイントの優先度

#### ネストされたエンドポイント (`nested_endpoint`)

-   `nested_endpoint.linked_traffic_manager_name` : 接続する下位 Traffic Manager の名前
-   `nested_endpoint.weight` : エンドポイントに分散されるトラフィックの比重
-   `nested_endpoint.priority` : エンドポイントの優先度
-   `nested_endpoint.endpoint_location` : エンドポイントの Azure リージョン
-   `nested_endpoint.min_child_endpoints` : トラフィック転送に必要な最小オンライン エンドポイント数

#### 外部エンドポイント (`external_endpoint`)

-   `external_endpoint.target_name` : 外部エンドポイントの対象名（リソースまたはドメイン）
-   `external_endpoint.weight` : エンドポイントに分散されるトラフィックの比重
-   `external_endpoint.priority` : エンドポイントの優先度
-   `external_endpoint.endpoint_location` : エンドポイントの Azure リージョン
