## リソース概要

Network Interface は、Virtual Machine が Virtual Network 内のリソース、インターネット、およびオンプレミス ネットワークと通信できるようにするネットワーク接続リソースです。  
Subnet に属して IP アドレスが割り当てられ、必要に応じて Public IP を関連付けることで外部通信を構成できます。  
1 つの Network Interface に複数の IP 構成を定義できるため、さまざまなネットワーク シナリオに対応できます。

## リソース設定値

-   `included_subnet_name` : Network Interface が含まれる Subnet の名前

#### IP 構成 (`ip_configuration`)

-   `ip_configuration.is_primary` : プライマリ IP 構成を有効にするかどうか - `true`, `false`
-   `ip_configuration.private_ip_address_allocation` : プライベート IP アドレスの割り当て方式 - `Dynamic`, `Static`
-   `ip_configuration.private_ip_address` : プライベート IP アドレス
-   `ip_configuration.enabled_public_ip` : Public IP を使用するかどうか - `true`, `false`
-   `ip_configuration.linked_public_ip_name` : 使用する Public IP の名前

-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`
