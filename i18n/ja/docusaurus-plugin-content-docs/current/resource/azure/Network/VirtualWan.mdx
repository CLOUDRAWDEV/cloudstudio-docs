## リソース概要

Azure Virtual WAN は、複数のリージョンに分散されたネットワークリソースを中央で接続・管理するための **グローバルネットワークハブサービス** です。  
Site-to-Site VPN、Point-to-Site VPN、ExpressRoute 接続を単一の制御ポイントから統合的に管理でき、大規模なマルチリージョンネットワークアーキテクチャに適しています。
