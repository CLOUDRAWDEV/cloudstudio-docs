## リソース概要

Firewall Policy は、Azure Firewall で使用される **集中管理型のファイアウォール ポリシー管理リソース** です。  
ネットワーク ルール、アプリケーション ルール、NAT ルールを 1 つのポリシーとして定義し、複数の Firewall インスタンスに一貫して適用することで、セキュリティ ポリシーの再利用性と運用効率を向上させます。
