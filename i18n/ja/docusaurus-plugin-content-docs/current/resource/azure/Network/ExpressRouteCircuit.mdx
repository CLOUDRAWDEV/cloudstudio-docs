## リソース概要

ExpressRoute Circuit は、オンプレミス ネットワークを Microsoft クラウドに **プライベート専用回線** で接続するための Azure ネットワークリソースです。  
パブリック インターネットを経由しない安定した接続を提供し、帯域幅・遅延・セキュリティ要件が高いエンタープライズ環境で主に利用されます。

## リソース設定値

-   `service_provider` : ExpressRoute 回線を提供する ISP プロバイダー
-   `peering_location` : ISP が回線をプロビジョニングするピアリング ロケーション
-   `bandwidth_in_mbps` : ExpressRoute 回線の帯域幅（Mbps）
-   `sku_tier` : ExpressRoute 回線の価格レベル - `Basic`, `Local`, `Standard`, `Premium`
-   `sku_family` : アウトバウンド データ転送の課金モデル - `MeteredData`, `UnlimitedData`
-   `authorization_names` : 回線の使用を許可する認可名の一覧
-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`

#### 回線ピアリング設定 (`circuit_peering`)

-   `circuit_peering.enabled_peering` : 該当するピアリング タイプを有効にするかどうか - `true`, `false`
-   `circuit_peering.peer_asn` : BGP ピアリングに使用する ASN 値
-   `circuit_peering.primary_peer_address` : プライマリ リンク用の `/30` IPv4 サブネット
-   `circuit_peering.secondary_peer_address` : セカンダリ リンク用の `/30` IPv4 サブネット
-   `circuit_peering.vlan_id` : ピアリング設定用の VLAN ID
-   `circuit_peering.advertised_public_prefixes` : BGP セッションを通じて広告するパブリック IPv4 アドレス プレフィックスの一覧
