## リソース概要

Bastion Host は、VM にパブリック IP を直接公開することなく、Virtual Network 内の仮想マシンに対して **安全な RDP および SSH 接続** を提供する Azure の PaaS ネットワーク サービスです。  
ブラウザベースのアクセスをサポートし、管理ポートを開放せずに集中管理されたアクセス ポイントを構成できるため、セキュリティと運用の利便性を同時に確保できます。

## リソース設定値

-   `included_subnet_name` : Bastion Host を配置する Subnet の名前
-   `sku` : Bastion Host の SKU - `Basic`, `Standard`
-   `linked_public_ip_name` : Bastion Host に関連付ける Public IP の名前
-   `ip_config_name` : Bastion Host で使用する IP 構成の名前
-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`
