## リソース概要

Virtual Network Gateway は、Azure Virtual Network とオンプレミス ネットワーク、または別の Virtual Network 間で **暗号化されたトラフィック通信経路** を提供するネットワーク ゲートウェイです。  
VPN または ExpressRoute 方式で接続でき、ハイブリッド ネットワーク構成や安全な専用接続を実現するための中核コンポーネントです。

## リソース設定値

-   `included_subnet_name` : Virtual Network Gateway を通じてトラフィックを送受信する Subnet 名
-   `gateway_type` : Virtual Network Gateway の種類 - `Vpn`, `ExpressRoute`
-   `vpn_type` : VPN 接続の種類 - `RouteBased`, `PolicyBased`
-   `sku` : Virtual Network Gateway の価格レベル
-   `generation` : Virtual Network Gateway の世代 - `Generation1`, `Generation2`
-   `enabled_active_active_mode` : Active-Active モードの有効化 여부
-   `enabled_configure_bgp` : BGP の有効化 여부
-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`

#### IP 構成 (`ip_configuration`)

-   `ip_configuration.linked_public_ip_name` : Virtual Network Gateway に関連付ける Public IP 名
