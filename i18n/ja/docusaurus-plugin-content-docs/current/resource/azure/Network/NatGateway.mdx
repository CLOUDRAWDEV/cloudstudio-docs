## リソース概要

NAT Gateway は、Virtual Network 内の 1 つ以上の Subnet に対して **アウトバウンド（Outbound）インターネット接続** を提供するリソースです。  
Subnet に関連付けると、その Subnet 内のリソースは指定された Public IP を通じて外部と通信し、インバウンド（Inbound）の公開エンドポイントは提供されません。  
アイドル（Idle）接続のタイムアウトを調整することで、長時間の接続を維持したり、不要な接続を迅速に解放したりすることができます。

## リソース設定値

-   `linked_subnet_names` : Nat Gateway を関連付ける Subnet の名前
-   `linked_public_ip_name` : Nat Gateway に関連付ける Public IP の名前
-   `idle_timeout_in_minutes` : Nat Gateway におけるアイドル フローを削除するまでのタイムアウト（分） - `4` ~ `120`
-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`
