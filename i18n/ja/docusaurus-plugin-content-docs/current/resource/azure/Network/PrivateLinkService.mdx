## リソース概要

Private Link Service は、ユーザーの内部サービス（Load Balancer ベース）を外部の顧客に対して **Private Endpoint 方式で安全に公開** するためのネットワーク サービスです。  
パブリック IP を使用せずに Azure バックボーン ネットワークを介して接続され、アクセス制御および承認ポリシーにより、サービス公開範囲をきめ細かく管理できます。

## リソース設定値

-   `auto_approval_subscription_ids` : 事前承認なしで Private Endpoint 接続を自動的に許可するサブスクリプション ID の一覧
-   `visibility_subscription_ids` : Private Link Service を検出し、接続要求を送信できるサブスクリプション ID の一覧

#### Load Balancer IP 構成 (`lb_ip_configuration`)

-   `lb_ip_configuration.target_lb_name` : 接続対象となる Load Balancer の名前
-   `lb_ip_configuration.target_ip_config_name` : Load Balancer の Frontend IP Configuration 名

#### NAT IP 構成 (`nat_ip_configuration`)

-   `nat_ip_configuration.target_subnet_name` : NAT IP 構成を適用する対象 Subnet 名
-   `nat_ip_configuration.private_ip_address` : NAT IP として使用する固定の Private IP アドレス
-   `nat_ip_configuration.private_ip_address_version` : Private IP のバージョン - `IPv4`
-   `nat_ip_configuration.enable_primary` : この NAT IP 構成をプライマリとして使用するかどうか - `true`, `false`
