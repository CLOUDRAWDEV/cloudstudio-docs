## リソース概要

Virtual Network は、Azure リソース間の通信を可能にし、インターネットまたはオンプレミスネットワークとの接続を構成するための **仮想ネットワークリソース** です。  
IP アドレス空間（Address Space）を基に、サブネット、セキュリティポリシー、ピアリングなどを構成することで、Azure 環境のネットワーク構造を定義できます。

## リソース設定値

-   `vnet_address_space` : Virtual Network が使用する IP アドレス空間

    -   CIDR 形式のアドレスを 1 つ以上指定可能

-   `enable_ddos_protection` : Virtual Network に DDoS Protection Plan を適用するかどうか
    -   `true`, `false`
-   `ddos_protection_plan_name` : Virtual Network に関連付ける DDoS Protection Plan の名前

#### VNet ピアリング (`peering`)

他の Virtual Network との接続設定を定義します。

-   `peering.linked_vnet_name` : 接続対象の Virtual Network 名（読み取り専用）
-   `peering.allow_access_to_remote_vnet` : リモート Virtual Network へのアクセスを許可するかどうか
-   `peering.allow_receive_forwarded_traffic` : 転送されたトラフィックの受信を許可するかどうか
-   `peering.allow_forward_traffic_to_remote_vnet` : リモート Virtual Network へのトラフィック転送を許可するかどうか
-   `peering.allow_use_remote_gateway` : リモート Virtual Network のゲートウェイを使用するかどうか
    -   各項目の値：`true`, `false`

#### タグ

-   `tag` : リソースをカテゴリ分けするためのタグ
    -   最大 512 文字、`key`:`value` 形式
