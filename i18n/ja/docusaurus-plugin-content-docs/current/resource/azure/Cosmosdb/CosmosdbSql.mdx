## リソース概要

Azure Cosmos DB SQL API は、SQL API がサポートする JSON 形式のデータを保存およびクエリできる完全マネージド型 NoSQL データベースサービスです。  
グローバル分散、自動フェールオーバー、バックアップ、整合性ポリシーなどにより、高いスケーラビリティと可用性を提供します。

## リソース設定値

#### 基本設定

-   `capabilities_list` : 使用する Cosmos DB の API 一覧
-   `enable_multiple_write_locations` : マルチリージョン書き込みの有効化 여부 - `true`, `false`
-   `public_network_access_enabled` : 公開 IP アドレスまたはサービス エンドポイントを介したアカウントへの公開接続を有効化 - `true`, `false`
-   `enable_automatic_failover` : 自動フェールオーバーの有効化 - `true`, `false`
-   `virtual_network_filter_enabled` : 特定の仮想ネットワーク Subnet のみがアカウントにアクセスできるようにするフィルターの有効化 - `true`, `false`
-   `network_acl_bypass_for_azure_services` : Azure サービスに対する ACL バイパスの有効化 - `true`, `false`

#### リージョン設定（`geo_location`）

-   `geo_location.failover_priority` : リージョンのフェールオーバー優先順位
-   `geo_location.zone_redundant` : 障害対策として自動ゾーン冗長を有効化 - `true`, `false`

#### 整合性ポリシー（`consistency_policy`）

-   `consistency_policy.consistency_level` : データベースの可用性とパフォーマンスを制御する整合性レベル
-   `consistency_policy.max_interval_in_seconds` : 整合性レベルが Bounded Staleness の場合に許容される最大遅延時間（秒）
-   `consistency_policy.max_staleness_prefix` : 整合性レベルが Bounded Staleness の場合に許容される最大 Stale リクエスト数

#### バックアップ設定（`backup`）

-   `backup.type` : バックアップポリシーの種類 - `Continuous`, `Periodic`
-   `backup.interval_in_minutes` : バックアップ実行間隔（分） - `60` ~ `1440`
-   `backup.retention_in_hours` : バックアップの保持期間（時間） - `8` ~ `720`

#### SQL データベース設定（`sql_database`）

-   `sql_database.throughput` : Cosmos DB SQL データベースのスループット - `400` ~ `1000000`
-   `sql_database.enable_autoscale` : 自動スケーリングの有効化 여부 - `true`, `false`

#### SQL コンテナー設定（`sql_container`）

-   `sql_container.partition_key_version` : パーティションキーのバージョン - `1`, `2`
-   `sql_container.partition_key_paths` : SQL コンテナーで使用するパーティションキーのパス一覧
-   `sql_container.throughput` : SQL コンテナーのスループット - `400` ~ `1000000`
-   `sql_container.indexing_mode` : インデックスの種類 - `consistent`, `none`
-   `sql_container.included_path` : インデックスに含めるパスの一覧
-   `sql_container.excluded_path` : インデックスから除外するパスの一覧
-   `sql_container.unique_key_path` : データ整合性レイヤーを追加するための一意キーのパス一覧
-   `sql_container.enable_autoscale` : 自動スケーリングの有効化 여부 - `true`, `false`
-   `sql_container.included_sql_database_name` : SQL コンテナーが作成される SQL データベース名

#### タグ

-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`
