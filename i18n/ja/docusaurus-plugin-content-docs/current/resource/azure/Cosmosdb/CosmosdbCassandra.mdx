## リソース概要

Azure Cosmos DB Cassandra は、Apache Cassandra API と互換性のある分散型 NoSQL データベースサービスです。  
グローバル分散、自動スケーリング、高可用性、複数の一貫性モデルを提供し、Cassandra API ベースのアプリケーションを Azure 環境で容易に運用できます。

## リソース設定値

-   `capabilities_list` : 使用する Cosmos DB の機能（API）の一覧
-   `enable_multiple_write_locations` : 複数リージョン書き込みの有効化 여부
-   `public_network_access_enabled` : 公開ネットワーク経由でのアカウントアクセス許可 여부
-   `enable_automatic_failover` : 自動フェールオーバーの有効化 여부
-   `virtual_network_filter_enabled` : 特定の仮想ネットワーク Subnet のみアクセスを許可する 여부
-   `network_acl_bypass_for_azure_services` : Azure サービスに対する ACL バイパスの許可 여부

#### リージョン設定（`geo_location`）

-   `geo_location.failover_priority` : リージョンのフェールオーバー優先順位
-   `geo_location.zone_redundant` : 可用性ゾーン（Zone）冗長構成の有効化 여부

#### 一貫性ポリシー（`consistency_policy`）

-   `consistency_policy.consistency_level` : Cassandra DB の一貫性レベル
-   `consistency_policy.max_interval_in_seconds` : Bounded Staleness 使用時に許容される最大遅延時間（秒）
-   `consistency_policy.max_staleness_prefix` : Bounded Staleness 使用時に許容される最大の Stale リクエスト数

#### バックアップ設定（`backup`）

-   `backup.type` : バックアップポリシーの種類（`Continuous`, `Periodic`）
-   `backup.interval_in_minutes` : バックアップ実行間隔（分）
-   `backup.retention_in_hours` : バックアップ保持期間（時間）

#### Cassandra キースペース（`cassandra_keyspace`）

-   `cassandra_keyspace.throughput` : Cassandra キースペースのスループット
-   `cassandra_keyspace.enable_autoscale` : スループット自動スケーリングの有効化 여부

#### Cassandra テーブル（`cassandra_table`）

-   `cassandra_table.throughput` : Cassandra テーブルのスループット
-   `cassandra_table.column` : カラム名と型の一覧（`名前:型` 形式）
-   `cassandra_table.partition_key` : パーティションキー名
-   `cassandra_table.cluster_key_name` : クラスターキー名
-   `cassandra_table.cluster_key_order` : クラスターキーの並び順
-   `cassandra_table.enable_autoscale` : テーブルスループット自動スケーリングの有効化 여부
-   `cassandra_table.included_cosmosdb_keyspace_name` : テーブルが作成される Cassandra キースペース名

#### タグ

-   `tag` : リソースをカテゴリ分けするためのタグ
