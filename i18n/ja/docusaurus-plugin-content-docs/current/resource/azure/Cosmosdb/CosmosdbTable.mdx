## リソース概要

Azure Cosmos DB Table API は、インデックスを個別に管理することなく自動インデックスを利用できる高可用性の Table API です。  
グローバル分散、自動フェールオーバー、バックアップ、一貫性ポリシーなどを通じて、拡張性と安定性を提供します。

## リソース設定値

#### 基本設定

-   `capabilities_list` : 使用する Cosmos DB の API 一覧
-   `enable_multiple_write_locations` : 複数リージョン書き込みの有効化 여부 - `true`, `false`
-   `public_network_access_enabled` : 公開 IP アドレスまたはサービスエンドポイント経由でアカウントへの公開接続を有効化 - `true`, `false`
-   `enable_automatic_failover` : 自動フェールオーバーの有効化 - `true`, `false`
-   `virtual_network_filter_enabled` : 特定の仮想ネットワーク Subnet のみがアカウントにアクセスできるようフィルターを有効化 - `true`, `false`
-   `network_acl_bypass_for_azure_services` : Azure サービスに対する ACL バイパスの有効化 - `true`, `false`

#### リージョン設定（`geo_location`）

-   `geo_location.failover_priority` : リージョンのフェールオーバー優先順位
-   `geo_location.zone_redundant` : 障害対策として自動的にゾーン冗長を有効化 - `true`, `false`

#### 一貫性ポリシー（`consistency_policy`）

-   `consistency_policy.consistency_level` : データベースの可用性およびパフォーマンスを設定する一貫性レベル
-   `consistency_policy.max_interval_in_seconds` : 一貫性レベルが Bounded Staleness の場合に許容される最大遅延時間（秒）
-   `consistency_policy.max_staleness_prefix` : 一貫性レベルが Bounded Staleness の場合に許容される最大 Stale リクエスト数

#### バックアップ設定（`backup`）

-   `backup.type` : バックアップポリシーの種類 - `Continuous`, `Periodic`
-   `backup.interval_in_minutes` : バックアップ実行間隔（分） - `60` ~ `1440`
-   `backup.retention_in_hours` : バックアップ保持期間（時間） - `8` ~ `720`

#### テーブル設定（`table`）

-   `table.throughput` : Cosmos DB テーブルのスループット - `400` ~ `1000000`
-   `table.enable_autoscale` : 自動スケーリングの有効化 여부 - `true`, `false`

#### タグ

-   `tag` : リソースをカテゴリ別に分類するためのタグ - 最大 512 文字、`key`:`value`
