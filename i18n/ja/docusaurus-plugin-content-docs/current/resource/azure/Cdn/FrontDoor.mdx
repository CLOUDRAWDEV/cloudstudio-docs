## リソース概要

Azure Front Door は、世界中に分散された Microsoft のグローバル エッジ ネットワークを活用し、ユーザーに Web コンテンツを高速かつ安定して配信するグローバル アプリケーション アクセラレーション サービスです。  
トラフィック ルーティング、ロード バランシング、ヘルス プローブ、TLS 終端、およびセキュアな通信をサポートし、複数のオリジンを持つ環境でも高可用性と低レイテンシを提供します。

## リソース設定値

### 基本設定

-   `sku` : Front Door プロファイルの SKU - `Standard_AzureFrontDoor`, `Premium_AzureFrontDoor`

-   `endpoint_names` : 使用するエンドポイント名の一覧

### オリジン グループ設定（`origin_group`）

-   `restore_traffic_time_in_minutes` : エンドポイント障害発生時、または新しいエンドポイント追加時に、トラフィックを切り替える前の待機時間（分）- `0` ~ `50`

-   `session_affinity_enabled` : セッション アフィニティ（Session Affinity）を有効にするかどうか - `true`, `false`

-   `health_probe_path` : オリジンの状態確認に使用する相対パス

-   `health_probe_protocol` : ヘルス プローブに使用するプロトコル - `Http`, `Https`

-   `health_probe_method` : ヘルス プローブのリクエスト方式 - `HEAD`, `GET`

-   `health_probe_interval_in_seconds` : ヘルス プローブの実行間隔（秒）

-   `load_balancing_latency_in_milliseconds` : 最小レイテンシ バケットに含める追加レイテンシ（ミリ秒）

-   `load_balancing_sample_size` : ロード バランシング判断に使用するサンプル数

-   `load_balancing_sample_required` : 正常と判断されるために必要な成功サンプル数

### オリジン設定（`origin`）

-   `origin_group_name` : オリジンが属するオリジン グループ名

-   `host_name` : オリジンのホスト名（IPv4、IPv6、またはドメイン）

-   `origin_host_header` : オリジンに送信される Host ヘッダーの値

-   `certificate_name_check_enabled` : 証明書名の検証を有効にするかどうか - `true`, `false`

-   `enabled` : オリジンを有効にするかどうか - `true`, `false`

-   `priority` : オリジンの優先順位 - `1` ~ `5`

-   `weight` : ロード バランシングの重み - `1` ~ `1000`

-   `http_port` : HTTP ポート番号 - `1` ~ `65535`

-   `https_port` : HTTPS ポート番号 - `1` ~ `65535`

### ルート設定（`route`）

-   `endpoint_name` : ルートを適用する Front Door エンドポイント名

-   `origin_group_name` : トラフィックを転送するオリジン グループ名

-   `patterns_to_match` : ルーティング対象となるパス パターンの一覧

-   `supported_protocols` : Front Door で許可されるプロトコル - `Http`, `Https`

-   `forwarding_protocol` : バックエンドへトラフィックを転送する際に使用するプロトコル - `HttpOnly`, `HttpsOnly`, `MatchRequest`
