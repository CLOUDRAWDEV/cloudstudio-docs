## リソース概要

Azure Container Apps Environment は、Azure Container Apps が実行されるネットワークおよび監視環境を定義するリソースです。  
Container Apps の作成および実行時に使用される Log Analytics ワークスペースなどの運用環境を関連付けることで、ログ収集や監視設定を一貫して適用できます。
