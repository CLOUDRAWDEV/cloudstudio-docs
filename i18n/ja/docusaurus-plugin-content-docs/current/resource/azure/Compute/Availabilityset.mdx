## リソース概要

Azure Availability Set は、仮想マシンを複数の障害ドメイン（Fault Domain）および更新ドメイン（Update Domain）に分散配置することで、  
ハードウェア障害やメンテナンス作業が発生した場合でもアプリケーションの可用性を高めるための論理的な VM グループです。  
同一の Availability Set に含まれる VM は物理的に分離されたインフラに配置され、単一障害点（SPOF）を防止します。

## リソース設定値

-   `update_domain_count` :  
    仮想マシングループを同時に再起動するための更新ドメイン数 – `1` ~ `20`

-   `enabled_managed_disks` :  
    管理ディスク（Managed Disk）を使用して Availability Set に仮想マシンの作成を許可するかどうか – `true`, `false`

-   `fault_domain_count` :  
    同一の電源および物理ネットワークスイッチを共有するよう構成される障害ドメイン数 – `1` ~ `3`

-   `tag` :  
    リソースをカテゴリ別に分類するためのタグ – 最大 512 文字、`key`:`value`
