## リソース概要

Azure Disk は、Azure Virtual Machine で使用されるマネージド型ブロックストレージリソースです。  
オペレーティングシステムディスク（OS Disk）またはデータディスク（Data Disk）として利用でき、  
ストレージの性能要件やコスト要件に応じて、さまざまなストレージタイプを選択できます。

## リソース設定値

-   `storage_type` :  
    ディスクを保存するためのストレージタイプ

    -   `Standard_LRS`
    -   `StandardSSD_LRS`
    -   `Premium_LRS`

-   `size_gb` :  
    ディスクのサイズ（GB） - `1` ~ `32767`

-   `enabled_public_network_access` :  
    ディスクに対するパブリックネットワークアクセスを許可するかどうか - `true`, `false`

-   `tag` :  
    リソースをカテゴリ別に分類するためのタグ - 最大 512 文字、`key`:`value`
