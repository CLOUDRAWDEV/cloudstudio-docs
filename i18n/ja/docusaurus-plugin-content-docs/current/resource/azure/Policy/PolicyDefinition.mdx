## リソース概要

Azure PolicyDefinition は、**リソースが遵守すべきルールや条件、および条件違反時に適用される効果を定義するポリシー定義リソース**です。  
ポリシーの種類と適用モードに基づき、Azure リソース全体のコンプライアンス状態を一貫して管理できます。

## リソース設定値

-   `type` : ポリシー定義の種類 - `Custom`, `BuiltIn`, `NotSpecified`
-   `mode` : ポリシー評価対象となるリソースタイプのモード
-   `display_name` : ポリシー定義の表示名
-   `linked_resource_group_name` : ポリシーを適用する Resource Group の情報
