## リソース概要

Azure PolicySetDefinition は、**複数の Policy Definition を 1 つの論理的な集合としてまとめて管理するためのポリシーセット定義リソース**です。  
共通の目的を持つポリシーを単一の単位として構成することで、大規模な環境でもポリシーの適用と管理を一貫して実施できます。

## リソース設定値

-   `type` : ポリシーセット定義の種類 - `Custom`, `BuiltIn`
-   `display_name` : ポリシーセット定義の表示名
-   `definition_names` : ポリシーセットに含まれる Policy Definition 名の一覧
