## リソース概要

Event Hubs は、大規模なリアルタイムイベント（ログ、IoT テレメトリ、アプリケーションイベントなど）を収集し、ストリーミング処理パイプラインへ配信するための分散型ストリーミングプラットフォームです。  
Namespace 単位でスループット（Throughput）やネットワークアクセス ポリシーを設定でき、その配下に Event Hub（トピックに類似した単位）を作成することで、パーティション（Partition）ベースのスケーラブルなイベント収集および保持を実現します。

## リソース設定

### Namespace 設定

-   `sku` : 使用する Tier – `Basic`, `Standard`, `Premium`

-   `capacity` : Standard SKU の Namespace 容量 / スループット単位 – `1` ~ `16`

-   `enable_auto_inflate` : Event Hub Namespace に対して自動スケーリングを有効にするかどうか – `true`, `false`

-   `maximum_throughput_units` : Auto Inflate が有効な場合の最大スループット単位数 – `1` ~ `40`

-   `minimum_tls_version` : Event Hub Namespace でサポートされる最小 TLS バージョン – `1.0`, `1.1`, `1.2`

-   `enable_local_authentication` : Event Hub Namespace に対して SAS 認証を使用するかどうか – `true`, `false`

-   `enable_public_network_access` : Event Hub Namespace に対してパブリック ネットワーク アクセスを許可するかどうか – `true`, `false`

### ネットワークアクセス制御（`network_rulesets`）

-   `network_rulesets.default_action` : デフォルトのネットワークアクセス動作 – `Allow`, `Deny`

-   `network_rulesets.virtual_network_rule.target_subnet_name` : 接続するサブネット名

-   `network_rulesets.virtual_network_rule.ignore_missing_virtual_network_service_endpoint` : 仮想ネットワーク サービス エンドポイントが存在しない場合に無視するかどうか – `true`, `false`

### Event Hub 設定（`eventhub`）

-   `eventhub.default.partition_count` : Event Hub の現在のシャード（パーティション）数 – `1` ~ `100`

-   `eventhub.default.message_retention` : Event Hub にイベントを保持する日数 – `1` ~ `90`

-   `eventhub.default.enabled_capture` : Capture を有効にするかどうか – `true`, `false`

-   `eventhub.default.encoding` : Capture で使用されるエンコーディング – `Avro`, `AvroDeflate`

-   `eventhub.default.time_window` : Capture が実行される時間間隔（分） – `1` ~ `15`

-   `eventhub.default.size_window` : Capture がトリガーされる前に Event Hub に蓄積されるデータ量 – `11` ~ `524`

-   `eventhub.default.skip_empty_archives` : Capture の時間ウィンドウ内にイベントが存在しない場合、空のファイルを出力しないかどうか – `true`, `false`

-   `eventhub.default.capture_file_name_format` : Blob Storage に保存する際のファイル命名規則

-   `eventhub.default.linked_storage_account` : メッセージを保存する Blob Storage アカウント内のコンテナー名

-   `eventhub.default.target_storage_container_name` : メッセージを保存する Blob Storage アカウント
