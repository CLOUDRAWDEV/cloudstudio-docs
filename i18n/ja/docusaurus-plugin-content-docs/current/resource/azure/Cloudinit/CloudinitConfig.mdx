## リソース概要

Cloud-init は、仮想マシンインスタンスの初回起動時に自動的に初期設定を実行するための標準的な初期化ツールです。  
オペレーティングシステムの設定、パッケージのインストール、ユーザーの作成、スクリプトの実行など、さまざまな初期構成作業を宣言的に定義でき、マルチクラウド環境および多様な Linux ディストリビューションで広く利用されています。

## リソース設定値

-   `gzip` : データ圧縮アルゴリズムを使用するかどうか - `true`, `false`

-   `part` : ディスクのパーティショニングおよび初期化スクリプトの設定

    -   `content_type` : 挿入するデータの形式
        -   `text/cloud-config`
        -   `text/x-shellscript`
        -   `text/cloud-boothook`
        -   `multipart/mixed`
        -   `text/cloud-config-archive`
        -   `text/jinja`
        -   `text/x-include-url`
        -   `text/part-handler`
    -   `content` : 挿入する実際のデータ

-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`
