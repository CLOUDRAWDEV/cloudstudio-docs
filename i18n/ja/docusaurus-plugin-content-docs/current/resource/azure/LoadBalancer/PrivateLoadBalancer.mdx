## リソース概要

Private Load Balancer は、トラフィックの過負荷を防ぐために、フロントエンドに流入するトラフィックをバックエンドプールのインスタンスへ分散する負荷分散装置です。

## リソース設定値

#### 基本設定

-   `sku` : Azure Load Balancer の規模および機能を選択するための価格レベル - `Standard`, `Basic`
-   `virtual_network_name` : Load Balancer がトラフィックを転送する Virtual Network の名前

#### フロントエンド IP 構成 (`private_lb_frontend_ip_config`)

-   `private_lb_frontend_ip_config.subnet_name` : IP 構成と連携する Subnet の名前

#### バックエンドプール (`backend_pool`)

-   `backend_pool` : Load Balancer の Backend Pool 名
-   `backend_pool.linked_virtual_machine_names` : Load Balancer がトラフィックを転送する Virtual Machine の名前（選択した Virtual Network に属する）

#### ヘルスプローブ (`health_probe`)

-   `health_probe.protocol` : ヘルスプローブが使用するバックエンドエンドポイントのプロトコルタイプ - `Http`, `Https`, `Tcp`
-   `health_probe.port` : ヘルスプローブがバックエンドエンドポイントを確認するポート - `1` ~ `65535`
-   `health_probe.request_path` : Http(s) プローブ使用時に GET に使用するパス
-   `health_probe.interval_in_seconds` : ヘルスプローブがバックエンドプールインスタンスの応答を確認する間隔（秒） - `5` ~ `2147483646`

#### 負荷分散ルール (`rule`)

-   `rule.protocol` : 外部エンドポイント向けの転送プロトコル - `Tcp`, `Udp`, `All`
-   `rule.frontend_port` : 外部エンドポイントのポート - `0` ~ `65534`
-   `rule.backend_port` : 内部接続に使用するポート - `0` ~ `65535`
-   `rule.disable_outbound_snat` : アウトバウンド接続のためにルールの SNAT を有効化 - `true`, `false`
-   `rule.frontend_ip_config_name` : ルールに連携される Frontend IP 構成の名前
-   `rule.backend_pool_name` : Load Balancer がトラフィックを転送する Backend Address Pool の名前

#### NAT ルール (`nat_rule`)

-   `nat_rule.protocol` : 外部エンドポイント向けの転送プロトコル - `Tcp`, `Udp`, `All`
-   `nat_rule.frontend_port` : 外部エンドポイントのポート - `0` ~ `65534`
-   `nat_rule.backend_port` : 内部接続に使用するポート - `0` ~ `65535`
-   `nat_rule.frontend_ip_config_name` : NAT ルールに連携される Frontend IP 構成の名前

#### タグ

-   `tag` : リソースをカテゴリ分けするためのタグ - 最大 512 文字、`key`:`value`
