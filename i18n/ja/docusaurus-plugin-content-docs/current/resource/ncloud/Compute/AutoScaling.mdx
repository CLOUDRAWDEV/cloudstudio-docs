## リソース概要

ユーザーが定義したスケジュールやモニタリング結果に基づき、仮想サーバー数を自動的に増減させ、需要変動に柔軟に対応するサービスです。

## リソース設定値

#### 基本設定

-   `linked_acg_names` : 適用する ACG 名一覧
-   `included_subnet_name` : サーバー生成用サブネット名
-   `launch_configuration_name` : 使用する Launch Configuration 名
-   `health_check_type_code` : ヘルスチェック方式 - `SVR`, `LOADB`
-   `health_check_grace_period` : ヘルスチェック猶予時間（秒）
-   `linked_target_group_list` : 接続するターゲットグループ名一覧
-   `min_size` : 最小サイズ - `1` ~ `30`
-   `max_size` : 最大サイズ - `1` ~ `30`

#### Auto Scaling ポリシー (`policy`)

-   `policy.adjustment_type_code` : 変更方式 - `CHANG`, `PRCNT`, `EXACT`
-   `policy.scaling_adjustment` : 変更値
-   `policy.cooldown` : クールダウン時間（秒）
-   `policy.min_adjustment_step` : 最小変更単位

#### Auto Scaling スケジュール (`schedule`)

-   `schedule.min_size` : 最小サイズ
-   `schedule.max_size` : 最大サイズ
-   `schedule.desired_capacity` : 期待サイズ
-   `schedule.start_time` : 開始日時
-   `schedule.end_time` : 終了日時
