## リソース概要

Init Script は、サーバー作成時に事前定義したスクリプトを自動実行できる機能です。  
同一用途のサーバーを一括作成する場合や、初期環境の自動構成に利用できます。

## リソース設定値

#### 基本設定

-   `os_type` : サーバー OS 種別 - `LNX`, `WND`
-   `content` : 自動実行されるスクリプト内容
-   `description` : Init Script の説明
