## リソース概要

Auto Scaling の実行中にサーバー拡張が必要な場合、自動的に生成される仮想サーバーのスペックを定義するテンプレートです。

## リソース設定値

#### 基本設定

-   `server_image_product_code` : 使用する OS イメージコード（CNTOS:CentOS, UBNTU:Ubuntu, WND:Windows / MYSQL,MARIA:Database / SVR:Server, EN:English Edition） - `ncloudServerImage`
-   `server_product_code` : サーバーのハードウェア構成コード（HICPU:High CPU, STAND:Standard, HIMEM:High Memory / C:コア数, M:メモリ(GB)） - `ncloudServerType`
-   `login_key_name` : 暗号化用の公開ログインキー名
-   `init_script` : サーバー作成時に自動実行されるスクリプト内容
-   `is_encrypted_volume` : Basic Block Storage の暗号化有無 - `true`, `false`
