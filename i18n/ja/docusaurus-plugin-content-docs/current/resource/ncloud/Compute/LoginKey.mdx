## リソース概要

実際のハードウェアを管理することなく、仮想化の柔軟性を提供するコンピューティングリソースです。  
クラウド環境でサーバーを作成することで、時間およびコスト面で効率的に運用でき、一時的に多くのサーバーリソースが必要な場合にも適しています。

## リソース設定値

#### 基本設定

-   `included_subnet_name` : サーバーが配置される Subnet 名
-   `server_image_product_code` : 使用する OS イメージコード - `ncloudServerImage`
-   `server_product_code` : サーバーのハードウェア構成コード - `ncloudServerType`
-   `login_key_name` : 使用する Login Key 名
-   `init_script` : 使用する Init Script 名
-   `is_encrypted_base_block_storage_volume` : Block Storage 暗号化有無 - `true`, `false`
-   `linked_network_interface_names` : サーバーに割り当てるネットワークインターフェース
