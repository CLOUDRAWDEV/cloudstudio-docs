## Resource Overview

複数のサーバーをネットワークで接続し、多数のユーザーがデータを共有できるストレージサービスです。  
ネットワーク経由の共有ストレージとして、共同利用に適しています。

-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## Resource Setting Values

#### Basic Settings

-   `volume_name_postfix` : NAS ボリューム名の接尾辞（英数字、3 ~ 20 文字）
-   `volume_size` : ボリューム容量（100GB 単位） - `500` ~ `10000`
-   `volume_allotment_protocol_type` : プロトコルタイプ - `NFS`, `CIFS`
-   `cifs_user_name` : CIFS 認証用ユーザー ID
-   `cifs_user_password` : CIFS 認証用パスワード
-   `linked_instances` : NAS ボリュームを接続するサーバーインスタンス名一覧
-   `is_encrypted` : AES-256 ベースのボリューム単位暗号化可否
