## Resource Overview

サーバーの基本ストレージに加えて提供される HDD または SSD ストレージサービスです。  
短時間で作成して即座にサーバーへ接続でき、不要な場合はすぐに返却できます。

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### Connected Resources

-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## Resource Setting Values

#### Basic Settings

-   `zone` : Block Storage が配置される物理リージョン - `KR-1`, `KR-2`
-   `linked_server_name` : ブロックストレージを接続するサーバー名
-   `storage_size` : ブロックストレージ容量（GB） - `10` ~ `16380`
-   `storage_disk_type` : ディスクタイプ - `SSD`, `HDD`
