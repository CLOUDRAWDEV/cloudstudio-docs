## Resource Overview

Object Storage は、あらゆる種類のデータをインターネット上に保存・取得できるオブジェクトストレージサービスです。  
アクセスポリシー（rule）を通じて、バケット／オブジェクトへのアクセス権限を設定できます。

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

## Resource Setting Values

#### Basic Settings

-   `rule` : Object Storage アクセスポリシー設定 - `private`, `public-read`, `public-read-write`, `authenticated-read`
