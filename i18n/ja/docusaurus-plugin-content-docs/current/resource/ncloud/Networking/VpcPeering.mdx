## リソース概要

VPC 間通信のための VPC ピアリングを設定するリソースです。

## 関連リソース

### 親リソース

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### 接続リソース

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

---

## リソース設定値

#### 基本設定

-   `linked_vpc_name_01` : ピアリング要求を送信する VPC 名（読み取り専用）
-   `linked_vpc_name_02` : ピアリング要求を受信する VPC 名（読み取り専用）
