## リソース概要

サーバーに割り当てるネットワークインターフェースを作成するサービスです。  
ネットワークインターフェースが適用されたサーバーは、Subnet を利用して独立したネットワーク通信が可能になります。

## リソース設定値

#### 基本設定

-   `included_subnet_name` : Network Interface が属する Subnet 名
-   `linked_acg_names` : Network Interface に適用する Access Control Group 名リスト
