## リソース概要

1 つのパブリック IP を使用して複数のサーバーを接続し、外部からの直接アクセスを遮断するサービスです。  
複数のプライベート IP を持つサーバーが外部サーバーと通信できるようにし、同時に外部からの直接アクセスを防いでセキュリティを維持します。

## リソース設定値

#### 基本設定

-   `included_vpc_name` : NAT Gateway を作成する VPC 名
-   `included_subnet_name` : NAT Gateway を作成する Subnet 名
