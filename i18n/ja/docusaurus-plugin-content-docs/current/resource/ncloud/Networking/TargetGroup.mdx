## リソース概要

ロードバランサーのリクエストを処理するターゲットの集合を表すリソースです。

## リソース設定値

#### 基本設定

-   `included_vpc_name` : Target Group が作成される VPC 名（読み取り専用）
-   `protocol` : トラフィックルーティングに使用するプロトコル - `TCP`, `PROXY_TCP`, `HTTP`, `HTTPS`
-   `port` : ターゲットがトラフィックを受信するポート番号
-   `algorithm_type` : ロードバランシングアルゴリズム - `RR`, `SIPHS`, `LC`, `MH`
-   `health_check_protocol` : ヘルスチェックに使用するプロトコル - `TCP`, `HTTP`, `HTTPS`
-   `health_check_http_method` : HTTP/HTTPS 使用時のヘルスチェックメソッド - `HEAD`, `GET`
-   `health_check_port` : ヘルスチェックに使用するポート番号
-   `health_check_cycle` : ヘルスチェック周期（秒） - `5` ~ `300`
-   `health_check_up_threshold` : 正常状態に移行するための連続成功回数 - `2` ~ `10`
-   `health_check_down_threshold` : 異常状態に移行するための連続失敗回数 - `2` ~ `10`
-   `health_check_url_path` : ヘルスチェックリクエスト URL パス
-   `linked_server_names` : Target Group に接続する Server 名リスト
