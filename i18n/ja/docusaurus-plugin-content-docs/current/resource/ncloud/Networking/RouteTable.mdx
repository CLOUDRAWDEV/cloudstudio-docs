## リソース概要

VPC 内のリソースに対するネットワーク経路を定義するサービスです。

## 関連リソース

### 親リソース

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

### 接続リソース

-   [**Subnet**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Subnet)

## リソース設定値

#### 基本設定

-   `included_vpc_name` : Route Table を接続する VPC 名
-   `supported_subnet_type` : サポートする Subnet タイプ (`PUBLIC`, `PRIVATE`)
-   `route_table_description` : Route Table の説明
-   `linked_subnet_names` : Route Table を接続する Subnet 名リスト

#### ルーティング設定 (`route`)

-   `target_type` : 宛先タイプ (`NATGW`, `VPCPEERING`)
-   `target_name` : 宛先リソース名
-   `destination_cidr_block` : CIDR 形式の宛先 IP 範囲
