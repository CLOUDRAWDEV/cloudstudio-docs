## リソース設定値

#### 基本設定

-   `subnet_cidr` : VPC CIDR 範囲内で割り当てる Subnet IP 範囲
-   `zone` : Subnet が配置される可用ゾーン (`KR-1`, `KR-2`)
-   `subnet_type` : Subnet タイプ (`PUBLIC`, `PRIVATE`)
-   `usage_type` : Subnet 使用目的 (`General`, `LoadBalancer`, `BareMetal`, `NatGateway`)
-   `included_vpc_name` : Subnet が属する VPC 名（読み取り専用）
-   `linked_nacl_name` : Subnet に適用する Network ACL 名（読み取り専用）
