## リソース概要

サーバーの性能や負荷状況を考慮して、ネットワークトラフィックを複数のサーバーへ分散する装置です。  
特定のサーバーに集中する負荷を分散することで、サーバーの可用性と応答時間を最適化し、無停止サービスを提供できます。

## リソース設定値

#### 基本設定

-   `network_type` : ネットワークタイプ - `PUBLIC`, `PRIVATE`
-   `type` : ロードバランサータイプ - `APPLICATION`, `NETWORK`, `NETWORK_PROXY`
-   `throughput_type` : 処理性能（秒間接続数） - `SMALL(3万)`, `MEDIUM(6万)`, `LARGE(9万)`
-   `included_subnet_names` : ロードバランサーを接続する Subnet 名リスト

#### リスナー (`listener`)

-   `listener.protocol` : リスナープロトコル - `HTTP`, `HTTPS`, `TCP`, `TLS`
-   `listener.tls_min_version_type` : TLS 最小サポートバージョン - `TLSV10`, `TLSV11`, `TLSV12`
-   `listener.port` : リスナーポート番号 - `1` ~ `65534`
-   `listener.use_http2` : HTTP/2 使用可否 - `true`, `false`
-   `listener.ssl_certificate_no` : SSL 証明書番号
-   `listener.target_group_name` : 接続する Target Group 名
