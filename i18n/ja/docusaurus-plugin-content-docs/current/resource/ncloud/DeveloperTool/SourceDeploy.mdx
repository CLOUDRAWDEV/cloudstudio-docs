## Resource Overview

SourceDeploy は、新規作成または更新されたソースを自動的にサーバーへデプロイして適用するデプロイ自動化サービスです。  
事前に設定されたユーザー定義コマンドを使用して、ソースのデプロイ・実行・検証を自動化し、デプロイ中のサービス停止時間を最小限に抑えられます。
