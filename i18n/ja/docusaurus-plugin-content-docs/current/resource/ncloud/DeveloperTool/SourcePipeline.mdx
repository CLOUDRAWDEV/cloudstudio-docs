## Resource Overview

SourceCommit・SourceBuild・SourceDeploy サービスを統合し、  
迅速かつ安定したソフトウェアリリースのためのプロセス自動化を提供するサービスです。

## Resource Setting Values

#### Basic Settings

-   `description` : 作成する Pipeline プロジェクトの説明（最大 500 文字）

#### 基本タスク (`default_task`)

-   `default_task.name` : 最初に実行されるタスク名（英字／数字／`-`／`_`、1~50 文字）
-   `default_task.type` : タスクタイプ - `SourceBuild`, `SourceDeploy`
-   `default_task.target_source_build_project` : SourceBuild プロジェクト名
-   `default_task.target_source_deploy_project` : SourceDeploy プロジェクト名
-   `default_task.target_source_deploy_project_stage` : SourceDeploy Stage 名
-   `default_task.target_source_deploy_project_scenario` : SourceDeploy Scenario 名
-   `default_task.repository_branch` : SourceBuild 対象ブランチ名

#### 追加タスク (`additional_task`)

-   `additional_task.type` : タスクタイプ - `SourceBuild`, `SourceDeploy`
-   `additional_task.target_source_build_project` : SourceBuild プロジェクト名
-   `additional_task.target_source_deploy_project` : SourceDeploy プロジェクト名
-   `additional_task.target_source_deploy_project_stage` : Stage 名
-   `additional_task.target_source_deploy_project_scenario` : Scenario 名
-   `additional_task.repository_branch` : 対象ブランチ名
-   `additional_task.pre_tasks` : 先行実行タスクリスト

#### Push トリガー (`trigger_push_repository`)

-   `trigger_push_repository.type_of_repository` : Repository タイプ - `sourcecommit`
-   `trigger_push_repository.name_of_repository` : Repository 名
-   `trigger_push_repository.branch_of_repository` : Repository ブランチ名

#### スケジュールトリガー (`trigger_schedule`)

-   `trigger_schedule.day` : 実行曜日 - `MON`, `TUE`, `WED`, `THU`, `FRI`, `SAT`, `SUN`
-   `trigger_schedule.time` : 実行時間
-   `trigger_schedule.timezone` : タイムゾーン
-   `trigger_schedule.execute_only_with_change` : 変更時のみ実行するかどうか - `true`, `false`

#### パイプラインチェイニング (`trigger_target_sourcecpipeline_id`)

-   `trigger_target_sourcecpipeline_id` : 完了後に自動実行する Pipeline ID リスト
