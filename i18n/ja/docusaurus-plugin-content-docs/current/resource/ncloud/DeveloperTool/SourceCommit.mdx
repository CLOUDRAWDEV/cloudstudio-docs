## リソース概要

SourceCommit は、ソースコードや各種ファイルを安全に保存するためのプライベート Git リポジトリサービスです。  
SourceCommit 上でリポジトリを作成し、チームプロジェクトを効率的に管理しながら、ソースコードなどのデータを簡単に保存できます。

## Resource Setting Values

#### 基本設定

-   `enable_file_safer` : File Safer 使用可否 - `true`, `false`
-   `description` : リポジトリの説明（最大 500 文字）
