## リソース概要

Ncloud リソースをデプロイするリージョンを指定するリソースです。韓国(KR)、日本(JPN)、シンガポール(SGN)をサポートします。

## 関連リソース

### 親リソース

-   [**Base**](https://docs.cstudio.app/ja/docs/resource/ncloud/Base/)

### 子リソース

-   [**Vpc**](https://docs.cstudio.app/ja/docs/resource/ncloud/Networking/Vpc)
-   [**BlockStorage**](https://docs.cstudio.app/ja/docs/resource/ncloud/Storage/BlockStorage)
-   [**ObjectStorage**](https://docs.cstudio.app/ja/docs/resource/ncloud/Storage/ObjectStorage)

## リソース設定値

#### 基本設定

-   `region` : デプロイ先リージョン - `KR`, `JPN`, `SGN`
