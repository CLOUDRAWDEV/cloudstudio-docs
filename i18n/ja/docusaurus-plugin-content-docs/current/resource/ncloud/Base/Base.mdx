## リソース概要

ユーザーのサブスクリプション情報を管理する、Ncloud における最上位グループを表します。

## 関連リソース

### 子リソース

-   [**Region**](https://docs.cstudio.app/ja/docs/resource/ncloud/Base/Region)
-   [**LoginKey**](https://docs.cstudio.app/ja/docs/resource/ncloud/Compute/LoginKey)

## リソース設定値

#### 基本設定

-   `credential_id` : ユーザー Credential
-   `site` : Ncloud サービス種別
