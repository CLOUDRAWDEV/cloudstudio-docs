## リソース概要

Elasticsearch および OpenSearch クラスターを容易に管理できる環境を提供し、各種サーバータイプやストレージ容量を選択して、クラスターの構築・デプロイ・運用・スケールを行えるリソースです。

## リソース設定値

#### 基本設定

-   `included_vpc_name` : SES を作成する VPC 名
-   `os_image_code` : 使用する OS タイプ - `osImageName`
-   `enable_master_node` : マスターノード使用可否 - `true`, `false`
-   `login_key_name` : 公開ログインキー名

#### Search Engine 設定 (`search_engine`)

-   `search_engine.version_code` : 使用する Search Engine バージョン - `versionCode`
-   `search_engine.user_name` : Search Engine ユーザー名
-   `search_engine.user_password` : Search Engine パスワード
-   `search_engine.dashboard_port` : ダッシュボードポート - `1024` ~ `65535`

#### Manager Node 設定 (`manager_node`)

-   `manager_node.enable_dual_manager` : マネージャーノード冗長化可否 - `true`, `false`
-   `manager_node.manager_node_subnet_name` : 配置するサブネット名
-   `manager_node.manager_node_product_code` : マネージャーノード製品コード - `managerNodeProductCode`

#### Data Node 設定 (`data_node`)

-   `data_node.data_node_subnet_name` : 配置するサブネット名
-   `data_node.data_node_product_code` : データノード製品コード - `managerNodeProductCode`
-   `data_node.data_node_count` : データノード数 - `3` ~ `10`
-   `data_node.data_node_storage_size` : ストレージ容量 - `100` ~ `2000`

#### Master Node 設定 (`master_node`)

-   `master_node.master_node_subnet_name` : 配置するサブネット名
-   `master_node.master_node_product_code` : マスターノード製品コード - `managerNodeProductCode`
-   `master_node.master_node_count` : マスターノード数 - `3` ~ `5`
