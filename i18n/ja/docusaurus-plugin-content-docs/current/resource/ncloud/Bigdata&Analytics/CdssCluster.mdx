## リソース概要

リアルタイム・ストリーミングデータパイプラインおよびアプリケーション構築のためのオープンソースプラットフォームである Apache Kafka クラスターを、容易にデプロイ・保護・運用・スケールできるサービスです。

## リソース設定値

#### 基本設定

-   `included_vpc_name` : CDSS を作成する VPC 名
-   `kafka_version_code` : CDSS で使用する Kafka バージョン - `kafkaVersionCode`
-   `linked_config_group_name` : 使用する CDSS Config Group 名
-   `os_image` : 使用する OS イメージタイプ - `osImage`

#### CMAK 設定 (`cmak`)

-   `cmak.user_name` : CMAK アクセス ID
-   `cmak.user_password` : CMAK アクセスパスワード

#### マネージャーノード設定 (`manager_node`)

-   `manager_node.manager_node_subnet_name` : マネージャーノードを配置するサブネット名
-   `manager_node.manager_node_product_code` : マネージャーノードのハードウェア製品コード - `managerNodeProductCode`

#### ブローカーノード設定 (`broker_node`)

-   `broker_node.broker_node_subnet_name` : ブローカーノードを配置するサブネット名
-   `broker_node.broker_node_product_code` : ブローカーノードのハードウェア製品コード - `managerNodeProductCode`
-   `broker_node.broker_node_count` : ブローカーノード数 - `3` ~ `10`
-   `broker_node.broker_node_storage_size` : ブローカーノードのストレージ容量 - `100` ~ `2000`
