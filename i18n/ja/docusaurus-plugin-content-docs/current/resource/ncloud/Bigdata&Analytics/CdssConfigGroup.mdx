## リソース概要

Cdss Config Group は、CDSS クラスターに適用される Kafka 設定ファイルを管理するサービスです。

## 関連リソース

### 親リソース

-   [**Region**](https://docs.cstudio.app/ja/docs/resource/ncloud/Base/Region)

### 接続リソース

-   [**CdssCluster**](https://docs.cstudio.app/ja/docs/resource/ncloud/Bigdata&Analytics/CdssCluster)

## リソース設定値

#### 基本設定

-   `kafka_version_code` : CDSS Config Group で使用する Kafka バージョン - `kafkaVersionCode`
-   `description` : Config Group の説明
