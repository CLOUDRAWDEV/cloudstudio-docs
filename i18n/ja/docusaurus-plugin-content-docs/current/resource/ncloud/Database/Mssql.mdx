## リソース概要

Cloud DB for MSSQL は、MSSQL データベースを簡単に構築し、自動管理できるフルマネージド型クラウドデータベースサービスです。

## リソース設定値

#### 基本設定

-   `included_subnet_name` : MSSQL が属する Subnet 名
-   `enable_high_availability` : 高可用性使用可否 - `true`, `false`
-   `user_name` : MSSQL ユーザー ID
-   `user_password` : MSSQL ユーザーパスワード
-   `image_product_code` : MSSQL イメージ製品コード
-   `product_code` : MSSQL サーバー製品コード
-   `data_storage_type` : ストレージタイプ - `SSD`, `HDD`
-   `backup_file_retention_period` : バックアップ保持期間 - `1` ~ `30`
-   `enable_automatic_backup` : 自動バックアップ使用可否
-   `backup_time` : バックアップ時間
-   `port` : MSSQL ポート（既定: `1433`）
-   `character_set_name` : 文字セット名
