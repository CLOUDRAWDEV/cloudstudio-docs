## リソース概要

MySQL は、MySQL を利用したフルマネージド型クラウドデータベースサービスで、安定した運用と障害時の自動復旧を提供します。

## リソース設定値

#### 基本設定

-   `server_name_prefix` : MySQL サーバー名
-   `users` : ユーザー設定情報
-   `databases` : 作成するデータベース名一覧
-   `included_subnet_names` : Subnet 名一覧
-   `image_product_code` : MySQL イメージ製品コード
-   `product_code` : MySQL サーバー製品コード
-   `data_storage_type` : ストレージタイプ - `SSD`, `HDD`
-   `enable_high_availability` : 高可用性使用可否
-   `enable_storage_encryption` : ストレージ暗号化使用可否
-   `enable_backup` : バックアップ使用可否
-   `backup_file_retention_period` : バックアップ保持期間 - `1` ~ `30`
-   `enable_automatic_backup` : 自動バックアップ使用可否
-   `backup_time` : バックアップ時間
-   `port` : MySQL ポート - `3306` ~ `20000`
