## リソース概要

Cloud DB for MongoDB は、MongoDB データベースを簡単に構築し、自動管理できるフルマネージド型クラウドデータベースサービスです。

-   [**Subnet**](https://docs.cstudio.app/ja/docs/resource/ncloud/Networking/Subnet)

## リソース設定値

#### 基本設定

-   `server_name_prefix` : MongoDB サーバー名
-   `user_name` : MongoDB ユーザー ID
-   `user_password` : MongoDB ユーザーパスワード
-   `included_vpc_name` : MongoDB が属する VPC 名
-   `included_subnet_name` : MongoDB が属する Subnet 名
-   `cluster_type_code` : MongoDB クラスタータイプコード
-   `shard_count` : シャード数 - `2`, `3`
-   `image_product_code` : MongoDB イメージ製品コード
-   `backup_file_retention_period` : バックアップ保持期間 - `1` ~ `30`
-   `backup_time` : バックアップ実行時間
-   `data_storage_type` : ストレージタイプ - `SSD`, `HDD`
-   `compress_code` : データ圧縮方式 - `SNPP`, `ZLIB`, `ZSTD`, `NONE`
