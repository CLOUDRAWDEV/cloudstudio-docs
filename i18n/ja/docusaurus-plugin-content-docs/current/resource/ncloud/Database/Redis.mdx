## リソース概要

Cloud DB for Redis は、数回の設定とクリックだけで Redis キャッシュを簡単に構築でき、  
Naver の最適化設定により安定した運用と、障害発生時の自動復旧を提供する  
フルマネージド型クラウドキャッシュサービスです。

## リソース設定値

#### 基本設定

-   `server_name_prefix` : Redis サーバー名（英小文字／数字／ハイフン使用可、3〜15文字）
-   `included_vpc_name` : Redis が属する VPC 名
-   `included_subnet_name` : Redis が属する Subnet 名
-   `redis_mode` : Redis 構成モード - `CLUSTER`, `SIMPLE`
-   `engine_version_code` : Redis エンジンバージョン
-   `image_product_code` : Redis サーバーイメージ製品コード
-   `product_code` : Redis インスタンスサーバー仕様製品コード
-   `target_config_group_name` : 接続する Redis Config Group 名
-   `shard_count` : シャード数（master node 基準） - `3` ~ `10`
-   `shard_copy_count` : シャード当たりのレプリカ数（slave node 数） - `0` ~ `4`
-   `enable_high_availability` : 高可用性機能使用可否 - `true`, `false`
-   `enable_backup` : バックアップ使用可否 - `true`, `false`
-   `backup_file_retention_period` : バックアップ保持期間（日） - `1` ~ `7`
-   `enable_automatic_backup` : 自動バックアップ使用可否 - `true`, `false`
-   `backup_time` : バックアップ時間
-   `port` : Redis 接続ポート - `6379` ~ `20000`
