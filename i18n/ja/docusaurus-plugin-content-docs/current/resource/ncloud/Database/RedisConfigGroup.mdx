## リソース概要

Redis Config Group では、作成した Redis サーバーをグループ化し、  
グループに属するサーバーに同一設定を適用することで効率的に管理できます。

## 関連リソース

## リソース設定値

#### 基本設定

-   `redis_version` : Redis Config Group バージョンおよびモード
-   `description` : Redis Config Group の説明
