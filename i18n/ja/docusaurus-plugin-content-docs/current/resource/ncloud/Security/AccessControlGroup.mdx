## Resource Overview

サーバー間のネットワークアクセス制御および管理を行う IP／Port ベースのフィルタリング型ファイアウォールサービスです。

## Associated Resources

### Parent Resource

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

### Connected Resources

-   [**NetworkInterface**](https://docs.cstudio.app/docs/resource/ncloud/Networking/NetworkInterface)
-   [**AutoScaling**](https://docs.cstudio.app/docs/resource/ncloud/Compute/AutoScaling)

## Resource Setting Values

#### Basic Settings

-   `included_vpc_name` : ACG を作成する VPC 名
-   `acg_description` : ACG に関する説明

#### インバウンドルール (`inbound_rule`)

-   `inbound_rule.protocol` : インバウンドトラフィックのプロトコル - `TCP`, `UDP`, `ICMP`
-   `inbound_rule.rule_apply_method` : インバウンドルール適用方式 - `ip_block`, `source_name`
-   `inbound_rule.ip_block` : インバウンドトラフィック宛先 IP 範囲（CIDR 形式）
-   `inbound_rule.source_access_control_group_name` : インバウンドトラフィックの送信元 ACG 名
-   `inbound_rule.port_range` : 適用するポート範囲 - `1` ~ `65535`
-   `inbound_rule.description` : インバウンドルールの説明

#### アウトバウンドルール (`outbound_rule`)

-   `outbound_rule.protocol` : アウトバウンドトラフィックのプロトコル - `TCP`, `UDP`, `ICMP`
-   `outbound_rule.rule_apply_method` : アウトバウンドルール適用方式 - `ip_block`, `source_name`
-   `outbound_rule.ip_block` : アウトバウンドトラフィック宛先 IP 範囲（CIDR 形式）
-   `outbound_rule.source_access_control_group_name` : アウトバウンドトラフィックの送信元 ACG 名
-   `outbound_rule.port_range` : 適用するポート範囲 - `1` ~ `65535`
-   `outbound_rule.description` : アウトバウンドルールの説明
