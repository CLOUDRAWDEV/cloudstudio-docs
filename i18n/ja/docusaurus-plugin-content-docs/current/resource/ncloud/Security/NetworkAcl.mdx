## Resource Overview

サブネットに対するネットワークセキュリティ管理を行うサービスです。

## Associated Resources

### Parent Resource

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

### Connected Resources

-   [**Subnet**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Subnet)

## Resource Setting Values

#### Basic Settings

-   `included_vpc_name` : ACL を作成する VPC 名
-   `nacl_description` : ACL に関する説明

#### インバウンドルール (`inbound_rule`)

-   `inbound_rule.priority` : インバウンドルール優先順位 - `0` ~ `199`
-   `inbound_rule.protocol` : インバウンドトラフィックプロトコル - `TCP`, `UDP`, `ICMP`
-   `inbound_rule.rule_action` : インバウンドトラフィック許可可否 - `ALLOW`, `DROP`
-   `inbound_rule.ip_block` : インバウンドトラフィック送信元 IP 範囲（CIDR 形式）
-   `inbound_rule.port_range` : 適用するポート範囲 - `1` ~ `65535`

#### アウトバウンドルール (`outbound_rule`)

-   `outbound_rule.priority` : アウトバウンドルール優先順位 - `0` ~ `199`
-   `outbound_rule.protocol` : アウトバウンドトラフィックプロトコル - `TCP`, `UDP`, `ICMP`
-   `outbound_rule.rule_action` : アウトバウンドトラフィック許可可否 - `ALLOW`, `DROP`
-   `outbound_rule.ip_block` : アウトバウンドトラフィック宛先 IP 範囲（CIDR 形式）
-   `outbound_rule.port_range` : 適用するポート範囲 - `1` ~ `65535`
