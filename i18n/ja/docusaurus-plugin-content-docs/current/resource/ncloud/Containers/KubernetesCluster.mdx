## リソース概要

アプリケーションのコンテナ化・デプロイ・管理を自動化するオープンソースプラットフォームである Kubernetes サービスです。  
コンテナのデプロイ、管理、スケーリングなどを自動化し、業務効率を向上させます。

## リソース設定値

#### 基本設定

-   `zone` : クラスターを作成する物理リージョン - `KR-1`, `KR-2`
-   `included_vpc_name` : クラスターを作成する VPC 名
-   `hypervisor_code` : ハイパーバイザーコード - `XEN`
-   `version` : クラスターバージョン
-   `maximum_number_of_nodes` : クラスターの最大ノード数 - `10`, `50`
-   `enable_public_subnet_network` : パブリックサブネット接続可否 - `true`, `false`
-   `subnet_names` : クラスターを構成するサブネット名一覧（最大 3）
-   `lb_private_subnet_name` : ロードバランサー用プライベートサブネット名
-   `lb_public_subnet_name` : ロードバランサー用パブリックサブネット名
-   `login_key_name` : 使用する Login Key 名
-   `enable_audit_log` : Audit Log 機能使用可否 - `true`, `false`

#### ノードプール (`node_pool`)

-   `node_pool.node_count` : ノード数 - `1` ~ `10`
-   `node_pool.software_code` : ノード OS イメージコード
-   `node_pool.product_code` : ノードハードウェア構成コード
-   `node_pool.node_pool_subnet_names` : ノードプール用サブネット名
-   `node_pool.enable_autoscale` : オートスケール使用可否 - `true`, `false`
-   `node_pool.min_value` : 最小ノード数
-   `node_pool.max_value` : 最大ノード数
-   `node_pool.label` : ノードプールラベル

#### ノード Taint 設定 (`node_pool.taint`)

-   `node_pool.taint.taint_effect` : Taint 効果 - `NoSchedule`, `PreferNoSchedule`, `NoExecute`
-   `node_pool.taint.taint_key` : Taint Key
-   `node_pool.taint.taint_value` : Taint Value
