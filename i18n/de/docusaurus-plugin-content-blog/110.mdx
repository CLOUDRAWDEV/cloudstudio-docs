#### Neue Funktionen wurden hinzugefügt.

<div className={styles.releaseWrap} >
<div className={styles.tag} data-type="feature">
    Feature

1. Infrastruktur laden
    - Bereits bereitgestellte Infrastruktur kann angezeigt und visualisiert werden.
    - Bestehende Infrastruktur kann in IaC umgewandelt und Statuswerte erstellt werden, die wiederverwendet werden können.
2. Infrastruktur umwandeln
    - Das konfigurierte Infrastrukturdiagramm kann auf eine andere CSP (Cloud Service Provider) umgestellt werden.
    - Beim Umstellen werden die zugeordneten Ressourcen und Kosten verglichen.
