#### Neue KI-Ressourcen wurden hinzugefügt.

<div className={styles.releaseWrap} >
<div className={styles.tag} data-type="feature">
    Feature
</div>

1. Neue KI-Ressourcen auf Basis von AWS und Azure wurden hinzugefügt.

    - AWS KI-Ressourcen

        - Bedrock Agent
        - Bedrock Knowledge Base
        - Bedrock Action Group
        - Bedrock Guardrail

    - Azure KI-Ressourcen

        - Content Safety
        - AI Service
        - Search Service

    - Benutzer können nun KI-bezogene Ressourcen, die von führenden Cloud-Services bereitgestellt werden, intuitiver entwerfen und verwalten.

2. Eine Funktion zum Anzeigen/Ausblenden von Konfigurationsfehlern wurde hinzugefügt.
    - Auch wenn in Ressourcen ungelöste Fehler vorhanden sind, können Fehleranzeigen optional ein- oder ausgeblendet werden.
