#### Wir bieten Dienstleistungen für Azure, AWS, Naver Cloud und Kubernetes an.

<div className={styles.releaseWrap} >
<div className={styles.tag} data-type="new">
    New
</div>
<div>

1. Cloud-Infrastruktur-Diagramm
    - Sie können die Cloud-Infrastruktur per Drag & Drop entwerfen.
    - Fehler in der Konfiguration der Infrastruktur werden in Echtzeit angezeigt.
    - Das gezeichnete Infrastrukturdiagramm wird in IaC (Infrastructure as Code) umgewandelt.
2. Versionsverwaltung
    - Es wird eine Versionsspeicherfunktion für die IaC-basierte Infrastruktur angeboten, mit der Sie zu einer bestimmten Version zurückkehren können.
3. Kostenberechnung
    - Es werden monatliche, tägliche und stündliche Betriebskosten der gezeichneten Infrastruktur angezeigt (KRW, USD, JPY, EUR)
4. Schwachstellenanalyse
    - Eine Schwachstellenanalyse der gezeichneten Infrastruktur wird angeboten, zusammen mit einer Anleitung zur Behebung der Schwachstellen.
5. Bereitstellungsmanagement
    - Die gezeichnete Infrastruktur kann durch ein vorheriges Bereitstellungstest auf ihre Gültigkeit überprüft werden, und sie kann mit den CSP-spezifischen Anmeldeinformationen verbunden werden, um die tatsächliche Infrastruktur bereitzustellen.
