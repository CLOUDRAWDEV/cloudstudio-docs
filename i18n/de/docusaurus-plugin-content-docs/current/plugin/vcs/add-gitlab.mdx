## Registrierung von Gitlab

Um die Versionskontrolle des Canvas in Cloud Studio durchzuführen, ist die Integration eines VCS (Version Control System) erforderlich.<br/>
Zur Verknüpfung des Terraform Cloud-Kontos für die Validierung und Bereitstellung von Projekten muss zuvor das VCS-Konto integriert werden.<br/>
Auf dieser Seite wird beschrieben, wie Sie ein Gitlab-Konto mit einem VCS verbinden.

<br />

<details>
    <summary>Was ist Gitlab?</summary>
    <h5>
        Gitlab ist eine Plattform, auf der Softwareentwicklungsprojekte gehostet
        und verwaltet werden können.
    </h5>
</details>

<p>&nbsp;</p>

1. [Gitlab](https://gitlab.com/) Nach der Anmeldung und Registrierung klicken Sie oben links auf das `Profil-Symbol - Einstellungen`.

<img width="100%" src={gitlab01} alt="otp img" />

<p>&nbsp;</p>

2. Klicken Sie in der linken Seitenleiste auf `Access tokens` und klicken Sie dann rechts auf die Schaltfläche `Add new token`.

<img width="100%" src={gitlab02} alt="otp img" />

<p>&nbsp;</p>

3. Geben Sie den `Token-Namen` und die `Token-Gültigkeitsdauer` ein und wählen Sie im Abschnitt Select scopes die Berechtigungen `api`, `read_repository`, `write_repository` aus. Klicken Sie dann auf die Schaltfläche `Create personal access token`, um den Token zu erstellen.

<img width="100%" src={gitlab03} alt="otp img" />

<p>&nbsp;</p>

4. Überprüfen Sie den generierten Token.

<img width="100%" src={gitlab04} alt="otp img" />

<p>&nbsp;</p>

:::caution

Der generierte Token kann später nicht erneut eingesehen werden. Speichern Sie ihn daher unbedingt separat.

:::

<p>&nbsp;</p>

5. Klicken Sie in Cloud Studio auf `Meine Informationen - Plugin-Verwaltung` und dann auf die Schaltfläche +, um das VCS-Konto zu verbinden.

<img width="100%" src={github05} alt="otp img" />

<p>&nbsp;</p>

6. Wählen Sie Gitlab als VCS aus, geben Sie den `Benutzernamen` und den generierten `Token` Ihres Gitlab-Kontos ein und klicken Sie auf die Schaltfläche `Registrieren`.

<img width="100%" src={gitlab05} alt="otp img" />

<p>&nbsp;</p>

7. Sobald der `Benutzername` und der generierte `Token` eines gültigen Gitlab-Kontos eingegeben sind, wird die Gitlab-Integration erfolgreich abgeschlossen.

<img width="100%" src={gitlab06} alt="otp img" />

<p>&nbsp;</p>

:::caution

Für die Integration der Gitlab Community- und Gitlab Enterprise-Versionen müssen die gehosteten `Http URL` und `API URL` zusätzlich eingegeben werden.

:::
