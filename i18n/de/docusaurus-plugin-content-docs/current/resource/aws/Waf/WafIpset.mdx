## Ressourcenübersicht

AWS WAF IPSet ist eine Liste von IP-Adressen, die in der Web Application Firewall von Amazon Web Services verwendet wird. Damit können Benutzer Zugriffsregeln für definierte IP-Adressen erstellen und verwalten. Durch den Einsatz von IP-Sets lässt sich die Sicherheit von Webanwendungen erhöhen, indem Anfragen von bestimmten IP-Adressen zugelassen oder blockiert werden.

## Ressourcenübersicht

Ein AWS WAF IP Set ist eine Ressource, die eine oder mehrere IP-Adressen oder CIDR-Blöcke gruppiert, um sie in Web-ACL-Regeln zu referenzieren. Sie wird verwendet, um Zulassungs- oder Blockierungsrichtlinien für bestimmte IP-Bereiche zu konfigurieren.

## Ressourceneinstellungen

#### Grundeinstellungen

-   `scope` : Anwendungsbereich des IP-Sets – `REGIONAL`, `CLOUDFRONT`
-   `ip_address_version` : IP-Adressversion – `IPV4`, `IPV6`
-   `addresses` : Liste von IP-Adressen oder IP-Adressblöcken im CIDR-Format

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
