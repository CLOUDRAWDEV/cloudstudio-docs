## Ressourcenübersicht

AWS WAF IPSet ist eine Liste von IP-Adressen, die in der Web Application Firewall von Amazon Web Services verwendet wird. Damit können Benutzer Zugriffsregeln für die definierten IP-Adressen erstellen und verwalten. Durch die Nutzung von IPSet können Sie Anfragen von bestimmten IP-Adressen zulassen oder blockieren, um die Sicherheit der Webanwendung zu erhöhen.

## Ressourcen-Einstellwerte

-   `scope` : Geben Sie an, ob es für eine AWS CloudFront-Verteilung oder für eine regionale Anwendung ist - `REGIONAL`, `CLOUDFRONT`
-   `ip_address_version` : Geben Sie IPV4 oder IPV6 an - `IPV4`, `IPV6`
-   `addresses` : Geben Sie ein Array von Zeichenfolgen ein, das eine oder mehrere IP-Adressen oder IP-Adressblöcke in CIDR-Notation angibt
