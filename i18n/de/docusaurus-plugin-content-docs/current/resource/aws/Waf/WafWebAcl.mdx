## Ressourcenübersicht

AWS WAF Web ACL ist die oberste Ebene der Sammlung von Regeln, die auf eine Webanwendung angewendet werden. Mit Web ACL können mehrere Rule Groups und Regeln kombiniert und die Reihenfolge der Anforderungsverarbeitung für die Webanwendung definiert werden.

## Ressourcen-Einstellwerte

-   `scope` : Geben Sie an, ob es für eine AWS CloudFront-Verteilung oder für eine regionale Anwendung ist - `REGIONAL`, `CLOUDFRONT`
-   `cloudwatch_metrics_enabled` : Festlegen, ob die verbundenen Ressourcen Metriken an CloudWatch senden sollen - `true`, `false`
-   `metric_name` : Der Name der CloudWatch-Metrik darf nur Kleinbuchstaben, Großbuchstaben, Bindestriche (-) und Unterstriche (_) enthalten und muss eine Länge von 1-128 Zeichen haben
-   `sampled_requests_enabled` : Festlegen, ob AWS WAF eine Stichprobe der Webanfragen speichern soll, die mit den Regeln übereinstimmen - `true`, `false`
