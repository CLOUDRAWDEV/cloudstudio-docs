## Ressourcenübersicht

Eine AWS WAF Web ACL ist die oberste Ebene einer Regelsammlung, die auf Webanwendungen angewendet wird. Mit einer Web ACL können mehrere Rule Groups und einzelne Regeln kombiniert sowie die Reihenfolge der Anforderungsverarbeitung definiert werden. Dadurch lässt sich die Sicherheit von Webanwendungen erhöhen und das Zulassen, Blockieren oder Zählen von Anfragen steuern.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `scope` : Anwendungsbereich der Web ACL – `REGIONAL`, `CLOUDFRONT`
-   `cloudwatch_metrics_enabled` : Aktivierung der Übermittlung von CloudWatch-Metriken – `true`, `false`
-   `metric_name` : Name der CloudWatch-Metrik, erlaubt sind Groß-/Kleinbuchstaben, Bindestriche und Unterstriche, `1` ~ `128` Zeichen
-   `sampled_requests_enabled` : Speicherung von Stichproben der mit Regeln übereinstimmenden Webanfragen – `true`, `false`

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
