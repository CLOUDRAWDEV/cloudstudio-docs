## Ressourcenübersicht

Eine AWS WAF Rule Group ist eine Sammlung von Regeln, die in der Web Application Firewall verwendet werden. Durch die Gruppierung mehrerer Regeln können diese gemeinsam auf Webanwendungen angewendet werden, wodurch Wiederverwendbarkeit und Verwaltungseffizienz erhöht werden. Rule Groups steuern zentrale Aspekte der Webanwendungssicherheit und können Anfragen zulassen, blockieren oder zählen.

## Ressourceneinstellungen

#### Grundeinstellungen

-   `scope` : Anwendungsbereich der Rule Group – `REGIONAL`, `CLOUDFRONT`
-   `capacity` : Erforderliche Web-ACL-Kapazitätseinheiten (WCU) für die Regelgruppe
-   `cloudwatch_metrics_enabled` : Aktivierung der Übermittlung von CloudWatch-Metriken – `true`, `false`
-   `metric_name` : Name der CloudWatch-Metrik, erlaubt sind Groß-/Kleinbuchstaben, Bindestriche und Unterstriche, `1` ~ `128` Zeichen
-   `sampled_requests_enabled` : Speicherung von Stichproben der mit Regeln übereinstimmenden Webanfragen – `true`, `false`

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
