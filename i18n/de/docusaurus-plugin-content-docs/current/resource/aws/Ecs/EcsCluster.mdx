## Ressourceneinstellungen

-   `set_container_insights` : Festlegen, ob Container Insights dem Cluster zugewiesen werden soll - `Enabled`
-   `kms_key_name` : Name des AWS Key Management Service-Schlüssels zum Verschlüsseln von Daten zwischen dem lokalen Client und dem Container
-   `logging` : Protokolleinstellungen für die Umleitung der Ausführungsergebnisse - `OVERRIDE`,`NONE`,`DEFAULT`
-   `cloud_watch_encryption_enabled` : Ob die Verschlüsselung in CloudWatch-Protokollen aktiviert ist - `false`,`true`
-   `capacity_providers` : Name der CloudWatch-Protokollgruppe, an die Protokolle gesendet werden sollen - `Fargate`,`Fargate_spot`
-   `service`
    -   `name` : Name des Dienstes
    -   `computing_option` : Verteilungsmethode der Aufgaben im Dienst - `capacity_provider_stratege`,`launch_type`

    -   `computing_option`
        -   `capacity_provider_strategy`
            -   `capacity_provider` :  `Fargate`,`Fargate_spot`   
            -   `base` :  Mindestens auszuführende Anzahl von Aufgaben (bis zu 100000)
            -   `weight` :  Relativer Prozentsatz der insgesamt ausgeführten Aufgaben (bis zu 1000)

    -   `computing_option.launch_type` : Starttyp des Dienstes
        -   `launch_type`
            -   `launch_type` : `ec2`,`Fargate`,`External`   
            -   `task_definition_name` : Name der ECS Task Definition, die für den Dienst verwendet wird
            -   `desired_count` : Anzahl der Instanzen der Task Definition, die für den Dienst ausgeführt werden
