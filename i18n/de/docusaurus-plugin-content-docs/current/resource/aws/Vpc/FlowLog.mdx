## Ressourcenübersicht

VPC Flow Logs ermöglichen das Sammeln von Informationen über IP-Verkehr, der von und zu den Netzwerk-Interfaces einer VPC gesendet und empfangen wird. Flow-Log-Daten können in Amazon CloudWatch Logs, Amazon S3 oder Amazon Kinesis Data Firehose veröffentlicht werden. Durch das Erstellen von Flow Logs können Sie Flow-Log-Einträge in der konfigurierten Log-Gruppe, dem Bucket oder dem Versandstream abrufen und anzeigen.

## Ressourcenkonfigurationswerte

-   `linked_log_destination_type` : Speichertyp für die zu speichernden Log-Daten
-   `linked_log_destination_name` : Name des Speichers für die Log-Daten
-   `traffic_type` : Art des zu sammelnden Verkehrs
-   `included_vpc_name` : Name der VPC, mit der das Flow Log verbunden werden soll
