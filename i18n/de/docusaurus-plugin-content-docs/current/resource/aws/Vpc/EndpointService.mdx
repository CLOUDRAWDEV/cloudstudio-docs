## Ressourcenübersicht

Ein Dienst, der eine private Verbindung zu vom Kunden unterstützten AWS-Services und VPC-Endpoint-Services ermöglicht

## Zugehörige Ressourcen

### Verknüpfte Ressourcen

-   [**Endpoint**](https://docs.cstudio.app/de/docs/resource/aws/Vpc/Endpoint)

## Ressourceneinstellungen

#### Grundeinstellungen

-   `acceptance_required` : Gibt an, ob der Serviceinhaber Endpoint-Verbindungsanfragen akzeptieren muss – `true`, `false`
-   `load_balancer_type` : Typ des mit dem Endpoint-Service zu verbindenden Load Balancers – `network`, `gateway`
-   `linked_lb_names` : Liste der Load-Balancer-Namen für den Endpoint-Service
-   `manual_lb_arns` : Liste der Load-Balancer-ARNs für den Endpoint-Service
-   `supported_ip_address_types` : Liste der unterstützten IP-Adresstypen – `ipv4`
-   `activate_private_dns_name` : Privater DNS-Name für den Service

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
