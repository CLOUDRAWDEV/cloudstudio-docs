## Ressourcenübersicht

Ein NAT-Gateway ist ein NAT-Dienst (Network Address Translation). Es ermöglicht Instanzen in privaten Subnetzen, Verbindungen zu Diensten außerhalb der VPC herzustellen, verhindert jedoch, dass externe Dienste Verbindungen zu diesen Instanzen initiieren.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `included_subnet_name` : Name des Subnetzes, mit dem das NAT-Gateway verbunden wird
-   `connectivity_type` : Verbindungstyp des NAT-Gateways – `public`, `private`
-   `linked_eip_name` : Name der zu verbindenden Elastic IP

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
