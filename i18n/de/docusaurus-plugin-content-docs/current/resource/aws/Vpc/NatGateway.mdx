## Ressourcenübersicht

NAT Gateway ist ein Network Address Translation (NAT)-Service. Mit einem NAT Gateway können Instanzen im privaten Subnetz mit Diensten außerhalb der VPC kommunizieren, jedoch können diese externen Dienste keine Verbindungen zu diesen Instanzen initiieren.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Subnet**](https://docs.cstudio.app/docs/resource/aws/Vpc/Subnet)

## Ressourcenkonfigurationswerte

-   `included_subnet_name` : Der Name des Subnetzes, das mit dem NAT Gateway verbunden wird
-   `connectivity_type` : Verbindungstyp des NAT Gateways - `public`, `private`
-   `eip_name` : Name der EIP
