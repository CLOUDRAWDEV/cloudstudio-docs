## Ressourcenübersicht

Eine Security Group steuert den ein- und ausgehenden Datenverkehr zu und von den zugeordneten Ressourcen. Wird beispielsweise eine Security Group mit einer EC2-Instance verknüpft, kontrolliert sie den eingehenden und ausgehenden Datenverkehr dieser Instance. Security Groups können ausschließlich mit Ressourcen innerhalb der VPC verbunden werden, in der sie erstellt wurden.  
Beim Erstellen einer VPC wird automatisch eine Standard-Security-Group bereitgestellt, und für jede VPC können zusätzliche Security Groups erstellt werden.  
Für die Nutzung von Security Groups fallen keine zusätzlichen Kosten an.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `description` : Beschreibung der Security Group
-   `included_vpc_name` : Name der VPC, zu der die Security Group gehört

#### Eingehende Regeln (`ingress`)

-   `ingress.rule_name` : Name der Ingress-Regel
-   `ingress.description` : Beschreibung der Ingress-Regel
-   `ingress.from_port` : Startport der zulässigen Verbindung
-   `ingress.to_port` : Endport der zulässigen Verbindung
-   `ingress.protocol` : Protokoll – `tcp`, `udp`, `icmp`, `all`
-   `ingress.cidr_block` : Zulässiger Quell-CIDR-Block

#### Ausgehende Regeln (`egress`)

-   `egress.rule_name` : Name der Egress-Regel
-   `egress.description` : Beschreibung der Egress-Regel
-   `egress.from_port` : Startport der zulässigen Verbindung
-   `egress.to_port` : Endport der zulässigen Verbindung
-   `egress.protocol` : Protokoll – `tcp`, `udp`, `icmp`, `icmpv6`, `all`
-   `egress.cidr_block` : Zulässiger Ziel-CIDR-Block

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
