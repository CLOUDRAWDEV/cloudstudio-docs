## Ressourcenkonfiguration

#### Grundeinstellungen

-   `service_range` : Servicekategorie für den Endpoint-Dienst – `awsService`, `endpointService`
-   `aws_service_name` : Name des AWS-Services für den Endpoint-Dienst
-   `vpc_endpoint_type` : Typ des Endpoints – `Gateway`, `Interface`, `GatewayLoadBalancer`
-   `included_vpc_name` : Name der VPC, in der der Endpoint erstellt wird
-   `enabled_private_dns` : Aktivierung von privatem DNS – `true`, `false`
-   `enable_private_dns_only_for_inbound_resolver_endpoint` : Aktivierung ausschließlich privaten DNS für eingehende Anfragen – `true`, `false`
-   `dns_record_ip_type` : IP-Typ des DNS-Eintrags – `ipv4`, `dualstack`, `servicedefined`, `ipv6`
-   `ip_address_type` : IP-Adresstyp des Endpoints – `ipv4`, `ipv6`, `dualstack`
-   `policy_access` : Richtlinienzugriffsbereich für den Endpoint – `Full`, `Custom`
-   `custom_policy` : Benutzerdefinierte Richtlinie zur Steuerung des Servicezugriffs

#### Endpoint-Service-Einstellungen (`endpoint_service`)

-   `endpoint_service.is_manual` : Direkte Eingabe der Endpoint-Service-ARN – `true`, `false`
-   `endpoint_service.service_name` : Name des Endpoint-Services
-   `endpoint_service.linked_endpoint_service_name` : Name des verknüpften Endpoint-Services

#### Netzwerkeinstellungen

-   `linked_security_group_names` : Liste der mit dem Endpoint zu verbindenden Security Groups
-   `linked_subnet_names` : Liste der Subnetze zur Erstellung von Netzwerkschnittstellen
-   `route_table_names` : Liste der mit dem Endpoint zu verbindenden Route Tables

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
