## Ressourcenkonfigurationswerte

-   `service_range` : Kategorie des Dienstes, der den Endpoint-Dienst verwenden wird - `awsService`,`endpointService`
-   `aws_service_name` : Name des AWS-Dienstes, der den Endpoint-Dienst verwenden wird
-   `vpc_endpoint_type` : Name eines anderen Endpoint-Dienstes, der den Endpoint-Dienst verwenden wird - `gateway`, `interface`, `gatewayloadbalancer`
-   `included_vpc_name` : Name der VPC, in der der Endpoint erstellt wird
-   `route_table_names` : Eine oder mehrere Route-Table-IDs, mit denen der Endpoint verbunden wird
-   `policy_access` : Zugriffsrichtlinie des Endpoints, die den Zugriff auf den Dienst steuert - `Full`, `Custom`
