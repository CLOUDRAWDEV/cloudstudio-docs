## Ressourcenübersicht

Eine Virtual Private Cloud (VPC) ist ein virtuelles Netzwerk, das ausschließlich Ihrem AWS-Konto gehört und logisch von anderen virtuellen Netzwerken in der AWS-Cloud getrennt ist. AWS-Ressourcen (z. B. Amazon-EC2-Instances) können innerhalb einer VPC gestartet werden.  
Eine VPC-Peering-Verbindung ist eine Netzwerkverbindung zwischen zwei VPCs, die es ermöglicht, Datenverkehr über private IPv4- oder IPv6-Adressen zu routen. Dadurch können Instances in den VPCs miteinander kommunizieren, als befänden sie sich im selben Netzwerk. VPC-Peering-Verbindungen können zwischen Ihrer eigenen VPC oder einer VPC eines anderen AWS-Kontos erstellt werden. Die VPCs können sich in unterschiedlichen Regionen befinden (regionsübergreifendes VPC-Peering).

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `linked_vpc_name_01` : Name der VPC, die die Peering-Verbindung anfordert
-   `linked_vpc_name_02` : Name der Ziel-VPC für die Peering-Verbindung
-   `auto_accept` : Automatische Annahme der Peering-Verbindung – `true`, `false`

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
