## Ressourcenübersicht

Virtual Private Cloud (VPC) ist ein virtuelles Netzwerk, das exklusiv für Ihr AWS-Konto ist. Das VPC ist logisch von anderen virtuellen Netzwerken in der AWS-Cloud getrennt. Sie können AWS-Ressourcen (z. B. Amazon EC2-Instanzen) innerhalb des VPC starten.
Eine VPC-Peering-Verbindung ist eine Netzwerkverbindung zwischen zwei VPCs, die es ermöglicht, den Datenverkehr mit privaten IPv4- oder IPv6-Adressen zwischen ihnen zu routen. Instanzen innerhalb der VPC können miteinander kommunizieren, wie es in einem gleichen Netzwerk der Fall wäre. Sie können eine VPC-Peering-Verbindung zwischen Ihrer eigenen VPC oder der VPC eines anderen AWS-Kontos herstellen. Die VPCs können sich in verschiedenen Regionen befinden (dies wird auch als regionenübergreifende VPC-Peering-Verbindung bezeichnet).

## Ressourcen-Einstellwerte

-   `linked_vpc_name_01` : Name der VPC, die für das Peering verwendet wird
-   `linked_vpc_name_02` : Name der VPC, die für das Peering verwendet wird
-   `auto_accept` : Ob die Peering-Verbindung automatisch akzeptiert wird - `true`, `false`
