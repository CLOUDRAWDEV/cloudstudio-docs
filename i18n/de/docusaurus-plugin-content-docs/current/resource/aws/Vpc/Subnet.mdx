## Ressourcenübersicht

Ein Subnetz ist ein IP-Adressbereich innerhalb einer VPC. In einem bestimmten Subnetz können AWS-Ressourcen wie beispielsweise EC2-Instanzen erstellt werden.

## Ressourceneinstellungen

#### Grundeinstellungen

-   `included_vpc_name` : Name der VPC, in der das Subnetz bereitgestellt wird
-   `cidr_block` : IP-Adressbereich (CIDR) des Subnetzes
-   `availability_zone` : Verfügbarkeitszone für das Subnetz
-   `pip_enable` : Automatische Zuweisung öffentlicher IP-Adressen – `true`, `false`

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
