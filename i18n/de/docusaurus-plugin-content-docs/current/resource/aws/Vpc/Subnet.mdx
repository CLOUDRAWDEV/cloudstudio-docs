## Ressourcenübersicht

Ein Subnetz ist der IP-Adressbereich eines VPCs. In einem bestimmten Subnetz können AWS-Ressourcen wie EC2-Instanzen erstellt werden.

## Ressourcen-Einstellwerte

-   `included_vpc_name` : Name der VPC, in der das Subnetz bereitgestellt werden soll
-   `cidr_block` : IP-Adressbereich (CIDR) des Subnetzes
-   `availability_zone` : Verfügbarkeitszone, in der das Subnetz bereitgestellt werden soll
-   `pip_enable` : Zuweisung einer öffentlichen IP
