## Ressourcenübersicht

Ein Virtual Private Gateway ist der VPN-Gateway auf der Amazon-Seite der Site-to-Site VPN-Verbindung. Erstellen Sie ein Virtual Private Gateway und verbinden Sie es mit der VPC, für die Sie eine Site-to-Site VPN-Verbindung einrichten möchten.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Verbundene Ressourcen

-   [**Vpc**](https://docs.cstudio.app/docs/resource/aws/Vpc/)

-   [**Vpc Customer Gateway**](https://docs.cstudio.app/docs/resource/aws/Vpc/CustomerGateway)

## Ressourcen-Einstellwerte

-   `linked_vpc_name` : Name der VPC, die das VPN-Gateway enthalten wird
-   `vpn_connection` : Name der VPN-Verbindung
    -   `linked_customer_gateway` : Name des Customer Gateways, das mit dem VPN-Gateway verbunden wird
    -   `static_routes_only` : Geben Sie an, ob nur statisches Routing zwischen den Gateways verwendet werden soll - `true`, `false`
