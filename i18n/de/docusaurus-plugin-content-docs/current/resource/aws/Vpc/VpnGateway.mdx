## Ressourcenübersicht

Ein Virtual Private Gateway ist der VPN-Endpunkt auf der Amazon-Seite einer Site-to-Site-VPN-Verbindung. Durch die Erstellung eines Virtual Private Gateways und dessen Anbindung an eine VPC kann eine Site-to-Site-VPN-Verbindung eingerichtet werden.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `linked_vpc_name` : Name der VPC, mit der das VPN-Gateway verbunden wird
-   `dx_gateway` : Konfiguration der Direct-Connect-Gateway-Integration
-   `dx_gateway.linked_dx_gateway` : Name des zu verbindenden Dx-Gateways
-   `dx_gateway.allowed_prefixes` : Liste der CIDR-Prefixe, die an das On-Premises-Netzwerk angekündigt werden

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
