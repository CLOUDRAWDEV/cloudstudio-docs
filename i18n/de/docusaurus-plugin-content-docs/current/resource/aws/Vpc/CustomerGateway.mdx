## Ressourcenübersicht

AWS Transit Gateway verbindet Amazon Virtual Private Clouds (VPCs) und On-Premises-Netzwerke über einen zentralen Hub. Diese Verbindung vereinfacht Netzwerke, indem komplexe Peering-Beziehungen eliminiert werden. Transit Gateway fungiert als hochskalierbarer Cloud-Router.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `bgp_asn` : BGP-ASN-Wert des Gateways – `1` ~ `2147483647`
-   `ip_address` : Feste öffentliche IP-Adresse der externen Gateway-Schnittstelle
-   `private_certificate_arn` : ARN des AWS Private Certificate Manager-Zertifikats

#### VPN-Verbindungseinstellungen (`vpn_connection`)

-   `vpn_connection.resource_type` : Typ der mit dem Customer Gateway zu verbindenden Ressource – `none`, `transit_gateway`, `vpn_gateway`
-   `vpn_connection.linked_resource_name` : Name der zu verbindenden Ressource
-   `vpn_connection.static_routes_only` : Verwendung ausschließlich statischer Routen – `true`, `false`
-   `vpn_connection.outside_ip_address_type` : Typ der externen IP-Adresse – `PublicIpv4`, `PrivateIpv4`
-   `vpn_connection.dx_gateway_name` : Name des Transit-Gateway-Attachments für Private-IP-VPN-Verbindungen

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
