## Ressourcenübersicht

AWS Transit Gateway verbindet Amazon Virtual Private Cloud (VPC) mit On-Premises-Netzwerken über ein zentrales Hub und vereinfacht das Netzwerk, indem es komplexe Peering-Beziehungen entfernt. Transit Gateway fungiert als hochgradig skalierbarer Cloud-Router.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

## Ressourcenkonfigurationswerte

-   `bgp_asn` : BGP (Border Gateway Protocol) ASN (Autonomous System Number) des Gateways
-   `ip_address` : IP-Adresse des externen Interfaces des Gateways, das für die Internet-Routable-Verbindung verwendet wird
