## Ressourcenkonfiguration

#### Grundeinstellungen

-   `linked_transit_gateway_name` : Name des Transit Gateways, das mit der VPC verbunden wird
-   `is_manual` : Gibt an, ob die VPC-ID manuell eingegeben wird – `true`, `false`
-   `linked_vpc_name` : Name der VPC, die mit dem Transit Gateway verbunden wird
-   `subnet_names` : Liste der Subnetznamen, die mit dem Transit Gateway verbunden werden

#### Manuelle Verbindungseinstellungen (`manual`)

-   `vpc_id` : VPC-ID, die mit dem Transit Gateway verbunden wird
-   `subnet_ids` : Liste der Subnetz-IDs innerhalb der durch `vpc_id` angegebenen VPC

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
