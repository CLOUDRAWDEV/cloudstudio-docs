## Ressourcenübersicht

Die AWS Network Firewall Policy definiert die Überwachungs- und Schutzmaßnahmen für die Network Firewall.
## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Verbundene Ressourcen

-   [**Network Firewall**](https://docs.cstudio.app/docs/resource/aws/Vpc/NetworkFirewall)
-   [**Network Firewall Rule Group**](https://docs.cstudio.app/docs/resource/aws/Vpc/NetworkFirewallRuleGroup)


## Ressourcen-Einstellwerte

-   `description` : Beschreibung der Firewall-Policy
-   `stream_exception_policy` : Wie der Traffic mit unterbrochener Midstream behandelt wird - `drop`,`continue`,`reject`
-   `stateless_default_action` : Einstellung der stateless_default_action
    -   `enabled_fragment_packet_action` : Aktivierung von Fragment-Paket-Operationen - `false`,`true`
    -   `default_action` : Liste der Aktionen, die durchgeführt werden, wenn Pakete nicht mit den stateless Regeln der Policy übereinstimmen - `aws:drop`,`aws:pass`,`aws:forward_to_sfe`
-   `stateless_rule_group_names` : Stateless Regelgruppen, die in der Policy verwendet werden
-   `stateful_default_action` : Konfiguration der stateful Standardaktion
    -   `rule_evaluation_order` : Wie die Reihenfolge der Bewertung der stateful Regeln in der Policy verwaltet wird
    -   `default_actions` : Liste der Aktionen, die durchgeführt werden, wenn Pakete nicht mit den stateful Regeln der Policy übereinstimmen - `aws:drop_strict`,`aws:drop_established`,`aws:alert_strict`,`aws:alert_established`
-   `strict_stateful_rule_group_names` : Liste der Aktionen, die durchgeführt werden, wenn Pakete nicht mit den stateful Regeln der Policy übereinstimmen
-   `rule_variables` : Variablen, die zum Überschreiben der Standardwiederherstellungsdateneinstellungen in der Firewall-Policy verwendet werden können
-   `encryption_configuration.
    -   `enabled_custom_configuration` : Daten mit AWS verwalteten Schlüsseln verschlüsseln - `false`,`true`
