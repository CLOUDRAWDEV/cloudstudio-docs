## Ressourcenübersicht

Eine AWS Network Firewall Policy definiert Überwachungs- und Schutzverhalten für Network Firewalls.

---

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `description` : Beschreibung der Firewall-Richtlinie (maximal 256 Zeichen)
-   `stream_exception_policy` : Umgang mit unterbrochenem Midstream-Datenverkehr – `DROP`, `CONTINUE`, `REJECT`

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
