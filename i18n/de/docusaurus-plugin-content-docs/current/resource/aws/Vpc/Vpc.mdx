## Ressourcenübersicht

Mit Amazon Virtual Private Cloud (Amazon VPC) haben Sie die vollständige Kontrolle über Ihre virtuelle Netzwerkumgebung, einschließlich der Ressourcenzuweisung, der Verbindung und der Sicherheit. Starten Sie, indem Sie VPC über die AWS Service-Konsole einrichten. Fügen Sie dann Ressourcen wie Amazon Elastic Compute Cloud (EC2) und Amazon Relational Database Service (RDS)-Instanzen zu Ihrem VPC hinzu. Definieren Sie schließlich, wie das VPC miteinander in einem Konto, einer Verfügbarkeitszone oder einer AWS-Region kommuniziert. Im folgenden Beispiel wird der Netzwerkverkehr zwischen zwei VPCs innerhalb jeder Region geteilt.
