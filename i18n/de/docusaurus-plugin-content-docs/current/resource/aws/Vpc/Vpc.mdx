## Ressourcenübersicht

Mit Amazon Virtual Private Cloud (Amazon VPC) erhalten Sie vollständige Kontrolle über Ihre virtuelle Netzwerkumgebung, einschließlich Ressourcenplatzierung, Konnektivität und Sicherheit. Beginnen Sie mit der Einrichtung einer VPC über die AWS-Servicekonsole. Anschließend fügen Sie Ressourcen wie Amazon Elastic Compute Cloud (EC2)- und Amazon Relational Database Service (RDS)-Instanzen zur VPC hinzu.  
Abschließend definieren Sie, wie VPCs über Konten, Availability Zones oder AWS-Regionen hinweg miteinander kommunizieren. Im folgenden Beispiel wird der Netzwerkverkehr zwischen zwei VPCs innerhalb jeder Region gemeinsam genutzt.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `cidr_block` : IP-Adressbereich (CIDR) der VPC
-   `enabled_dns_support` : Aktivierung der DNS-Auflösung – `true`, `false`
-   `enabled_dns_hostnames` : Aktivierung der DNS-Hostnamen – `true`, `false`

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
