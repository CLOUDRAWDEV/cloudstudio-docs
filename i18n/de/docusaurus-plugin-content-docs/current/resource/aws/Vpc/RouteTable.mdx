## Ressourcenübersicht

Die Route Table in einer AWS VPC (Virtual Private Cloud) ist eine AWS-Ressource, die definiert, an welches Ziel der Datenverkehr für Subnetze innerhalb der VPC weitergeleitet wird. Alle Subnetze innerhalb der VPC sind mit einer oder mehreren Routing-Tabellen verbunden, und die Routing-Tabelle spezifiziert Routing-Regeln für Ziele wie Internet-Gateways, NAT-Gateways, VPC-Endpunkte oder VPN-Verbindungen. Die Routing-Tabelle leitet den Datenverkehr in der Reihenfolge der Routing-Regeln weiter, und aller Datenverkehr, der in einem Subnetz erzeugt wird, wird über die verbundene Routing-Tabelle an das Ziel weitergeleitet. Dies ermöglicht es den Subnetzen innerhalb der VPC, sicher mit dem Internet oder anderen VPCs zu kommunizieren.

## Ressourcen-Einstellwerte

-   `included_vpc_name` : Name der VPC, die die Routing-Tabelle enthält
-   `subnet_names` : Beschreibung der Routing-Tabelle
-   `linked_route` : Name des Routing-Pfads
    -   `cidr_block` : CIDR des Zielressourcen für das Routing
    -   `internet_gateway_name` : Name des Internet-Gateways, das für den Routing-Pfad festgelegt wird
    -   `ec2_instance_name` : Name der EC2-Instanz, die für den Routing-Pfad festgelegt wird
    -   `nat_gateway_name` : Name des NAT-Gateways, das für den Routing-Pfad festgelegt wird
    -   `vpc_peering_name` : Name des NAT-Gateways, das für den Routing-Pfad festgelegt wird
