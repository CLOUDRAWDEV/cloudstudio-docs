## Ressourcenübersicht

Die Route Table einer AWS VPC (Virtual Private Cloud) ist eine AWS-Ressource, die definiert, an welches Ziel der Datenverkehr von Subnetzen innerhalb der VPC weitergeleitet wird. Jedes Subnetz in einer VPC ist mit einer oder mehreren Routing-Tabellen verknüpft. Routing-Tabellen enthalten Routing-Regeln für Ziele wie Internet-Gateways, NAT-Gateways, VPC-Endpunkte oder VPN-Verbindungen.  
Der Datenverkehr wird entsprechend der Reihenfolge der Routing-Regeln weitergeleitet, und sämtlicher aus einem Subnetz erzeugter Verkehr wird über die zugeordnete Routing-Tabelle an das Ziel gesendet. Dadurch können Subnetze innerhalb einer VPC sicher mit dem Internet oder anderen VPCs kommunizieren.

## Ressourceneinstellungen

#### Grundeinstellungen

-   `included_vpc_name` : Name der VPC, zu der die Route Table gehört
-   `subnet_names` : Liste der Subnetznamen, die mit der Route Table verknüpft werden

#### Routing-Pfade (`linked_route`)

-   `linked_route.cidr_block` : CIDR-Block der Zielressource für das Routing
-   `linked_route.resource_type` : Typ der Zielressource – `internet_gateway`, `ec2_instance`, `nat_gateway`, `transit_gateway`, `vpc_peering`
-   `linked_route.linked_resource_name` : Name der Zielressource für das Routing

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
