Eine Ressource zur Entscheidung über die Genehmigung der gemeinsamen Nutzung von Ressourcen aus anderen AWS-Konten

## Zugehörige Ressourcen

### Verknüpfte Ressourcen

-   [**TransitGatewayAttachment**](https://docs.cstudio.app/de/docs/resource/aws/Vpc/TransitGatewayAttachment)

## Ressourceneinstellungen

#### Grundeinstellungen

-   `is_manual` : Gibt an, ob die ID des Transit-Gateway-Attachments manuell eingegeben wird – `true`, `false`
-   `transit_gateway_attachment_id` : ID des Transit-Gateway-Attachments, dessen Freigabe erlaubt wird
-   `linked_transit_gateway_attachment_name` : Name des Transit-Gateway-Attachments, dessen Freigabe erlaubt wird

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
