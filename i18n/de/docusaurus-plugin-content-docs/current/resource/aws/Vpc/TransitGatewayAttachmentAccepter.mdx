## Ressourcenübersicht

Ressource, die entscheidet, ob die Freigabe von Ressourcen für andere Konten erlaubt ist

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Verbundene Ressourcen

-   [**TransitGatewayAttachment**](https://docs.cstudio.app/docs/resource/aws/Vpc/TransitGatewayAttachment)

## Ressourcen-Einstellwerte

-   `is_manual` : Ob die Transit Gateway Attachment-ID direkt eingegeben werden soll - `false`,`true`
-   `linked_transit_gateway_attachment_name` : Name des anderen Transit Gateway Attachments, für das die Freigabe erlaubt werden soll
