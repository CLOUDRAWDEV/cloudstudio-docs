Wiederverwendbare Kriterienreihe zur Überprüfung und Verarbeitung von Netzwerkverkehr

## Ressourcen-Einstellwerte

-   `description` : Beschreibung der Netzwerk-Firewall-Regelgruppe
-   `rule_group_type` : Regelgruppentyp - `STATEFUL`,`STATELESS`
-   `generated_rules_type` : Regelgruppenformat - `StandardStatefulRules`,`DomainList`,`SuricataRuleStrings`
-   `rule_evaluation_order` : `STRICT_ORDER`,`DEFAULT_ACTION_ORDER`
-   `capacity` : Erwartete Anzahl der Regeln, die während des Lebenszyklus in diese Regelgruppe aufgenommen werden - `1-30000`
-   `ip_set` : IP-Set-Variable
    -   `name` : Name der IP-Set-Variable
    -   `cidrs` : Wert der IP-Set-Variable
-   `port_set` : Port-Variable 
    -   `name` : Name der Port-Variable
    -   `cidrs` : Wert der Port-Variable
-   `stateful_rule` : Standard-stateful Regel 
    -   `name` : Name der Standard-stateful Regel
    -   `protocol` : Zu überprüfendes Übertragungsprotokoll - `IP`,`TCP`,`UDP`,`ICMP`,`HTTP`
    -   `source_ip_or_cidr` : Zu überprüfende Quell-IP-Adresse und Adressbereich
    -   `source_port` : Zu überprüfender Quellport oder Portbereich
    -   `target_ip_or_cidr` : Zu überprüfende Ziel-IP-Adresse und Adressbereich
    -   `target_ip_or_cidr` : Zu überprüfende Ziel-IP-Adresse und Adressbereich
    -   `traffic_direction` : Zu überprüfende Verkehrsrichtung - `ANY`,`FORWARD`
    -   `action` : Aktion, die die Netzwerk-Firewall ausführt, wenn Pakete mit den Regel-Einstellungen übereinstimmen - `ALERT`,`DROP`,`PASS`,`REJECT`
-   `encryption_configuration.
    -   `enabled_custom_configuration` : Daten mit AWS verwalteten Schlüsseln verschlüsseln - `false`,`true`
