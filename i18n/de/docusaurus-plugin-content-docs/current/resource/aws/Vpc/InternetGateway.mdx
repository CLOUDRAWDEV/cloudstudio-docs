## Ressourcenübersicht

Das Internet-Gateway ist eine horizontal skalierbare und hochverfügbare redundante VPC-Komponente, die die Kommunikation zwischen der VPC und dem Internet ermöglicht. Es unterstützt sowohl IPv4- als auch IPv6-Verkehr und stellt sicher, dass keine Verfügbarkeitsrisiken oder Bandbreitenbeschränkungen für den Netzwerkverkehr bestehen.
Wenn eine Ressource über eine öffentliche IPv4- oder IPv6-Adresse verfügt, ermöglicht das Internet-Gateway den Zugriff auf Ressourcen in einem öffentlichen Subnetz (z. B. EC2-Instanzen) aus dem Internet. Ebenso können Ressourcen im Internet über öffentliche IPv4- oder IPv6-Adressen Verbindungen zu Ressourcen in einem Subnetz initiieren. Ein Beispiel ist die Verbindung von EC2-Instanzen in AWS von einem lokalen Computer aus durch ein Internet-Gateway.
Das Internet-Gateway bietet Ziele für den internetfähigen Verkehr in der VPC-Routing-Tabelle. Bei IPv4-Kommunikation führt das Internet-Gateway auch Network Address Translation (NAT) durch. Bei der Verwendung von IPv6-Kommunikation sind die IPv6-Adressen öffentlich, sodass NAT nicht erforderlich ist.
