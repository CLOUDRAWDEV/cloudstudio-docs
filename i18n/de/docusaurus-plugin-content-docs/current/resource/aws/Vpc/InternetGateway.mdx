## Ressourcenübersicht

Ein Internet-Gateway ist eine horizontal skalierbare, hochverfügbare und redundante VPC-Komponente, die die Kommunikation zwischen einer VPC und dem Internet ermöglicht. Es unterstützt IPv4- und IPv6-Datenverkehr und verursacht keine Verfügbarkeitsrisiken oder Bandbreitenbeschränkungen im Netzwerkverkehr.
Wenn eine Ressource über eine öffentliche IPv4- oder IPv6-Adresse verfügt, ermöglicht ein Internet-Gateway Ressourcen in öffentlichen Subnetzen (z. B. EC2-Instances) den Zugriff auf das Internet. Ebenso können Ressourcen aus dem Internet Verbindungen zu Ressourcen in Subnetzen über öffentliche IPv4- oder IPv6-Adressen initiieren. Beispielsweise kann über ein Internet-Gateway eine Verbindung von einem lokalen Computer zu einer EC2-Instance in AWS hergestellt werden.
Ein Internet-Gateway stellt in VPC-Routing-Tabellen ein Ziel für internetfähigen Datenverkehr bereit. Für IPv4-Kommunikation führt das Internet-Gateway auch Network Address Translation (NAT) durch. Bei IPv6-Kommunikation ist kein NAT erforderlich, da IPv6-Adressen öffentlich sind.
