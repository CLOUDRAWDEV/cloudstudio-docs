## Ressourcenübersicht

Der Transit Gateway ist ein Netzwerk-Transit-Hub, der verwendet werden kann, um virtuelle private Clouds (VPCs) mit On-Premises-Netzwerken zu verbinden. Da die Cloud-Infrastruktur weltweit skaliert, werden Regions-Peerings unter Verwendung der globalen AWS-Infrastruktur miteinander verbunden. Daten werden automatisch verschlüsselt und über das öffentliche Internet nicht übertragen.

## Ressourcen-Einstellwerte

-   `dns_support` : DNS-Auflösung für verbundenes VPC aktivieren - `enable`, `disable`
-   `vpn_ecmp_support` : Unterstützung für ECMP (Equal-Cost Multi-Path) Routing für verbundene VPNs - `enable`, `disable`
-   `default_route_table_association` : Attachment automatisch mit der Standard-Routing-Tabelle verbinden - `enable`, `disable`
-   `default_route_table_propagation` : Attachment automatisch an die Standard-Routing-Tabelle propagieren - `enable`, `disable`
-   `multicast_support` : Multicast-Domänen erstellen aktivieren - `enable`, `disable`
-   `transit_gateway_cidr_blocks` : Transit Gateway CIDR-Block
-   `vpc_attachment`
