## Ressourcenübersicht

Ein Transit Gateway ist ein Netzwerk-Transport-Hub, der zur gegenseitigen Verbindung von Virtual Private Clouds (VPCs) und On-Premises-Netzwerken verwendet wird. Mit der globalen Skalierung der Cloud-Infrastruktur verbindet regionsübergreifendes Peering Transit Gateways über die globale AWS-Infrastruktur. Die Daten werden automatisch verschlüsselt und nicht über das öffentliche Internet übertragen.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `dns_support` : Aktivierung der DNS-Auflösung für verbundene VPCs – `enable`, `disable`
-   `vpn_ecmp_support` : Unterstützung von ECMP-(Multipath)-Routing für verbundene VPNs – `enable`, `disable`
-   `default_route_table_association` : Automatische Zuordnung von Attachments zur Standard-Routing-Tabelle – `enable`, `disable`
-   `default_route_table_propagation` : Automatische Weitergabe von Attachments an die Standard-Routing-Tabelle – `enable`, `disable`
-   `multicast_support` : Aktivierung der Erstellung von Multicast-Domänen – `enable`, `disable`
-   `transit_gateway_cidr_blocks` : Liste der CIDR-Blöcke, die dem Transit Gateway zugewiesen werden

#### Direct-Connect-Gateway-Einstellungen (`dx_gateway`)

-   `dx_gateway.linked_dx_gateway` : Name des zu verbindenden Direct-Connect-Gateways
-   `dx_gateway.allowed_prefixes` : Liste der VPC-Prefixe (CIDR), die an das On-Premises-Netzwerk beworben werden

-   `tag` : Tag zur Kategorisierung der Ressource
