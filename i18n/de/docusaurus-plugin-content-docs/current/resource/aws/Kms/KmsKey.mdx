## Ressourcenübersicht

AWS Key Management Service (AWS KMS) ist ein verschlüsselungs- und schlüsselverwaltungsdienst, der speziell für die Cloud entwickelt wurde. AWS KMS-Schlüssel und Funktionen werden in anderen AWS-Diensten verwendet, und Benutzer können diese AWS KMS-Schlüssel und Funktionen verwenden, um Daten in ihren eigenen Anwendungen, die AWS nutzen, zu schützen.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

## Ressourceneinstellungen

-   `description` : Beschreibung des Schlüssels, der in der AWS-Konsole angezeigt wird
-   `key_usage` : Festlegung der Verwendung des Schlüssels - `ENCRYPT_DECRYPT`
-   `multi_region` : Festlegen, ob der KMS-Schlüssel in mehreren Regionen verwendet werden soll - `true`, `false`
-   `deletion_window_in_days` : Gültigkeitsdauer des KMS-Schlüssels
-   `enable_key_rotation` : Festlegung, ob die Schlüsselrotation aktiviert werden soll - `true`, `false`
-   `grant_list` : Name des KMS Grants
    -   `operations` : Zulässige Aktionen für den KMS-Schlüssel - `Decrypt`, `Encrypt`, `GenerateDataKey`, `GenerateDataKeyWithoutPlaintext`, `ReEncryptFrom`, `ReEncryptTo`, `Sign`, `Verify`, `CreateGrant`, `RetireGrant`, `DescribeKey`
