## Ressourcenkonfiguration

#### Grundeinstellungen

-   `target_bedrock_agent` : Ziel-Bedrock-Agent, mit dem die Aktionsgruppe verbunden wird
-   `enable_action_group_state` : Aktivierung der Statusbeibehaltung der Aktionsgruppe – `ENABLED`, `DISABLED`
-   `custom_control_method` : Steuerungsmethode für das Agentenverhalten – `custom_control`, `lambda_function`
-   `target_lambda_function` : AWS-Lambda-Funktion, die bei der Ausführung einer Aktion aufgerufen wird

#### Funktionsdefinitionen (`functions`)

-   `functions.description` : Beschreibung des Zwecks oder der Funktion, die die Funktion ausführt (maximal 5000 Zeichen)

##### Funktionsparameter (`functions.parameters`)

-   `functions.parameters.type` : Datentyp des Parameters – `string`, `number`, `integer`, `boolean`, `array`
-   `functions.parameters.description` : Bedeutung oder Verwendungszweck des Parameters
-   `functions.parameters.required` : Gibt an, ob eine Eingabe erforderlich ist – `true`, `false`
