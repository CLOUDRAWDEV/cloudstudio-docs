## Ressourcenübersicht

Sicherheitsschlüssel-Satz, der zur Authentifizierung von Anmeldeinformationen bei der Verbindung mit einer AWS EC2-Instanz verwendet wird

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

## Ressourceneinstellungen

-   `public_key` : Öffentlicher Schlüssel des vom Benutzer erstellten Schlüsselpaares
