## Ressourcenübersicht

Ein Satz von Sicherheitsanmeldeinformationen, der zur Authentifizierung beim Zugriff auf AWS-EC2-Instances verwendet wird.

## Zugehörige Ressourcen

### Übergeordnete Ressource

-   [**Region**](https://docs.cstudio.app/de/docs/resource/aws/Base/Region)

## Ressourceneinstellungswerte

#### Grundeinstellungen

-   `public_key` : Öffentlicher Schlüssel des vom Benutzer erstellten Key Pairs

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
