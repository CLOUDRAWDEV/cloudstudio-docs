## Ressourcenübersicht

Logische Netzwerkkonfigurationseinheit, die eine virtuelle Netzwerkkarte in einer VPC darstellt

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Subnet**](https://docs.cstudio.app/docs/resource/aws/Vpc/Subnet)

### Verbundene Ressourcen

-   [**Eip**](https://docs.cstudio.app/docs/resource/aws/Ec2/Eip)

## Ressourceneinstellungen

-   `private_ips` : Liste der privaten IP-Adressen
-   `linked_security_group_names` : Name der Security Group, die für das Netzwerk-Interface verwendet wird
-   `linked_eip_names` : Name der zu verwendenden Elastic IP
