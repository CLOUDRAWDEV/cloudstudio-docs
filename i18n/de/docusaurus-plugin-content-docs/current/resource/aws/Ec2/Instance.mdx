## Ressourcenübersicht

Amazon Elastic Compute Cloud (Amazon EC2) bietet skalierbare Rechenkapazitäten in der Amazon Web Services (AWS) Cloud. Mit Amazon EC2 müssen Sie keine Hardware im Voraus investieren, sodass Sie Anwendungen schneller entwickeln und bereitstellen können. Mit Amazon EC2 können Sie eine beliebige Anzahl virtueller Server erstellen, Sicherheit und Netzwerkkonfiguration einrichten und Speicher verwalten. Mit Amazon EC2 können Sie Anforderungen oder Nutzungsspitzen durch Skalierung nach oben oder unten anpassen, wodurch die Notwendigkeit entfällt, den Verkehr vorherzusagen.

## Ressourceneinstellungen

-   `ami` : Ein Image mit den erforderlichen Informationen zum Ausführen einer Instanz (von AWS bereitgestellt und unterstützt)
-   `instance_type` : Typ der EC2-Instanz
-   `included_subnet_name` : Name des Subnetzes, in dem die EC2-Instanz bereitgestellt wird
-   `security_group_name` : Name der Security Group, die der NIC der EC2-Instanz zugewiesen wird
-   `eip_enable` : Festlegen, ob eine EIP für die EC2-Instanz verwendet werden soll - `true`, `false`
-   `eip_name` : Name der EIP
-   `http_endpoint` : Festlegen, ob der Metadatenservice verwendet werden kann - `enabled`, `disabled`
-   `http_tokens` : Festlegen, ob ein Sitzungstoken für den Metadatenservice erforderlich ist - `required`, `optional`
-   `root_volume_type` : Typ des Root Volumes - `gp2`, `gp3`, `io1`, `io2`, `sc1`, `st1`, `standard`
-   `root_volume_size` : Größe des Root Volumes (GiB)
-   `ebs_block_device`
    -   `volume_size` : Größe des EBS Volumes (GiB)
    -   `volume_type` : Typ des EBS Volumes
