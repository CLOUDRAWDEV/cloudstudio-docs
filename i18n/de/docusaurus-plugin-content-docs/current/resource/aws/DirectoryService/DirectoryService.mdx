## Ressourcenübersicht

AWS Directory Service bietet mehrere Möglichkeiten zur Nutzung von Microsoft Active Directory (AD) mit anderen AWS-Services.  
Verzeichnisse speichern Informationen über Benutzer, Gruppen und Geräte und ermöglichen Administratoren die Verwaltung von Zugriffen auf Informationen und Ressourcen.  
AWS Directory Service stellt verschiedene Verzeichnisoptionen für Kunden bereit, die vorhandene Microsoft-AD- oder LDAP-fähige Anwendungen in der Cloud verwenden möchten, sowie für Entwickler, die Verzeichnisse zur Verwaltung von Benutzern, Gruppen, Geräten und Zugriffsrechten benötigen.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `password` : Passwort des Verzeichnisadministrators oder des Connector-Benutzers
-   `type` : Typ des Verzeichnisses – `SimpleAD`, `MicrosoftAD`
-   `size` : Größe des Verzeichnisses – `Small`, `Large`
-   `edition` : Edition von MicrosoftAD – `Standard`, `Enterprise`
-   `included_vpc_name` : Name des VPCs, in dem sich das Verzeichnis befindet
-   `included_subnet_names` : Namen der Subnetze für die Verzeichnisserver

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
