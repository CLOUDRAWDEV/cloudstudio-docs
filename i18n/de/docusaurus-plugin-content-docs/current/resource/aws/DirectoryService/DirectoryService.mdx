## Ressourcenübersicht

AWS Directory Service bietet mehrere Möglichkeiten, wie andere AWS-Dienste Microsoft Active Directory (AD) nutzen können. Ein Verzeichnis speichert Informationen über Benutzer, Gruppen und Geräte, und Administratoren können diese verwenden, um den Zugriff auf Informationen und Ressourcen zu verwalten. AWS Directory Service bietet eine Vielzahl von Verzeichnisoptionen für Kunden, die Microsoft AD oder LDAP (Lightweight Directory Access Protocol) -kompatible Anwendungen in der Cloud verwenden möchten. Es bietet auch die gleichen Auswahlmöglichkeiten für Entwickler, die ein Verzeichnis benötigen, um Benutzer, Gruppen, Geräte und Zugriffsrechte zu verwalten.

## Ressourceneinstellungen

-   `password` : Passwort des Verzeichnisadministrators oder des Connector-Benutzers
-   `type` : `SimpleAD`,`MicrosoftAD`
-   `size` : Größe des Verzeichnisses - `Small`,`Large`
-   `included_vpc_name` : Name der VPC, in der sich das Verzeichnis befindet
-   `included_subnet_names` : Name des Subnetzes des Verzeichnisservers (Subnets müssen in verschiedenen Availability Zones (AZs) bereitgestellt werden)
