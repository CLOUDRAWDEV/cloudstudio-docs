## Ressourcenübersicht

Die Cloudfront-Cache-Richtlinie ist eine Cache-Richtlinie, die die benutzerdefinierten Cache-Einstellungen von CloudFront festlegt, indem sie mit dem Cache-Verhalten der CloudFront-Verteilung verbunden wird.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Base**](https://docs.cstudio.app/docs/resource/aws/Base)

### Verbundene Ressourcen

-   [**CloudfrontDistribution**](https://docs.cstudio.app/docs/resource/aws/Cloudfront/CloudfrontDistribution)

## Ressourceneinstellungen

-   `min_ttl` :Minimale Zeit (Sekunden), die ein Objekt im CloudFront-Cache verbleiben muss
-   `max_ttl` : Maximale Zeit (Sekunden), die ein Objekt im CloudFront-Cache verbleiben darf
-   `default_ttl` : Standardzeit (Sekunden), die ein Objekt im CloudFront-Cache verbleiben soll
-   `cookie_behavior` : Ob Cookies an den Origin-Server weitergegeben werden sollen - `whitelist`,`all`,`none`,`allExcept`
-   `header_behavior` : Ob das Objekt basierend auf den Werten der angegebenen Header im Cache gespeichert werden soll - `whitelist`,`none`
-   `query_string_behavior` : Ob verschiedene Versionen des Inhalts basierend auf den Werten der Abfragezeichenfolgenparameter im Cache gespeichert werden sollen - `whitelist`,`all`,`none`,`allExcept`
