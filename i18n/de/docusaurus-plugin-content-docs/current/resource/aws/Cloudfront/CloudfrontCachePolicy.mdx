## Ressourcenkonfiguration

#### Grundeinstellungen

-   `min_ttl` : Minimale Zeit (Sekunden), die ein Objekt im Cache verbleibt
-   `default_ttl` : Standardzeit (Sekunden), die ein Objekt im Cache verbleibt
-   `max_ttl` : Maximale Zeit (Sekunden), die ein Objekt im Cache verbleibt

#### Cookie-Einstellungen (`cookie_config`)

-   `cookie_behavior` : Methode zur Cookie-Weitergabe – `whitelist`, `all`, `none`, `allExcept`
-   `cookies_items` : Liste der Cookies, die an den Origin weitergeleitet werden

#### Header-Einstellungen (`header_config`)

-   `header_behavior` : Header-basiertes Caching-Verhalten – `whitelist`, `none`
-   `headers_items` : Liste der Header, die für das Caching verwendet werden

#### Query-String-Einstellungen (`query_string_config`)

-   `query_string_behavior` : Verarbeitung von Query-Strings – `whitelist`, `all`, `none`, `allExcept`
-   `query_strings_items` : Liste der Query-String-Parameter für das Caching
