## Ressourcenübersicht

Der AWS ElastiCache User ist ein IAM-Benutzer, der für die Nutzung von ElastiCache-Clustern erforderlich ist. ElastiCache User verfügen über Berechtigungen zum Erstellen, Ändern und Löschen von ElastiCache-Clustern. Sie werden in AWS IAM erstellt und typischerweise Anwendungen oder Entwicklern zugewiesen, die ElastiCache verwenden. ElastiCache User sind für Sicherheit und Zugriffskontrolle auf ElastiCache-Cluster verantwortlich und tragen so zum Schutz von Anwendungen und Daten bei. Sie können gemeinsam mit anderen Ressourcen innerhalb eines AWS-Kontos genutzt werden.

## Ressourceneinstellungswerte

#### Grundeinstellungen

-   `user_id` : Eindeutige ID des Benutzers
-   `access_string` : Zeichenkette zur Definition der dem Benutzer zugewiesenen Berechtigungen
-   `authentication_type` : Authentifizierungsmethode für den Zugriff auf den Cluster – `iam`, `password`, `no-password-required`
-   `passwords` : Passwörter des Benutzers (maximal 2 konfigurierbar)

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
