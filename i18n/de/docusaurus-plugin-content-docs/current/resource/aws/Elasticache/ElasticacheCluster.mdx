## Ressourcenübersicht

Der AWS ElastiCache Cluster ist ein cloudbasierter In-Memory-Datenspeicher, der eine schnelle und skalierbare Caching-Lösung bereitstellt. ElastiCache Cluster kann mit der Redis- oder Memcached-Engine im Cluster-Modus oder im Einzelknoten-Modus betrieben werden. Er wird zur Verbesserung der Anwendungsleistung eingesetzt, indem Daten schneller abgerufen und verarbeitet werden können. ElastiCache Cluster bietet automatische Backups, Wiederherstellung, Skalierung und Überwachungsfunktionen, sodass Daten zuverlässig gespeichert werden können.

## Ressourceneinstellungswerte

#### Grundeinstellungen

-   `engine` : Typ der Cache-Engine – `redis`, `memcached`
-   `engine_version` : Version der Cache-Engine
-   `port` : Verbindungsport des Cache-Nodes (Redis: 6379, Memcached: 11211)
-   `parameter_group_name` : Name der zu verknüpfenden Parametergruppe
-   `node_type` : Instanztyp des Cache-Nodes
-   `num_cache_nodes` : Anzahl der Cache-Nodes
-   `az_mode` : Konfiguration der Availability Zones – `single-az`, `cross-az`
-   `included_subnet_names` : Liste der Subnet-Namen, die in die Subnet-Gruppe aufgenommen werden
-   `subnet_group_name` : Name der zu verwendenden Subnet-Gruppe
-   `snapshot_retention_limit` : Aufbewahrungsdauer automatischer Snapshots (Tage)

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
