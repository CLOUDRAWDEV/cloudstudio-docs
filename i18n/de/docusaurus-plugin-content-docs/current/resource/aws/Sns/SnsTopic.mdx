## Ressourcenübersicht

Logischer Zugriffspunkt, der die Kommunikationskanalrolle in AWS SNS übernimmt

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Verknüpfte Ressourcen

-   [**Metric**](https://docs.cstudio.app/docs/resource/aws/Cloudwatch/Metric)
-   [**Config**](https://docs.cstudio.app/docs/resource/aws/Config/Config)

## Ressourcenkonfigurationswerte

-   `display_name` : Anzeigename des SNS-Themas
-   `type` : Typ des SNS-Themas - `FIFO`, `Standard`
-   `kms_key_name` : Name des KMS-Schlüssels, der für das SNS-Thema verwendet wird
