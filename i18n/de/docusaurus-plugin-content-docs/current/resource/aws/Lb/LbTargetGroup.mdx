## Ressourcenübersicht

Ein Service, der Anfragen anhand des festgelegten Protokolls und Ports an ein oder mehrere registrierte Ziele wie EC2-Instances weiterleitet.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `target_type` : Typ des LB-Ziels – `instance`, `ip`, `lambda`, `alb`
-   `protocol` : Protokoll für das Routing des Traffics – `HTTP`, `HTTPS`, `TCP`, `TCP_UDP`, `TLS`, `UDP`, `GENEVE`
-   `port` : Empfangsport für Traffic – `1` ~ `65535`
-   `included_vpc_name` : Name des VPCs für die Zielgruppe
-   `linked_instance_names` : Liste der Ziel-Instance-Namen
-   `ips` : Liste der Ziel-IP-Adressen
-   `linked_lambda_name` : Name der Ziel-Lambda-Funktion
-   `linked_application_lb_name` : Name des Ziel-ALB

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource – maximal 512 Zeichen, `key`:`value`
