## Ressourcenübersicht

Mit AWS Service Catalog können IT-Administratoren Portfolios genehmigter Produkte erstellen, verwalten und an Endbenutzer bereitstellen. Endbenutzer erhalten über ein personalisiertes Portal Zugriff auf die benötigten Produkte. Typische Produkte umfassen Server, Datenbanken, Websites oder Anwendungen, die mithilfe von AWS-Ressourcen bereitgestellt werden, beispielsweise Amazon-EC2-Instances oder Amazon-RDS-Datenbanken. Durch die Kontrolle, welche Benutzer auf bestimmte Produkte zugreifen dürfen, können organisatorische Compliance-Standards durchgesetzt, Produktlebenszyklen verwaltet und Benutzern ermöglicht werden, Produkte sicher zu entdecken und zu starten.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `description` : Beschreibung des Portfolios
-   `provider_name` : Name der Person oder Organisation, die das Portfolio besitzt

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
