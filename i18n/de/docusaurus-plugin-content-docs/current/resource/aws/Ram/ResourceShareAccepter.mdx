## Ressourcenübersicht

Eine Ressource zur Entscheidung, ob eine von einem anderen Konto freigegebene Ressource (Resource Share) akzeptiert wird.

## Zugehörige Ressourcen

### Übergeordnete Ressource

-   [**Region**](https://docs.cstudio.app/de/docs/resource/aws/Base/Region)

### Verknüpfte Ressourcen

-   [**ResourceShare**](https://docs.cstudio.app/de/docs/resource/aws/RAM/ResourceShare)

## Ressourceneinstellungswerte

#### Grundeinstellungen

-   `is_manual` : Ob die Resource-Share-ARN manuell eingegeben wird – `true`, `false`
-   `linked_resource_share_name` : Name des zu verbindenden Resource Shares
-   `resource_share_arn` : ARN des freizugebenden Resource Shares

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource – maximal 512 Zeichen, `key`:`value`
