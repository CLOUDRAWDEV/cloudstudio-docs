## Ressourcenkonfiguration

#### Grundeinstellungen

-   `billing_mode` : Abrechnungs- und Kapazitätsmodus für Lese- und Schreibdurchsatz – `PROVISIONED`, `PAY_PER_REQUEST`
-   `read_capacity` : Anzahl der Lese-Kapazitätseinheiten der DynamoDB-Tabelle
-   `write_capacity` : Anzahl der Schreib-Kapazitätseinheiten der DynamoDB-Tabelle
-   `hash_key` : Attribut, das als Hash- (Partitions-)Schlüssel verwendet wird
-   `hash_key_type` : Typ des Hash-Schlüssels – `S`, `N`, `B`
-   `range_key` : Attribut, das als Sortierschlüssel verwendet wird
-   `range_key_type` : Typ des Sortierschlüssels – `S`, `N`, `B`
-   `point_in_time_recovery_enabled` : Aktivierung der Point-in-Time-Wiederherstellung – `true`, `false`

#### Serverseitige Verschlüsselung (`server_side_encryption`)

-   `server_side_encryption.encryption_enabled` : Aktivierung der Verschlüsselung gespeicherter Daten mit einem von AWS verwalteten KMS-CMK – `true`, `false`
-   `server_side_encryption.kms_key_name` : Name des für die AWS-KMS-Verschlüsselung zu verwendenden CMK

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
