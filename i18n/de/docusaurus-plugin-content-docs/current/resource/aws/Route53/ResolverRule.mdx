## Ressourcenübersicht

Eine Regel, die der Resolver verwendet, um Abfragen für einen bestimmten Domainnamen an das Netzwerk weiterzuleiten.

## Zugehörige Ressourcen

### Übergeordnete Ressource

-   [**Region**](https://docs.cstudio.app/de/docs/resource/aws/Base/Region)

### Verknüpfte Ressourcen

-   [**ResolverEndpoint**](https://docs.cstudio.app/de/docs/resource/aws/Route53/ResolverEndpoint)
-   [**Vpc**](https://docs.cstudio.app/de/docs/resource/aws/Vpc/)

## Ressourceneinstellungswerte

#### Grundeinstellungen

-   `rule_type` : Regeltyp – `FORWARD`, `SYSTEM`
-   `domain_name` : Domainname, an den DNS-Abfragen weitergeleitet werden
-   `linked_vpc_names` : Liste der VPC-Namen, die diese Regel verwenden
-   `linked_resolver_endpoint_name` : Name des vom Resolver verwendeten Outbound-Endpunkts
-   `target_ip.ip` : Ziel-IP-Adresse
-   `target_ip.port` : Port der Ziel-IP-Adresse

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
