## Ressourcenkonfiguration

#### Grundeinstellungen

-   `routing_type` : Routing-Typ der Route53-Zone – `PRIVATE`, `PUBLIC`
-   `linked_vpc_names` : Liste der mit der Route53-Zone zu verbindenden VPC-Namen

#### Record (`record`)

-   `record.type` : Typ des Records – `A`, `AAAA`, `CAA`, `CNAME`, `DS`, `MX`, `NAPTR`, `NS`, `PTR`, `SOA`, `SPF`, `SRV`, `TXT`
-   `record.ttl` : TTL des Records
-   `record.records` : Liste der Record-Zeichenfolgen

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
