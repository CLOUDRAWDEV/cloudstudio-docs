## Ressourcenübersicht

Ein Endpunktdienst für DNS-Abfragen, die mit Amazon VPC gesendet und empfangen werden.

## Zugehörige Ressourcen

### Übergeordnete Ressource

-   [**Region**](https://docs.cstudio.app/de/docs/resource/aws/Base/Region)

### Verknüpfte Ressourcen

-   [**Vpc**](https://docs.cstudio.app/de/docs/resource/aws/Vpc/)
-   [**SecurityGroup**](https://docs.cstudio.app/de/docs/resource/aws/Vpc/SecurityGroup)
-   [**ResolverRule**](https://docs.cstudio.app/de/docs/resource/aws/Route53/ResolverRule)

## Ressourceneinstellungswerte

#### Grundeinstellungen

-   `direction` : Richtung der DNS-Abfragen – `INBOUND`, `OUTBOUND`
-   `linked_vpc_name` : Name des mit dem Endpunkt zu verbindenden VPCs
-   `linked_security_group_names` : Liste der auf den Endpunkt anzuwendenden Security Groups
-   `ip_address.subnet_name` : Name des zu verwendenden Subnets
-   `ip_address.ip` : Verfügbare IP-Adresse innerhalb des Subnets

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
