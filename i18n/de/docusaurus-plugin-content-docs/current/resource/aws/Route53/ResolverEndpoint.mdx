## Ressourcenübersicht

Endpoint-Service für DNS-Abfragen, die mit Amazon VPC gesendet und empfangen werden

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Verknüpfte Ressourcen

-   [**Vpc**](https://docs.cstudio.app/docs/resource/aws/Vpc/Vpc)
-   [**SecurityGroup**](https://docs.cstudio.app/docs/resource/aws/Vpc/SecurityGroup)
-   [**ResolverRule**](https://docs.cstudio.app/docs/resource/aws/Route53/ResolverRule)

## Ressourcenkonfigurationswerte

-   `direction` : Richtung der DNS-Abfragen - `INBOUND`, `OUTBOUND`
-   `linked_vpc_name` : Name der VPC zur Verbindung mit dem Endpoint
-   `linked_security_group_names` : Name der Sicherheitsgruppe für den Endpoint
-   `ip_address` : Name für die IP-Adresse
