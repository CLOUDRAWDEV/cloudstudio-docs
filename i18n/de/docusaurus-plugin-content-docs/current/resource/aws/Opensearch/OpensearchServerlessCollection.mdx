## Ressourcenübersicht

Eine serverlose OpenSearch-Indexgruppe, die das Speichern und Durchsuchen von Daten in einer automatisch skalierenden OpenSearch-Cluster-Umgebung ohne Infrastrukturverwaltung ermöglicht.

## Ressourceneinstellungswerte

#### Grundeinstellungen

-   `shared_resource_types` : Liste der zu teilenden Ressourcentypen
-   `transit_gateway_names` : Liste der zu teilenden Transit-Gateway-Namen
-   `resource_arns` : Liste der zu teilenden Ressourcen-ARNs
-   `enabled_allow_external_principals` : Zulassen externer AWS-Konten für die Freigabe – `true`, `false`
-   `principal_arns` : Liste der Sicherheitsprinzipal-ARNs oder AWS-Konto-IDs mit Freigabezugriff

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource – maximal 512 Zeichen, `key`:`value`
