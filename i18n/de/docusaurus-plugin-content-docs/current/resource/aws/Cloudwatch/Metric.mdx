## Ressourcenübersicht

AWS CloudWatch-Metriken sind Name-Wert-Paare, die Messwerte darstellen, die von überwachten Ressourcen gesammelt werden. Zum Beispiel können Metriken wie die CPU-Auslastung, Netzwerk-Eingabe und -Ausgabe von einer EC2-Instanz gesammelt werden. Diese Messwerte werden als CloudWatch-Metriken gespeichert und für Dashboards, Benachrichtigungen und Analysen verwendet. Außerdem können benutzerdefinierte Metriken erstellt werden, um Daten zu überwachen, die von Anwendungen und Diensten gesammelt wurden.Außerdem können benutzerdefinierte Metriken erstellt werden, um Daten zu überwachen, die von Anwendungen und Diensten gesammelt wurden. CloudWatch-Metriken werden in die verschiedenen Dienste von AWS integriert und verwendet.

## Ressourceneinstellungen

-   `comparison_operator` : Arithmetische Operation, die beim Vergleich der angegebenen Metriken und Schwellenwerte verwendet wird
-   `evaluation_periods` : Anzahl der Perioden, in denen die Daten mit dem angegebenen Schwellenwert verglichen werden
-   `metric_name` : Name der Metrik, die mit der Alarmierung verbunden ist
-   `namespace` : Namespace der Metrik, die mit der Alarmierung verbunden ist
-   `period` : Zeitraum (Sekunden), für den die angegebene Statistik angewendet wird
-   `statistic` : Die Statistik, die auf die betreffende Metrik des Alarms angewendet wird
-   `threshold` : Wert, mit dem die angegebene Statistik verglichen wird
-   `alarm_description` : Beschreibung des Alarms
-   `insufficient_data_actions` : Liste der Aktionen, die ausgeführt werden sollen, wenn der Alarm in den Zustand insufficient_data wechselt
