## Ressourcenübersicht

AWS CloudWatch OAM Monitoring Accounts sind ein Service zur Einrichtung eines zentralen Überwachungskontos, um Anwendungen über mehrere Konten hinweg zu überwachen.

## Zugehörige Ressourcen

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/de/docs/resource/aws/Base/Region)

### Verknüpfte Ressourcen

-   [**OamSourceAccount**](https://docs.cstudio.app/de/docs/resource/aws/CloudWatch/OamSourceAccount)

---

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `oam_source_accounts` : Liste der Quellkonten, die Daten mit dem Überwachungskonto teilen (Konten-ID, Organisationspfad oder Organisations-ID)
-   `resource_types` : Typen der von den Quellkonten freigegebenen Daten – `AWS::Logs::LogGroup`, `AWS::CloudWatch::Metric`, `AWS::XRay::Trace`, `AWS::ApplicationInsights::Application`

#### Tag-Einstellungen

-   `tag` : Liste der Tags zur Klassifizierung der Ressource
