## Ressourcenübersicht

AWS CloudWatch OAM Source Accounts konfigurieren Quellkonten, die Daten mit einem zentralen Überwachungskonto teilen.

## Zugehörige Ressourcen

### Übergeordnete Ressourcen

### Verknüpfte Ressourcen

-   [**OamMonitoringAccount**](https://docs.cstudio.app/de/docs/resource/aws/CloudWatch/OamMonitoringAccount)

---

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `is_manual` : Gibt an, ob die ARN des OAM-Source-Accounts manuell angegeben wird – `true`, `false`
-   `linked_oam_monitoring_account_name` : Name des zu verknüpfenden OAM-Monitoring-Accounts
-   `oam_monitoring_account_arn` : ARN des Monitoring-Accounts, mit dem Daten geteilt werden
-   `resource_types` : Datentypen, die mit dem Monitoring-Account geteilt werden – `AWS::Logs::LogGroup`, `AWS::CloudWatch::Metric`, `AWS::XRay::Trace`, `AWS::ApplicationInsights::Application`
-   `label_template` : Vorlage zur Identifikation des Quellkontos – `$AccountName`, `$AccountEmail`, `$AccountEmailNoDomain`

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
