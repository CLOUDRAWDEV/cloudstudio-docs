## Ressourcenübersicht

AWS CloudWatch OAM Source Accounts konfiguriert Quellkonten, die mit dem zentralen Überwachungskonto geteilt werden sollen.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Verbundene Ressourcen

-   [**Oam Monitoring Account**](https://docs.cstudio.app/docs/resource/aws/Cloudwatch/OamMonitoringAccount)

## Ressourceneinstellungen

-   `is_manual` : Ob die ARN des OAM-Source-Account manuell eingegeben werden soll - `false`,`true`
-   `linked_oam_monitoring_account_name` : Name des OAM Monitoring-Account, mit dem verbunden werden soll
-   `resource_types` : Datentypen, die mit dem Überwachungskonto geteilt werden sollen
    -   `AWS::Logs::LogGroup`
    -   `AWS::Cloudwatch::LogGroup`
    -   `AWS::Logs::LogGroup`
    -   `AWS::Logs::LogGroup`
    -   `AWS::Logs::LogGroup`
-   `label_template` : Etiketten zur Identifizierung des Quellkontos
