## Ressourcenübersicht

Mit AWS Direct Connect können Sie Ihr internes Netzwerk über ein Standard-Ethernet-Glasfaserkabel mit einer AWS Direct Connect-Standort verbinden. Ein Ende des Kabels wird mit Ihrem Router verbunden, das andere Ende wird mit dem AWS Direct Connect-Router verbunden. Über diese Verbindung können Sie Folgendes erstellen. Virtuelle Schnittstellen, die den Internetdienstanbieter im AWS-Netzwerk umgehen und Daten an Dienste wie Amazon S3 oder Amazon VPC übertragen. Der AWS Direct Connect-Standort bietet Zugriff auf die öffentlichen AWS-Regionen über eine einzelne Verbindung in der Region, in der der Service ursprünglich angefordert wurde, oder auf den Zugriff auf AWS GovCloud (US) und andere öffentliche AWS-Regionen.

## Ressourceneinstellungen

-   `bandwidth` : Direct Connection의 Bandwidth - `50Mbps`,`100Mbps`,`200Mbps`,`300Mbps`,`400Mbps`,`500Mbps`,`1Gbps`,`2Gbps`,`5Gbps`,`10Gbps`,`100Gbps`
-   `location` : AWS Direct Connect-Standort, an dem die Verbindung besteht
