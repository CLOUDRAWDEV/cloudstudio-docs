## Ressourcenkonfiguration

#### Grundeinstellungen

-   `cluster_type` : Typ des Clusters – `provisioned`, `serverless`
-   `kafka_version` : Apache-Kafka-Version für den MSK-Cluster
-   `kms_key_name` : Name des für die Datenverschlüsselung verwendeten KMS-Schlüssels
-   `unauthenticated_access` : Zulassen nicht authentifizierter Zugriffe – `true`, `false`
-   `iam_role_based_authentication` : Aktivierung der IAM-rollenbasierten Authentifizierung – `true`, `false`
-   `scram_authentication` : Aktivierung der SCRAM-basierten Authentifizierung – `true`, `false`
-   `cloudwatch_metrics` : Umfang der CloudWatch-Metrikerfassung – `DEFAULT`, `PER_BROKER`, `PER_TOPIC_PER_BROKER`, `PER_TOPIC_PER_PARTITION`

#### Broker-Einstellungen (`broker`)

-   `broker.instance_type` : Instanztyp des Brokers
-   `broker.broker_count_per_zone` : Anzahl der Broker pro Availability Zone (AZ)

#### Speicher-Einstellungen (`storage`)

-   `storage.ebs_volume_size` : Größe des dem Broker zugewiesenen EBS-Volumes (GB) – `1` ~ `16384`
-   `storage.enable_provisioned_throughput` : Aktivierung des provisionierten Durchsatzes – `true`, `false`
-   `storage.provisioned_throughput_per_broker` : Provisionierter Durchsatz pro Broker (MiB/s) – mindestens `250`

#### Netzwerkeinstellungen (`network`)

-   `network.linked_vpc_name` : Name des VPCs, mit dem der Cluster verbunden wird
-   `network.subnet_names` : Liste der Subnet-Namen für den MSK-Cluster
-   `network.security_group_names` : Liste der für den MSK-Cluster verwendeten Security Groups

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource – maximal 512 Zeichen, `key`:`value`
