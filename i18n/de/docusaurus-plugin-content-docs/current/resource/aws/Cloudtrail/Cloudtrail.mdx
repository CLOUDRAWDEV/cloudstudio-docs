## Ressourcenübersicht

Mit AWS CloudTrail können Sie den Status Ihrer AWS-Bereitstellung in der Cloud überwachen, indem Sie eine Aufzeichnung der API-Aufrufe für Ihr Konto abrufen, einschließlich der API-Aufrufe, die über die AWS Management Console, AWS SDKs, Befehlszeilenwerkzeuge und andere AWS-Dienste durchgeführt wurden. Sie können auch sehen, welcher Benutzer und welches Konto die AWS-APIs für CloudTrail-unterstützte Dienste aufgerufen hat, von welcher Quell-IP-Adresse der Aufruf kam und wann der Aufruf stattgefunden hat. Mit der API können Sie CloudTrail in Ihre Anwendung integrieren, die Erstellung von Protokollen für Ihre Organisation automatisieren, den Status der Protokollierung überwachen und steuern, wie Administratoren das CloudTrail-Logging aktivieren und deaktivieren.

## Ressourceneinstellungen

-   `linked_s3_bucket_name` : Name des S3-Buckets, der für die publish der Logdateien festgelegt wurde
-   `s3_key_prefix` : S3-Schlüssel-Präfix, das nach dem angegebenen Bucket-Namen für die Logdateien verwendet wird
-   `multi_region_enabled` : Aktivierung der Multi-Region-Protokollierung
-   `global_service_events` : Ob CloudTrail Ereignisse von globalen Diensten wie IAM in den Logdateien veröffentlicht - `true`, `false`
