## Ressourcenübersicht

Erstellen eines Dateisystems, Anhängen des Dateisystems an eine EC2-Instanz und Lesen von Daten auf der EC2-Instanz sowie Schreiben in das Dateisystem oder das Teilen von Dateien.

## Ressourceneinstellungen

-   `create_token` : Eindeutiger Name, der als Referenz verwendet wird, wenn ein Elastic File System erstellt wird, um die Erstellung des Dateisystems sicherzustellen
-   `availability_zone_name` : AWS Availability Zone, in der das Dateisystem erstellt werden soll
-   `enabled_encrypted` : Ob das Dateisystem verschlüsselt werden soll - `false`,`true`
-   `throughput_mode` : Durchsatzmodus des Dateisystems - `provisioned`,`elastic`, `bursting`
-   `provisioned_throughput_in_mibps` : Provisionierter Durchsatz für das Dateisystem (in MiB/s) - `1-3414`
-   `performance_mode` : Leistungsmodus des Dateisystems - `generalPurpose`, `maxIO`
-   `lifecycle_policy` : Lebenszyklusverwaltung zur automatischen Kostensenkung basierend auf Änderungen des Zugriffsmodells
    -   `transition_to_ia` : Zeit, die benötigt wird, um eine Datei in die IA-Speicherklasse zu verschieben - `1`,`7`,`14`,`30`,`60`
    -   `ransition_to_primary_storage_class` : Richtlinie, die verwendet wird, um eine Datei von einem Access-Storage in den Standard-Storage zu verschieben - `None`,`FirstAccess`
-   `mount_target_subnets` : Liste der Subnetze, zu denen ein Mount-Target hinzugefügt werden soll
-   `file_system_policy` : JSON-Format der Dateisystemrichtlinie für das EFS-Dateisystem
-   `enable_backup_policy` : Ob die Backup-Richtlinie aktiviert ist - `false`,`true`
-   `enable_replica` : Ob eine Replikation erstellt werden soll - `false`,`true`
-   `access_point` : Anwendungsspezifischer Einstiegspunkt des EFS-Dateisystems, um den Zugriff auf geteilte Datensätze leichter zu verwalten
    -   `root_directory_path` : Pfad des EFS-Dateisystems, der dem NFS-Client beim Zugriff auf das Dateisystem über einen Access Point als Root-Verzeichnis angezeigt wird
    -   `posix_user_uid` : POSIX-Benutzer-ID, die für alle Dateisystemoperationen, die diesen Access Point verwenden, verwendet wird - `bis 4294967295`
    -   `posix_user_gid` : POSIX-Gruppen-ID, die für alle Dateisystemoperationen, die diesen Access Point verwenden, verwendet wird - `bis 4294967295`
    -   `posix_user_secondary_gids` : Sekundäre POSIX-Gruppen-ID, die für alle Dateisystemoperationen, die diesen Access Point verwenden, verwendet wird
    -   `root_owner_uid` : POSIX-Benutzer-ID, die auf das Root-Verzeichnis angewendet wird - `bis 4294967295`
    -   `root_owner_gid` : POSIX-Gruppen-ID, die auf das Root-Verzeichnis angewendet wird - `bis 4294967295`
    -   `root_permissions` : POSIX-Berechtigungen im oktalen Format, die auf das Root-Verzeichnis angewendet werden können, um die Modusbits einer Datei darzustellen
