## Ressourcenübersicht

Amazon Elastic Kubernetes Service (Amazon EKS) ist ein verwalteter Service, mit dem Kubernetes-Cluster auf AWS einfach ausgeführt werden können, ohne diese selbst installieren oder betreiben zu müssen.

## Ressourceneinstellungswerte

#### Grundeinstellungen

-   `version` : Kubernetes-Version des EKS-Clusters
-   `cluster_role_arn` : IAM-Rolle, die von der Kubernetes-Control-Plane zur Verwaltung von AWS-Ressourcen verwendet wird
-   `enabled_encryption` : Aktivierung der Cluster-Verschlüsselung – `true`, `false`
-   `kms_key_name` : Name des im Cluster verwendeten KMS-Schlüssels
-   `included_subnet_names` : Liste der Subnet-Namen, die zur Subnet-Gruppe des EKS-Clusters gehören
-   `linked_security_group_names` : Liste der mit dem EKS-Cluster verknüpften Security Groups
-   `endpoint_access_type` : Zugriffstyp auf den EKS-API-Server – `Public`, `Public and Private`, `Private`
-   `public_access_cidrs` : Liste der CIDR-Blöcke, die Zugriff auf den öffentlichen EKS-API-Server erhalten

#### Control-Plane-Logging

-   `enabled_cluster_log_types` : Aktivierte Control-Plane-Logtypen – `api`, `authenticator`, `audit`, `scheduler`, `controllerManager`

#### Add-ons (`add_ons`)

-   `add_ons.kube_proxy_version` : Version von kube-proxy, die auf jedem Node ausgeführt wird
-   `add_ons.vpc_cni_version` : Version des Amazon-VPC-CNI-Plug-ins
-   `add_ons.core_dns_version` : Vom Cluster bereitgestellte CoreDNS-Version

#### Node-Gruppe (`node_group`)

-   `node_group.node_role_name` : IAM-Rolle für Worker-Nodes
-   `node_group.enabled_launch_template` : Aktivierung der Launch-Vorlage – `true`, `false`
-   `node_group.launch_template_name` : Name der für die Node-Gruppe verwendeten Launch-Vorlage
-   `node_group.launch_template_version` : Version der Launch-Vorlage
-   `node_group.min_node_count` : Mindestanzahl der Worker-Nodes
-   `node_group.max_node_count` : Maximale Anzahl der Worker-Nodes
-   `node_group.desired_node_count` : Gewünschte Anzahl der Worker-Nodes
-   `node_group.max_node_unavailable` : Maximal zulässige Anzahl nicht verfügbarer Worker-Nodes während eines Updates
-   `node_group.max_percentage_unavailable` : Maximal zulässiger Prozentsatz nicht verfügbarer Worker-Nodes während eines Updates
-   `node_group.disk_size` : Größe des an jeden Node angehängten EBS-Volumes (GB) – `1` ~ `16384`

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
