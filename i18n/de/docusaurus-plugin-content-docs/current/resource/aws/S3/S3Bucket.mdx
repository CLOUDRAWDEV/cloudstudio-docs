## Ressourcenübersicht

Amazon Simple Storage Service (Amazon S3) ist ein Objektspeicher-Service, der branchenführende Skalierbarkeit, Datenverfügbarkeit, Sicherheit und Leistung bietet. Kunden aller Größenordnungen und Branchen können Amazon S3 verwenden, um beliebige Mengen an Daten in verschiedenen Anwendungsfällen wie Data Lakes, Websites, mobilen Anwendungen, Backup und Wiederherstellung, Archivierung, Unternehmensanwendungen, IoT-Geräten und Big-Data-Analysen zu speichern und zu schützen. Amazon S3 bietet Verwaltungsfunktionen, mit denen der Zugriff auf Daten optimiert, strukturiert und konfiguriert werden kann, um spezifische Geschäfts-, Organisations- und Compliance-Anforderungen zu erfüllen.

## Ressourcenkonfigurationswerte

-   `versioning_status` : Versionierungsstatus des Buckets - `Enabled`, `Suspended`
-   `logging_target_prefix` : Präfix für alle Log-Objekt-Schlüssel
-   `sse_algorithm` : Verwendeter Server-seitiger Verschlüsselungsalgorithmus - `aws:kms`, `AES256
-   `kms_key_name` : Name des AWS KMS Master-Schlüssels, der für SSE-KMS-Verschlüsselung verwendet wird
-   `public_access_block` : Name des S3 Public Access Block

    -   `block_public_acls` : Ob Amazon S3 den öffentlichen ACL für den Bucket blockieren soll - `true`, `false`
    -   `block_public_policy` : Ob Amazon S3 die öffentliche Bucket-Policy für diesen Bucket blockieren soll - `true`, `false`
    -   `ignore_public_acls` : Ob Amazon S3 den öffentlichen ACL für diesen Bucket ignorieren soll - `true`, `false`
    -   `restrict_public_buckets` : Ob Amazon S3 die öffentliche Bucket-Policy für diesen Bucket einschränken soll - `true`, `false`

-   `ownership_control`
    -   `acl_enabled` : Aktivierung der Nutzung von Objektbesitz und ACL für in den S3-Bucket hochgeladene Objekte - `true`, `false`
    -   `object_ownership` : Art des Besitzes von Objekten, die in den S3-Bucket hochgeladen werden - `BucketOwnerEnforced`, `BucketOwnerPreferred`, `ObjectWriter`
