## Ressourceneinstellungswerte

#### Grundeinstellungen

-   `gzip` : Gibt an, ob ein Datenkomprimierungsalgorithmus verwendet wird – `true`, `false`

#### Teileinstellungen (`part`)

-   `part.content_type` : Typ der einzubettenden Daten – `text/cloud-config`, `text/x-shellscript`, `text/cloud-boothook`, `multipart/mixed`, `text/cloud-config-archive`, `text/jinja`, `text/x-include-url`, `text/part-handler`
-   `part.content` : Tatsächlicher Inhalt der einzubettenden Daten

#### Tags

-   `tag` : Tag zur Kategorisierung der Ressource
