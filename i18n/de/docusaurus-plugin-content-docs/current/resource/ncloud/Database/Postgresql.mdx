## Ressourcenübersicht

PostgreSQL ist ein **Open-Source-relationales Datenbankmanagementsystem (RDBMS)**.  
Bei Ncloud wird es als vollständig verwalteter Datenbankservice mit Hochverfügbarkeit (HA), automatisierter Sicherung und verschlüsseltem Storage angeboten.  
So lässt sich eine PostgreSQL-Umgebung ohne komplexe Infrastrukturkonfiguration einfach bereitstellen.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `server_name_prefix` : Name des PostgreSQL-Servers (Kleinbuchstaben/Zahlen/Bindestrich erlaubt, Beginn mit Kleinbuchstabe, Ende mit Kleinbuchstabe oder Zahl, 3–30 Zeichen)
-   `included_vpc_name` : Name des VPC, in dem PostgreSQL enthalten ist
-   `included_subnet_name` : Name des Subnetzes, in dem PostgreSQL enthalten ist
-   `enable_high_availability` : Aktivierung der Hochverfügbarkeitsfunktion – `true`, `false`
-   `user_name` : PostgreSQL-Benutzer-ID
-   `user_password` : Passwort des PostgreSQL-Benutzers
-   `image_product_code` : Image-Produktcode des PostgreSQL-Servers
-   `product_code` : Produktcode der PostgreSQL-Instanz
-   `data_storage_type` : Datenspeichertyp – `SSD`, `HDD`
-   `is_backup` : Verwendung von Backups – `true`, `false`
-   `backup_file_retention_period` : Aufbewahrungsdauer der Backup-Dateien (Tage) – `1` ~ `30`
-   `enable_automatic_backup` : Aktivierung automatischer Backups – `true`, `false`
-   `backup_time` : Benutzerdefinierte Backup-Zeit
-   `port` : Portnummer für den PostgreSQL-Zugriff
-   `client_cidr` : IP-Adressbereich für Client-Zugriffe
-   `database_name` : Name der Standarddatenbank
-   `enable_storage_encryption` : Aktivierung der Storage-Verschlüsselung – `true`, `false`
