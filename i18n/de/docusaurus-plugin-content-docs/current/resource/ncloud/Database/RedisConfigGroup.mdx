## Ressourcenübersicht

In der Redis Config Group können die erstellten Redis-Server gruppiert werden, sodass denselben Servern innerhalb der Gruppe gleiche Konfigurationseinstellungen zugewiesen werden, um eine effiziente Verwaltung zu ermöglichen.
