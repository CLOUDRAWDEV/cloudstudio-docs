## Ressourcenübersicht

Mit Redis Config Group können erstellte Redis-Server gruppiert und effizient verwaltet werden, indem einheitliche Konfigurationen auf alle Server innerhalb einer Gruppe angewendet werden.

## Zugehörige Ressourcen

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/de/docs/resource/ncloud/Base/Region)

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `redis_version` : Version und Modus der Redis-Config-Group – `5.0.14-cluster`, `5.0.14-simple`, `7.0.13-cluster`, `7.0.13-simple`, `7.0.15-cluster`, `7.0.15-simple`, `7.2.6-cluster`, `7.2.6-simple`, `7.2.8-cluster`, `7.2.8-simple`
-   `description` : Beschreibung der Redis-Config-Group
