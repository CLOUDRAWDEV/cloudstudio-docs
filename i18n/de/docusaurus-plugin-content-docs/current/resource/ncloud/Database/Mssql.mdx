## 리소스 개요

Cloud DB for MSSQL allows you to easily build and automatically manage MSSQL databases. It is a fully managed cloud database service that operates stably through Naver’s optimized settings and automatically recovers in case of failures.

## 연관 리소스

### 상위 리소스

-   [**Subnet**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Subnet)

## 리소스 설정 값

#### 기본 설정

-   `included_subnet_name` : Name of the subnet that includes MSSQL
-   `enable_high_availability` : Whether to enable high availability - `true`, `false`
-   `user_name` : MSSQL user access ID
-   `user_password` : MSSQL user access password
-   `image_product_code` : Image product code for the MSSQL instance server to be created - `imageProductCode`
-   `product_code` : Product code for the MSSQL instance server to be created - `productCode`
-   `data_storage_type` : Data storage type - `SSD`, `HDD`
-   `backup_file_retention_period` : Backup file retention period (daily) - `1` ~ `30`
-   `enable_automatic_backup` : Whether to enable automatic backup - `true`, `false`
-   `backup_time` : User-defined specific backup time
-   `port` : TCP port number for MSSQL access (default: `1433`)
-   `character_set_name` : DB character set - `characterSetName`
