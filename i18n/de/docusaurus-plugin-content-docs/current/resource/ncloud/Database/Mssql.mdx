## Ressourcenübersicht

Cloud DB for MSSQL ermöglicht eine einfache Einrichtung und automatische Verwaltung von MSSQL-Datenbanken. Durch die optimierten Einstellungen von Naver wird ein stabiler Betrieb gewährleistet, und im Falle einer Störung erfolgt eine automatische Wiederherstellung. Es handelt sich um einen vollständig verwalteten Cloud-Datenbankdienst.

## Referenzmaterial

-   `enable_high_availability` : Ob die Hochverfügbarkeitsfunktion verwendet werden soll
-   `user_name` : Benutzerzugriffs-ID für MSSQL
-   `user_password` : Benutzerzugriffs-Passwort für MSSQL
-   `image_product_code` : Produktnummer des Server-Image-Spezifikations für die zu erstellende MSSQL-Instanz
-   `product_code` : Produktnummer der Spezifikationen für das zu erstellende MSSQL-Instanz-Server-Image
-   `data_storage_type` : Art des Datenspeichers  - `SSD`, `HDD`
-   `backup_file_retention_period` : Aufbewahrungszeitraum der Backup-Dateien (tägliche Backups, 1-30 Tage)
-   `enable_automatic_backup` : Ob die Backup-Automatisierung aktiviert wird
-   `port` : MySQL-Zugangsport - `3306~20000`
-   `character_set_name` : Der DB-Zeichensatz kann aus einer Kombination von Koreanisch und Englisch ausgewählt werden
