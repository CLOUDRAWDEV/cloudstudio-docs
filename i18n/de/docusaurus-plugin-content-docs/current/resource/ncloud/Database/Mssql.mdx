## Ressourcenübersicht

Cloud DB for MSSQL ist ein vollständig verwalteter Cloud-Datenbankservice für MSSQL, der einen stabilen Betrieb mit automatischer Wiederherstellung bei Ausfällen ermöglicht.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `included_subnet_name` : Subnetzname
-   `enable_high_availability` : Aktivierung der Hochverfügbarkeit – `true`, `false`
-   `user_name` : MSSQL-Benutzer-ID
-   `user_password` : MSSQL-Benutzerpasswort
-   `image_product_code` : Image-Produktcode – `imageProductCode`
-   `product_code` : Produktcode – `productCode`
-   `data_storage_type` : Storage-Typ – `SSD`, `HDD`
-   `backup_file_retention_period` : Backup-Aufbewahrung (Tage) – `1` ~ `30`
-   `enable_automatic_backup` : Automatische Backups – `true`, `false`
-   `backup_time` : Benutzerdefinierte Backup-Zeit
-   `port` : TCP-Port (Standard: `1433`)
-   `character_set_name` : Zeichensatz – `characterSetName`
