## Ressourcenübersicht

MySQL ist ein vollständig verwalteter Cloud-Datenbankdienst, der auf der relationalen Datenbank MySQL basiert. Er ermöglicht eine einfache Einrichtung, eine stabile Betriebsführung und eine automatische Wiederherstellung im Falle von Störungen.

## Ressourcen-Einstellwerte

-   `server_name_prefix` : Name des MySQL-Servers
-   `user_name` : Benutzerzugriffs-ID für MySQL
-   `user_password` : Benutzerpasswort für MySQL
-   `host_ip` : IP-Adresse des Clients, der auf den Server zugreifen möchte
-   `database_name` : Name der zu erstellenden Datenbank
-   `image_product_code` : Produktcode des MySQL-Server-Images für die Konfiguration des MySQL-Instanz-Specs
-   `product_code` : Produktcode zur Bestimmung der Server-Spezifikationen für die zu erstellende MySQL-Instanz
-   `data_storage_type` : Art des Datenspeichers - `SSD`, `HDD`
-   `enable_high_availability` : Ob die Hochverfügbarkeitsfunktion verwendet wird
-   `enable_backup` : Ob die Backup-Funktion aktiviert ist
-   `backup_file_retention_period` : Die Aufbewahrungsdauer der Backup-Dateien wird festgelegt. Backups werden täglich durchgeführt, und die Backup-Dateien werden in einem separaten Speicher abgelegt - `1~30`
-   `enable_automatic_backup` : Ob die Backup-Automatisierung aktiviert wird
-   `port` : MySQL-Zugangsport - `3306~20000`
