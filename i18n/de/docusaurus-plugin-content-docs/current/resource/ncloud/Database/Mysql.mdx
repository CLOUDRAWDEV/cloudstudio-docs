## Ressourcenübersicht

MySQL ist ein vollständig verwalteter Cloud-Datenbankservice auf Basis von MySQL, der eine einfache Bereitstellung, stabilen Betrieb und automatische Wiederherstellung bei Ausfällen bietet.

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `server_name_prefix` : MySQL-Servername (3–30 Zeichen, Kleinbuchstaben/Zahlen/Bindestrich)
-   `users` : Benutzerkonfiguration (`password`, `host_ip`, `authority`)
-   `databases` : Liste der zu erstellenden Datenbanken
-   `included_subnet_names` : Subnetzliste
-   `image_product_code` : Image-Produktcode
-   `product_code` : Produktcode der Instanz
-   `data_storage_type` : Storage-Typ – `SSD`, `HDD`
-   `enable_high_availability` : Hochverfügbarkeit – `true`, `false`
-   `enable_storage_encryption` : Storage-Verschlüsselung – `true`, `false`
-   `enable_backup` : Backup-Funktion – `true`, `false`
-   `backup_file_retention_period` : Backup-Aufbewahrung (Tage) – `1` ~ `30`
-   `enable_automatic_backup` : Automatische Backups – `true`, `false`
-   `backup_time` : Benutzerdefinierte Backup-Zeit
-   `port` : MySQL-Port – `3306` ~ `20000`
