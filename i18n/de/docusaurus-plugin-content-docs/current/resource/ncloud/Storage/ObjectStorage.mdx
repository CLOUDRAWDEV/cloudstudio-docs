## Ressourcenübersicht

Object Storage ist ein objektbasierter Speicherdienst, mit dem alle Arten von Daten über das Internet gespeichert und abgerufen werden können.  
Über Zugriffsrichtlinien (Rules) lassen sich Berechtigungen für Buckets und Objekte konfigurieren.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `rule` : Zugriffspolicy für Object Storage – `private`, `public-read`, `public-read-write`, `authenticated-read`
