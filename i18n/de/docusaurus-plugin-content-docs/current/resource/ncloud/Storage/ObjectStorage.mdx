## 리소스 개요

Object Storage is an object storage service that allows you to store and retrieve all types of data over the internet.  
Access permissions for buckets and objects can be configured through access policies (rules).

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

## 리소스 설정 값

#### 기본 설정

-   `rule` : Object Storage access policy setting - `private`, `public-read`, `public-read-write`, `authenticated-read`
