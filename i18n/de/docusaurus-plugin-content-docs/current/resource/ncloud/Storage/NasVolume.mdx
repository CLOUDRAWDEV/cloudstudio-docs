## Ressourcenübersicht

Ein netzwerkbasierter Speicherdienst, der mehreren Benutzern und Servern das gemeinsame Nutzen von Daten ermöglicht.  
Geeignet für Szenarien, in denen mehrere Nutzer gleichzeitig auf denselben Speicher zugreifen müssen.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `volume_name_postfix` : Suffix des NAS-Volume-Namens (alphanumerisch, 3–20 Zeichen)
-   `volume_size` : Volume-Größe (in 100-GB-Einheiten) – `500` ~ `10000`
-   `volume_allotment_protocol_type` : Protokolltyp – `NFS`, `CIFS`
-   `cifs_user_name` : Benutzer-ID für CIFS-Authentifizierung
-   `cifs_user_password` : Passwort für CIFS-Authentifizierung
-   `linked_instances` : Liste der Serverinstanzen, die mit dem NAS-Volume verbunden werden
-   `is_encrypted` : Aktivierung der volumenbasierten AES-256-Verschlüsselung
