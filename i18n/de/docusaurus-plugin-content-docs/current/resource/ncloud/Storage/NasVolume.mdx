## 리소스 개요

A storage service that connects multiple servers over a network so that multiple users can share data. As a network-connected storage space, it is suitable for data sharing among multiple users.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### 연결 대상

-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## 리소스 설정 값

#### 기본 설정

-   `volume_name_postfix` : NAS volume name postfix (alphanumeric, 3 ~ 20 characters)
-   `volume_size` : Volume size (in units of 100 GB) - `500` ~ `10000`
-   `volume_allotment_protocol_type` : Protocol type - `NFS`, `CIFS`
-   `cifs_user_name` : User ID for CIFS authentication
-   `cifs_user_password` : Password for CIFS authentication
-   `linked_instances` : List of server instance names to connect to the NAS volume
-   `is_encrypted` : Whether volume-level encryption based on AES-256 is enabled
