## 리소스 개요

An additional HDD or SSD storage service provided on top of a server’s base storage. It can be created quickly and immediately attached to a server, and can be returned right away when no longer needed.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### 연결 대상

-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## 리소스 설정 값

#### 기본 설정

-   `zone` : Physical zone where the Block Storage will be located - `KR-1`, `KR-2`
-   `linked_server_name` : Name of the server to which the block storage will be attached
-   `storage_size` : Block storage size (GB) - `10` ~ `16380`
-   `storage_disk_type` : Block storage disk type - `SSD`, `HDD`
