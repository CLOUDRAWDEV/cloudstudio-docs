## Ressourcenübersicht

Ein zusätzlicher HDD- oder SSD-Speicherdienst, der über den Basis-Speicher eines Servers hinaus bereitgestellt wird.  
Er kann kurzfristig erstellt und sofort mit einem Server verbunden sowie bei Nichtbedarf umgehend freigegeben werden.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `zone` : Physische Zone des Block Storage – `KR-1`, `KR-2`
-   `linked_server_name` : Name des Servers, mit dem der Block Storage verbunden wird
-   `storage_size` : Größe des Block Storage (GB) – `10` ~ `16380`
-   `storage_disk_type` : Typ des Block Storage – `SSD`, `HDD`
