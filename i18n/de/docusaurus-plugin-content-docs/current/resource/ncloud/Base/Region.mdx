## Ressourcenübersicht

Dies ist eine Ressource, die die Region für die Bereitstellung von Naver Cloud-Ressourcen angibt. Es werden Korea (KR), Japan (JPN) und Singapur (SGN) unterstützt.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Base**](https://docs.cstudio.app/docs/resource/ncloud/Base/)

### Untergeordnete Ressourcen

-   [**Network Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Network/Vpc)
-   [**Network Vpc Peering**](https://docs.cstudio.app/docs/resource/ncloud/Network/VpcPeering)

## Ressourcen-Einstellwerte

-   `region` : Bereitstellungsregion
