## Ressourcenübersicht

Dies ist ein Service, der die Netzwerksicherheit für Subnetze verwalten kann.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

## Ressourcen-Einstellwerte

-   `included_vpc_name` : VPC-Name für die Erstellung der ACL
-   `nacl_description` : Beschreibung der ACL
-   `inbound_rule`
    -   `priority` : Priorität der eingehenden Regel, 0 ~ 199
    -   `protocol` : Protokoll des eingehenden Datenverkehrs - `TCP`, `UDP`, `ICMP`
    -   `rule_action` : Aktion der eingehenden Regel für den Datenverkehr - `ALLOW`, `DROP`
    -   `ip_block` : Quell-IP-Bereich des eingehenden Datenverkehrs im CIDR-Format
    -   `port_range` : Portbereich, auf den die eingehende Regel angewendet wird, im Bereich von 1 bis 65535
-   `outbound_rule` :
    -   `priority` : Priorität der ausgehenden Regel, 0 ~ 199
    -   `protocol` : Protokoll des ausgehenden Datenverkehrs - `TCP`, `UDP`, `ICMP`
    -   `rule_action` : Aktion der ausgehenden Regel für den Datenverkehr - `ALLOW`, `DROP`
    -   `ip_block` : Ziel-IP-Bereich des ausgehenden Datenverkehrs im CIDR-Format
    -   `port_range` : Portbereich, auf den die ausgehende Regel angewendet wird, im Bereich von 1 bis 65535 (wenn ein Bereich festgelegt wird: 100-200)
