## Ressourcenübersicht

Init Script ist eine Funktion, mit der vordefinierte Skripte beim Erstellen von Servern automatisch ausgeführt werden können. Sie eignet sich für die Massenbereitstellung identischer Server, die regelmäßige Erstellung gleichartiger Umgebungen oder die initiale Konfigurationsverwaltung je nach Einsatzzweck.

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `os_type` : Typ der zu verwendenden Serverinstanz – `LNX`, `WND`
-   `content` : Skriptinhalt, der beim Erstellen des Servers automatisch ausgeführt wird
-   `description` : Beschreibung des Init-Skripts
