## Ressourcenübersicht

Das Init-Skript ist eine Funktion, mit der ein zuvor erstelltes Skript beim Erstellen eines Servers automatisch ausgeführt wird. Es kann in verschiedenen Fällen genutzt werden, z. B. beim gleichzeitigen Erstellen mehrerer Server mit derselben Funktion, beim regelmäßigen Erstellen von Servern mit derselben Umgebung oder wenn eine Verwaltung der anfänglichen Serverumgebung für bestimmte Zwecke erforderlich ist.

## Ressourcen-Einstellwerte

-   `OS_type` : Verwendeter Serverinstanztyp - `LNX`, `WND`
-   `Content` : Automatisch ausgeführtes Skript beim Erstellen des Servers, Beispiel) #!/bin/bash yum install -y httpd && systemctl start httpd
