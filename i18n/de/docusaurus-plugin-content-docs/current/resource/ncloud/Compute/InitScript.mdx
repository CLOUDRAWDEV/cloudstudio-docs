## 리소스 개요

Init Script is a feature that allows pre-written scripts to be executed automatically when a server is created. It can be used in various scenarios, such as creating multiple servers with the same purpose in bulk, periodically creating servers with the same environment, or managing initial server environments by purpose.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

## 리소스 설정 값

#### 기본 설정

-   `os_type` : Type of server instance to use - `LNX`, `WND`
-   `content` : Script content to be executed automatically when the server is created
-   `description` : Description of the Init Script to be created
