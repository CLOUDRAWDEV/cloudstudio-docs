## 리소스 개요

A computing resource that provides the flexibility of virtualization without the need to manage physical hardware. Creating servers in a cloud environment is efficient in terms of time and cost, and is suitable for cases where infrastructure operation is burdensome or when a large amount of server resources is temporarily required.

## 리소스 설정 값

#### 기본 설정

-   `included_subnet_name` : Name of the subnet where the server is located
-   `server_image_product_code` : Operating system image code to use - `ncloudServerImage`
-   `server_product_code` : Code for server hardware configuration - `ncloudServerType`
-   `login_key_name` : Login key name to use
-   `init_script` : Init Script name to use
-   `is_encrypted_base_block_storage_volume` : Whether to encrypt block storage - `true`, `false`
-   `linked_network_interface_names` : Network interfaces assigned to the server
