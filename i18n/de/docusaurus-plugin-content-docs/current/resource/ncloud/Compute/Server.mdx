## Ressourcenübersicht

Eine Computing-Ressource, die die Flexibilität der Virtualisierung bietet, ohne dass physische Hardware verwaltet werden muss.  
Sie ermöglicht die effiziente Erstellung von Servern in Cloud-Umgebungen und eignet sich besonders für Szenarien mit temporär hohem Ressourcenbedarf oder reduziertem Infrastrukturverwaltungsaufwand.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `included_subnet_name` : Name des Subnetzes, in dem der Server platziert wird
-   `server_image_product_code` : Betriebssystem-Image-Code – `ncloudServerImage`
-   `server_product_code` : Hardwarekonfigurationscode des Servers – `ncloudServerType`
-   `login_key_name` : Name des zu verwendenden Login-Schlüssels
-   `init_script` : Name des zu verwendenden Init-Skripts
-   `is_encrypted_base_block_storage_volume` : Aktivierung der Block-Storage-Verschlüsselung – `true`, `false`
-   `linked_network_interface_names` : Dem Server zugewiesene Netzwerkschnittstellen
