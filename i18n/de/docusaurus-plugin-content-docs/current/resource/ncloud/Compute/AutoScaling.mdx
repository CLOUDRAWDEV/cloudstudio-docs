## 리소스 개요

A service that automatically increases or decreases the number of virtual servers according to user-defined schedules or monitoring results, allowing flexible responses to changes in demand. By monitoring servers based on predefined thresholds and automatically adjusting the number of servers, services can be operated stably.

## 리소스 설정 값

#### 기본 설정

-   `linked_acg_names` : List of ACG names to apply to Auto Scaling
-   `included_subnet_name` : Subnet name for server creation
-   `launch_configuration_name` : Name of the Launch Configuration to use
-   `health_check_type_code` : Health check type, server or load balancer - `SVR`, `LOADB`
-   `health_check_grace_period` : Grace period for health checks after the server instance is added to the service - `1` ~ `2147486347`
-   `linked_target_group_list` : List of target group names to connect
-   `min_size` : Minimum size of the Auto Scaling group, within the range of 0 to 30 - `1` ~ `30`
-   `max_size` : Maximum size of the Auto Scaling group, within the range of 0 to 30 - `1` ~ `30`

#### Auto Scaling 정책 (`policy`)

-   `policy.adjustment_type_code` : Scaling adjustment type code, change(CHANG)/percentage(PRCNT)/exact(EXACT) - `CHANG`, `PRCNT`, `EXACT`
-   `policy.scaling_adjustment` : Scaling adjustment value
-   `policy.cooldown` : Time (seconds) during which additional alarms are ignored - `0` ~ `214748364`
-   `policy.min_adjustment_step` : Minimum adjustment step when changing the number of instances - `0` ~ `214748364`

#### Auto Scaling 일정 (`schedule`)

-   `schedule.min_size` : Minimum size of the Auto Scaling group - `1` ~ `30`
-   `schedule.max_size` : Maximum size of the Auto Scaling group - `1` ~ `30`
-   `schedule.desired_capacity` : Desired capacity of the Auto Scaling group - `1` ~ `30`
-   `schedule.start_time` : Schedule start date and time
-   `schedule.end_time` : Schedule end date and time
