## Ressourcenübersicht

Eine Vorlage zur Definition der Spezifikationen virtueller Server, die während des Auto-Scaling-Vorgangs automatisch erstellt werden, wenn eine Servererweiterung erforderlich ist.

## Zugehörige Ressourcen

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/de/docs/resource/ncloud/Base/Region)

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `server_image_product_code` : Betriebssystem-Image-Code (CNTOS: CentOS, UBNTU: Ubuntu, WND: Windows / MYSQL, MARIA: Database / SVR: Server, EN: English Edition) – `ncloudServerImage`
-   `server_product_code` : Code für die Server-Hardwarekonfiguration (HICPU: High CPU, STAND: Standard, HIMEM: High Memory / C: CPU-Kerne, M: Speicher(GB)) – `ncloudServerType`
-   `login_key_name` : Name des öffentlichen Login-Schlüssels zur Verschlüsselung
-   `init_script` : Skriptinhalt, der beim Erstellen des Servers automatisch ausgeführt wird
-   `is_encrypted_volume` : Aktivierung der Verschlüsselung des Basic Block Storage – `true`, `false`
