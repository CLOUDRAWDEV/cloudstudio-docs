## 리소스 개요

SourceCommit is a private Git repository service for securely storing source code and various files. You can create repositories in SourceCommit to efficiently manage team projects and easily store data such as source code.

## 연관 리소스

-   [**Source Pipeline**](https://docs.cstudio.app/docs/resource/ncloud/DeveloperTool/SourcePipeline)

### 연결 리소스

-   [**Source Build**](https://docs.cstudio.app/docs/resource/ncloud/DeveloperTool/SourceBuild)
-   [**Source Deploy Stage**](https://docs.cstudio.app/docs/resource/ncloud/DeveloperTool/SourceDeployStage)

## 리소스 설정 값

#### 기본 설정

-   `enable_file_safer` : Whether to use File Safer - `true`, `false`
-   `description` : Repository description - up to 500 characters
