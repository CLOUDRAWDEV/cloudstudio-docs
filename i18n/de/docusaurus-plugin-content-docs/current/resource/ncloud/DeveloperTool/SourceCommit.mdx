## Ressourcenübersicht

SourceCommit ist ein privater Git-Repository-Service zum sicheren Speichern von Quellcode und verschiedenen Dateien.  
Er ermöglicht die effiziente Verwaltung von Teamprojekten und eine einfache Speicherung von Code und Daten.

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `enable_file_safer` : Verwendung von File Safer – `true`, `false`
-   `description` : Beschreibung des Repositorys – max. 500 Zeichen
