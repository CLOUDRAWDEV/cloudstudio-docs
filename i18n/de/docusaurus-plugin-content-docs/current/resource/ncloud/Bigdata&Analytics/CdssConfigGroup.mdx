## Ressourcenübersicht

Die CDSS Config Group ist ein Service, der die Verwaltung von Kafka-Konfigurationsdateien bietet, die auf den CDSS-Cluster angewendet werden.

## Verwandte Ressourcen

### Untergeordnete Ressourcen



## Ressourcen-Einstellwerte

-   `kafka_version_code` : Die Kafka-Version, die in der CDSS Config Group verwendet wird, kann vom Benutzer ausgewählt werden, wobei jede Version verschiedene Funktionen und Leistungsverbesserungen bietet.
