## Ressourcenübersicht

Cdss Config Group ist ein Service zur Verwaltung von Kafka-Konfigurationsdateien, die auf einen CDSS-Cluster angewendet werden.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `kafka_version_code` : Kafka-Version für die CDSS-Config-Group – `kafkaVersionCode`
-   `description` : Beschreibung der Config-Group
