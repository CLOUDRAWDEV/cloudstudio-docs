## 리소스 개요

Cdss Config Group is a service that manages Kafka configuration files applied to CDSS clusters.

## 연관 리소스

### 상위 리소스

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

### 연결 리소스

-   [**CdssConfigGroup**](https://docs.cstudio.app/docs/resource/ncloud/Bigdata&Analytics/CdssConfigGroup)

## 리소스 설정 값

#### 기본 설정

-   `kafka_version_code` : Kafka version to use in the CDSS config group - `kafkaVersionCode`
-   `description` : Description of the config group
