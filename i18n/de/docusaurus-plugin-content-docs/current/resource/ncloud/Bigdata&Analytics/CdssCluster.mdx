## Ressourcenübersicht

Es ist ein Service, mit dem Sie Apache Kafka-Cluster, eine Open-Source-Plattform für den Aufbau von Echtzeit-Streaming-Datenpipelines und -anwendungen, einfach bereitstellen, schützen, betreiben und skalieren können.

## Ressourcen-Einstellwerte

-   `kafka_version_code` : Kafka-Version, die im CDSS verwendet wird
-   `linked_config_group_name` : Name der zu verwendenden CDSS-Konfigurationsgruppe
-   `os_image` : Zu verwendender OS-Image-Typ
-   `cmak` : Konfigurationsinformationen für CMAK (Cluster Manager für Apache Kafka) 
    -   `user_name` : CMAK-Zugriffs-ID
    -   `user_password` : CMAK-Zugriffs-ID
-   `manager_node` : Konfigurationsinformationen der Knoten, die den Apache Kafka-Cluster über CMAK verwalten
    -   `manager_node_subnet_name` : Name des Subnetzes, in dem die Knoten für die Region positioniert sind
    -   `manager_node_product_name` : Hardware-Produktcode für Manager-Knoten
-   `broker_node` : Konfigurationsinformationen für Serverknoten, auf denen die tatsächlichen Daten gespeichert werden
    -   `broker_node_subnet_name` : Name des Subnetzes, in dem Broker-Knoten positioniert sind
    -   `broker_node_product_code` : Hardware-Produktcode für Broker-Knoten
    -   `broker_node_count` : Anzahl der Broker-Knoten
    -   `broker_node_storage_size` : Speicherkapazität der Broker-Knoten - `100~2000`
