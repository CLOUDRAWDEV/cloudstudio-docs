## 리소스 개요

A service that allows easy deployment, protection, operation, and scaling of Apache Kafka clusters, an open-source platform for real-time streaming data pipelines and application development.

## 연관 리소스

### 상위 리소스

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

### 연결 리소스

-   [**CdssConfigGroup**](https://docs.cstudio.app/docs/resource/ncloud/Bigdata&Analytics/CdssConfigGroup)

## 리소스 설정 값

#### 기본 설정

-   `included_vpc_name` : Name of the VPC where CDSS will be created
-   `kafka_version_code` : Kafka version to use in CDSS - `kafkaVersionCode`
-   `linked_config_group_name` : Name of the CDSS config group to use
-   `os_image` : OS image type to use - `osImage`

#### CMAK 설정 (`cmak`)

-   `cmak.user_name` : CMAK access ID
-   `cmak.user_password` : CMAK access password

#### 매니저 노드 설정 (`manager_node`)

-   `manager_node.manager_node_subnet_name` : Subnet name where the manager node will be located
-   `manager_node.manager_node_product_code` : Manager node hardware product code - `managerNodeProductCode`

#### 브로커 노드 설정 (`broker_node`)

-   `broker_node.broker_node_subnet_name` : Subnet name where the broker node will be located
-   `broker_node.broker_node_product_code` : Broker node hardware product code - `managerNodeProductCode`
-   `broker_node.broker_node_count` : Number of broker nodes - `3` ~ `10`
-   `broker_node.broker_node_storage_size` : Broker node storage size - `100` ~ `2000`
