## 리소스 개요

A resource that provides an environment for conveniently managing Elasticsearch and OpenSearch clusters, allowing you to configure clusters by selecting various server types and storage capacities, and easily deploy, operate, and scale them.

## 연관 리소스

### 상위 리소스

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

## 리소스 설정 값

#### 기본 설정

-   `included_vpc_name` : Name of the VPC where SES will be created
-   `os_image_code` : OS type to use - `osImageName`
-   `enable_master_node` : Whether to enable the master node - `true`, `false`
-   `login_key_name` : Public login key name for encryption

#### Search Engine 설정 (`search_engine`)

-   `search_engine.version_code` : Search Engine version code to use - `versionCode`
-   `search_engine.user_name` : Search Engine username
-   `search_engine.user_password` : Search Engine user password
-   `search_engine.dashboard_port` : Port of the Search Engine dashboard - `1024` ~ `65535`

#### Manager Node 설정 (`manager_node`)

-   `manager_node.enable_dual_manager` : Whether to enable manager node redundancy - `true`, `false`
-   `manager_node.manager_node_subnet_name` : Subnet name where the manager node will be located
-   `manager_node.manager_node_product_code` : Manager node product code to use - `managerNodeProductCode`

#### Data Node 설정 (`data_node`)

-   `data_node.data_node_subnet_name` : Subnet name where the data node will be located
-   `data_node.data_node_product_code` : Data node product code to use - `managerNodeProductCode`
-   `data_node.data_node_count` : Number of data nodes - `3` ~ `10`
-   `data_node.data_node_storage_size` : Data node storage size - `100` ~ `2000`

#### Master Node 설정 (`master_node`)

-   `master_node.master_node_subnet_name` : Subnet name where the master node will be located
-   `master_node.master_node_product_code` : Master node product code to use - `managerNodeProductCode`
-   `master_node.master_node_count` : Number of master nodes - `3` ~ `5`
