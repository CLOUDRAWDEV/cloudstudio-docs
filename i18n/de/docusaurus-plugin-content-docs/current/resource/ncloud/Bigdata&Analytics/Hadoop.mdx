## 리소스 개요

Hadoop is an **Ncloud Big Data platform** designed for distributed processing of large-scale data.  
You can easily build a cluster composed of edge, master, and worker nodes, manage it through the Ambari console, and optionally add add-ons such as Spark, HBase, and Impala.

## 연관 리소스

### 상위 리소스

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

## 리소스 설정 값

#### 기본 설정

-   `included_vpc_name` : Name of the VPC where SES will be created
-   `cluster_name` : Cluster name
-   `cluster_type_code` :
-   `admin_user_name` : Administrator username required to access the Ambari management console
-   `admin_user_password` : Password for the Ambari administrator account
-   `login_key_name` : Public login key name for encryption
-   `edge_node_subnet_no` : Subnet ID where the edge node will be located
-   `master_node_subnet_no` : Subnet ID where the master node will be located
-   `worker_node_subnet_no` : Subnet ID where the worker node will be located
-   `bucket_name` : Bucket name for storing data in Object Storage
-   `master_node_data_storage_type` : Master node storage type - `SSD`, `HDD`
-   `worker_node_data_storage_type` : Worker node storage type - `SSD`, `HDD`
-   `master_node_data_storage_size` : Master node storage size
-   `worker_node_data_storage_size` : Worker node storage size
-   `image_product_code` : Image product code for Hadoop instance server image specification - `image_product`
-   `engine_version_code` : Engine version code - `HADOOP2.3`, `HADOOP2.2`
-   `edge_node_product_code` : Edge node product code - `edge_product_list`
-   `master_node_product_code` : Master node product code - `product_list`
-   `worker_node_product_code` : Worker node product code - `product_list`
-   `add_on_code_list` : Add-on list, available options - `HBASE`, `IMPALA`, `KUDU`, `TRINO`, `NIFI`
-   `worker_node_count` : Number of worker nodes - `2` ~ `8`
-   `use_kdc` : Whether to use KDC - `true`, `false`
-   `kdc_realm` : KDC Realm
-   `kdc_password` : KDC password
-   `use_bootstrap_script` : Whether to use a bootstrap script - `true`, `false`
-   `bootstrap_script` : Bootstrap script
-   `use_data_catalog` : Whether to use the data catalog - `true`, `false`

## 리소스 설정 값

-   `included_vpc_name` : Name of the VPC where the Hadoop cluster will be created
-   `cluster_name` : Cluster name
-   `cluster_type_code` : Cluster type code (e.g., including Spark)
-   `admin_user_name` : Ambari administrator account name
-   `admin_user_password` : Ambari administrator password
-   `login_key_name` : Login key name (for public key–based encrypted access)
-   `edge_node_subnet_no` : Subnet ID where the edge node will be located
-   `master_node_subnet_no` : Subnet ID where the master node will be located
-   `worker_node_subnet_no` : Subnet ID where the worker node will be located
-   `bucket_name` : Object Storage bucket name (for data storage)
-   `master_node_data_storage_type` : Master node storage type (`SSD`, `HDD`)
-   `worker_node_data_storage_type` : Worker node storage type (`SSD`, `HDD`)
-   `master_node_data_storage_size` : Master node storage size
-   `worker_node_data_storage_size` : Worker node storage size
-   `image_product_code` : Hadoop server image product code
-   `engine_version_code` : Hadoop engine version code (`HADOOP2.2`, `HADOOP2.3`)
-   `edge_node_product_code` : Edge node product code
-   `master_node_product_code` : Master node product code
-   `worker_node_product_code` : Worker node product code
-   `add_on_code_list` : List of add-ons to install (`HBASE`, `IMPALA`, `KUDU`, `TRINO`, `NIFI`)
-   `worker_node_count` : Number of worker nodes (`2~8`)
-   `use_kdc` : Whether to use KDC authentication (`true`, `false`)
-   `kdc_realm` : KDC Realm name
-   `kdc_password` : KDC password
-   `use_bootstrap_script` : Whether to use a bootstrap script
-   `bootstrap_script` : Path of the bootstrap script to execute
-   `use_data_catalog` : Whether to use the data catalog
