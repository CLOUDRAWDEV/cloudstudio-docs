## Ressourcenübersicht

Ein VPC-Subnetz, das nach Netzwerkzwecken unterteilt werden kann.

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

-   [**Network Acl**](https://docs.cstudio.app/docs/resource/ncloud/Network/NetworkAcl)

## Ressourcen-Einstellwerte

-   `subnet_cidr` : IP-Adressbereich des Subnetzes innerhalb des VPC-Adressbereichs
-   `zone` : Die physische Region, in der das Subnetz platziert wird - `KR-1`, `KR-2`
-   `subnet_type` : Einstellungen für öffentliches oder privates Subnetz - `PUBLIC`, `PRIVATE`
-   `usage_type` : Einstellung zur Verwendung eines Load Balancers - `GEN`, `BM`
-   `included_vpc_name` : Der Name des VPC, in dem sich das Subnetz befindet
-   `linked_nacl_name` : Die Network Access Control List zur Zugriffskontrolle auf das Subnetz
