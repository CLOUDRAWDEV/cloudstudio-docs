## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `subnet_cidr` : IP-Adressbereich des Subnets innerhalb des VPC-CIDR-Bereichs
-   `zone` : Verfügbarkeitszone, in der sich das Subnet befindet (`KR-1`, `KR-2`)
-   `subnet_type` : Typ des Subnets (`PUBLIC`, `PRIVATE`)
-   `usage_type` : Verwendungszweck des Subnets (`General`, `LoadBalancer`, `BareMetal`, `NatGateway`)
-   `included_vpc_name` : Name des VPC, zu dem das Subnet gehört (schreibgeschützt)
-   `linked_nacl_name` : Name des auf das Subnet angewendeten Network ACL (schreibgeschützt)
