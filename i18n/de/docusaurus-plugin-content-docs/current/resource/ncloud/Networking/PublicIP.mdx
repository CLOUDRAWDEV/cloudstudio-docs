## Ressourcenübersicht

Dies ist ein Service, der dazu dient, Server für Servicezwecke zu nutzen oder den Zugriff auf erstellte Server zu erleichtern.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### Verbundene Ressourcen

-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## Ressourcen-Einstellwerte

-   `target_server_name` : Der Name der Serverinstanz, auf die die öffentliche IP angewendet werden soll
