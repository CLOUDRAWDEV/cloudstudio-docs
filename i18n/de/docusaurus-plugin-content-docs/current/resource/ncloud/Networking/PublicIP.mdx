## 리소스 개요

A service that helps use servers for service purposes or connect to created servers.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### 연결 리소스

-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## 리소스 설정 값

#### 기본 설정

-   `target_server_name` : Name of the server instance to which the public IP will be applied
