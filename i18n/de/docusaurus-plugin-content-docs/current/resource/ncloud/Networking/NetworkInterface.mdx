## Ressourcenübersicht

Ein Dienst zur Erstellung von Netzwerkschnittstellen, die Servern zugewiesen werden können.  
Server mit zugewiesener Netzwerkschnittstelle können über Subnetze unabhängig kommunizieren.

## Zugehörige Ressourcen

### Übergeordnete Ressourcen

-   [**Subnet**](https://docs.cstudio.app/de/docs/resource/ncloud/Networking/Subnet)

### Verbundene Ressourcen

-   [**AccessControlGroup**](https://docs.cstudio.app/de/docs/resource/ncloud/Networking/AccessControlGroup)
-   [**Server**](https://docs.cstudio.app/de/docs/resource/ncloud/Compute/Server)

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `included_subnet_name` : Subnet-Name der Netzwerkschnittstelle
-   `linked_acg_names` : Liste der zugeordneten Access-Control-Groups
