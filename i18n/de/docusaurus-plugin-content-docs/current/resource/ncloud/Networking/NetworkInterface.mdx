## 리소스 개요

A service that creates network interfaces that can be assigned to servers. Servers with network interfaces applied can perform isolated network communication using subnets.

## 연관 리소스

### 상위 리소스

-   [**Subnet**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Subnet)

### 연결 리소스

-   [**Access Control Group**](https://docs.cstudio.app/docs/resource/ncloud/Networking/AccessControlGroup)
-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## 리소스 설정 값

#### 기본 설정

-   `included_subnet_name` : Name of the subnet that includes the Network Interface
-   `linked_acg_names` : List of Access Control Group names to apply to the Network Interface
