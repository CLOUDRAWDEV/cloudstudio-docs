## 리소스 개요

A resource for configuring VPC peering to enable communication between VPCs.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### 연결 리소스

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

## 리소스 설정 값

#### 기본 설정

-   `linked_vpc_name_01` : Name of the VPC sending the peering request (read-only)
-   `linked_vpc_name_02` : Name of the VPC receiving the peering request (read-only)
