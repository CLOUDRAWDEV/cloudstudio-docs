## Ressourcenübersicht

Dies ist eine Ressource zur Einrichtung einer VPC-Peering-Verbindung für die Kommunikation zwischen VPCs.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### Verbundene Ressourcen

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

## Ressourcen-Einstellwerte

-   `linked_vpc_name_01` : Name der anfragenden VPC
-   `linked_vpc_name_02` : Name der empfangenden VPC
