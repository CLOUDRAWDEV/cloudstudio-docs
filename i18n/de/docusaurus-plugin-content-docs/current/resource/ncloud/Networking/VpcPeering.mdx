Eine Ressource zur Einrichtung von VPC-Peering für die Kommunikation zwischen verschiedenen VPCs.

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `linked_vpc_name_01` : Name des anfragenden VPC (schreibgeschützt)
-   `linked_vpc_name_02` : Name des empfangenden VPC (schreibgeschützt)
