## Ressourcenübersicht

Ein Dienst, der Netzwerkverkehr unter Berücksichtigung von Serverleistung und Auslastung auf mehrere Server verteilt.  
Durch Lastverteilung werden Verfügbarkeit und Antwortzeiten optimiert und unterbrechungsfreie Services ermöglicht.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `network_type` : Netzwerktyp – `PUBLIC`, `PRIVATE`
-   `type` : Load-Balancer-Typ – `APPLICATION`, `NETWORK`, `NETWORK_PROXY`
-   `throughput_type` : Leistungsstufe (Verbindungen/Sek.) – `SMALL(30k)`, `MEDIUM(60k)`, `LARGE(90k)`
-   `included_subnet_names` : Liste der verbundenen Subnet-Namen

#### Listener (`listener`)

-   `listener.protocol` : Listener-Protokoll – `HTTP`, `HTTPS`, `TCP`, `TLS`
-   `listener.tls_min_version_type` : Minimale TLS-Version – `TLSV10`, `TLSV11`, `TLSV12`
-   `listener.port` : Listener-Port – `1` ~ `65534`
-   `listener.use_http2` : Verwendung von HTTP/2 – `true`, `false`
-   `listener.ssl_certificate_no` : SSL-Zertifikatsnummer
-   `listener.target_group_name` : Ziel-Target-Group-Name
