## Ressourcenübersicht

Dies ist ein Gerät, das den Netzwerkverkehr unter Berücksichtigung der Serverleistung und der Last auf mehrere Server verteilt. Durch die Lastenverteilung auf spezifische Server kann die Serververfügbarkeit und Reaktionszeit optimiert werden, sodass ein unterbrechungsfreier Service gewährleistet werden kann.

## Ressourcen-Einstellwerte

-   `network_type` : Netzwerkzeit, öffentlich oder privat - `PUBLIC`, `PRIVATE`
-   `type` : Der Typ des zu erstellenden Load Balancers, Anwendung/Netzwerk/Netzwerk Proxy - `NETWORK`, `NETWORK_PROXY`, `APPLICATION`
-   `throughput_type` : Lastverarbeitungsleistung, Anzahl der Verbindungen pro Sekunde 30.000/60.000/90.000 - `SMALL`, `MEDIUM`, `LARGE`
-   `included_vpc_name` : Der Name des VPC, in dem die Zielgruppe erstellt wird
-   `subnet_config`
    -   `cidr`
    -   `linked_nacl_name`
    -   `zone`
-   `target_group`
    -   `protocol` : Der Protokolltyp, der für die Routenführung des Verkehrs verwendet wird - `TCP`, `PROXY_TCP`, `HTTP`, `HTTPS`
    -   `port` : Die Portnummer, die den eingehenden Verkehr empfängt
    -   `algorithm_type` : Der Algorithmustyp, der für das Load Balancing verwendet wird, RR/SIPHS/LC - `RR`, `SIPHS`, `LC`, `MH`
    -   `health_check_protocol` : Das Protokoll, das für die Überprüfung des Zielstatus verwendet wird - `TCP`, `HTTP`, `HTTPS`
    -   `health_check_http_method` : Die HTTP-Methode, die verwendet wird, wenn das Überprüfungsprotokoll HTTP/HTTPS ist - `HEAD`, `GET`
    -   `health_check_port` : Die Portnummer, die für die Überprüfung des Zielstatus verwendet wird
    -   `health_check_cycle` : Der Intervall (in Sekunden), in dem der Zielstatus überprüft wird (zwischen 5 und 300)
    -   `health_check_up_threshold` : Der Schwellenwert für den Übergang von einem fehlerhaften Ziel in einen gesunden Status, Anzahl der erfolgreichen Überprüfungen
    -   `health_check_down_threshold` : Der Schwellenwert für den Übergang von einem gesunden Ziel in einen fehlerhaften Status, Anzahl der fehlgeschlagenen Überprüfungen
-   `listener`
    -   `target_group_name` : Der Name der Zielgruppe, mit der verbunden wird
    -   `protocol` : Der Protokolltyp, mit dem der Listener arbeitet, Anwendung-HTTP oder HTTPS/Netzwerk-TCP/Netzwerk Proxy-TCP oder TLS - `APPLICATION`, `HTTP`, `HTTPS`, `TCP`, `TLS`
    -   `port` : Die Portnummer, die der Listener an den Load Balancer bindet
-   `target_group_attachment`
    -   `target_group_name` : Der Name der Zielgruppe, mit der verbunden wird
    -   `linked_server_names` : Eine Liste der Servernamen, mit denen verbunden wird
