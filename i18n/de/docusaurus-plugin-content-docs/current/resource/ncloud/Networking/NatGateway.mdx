## 리소스 개요

A service that connects multiple servers using a single public IP and blocks direct external access. It allows multiple servers with private IPs to communicate with external servers while preventing direct access from outside to maintain security.

## 연관 리소스

### 상위 리소스

-   [**Subnet**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Subnet)

## 리소스 설정 값

#### 기본 설정

-   `included_vpc_name` : Name of the VPC where the NAT Gateway will be created
-   `included_subnet_name` : Name of the subnet where the NAT Gateway will be created
