## Ressourcenübersicht

Ein Service, der mehreren Servern mit privaten IP-Adressen den Zugriff auf externe Netzwerke über eine einzige öffentliche IP ermöglicht und gleichzeitig direkte externe Zugriffe blockiert.

## Zugehörige Ressourcen

### Übergeordnete Ressourcen

-   [**Subnet**](https://docs.cstudio.app/de/docs/resource/ncloud/Networking/Subnet)

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `included_vpc_name` : Name des VPC für das NAT-Gateway
-   `included_subnet_name` : Name des Subnetzes für das NAT-Gateway
