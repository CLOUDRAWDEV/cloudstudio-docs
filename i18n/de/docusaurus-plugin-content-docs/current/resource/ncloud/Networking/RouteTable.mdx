## Ressourcenübersicht

Dies ist ein Service, der den Netzwerkpfad für Ressourcen innerhalb eines VPC definiert.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

### Verbundene Ressourcen

-   [**Subnet**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Subnet)

## Ressourcen-Einstellwerte

-   `included_vpc_name` : Name des zu verbindenden VPC
-   `supported_subnet_type` : Unterstützte Subnetzeinstellungen, öffentlich oder privat - `PUBLIC`, `PRIVATE`
-   `route_table_description` : Beschreibung der Route-Tabelle
-   `linked_subnet_names` : Liste der Subnetz-Namen, mit denen verbunden werden soll
-   `route`
    -   `target_type` : Zieltyp, Nat Gateway oder VPC-Peering - `NATGW`, `VPCPEERING`, `VGW`
    -   `target_name` : Zielname
    -   `destination_cidr_block` : Ziel-IP-Bereich im CIDR-Format
