## Ressourcenkonfiguration

#### Grundeinstellungen

-   `included_vpc_name` : Name des zu verknüpfenden VPC
-   `supported_subnet_type` : Unterstützter Subnet-Typ (`PUBLIC`, `PRIVATE`)
-   `route_table_description` : Beschreibung der Route-Table
-   `linked_subnet_names` : Liste der verknüpften Subnet-Namen

#### Routing (`route`)

-   `target_type` : Zieltyp (`NATGW`, `VPCPEERING`)
-   `target_name` : Name der Zielressource
-   `destination_cidr_block` : Ziel-IP-Bereich im CIDR-Format
