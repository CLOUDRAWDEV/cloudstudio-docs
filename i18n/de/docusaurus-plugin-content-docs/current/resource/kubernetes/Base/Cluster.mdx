## Ressourcenkonfiguration

#### Grundeinstellungen

-   `target_cluster` : Auswahl des zu verbindenden Ncloud-Kubernetes-Clusters
-   `token` : Authentifizierungs-Token für die Verbindung zum Ncloud Kubernetes Service
