## Ressourcenübersicht

Eine Kubernetes-Ressource, um den Ingress-Controller auszuwählen, den Ingress verwenden soll

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)



### Verbundene Ressourcen

-   [**Ingress**](https://docs.cstudio.app/docs/resource/kubernetes/Networking/Ingress)



## Ressourcen-Einstellwerte

-   `service_name` : IngressClass Ressource Name
-   `annotations` : Schlüssel-Wert-Paare, die verwendet werden, um notwendige Informationen im Kubernetes-System anzuzeigen
-   `labels` : Vom Benutzer festgelegte Werte, um Objekte zu kennzeichnen und zu unterscheiden
-   `controller` : Der Name des Controllers, der die IngressClass verarbeiten muss
-   `parameters` : Informationen über die referenzierten Ressourcen
    -   `name` : Der Name der referenzierten Ressource
    -   `kind` : Der Typ der referenzierten Ressource
    -   `namespace` : Der Namespace der referenzierten Ressource
    -   `scope` : Der Gültigkeitsbereich der Ressource – entweder Cluster oder Namespace
    -   `api_group` : Die API-Gruppe der referenzierten Ressource
