## Ressourcenübersicht

Eine Kubernetes-Ressource zur Auswahl des Ingress-Controllers, der von Ingress verwendet werden soll.

## Zugehörige Ressourcen

### Übergeordnete Ressourcen

-   [**Cluster**](https://docs.cstudio.app/de/docs/resource/kubernetes/Base/Cluster)

### Verbundene Ressourcen

-   [**Ingress**](https://docs.cstudio.app/de/docs/resource/kubernetes/Networking/Ingress)

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `annotations` : Key-Value-Metadaten für das Verhalten der IngressClass
-   `labels` : Benutzerdefinierte Labels zur Identifikation der IngressClass
-   `controller` : Kennung des Ingress-Controllers für diese IngressClass

#### Parameterkonfiguration (`parameters`)

-   `parameters.kind` : Typ der referenzierten Parameter-Ressource – `IngressParameter`, `ClusterIngressParameter`
-   `parameters.namespace` : Namespace der referenzierten Parameter-Ressource
-   `parameters.api_group` : API-Gruppe der referenzierten Parameter-Ressource
