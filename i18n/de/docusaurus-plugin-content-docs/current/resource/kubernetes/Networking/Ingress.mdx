## Ressourcenübersicht

Kubernetes-Ressource, die Regeln für eingehende Verbindungen definiert, die es ihnen ermöglichen, das von der Backend-Anwendung definierte Endpunkt zu erreichen

## Ressourcen-Einstellwerte

-   `service_name` : Name der Ingress-Ressource
-   `namespace` : Namespace, in dem die Ingress-Ressource bereitgestellt wird
-   `annotations` : Key-Value-Paare, die verwendet werden, um die erforderlichen Informationen im Kubernetes-System anzuzeigen
-   `labels` : Der Benutzer kann einen beliebigen Wert festlegen, um das Objekt zu unterscheiden
-   `tls` : TLS anwenden
    -   `hosts` : Liste der Hosts, die im TLS-Zertifikat enthalten sind
    -   `secret_name` : Geben Sie den Namen des Kubernetes-Secrets an, das mit dem TLS-Zertifikat verknüpft ist
-   `ingress_class_name` : Geben Sie den Namen der Ingress-Klasse an, mit der verbunden werden soll
-   `host` : Geben Sie die Hostnamen-Adresse an, auf die die Routing-Regeln angewendet werden sollen
-   `backend` : Geben Sie die Backend-Informationen ein, auf die geroutet werden soll
    -   `name` : Name der Routing-Rege
        -   `path` : Pfad, der mit dem Backend verbunden werden soll
        -   `path_type` : Bestimmung der Interpretation der Pfadübereinstimmung - `Prefix`, `ImplementationSpecific`, `Exact`
        -   `port` : Portnummer des Dienstes - `1~65535`
