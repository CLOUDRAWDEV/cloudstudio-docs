## Ressourcenübersicht

Eine Kubernetes-Ressource mit Regeln, die es eingehenden Verbindungen erlauben, die im Backend definierten Endpunkte zu erreichen.

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `namespace` : Namespace, in dem die Ingress-Ressource bereitgestellt wird
-   `annotations` : Key-Value-Metadaten für das Kubernetes-System
-   `labels` : Benutzerdefinierte Labels zur Objektidentifikation
-   `ingress_class_name` : Name der zu verbindenden Ingress-Klasse

#### TLS-Konfiguration (`tls`)

-   `tls.hosts` : Liste der Hosts im TLS-Zertifikat
-   `tls.secret_name` : Name des Kubernetes-Secrets für das TLS-Zertifikat

#### Routing-Regeln (`rule`)

-   `rule.host` : Hostname, auf den die Routing-Regel angewendet wird

#### Backend-Konfiguration (`rule.backend`)

-   `rule.backend.target_service` : Ziel-Backend-Service
-   `rule.backend.path` : Pfad zum Backend
-   `rule.backend.port` : Portnummer des Services
-   `rule.backend.path_type` : Auswertung der Pfadübereinstimmung – `ImplementationSpecific`, `Prefix`, `Exact`
