## Ressourcenübersicht

Ein Kubernetes-Service, der sicherstellt, dass eine festgelegte Anzahl von Pod-Replikaten jederzeit ausgeführt wird.

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `namespace` : Namespace, in dem die Deployment-Ressource bereitgestellt wird
-   `annotations` : Kubernetes-Systemmetadaten im Key-Value-Format
-   `labels` : Labels zur Identifizierung der Deployment-Ressource
-   `template_labels` : Labels, die auf die zu erstellenden Pods angewendet werden
-   `replicas` : Anzahl der beizubehaltenden Pod-Replikate
-   `pod_security_context` : Sicherheits- und Berechtigungseinstellungen auf Pod-Ebene
-   `init_containers` : Definition von Initialisierungs-Containern vor Ausführung des Haupt-Containers
-   `containers` : Definition der im Pod enthaltenen Container
-   `volume` : Definition der im Pod verwendeten Volumes
-   `dns_policy` : DNS-Richtlinie des Pods
-   `enable_service_links` : Ob Service-Umgebungsvariablen automatisch injiziert werden
-   `host_network` : Ob das Host-Netzwerk verwendet wird
-   `image_pull_secrets` : Liste der Secrets, die beim Image-Pull verwendet werden
