## Ressourcenübersicht

Ein Kubernetes-Ressource, die die Bereitstellung und Skalierung einer Pod-Gruppe verwaltet und eine Garantie für die Reihenfolge und Einzigartigkeit dieser Pods bietet.

## Ressourcen-Einstellwerte

-   `service_name` : StatefulSet Ressourcename
-   `namespace` : StatefulSet-Ressource wird im Namespace bereitgestellt
-   `annotations` : Key-Value-Paare, die von Kubernetes-Systemen verwendet werden, um notwendige Informationen anzuzeigen
-   `labels` : Werte, die der Benutzer für die Unterscheidung von Objekten festlegt
-   `template_labels` : Labels, die für Pods festgelegt werden, die auf einzelnen Knoten erstellt werden
-   `pod_management_policy` : Steuert, wie Pods beim Ersetzen oder Reduzieren von Knoten erstellt werden - `Parallel`,`OrderedReady`
-   `revision_history_limit` : Maximale Anzahl von Revisionen, die für StatefulSet-Verlaufsprotokolle gespeichert werden, Standardwert ist 10
-   `service_name` : Name des Headless-Dienstes, der das StatefulSet verwaltet
-   `replicas` : Die gewünschte Anzahl von Pod-Replikaten - Standardwert ist 1

-   `containers` : Vorlage für Container, die zu Pods gehören, mit grundlegenden Einstellungen und detaillierteren Konfigurationsmöglichkeiten.
    -   `name` : Name des Containers
        -   `image` : Verwendetes Docker-Image
        -   `args` : Befehle, die im Container ausgeführt werden
        -   `command` : Befehle, die im Container ausgeführt werden
        -   `port` : Liste der Ports, die im Container exponiert werden

        -   `resources` : Festlegung der Menge an Rechenressourcen für den Container - Detaillierte Einstellungen
            -   `name` : Festlegung der minimalen/maximalen Rechenressourcen   - `Limits`, `requests`     
            -   `cpu` : Menge an CPU-Ressourcen
            -   `memory` : Menge an Speicherressourcen

        -   `probe` : Definiert die Methode zur Diagnose des Pod-Zustands - Detaillierte Einstellungen
            -   `name` : Auswahl der Probe-Methode - `startup`,`liveness`,`readiness`
            -   `http_get_path` : Pfad zum Zugriff auf den HTTP-Server
            -   `http_get_port` : Portnummer für den Zugriff im Container
            -   `http_header` : Benutzerdefinierte Header für die Anforderung
            -   `initial_delay_seconds` : Zeit (in Sekunden), die nach dem Start des Containers verstreichen muss, bevor die Probe gestartet wird
            -   `period_seconds` : Häufigkeit der Durchführung der Probe (in Sekunden)

        -   `env` : Block von Key-Value-Paaren, die als Umgebungsvariablen im Container gesetzt werden - Detaillierte Einstellungen
            -   `name` : Festlegung des Namens der Umgebungsvariable
            -   `value` : Wert der Umgebungsvariable

        -   `volume_mount` : Volumen, das im Container-Dateisystem gemountet werden soll - Detaillierte Einstellungen
            -   `name` : Festlegung des Namens des Volumen-Mounts
            -   `path` 
                -   `mount_path` : Der Pfad innerhalb des Containers, an dem das Volumen gemountet werden soll
                -   `sub_path` : Der Pfad innerhalb des Containers, an dem das Volumen gemountet werden soll
            
-   `volume` : Volume-Listen für Container in einem Pod
    -   `name` : Name des Volumens
        -   `type` : Typ des Volumens, das gemountet werden soll - `EmptyDir`,`ConfigMap`,`PersistentVolumeClaim`
        -   `target_name` : Name des Persistent Volume Claims
        -   `default_mode` : Modus, der für die erstellte Datei verwendet wird - Werte von 0 bis 0777, der Standardwert ist 0644
        -   `read_only` : Wenn true, wird das Volumen im schreibgeschützten Modus gemountet, andernfalls ist es lesbar und schreibbar

-   `image_pull_secrets` : Secrets im gleichen Namespace, die die notwendigen Berechtigungen zum Abrufen des verwendeten Container-Images enthalten
