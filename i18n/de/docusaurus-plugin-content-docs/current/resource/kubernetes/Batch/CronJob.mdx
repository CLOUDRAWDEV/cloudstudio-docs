## Ressourcenübersicht

Eine Kubernetes-Ressource, die gemäß einem Zeitplan periodisch Jobs erstellt.

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `namespace` : Namespace, in dem der CronJob bereitgestellt wird
-   `schedule` : Ausführungsintervall des Jobs, definiert durch einen Cron-Ausdruck
-   `timezone` : Referenzzeitzone für die Interpretation des Zeitplans
-   `concurrency_policy` : Richtlinie für die gleichzeitige Ausführung von Jobs (Allow / Forbid / Replace)
-   `starting_deadline_seconds` : Zulässige Startzeit, wenn ein Zeitplan verpasst wurde
-   `successful_jobs_history_limit` : Anzahl der aufzubewahrenden erfolgreichen Jobs
-   `failed_jobs_history_limit` : Anzahl der aufzubewahrenden fehlgeschlagenen Jobs
-   `containers` : Definition der auszuführenden Container-Spezifikationen
-   `init_containers` : Definition vorbereitender Aufgaben vor Ausführung des Haupt-Containers
-   `volume` : Volume-Einstellungen für Container-Mounts
-   `pod_security_context` : Sicherheitskontext-Einstellungen auf Pod-Ebene
-   `image_pull_secrets` : Referenz auf Secrets für den Image-Pull
