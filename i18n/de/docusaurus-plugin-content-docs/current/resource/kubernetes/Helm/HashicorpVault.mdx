## Ressourcen-Einstellwerte

-   `service_name` : Hashicorp-Vault Helm-Chart Release-Name
-   `namespace` : Der Namespace, in dem das Hashicorp-Vault Helm-Chart bereitgestellt wird
-   `version` : Die Version des zu verwendenden Hashicorp-Vault Helm-Charts
-   `set` : Dynamische Änderung der Standardwerte des Hashicorp-Vault Charts
