## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `namespace` : Namespace, in dem die Nginx-Ingress-Helm-Chart-Ressource bereitgestellt wird
-   `version` : Version des zu verwendenden Nginx-Ingress-Helm-Charts
-   `replica_count` : Anzahl der Replikate des Ingress-Controller-Deployments
-   `external_traffic_policy` : Behandlung des externen Traffics – `Cluster`, `Local`
-   `ingress_class_name` : Name der IngressClass, die von diesem Controller verwaltet wird
-   `set` : Key-Value-Einstellungen zur dynamischen Änderung der Standardwerte des Nginx-Ingress-Controller-Helm-Charts
