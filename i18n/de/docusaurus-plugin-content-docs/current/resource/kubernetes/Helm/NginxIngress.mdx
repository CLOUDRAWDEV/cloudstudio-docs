## Ressourcenübersicht

Dies ist das Helm-Chart zur Installation des Nginx Ingress Controllers.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)
-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

### Verbundene Ressourcen

-   [**Ingress**](https://docs.cstudio.app/docs/resource/kubernetes/Networking/Ingress)


## Ressourcen-Einstellwerte

-   `service_name` : Nginx Ingress-Controller Helm-Chart Release-Name
-   `namespace` : Der Namespace, in dem das Nginx Ingress-Controller Helm-Chart bereitgestellt wird
-   `version` : Die Version des zu verwendenden Nginx Ingress-Controller Helm-Charts
-   `replica_count` : Die Anzahl der Replikate für das Ingress-Controller Deployment
-   `external_traffic_policy` : Die Richtlinie zur Behandlung des externen Verkehrs - `Cluster`,`Local`
-   `ingress_class_name` : Der Name der Ingress-Klasse, die angibt, welcher Ingress-Controller die Ingress-Ressourcen verwaltet
-   `set` : Dynamische Änderung der Standardwerte des Nginx Ingress-Controller Charts
