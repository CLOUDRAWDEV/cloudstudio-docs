### Verbundene Ressourcen




## Ressourcen-Einstellwerte

-   `service_name` : Istio CRDs Helm-Chart Release-Name`
-   `namespace` : Der Namespace, in dem das Istio CRDs Helm-Chart bereitgestellt wird – festgelegt auf `istio-system`
-   `version` : Die Version des zu verwendenden Istio CRDs Helm-Charts
-   `set` : Dynamische Änderung der Standardwerte des Istio CRDs Charts
