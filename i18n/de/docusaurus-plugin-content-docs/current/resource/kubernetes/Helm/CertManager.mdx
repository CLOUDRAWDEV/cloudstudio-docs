### Verbundene Ressourcen



## Ressourcen-Einstellwerte

-   `service_name` : Cert-Manager Helm-Chart-Release-Name
-   `namespace` : Der Namespace, in dem das Cert-Manager Helm-Chart bereitgestellt wird
-   `version` : Die Version des zu verwendenden CertManager Helm-Charts
-   `installCRDs` : Überprüfung, ob die Custom Resource Definitions (CRDs) für CertManager installiert werden sollen
