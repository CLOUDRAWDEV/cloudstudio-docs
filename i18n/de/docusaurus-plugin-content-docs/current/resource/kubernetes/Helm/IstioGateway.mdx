## Ressourcen-Einstellwerte

-   `service_name` : Istio Gateway Helm-Chart Release-Name
-   `namespace` : Der Namespace, in dem das Istio Gateway Helm-Chart bereitgestellt wird
-   `version` : Die Version des zu verwendenden Istio Gateway Helm-Charts
-   `set` : Dynamische Änderung der Standardwerte des Istio Gateway Charts
