## Ressourcenübersicht

Dies ist eine Ressource, mit der das Standard-Helm-Chart mit benutzerdefinierten Werten konfiguriert und bereitgestellt werden kann.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

### Verbundene Ressourcen



## Ressourcen-Einstellwerte

-   `service_name` : Helm Custom Chart Release-Name
-   `namespace` : Der Namespace, in dem das Helm Custom bereitgestellt wird
-   `repository` : Das Repository zum Speichern und Teilen von Helm-Charts (geben Sie das Repository an, in dem das anzupassende Chart gespeichert ist)
-   `chart` : Der Name des Helm-Charts, das angepasst werden soll
-   `version` : Die Version des Helm-Charts, das angepasst werden soll
-   `set` : Dynamische Änderung der Standardwerte des Charts
