## Ressourcenübersicht

Eine Ressource, mit der ein Helm-Chart mithilfe benutzerdefinierter Werte bereitgestellt werden kann.

## Zugehörige Ressourcen

### Übergeordnete Ressourcen

-   [**Namespace**](https://docs.cstudio.app/de/docs/resource/kubernetes/Core/Namespace)

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `namespace` : Namespace, in dem die benutzerdefinierte Helm-Chart-Ressource bereitgestellt wird
-   `repository` : Repository-URL, in dem das anzupassende Helm-Chart gespeichert ist
-   `chart` : Name des anzupassenden Helm-Charts
-   `version` : Version des anzupassenden Helm-Charts
-   `set` : Key-Value-Einstellungen zur dynamischen Änderung der Standardwerte des Helm-Charts
