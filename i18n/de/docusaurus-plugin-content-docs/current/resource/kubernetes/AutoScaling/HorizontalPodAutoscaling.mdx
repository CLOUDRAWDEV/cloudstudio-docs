## Ressourcenübersicht

Es ist eine Kubernetes-Ressource, die die Anzahl der Pods in einem Deployment, ReplicaSet oder StatefulSet basierend auf der beobachteten CPU-Auslastung automatisch skaliert.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)
-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

### Verbundene Ressourcen

-   [**Deployment**](https://docs.cstudio.app/docs/resource/kubernetes/Apps/Deployment)
-   [**StatefulSet**](https://docs.cstudio.app/docs/resource/kubernetes/Apps/StatefulSet)

## Ressourcen-Einstellwerte

-   `service_name` : HPA Ressourcename
-   `namespace` : Der Namespace, in dem die HPA-Ressource bereitgestellt wird
-   `annotations` : Schlüssel-Wert-Paare, die verwendet werden, um notwendige Informationen im Kubernetes-System anzugeben
-   `labels` : Vom Benutzer festgelegte Werte, um Objekte zu unterscheiden
-   `min_replicas` : Die Mindestanzahl von Pods, die in der HPA konfiguriert werden können - der Standardwert ist 1
-   `max_replicas` : Die Höchstanzahl von Pods, die in der HPA konfiguriert werden können
-   `target_cpu_utilization_percentage` : Das Ziel für die durchschnittliche CPU-Auslastung der Pods (angegeben als Prozentsatz der angeforderten CPU)
-   `scale_target_ref` : Eine Referenz auf die skalierte Ressource
    -   `name` : Der Name der referenzierten Ressource
    -   `kind` : Die Art der referenzierten Ressource. - `Deployment`, `StatefulSet`
