## Ressourcenübersicht

Eine Kubernetes-Ressource, die basierend auf der beobachteten CPU-Auslastung automatisch die Anzahl der Pods von Deployments, ReplicaSets und StatefulSets skaliert.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `namespace` : Namespace, in dem die HPA-Ressource bereitgestellt wird
-   `annotations` : Kubernetes-Systemmetadaten im Key-Value-Format
-   `labels` : Labels zur Identifizierung der HPA-Ressource
-   `min_replicas` : Minimale Anzahl von Pods bei automatischer Skalierung
-   `max_replicas` : Maximale Anzahl von Pods bei automatischer Skalierung
-   `target_cpu_utilization_percentage` : Zielwert für die durchschnittliche CPU-Auslastung der Pods
-   `scale_target_ref` : Referenz auf die zu skalierende Controller-Ressource (Deployment, StatefulSet)
