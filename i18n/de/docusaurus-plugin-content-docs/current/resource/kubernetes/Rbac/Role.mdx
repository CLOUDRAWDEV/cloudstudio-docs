## Ressourcenübersicht

Eine Kubernetes-Ressource zum Erstellen von Rollen, die nur in einem bestimmten Namespace gelten.

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `namespace` : Namespace, in dem die Role-Ressource bereitgestellt wird
-   `annotations` : Key-Value-Metadaten für das Kubernetes-System
-   `labels` : Benutzerdefinierte Labels zur Objektunterscheidung

#### Richtlinienregeln (`rule`)

-   `rule.api_groups` : API-Gruppen, die die erlaubten Ressourcen enthalten
-   `rule.resources` : Liste der Ressourcen, auf die diese Regel angewendet wird
-   `rule.resource_names` : Auswahl einzelner Ressourceninstanzen
-   `rule.verbs` : Verben, die auf alle Ressourcen der Regel angewendet werden – `get`, `list`, `create`, `update`, `patch`, `watch`, `delete`, `deletecollection`
