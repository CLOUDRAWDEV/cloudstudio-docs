## Ressourcenübersicht

Kubernetes-Ressource, die eine Rolle referenziert, die auf Cluster-Ebene und in allen Namespaces auf den Benutzer angewendet wird

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)


### Verbundene Ressourcen

-   [**ClusterRole**](https://docs.cstudio.app/docs/resource/kubernetes/Rbac/ClusterRole)



## Ressourcen-Einstellwerte

-   `service_name` : Name der ClusterRoleBinding-Ressource
-   `annotations` : Key-Value-Paare, die verwendet werden, um die erforderlichen Informationen im Kubernetes-System anzuzeigen
-   `labels` : Der Benutzer kann einen beliebigen Wert festlegen, um das Objekt zu unterscheiden
-   `role_name` : Geben Sie den Namen der Rolle an, die mit dem Subjekt gebunden werden soll
-   `subject` : Festlegung des Subjekts, dem die Rolle zugewiesen werden soll 
    -   `name` : Geben Sie den Namen des Subjekts ein, das gebunden werden soll
    -   `namespace` : Geben Sie das Namespace des Subjekts ein, das gebunden werden soll
    -   `api_group` : API-Gruppe, die die Genehmigungsentscheidung trifft - `rbac.authorization.k8s.io`,`User`,`Group`
    -   `kind` : Wählen Sie den Typ des Subjekts aus, das gebunden werden soll- `ServiceAccount`,`User`,`Group`
