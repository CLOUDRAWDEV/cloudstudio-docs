## Ressourcenübersicht

Ein abstrahiertes Kubernetes-Ressourcenobjekt, das einen einzelnen Einstiegspunkt für Pods bereitstellt und die Kommunikation zwischen diesen Pods verwaltet.

## Ressourcen-Einstellwerte

-   `service_name` : Service Ressourcenname
-   `namespace` : Der Namespace, in dem die Service-Ressource bereitgestellt wird
-   `annotations` : Schlüssel-Wert-Paare, die verwendet werden, um benötigte Informationen im Kubernetes-System anzuzeigen
-   `labels` : Vom Benutzer festgelegte Werte, um Objekte zu unterscheiden
-   `selector` : Der Selector verwendet Schlüssel-Wert-Paare von Labels, um den Dienstverkehr an Pods weiterzuleiten, die mit diesen Labels übereinstimmen
-   `type` : Bestimmt den Typ des Dienstes - `ClusterIP`,`NodePort`,`LoadBalancer`
-   `session_affinity` : Eine Richtlinie, die sicherstellt, dass die Anfragen eines Clients nur an bestimmte Pods weitergeleitet werden - `None`,`clientIP`
-   `port` : Liste der Ports, die vom Service freigegeben werden
    -   `name` : Name der Portkonfiguration
        -   `protocol` : Das IP-Protokoll des Ports - `TCP`,`UDP`
        -   `port` : Die Portnummer, die vom Service freigegeben wird
        -   `target_port` : Die Portnummer, die vom Zielpod des Service zugänglich ist
