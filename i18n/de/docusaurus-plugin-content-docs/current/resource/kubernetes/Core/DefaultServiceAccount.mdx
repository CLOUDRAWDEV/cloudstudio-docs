## Ressourcenübersicht

Ein standardmäßiger ServiceAccount, der Pods im Kubernetes-Cluster den Zugriff auf den API-Server und Cluster-Ressourcen erlaubt.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `namespace` : Namespace, in dem die ServiceAccount-Ressource bereitgestellt wird
-   `annotations` : Kubernetes-Systemmetadaten
-   `labels` : Benutzerdefinierte Labels zur Ressourcenidentifikation und -klassifizierung
-   `secret` : Liste der Secrets, die von Pods mit diesem ServiceAccount referenziert werden können
-   `image_pull_secrets` : Secrets, die Pods beim Image-Pull verwenden
-   `automount_service_account_token` : Automatisches Mounten des ServiceAccount-Tokens im Pod
