## Ressourcenübersicht

Es ist eine Kubernetes-Ressource, die verwendet wird, um Anwendungsstellinformationen zu trennen und in einem Pod an Container zu übergeben.

## Ressourcen-Einstellwerte

-   `service_name` : ConfigMap-Ressourcenname
-   `namespace` : Der Namespace, in dem die ConfigMap-Ressource bereitgestellt wird
-   `annotations` : Key-Value-Paare, die verwendet werden, um Informationen an das Kubernetes-System zu übermitteln
-   `labels` : Vom Benutzer festgelegte Werte, um Objekte zu unterscheiden
-   `data` : Allgemeine Daten als Key-Value-Paare - Wird zum Speichern von Konfigurationsinformationen wie Konfigurationsdateien und Umgebungsvariablen im Textformat verwendet
    -   `data.name` : Der Key-Wert der Daten
    -   `data.value` : Der Value-Wert der Daten
-   `binary_data` : Binärdaten für bestimmte Schlüssel - Wird zum Speichern von Binärdateien oder anderen binären Formaten verwendet
    -   `data.name` : Der Key-Wert der Binärdaten
    -   `data.value` : Der Value-Wert der Binärdaten
