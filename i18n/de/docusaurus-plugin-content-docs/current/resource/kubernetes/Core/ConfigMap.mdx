## Ressourcenübersicht

Eine Kubernetes-Ressource, die Anwendungs-Konfigurationsdaten getrennt speichert und an Container innerhalb von Pods übergibt.

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `namespace` : Namespace, in dem die ConfigMap-Ressource bereitgestellt wird
-   `annotations` : Kubernetes-Systemmetadaten
-   `data` : Speicherung textbasierter Konfigurationsdaten als Key-Value-Paare
-   `labels` : Benutzerdefinierte Labels zur Ressourcenidentifikation und -klassifizierung
-   `binary_data` : Speicherung binärer Daten als Key-Value-Paare
