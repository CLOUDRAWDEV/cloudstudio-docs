## Ressourcen-Einstellwerte

-   `service_name` : ConfigMap-Ressourcenname
-   `annotations` : Wird verwendet, um benötigte Informationen im Kubernetes-System in Form von Schlüssel-Wert-Paaren anzuzeigen
-   `labels` : Wird verwendet, um benutzerdefinierte Werte zur Unterscheidung von Objekten festzulegen
