## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `namespace` : Namespace, in dem die Secret-Ressource bereitgestellt wird
-   `annotations` : Kubernetes-Systemmetadaten
-   `labels` : Benutzerdefinierte Labels zur Secret-Identifikation und -Klassifizierung
-   `type` : Secret-Typ – `Opaque`, `kubernetes.io/basic-auth`, `kubernetes.io/service-account-token`, `kubernetes.io/dockerconfigjson`, `helm.sh/release.v1`, `kubernetes.io/tls`, `kubernetes.io/ssh-auth`, `istio.io/ca-root`
-   `immutable` : Ob Secret-Daten unveränderlich sind
-   `data` : Base64-kodierte Secret-Daten als Key-Value-Paare
