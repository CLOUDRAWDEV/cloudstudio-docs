## Ressourcenübersicht

Es ist eine Kubernetes-Ressource, die zum Speichern wichtiger Informationen in Form von einzelnen Attributen oder groben Elementen wie einer gesamten Datei oder einem JSON-Blob verwendet wird.

## Ressourcen-Einstellwerte

-   `service_name` : Secret-Ressourcenname
-   `namespace` : Der Namespace, in dem die Secret-Ressource bereitgestellt wird
-   `annotations` : Key-Value-Paare, die zur Anzeige von Informationen verwendet werden, die vom Kubernetes-System benötigt werden
-   `labels` : Benutzerdefinierte Werte, die verwendet werden, um Objekte zu unterscheiden
-   `type` : Der Typ des Secrets - `Opaque`,`kubernetes.io/basic-auth`,`kubernetes.io/service-account-token`,`kubernetes.io/dockerconfigjson`
-   `immutable` : Legt fest, dass die in den Sicherheitsgeheimnissen gespeicherten Daten nicht aktualisiert werden können (nur Metadaten des Objekts können geändert werden) - `false`,`true`

-   `data` : Die Daten, die in das Secret aufgenommen werden
    -   `data.name` : Der Name der Daten, die in das Secret aufgenommen werden  - `Opaque`,`kubernetes.io/asic-auth` 
        -   `data.secret` : Der Wert der Daten, die in das Secret aufgenommen werden - `Opaque`,`kubernetes.io/basic-auth`         
    -   `data.name` : Der Name des privaten Docker-Registrierungsservers - `kubernetes.io/dockerconfigjson`
        -   `data.username` : Der Benutzername für die Authentifizierung bei der privaten Docker-Registry - `kubernetes.io/dockerconfigjson`
        -   `data.password` : Das Passwort für die Authentifizierung bei der privaten Docker-Registry - `kubernetes.io/dockerconfigjson`
