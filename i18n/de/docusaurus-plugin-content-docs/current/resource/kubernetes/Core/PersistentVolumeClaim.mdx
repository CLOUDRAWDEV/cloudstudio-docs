## Ressourcenkonfiguration

#### Grundeinstellungen

-   `namespace` : Namespace, in dem die PVC-Ressource erstellt wird
-   `annotations` : Kubernetes-Systemmetadaten
-   `labels` : Benutzerdefinierte Labels zur Identifikation und Klassifizierung der PVC
-   `spec.storage_class_name` : Name der zu verwendenden StorageClass
-   `spec.volume_name` : Name des zu bindenden PersistentVolumes
-   `spec.volume_mode` : Art der Speicherbereitstellung – `Filesystem / Block`
-   `spec.request_storage` : Angeforderte Speicherkapazität
-   `spec.access_modes` : Angeforderte Zugriffsmodi – `ReadOnlyMany, ReadWriteOnce, ReadWriteMany`
-   `wait_until_bound` : Ob gewartet wird, bis die PVC an ein PV gebunden ist
