## Ressourcen-Einstellwerte

-   `service_name` : PersistentVolumeClaim Ressourcenname
-   `namespace` : Der Namespace, in dem die PersistentVolumeClaim-Ressource bereitgestellt wird
-   `annotations` : Key-Value-Paare, die von Kubernetes verwendet werden, um erforderliche Informationen anzuzeigen
-   `labels` : Werte, die vom Benutzer zur Unterscheidung von Objekten beliebig festgelegt werden
-   `spec` : Definiert die spezifische Spezifikation der PersistentVolumeClaim (PVC)
    -   `spec.storage_class_name` : Gibt den Namen der zu verwendenden StorageClass an
    -   `spec.volume_name` : Der Name des PersistentVolume (PV), mit dem das PVC verbunden wird
    -   `spec.request_storage` : Der Speicherplatz, den das PVC vom PV anfordert
    -   `spec.access_modes` : Die gewünschten Zugriffsmodi des PVs (muss mit den Zugriffsmodi des PV übereinstimmen oder sie enthalten) - `ReadOnlyMany`,`ReadWriteMany`,`ReadWriteOnce`
