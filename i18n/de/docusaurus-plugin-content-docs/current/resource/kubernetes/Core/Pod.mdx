## Ressourcenkonfiguration

#### Grundeinstellungen

-   `namespace` : Namespace, in dem die Pod-Ressource bereitgestellt wird
-   `annotations` : Kubernetes-Systemmetadaten
-   `labels` : Benutzerdefinierte Labels zur Pod-Identifikation und -Klassifizierung
-   `pod_security_context` : Sicherheits- und Berechtigungseinstellungen auf Pod-Ebene
-   `init_containers` : Definition von Initialisierungs-Containern vor Ausführung des Haupt-Containers
-   `containers` : Definition der im Pod auszuführenden Container
-   `containers.image` : Container-Image
-   `containers.resources` : CPU-/Speicheranforderungen und -Limits
-   `containers.probe` : Startup-, Liveness- und Readiness-Probes
-   `containers.env` : Definition von Umgebungsvariablen
-   `containers.env_from` : Injektion von Umgebungsvariablen aus ConfigMap/Secret
-   `containers.command` : Auszuführender Container-Befehl
-   `containers.args` : Ausführungsargumente des Containers
-   `containers.port` : Vom Container exponierte Ports
-   `containers.volume_mount` : Volume-Mount-Pfade im Container
-   `volume` : Definition der im Pod verwendeten Volumes
-   `dns_policy` : DNS-Richtlinie
-   `enable_service_links` : Automatische Injektion von Service-Umgebungsvariablen
-   `host_network` : Verwendung des Host-Netzwerks
-   `image_pull_secrets` : Liste der Secrets für den Image-Pull
