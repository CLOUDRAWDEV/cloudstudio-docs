## Ressourcenübersicht

Dies ist eine Kubernetes-Ressource, die Netzwerk-gebundenen Speicher für das Cluster bereitstellt.

## Ressourcen-Einstellwerte

-   `service_name` : PersistentVolume Ressource Name
-   `annotations` : Informationen, die vom Kubernetes-System benötigt werden, werden als Schlüssel-Wert-Paare angezeigt
-   `labels` : Vom Benutzer benutzerdefinierte Werte, um Objekte zu kennzeichnen
-   `spec` : Definiert die spezifischen Spezifikationen des Persistent Volumes
    -   `spec.storage_class_name` : Der Name der zu verwendenden StorageClass angeben
    -   `spec.storage_capacity` : Die zu verwendende Speicherkapazität festlegen
    -   `spec.volume_driver` : Den zu verwendenden Volume-Treiber festlegen
    -   `spec.volume_handle` : Der Bezeichner, der das PV mit der tatsächlichen Speicherressource verbindet
    -   `spec.persistent_volume_reclaim_policy` : Die Volumenrückgewinnungsrichtlinie, wenn es aus einer Anforderung entfernt wird - `retain`,`delete`,`recycle`
    -   `spec.read_only` : Gibt an, ob das Volume im Mount als schreibgeschützt gesetzt werden soll - `false`,`true`
    -   `spec.volume_attributes` : Die Attribute des zu verwendenden Volumes festlegen
    -   `spec.access_modes` : Legt die Arten fest, wie das Volume gemountet werden kann - `ReadOnlyMany`,`ReadWriteOnce`,`ReadWriteMany`
    -   `spec.mount_options` : Zusätzliche Mount-Optionen festlegen
-   `node_stage_secret_ref` : Kubernetes-Geheimnisse, die die Authentifizierung für den Zugriff auf den Speicher enthalten
    -   `node_stage_secret_ref.name` : Name des Geheimnisses festlegen
    -   `node_stage_secret_ref.namespace` : Das Namespace des Geheimnisses festlegen
