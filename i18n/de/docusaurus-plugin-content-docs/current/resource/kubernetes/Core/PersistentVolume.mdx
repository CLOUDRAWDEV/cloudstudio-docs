## Ressourcenkonfiguration

#### Grundeinstellungen

-   `annotations` : Kubernetes-Systemmetadaten
-   `labels` : Benutzerdefinierte Labels zur Identifikation und Klassifizierung von PVs
-   `spec.storage_class_name` : Name der zu verwendenden StorageClass
-   `spec.storage_capacity` : Speicherkapazität
-   `spec.volume_driver` : CSI-basierter Volume-Treiber
-   `spec.volume_handle` : Kennung der tatsächlichen Speicherressource
-   `spec.persistent_volume_reclaim_policy` : Richtlinie zur Volume-Behandlung nach Freigabe des Claims – `Retain / Delete / Recycle`
-   `spec.read_only` : Ob das Volume schreibgeschützt ist
-   `spec.volume_attributes` : Zusätzliche volumespezifische Attribute des Treibers
-   `spec.access_modes` : Zugriffsmodi des Volumes – `ReadOnlyMany, ReadWriteOnce, ReadWriteMany`
-   `spec.mount_options` : Zusätzliche Mount-Optionen
-   `node_stage_secret_ref` : Referenz auf ein Secret mit Authentifizierungsinformationen für den Speicherzugriff
