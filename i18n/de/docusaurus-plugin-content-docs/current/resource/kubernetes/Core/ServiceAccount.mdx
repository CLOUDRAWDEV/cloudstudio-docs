## Ressourcenübersicht

Ein Konto, das Anwendungen und Diensten im Kubernetes-Cluster Berechtigungen für den Zugriff auf Cluster-Ressourcen erteilt.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `namespace` : Namespace, in dem die ServiceAccount-Ressource bereitgestellt wird
-   `annotations` : Kubernetes-Systemmetadaten
-   `labels` : Labels zur Identifikation und Klassifizierung des ServiceAccounts
-   `secret` : Liste der Secrets, die von Pods mit diesem ServiceAccount verwendet werden dürfen
-   `image_pull_secrets` : Secrets, die Pods beim Image-Pull verwenden
-   `automount_service_account_token` : Ob der ServiceAccount-Token automatisch im Pod gemountet wird
