## Ressourcenübersicht

Ein Konto, das Anwendungen und Diensten im Kubernetes-Cluster die Berechtigung erteilt, auf Cluster-Ressourcen zuzugreifen und diese zu nutzen.

## Verwandte Ressourcen

### Übergeordnete Ressourcen

### Verbundene Ressourcen


## Ressourcen-Einstellwerte

-   `service_name` : ServiceAccount Ressourcename
-   `namespace` : Der Namespace, in dem die ServiceAccount-Ressource bereitgestellt wird
-   `annotations` : Key-Value Paare, die verwendet werden, um Informationen an das Kubernetes-System weiterzugeben
-   `labels` : Benutzerspezifizierte Werte zur Unterscheidung von Objekten
-   `secret` : Die Liste der Geheimnisse, die von Pods, die dieses ServiceAccount referenzieren, verwendet werden dürfen
-   `image_pull_secrets` : Die Liste der Geheimnisse im gleichen Namespace, die von Pods, die dieses ServiceAccount referenzieren, zum Abrufen von Images verwendet werden
