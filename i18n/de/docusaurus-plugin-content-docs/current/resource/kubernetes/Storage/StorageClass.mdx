## Ressourcenübersicht

Eine Kubernetes-Ressource zur Definition der dynamischen Speicherbereitstellung in Verbindung mit einem bestimmten Storage-Provisioner.

## Ressourcen-Einstellungswerte

#### Grundeinstellungen

-   `annotations` : Key-Value-Metadaten zur Anzeige erforderlicher Informationen im Kubernetes-System
-   `labels` : Benutzerdefinierte Labels zur Identifikation der StorageClass
-   `storage_provisioner` : Typ des Storage-Provisioners, der den Speicher erstellt
-   `reclaim_policy` : Rückgewinnungsrichtlinie beim Freigeben eines Volumes – `Retain`, `Delete`
-   `volume_binding_mode` : Zeitpunkt der Volume-Bindung und dynamischen Bereitstellung – `Immediate`, `WaitForFirstConsumer`
-   `allow_volume_expansion` : Erlaubnis zur Erweiterung des Volume-Speichers
-   `parameters` : Zusätzliche Parameter für den Storage-Provisioner
-   `mount_options` : Mount-Optionen für dynamisch erstellte PersistentVolumes
