## Ressourcenübersicht

Dies ist eine Kubernetes-Ressource, die das dynamische Speicherprovisioning definiert, das mit einem bestimmten Storage Provisioner zusammenarbeitet

## Verwandte Ressourcen

### Übergeordnete Ressourcen

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)


### Verbundene Ressourcen

-   [**PersistentVolume**](https://docs.cstudio.app/docs/resource/kubernetes/Core/PersistentVolume)


## Ressourcen-Einstellwerte

-   `service_name` : Name der StorageClass-Ressource
-   `annotations` : Key-Value-Paare, die verwendet werden, um die erforderlichen Informationen im Kubernetes-System anzuzeigen
-   `labels` : Der Benutzer kann einen beliebigen Wert festlegen, um das Objekt zu identifizieren
-   `storage_Provisioner` : Typ des Storage-Anbieters
-   `reclaim_policy` : Verwendete Rückgabepolitik – Wenn nicht angegeben, ist der Standardwert Delete
-   `volume_binding_mode` : Wann Volume-Bindung und dynamische Bereitstellung stattfinden müssen - `Immediate`, `WaitForFirstConsumer`
-   `allow_volume_expansion` :Ob die Storage-Klasse die Volumen-Erweiterung erlaubt- `False`, `True`
-   `parameters` : Die Parameter für den Provisioner, der das Volume in einer StorageClass erstellen muss, umfassen typischerweise
-   `mount_options` : Die durch die StorageClass dynamisch erstellten Persistent Volumes haben Mount-Optionen, die festgelegt werden
