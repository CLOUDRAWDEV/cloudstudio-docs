## Ressourcenübersicht

Azure Private DNS bietet einen zuverlässigen und vertrauenswürdigen DNS-Dienst, mit dem Sie die Domainnamen eines virtuellen Netzwerks verwalten und auflösen können, ohne eine benutzerdefinierte DNS-Lösung hinzuzufügen.
Mit privaten DNS-Zonen können Sie anstelle der standardmäßigen von Azure bereitgestellten Namen Ihren eigenen benutzerdefinierten Domainnamen verwenden.
Die in der privaten DNS-Zone enthaltenen Records sind im Internet nicht auflösbar. DNS-Abfragen für private DNS-Zonen funktionieren nur innerhalb des verbundenen virtuellen Netzwerks.

## Ressourcen-Einstellwerte

-   `private_dns_a_record`

    -   `ttl` : DNS-Eintrag Time To Live (TTL) in Sekunden - `0` ~ `2147483647`
    -   `records` : Liste der IPv4-Adressen

-   `private_dns_aaaa_record`

    -   `ttl` : DNS-Eintrag Time To Live (TTL) in Sekunden - `0` ~ `2147483647`
    -   `records` : Liste der IPv6-Adressen

-   `private_dns_cname_record`

    -   `ttl` : DNS-Eintrag Time To Live (TTL) in Sekunden - `0` ~ `2147483647`
    -   `record` : Alias zum Verknüpfen eines Subdomains mit einem anderen Record

-   `private_dns_ptr_record`

    -   `ttl` : DNS-Eintrag Time To Live (TTL) in Sekunden - `0` ~ `2147483647`
    -   `records` : Liste der Domainnamen für den Typ des Pointer Records

-   `private_dns_txt_record`

    -   `ttl` : DNS-Eintrag Time To Live (TTL) in Sekunden - `0` ~ `2147483647`
    -   `records` : Liste der Textdatensatztypen

-   `vnet_link`

    -   `linked_vnet_name` : DNS Record의 Time To Live(초)

-   `tag` : Tags zur Kategorisierung von Ressourcen - maximal 512 Zeichen, `key`:`value`
