## Ressourcenübersicht

Eine Private DNS Zone ist ein Bereich zur Verwaltung von DNS-Einträgen für private Domainnamen, die ausschließlich innerhalb eines Azure Virtual Networks verwendet werden.  
Durch die Verknüpfung mit einem virtuellen Netzwerk (VNet Link) kann die Namensauflösung zwischen internen Ressourcen sicher durchgeführt werden.

## Ressourcenkonfiguration

#### A-Eintrag (`private_dns_a_record`)

-   `private_dns_a_record.ttl` : Time To Live des DNS-Eintrags (Sekunden) - `0` ~ `2147483647`
-   `private_dns_a_record.records` : Liste der IPv4-Adressen

#### AAAA-Eintrag (`private_dns_aaaa_record`)

-   `private_dns_aaaa_record.ttl` : Time To Live des DNS-Eintrags (Sekunden) - `0` ~ `2147483647`
-   `private_dns_aaaa_record.records` : Liste der IPv6-Adressen

#### CNAME-Eintrag (`private_dns_cname_record`)

-   `private_dns_cname_record.ttl` : Time To Live des DNS-Eintrags (Sekunden) - `0` ~ `2147483647`
-   `private_dns_cname_record.record` : Alias zur Verknüpfung einer Subdomain mit einem anderen Eintrag

#### PTR-Eintrag (`private_dns_ptr_record`)

-   `private_dns_ptr_record.ttl` : Time To Live des DNS-Eintrags (Sekunden) - `0` ~ `2147483647`
-   `private_dns_ptr_record.records` : Liste der Domainnamen für Pointer-Eintragstypen

#### TXT-Eintrag (`private_dns_txt_record`)

-   `private_dns_txt_record.ttl` : Time To Live des DNS-Eintrags (Sekunden) - `0` ~ `2147483647`
-   `private_dns_txt_record.records` : Liste der Text-Einträge

#### Virtueller Netzwerk-Link (`vnet_link`)

-   `vnet_link.linked_vnet_name` : Name des virtuellen Netzwerks, das mit der Private DNS Zone verknüpft ist

#### Tags

-   `tag` : Tags zur Kategorisierung der Ressource – maximal 512 Zeichen, `key`:`value`
