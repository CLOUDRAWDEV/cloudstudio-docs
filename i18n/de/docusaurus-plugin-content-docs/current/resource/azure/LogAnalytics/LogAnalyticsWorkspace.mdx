## Ressourcenübersicht

Log Analytics ist ein Tool im Azure Portal, das zum Bearbeiten und Ausführen von Abfragen für die Daten im Azure Monitor-Log-Speicher verwendet wird.
Sie können eine einfache Abfrage erstellen, die einen Satz von Datensätzen zurückgibt, und dann die Funktionen von Log Analytics verwenden, um diese zu sortieren, zu filtern und zu analysieren. Alternativ können Sie auch komplexere Abfragen erstellen, um statistische Analysen durchzuführen und die Ergebnisse in Diagrammen zu visualisieren, um bestimmte Trends zu erkennen.
Ob Sie die Abfrageergebnisse interaktiv bearbeiten oder sie in Verbindung mit anderen Azure Monitor-Funktionen wie Abfragewarnungen oder Arbeitsblatt-Logs verwenden, Log Analytics wird für das Erstellen und Testen von Abfragen genutzt.

## Ressourcen-Einstellwerte

-   `retention_in_days` : Anzahl der Tage, an denen die Daten im Workspace aufbewahrt werden - `30`~ `730`

-   `internet_query_enabled` : Aktivierung der Abfragen über das öffentliche Internet - `true`, `false`

-   `internet_ingestion_enabled` : Aktivierung der Datensammlung über das öffentliche Internet - `true`, `false`

-   `linked_automation_account_names` : Liste der lesbaren Ressourcennamen, die mit dem Workspace verknüpft sind
