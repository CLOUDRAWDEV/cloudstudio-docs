## Ressourcenübersicht

Azure Container Apps Environment ist eine Ressource, die die Netzwerk- und Überwachungsumgebung definiert, in der Azure Container Apps ausgeführt werden.  
Durch die Verknüpfung von Betriebsumgebungen wie einem Log Analytics-Arbeitsbereich, der beim Erstellen und Ausführen von Container Apps verwendet wird, können Protokollsammlung und Monitoring-Konfigurationen einheitlich angewendet werden.
