## Ressourcenübersicht

Azure Backup ist eine **auf Recovery Services basierende Backup-Speichereinheit, die Sicherungsdaten für verschiedene Azure-Dienste wie IaaS-VMs und Azure SQL-Datenbanken speichert und die Wiederherstellung unterstützt**.  
Über Sicherungsrichtlinien können Sicherungsintervalle, -zeiten und Aufbewahrungszeiträume definiert sowie virtuelle Maschinen und Dateifreigaben als geschützte Elemente registriert werden.

## Ressourcenkonfiguration

-   `sku` : Preismodell für die Nutzung des Recovery Services Vault - `Standard`, `RS0`
-   `soft_delete_enabled` : Aktivierung der Soft-Delete-Funktion im Vault - `true`, `false`
-   `tag` : Tags zur Kategorisierung der Ressource

#### VM-Sicherungsrichtlinie (`vm_backup_policy`)

-   `vm_backup_policy.backup_frequency` : Sicherungshäufigkeit - `Daily`, `Weekly`
-   `vm_backup_policy.backup_time` : Zeitpunkt der Sicherung
-   `vm_backup_policy.weekly_backup_days` : Wochentage für die Sicherung - `Sunday`, `Monday`, `Tuesday`, `Wednesday`, `Thursday`, `Friday`, `Saturday`
-   `vm_backup_policy.timezone` : Zeitzone der Sicherungszeit
-   `vm_backup_policy.retention_count` : Anzahl der aufzubewahrenden täglichen Sicherungen - `7` ~ `9999`

#### Geschützte VM (`protected_vm`)

-   `protected_vm.backup_policy_name` : Name der angewendeten Sicherungsrichtlinie

#### Dateifreigabe-Sicherungsrichtlinie (`share_backup_policy`)

-   `share_backup_policy.backup_frequency` : Sicherungshäufigkeit - `Daily`, `Hourly`
-   `share_backup_policy.backup_time` : Zeitpunkt der Sicherung
-   `share_backup_policy.hourly_schedule` : Intervall für stündliche Sicherungen - `4`, `6`, `8`, `12`
-   `share_backup_policy.hourly_duration` : Dauer der stündlichen Sicherungen - `4` ~ `23`
-   `share_backup_policy.timezone` : Zeitzone der Sicherungszeit
-   `share_backup_policy.daily_retention_count` : Anzahl der täglich aufzubewahrenden Sicherungen - `1` ~ `200`
-   `share_backup_policy.enabled_weekly_backup` : Aktivierung der wöchentlichen Sicherung - `true`, `false`
-   `share_backup_policy.weekly_backup_days` : Wochentage für wöchentliche Sicherungen
-   `share_backup_policy.weekly_retention_count` : Anzahl der wöchentlich aufzubewahrenden Sicherungen - `1` ~ `200`

#### Geschützte Dateifreigabe (`protected_share`)

-   `protected_share.source_storage_account_name` : Name des Storage Accounts mit der zu sichernden Dateifreigabe
-   `protected_share.source_share_name` : Name der zu sichernden Dateifreigabe
-   `protected_share.backup_policy_name` : Name der angewendeten Sicherungsrichtlinie
