## Ressourcenübersicht

Azure Backup ist eine cloudbasierte Backup-Lösung von Microsoft, mit der Daten und Anwendungen in der Cloud gesichert und geschützt werden können.
Mit Azure Backup können Daten von On-Premise-Servern, virtuellen Maschinen, die in Azure ausgeführt werden, und anderen Cloud-Diensten gesichert werden.
Azure Backup bietet flexible Backup-Zeitpläne und Aufbewahrungsrichtlinien, sodass Sie die Häufigkeit und Dauer der Aufbewahrung Ihrer Backups anpassen können.
Es bietet auch Funktionen wie inkrementelle Backups, Verschlüsselung und Datenkomprimierung, um die Nutzung des Backup-Speichers zu optimieren und die Backup-Zeit zu reduzieren.

## Ressourcen-Einstellwerte

-   `sku` : Preismodell für die Verwendung von Recovery Services Vault - `Standard`,`RS0`

-   `soft_delete_enabled` : Aktivierung der Soft-Delete-Funktion für das Vault - `true`,`false`

-   `vm_backup_policy`

    -   `backup_frequency` : Häufigkeit der Backups - `Daily`,`Weekly`
    -   `backup_time` : Uhrzeit des Backups
    -   `timezone` : Zeitzone für die Backup-Zeit
    -   `retention_count` : Anzahl der zu behaltenden täglichen Backups - `7`~`9999`

-   `protected_vm`

-   `share_backup_policy`

    -   `backup_frequency` : Häufigkeit der Backups - `Daily`,`Weekly`
    -   `backup_time` : Uhrzeit des Backups
    -   `timezone` : Zeitzone für die Backup-Zeit
    -   `daily_retention_count` : Anzahl der zu behaltenden täglichen Backups - `1`~`200`
    -   `enabled_weekly_backup` : Aktivierung des wöchentlichen Backups

-   `protected_share`

    -   `source_storage_account_name` : Name des Speicherkontos der Dateifreigabe, die gesichert werden soll
    -   `source_share_name` : Name der Dateifreigabe, die gesichert werden soll
    -   `backup_policy_name` : Name der Backup-Politik, die für das Backup angewendet wird

-   `tag` : Tag zur Kategorisierung der Ressource - maximal 512 Zeichen, `key`:`value`
