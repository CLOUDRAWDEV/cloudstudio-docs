## Ressourcenübersicht

Azure Policy Definition bietet eine Möglichkeit, Governance-Richtlinien anzuwenden und zu überwachen. Mit der Richtliniendefinition können Regeln für Ressourceneigenschaften, Tags oder Ressourcengruppen festgelegt werden.
Beispielsweise kann eine Richtlinie erstellt werden, die vorschreibt, dass alle virtuellen Maschinen ein bestimmtes Tag haben oder die Erstellung von virtuellen Maschinen in bestimmten Regionen einschränkt.
Nachdem die Richtliniendefinition erstellt wurde, kann sie auf einen Azure-Bereich wie eine Ressourcengruppe oder ein Abonnement angewendet werden. Dadurch wird die Richtlinie auf alle Ressourcen in diesem Bereich angewendet, und es wird ein Compliance-Bericht bereitgestellt, um sicherzustellen, dass die Ressourcen den Governance-Vorgaben entsprechen.

## Ressourcen-Einstellwerte

-   `type` : Erstellung einer neuen Richtlinie oder Verwendung eines vorhandenen Elements - `Custom`,`BuiltIn`,`NotSpecified`

-   `mode` : Gibt den Ressourcentyp an, auf den die Richtlinie angewendet wird

-   `display_name` : Der Anzeigename der Richtliniendefinition

-   `linked_resource_group_name` : Die MyPage-ID und der Name der Ressourcengruppe, auf die die Richtlinie angewendet wird
