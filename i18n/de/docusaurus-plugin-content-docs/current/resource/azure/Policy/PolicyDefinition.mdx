## Ressourcenübersicht

Azure PolicyDefinition ist eine **Ressource zur Definition von Richtlinien, die Regeln und Bedingungen festlegt, denen Ressourcen entsprechen müssen, sowie die Auswirkungen bei Regelverstößen definiert**.  
Basierend auf dem Richtlinientyp und dem Durchsetzungsmodus ermöglicht sie eine konsistente Verwaltung des Compliance-Status aller Azure-Ressourcen.

## Ressourcenkonfigurationswerte

-   `type` : Typ der Richtliniendefinition – `Custom`, `BuiltIn`, `NotSpecified`
-   `mode` : Modus zur Festlegung der durch die Richtlinie bewerteten Ressourcentypen
-   `display_name` : Anzeigename der Richtliniendefinition
-   `linked_resource_group_name` : Resource Group, auf die die Richtlinie angewendet wird
