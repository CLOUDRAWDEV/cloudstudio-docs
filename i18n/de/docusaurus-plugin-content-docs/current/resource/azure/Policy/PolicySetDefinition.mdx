## Ressourcenübersicht

Azure Policy Set Definition ist eine Sammlung von ein oder mehreren Richtlinien, die zur einfacheren Verwaltung und Zuweisung gruppiert wurden. Sie können eine Richtliniensammlung erstellen, die auf mehrere Ressourcentypen, Ressourcengruppen oder Abonnements angewendet werden kann.
Mit der Definition einer Richtliniensammlung können Sie diese auf Ressourcen oder Ressourcengruppen als eine einzige Aufgabe anwenden, ohne jede Richtlinie einzeln zuzuweisen. Dadurch wird die Verwaltung von Richtlinien vereinfacht und sichergestellt, dass alle Ressourcen den Standards und Richtlinien Ihrer Organisation entsprechen.
Richtliniensammlungsdefinitionen können im JSON-Format definiert werden und Parameter, Metadaten und Richtliniendefinitionen enthalten. Sie können auch auf andere Richtliniensammlungsdefinitionen oder Richtliniendefinitionen verweisen, um komplexe Richtlinien zu erstellen, die auf mehrere Ressourcen und Ressourcengruppen angewendet werden können.

## Ressourcen-Einstellwerte

-   `type` : Neuen Satz von Richtlinien erstellen oder vorhandene verwenden - `Custom`, `BuiltIn`

-   `display_name` : Der angezeigte Name der Richtliniendefinition

-   `included_definition_name` : Die Namen der Richtliniendefinitionen, die in der Richtlinienset-Definition enthalten sind
