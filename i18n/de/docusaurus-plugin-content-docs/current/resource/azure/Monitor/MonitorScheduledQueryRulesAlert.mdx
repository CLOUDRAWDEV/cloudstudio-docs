## Ressourcenübersicht

Azure Monitor Geplante Abfrage-Regel-Warnungen (Scheduled Query Rule Alerts, SQR) sind eine Funktion innerhalb von Azure Monitor, mit der Benutzer Warnungen basierend auf benutzerdefinierten Log-Abfragen erstellen können.
Mit geplanten Abfrage-Regeln (SQR) können Benutzer Abfragen definieren, die gemäß einem festgelegten Zeitplan ausgeführt werden, und dann die Ergebnisse gemäß festgelegten Schwellenwerten oder Kriterien bewerten.
Wenn die Abfrageergebnisse die definierten Kriterien erfüllen, löst die SQR eine Warnung aus, die an verschiedene Ziele wie E-Mail, SMS, Webhooks oder Azure Functions weitergeleitet werden kann.
Die Warnung kann Informationen über die spezifischen Abfrageergebnisse enthalten, die die Warnung ausgelöst haben, sowie relevante Metadaten oder Kontextinformationen.

## Ressourcen-Einstellwerte

-   `linked_application_insights_name` : URI der Ressource, auf der die Abfrage ausgeführt wird

-   `severity` : Schweregrad der Warnung - `0`, ` 1````,  `2` , ```3 `, `4`

-   `frequency` : Häufigkeit, mit der die Warnregel ausgeführt wird - `5`~ ```1440````

-   `time_window` : Zeitraum (in Minuten), in dem Daten für die Abfrage gesammelt werden (Bereich: 5 ~ 2880 Minuten) - `5`, ```2880````

-   `action_group_name` : Name der Aktionsgruppe, auf die die Warnregel angewendet wird

-   `email_subject` : Betreff, der auf alle E-Mails der Aktionsgruppe angewendet wird

-   `custom_webhook_payload` : Benutzerdefinierte Nutzlast, die für alle Webhook-Payloads in der Warnaktion gesendet wird

-   `operator` : Operator zum Vergleichen des Metrik-Werts mit dem Schwellenwert - `Equal`, ` GreaterThan````,  `LessThan````

-   `threshold` : Schwellenwert, der die Warnung auslöst - `0`~ ```10000````

-   `tag` : Tags zur Kategorisierung von Ressourcen - maximal 512 Zeichen, `key`:`value`
