## Ressourcenübersicht

Azure Monitor Metric Alerts ist eine Funktion von Microsoft Azure, die es Benutzern ermöglicht, Warnungen auf der Grundlage von Metriken für Ressourcen in der Cloud zu konfigurieren.
Azure Monitor bietet eine Plattform zur Sammlung, Analyse und Verarbeitung von Telemetriedaten von Azure-Ressourcen und anderen Quellen, einschließlich On-Premises-Umgebungen und anderer Cloud-Anbieter.
Mit Metrik-Warnungen können Benutzer Metriken für Azure-Ressourcen überwachen und Benachrichtigungen erhalten, wenn bestimmte Bedingungen erfüllt sind, wie z. B. das Überschreiten eines festgelegten Schwellenwerts oder plötzliche Aktivitätssteigerungen.
Metrik-Warnungen können für eine Vielzahl von Azure-Ressourcen konfiguriert werden, darunter virtuelle Maschinen, Datenbanken, Speicherkonten und mehr.

## Ressourcen-Einstellwerte

-   `target_resource_name` : Name der Ressource, auf die die Metrik-Warnung angewendet wird

-   `severity` : Schweregrad der Metrik-Warnung - `0`, ` 1````,  `2` , ```3 `, `4`

-   `frequency` : Häufigkeit, mit der die Metrik-Warnung bewertet wird

-   `auto_mitigate` : Automatische Behebung der Metrik-Warnung aktivieren - `true`, ```false````

-   `linked_action_group_name` : Name der Aktionsgruppe, auf die die Warnregel angewendet wird

-   `metric_namespace` : Metrik-Namespace, der überwacht werden soll

-   `criteria`

    -   `metric_name` : Name der zu überwachenden Metrik
    -   `aggregation` : Methode zur Aggregation der Metrik-Werte - `Average`, ` Count````,  `Total` , ```Minimum `, `Maximum`
    -   `operator` : Operator zum Vergleichen des Metrik-Werts mit dem Schwellenwert - `Equals`, ` NotEquals````,  `GreaterThan` , ```GreaterThanOrEqual `, `LessThan`, `LessThanOrEqual`
    -   `threshold` : Schwellenwert, der die Warnung auslöst

-   `tag` : Tags zur Kategorisierung von Ressourcen - maximal 512 Zeichen, `key`:`value`
