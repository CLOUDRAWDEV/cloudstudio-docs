## Ressourcenübersicht

Smart Detection Alert Rules sind eine Funktion von Azure Monitor, die automatisch Probleme bei Azure-Ressourcen erkennt und Warnmeldungen über potenzielle Probleme sendet.
Smart Detection Alert Rules verwenden maschinelles Lernen, um Metriken zur Anwendungsleistung und Anwendungsprotokolle sowie andere Telemetriedaten von Azure-Ressourcen zu analysieren und automatisch Probleme zu erkennen, die den Status oder die Leistung einer Anwendung oder eines Dienstes beeinträchtigen könnten.
Wenn ein Problem erkannt wird, kann die Smart Detection Alert Rule so konfiguriert werden, dass sie eine Warnung auslöst, die über E-Mail, SMS oder andere Kommunikationskanäle gesendet wird.

## Ressourcen-Einstellwerte

-   `linked_application_insights_name` : Name von Application Insights, auf den die Warnregel angewendet wird

-   `severity` : Schweregrad der Warnung, nachdem die in der Warnregel festgelegten Kriterien erfüllt sind - `Sev0`, ` Sev1````,  `Sev2` , ```Sev3 `, `Sev4`

-   `frequency` : Häufigkeit, mit der die Warnregel ausgeführt wird (in Minuten) - `1`, ` 5````,  `15` , ```30 `, `60`

-   `action_group_name` : Name der Aktionsgruppe, auf die die Warnregel angewendet wird

-   `tag` : Tags zur Kategorisierung von Ressourcen - maximal 512 Zeichen,`key`:`value`
