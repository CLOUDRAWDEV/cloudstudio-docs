## Ressourcenübersicht

Azure Monitor Activity Log Alert ist eine Art von Benachrichtigungsdienst in Azure, mit dem Warnungen auf der Grundlage bestimmter Ereignisse oder Änderungen im Azure Activity Log erstellt werden können.
Azure Activity Log Alert bietet ein umfassendes Protokoll aller durchgeführten Aktionen auf Ressourcen innerhalb eines Azure-Abonnements.
Aktivitätsprotokoll-Warnungen können so konfiguriert werden, dass sie Benachrichtigungen senden, wenn bestimmte Bedingungen erfüllt sind, wie z.B. die Erstellung, Änderung oder Löschung von Ressourcen.
Es können auch Warnungen basierend auf bestimmten Fehlermeldungen oder wenn bestimmte Schwellenwerte überschritten werden (z.B. eine hohe Anzahl fehlgeschlagener Anfragen oder plötzliche Traffic-Steigerungen) erstellt werden.

## Ressourcen-Einstellwerte

-   `criteria_category` : Arbeitskategorien zur Filterung - `Administrative`,`Autoscale`,`Policy`,`Recommendation`,`Security`,`ResourceHealth`,`ServiceHealth`

-   `criteria_level` : Schweregradstufe des Ereignisses, das die Aktivitätsprotokoll-Warnung überwachen soll - `Verbose`,`Informational`,`Warning`,`Error`,`Critical`

-   `target_resource_name` : Name der Ressource, die von der Aktivitätsprotokoll-Warnung überwacht wird
-   `criteria_status` : Statuswert des Ereignisses, das die Aktivitätsprotokoll-Warnung überwachen soll - `Started`,`Failed`,`Succeeded`

-   `linked_action_group_name` : Name der Aktionsgruppe, auf die die Warnregel angewendet wird
-   `tag` : Tags zur Kategorisierung von Ressourcen - maximal 512 Zeichen, `key`:`value`
