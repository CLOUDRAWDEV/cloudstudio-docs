## Ressourcenübersicht

Azure Monitor Auto-Scaling ist eine Funktion von Microsoft Azure, die es ermöglicht, Ressourcen basierend auf vordefinierten Regeln und Metriken automatisch zu skalieren.
Durch die Nutzung des Auto-Scaling können Ressourcen wie virtuelle Maschinen, App-Dienste und AKS (Azure Kubernetes Service) Cluster erweitert oder reduziert werden, um den sich ändernden Anforderungen gerecht zu werden und gleichzeitig die Kosten zu optimieren.

## Ressourcen-Einstellwerte

-   `target_resource_name` : Name der Ressource, auf die die Auto-Scaling-Einstellungen angewendet werden sollen

-   `scale_condition`

    -   `min_instance_count` : Minimale Anzahl der Instanzen - `0` ~ `1000`
    -   `max_instance_count` : Maximale Anzahl der Instanzen - `1` ~ `1000`
    -   `default_instance_count` : Standardanzahl der Instanzen, die skaliert werden sollen, wenn keine Ressourcenspezifikationen abgerufen werden können und die aktuelle Kapazität unter der Standardkapazität liegt - `1` ~ `1000`
    -   `schedule_type` : Zeitplanmethode, die auf die Skalierungsoperationen angewendet wird - `start_end_dates`, `repeat_days`
    -   `timezone` : Zeitzone, in der der Zeitplan wirkt
    -   `start_date` : Startdatum des Zeitplans
    -   `end_date` : Enddatum des Zeitplans

-   `tag` : Tags zur Kategorisierung von Ressourcen - maximal 512 Zeichen, `key`:`value`
