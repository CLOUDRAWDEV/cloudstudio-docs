## Ressourcenübersicht

Die Azure Monitor-Aktionsgruppe ist eine Funktion von Microsoft Azure, mit der eine Reihe von Aktionen definiert werden kann, die ausgeführt werden sollen, wenn eine Warnung ausgelöst wird. Eine Aktionsgruppe kann als Sammlung von Benachrichtigungseinstellungen und Aktionen betrachtet werden, die mit einer bestimmten Warnung verbunden sind.
Wenn eine Warnung ausgelöst wird, kann Azure Monitor automatisch eine Reihe von Aktionen ausführen, die in der verbundenen Aktionsgruppe definiert sind.
Die Aktionsgruppe kann so konfiguriert werden, dass verschiedene Arten von Aktionen ausgeführt werden, wie z.B. das Senden einer E-Mail, das Senden einer SMS, das Tätigen eines Anrufs oder das Auslösen eines Webhooks.
Es können mehrere Aktionen angegeben werden, die parallel oder nacheinander ausgeführt werden, und es können Eskalationsrichtlinien festgelegt werden, um sicherzustellen, dass die Warnung angemessen behandelt wird.

## Ressourcen-Einstellwerte

-   `short_name` : Name der Aktionsgruppe, der in E-Mail- und SMS-Benachrichtigungen angezeigt wird

-   `enabled` : Aktivierung der Aktionsgruppe

-   `email`

    -   `email_address` : E-Mail-Adresse, an die die Benachrichtigungen gesendet werden
    -   `use_common_alert_schema` : Aktivierung oder Deaktivierung des gemeinsamen Warnschemas - `true`, `false`

-   `sms`

    -   `country_code` : Ländervorwahl für die SMS-Benachrichtigung
    -   `phone_number` : Telefonnummer, an die die Benachrichtigungen gesendet werden

-   `tag` : Tags zur Kategorisierung von Ressourcen - maximal 512 Zeichen, `key`:`value`
