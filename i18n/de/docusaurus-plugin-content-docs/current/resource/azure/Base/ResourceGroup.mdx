## Ressourcenübersicht

Eine Ressourcengruppe ist ein Container, der Ressourcen für eine Azure-Lösung enthält.
Eine Ressourcengruppe kann entweder alle Ressourcen einer Lösung oder nur die Ressourcen enthalten, die Sie als Gruppe verwalten möchten.
Entscheiden Sie, wie Sie Ressourcen basierend auf den Anforderungen Ihrer Organisation der Ressourcengruppe zuweisen.
Normalerweise fügen Sie Ressourcen zu einer Ressourcengruppe hinzu, die denselben Lebenszyklus teilen, um eine einfache Bereitstellung, Aktualisierung und Löschung als Gruppe zu ermöglichen.
