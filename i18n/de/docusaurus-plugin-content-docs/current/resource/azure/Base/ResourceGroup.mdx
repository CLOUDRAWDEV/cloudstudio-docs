## Ressourcenübersicht

Eine Ressourcengruppe ist ein Container, der zusammengehörige Ressourcen für eine Azure-Lösung enthält.
Eine Ressourcengruppe kann alle Ressourcen der Lösung enthalten oder nur die Ressourcen, die Sie als Gruppe verwalten möchten.
Wie Ressourcen Ressourcengruppen zugewiesen werden, entscheiden Sie anhand dessen, was am besten zu Ihrer Organisation passt.
In der Regel fügt man Ressourcen mit demselben Lebenszyklus derselben Ressourcengruppe hinzu, damit sie sich leicht gemeinsam bereitstellen, aktualisieren und als Gruppe löschen lassen.
