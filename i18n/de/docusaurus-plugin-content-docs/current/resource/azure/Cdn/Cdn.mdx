## Ressourcenübersicht

CDN (Content Delivery Network) ist ein verteiltes Netzwerk von Servern, das Webinhalte effizient an Benutzer liefert.  
CDN speichert gecachte Inhalte auf Edge-Servern an POP (Point-of-Presence)-Standorten in der Nähe des Endbenutzers, um die Latenz zu minimieren.

Azure CDN bietet Entwicklern eine globale Lösung, die Inhalte an physisch strategisch platzierte Knoten weltweit cached, um hochbandbreitige Inhalte schnell an Benutzer zu liefern.

Azure CDN verwendet CDN-POPs und verschiedene Netzwerkoptimierungen, um nicht gecachte dynamische Inhalte zu beschleunigen, wie beispielsweise die Routenoptimierung, die das BGP (Border Gateway Protocol) umgeht.

## Ressourcen-Einstellwerte

-   `sku` : Preisstufe des CDN-Profils

-   `cdn_profile_location` : Name des CDN-Endpunkts

-   `cdn_endpoint` : App Service oder Speicherkonto, für das CDN aktiviert werden soll
    -   `cdn_endpoint_name` : App Service oder Speicherkonto, für das CDN aktiviert werden soll
    -   `is_http_allowed` : Ob HTTP-Verkehr für den CDN-Endpunkt erlaubt ist
    -   `is_https_allowed` : Ob HTTPS-Verkehr für den CDN-Endpunkt erlaubt ist
    -   `type` : Ressourcentyp, der mit dem CDN-Endpunkt verbunden ist
    -   `host_name` : Domainname der Ressource, die mit dem CDN-Endpunkt verbunden wird
-   `tag` : Tags zur Kategorisierung von Ressourcen - maximal 512 Zeichen, `key`:`value`
