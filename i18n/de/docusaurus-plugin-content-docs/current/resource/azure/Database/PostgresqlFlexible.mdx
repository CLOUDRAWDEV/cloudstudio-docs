## Ressourcenübersicht

Azure PostgreSQL Flexible Server ist ein relationaler Datenbankdienst, der auf der Open-Source-Datenbank-Engine PostgreSQL basiert.

## Ressourcenkonfiguration

#### Grundeinstellungen

-   `version` : Zu verwendende PostgreSQL-Version – `11`, `12`, `13`, `14`
-   `sku_name` : Name der PostgreSQL-Preisleistungsstufe, Kombination aus Tier + Compute-Generation + Anzahl der Kerne
-   `storage_mb` : Maximale Speicherkapazität des PostgreSQL Flexible Servers (MB)
-   `admin_username` : Administrator-Benutzername des Servers bei Creation Mode `default`, alphanumerisch, keine reservierten Wörter, `1` ~ `16` Zeichen
-   `admin_password` : Administrator-Anmeldekennwort des Servers bei Creation Mode `default`, muss 3 von Kleinbuchstaben/Großbuchstaben/Zahlen/Sonderzeichen enthalten, darf nicht mehr als 3 aufeinanderfolgende alphanumerische Zeichen des Benutzernamens enthalten, `8` ~ `128` Zeichen
-   `availability_zone` : Festlegung der Verfügbarkeitszone. Mögliche Werte sind `1`, `2`, `3` – `1` ~ `3`
-   `enable_high_availability` : Aktivierung der Hochverfügbarkeit für den PostgreSQL Flexible Server – `true`, `false`
-   `high_availability_mode` : Hochverfügbarkeitsmodus des PostgreSQL Flexible Servers – `SameZone`, `ZoneRedundant`
-   `standby_availability_zone` : Verfügbarkeitszone des Standby-Servers. Mögliche Werte sind `1`, `2`, `3`. Darf nicht mit der primären Zone identisch sein – `1` ~ `3`
-   `backup_retention_days` : Anzahl der Tage für die Aufbewahrung von Backups des PostgreSQL Flexible Servers – mögliche Werte `1` ~ `35`, Standard `7` ~ `35`
-   `geo_redundant_backup_enabled` : Aktivierung der georedundanten Sicherung – `true`, `false`
-   `public_network_access_enabled` : Zulassen des öffentlichen Netzwerkzugriffs auf den Server – `true`, `false`
-   `delegated_subnet_name` : Name des Subnetzes für die Delegierung des virtuellen Netzwerks
-   `private_dns_zone_name` : Private DNS-Zone zur Erstellung des PostgreSQL Flexible Servers

#### Serverkonfiguration (`configuration`)

-   `configuration.name` : Name des PostgreSQL-Server-Parameters
-   `configuration.param_value` : Wert der PostgreSQL-Flexible-Server-Konfiguration

#### Datenbank (`database`)

-   `database.charset` : Zeichensatz der PostgreSQL-Datenbank
-   `database.collation` : Sortierreihenfolge (Collation) der PostgreSQL-Datenbank

#### Firewall-Regeln (`firewall_rule`)

-   `firewall_rule.start_ip_address` : Start-IP-Adresse der Firewall-Regel
-   `firewall_rule.end_ip_address` : End-IP-Adresse der Firewall-Regel

#### Tags

-   `tag` : Tags zur Kategorisierung der Ressource – maximal 512 Zeichen, `key`:`value`
