## Ressourcenübersicht

Azure Database for PostgreSQL Flexible Server ist ein skalierbarer, vollständig verwalteter Open-Source-Beziehungsdatenbankdienst von Azure, der eine flexible Serverarchitektur bietet.
Er wurde entwickelt, um verschiedene Workloads und Anwendungen zu unterstützen, die mehr Kontrolle über die PostgreSQL-Umgebung erfordern.
Mit Flexible Server können Kunden aus verschiedenen Rechen- und Speicheroptionen wählen, um spezifische Anforderungen zu erfüllen.
Es unterstützt sowohl Einzelnutzer- als auch Hochverfügbarkeitskonfigurationen und bietet mehrere Optionen für Backups und Disaster Recovery.

## Ressourcen-Einstellwerte

-   `version` : Verwendete PostgreSQL-Version - `11`, `12`, `13`, `14`

-   `sku_name` : PostgreSQL Preisstufenkombination, Tier + Rechengeneration + Kernanzahl - `azurePostgresqlFlexibleSku`

-   `storage_mb` : Maximale Kapazität des PostgreSQL Flexible Servers (MB) - `storageGB`

-   `admin_username` : Admin-Benutzername des Servers im Standardmodus

-   `admin_password` : Admin-Login-Passwort des Servers im Standardmodus

-   `availability_zone` : Verfügbarkeitszone angeben. Mögliche Werte sind 1, 2, 3. - `1` ~ `3`

-   `enable_high_availability` : Aktivierung der Hochverfügbarkeit für PostgreSQL Flexible Server - `true` , `false`

-   `backup_retention_days` : Aufbewahrungsdauer für Backups des MySQL Flexible Servers. Mögliche Werte sind 1–35 Tage. - `1` ~ `35`

-   `geo_redundant_backup_enabled` - `true` , `false`

-   `public_network_access_enabled` : Öffentlichen Netzwerkzugriff für den Server zulassen - `true` , `false`

-   `configuration`

    -   `name` : Name der PostgreSQL Flexible Server-Konfiguration
    -   `param_value` : Wert der PostgreSQL Flexible Server-Konfiguration

-   `database`

    -   `charset` : Zeichensatz der PostgreSQL-Datenbank - `azurePostgresqlChartSet`
    -   `collation` : Sortierreihenfolge der PostgreSQL-Datenbank - `azurePostgresqlFlexibleCol`

-   `firewall_rule`

    -   `start_ip_address` : Start-IP-Adresse, die mit der Firewall-Regel verbunden ist
    -   `end_ip_address` : End-IP-Adresse, die mit der Firewall-Regel verbunden ist

-   `tag` : Tag zum Kategorisieren der Ressourcen - maximal 512 Zeichen, `key`:`value`
