## Ressourcenübersicht

Azure SQL Database ist ein vollständig verwalteter relationaler Datenbankdienst, der auf der weit verbreiteten Microsoft SQL Server-Engine basiert und von Microsoft Azure bereitgestellt wird.
Ohne die Notwendigkeit, Hardware- oder Software-Infrastrukturen zu verwalten, können Sie SQL Server-Datenbanken in der Cloud erstellen und verwalten.
Mit Azure SQL Database können Sie Funktionen wie automatische Patches, Backups, Hochverfügbarkeit und Notfallwiederherstellung nutzen.
Außerdem bietet es Funktionen wie intelligente Leistungsüberwachung, automatische Anpassung und erweiterte Sicherheitsfunktionen, um die Leistung der Datenbank zu optimieren und wichtige Daten zu schützen.

## Ressourcen-Einstellwerte

-   `included_mssql_server_name` : Name des Microsoft SQL Servers, auf dem die Datenbank erstellt wird

-   `sku_name` : Administrator-Benutzername des Servers
-   `max_size_gb` : Maximale Datenbankgröße (GB) - `1` ~ `1024`
-   `collation` : Datenbank-Sortierreihenfolge in Microsoft SQL - `azureMssqlCol`
-   `license_type` : Lizenztyp, der auf die Datenbank angewendet werden soll - `LicenseIncluded` , `BasePrice`
-   `read_scale` : Aktivierung der Funktion zum Offloading von Lese-Workloads unter Verwendung der Rechenkapazität einer schreibgeschützten Replik - `true` , `false`
-   `zone_redundant` : Aktivierung der Bereichsredundanz für Wartungsaufgaben der Datenbank - `true` , `false`

-   `auditing_policy` : Name der Überwachungsrichtlinie

    -   `database_name` : Name der Datenbank, auf die die Überwachungsrichtlinie angewendet wird
    -   `enable_storage_destination` : Aktivierung des Storage-Kontos - `true` ~ `false`
    -   `enable_log_analytics_destination` : Aktivierung der Überwachungsrichtlinie mit Log Analytics Workspace - `true` , `false`

-   `tag` :Tags zur Kategorisierung von Ressourcen - maximal 512 Zeichen, `key`:`value`
