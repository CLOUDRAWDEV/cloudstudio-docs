## Ressourcenkonfiguration

#### Grundeinstellungen

-   `version` : Zu verwendende MySQL-Version – `5.7`, `8.0.21`
-   `sku_name` : Name der MySQL-Preis-/Leistungsstufe, bestehend aus Tier + Compute-Generation + Anzahl der Kerne
-   `storage_gb` : Speicherkapazität des MySQL-Servers (GB)
-   `iops` : Speicher-IOPS des MySQL Flexible Servers – `360` ~ `20000`
-   `admin_username` : Administrator-Benutzername des Servers, wenn der Erstellungsmodus `default` ist; alphanumerisch, keine reservierten Wörter, `1` ~ `16` Zeichen
-   `admin_password` : Administrator-Anmeldekennwort des Servers, wenn der Erstellungsmodus `default` ist; muss 3 von 4 Zeichentypen (Kleinbuchstaben, Großbuchstaben, Zahlen, Sonderzeichen) enthalten; darf keine 3 oder mehr aufeinanderfolgenden alphanumerischen Zeichen aus dem Anmeldenamen enthalten; `8` ~ `128` Zeichen
-   `auto_grow_enabled` : Aktivierung der automatischen Speichererweiterung – `true`, `false`
-   `availability_zone` : Festlegung der Verfügbarkeitszone. Mögliche Werte sind `1`, `2`, `3` – `1` ~ `3`
-   `enable_high_availability` : Aktivierung der Hochverfügbarkeit für den MySQL Flexible Server – `true`, `false`
-   `high_availability_mode` : Hochverfügbarkeitsmodus des MySQL Flexible Servers – `SameZone`, `ZoneRedundant`
-   `standby_availability_zone` : Festlegung der Verfügbarkeitszone für den Standby-Server. Mögliche Werte sind `1`, `2`, `3`. Darf nicht mit der primären Verfügbarkeitszone identisch sein – `1` ~ `3`
-   `backup_retention_days` : Aufbewahrungsdauer der Backups des MySQL Flexible Servers in Tagen. Zulässige Werte sind `1` ~ `35` – `1` ~ `35`
-   `public_network_access_enabled` : Zulassen des öffentlichen Netzwerkzugriffs auf den Server – `true`, `false`
-   `delegated_subnet_name` : Name des Subnetzes für die Delegation des virtuellen Netzwerks
-   `private_dns_zone_name` : Private DNS-Zone zur Erstellung des MySQL Flexible Servers

#### Serverkonfiguration (`configuration`)

-   `configuration.param_value` : Wert der Konfigurationsparameter des MySQL Flexible Servers

#### Datenbank (`database`)

-   `database.charset` : Zeichensatz der MySQL-Datenbank
-   `database.collation` : Sortierreihenfolge (Collation) der MySQL-Datenbank

#### Firewall-Regeln (`firewall_rule`)

-   `firewall_rule.start_ip_address` : Start-IP-Adresse der Firewall-Regel
-   `firewall_rule.end_ip_address` : End-IP-Adresse der Firewall-Regel

#### Tags

-   `tag` : Tags zur Kategorisierung der Ressource – maximal 512 Zeichen, `key`:`value`
