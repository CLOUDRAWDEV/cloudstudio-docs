## Ressourcenübersicht

Azure Database for MySQL - Flexible Server ist ein vollständig verwalteter, produktionsbereiter Datenbankdienst, der darauf ausgelegt ist, detailliertere Steuerung und Flexibilität bei Datenbankverwaltungsfunktionen und Konfigurationseinstellungen bereitzustellen.
Flexible Server eignet sich am besten für.

-   Einfachere Bereitstellung von Funktionen wie Backups, Hochverfügbarkeit, Sicherheit und Monitoring, grundlegender Skalierung und geringem Verwaltungsaufwand für Datenbanken
-   Entwicklung von Anwendungen, die die Community-Version von MySQL mit besserer Kontrolle und Anpassung erfordern
-   Produktionsworkloads mit hoher Verfügbarkeit in derselben Region, zonenübergreifender Redundanz und verwalteten Wartungsfenstern
-   Vereinfachte Entwicklungsumgebungen
-   Unternehmenssicherheit, Compliance und Datenschutz

## Ressourcen-Einstellwerte

-   `version` : Verwendete MySQL-Version - `5.7`, ``8.0.21`

-   `sku_name` : Preisstufenkombination für MySQL, Tier + Computergeneration + Anzahl der Kerne - `azureMysqlFlexibleSku`

-   `storage_gb` : MySQL Server-Speichergröße (GB) - `storageGB`

-   `iops` : Storage IOPS für MySQL Flexible Server - `360` ~ `20000`

-   `admin_username` : Administrator-Benutzername des Servers im Standard-Erstellungsmodus

-   `admin_password` : Administrator-Anmeldepasswort des Servers im Standard-Erstellungsmodus

-   `auto_grow_enabled` : Aktivierung der automatischen Speichererweiterung - `true` , `false`

-   `availability_zone` : Festlegung der Verfügbarkeitszone. Mögliche Werte sind 1, 2, 3. - `1` ~ `3`

-   `enable_high_availability` : Aktivierung der Hochverfügbarkeit für MySQL Flexible Server - `true` , `false`

-   `high_availability_mode` :Modus der Hochverfügbarkeit für MySQL Flexible Server - `SameZone` , `ZoneRedundant`

-   `standby_availability_zone` : Festlegung der Verfügbarkeitszone des Standby-Servers. Mögliche Werte sind 1, 2, 3. Es kann nicht mit der Verfügbarkeitszone übereinstimmen. - `1` ~ `3`

-   `backup_retention_days` : Aufbewahrungsdauer für Backups im MySQL Flexible Server. Mögliche Werte sind 1-35 Tage. - `1` ~ `35`

-   `public_network_access_enabled` : Erlauben Sie den öffentlichen Netzwerkzugriff auf den Server - `true` , `false`

-   `configuration`

    -   `name` : Name der MySQL Flexible Server-Konfiguration
    -   `param_value` : Wert der MySQL Flexible Server-Konfiguration

-   `database`

    -   `charset` : Zeichensatz der MySQL-Datenbank - `azureMysqlChartSet`
    -   `collation` : Kollation der Microsoft SQL-Datenbank - `azureMysqlCol`

-   `firewall_rule`
    -   `start_ip_address` : Start-IP-Adresse, die mit der Firewall-Regel verbunden ist
    -   `end_ip_address` : End-IP-Adresse, die mit der Firewall-Regel verbunden ist
-   `tag` : Tag, um Ressourcen in Kategorien zu klassifizieren - maximal 512 Zeichen, `key`:`value`
