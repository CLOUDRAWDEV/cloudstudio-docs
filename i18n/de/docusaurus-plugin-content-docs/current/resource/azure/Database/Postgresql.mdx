## Ressourcenübersicht

Azure Database for PostgreSQL ist ein vollständig verwalteter relationaler Datenbankdienst, der auf der weit verbreiteten Open-Source-PostgreSQL-Datenbank-Engine basiert und von Microsoft Azure bereitgestellt wird.
Mit Azure Database for PostgreSQL können Benutzer PostgreSQL-Datenbanken einfach in der Cloud bereitstellen, verwalten und skalieren, ohne sich um die zugrunde liegende Infrastruktur kümmern zu müssen.
Die Nutzung von Azure Database for PostgreSQL ermöglicht es Microsoft, Aufgaben wie das Anwenden von Patches, Backups und Überwachung zu übernehmen, sodass Datenbanken mit minimalem Verwaltungsaufwand erstellt und verwaltet werden können.
Zusätzlich können Funktionen wie Hochverfügbarkeit, automatische Backups und Wiederherstellung zu einem bestimmten Zeitpunkt genutzt werden.

## Ressourcen-Einstellwerte

-   `version` : Verwendete PostgreSQL-Version - `9.5`, ` 9.6`,  `10` , `10.0 `, ` 10.2`,  `11`

-   `sku_name` : PostgreSQL Preisstrukturname, Tier + Rechengeneration + Kombination der Kernanzahl - `azureDatabaseSku`

-   `storage_mb` : Maximale Kapazität des PostgreSQL-Servers (MB) - `5120`~`16777216`

-   `create_mode` : IOPS für den Speicher des PostgreSQL Flexible Servers - `Default`,`Replica`,`GeoRestore`,`PointInTimeRestore`

-   `admin_username` : Administratorbenutzername des Servers im Standard-Erstellungsmodus

-   `admin_password` : Administratorpasswort des Servers im Standard-Erstellungsmodus

-   `public_network_access_enabled` : Öffentlichen Netzwerkzugriff auf den Server zulassen - `true` , `false`

-   `ssl_enforcement_enabled` : Verschlüsselte Verbindung (SSL) aktivieren - `true` , `false`

-   `minimal_tls_version` : Minimale unterstützte TLS-Version auf dem Server - `TLS1_2` , `TLS1_1` , `TLS1_0` , `TLSEnforcementDisabled`

-   `database`

    -   `charset` : Zeichensatz der PostgreSQL-Datenbank - `azurePostgresqlChartSet`
    -   `collation` : Sortierung der PostgreSQL-Datenbank - `azurePostgresqlCol`

-   `firewall_rule`

    -   `start_ip_address` : Start-IP-Adresse in der Firewall-Regel
    -   `end_ip_address` : End-IP-Adresse in der Firewall-Regel

-   `tag` : Tags zur Kategorisierung von Ressourcen - maximal 512 Zeichen, `key`:`value`
