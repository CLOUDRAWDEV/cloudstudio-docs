## Ressourcenübersicht

Azure Application Gateway ist ein Web-Traffic-Load-Balancer, der dazu dient, den Traffic für Webanwendungen zu verwalten.
Traditionelle Load-Balancer arbeiten auf der Transportebene (OSI-Schicht 4 – TCP und UDP) und leiten den Traffic basierend auf der Quell-IP-Adresse und dem Port an eine Ziel-IP-Adresse und einen Port weiter.
Der Application Gateway kann Routing-Entscheidungen basierend auf zusätzlichen Eigenschaften von HTTP-Anfragen treffen, wie zum Beispiel dem URI-Pfad oder den Host-Headern. Beispielsweise kann der Traffic basierend auf der eingehenden URL weitergeleitet werden.
Wenn die URL beispielsweise /images enthält, kann der Traffic zu einem bestimmten Satz von Servern (auch als Pools bezeichnet), die für Bilder konfiguriert sind, weitergeleitet werden. Wenn die URL /video enthält, wird der Traffic zu einem anderen Pool weitergeleitet, der für Videos optimiert ist.

## Ressourcen-Einstellwerte

-   `included_subnet_name` : Name des VNet, in dem das Application Gateway bereitgestellt wird

-   `linked_waf_policy_name` : Name der Web Application Firewall-Policy, die verbunden werden soll

-   `sku_tier` : Preismodellstufe für die Nutzung des Application Gateway

-   `sku_name` : Name des Preismodells für die Nutzung des Application Gateway

-   `sku_capacity` : Preismodellkapazität für die Nutzung des Application Gateway - `1` ~ `32`

-   `gateway_ip_config_name` : Name der IP-Konfiguration des Gateways

-   `frontend_ip_address_type` : Methode der Zuweisung einer öffentlichen IP-Adresse - `Both`, `Private`, `Public`

-   `public_frontend_ip_configuration`

    -   `ip_config_name` : Name der Frontend-IP-Konfiguration
    -   `linked_public_ip_name` : Name der öffentlichen IP-Adresse, die verbunden werden soll

-   `private_frontend_ip_configuration`

    -   `ip_config_name` : Name der privaten IP-Konfiguration
    -   `private_ip_address_allocation` : Zuweisungsmethode der privaten IP-Adresse - `Static`, `Dynamic`
    -   `private_ip_address` : Adresse der privaten IP-Adresse

-   `backend_pool_name` : Liste der Namen der Backend-Adress-Pools, mit denen das Application Gateway verbunden werden soll

-   `http_listener`
    -   `frontend_ip_config` : Verwendete Frontend-IP-Konfiguration - `Public`, `Private`
    -   `frontend_port_name` : Name des zu verwendenden Frontend-Ports
    -   `frontend_port` : Portnummer des Frontend-Ports - `1`~ `65502`
    -   `protocol` : Protokoll zwischen dem Client und dem Application Gateway - `Http`, `Https`
-   `backend_http_settings`
    -   `protocol` : Protokoll, das beim Weiterleiten von Anfragen an den Backend-Server verwendet wird - `Http`, `Https`
    -   `port` : Zu verwendender Frontend-Port - `1`~ `65535`
    -   `cookie_based_affinity` : Aktivierung der cookie-basierten Affinität für die Verarbeitung nachfolgender Anfragen - `Enabled`, `Disabled`
    -   `request_timeout` : Timeout für Anfragen (in Sekunden) - `1`~ `86400`
-   `request_routing_rule`

    -   `rule_type` : Routing-Regeltyp zur Definition des Backend-Serverpools, an den Anfragen weitergeleitet werden - `Basic`, `PathBasedRouting`
    -   `http_listener_name` : Name des HTTP-Listeners, mit dem die Regel verbunden ist
    -   `backend_pool_name` : Name des Backend-Adresspools, mit dem die Regel verbunden ist
    -   `backend_http_settings_name` : Name der Backend-HTTP-Einstellungen, mit denen die Regel verbunden ist
    -   `priority` : Priorität der Routing-Regel

-   `tag` : Tag zur Kategorisierung von Ressourcen - maximal 512 Zeichen, `key`:`value`
