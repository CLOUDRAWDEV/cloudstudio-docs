## Ressourcenübersicht

Azure Traffic Manager ist ein cloudbasierter Traffic-Management-Dienst von Microsoft Azure, der es Benutzern ermöglicht, den eingehenden Traffic von mehreren Endpunkten zu steuern und zu verteilen, einschließlich Azure-VMs, Cloud-Diensten, Web-Apps und sogar On-Premises-Endpunkten. 
Mit Traffic Manager können Benutzer den Traffic automatisch zu den besten verfügbaren Endpunkten weiterleiten, basierend auf verschiedenen Routing-Methoden wie Priorität, Leistung, geografischer Lage oder Round Robin, um die Verfügbarkeit, Leistung und Resilienz von Anwendungen zu verbessern.

## Ressourcen-Einstellwerte

-   `traffic_routing_method`

    -   `description` : Routing-Methoden zur Weiterleitung von Client-Anfragen an den entsprechenden Service-Endpunkt -`Geographic`, `MultiValue`, `Performance`, `Priority`, `Subnet`, `Weighted`

-   `relative_domain_name` : Der Domain-Name, den Traffic Manager verwenden soll
-   `ttl` : Time To Live-Wert des Profils, der von lokalen DNS-Benutzern verwendet wird - `0`~ `2147483647`
-   `endpoint_monitor_setting`

    -   `protocol` : Das Protokoll, das für das Monitoring verwendet werden soll -`HTTP`, `HTTPS`, `TCP`
    -   `port` : Die Portnummer, die für das Monitoring verwendet werden soll - `0`~ `65535`
    -   `path` : Der Pfad, der für das Monitoring verwendet wird, wenn das Protokoll HTTP oder HTTPS ist

-   `azure_endpoint`
-   `nested_endpoint`
-   `nested_endpoint`
-   `external_endpoint`
    -   `target_name` : Name der Zielressource, mit der der Endpunkt verbunden werden soll - Je nach Typ kann dies der Name der Ressource oder eine Domain sein
    -   `weight` : Die Menge des Traffics, die an den Endpunkt verteilt wird - `1`~ `1000`
    -   `priority` : Die Priorität des Endpunkts
    -   `endpoint_location` : Der Azure-Standort des Endpunkts
-   `tag` : Ein Tag zur Kategorisierung der Ressource - maximal 512 Zeichen, `key`:`value`
