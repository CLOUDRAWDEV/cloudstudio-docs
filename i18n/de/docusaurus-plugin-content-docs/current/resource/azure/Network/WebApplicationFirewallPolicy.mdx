## Ressourcenübersicht

Azure WAF (Web Application Firewall) policy ist eine Sicherheitsfunktion von Microsoft Azure, die hilft, Webanwendungen vor verschiedenen Angriffen wie XSS (Cross-Site Scripting), SQL-Injektion und anderen bekannten oder unbekannten Exploits zu schützen.
WAF-Richtlinien sind eine Sammlung von Regeln, die festlegen, wie der Datenverkehr durch den WAF gefiltert wird. Mit ihnen kann eine Liste von erlaubten und blockierten Verkehrszielen definiert sowie benutzerdefinierte Regeln und Ausnahmen für bestimmte Verkehrsströme konfiguriert werden.
WAF-Richtlinien können auf einzelne Webanwendungen oder auf das gesamte Application Gateway angewendet werden.

## Ressourcen-Einstellwerte

-   `managed_rule_set`

    -   `type` : Typen von Regelsets zum Schutz vor Schwachstellen - `OWASP`, `Microsoft_BotManagerRuleSet`
    -   `version` : Version des Regelsets

-   `managed_rule_group`
    -   `type` : Typ des Regelsets - `OWASP`, `Microsoft_BotManagerRuleSet`
    -   `rule_group_name` : Name der zu verwendenden Regelgruppe
    -   `disabled_rules` : Liste der deaktivierten Regel-IDs
-   `exclusion`
    -   `match_variable` : Die Variable, mit der verglichen werden muss, wie z. B. Abfragezeichenfolge oder Anforderungsmethode -`RequestArgNames`, `RequestCookieNames`, `RequestHeaderNames`
    -   `selector` : Der Wert, mit dem der Wert der Übereinstimmungsvariable verglichen wird
    -   `selector_match_operator` : Der Operator, der verwendet wird, um die Übereinstimmung zu bewerten -`Contains`, `EndsWith`, `Equals`, `EqualsAny`, `StartsWith`
-   `tag` : Ein Tag zur Kategorisierung der Ressource - maximal 512 Zeichen, `key`:`value`
