## Ressourcenübersicht

Eine Network Interface ist eine Netzwerkverbindungsressource, die es einer Virtual Machine ermöglicht, mit Ressourcen innerhalb eines Virtual Networks, dem Internet sowie mit On-Premises-Netzwerken zu kommunizieren.  
Sie gehört zu einem Subnet und erhält eine IP-Adresse; bei Bedarf kann eine Public IP zugeordnet werden, um externe Kommunikation zu ermöglichen.  
Eine einzelne Network Interface kann mehrere IP-Konfigurationen enthalten und unterstützt dadurch verschiedene Netzwerkszenarien.

## Ressourcenkonfiguration

-   `included_subnet_name` : Name des Subnets, das die Network Interface enthält

#### IP-Konfiguration (`ip_configuration`)

-   `ip_configuration.is_primary` : Gibt an, ob die primäre IP-Konfiguration aktiviert ist - `true`, `false`
-   `ip_configuration.private_ip_address_allocation` : Methode zur Zuweisung der privaten IP-Adresse - `Dynamic`, `Static`
-   `ip_configuration.private_ip_address` : Private IP-Adresse
-   `ip_configuration.enabled_public_ip` : Gibt an, ob eine Public IP verwendet wird - `true`, `false`
-   `ip_configuration.linked_public_ip_name` : Name der zu verwendenden Public IP

-   `tag` : Tags zur Kategorisierung der Ressource - bis zu 512 Zeichen, `key`:`value`
