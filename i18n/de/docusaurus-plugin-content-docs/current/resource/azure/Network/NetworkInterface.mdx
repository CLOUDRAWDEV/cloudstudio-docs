## Ressourcen-Einstellwerte

-   `included_subnet_name` : Subnetzname, das das Netzwerkinterface enthält
-   `ip_configuration`
    -   `is_primary` : Aktivierung der primären IP-Konfiguration - `true`, `false`
    -   `private_ip_address_allocation` : Methode zur Zuweisung der privaten IP-Adresse
    -   `enabled_public_ip` : Verwendung einer öffentlichen IP - `true`, `false`
    -   `linked_public_ip_name` : Name der zu verwendenden öffentlichen IP
-   `tag` : Tags zur Kategorisierung der Ressource - maximal 512 Zeichen, `key`:`value`
