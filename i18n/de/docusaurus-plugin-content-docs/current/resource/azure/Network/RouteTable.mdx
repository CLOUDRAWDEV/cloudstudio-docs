## Ressourcenübersicht

Azure Routen-Tabellen sind ein Dienst von Microsoft Azure, der hilft, den Netzwerkverkehr zwischen Subnetzen innerhalb eines VNet (virtuelles Netzwerk) und zwischen VNets zu routen. 
Eine Routen-Tabelle enthält eine Reihe von Regeln, die den Pfad für den Netzwerkverkehr von einem Subnetz oder VNet zu einem Ziel definieren. 
Routen-Tabellen sind nützlich, um den Datenverkehrsfluss zwischen Subnetzen eines virtuellen Netzwerks zu steuern und benutzerdefinierte Routing-Pfade für virtuelle Maschinen bereitzustellen. 
Wenn Routen in einer Routen-Tabelle definiert werden, kann der Verkehr über bestimmte Netzwerkschnittstellen, Gateways oder Service-Endpunkte an ein bestimmtes Ziel gesendet werden. 
In Azure können Routen-Tabellen mit Subnetzen verbunden werden, und alle Ressourcen im verbundenen Subnetz verwenden automatisch die in der Routen-Tabelle definierten Routen. 
Eine Routen-Tabelle kann auch mit einem virtuellen Netzwerk-Gateway verbunden werden, um den Datenverkehr zwischen virtuellen Netzwerken zu steuern.

## Ressourcen-Einstellwerte

-   `disable_bgp_route_propagation` : Deaktivierung der Gateway-Routenübertragung zur Verhinderung der On-Premises-Routenverbreitung über die Netzwerkschnittstelle des Subnetzes - `true`, `false`
-   `included_subnet_names` : Subnetz-Namen, die mit der Routentabelle verbunden werden sollen
-   `route`
    -   `route_address_prefix` : IP-Präfix, das den Pfad darstellt
    -   `next_hop_type` : Bestimmt den nächsten Hop für die Verarbeitung von übereinstimmenden Paketen im Pfad - `VirtualNetworkGateway`, `VnetLocal`, `Internet`, `VirtualAppliance`, `None`
-   `tag` : Tag zur Kategorisierung von Ressourcen - maximal 512 Zeichen, `key`:`value`
