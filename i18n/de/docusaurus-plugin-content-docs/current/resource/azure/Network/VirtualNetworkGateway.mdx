## Ressourcenübersicht

Virtual Network Gateway ist ein Netzwerk-Gateway, das **verschlüsselte Kommunikationspfade für Datenverkehr** zwischen einem Azure Virtual Network und einem On-Premises-Netzwerk oder einem anderen Virtual Network bereitstellt.  
Es kann über VPN oder ExpressRoute verbunden werden und ist eine zentrale Komponente für hybride Netzwerkkonfigurationen sowie sichere dedizierte Verbindungen.

## Ressourceneinstellungen

-   `included_subnet_name` : Name des Subnets, über das der Virtual Network Gateway Datenverkehr sendet und empfängt
-   `gateway_type` : Typ des Virtual Network Gateways - `Vpn`, `ExpressRoute`
-   `vpn_type` : Typ der VPN-Verbindung - `RouteBased`, `PolicyBased`
-   `sku` : Preisstufe des Virtual Network Gateways
-   `generation` : Generation des Virtual Network Gateways - `Generation1`, `Generation2`
-   `enabled_active_active_mode` : Gibt an, ob der Active-Active-Modus aktiviert ist
-   `enabled_configure_bgp` : Gibt an, ob BGP aktiviert ist
-   `tag` : Tags zur Kategorisierung der Ressource - bis zu 512 Zeichen, `key`:`value`

#### IP-Konfiguration (`ip_configuration`)

-   `ip_configuration.linked_public_ip_name` : Name der Public IP, die dem Virtual Network Gateway zugeordnet wird
