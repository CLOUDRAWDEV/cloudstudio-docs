## Ressourcenübersicht

Azure Virtual Network Gateway ist ein von Microsoft Azure bereitgestellter Dienst, der es ermöglicht, eine sichere Cross-Premises-Verbindung zwischen einem Azure Virtual Network und einer On-Premises-Infrastruktur oder anderen Azure Virtual Networks herzustellen.
Es fungiert als Brücke zwischen On-Premises-Infrastrukturen und Azure Virtual Networks, sodass Rechenzentren in die Cloud erweitert und hybride Lösungen erstellt werden können.
Azure Virtual Network Gateway bietet zwei Arten von VPN-Verbindungen: Site-to-Site VPN und Point-to-Site VPN.
Site-to-Site VPN wird verwendet, um On-Premises-Netzwerke mit Azure Virtual Networks zu verbinden. Point-to-Site VPN wird verwendet, um einzelne Computer mit einem Azure Virtual Network zu verbinden.
Azure Virtual Network Gateway unterstützt außerdem verschiedene Routingtypen wie BGP (Border Gateway Protocol), statisches Routing und dynamisches Routing. Es bietet auch Funktionen wie Hochverfügbarkeit, aktive-aktive Konfiguration und Unterstützung für mehrere Virtual Network Gateways.

## Ressourcen-Einstellwerte

-   `included_subnet_name` : Virtuelles Netzwerk-Gateway, über das der Datenverkehr gesendet und empfangen wird
-   `gateway_type` : Typ des virtuellen Netzwerk-Gateways -`Vpn`, `ExpressRoute`
-   `vpn_type` : VPN-Verbindungsart für die VPN-Konfiguration -`RouteBased`, `PolicyBased`
-   `sku` : Preisstaffel des virtuellen Netzwerk-Gateways
-   `generation` : Generation des virtuellen Netzwerk-Gateways - `Generation1`, `Generation2`, `None`
-   `enable_active_active_mode` : `true`, `false`
-   `enable_configure_bgp` : `true`, `false`
-   `ip_configuration` : Name der IP-Konfiguration
-   `tag` : Tag zur Kategorisierung von Ressourcen - maximal 512 Zeichen, `key`:`value`
