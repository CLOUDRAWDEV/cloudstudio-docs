## Ressourcenübersicht

Azure Private Endpoint ist eine Funktion von Azure, die es ermöglicht, sicher auf Azure-Dienste (z. B. Azure Storage, Azure SQL Database und Azure Cosmos DB) über ein privates Netzwerk innerhalb eines virtuellen Netzwerks zuzugreifen.
Dies ermöglicht den sicheren Zugriff auf diese Dienste über private Endpunkte im virtuellen Netzwerk, anstatt über das öffentliche Internet.
Durch die Verwendung von Azure Private Endpoint wird der Zugriff auf den Dienst einer privaten IP-Adresse des virtuellen Netzwerks zugeordnet, und der Datenverkehr zwischen dem virtuellen Netzwerk und dem Dienst wird über einen privaten Link geroutet.
Auf diese Weise bleibt der Datenverkehr innerhalb der Grenzen des virtuellen Netzwerks und wird nicht dem öffentlichen Internet ausgesetzt.

## Ressourcen-Einstellwerte

-   `included_subnet_name` : Subnetzname mit zugewiesenem Private IP-Adresse für den Private Endpoint
-   `linked_connection_resource_name` : Der Name der Ressource, mit der der Private Endpoint verbunden wird
-   `subresource_names` : Liste der Subresource-Namen, mit denen der Private Endpoint verbunden werden kann
-   `dns_zone_group_name` : Der Name der DNS-Zonengruppe, mit der der Private Endpoint verbunden werden soll
-   `private_dns_zone_names` : Liste der Namen der privaten DNS-Zonen, mit denen der Private Endpoint und die Ressource verbunden werden sollen
-   `connection_name` : Der Verbindungsname zwischen dem Private Endpoint und der Ressource
-   `manual_connection` : Erforderliche manuelle Genehmigung des externen Ressourceneigentümers
-   `tag` : Ein Tag zur Kategorisierung der Ressource - maximal 512 Zeichen, `key`:`value`
