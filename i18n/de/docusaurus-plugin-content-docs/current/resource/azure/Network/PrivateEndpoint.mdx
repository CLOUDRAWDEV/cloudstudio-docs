## Ressourcenübersicht

Ein Private Endpoint ist eine Netzwerkressource, die **private Konnektivität (Private Link)** zu Azure-Diensten innerhalb eines Virtual Networks bereitstellt, ohne eine öffentliche IP-Adresse zu verwenden.  
Der Dienstendpunkt wird über eine dem Subnet zugewiesene Private IP bereitgestellt, wodurch ein sicherer Kommunikationspfad ohne Nutzung des Internets ermöglicht wird.  
Durch die Integration mit einer Private DNS Zone kann der FQDN des Dienstes innerhalb des internen Netzwerks nahtlos aufgelöst werden.

## Ressourcenkonfiguration

-   `included_subnet_name` : Name des Subnets, das die dem Private Endpoint zugewiesene Private IP-Adresse enthält
-   `connection_name` : Name der Verbindung zwischen dem Private Endpoint und der Ressource
-   `linked_connection_resource_name` : Name der Ressource, mit der der Private Endpoint verbunden wird
-   `subresource_name` : Name der Subressource, mit der der Private Endpoint verbunden wird
-   `dns_zone_group_name` : Name der Private DNS Zone-Gruppe, die dem Private Endpoint zugeordnet wird
-   `private_dns_zone_names` : Liste der Private DNS Zone-Namen, die dem Private Endpoint zugeordnet werden
-   `manual_connection` : Gibt an, ob eine manuelle Genehmigung durch den externen Ressourceneigentümer erforderlich ist - `true`, `false`
-   `tag` : Tags zur Kategorisierung der Ressource - bis zu 512 Zeichen, `key`:`value`
