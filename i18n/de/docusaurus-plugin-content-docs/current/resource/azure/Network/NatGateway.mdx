## Ressourcenübersicht

Ein NAT Gateway ist eine Ressource, die **ausgehende (Outbound) Internetverbindungen** für ein oder mehrere Subnets innerhalb eines Virtual Networks bereitstellt.  
Wird es einem Subnet zugeordnet, kommunizieren die Ressourcen dieses Subnets ausgehend über die angegebene Public IP und stellen keine eingehenden (Inbound) öffentlichen Endpunkte bereit.  
Durch das Konfigurieren des Zeitlimits für inaktive (Idle-)Verbindungen können langlebige Verbindungen aufrechterhalten oder unnötige Verbindungen schnell bereinigt werden.

## Ressourcenkonfiguration

-   `linked_subnet_names` : Namen der Subnets, die mit dem NAT Gateway verknüpft werden
-   `linked_public_ip_name` : Name der Public IP, die mit dem NAT Gateway verknüpft wird
-   `idle_timeout_in_minutes` : Zeitlimit (in Minuten) zum Entfernen inaktiver Flows im NAT Gateway - `4` ~ `120`
-   `tag` : Tags zur Kategorisierung der Ressource - bis zu 512 Zeichen, `key`:`value`
