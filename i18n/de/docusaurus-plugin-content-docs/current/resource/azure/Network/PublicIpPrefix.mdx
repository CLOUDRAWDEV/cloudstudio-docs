## Ressourcenübersicht

Ein Public IP Prefix ist eine Netzwerkressource in Azure, mit der ein **zusammenhängender Bereich öffentlicher IP-Adressen** im Voraus reserviert und verwaltet werden kann.  
Durch die Zuweisung mehrerer Public IPs aus einem konsistenten Adressblock bietet er Vorhersagbarkeit und Betriebskomfort bei der Verwaltung von Firewall-Regeln oder der Integration externer Systeme.

## Ressourcenkonfiguration

-   `prefix_length` : Bitlänge des Public IP Prefix - `28` ~ `31`
-   `tag` : Tags zur Kategorisierung der Ressource - bis zu 512 Zeichen, `key`:`value`
