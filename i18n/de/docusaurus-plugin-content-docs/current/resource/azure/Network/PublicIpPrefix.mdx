## Ressourcenübersicht

Azure Public IP Prefix (Öffentliche IP-Präfixe) ist eine Ressource, die eine Reihe von zusammenhängenden öffentlichen IP-Adressbereichen bereitstellt.
Dies ist nützlich, wenn in bestimmten Szenarien eine große Anzahl öffentlicher IP-Adressen benötigt wird.
Mit Public IP Prefix können Sie eine große Anzahl öffentlicher IP-Adressen für Ressourcen wie Azure-VMs, Load Balancer, Application Gateways und andere Internet-exponierte Ressourcen einfach verwalten.


## Verwandte Ressourcen

## Ressourcen-Einstellwerte

-   `prefix_length` : `28`~`31`
-   `tag` : Tags zur Kategorisierung von Ressourcen - Maximal 512 Zeichen, `key`:`value`
