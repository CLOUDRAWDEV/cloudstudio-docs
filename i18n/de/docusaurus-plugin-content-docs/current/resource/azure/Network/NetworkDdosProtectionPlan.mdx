## Ressourcenübersicht

Network DDoS Protection Plan ist ein Sicherheitsdienst zum Schutz von Azure Virtual Network-Ressourcen vor groß angelegten Distributed-Denial-of-Service-(DDoS-)Angriffen.  
Durch Verkehrsanalysen und automatische Abwehrmechanismen wird die Verfügbarkeit von Anwendungen aufrechterhalten und bei Auftreten eines Angriffs zusätzlicher Schutz bereitgestellt.
