## Ressourcenübersicht

Azure DDoS Protection hilft dabei, Azure-Ressourcen vor DDoS (Distributed Denial of Service)-Angriffen zu schützen und wird von Microsoft Azure bereitgestellt.
Azure DDoS Protection bietet drei Schutzebenen: Basic, Standard und Premium.
Die Basic-Ebene bietet Schutz vor allgemeinen Netzwerkebenen-Angriffen, während die Standard- und Premium-Ebenen zusätzlichen Schutz vor komplexeren Anwendungenebenen-Angriffen bieten.
Der Azure DDoS Protection-Plan ist ein Preismodell, bei dem Kunden je nach Anzahl der geschützten öffentlichen IP-Adressen im Azure-Abonnement die Kosten für den DDoS-Schutzdienst bezahlen.
Dieser Plan bietet den Kunden eine kostengünstige Möglichkeit, Azure-Ressourcen vor DDoS-Angriffen zu schützen, ohne zusätzliche Kosten für den Schutzdienst aufwenden zu müssen.
