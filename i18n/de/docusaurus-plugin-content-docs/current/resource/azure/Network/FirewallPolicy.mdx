## Ressourcenübersicht

Firewall Policy ist eine **zentralisierte Ressource zur Verwaltung von Firewall-Richtlinien**, die von Azure Firewall verwendet wird.  
Durch das Definieren von Netzwerkregeln, Anwendungsregeln und NAT-Regeln in einer einzigen Richtlinie kann diese konsistent auf mehrere Firewall-Instanzen angewendet werden, wodurch die Wiederverwendbarkeit von Sicherheitsrichtlinien und die Betriebseffizienz erhöht werden.
