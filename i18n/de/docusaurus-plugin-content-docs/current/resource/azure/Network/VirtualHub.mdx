## Ressourcenübersicht

Azure Virtual Hub ist eine **regionale Hub-Ressource, die innerhalb einer Virtual-WAN-Umgebung für zentrale Routing- und Netzwerkverbindungen verantwortlich ist**.  
Er bündelt VPN-, ExpressRoute- und VNet-Verbindungen, um den Datenverkehr zu steuern, und wird als zentrale Komponente einer globalen Netzwerktopologie eingesetzt.

## Ressourcenkonfigurationswerte

-   `included_virtual_wan_name` : Name des übergeordneten Virtual WAN, mit dem der Virtual Hub verbunden ist
-   `address_prefix` : Adressraum (CIDR-Block), der innerhalb des Virtual Hub verwendet wird
-   `hub_routing_preference` : Priorität für die Auswahl des Internet-Routingpfads beim Datenverkehr
    -   `ExpressRoute`
    -   `ASPath`
    -   `VpnGateway`

#### Connection (`connection`)

-   `connection.target_virtual_network_name` : Name des Ziel-Virtual-Networks (VNet), das mit dem Virtual Hub verbunden wird
