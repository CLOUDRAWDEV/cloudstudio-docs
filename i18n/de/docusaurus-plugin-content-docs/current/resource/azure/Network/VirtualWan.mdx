## Ressourcenübersicht

Azure Virtual WAN ist ein **globaler Netzwerk-Hub-Dienst**, der dazu dient, über mehrere Regionen verteilte Netzwerkressourcen zentral zu verbinden und zu verwalten.  
Er ermöglicht die einheitliche Verwaltung von Site-to-Site-VPN-, Point-to-Site-VPN- und ExpressRoute-Verbindungen über einen einzigen Kontrollpunkt und eignet sich besonders für groß angelegte Multi-Region-Netzwerkarchitekturen.
