## Ressourcenübersicht

Azure Bastion ist ein Dienst, mit dem Sie über den Browser und das Azure Portal oder über bereits auf Ihrem lokalen Computer installierte Standard-SSH- oder RDP-Clients eine Verbindung zu virtuellen Maschinen herstellen können.
Der Azure Bastion-Dienst wird innerhalb des virtuellen Netzwerks als vollständig verwalteter PaaS-Dienst bereitgestellt. Er ermöglicht eine sichere und nahtlose RDP/SSH-Verbindung zu virtuellen Maschinen direkt über das Azure Portal über TLS.
Durch die Verbindung über Azure Bastion benötigen Sie keine öffentliche IP-Adresse, Agenten oder spezielle Client-Software, um auf die virtuelle Maschine zuzugreifen.

## Ressourcen-Einstellwerte

-   `included_subnet_name` : Subnetzname, in dem der Bastion Host platziert werden soll

-   `sku` : SKU des Bastion Hosts - `Basic`, `Standard`

-   `linked_public_ip_name` : Name der öffentlichen IP, die mit dem Bastion Host verbunden wird

-   `ip_config_name` : Name der IP-Konfiguration

-   `tag` : Tag, um die Ressource in Kategorien zu unterteilen - maximal 512 Zeichen, `key`:`value`
