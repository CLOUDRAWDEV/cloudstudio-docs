## Ressourcenübersicht

Ein Bastion Host ist ein Azure-PaaS-Netzwerkdienst, der **sicheren RDP- und SSH-Zugriff** auf virtuelle Maschinen innerhalb eines Virtual Networks bereitstellt, ohne öffentliche IP-Adressen direkt den VMs zuzuweisen.  
Er unterstützt browserbasierten Zugriff und ermöglicht die Einrichtung eines zentralisierten Zugriffspunkts ohne das Öffnen von Verwaltungsports, wodurch sowohl die Sicherheit als auch die Betriebseffizienz verbessert wird.
