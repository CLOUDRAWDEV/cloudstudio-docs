## Ressourcenübersicht

Eine Public IP ist eine Netzwerkressource, die eine öffentliche IP-Adresse bereitstellt, sodass Azure-Ressourcen **direkte eingehende und ausgehende Kommunikation** mit dem Internet durchführen können.  
Sie wird mit Diensten wie Load Balancer, Virtual Machine und NAT Gateway integriert und fungiert als Einstiegspunkt für eingehenden Datenverkehr oder als Ausgang für ausgehenden Datenverkehr. Verfügbarkeit und Verhalten variieren je nach SKU und Zuweisungsmethode.

## Ressourceneinstellungen

-   `sku` : Preiskategorie der Public IP - `Standard`, `Basic`
-   `allocation_method` : Zuweisungsmethode der Public IP-Adresse - `Static`, `Dynamic`
-   `tag` : Tags zur Kategorisierung der Ressource - bis zu 512 Zeichen, `key`:`value`
