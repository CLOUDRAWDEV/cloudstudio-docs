## Ressourcenübersicht

Azure Public IP (Öffentliche IP) ist eine eindeutige IP-Adresse, die über das Internet direkt zugänglich ist. 
Sie wird für Azure-Ressourcen wie virtuelle Maschinen, Load Balancer, VPN-Gateways und andere Ressourcen verwendet, die über das Internet erreichbar sind. 
Dadurch kann Internetverkehr an Azure-Ressourcen gesendet werden, und diese Ressourcen sind über das Internet zugänglich.

## Ressourcen-Einstellwerte

-   `sku` : Preismodell der öffentlichen IP - `true`, `false`
-   `allocation_method` : Zuweisungsmethode: Zuweisungsmethode der öffentlichen IP-Adresse - `Static`, `Dynamic`
-   `tag` : Ein Tag zur Kategorisierung von Ressourcen - maximal 512 Zeichen, `key`:`value`
