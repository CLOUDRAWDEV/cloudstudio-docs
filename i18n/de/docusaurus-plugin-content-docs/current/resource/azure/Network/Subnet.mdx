## Ressourcenübersicht

Ein Subnet ist ein Netzwerk, das innerhalb eines Virtual Networks erstellt wird, um Azure-Ressourcen im Virtual Network bereitzustellen.

## Ressourcenkonfiguration

-   `included_vnet_name` : Name des Virtual Networks, das das Subnet enthält
-   `address_prefixes` : IP-Adressbereich für das Subnet, ein eindeutiger im CIDR-Format angegebener Adressbereich innerhalb des Adressraums des Virtual Networks
-   `private_link_endpoint_enabled` : Gibt an, ob ein Private Endpoint mit dem Subnet verbunden werden soll - `true`, `false`

#### Delegierungseinstellungen (`delegation`)

-   `delegation.service_name` : Name des zu delegierenden Dienstes
-   `delegation.actions` : Liste der zu delegierenden Aktionen
