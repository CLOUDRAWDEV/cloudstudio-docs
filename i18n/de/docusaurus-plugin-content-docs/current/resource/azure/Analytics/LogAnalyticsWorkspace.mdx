## Ressourcenübersicht

Log Analytics ist ein Tool, das im Azure-Portal verwendet wird, um Abfragen für die Daten des Azure Monitor-Protokollspeichers zu bearbeiten und auszuführen.
Erstellen Sie eine einfache Abfrage, die ein Set von Datensätzen zurückgibt, und verwenden Sie dann die Funktionen von Log Analytics, um diese zu sortieren, zu filtern und zu analysieren. Oder Sie können fortgeschrittene Abfragen erstellen, um statistische Analysen durchzuführen und die Ergebnisse in Diagrammen zu visualisieren, um bestimmte Trends zu identifizieren.
Ob die Abfrageergebnisse interaktiv verarbeitet oder mit anderen Azure Monitor-Funktionen wie Abfragewarnungen oder Workbook-Protokollen verwendet werden, Log Analytics wird zum Erstellen und Testen von Abfragen verwendet.

## Ressourcen-Einstellwerte

-   `retention_in_days` : Anzahl der Tage, an denen Daten im Workspace aufbewahrt werden - `30`~ `730`

-   `internet_query_enabled` : Aktivierung von Abfragen über das öffentliche Internet - `true`, `false`

-   `internet_ingestion_enabled` : Aktivierung der Datensammlung über das öffentliche Internet - `true`, `false`

-   `tag` : Tag zum Kategorisieren von Ressourcen - maximal 512 Zeichen, `key`:`value`
