## Ressourcenübersicht

Azure App Service ist ein PaaS-Service, mit dem Sie Web-Apps, mobile Backends und RESTful APIs in der von Ihnen gewählten Programmiersprache erstellen und hosten können, ohne die Infrastruktur verwalten zu müssen.
App Service bietet Auto Scaling und hohe Verfügbarkeit und unterstützt sowohl Windows- als auch Linux-Betriebssysteme.
Es ist möglich, automatisch aus GitHub, Azure DevOps oder Git-Repositories bereitzustellen.

## Ressourcen-Einstellwerte

-   `linked_service_plan_name` : Planrichtlinie für den App Service anwenden
-   `delegated_subnet_name` : Subnetzname für die Delegierung des virtuellen Netzwerks
-   `client_cert_enabled` : Client-Zertifikat aktivieren - `true`, `false`
-   `auth_settings_enabled` : Authentifizierung aktivieren, um sicherzustellen, dass alle Kommunikation in der App authentifiziert wird - `true`, `false`
-   `detailed_error_messages_enabled` : Detaillierte Fehlermeldungen auf der Fehlerseite anzeigen, wenn ein HTTP-Fehler auftritt - `true`, `false`
-   `failed_request_tracing_enabled` : Detailliertes Verfolgungsprotokoll für fehlgeschlagene Anfragen aktivieren - `true`, `false`
-   `retention_in_days` : Aufbewahrungsdauer der HTTP-Anforderungsprotokolle (Tage) - `0`~`99999`
-   `retention_in_mb` : Speichergröße für die Aufbewahrung von HTTP-Anforderungsprotokollen (MB) - `25`~`100`
-   `ftps_state` : TLS/SSL für FTP aktivieren, um die Sicherheit zu gewährleisten, wenn FTP verwendet wird - `Disabled`, `FtpsOnly`, `AllAllowed`
-   `http2_enabled` : Die neueste Version des HTTP-Protokolls für die Sicherheit verwenden - `true`, `false`
-   `tag` : Tag zum Kategorisieren von Ressourcen - maximal 512 Zeichen, `key`:`value`
