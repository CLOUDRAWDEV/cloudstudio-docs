## Ressourcenübersicht
 Es ist eine serverlose Computing-Plattform, die von Microsoft Azure bereitgestellt wird, mit der Entwickler kleine Code-Schnipsel, sogenannte Funktionen, in der Cloud ausführen können. 
 Dies ermöglicht es Entwicklern, ereignisgesteuerte Anwendungen auf einer skalierbaren und flexiblen Plattform zu erstellen und bereitzustellen, ohne sich um die Infrastrukturverwaltung kümmern zu müssen.

## Ressourcen-Einstellwerte
- ```kind``` : Betriebssystemtyp für den App Service anwenden ```Linux```
- ```sku_tier``` : Preisstufe des App Service-Tarifs
- ```delegated_subnet_name``` : Subnetzname für die Delegierung des virtuellen Netzwerks
- ```function_app``` : Name des App Services
    -  ```storage_account_name``` : Name des allgemeinen Storage Accounts für die Nutzung der Function App
    -  ```https_only``` : Zugriff auf die Function App nur über HTTPS zulassen, um verschlüsselte und authentifizierte Sicherheitsverbindungen zu gewährleisten - ```true```, ```false```
    -  ```detailed_error_messages_enabled``` : Detaillierte Fehlermeldungen auf der Fehlerseite anzeigen, wenn ein HTTP-Fehler auftritt - ```true```, ```false```
    -  ```auth_settings_enabled``` : Aktivierung der Berechtigungen für die Function App - ```true```, ```false```
    -  ```http2_enabled``` : Aktivierung der neuesten Version des HTTP-Protokolls zur Sicherstellung der Sicherheit - ```true```, ```false```
