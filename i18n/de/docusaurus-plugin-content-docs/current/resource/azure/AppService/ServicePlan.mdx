## Ressourcenübersicht

Ein Service Plan ist ein Tarif- bzw. Hostingplan, der die Computing-Ressourcen definiert, auf denen App Services ausgeführt werden (Serverinstanzen, CPU/Arbeitsspeicher, Skalierung, Betriebssystem usw.).  
Beim Bereitstellen von Web-Apps, API-Apps oder Backend-Anwendungen als App Service wird über den Service Plan festgelegt, mit welchen Spezifikationen und in welcher Preiskategorie die jeweilige Anwendung ausgeführt wird.
