## Ressourcenübersicht

Cloud-init ist ein standardisiertes Initialisierungstool, das verwendet wird, um beim ersten Start einer virtuellen Maschineninstanz automatisch Initialkonfigurationen durchzuführen.  
Es ermöglicht die deklarative Definition verschiedener Initialisierungsaufgaben wie Betriebssystemkonfiguration, Paketinstallation, Benutzererstellung und Skriptausführung und wird in Multi-Cloud-Umgebungen sowie in zahlreichen Linux-Distributionen широко eingesetzt.

## Ressourcenkonfiguration

-   `gzip` : Gibt an, ob ein Datenkomprimierungsalgorithmus verwendet wird – `true`, `false`

-   `part` : Konfiguration für Festplattenpartitionierung und Initialisierungsskripte

    -   `content_type` : Typ der einzufügenden Daten
        -   `text/cloud-config`
        -   `text/x-shellscript`
        -   `text/cloud-boothook`
        -   `multipart/mixed`
        -   `text/cloud-config-archive`
        -   `text/jinja`
        -   `text/x-include-url`
        -   `text/part-handler`
    -   `content` : Die tatsächlich einzufügenden Daten

-   `tag` : Tags zur Kategorisierung der Ressource – maximal 512 Zeichen, `key`:`value`
