## Ressourcenübersicht

Azure Security Center ist ein cloudbasierter Dienst von Microsoft, der es Organisationen ermöglicht, Sicherheitsbedrohungen in Hybrid-Cloud-Workloads zu verhindern, zu erkennen und darauf zu reagieren. 
Es bietet ein zentrales Dashboard, das Einblick in den Sicherheitsstatus aller Ressourcen sowohl in Microsoft Azure als auch in On-Premise-Umgebungen bietet. 
Azure Security Center überwacht kontinuierlich die Umgebung und stellt Sicherheitsrichtlinien, Schwachstellenbewertungen, Bedrohungsinformationen und Sicherheitswarnungen bereit, um vor Bedrohungen zu schützen und potenzielle Schwachstellen zu identifizieren.

## Ressourcen-Einstellwerte

-   `linked_log_analytics_workspace` : Name des Log Analytics Workspace zum Speichern von Daten

-   `assessment_policy`

    -   `display_name`: Anzeige Name der Security Center Bewertung
    -   `severity`: Schweregrad der Security Center Bewertung
    -   `description`: Beschreibung der Security Center Bewertung

-   `assessment`

-   `linked_advanced_threat_protection` : Security Center Advanced Threat Protection-Name
