## Ressourcenübersicht
Azure Cost Management ist ein cloudbasierter Dienst, der von Microsoft Azure bereitgestellt wird und es Organisationen ermöglicht, Cloud-Kosten über mehrere Abonnements und Konten hinweg zu verwalten und zu optimieren.
Dadurch können Benutzer Ausgaben für verschiedene Azure-Dienste wie virtuelle Maschinen, Speicher, Datenbanken und andere Ressourcen überwachen und analysieren.





## Ressourcen-Einstellwerte
- ```recurrence_type``` : Häufigkeit des Exports von Daten - ```Monthly```, ```Annually```, ```Daily```, ```Weekly```

- ```recurrence_period_start_date``` : Startdatum des Exports

- ```recurrence_period_end_date``` : Enddatum des Exports

- ```root_folder_path``` : Speicherort für exportierte Daten

- ```export_type``` : Abfrageformat der Daten - ```Usage```, ```AmortizedCost```, ```ActualCost```

- ```export_time_frame``` : Datumsformat für den Export der Daten  
  ```WeekToDate```, ```MonthToDate```, ```BillingMonthToDate```, ```TheLastWeek```, ```TheLastMonth```, ```TheLastBillingMonth```, ```Custom```

- ```linked_storage_account_name``` : Name des Storage-Kontos, in das die Daten exportiert werden

- ```storage_container_name``` :   Name des Containers, in dem die exportierten Daten gespeichert werden
