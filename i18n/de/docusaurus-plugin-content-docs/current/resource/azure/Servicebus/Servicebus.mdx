## Ressourcenübersicht

Azure Service Bus ist ein vollständig verwalteter Enterprise-Messaging-Dienst, der asynchrones Messaging zwischen Anwendungen unterstützt.  
Mithilfe von Queue- sowie Topic-/Subscription-Modellen ermöglicht er eine zuverlässige Nachrichtenübermittlung, eine geringere Kopplung zwischen verteilten Systemen und unterstützt groß angelegte Ereignisverarbeitungsszenarien.

## Ressourcenkonfiguration

-   `sku` : Preisstufe von Service Bus - `Basic`, `Standard`, `Premium`
-   `capacity` : Kapazitätseinheit zur Steuerung der Durchsatzleistung im Premium-SKU
-   `premium_messaging_partitions` : Anzahl der im Premium-Messaging-Tier verwendeten Partitionen - `1`, `2`, `4`
-   `default_action` : Standardaktion bei Anwendung von Netzwerkregeln - `Allow`, `Deny`
-   `public_network_access_enabled` : Zulassen des Zugriffs auf Service Bus über das öffentliche Netzwerk - `true`, `false`

#### Network Rules (`network_rules`)

-   `network_rules.target_subnet_name` : Name des Ziel-Subnetzes, auf das die Netzwerkregeln angewendet werden
-   `network_rules.ignore_missing_vnet_service_endpoint` : Ob fehlende VNet-Serviceendpunkte im Subnetz ignoriert werden sollen - `true`, `false`

#### Topic (`topic`)

-   `topic.status` : Aktivierungsstatus des Topics - `Active`, `Disabled`
-   `topic.enable_partitioning` : Aktivierung der Nachrichtenpartitionierung - `true`, `false`

#### Subscription (`subscription`)

-   `subscription.target_topic_name` : Name des Ziel-Topics, mit dem das Abonnement verbunden ist
-   `subscription.max_delivery_count` : Maximale Anzahl von Zustellversuchen für eine Nachricht
