## Ressourcenübersicht

Azure Application Insights ist ein cloudbasierter Service von Microsoft, der Entwicklern hilft, Live-Anwendungen zu überwachen und zu analysieren.
Damit können Entwickler Probleme in der Anwendung erkennen und diagnostizieren sowie Echtzeit-Einblicke in die Leistung der Anwendung erhalten.
Mit Application Insights können Entwickler die Leistung und Nutzung der Anwendung verfolgen, einschließlich Anfragen pro Sekunde, Antwortzeiten und Fehlerquoten.
Außerdem können Entwickler die Abhängigkeiten und externen Dienste, die von der Anwendung verwendet werden, sichtbar machen, um Probleme schnell und effizient zu lösen.

## Ressourcen-Einstellwerte

-   `type` : Plattformtyp der zu erstellenden Application Insights - `ios`,`java`,`Node.js`,`other`,`MobileCenter`,`phone`,`store`,`web`
-   `retention_in_days` : Anzahl der Tage, an denen Daten aufbewahrt werden - `30`,`60`,`90`,`120`,`180`,`270`,`365`,`550`,`730`
-   `linked_workspace_name` : Name des Log Analytics Workspaces, in dem die von Application Insights gesammelten Daten gespeichert werden
-   `tag` : Tag zum Kategorisieren von Ressourcen - maximal 512 Zeichen, `key`:`value`
