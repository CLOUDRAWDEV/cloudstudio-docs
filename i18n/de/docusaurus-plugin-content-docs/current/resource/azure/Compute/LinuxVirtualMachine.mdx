## Ressourcenübersicht

Eine Azure Linux Virtual Machine ist eine virtuelle Maschine (VM), die ein Linux-Betriebssystem auf der Microsoft-Azure-Cloud-Computing-Plattform ausführt.  
Durch die Konfiguration von VM-Größe (SKU), Betriebssystem-Image, Authentifizierungsmethoden (Passwort/SSH-Schlüssel), Datenträgerkonfiguration, Netzwerk-Interface-Verbindungen sowie Cloud-init-Initialisierungsskripten können Server-Workloads ausgeführt werden.

## Ressourcenkonfiguration der Ressource

-   `included_vnet_name` : Name des Virtual Networks, zu dem die Virtual Machine gehört

-   `linked_availability_set_name` : Name des Availability Sets, das auf die Virtual Machine angewendet wird

-   `size` : Einstellung der Virtual-Machine-Größe für die Ausführung von Workloads

### Image-Konfiguration (`source_image`)

-   `source_image.type` : Verwendung einer benutzerdefinierten Image-ID – `recommended`, `custom_id`, `custom_input`

-   `source_image.image_id` : ID des Images, das zur Erstellung der VM verwendet wird

-   `source_image.image` : Image, das zur Erstellung der VM verwendet wird

-   `source_image.publisher` : Herausgeber des Images, das zur Erstellung der VM verwendet wird

-   `source_image.offer` : Offer-ID des Images, das zur Erstellung der VM verwendet wird

-   `source_image.sku` : Preis-SKU des Images, das zur Erstellung der VM verwendet wird

### Authentifizierungseinstellungen

-   `enable_ssh_key_authentication` : Gibt an, ob zur Administratorauthentifizierung ein SSH-Schlüssel verwendet wird – `true`, `false`

-   `admin_username` : Administrator-Benutzername der VM – 1 bis 64 Zeichen

-   `admin_password` : Administrator-Passwort der VM – 12 bis 72 Zeichen

-   `ssh_public_key` : Öffentlicher SSH-Schlüssel für die VM – bis zu 600 Zeichen

### OS-Datenträgereinstellungen

-   `os_disk_caching` : Cache-Typ für den OS-Datenträger – `ReadWrite`, `ReadOnly`, `None`

-   `storage_account_type` : Speichertyp des OS-Datenträgers – `Standard_LRS`, `StandardSSD_LRS`, `Premium_LRS`

-   `disk_size_gb` : Größe des OS-Datenträgers (GB) – `32` ~ `32767`

### Zusätzliche Datenträgerzuordnung (`disk_attachment`)

-   `disk_attachment.lun` : Logische Einheitennummer (LUN) des Datenträgers

-   `disk_attachment.host_caching` : Datenträger-Caching-Einstellung – `None`, `ReadOnly`, `ReadWrite`

### Netzwerkeinstellungen

-   `linked_network_interface_names` : Liste der Network-Interface-Namen

-   `primary_network_interface_name` : Name des Network Interfaces, das mit der Virtual Machine verbunden ist

### Initialisierungsskript

-   `cloudinit_config` : Skriptinhalt, der beim Erstellen des Servers automatisch ausgeführt wird

### Tags

-   `tag` : Tags zur Kategorisierung der Ressource – maximal 512 Zeichen, `key`:`value`
