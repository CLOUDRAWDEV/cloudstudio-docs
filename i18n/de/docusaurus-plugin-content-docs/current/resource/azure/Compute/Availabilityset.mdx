## Ressourcenübersicht

Azure Availability Set ist eine logische VM-Gruppe, die virtuelle Maschinen auf mehrere Fehlerdomänen (Fault Domains) und Updatedomänen (Update Domains) verteilt,  
um die Verfügbarkeit von Anwendungen auch bei Hardwareausfällen oder Wartungsarbeiten zu erhöhen.  
Virtuelle Maschinen innerhalb desselben Availability Sets werden auf physisch getrennten Infrastrukturen bereitgestellt, um einen Single Point of Failure (SPOF) zu vermeiden.

## Ressourcenkonfigurationswerte

-   `update_domain_count` :  
    Anzahl der Updatedomänen zum gleichzeitigen Neustart von Gruppen virtueller Maschinen – `1` ~ `20`

-   `enabled_managed_disks` :  
    Gibt an, ob die Erstellung virtueller Maschinen im Availability Set mit verwalteten Datenträgern (Managed Disks) erlaubt ist – `true`, `false`

-   `fault_domain_count` :  
    Anzahl der Fehlerdomänen, die so konfiguriert sind, dass sie dieselbe Stromversorgung und dieselben physischen Netzwerkswitches gemeinsam nutzen – `1` ~ `3`

-   `tag` :  
    Tags zur Kategorisierung der Ressource – maximal 512 Zeichen, `key`:`value`
