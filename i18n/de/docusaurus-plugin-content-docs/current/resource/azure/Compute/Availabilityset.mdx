## Ressourcenübersicht

Verfügbarkeitsgruppen sind logische Gruppen von VMs in Azure, die dazu dienen, Redundanz und Verfügbarkeit zu gewährleisten und zu verstehen, wie Anwendungen in Azure aufgebaut sind.
Es wird empfohlen, mehr als eine VM in einer Verfügbarkeitsgruppe zu erstellen, um hochverfügbare Anwendungen bereitzustellen und das Azure SLA von 99,95 % zu erfüllen.
Für die Verfügbarkeitsgruppe selbst fallen keine Kosten an, es wird nur für jede erstellte VM-Instanz eine Gebühr erhoben.

## Ressourcen-Einstellwerte

-   `update_domain_count` : Anzahl der Update-Domänen, um virtuelle Maschinen-Gruppen gleichzeitig neu zu starten - `1` ~ `20`
-   `fault_domain_count` : Preismodell für die Nutzung des Cognitive Service - `1` ~ `3`
-   `tag` : Tag zur Kategorisierung der Ressourcen – maximal 512 Zeichen, `key`:`value`
