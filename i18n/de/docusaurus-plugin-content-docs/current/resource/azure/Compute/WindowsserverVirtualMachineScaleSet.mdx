## Ressourcenübersicht

Die Azure Windows Server Virtual Machine Scale Sets sind Gruppen von virtuellen Maschinen, die das Windows-Betriebssystem ausführen und je nach Bedarf automatisch skalieren oder verkleinert werden können.
Die Anzahl der VMs im Scale Set kann manuell angepasst oder Regeln definiert werden, um die Größe basierend auf der Ressourcennutzung (z. B. CPU, Arbeitsspeicherbedarf oder Netzwerktraffic) automatisch zu skalieren.
Dann verteilt das Azure Load Balancer den Traffic auf die VM-Instanzen im Scale Set.

## Ressourcen-Einstellwerte

-   `included_vnet_name` : Name des virtuellen Netzwerks, das das Subnetz enthält
-   `orchestration_mode` : Orchestrierungsmodus, der bestimmt, ob die VM vom Scale Set verwaltet wird
-   `platform_fault_domain_count` : Anzahl der VMs in der Gruppe, die gemeinsam Strom- und Netzwerkschalter teilen
-   `vmss_sku` : Preismodell für das Virtual Machine Scale Set
-   `instances` : Anzahl der virtuellen Maschinen im Scale Set `1`~`1000`
-   `source_image`
    -   `enabled_custom_image` : Verwendung der benutzerdefinierten Image-ID - `true`, `false`
    -   `image_id` : ID des Images, das für die VM-Erstellung verwendet wird
    -   `publisher` : Anbieter des Images, das für die VM-Erstellung verwendet wird
    -   `Offer` : ID des Images, das für die VM-Erstellung verwendet wird
    -   `sku` : Preismodell des für die VM-Erstellung verwendeten Images
-   `computer_name_prefix` : Präfix für den Namen der virtuellen Maschinen
-   `admin_username` : Administrator-Benutzername für die VM
-   `admin_password` : Administrator-Passwort für die VM
-   `os_disk_caching` : Caching-Typ für die Verwendung der internen OS-Disk - `ReadWrite`, `ReadOnly`, `None`
-   `storage_account_type` : Speichertyp für die Sicherung der internen OS-Disk - `Standard_LRS`, `StandardSSD_LRS`, `Premium_LRS`
-   `disk_size_gb` : Größe der internen OS-Disk(GB) - `1`~`11400`
-   `network_interface` : Name der Netzwerkschnittstelle
-   `tag` : Tag zur Kategorisierung der Ressourcen - maximal 512 Zeichen, `key`:`value`
