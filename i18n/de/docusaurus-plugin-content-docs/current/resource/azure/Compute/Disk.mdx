## Ressourcenübersicht

Azure Virtual Machines (Virtuelle Maschinen) sind virtuelle Server, die in der Cloud ausgeführt werden.
Virtuelle Maschinen enthalten eine oder mehrere Festplatten, die verwendet werden, um das Betriebssystem (OS) und Daten der virtuellen Maschine zu speichern.
Festplatten fungieren als permanenter Speicher für die virtuelle Maschine.

### Verbundene Ressourcen

## Ressourcen-Einstellwerte

-   `storage_type` : Speichertyp für die Sicherung der Festplatte
-   `size_gb` : Festplattengröße (GB) - `1` ~ `32767`
-   `enabled_public_network_access` : Erlauben des öffentlichen Netzwerkzugriffs auf die Festplatte - `true`, `false`
-   `tag` : Tag zur Kategorisierung der Ressourcen – maximal 512 Zeichen, `key`:`value`
