## Ressourcenübersicht

Azure Disk ist eine verwaltete Blockspeicher-Ressource, die von Azure Virtual Machines verwendet wird.  
Sie kann als Betriebssystemdatenträger (OS Disk) oder als Datenträger (Data Disk) genutzt werden,  
und je nach Leistungs- und Kostenanforderungen stehen verschiedene Speichertypen zur Auswahl.

## Ressourcenkonfigurationswerte

-   `storage_type` :  
    Speichertyp zur Sicherung des Datenträgers

    -   `Standard_LRS`
    -   `StandardSSD_LRS`
    -   `Premium_LRS`

-   `size_gb` :  
    Größe des Datenträgers (GB) – `1` ~ `32767`

-   `enabled_public_network_access` :  
    Gibt an, ob öffentlicher Netzwerkzugriff auf den Datenträger erlaubt ist – `true`, `false`

-   `tag` :  
    Tags zur Kategorisierung der Ressource – maximal 512 Zeichen, `key`:`value`
