## Ressourcenübersicht

Azure Shared Image ist eine Ressource, mit der benutzerdefinierte Virtual-Machine-Images zentral verwaltet und  
über mehrere Subscriptions, Tenants und Regionen hinweg gemeinsam genutzt werden können.  
Dadurch lassen sich standardisierte VM-Images einfach bereitstellen und eine konsistente Infrastrukturverwaltung in großem Maßstab realisieren.

## Ressourcenkonfiguration

-   `image_gallery_description` :  
    Beschreibung der Image-Galerie – maximal 5000 Zeichen

### Image-Definitionen (`images`)

-   `images.os_type` :  
    Typ des in dem Image enthaltenen Betriebssystems

    -   `Linux`
    -   `Windows`

-   `images.publisher_name` :  
    Name des Publishers, der das Image veröffentlicht

-   `images.offer_name` :  
    Name des Angebots (Produktfamilie), zu dem das Image gehört

-   `images.sku` :  
    Detaillierte Konfiguration des Image-Angebots (SKU, Stock Keeping Unit)
