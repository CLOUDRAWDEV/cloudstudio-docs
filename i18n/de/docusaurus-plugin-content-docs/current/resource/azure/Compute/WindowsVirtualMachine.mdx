## Ressourcenübersicht

Azure Windows Server Virtual Machine ist eine virtuelle Maschine (VM), die das Betriebssystem Windows Server auf der Cloud-Computing-Plattform Microsoft Azure ausführt.  
Durch den Betrieb von Windows-Server-VMs in Azure können Benutzer die Skalierbarkeit, Zuverlässigkeit und globale Reichweite der Microsoft-Cloud-Plattform nutzen.

## Ressourcenkonfiguration

-   `included_vnet_name` : Name des Virtual Networks, zu dem die Virtual Machine gehört

-   `linked_availability_set_name` : Name des Availability Sets, das auf die Virtual Machine angewendet wird

-   `size` : Größe der Virtual Machine für die Ausführung von Workloads

-   `computer_name` : Hostname der Virtual Machine

-   `admin_username` : Administrator-Benutzername der VM

    -   1 ~ 64 Zeichen

-   `admin_password` : Administrator-Passwort der VM

    -   12 ~ 72 Zeichen

-   `os_disk_caching` : Caching-Typ für die interne OS-Festplatte

    -   `ReadWrite`, `ReadOnly`, `None`

-   `storage_account_type` : Speichertyp der internen OS-Festplatte

    -   `Standard_LRS`, `StandardSSD_LRS`, `Premium_LRS`

-   `disk_size_gb` : Größe der internen OS-Festplatte (GB)

    -   `32` ~ `32767`

-   `linked_network_interface_names` : Liste der Network-Interface-Namen

-   `primary_network_interface_name` : Name der primären Network Interface

-   `tag` : Tags zur Kategorisierung der Ressource
    -   Maximal 512 Zeichen, `key`:`value`

### Image-Einstellungen (`source_image`)

-   `source_image.type` : Verwendung einer benutzerdefinierten Image-ID

    -   `recommended`, `custom_id`, `custom_input`

-   `source_image.image_id` : ID des Images, das zur Erstellung der VM verwendet wird

-   `source_image.image` : Image, das zur Erstellung der VM verwendet wird

-   `source_image.publisher` : Herausgeber des Images, das zur Erstellung der VM verwendet wird

-   `source_image.offer` : Offer des Images, das zur Erstellung der VM verwendet wird

-   `source_image.sku` : SKU des Images, das zur Erstellung der VM verwendet wird
