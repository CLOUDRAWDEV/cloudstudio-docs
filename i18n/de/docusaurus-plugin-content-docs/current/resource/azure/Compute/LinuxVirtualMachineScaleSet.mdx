## Ressourcenübersicht

Das Azure Linux Virtual Machine Scale Set ist eine Gruppe von virtuellen Maschinen, die das Linux-Betriebssystem ausführen und nach Bedarf automatisch skaliert oder verkleinert werden kann. 
Die Anzahl der VMs im Scale Set kann manuell angepasst oder automatisch skaliert werden, basierend auf Ressourcennutzung (z. B. CPU, Arbeitsspeicheranforderungen oder Netzwerkverkehr). 
Der Azure Load Balancer verteilt dann den Verkehr auf die VM-Instanzen im Scale Set.

## Ressourcen-Einstellwerte

-   `included_vnet_name` : Name des virtuellen Netzwerks, das das Subnetz enthält
-   `orchestration_mode` : Orchestrierungsmodus, der entscheidet, ob die VM vom Scale Set verwaltet wird
-   `platform_fault_domain_count` : Anzahl der VM-Gruppen, die gemeinsam Strom und Netzwerkschalter teilen
-   `vmss_sku` : Preisstufe für das Virtual Machine Scale Set
-   `instances` : Anzahl der virtuellen Maschinen im Scale Set `1`~`1000`
-   `source_image`
    -   `enabled_custom_image` : Verwendung einer benutzerdefinierten Image-ID - `true`, `false`
    -   `image_id` : ID des verwendeten Images zur VM-Erstellung
    -   `publisher` : Anbieter des verwendeten Images zur VM-Erstellung
    -   `Offer` : ID des Images, das zur VM-Erstellung verwendet wird
    -   `sku` : Preisstufe des verwendeten Images zur VM-Erstellung
-   `enable_ssh_key_authentication` : Verwendung von SSH-Schlüsseln zur Authentifizierung des Administrator-Kontos
-   `admin_username` : Administrator-Benutzername für die VM
-   `admin_password` : Administrator-Passwort für die VM
-   `os_disk_caching` : Caching-Typ für das interne OS-Laufwerk - `ReadWrite`, `ReadOnly`, `None`
-   `storage_account_type` : Speichertyp für das Backup des internen OS-Laufwerks - `Standard_LRS`, `StandardSSD_LRS`, `Premium_LRS`
-   `disk_size_gb` : Größe des internen OS-Laufwerks (GB) - `1` ~ `11400`
-   `primary_network_interface_name` : Name des Netzwerkinterfaces, mit dem die virtuelle Maschine verbunden ist
-   `tag` : Tags zur Kategorisierung der Ressource - max. 512 Zeichen, `key`:`value`
