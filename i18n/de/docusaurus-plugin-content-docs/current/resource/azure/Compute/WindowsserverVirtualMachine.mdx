## Ressourcenübersicht

Azure WindowsServer Virtual Machine ist eine virtuelle Maschine (VM), die das WindowsServer-Betriebssystem auf der Azure-Cloud-Computing-Plattform von Microsoft ausführt.
Durch das Ausführen von WindowsServer-VMs auf Azure können Benutzer ihre bevorzugte Linux-Distribution verwenden und gleichzeitig die Skalierbarkeit, Zuverlässigkeit und globale Reichweite der Microsoft-Cloud-Plattform nutzen.

## Ressourcen-Einstellwerte

-   `included_vnet_name` : Name des virtuellen Netzwerks, das das Subnetz enthält
-   `size` : Größe der virtuellen Maschine zur Ausführung der Workloads festlegen
-   `source_image`
    -   `enabled_custom_image` : Verwendung der Benutzerbild-ID - `true`, `false`
    -   `publisher` : Anbieter des für die VM-Erstellung verwendeten Abbilds
    -   `Offer` : ID des für die VM-Erstellung verwendeten Abbilds
    -   `sku` : Preismodell des Abbilds, das für die VM-Erstellung verwendet wird
-   `computer_name` : Host-Name der virtuellen Maschine
-   `admin_username` : Administrator-Benutzername für die VM
-   `admin_password` : Administrator-Passwort für die VM
-   `on_disk_caching` : Cache-Typ für die Verwendung der internen OS-Disk
-   `storage_account_type` : Speichertyp für die Sicherung der internen OS-Disk
-   `disk_size_gb` : Größe der internen OS-Disk (GB) - `1`~`32767`
-   `disk_attachment` : Name der Festplattenverbindung
-   `linked_network_interface_names` : Name des Netzwerk-Interfaces
-   `primary_network_interface_name` : Name des Netzwerk-Interfaces, mit dem die virtuelle Maschine verbunden ist
-   `tag` : Tag zur Kategorisierung der Ressource - maximal 512 Zeichen, `key`:`value`
