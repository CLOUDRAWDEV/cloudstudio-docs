## Ressourcenübersicht

Azure Container Registry ist ein privater Container-Registry-Dienst zur sicheren Speicherung und Verwaltung von  
Container-Images und OCI-Artefakten.  
Der Dienst ist eng mit Docker- und Kubernetes-basierten Workloads integriert und ermöglicht eine  
feingranulare Konfiguration von Sicherheit, Leistung und Netzwerkzugriffskontrollen.

## Ressourceneinstellungen

-   `sku` :  
    SKU-Typ für Leistung und Skalierbarkeit der Container Registry

    -   `Basic`
    -   `Standard`
    -   `Premium`

-   `admin_enabled` :  
    Aktivierung des Administratorkontos – `true`, `false`

-   `public_network_access_enabled` :  
    Zulassen des Zugriffs über öffentliche Netzwerke – `true`, `false`

### Netzwerkrichtlinieneinstellungen (`network_rule_set`)

> Nur konfigurierbar, wenn die SKU auf `Premium` gesetzt ist.

-   `network_rule_set.default_action` :  
    Standardaktion für Anfragen, die keiner Regel entsprechen

    -   `Allow`
    -   `Deny`

-   `network_rule_set.ip_ranges` :  
    Liste der IP-Adress-CIDRs für Anfragen, die mit den Regeln übereinstimmen

### Tags

-   `tag` :  
    Tags zur Kategorisierung der Ressource – maximal 512 Zeichen, `key`:`value`
