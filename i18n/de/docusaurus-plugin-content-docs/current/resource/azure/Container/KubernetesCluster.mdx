## Ressourcenübersicht

Azure Kubernetes Service (AKS) ist ein verwalteter Dienst, der die einfache Bereitstellung und den Betrieb von Kubernetes-Clustern ermöglicht.  
Durch die Konfiguration von Basiseinstellungen des Clusters, Authentifizierung/Berechtigungen (RBAC), Netzwerkrichtlinien, Node-Pool-Konfigurationen und der Zugriffskontrolle auf den API-Server können containerbasierte Workloads betrieben werden.

## Ressourcenkonfigurationswerte

-   `dns_prefix` : DNS-Präfix zur Verwendung mit dem FQDN des gehosteten Kubernetes-API-Servers

-   `sku_tier` : Preismodell für die Nutzung des Kubernetes-Clusters – `Free`, `Standard`

-   `enable_public_network_access` : Aktivierung des Zugriffs über das öffentliche Netzwerk – `true`, `false`

-   `api_server_authorized_ip_ranges` : Liste autorisierter IP-Adressbereiche zum Schutz des Zugriffs auf den API-Server

-   `authentication_authorization` : Autorisierungsmethode zur Einschränkung des Zugriffs auf Cluster-Ressourcen – `local_accounts`, `azure_rbac`, `kubernetes_rbac`

-   `admin_group_object_ids` : Liste der Objekt-IDs von Azure Active Directory-Gruppen, die Administratorrechte für den Cluster besitzen müssen

-   `network_policy` : Netzwerkrichtlinie zur Zugriffsbeschränkung für bestimmte Pods – `calico`, `azure`, `none`

-   `load_balancer_sku` : Preismodell des Load Balancers – `standard`, `basic`

-   `network_plugin` : Standardmethode zur Konfiguration des virtuellen Netzwerks – `kubenet`, `azure`

-   `included_subnet_name` : Name des Subnetzes, in dem der Kubernetes-Cluster bereitgestellt wird

-   `pod_cidr` : CIDR für die Zuweisung von Pod-IP-Adressen

-   `service_cidr` : CIDR-Bereich zur Zuweisung von Service-Cluster-IPs

-   `dns_service_ip` : IP-Adresse, die dem Kubernetes-DNS-Dienst zugewiesen ist

-   `outbound_type` : Typ des ausgehenden Routings – `loadBalancer`, `userDefinedRouting`

### Standard-Node-Pool-Einstellungen (`default_node_pool`)

-   `default_node_pool.node_pool_name` : Name des Node Pools – Linux `1` ~ `12` Zeichen, Windows `1` ~ `6` Zeichen

-   `default_node_pool.enable_auto_scaling` : Aktivierung der automatischen Cluster-Skalierung – `true`, `false`

-   `default_node_pool.node_count` : Anzahl der Nodes im Node Pool – `0` ~ `1000`

-   `default_node_pool.min_node_count` : Mindestanzahl der Nodes im Node Pool – `1` ~ `1000`

-   `default_node_pool.max_node_count` : Maximale Anzahl der Nodes im Node Pool – `1` ~ `1000`

-   `default_node_pool.vm_size` : Größe der virtuellen Maschinen für die Nodes im Node Pool

-   `default_node_pool.os_disk_size_gb` : Größe der OS-Disk der virtuellen Maschine (GB) – `30` ~ `2048`

-   `default_node_pool.max_pods` : Maximale Anzahl von Pods, die auf einem Node ausgeführt werden können – `10` ~ `250`

-   `default_node_pool.enable_node_public_ip` : Aktivierung einer öffentlichen IP-Adresse pro Node – `true`, `false`

-   `default_node_pool.public_ip_prefix_name` : Ressourcen-ID des öffentlichen IP-Adresspräfixes für die Nodes dieses Node Pools

-   `default_node_pool.temporary_name_for_rotation` : Temporärer Node-Pool-Name, der bei bestimmten Wertänderungen zwingend angegeben werden muss

### Zusätzliche Node-Pool-Einstellungen (`cluster_node_pool`)

-   `cluster_node_pool.node_mode` : Node-Pool-Modus – `User`, `System`

-   `cluster_node_pool.node_os_type` : Betriebssystemtyp der virtuellen Maschinen im Node Pool – `Linux`, `Windows`

-   `cluster_node_pool.enable_auto_scaling` : Aktivierung der automatischen Skalierung – `true`, `false`

-   `cluster_node_pool.node_count` : Anzahl der Nodes im Node Pool

-   `cluster_node_pool.max_node_count` : Maximale Anzahl der Nodes im Node Pool

-   `cluster_node_pool.min_node_count` : Mindestanzahl der Nodes im Node Pool

-   `cluster_node_pool.vm_size` : Größe der virtuellen Maschinen für die Nodes im Node Pool

-   `cluster_node_pool.os_disk_size_gb` : Größe der OS-Disk der virtuellen Maschine (GB) – `30` ~ `2048`

-   `cluster_node_pool.max_pods` : Maximale Anzahl von Pods, die auf einem Node ausgeführt werden können – `10` ~ `250`

-   `cluster_node_pool.enable_node_public_ip` : Aktivierung einer öffentlichen IP-Adresse pro Node – `true`, `false`

-   `cluster_node_pool.public_ip_prefix_name` : Ressourcen-ID des öffentlichen IP-Adresspräfixes für die Nodes dieses Node Pools
