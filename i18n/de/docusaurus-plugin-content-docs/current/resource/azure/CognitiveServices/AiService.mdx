## Ressourcenübersicht

AI Service ist ein Dienst, der KI-Modelle und Analysefunktionen über APIs bereitstellt und eine einfache Integration von KI-Funktionen in Anwendungen ermöglicht.  
Durch Modellbereitstellung, Authentifizierungsmethoden, Netzwerkzugriffskontrollen und die Integration verwalteter Identitäten wird eine sichere und skalierbare Betriebsumgebung für KI-Dienste bereitgestellt.

## Ressourcenkonfigurationswerte

-   `sku_name` : Preisklasse für die Nutzung des AI Service

    -   `F0`, `F1`, `S0`, `S`, `S1`, `S2`, `S3`, `S4`, `S5`, `S6`, `P0`, `P1`, `P2`, `E0`, `DC0`

-   `local_authentication_enabled` : Aktivierung der lokalen Authentifizierung über API-Schlüssel – `true`, `false`

-   `custom_subdomain_name` : Benutzerdefinierter Subdomain-Name für tokenbasierte Authentifizierung und Endpunkt-URLs

-   `fqdns` : Liste der vollständig qualifizierten Domänennamen (FQDNs), die vom AI-Service-Konto verwendet werden dürfen

### Konfiguration der verwalteten Identität (`identity`)

-   `identity.identity_type` : Typ der zu verwendenden verwalteten Identität

    -   `SystemAssigned`, `UserAssigned`, `SystemAssigned, UserAssigned`

-   `identity.identity_ids` : Liste der IDs benutzerzugewiesener verwalteter Identitäten

### Netzwerkzugriffskontrolle (`network_acls`)

-   `network_acls.default_action` : Standardrichtlinie für die Netzwerkzugriffskontrolle – `Allow`, `Deny`

-   `network_acls.ip_rules` : Liste zulässiger IP-Adressen oder CIDR-Bereiche

-   `outbound_network_access_restricted` : Einschränkung der ausgehenden Kommunikation – `true`, `false`

-   `public_network_access` : Zugriff über das öffentliche Internet erlauben – `Enabled`, `Disabled`

### Modellbereitstellung (`deployment`)

-   `deployment.model_name` : Name des bereitzustellenden Modells

-   `deployment.model_version` : Versionsnummer des Modells

-   `deployment.sku_name` : Typ der zugewiesenen Verarbeitungskapazität

    -   `Standard`, `DataZoneBatch`, `DataZoneStandard`, `DataZoneProvisionedManaged`,  
        `GlobalBatch`, `GlobalProvisionedManaged`, `GlobalStandard`, `ProvisionedManaged`

-   `deployment.version_upgrade_option` : Strategie für Versions-Upgrades
    -   `OnceCurrentVersionExpired`, `OnceNewDefaultVersionAvailable`, `NoAutoUpgrade`
