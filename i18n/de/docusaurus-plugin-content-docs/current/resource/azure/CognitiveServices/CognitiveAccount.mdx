## Ressourcenübersicht

Azure Cognitive Services ist eine Cloud-basierte Dienstesuite, die Entwicklern vorkonfigurierte APIs bietet, um intelligente Funktionen zu Anwendungen hinzuzufügen, ohne Modelle für maschinelles Lernen von Grund auf neu bauen und trainieren zu müssen.
Diese Dienste umfassen natürliche Sprachverarbeitung, Spracherkennung, Bild- und Videoanalyse und vieles mehr.
Mit Azure Cognitive Services können Entwickler fortschrittliche Funktionen einfach und schnell in ihre Anwendungen integrieren, um die Funktionalität zu verbessern und eine bessere Benutzererfahrung zu bieten.
Durch die Nutzung von Azure Cognitive Services können Entwickler leistungsstarke KI-Funktionen zu ihren Anwendungen hinzufügen, ohne Fachwissen in maschinellem Lernen oder KI zu benötigen.







## Ressourcen-Einstellwerte
- ```kind``` : Zu erstellender Typ von Cognitive Service

- ```sku_name``` : Preismodell für die Nutzung des Cognitive Service

- ```custom_subdomain_name``` : Subdomain-Name für die tokenbasierte Authentifizierung
