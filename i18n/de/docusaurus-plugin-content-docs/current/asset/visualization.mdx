# Asset-Visualisierung

Die Asset-Visualisierung `stellt abgefragte Assets in einem Diagramm dar`.
Sie können jedes Asset auswählen, um dessen Details anzuzeigen.

1. Die Asset-Visualisierung wird auf Basis des `Anlagenregisters` erstellt.

    <img width="800" src={assetview} alt="img" />

2. Assets können nach `Gruppe` visualisiert werden.

    <img width="400" src={assetcategory} alt="img" />

3. Wählen Sie ein Asset aus, um dessen Details anzuzeigen.

    <img width="400" src={assetdetail} alt="img" />
