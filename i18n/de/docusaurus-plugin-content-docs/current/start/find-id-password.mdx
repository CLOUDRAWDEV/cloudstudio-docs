## Benutzername wiederfinden

1. Gehen Sie zur Anmeldeseite von Cloud Studio und klicken Sie auf `Benutzername finden`. **[Benutzername wiederfinden](https://cstudio.app/forgot/id)**
2. Geben Sie Ihre E-Mail-Adresse ein und klicken Sie auf "Code senden". Beispiel) `cloudstudio@cloudraw.kr`
3. Überprüfen Sie den `sechsstelligen Bestätigungscode`, der an die eingegebene E-Mail-Adresse gesendet wurde.
4. Kehren Sie zu Cloud Studio zurück, geben Sie den Bestätigungscode ein und klicken Sie auf `Bestätigen`.
5. Klicken Sie auf die Schaltfläche `Weiter`.
6. Überprüfen Sie den Benutzername, der an Ihre E-Mail-Adresse gesendet wurde.

## Passwort wiederfinden

1. Gehen Sie zur Anmeldeseite von Cloud Studio und klicken Sie auf Passwort finden. **[Passwort wiederfinden](https://cstudio.app/forgot/pw)**
2. Geben Sie Ihre E-Mail-Adresse ein und klicken Sie auf "Code senden". Beispiel) `cloudstudio@cloudraw.kr`
3. Überprüfen Sie den sechsstelligen Bestätigungscode, der an die eingegebene E-Mail-Adresse gesendet wurde.
4. Kehren Sie zu Cloud Studio zurück, geben Sie den Bestätigungscode ein und klicken Sie auf `Bestätigen`.
5. Klicken Sie auf die Schaltfläche `Passwort zurücksetzen`.
6. Geben Sie ein neues Passwort ein.
7. Geben Sie das neue Passwort zur Bestätigung erneut ein.
8. Klicken Sie auf die Schaltfläche `Passwort zurücksetzen`, um den Vorgang abzuschließen.

<div className={styles.imgWrap}>
    <img src={findPassword} alt="find password img" />
</div>

<p>&nbsp;</p>

:::info
Das Passwort muss die folgenden Bedingungen erfüllen.

-   Nur Groß- und Kleinbuchstaben, Zahlen und Sonderzeichen verwenden
-   Muss mit einem Kleinbuchstaben beginnen
-   Zwischen 8 und 20 Zeichen lang

:::
