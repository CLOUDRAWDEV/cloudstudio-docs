Geben Sie den 6-stelligen Authentifizierungscode aus der Google Authenticator-App ein. Wenn der Code übereinstimmt, ist die Zwei-Faktor-Authentifizierung abgeschlossen.
Sie müssen den Authentifizierungscode innerhalb von 3 Minuten eingeben. Wenn Sie den Authentifizierungsschlüssel verloren haben, wenden Sie sich bitte an help@cloudraw.kr.
