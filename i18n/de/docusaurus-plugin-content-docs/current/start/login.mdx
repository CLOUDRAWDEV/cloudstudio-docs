Cloud Studio kann nicht ohne Mitgliedschaft verwendet werden. Bitte registrieren Sie sich zuerst, bevor Sie sich `anmelden`.

🔗  [Cloud Studio Registrierungslink](https://cstudio.app/signup)

✏️  <Link to="/docs/start/sign-up">Wie man sich registriert</Link>

Nachdem Sie sich registriert haben, gehen Sie zur [Cloud Studio Anmeldeseite](https://cstudio.app/signin).

<p>&nbsp;</p>

1. Überprüfen Sie den Benutzernamen und das temporäre Passwort, das an die E-Mail-Adresse gesendet wurde, die Sie bei der Registrierung angegeben haben.

<div className={styles.imgWrap}>
    <img width="100%" src={login01} width="450px" alt="img" />
</div>

<p>&nbsp;</p>

2. Geben Sie den Benutzernamen und das temporäre Passwort auf der Cloud Studio Anmeldeseite ein.

<img width="100%" src={login02} alt="img" />

<p>&nbsp;</p>

3. Setzen Sie ein neues Passwort.

<img width="100%" src={otp06} alt="otp img" />

<p>&nbsp;</p>

:::info
Beim ersten Anmelden müssen Sie das Passwort zurücksetzen.

:::
