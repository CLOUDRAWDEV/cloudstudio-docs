Um sich bei Cloud Studio anzumelden, besuchen Sie bitte den folgenden Link.

[Start CloudStudio](https://cstudio.app/signin)

1. Klicken Sie auf die Schaltfläche Registrieren.
2. Geben Sie die E-Mail-Adresse ein, die Sie verwenden möchten, z. B.) `cloudstudio@cloudraw.kr`
3. Klicken Sie auf die Schaltfläche `Code senden` und überprüfen Sie die sechsstellige Bestätigungsnummer, die an die eingegebene E-Mail-Adresse gesendet wurde.
4. Kehren Sie zu Cloud Studio zurück, geben Sie die Bestätigungsnummer ein und klicken Sie auf `Bestätigen`, um die E-Mail-Verifizierung abzuschließen.

:::info
Die Bestätigungsnummer muss innerhalb von `3 Minuten` eingegeben werden. Wenn die Zeit abgelaufen ist, klicken Sie auf das **Wiederholungssymbol**, um den Code erneut zu senden.
:::

5. Geben Sie die gewünschte Benutzer-ID ein und klicken Sie auf `Überprüfen`.

:::info
Die Benutzer-ID muss die folgenden Bedingungen erfüllen.

-   Muss mit Kleinbuchstaben beginnen
-   Nur Buchstaben und Zahlen verwenden
-   Zwischen 6 und 16 Zeichen

:::

6. Stimmen Sie den Nutzungsbedingungen zu.
7. Klicken Sie auf `Registrieren`.
8. Ein temporäres Passwort wird an die registrierte E-Mail-Adresse gesendet.
