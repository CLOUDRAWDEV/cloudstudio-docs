Abgeschlossene Projekte können `bearbeitet, kopiert oder gelöscht` werden.

<br />

## Projektinformationen bearbeiten

### Projektnamen bearbeiten

1. Klicken Sie auf das Projekt, das Sie bearbeiten möchten, in meinen Vorlagen.
2. Klicken Sie auf das `Bearbeiten-Symbol` im Projektnamen, wenn das Popup erscheint.
3. Bearbeiten Sie den `Projektnamen`.
4. Klicken Sie erneut auf das `Bearbeiten-Symbol`, um die Bearbeitung abzuschließen.

### Projektbeschreibung bearbeiten

1. Klicken Sie auf das Projekt, das Sie bearbeiten möchten, in meinen Vorlagen.
2. Klicken Sie auf das `Bearbeiten-Symbol` in der Projektbeschreibung, wenn das Popup erscheint.
3. Bearbeiten Sie die Projektbeschreibung.
4. Klicken Sie erneut auf das Bearbeiten-Symbol, um die Bearbeitung abzuschließen.

## Projekt kopieren und löschen

### Projekt kopieren

1. Klicken Sie auf das `Mehr-Icon` des Projekts, das Sie kopieren möchten, in meinen Vorlagen.
2. Klicken Sie auf `Projekt kopieren`.
3. Wählen Sie im Popup-Fenster den Ordner aus, in den das Projekt kopiert werden soll.
4. Geben Sie den Projektnamen ein.

> -   Erlaubt sind Englisch, Koreanisch, Zahlen
> -   2 bis 20 Zeichen

5. Geben Sie eine Projektbeschreibung ein.

> -   Maximal 100 Zeichen

6. Klicken Sie auf `Kopieren`.

    <img src={modifyProject} width="800px" alt="Bild" />
</div>

<p>&nbsp;</p>

### Projekt löschen

1. Klicken Sie auf das `Mehr-Icon` des Projekts, das Sie löschen möchten, in den Vorlagen.
2. Klicken Sie auf `Projekt löschen`.
3. Geben Sie im Popup-Fenster den Projektnamen erneut ein.
4. Klicken Sie auf die Schaltfläche `Löschen`.

## Canvas bearbeiten

1. Klicken Sie auf das Projekt, das Sie im Template bearbeiten möchten.
2. Wenn das Popup geöffnet wird, klicken Sie auf `Projekt bearbeiten` auf der rechten Seite.
