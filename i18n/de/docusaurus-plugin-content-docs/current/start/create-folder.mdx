📁 Ein Ordner ist eine Funktion, mit der Sie mehrere Projekte verwalten können. Organisieren Sie die Projekte in dem erstellten Ordner!

<br />
<br />

<div className={styles.imgWrap}>
    <img src={createFolder} alt="이미지" />
</div>

1. Klicken Sie auf das `Ordner hinzufügen-Symbol` auf der Vorlagen-Seite im Cloud Studio, um einen neuen Ordner zu erstellen.
2. Wenn das Popup erscheint, in dem Sie einen Ordner hinzufügen können, geben Sie den `Ordnernamen` und eine `Ordnerbeschreibung` ein. Die Ordnerbeschreibung ist optional. Der Ordnername und die Ordnerbeschreibung müssen die folgenden `Bedingungen` erfüllen.

    > Ordnername

    - Englisch, Koreanisch, Zahlen erlaubt
    - 2 bis 12 Zeichen
    - Ohne Leerzeichen

    > Ordnerbeschreibung

    - Bis zu 100 Zeichen

3. Nachdem Sie die Popup-Inhalte ausgefüllt haben, klicken Sie auf den `Erstellen`-Button.
4. Die erstellte Ordnerliste kann unter `Vorlagen > Meine Ordner` eingesehen werden.
