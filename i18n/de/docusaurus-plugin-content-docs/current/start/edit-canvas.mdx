Das Canvas ist der <highlight color="#206FD6">zentrale Service von Cloud Studio</highlight>, mit dem Sie Cloud-Infrastrukturen erstellen, Versionen verwalten und diese bereitstellen können, indem Sie Ressourcen per `Drag & Drop` ziehen und ablegen.
Die im Canvas erstellte Infrastruktur kann nicht nur als visuelle Architektur verwendet werden, sondern auch direkt an den gewünschten CSP-Anbieter bereitgestellt werden.

✂️ Bearbeiten Sie das Canvas frei!

<p>&nbsp;</p>

## Ressourcen Drag & Drop {#drag-drop}

`Drag & Drop` ist die einfachste Funktion zum Erstellen eines Canvas.
Ziehen Sie die gewünschten Ressourcen aus der linken `Ressourcenliste` und legen Sie sie auf dem Canvas ab!
Ressourcen, die nicht miteinander verbunden werden können, werden mit einer roten Linie abgewiesen.

    <img src={dragDrop} alt="Drag-and-Drop-Bild" width={800} />
</div>

<br />

:::info

Die `Ressourcenliste` ist ein Panel, das die Ressourcen auf der linken Seite des Canvas zusammenfasst.

:::

### Ressourcentypen

Ressourcen werden hauptsächlich in die folgenden `vier Typen` unterteilt. Verwenden Sie die untenstehende Liste, um die Canvas-Ressourcen miteinander zu verbinden.

| Bild                                            | Name   | Beschreibung                                                   |
| ------------------------------------------------- | ------ | ------------------------------------------------------ |
| <img width="40px" src={ basic } alt="Bild" />   | Grundtyp | Zeigt Ressourcen an, die in einer Gruppe enthalten sein können.          |
| <img width="40px" src={ connect } alt="Bild" /> | Verbindungstyp | Zeigt eine Liste von Ressourcen an, die mit dieser Ressource verbunden werden können. |
| <img width="40px" src={ group } alt="Bild" />   | Gruppentyp | 	Zeigt eine Liste von Ressourcen an, die dieser Gruppe zugeordnet werden können.    |
| <img width="40px" src={ tools } alt="Bild" />   | Tools  | 	Zeigt die Liste der Canvas-Werkzeuge an.                        |

## 	Zeigt die Liste der Canvas-Werkzeuge an. {#option-edit}

Durch einen `Doppelklick` auf eine Ressource öffnet sich das `Bearbeitungsfenster`, in dem die Ressourceneinstellungen geändert werden können.
Klicken Sie auf das `Details anzeigen-Symbol`, um die Beschreibung der Ressource zu sehen.
❓ Wenn Sie mit der Maus über das `Fragezeichen-Symbol` fahren, wird eine Beschreibung zu jeder Option angezeigt. Verwenden Sie diese Beschreibungen, um die gewünschten Werte festzulegen.

## Fehlerbehebung {#error-correction}

🔴 Der rote Punkt zeigt an, dass es einen Fehler in der betreffenden Ressource gibt. <highlight color="#FF7272">Wenn Fehler vorhanden sind, können Sie das Canvas nicht speichern oder bereitstellen.</highlight>
Um den Fehler zu beheben, klicken Sie mit der rechten Maustaste auf die fehlerhafte Ressource und öffnen Sie das Fehlerfenster.
Wenn Sie auf den spezifischen Fehler im Fehlerfenster `doppelklicken`, gelangen Sie direkt zum Fehlerort. Beheben Sie die Fehler anhand der Fehlerursache.

<div className={styles.imgWrap}>
    <img src={error} alt="Fehlerbehebung Bild" width={800} />
</div>

<p>&nbsp;</p>

### Fehlerarten

| Art  | Beschreibung                                                  |
| ----- | ----------------------------------------------------- |
| value | Fehler, der auftritt, wenn der Eingabewert falsch ist                  |
| group | Fehler, der auftritt, wenn die Ressource keiner Gruppe angehört      |
| line  | 	Fehler, der auftritt, wenn eine benötigte Ressource nicht verbunden ist |

## Verwendung der Toolbox {#toolbox}

Die oben platzierte Toolbox bietet verschiedene Funktionen, um das Canvas zu gestalten.

| Bild                                                       | Aktion          | Funktion                                                   |
| ------------------------------------------------------------ | ------------- | ------------------------------------------------------ |
| <img width="40px" src={ undo } alt="Rückgängig Bild" />     | Rückgängig    | Macht einen Schritt rückgängig.                     |
| <img width="40px" src={ redo } alt="Wiederherstellen Bild" />     | Wiederherstellen    | Macht einen Schritt vorwärts.                            |
| <img width="40px" src={ front } alt="Wiederherstellen Bild" />              | Nach hinten schicken  | Sendet die ausgewählte Ressource nach hinten, wenn zwei Ressourcen sich überschneiden. |
| <img width="40px" src={ back } alt="Wiederherstellen Bild" />               | Nach vorne schicken | Sendet die ausgewählte Ressource nach vorne, wenn zwei Ressourcen sich überschneiden. |
| <img width="40px" src={ list } alt="Ressourcenliste Bild" /> | Ressourcenliste | 	Schaltet die Ressourcenliste ein oder aus.               |
| <img width="100px" src={ ratio } alt="Bildschirmmaßstab Bild" />   | Bildschirmmaßstab   | Passen Sie den Maßstab des Canvas an.                     |
| <img width="100px" src={ grid } alt="Gitterbild Bild" />       | Gitter        | 	Deaktiviert das Canvas-Gitter.                |
