Cloud Studio bietet nicht nur eine visuelle Infrastrukturarchitektur, sondern auch die Funktion, die in der Leinwand gezeichnete Infrastruktur auf dem `tatsächlichen CSP bereitzustellen`. Dadurch können Benutzer Cloud-Infrastrukturen einfach aufbauen.

<p>&nbsp;</p>

## Bereitstellungstest {#deploy-test}

Dies ist der Schritt, in dem die syntaktischen Fehler von IaC oder die korrekte Konfiguration virtuell überprüft werden. Es wird nicht auf dem tatsächlichen CSP bereitgestellt.
(Es funktioniert ähnlich wie die --dry-run Option.)

1. Um den Bereitstellungstest durchzuführen, klicken Sie auf `Bereitstellungsmanagement > Validierung`.

<div className={styles.imgWrap}>
    <img src={deploy03} width="200px" alt="Bereitstellungsbild" />
</div>

<br />

2. Klicken Sie im linken Menü auf die Schaltfläche `Validierung durchführen`.
3. Wählen Sie die `Berechtigung` aus.
4. Klicken Sie auf die Schaltfläche `Validierung durchführen`.

<div className={styles.imgWrap}>
    <img src={deploy02} alt="Bereitstellungsbild" />
</div>

<p>&nbsp;</p>

:::info

Vor der Durchführung des Bereitstellungstests müssen Berechtigungen unbedingt registriert werden. Eine Anleitung zur Registrierung von `Berechtigungen` finden Sie hier. [Hier](/docs/credential/createCredential)

:::

## Bereitstellungshistorie  {#tedeployst-history}

Die Bereitstellungshistorie zeigt die `Tatsächliche Bereitstellungshistorie der Infrastruktur`.

1. Klicken Sie auf `Bereitstellung > Bereitstellungshistorie`, um die Bereitstellungshistorie anzuzeigen.

<div className={styles.imgWrap}>
    <img src={deploy01} width="500px" alt="Bereitstellungsbild" />
</div>

<br />

2. Überprüfen Sie die neuesten Bereitstellungshistorien. Wenn Sie einen Eintrag löschen möchten, wählen Sie den gewünschten Eintrag aus und klicken Sie auf die Schaltfläche `Löschen`.
