<br />

Auf der Berechtigungsnachweisverwaltungsseite können Sie die Berechtigungsnachweisinformationen einsehen und löschen.
Um einen registrierten Berechtigungsnachweis zu löschen, folgen Sie bitte den `nachstehenden Schritten`.

<div className={styles.imgWrap}>
    <img src={deleteCredential} />
</div>

<br />
<br />

1. Klicken Sie auf `Meine Informationen > Berechtigungsnachweisverwaltung`.
2. Klicken Sie im Einstellungen auf das `Mehr Optionen-Symbol`.
3. Klicken Sie auf `Löschen`.
4. Geben Sie den registrierten `Berechtigungsnachweisnamen` ein und klicken Sie auf die Schaltfläche Löschen, um den Löschvorgang abzuschließen.

<br />

:::caution

Um einen Berechtigungsnachweis zu löschen, muss vorher unbedingt ein OTP registriert sein.

:::

<br />

:::tip

Verwenden Sie die Suchfunktion für Berechtigungsnachweise, um die von Ihnen registrierten Berechtigungsnachweise schneller zu finden.

:::
