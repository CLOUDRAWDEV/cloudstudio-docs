Dies sind die `Tastenkürzel`, die im Cloud Studio Canvas verwendet werden können.

| Tastenkürzel               | Erklärung                             |
| -------------------------- | ------------------------------------- |
| Ctrl + Mausrad             | Bildschirm vergrößern und verkleinern |
| Space + Mausklick + Ziehen | Bildschirm verschieben                |
| Delete                     | Löschen                               |
| Ctrl + Z                   | Rückgängig machen                     |
| Ctrl + C                   | Kopieren                              |
| Ctrl + V                   | Einfügen                              |
