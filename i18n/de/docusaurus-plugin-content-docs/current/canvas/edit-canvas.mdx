Canvas ist ein <highlight color="#206FD6">Kerndienst von Cloud Studio</highlight>, der es Ihnen ermöglicht, Cloud-Infrastrukturen per `Drag & Drop` zu zeichnen, Versionen zu verwalten und bereitzustellen.
Die mit dem Canvas erstellte Infrastruktur kann nicht nur als visuelle Architektur verwendet werden, sondern auch direkt an den gewünschten CSP geliefert werden.

✂️ Bearbeiten Sie das Canvas nach Belieben!

<p>&nbsp;</p>

## Ressourcen Drag & Drop {#drag-drop}

`Drag & Drop` ist die grundlegendste Methode zur Konfiguration des Canvas.
Sie können eine gewünschte Ressource aus der linken `Ressourcenliste` auswählen und im Canvas-Bereich platzieren.
Wenn Ressourcen nicht miteinander verbunden werden können, wird die Verbindung mit einer roten Markierung eingeschränkt.

<div className={styles.imgWrap}>
    <img src={dragDrop} alt="Drag & Drop Bild" />
</div>

<br />

:::info

Die `Ressourcenliste` ist ein Panel, das alle Ressourcen auf der linken Seite der Leinwand zusammenstellt.

:::

## Ressourcen verbinden {#resource-connect}

Unter den auf dem Canvas platzierten Ressourcen können miteinander verbindbare Ressourcen durch Linien verbunden werden.<br/>
Diese Verbindungen werden verwendet, um bestimmte Optionen zwischen Ressourcen zu konfigurieren oder deren Beziehungen zu definieren.

## Ressourcenoptionen bearbeiten {#option-edit}

Durch einen `Doppelklick` auf eine Ressource können Sie das `Bearbeitungsfenster` öffnen, um die Ressourceneinstellungen zu ändern.
Durch Klicken auf das `Details anzeigen`-Symbol können Sie die Beschreibung der entsprechenden Ressource einsehen.<br/>
Wenn Sie den Mauszeiger über das `Fragezeichen-Symbol` neben einer Option bewegen, wird eine Beschreibung dieser Option angezeigt.
Anhand der bereitgestellten Beschreibungen können die erforderlichen Werte konfiguriert werden.

## Fehlerbehebung {#error-correction}

🔴 Rote Punkte zeigen an, dass bei der entsprechenden Ressource ein Fehler vorliegt. <highlight color="#FF7272">Wenn ein Fehler vorhanden ist, kann die Canvas nicht gespeichert oder bereitgestellt werden.</highlight>
Um den Fehler zu beheben, doppelklicken Sie auf der Canvas auf die Ressource mit dem Fehler, um das Canvas-Fehlerfenster zu öffnen.
Wenn Sie im Canvas-Fehlerfenster einen bestimmten Fehler doppelt anklicken, werden Sie zur entsprechenden Fehlerstelle geführt und können das Problem anhand der angezeigten Fehlerursache beheben.

<div className={styles.imgWrap}>
    <img src={error} alt="Fehlerbehebung Bild" />
</div>

<p>&nbsp;</p>

### Fehlertypen

| Arten | Erklärung                                                                      |
| ----- | ------------------------------------------------------------------------------ |
| value | Ein Fehler, der auftritt, wenn die Eingabewerte ungültig sind                  |
| group | Ein Fehler, der auftritt, wenn keine Zugehörigkeit zu einer Gruppe besteht     |
| line  | Ein Fehler, der auftritt, wenn die erforderliche Ressource nicht verbunden ist |
