# Gruppenverwaltung

Um Gruppen zu verwalten, klicken Sie auf `Inspektion > Inspektionsmanagement`.
Um eine Inspektion durchzuführen, müssen Sie eine `Gruppe erstellen`.

## Erstellung

1. Klicken Sie auf das `Symbol Gruppe hinzufügen`, um eine Gruppe zu erstellen.

    <img width="200" src={group1} alt="img" />

2. Geben Sie die Gruppeninformationen ein. <br/>
    <img width="700" src={group2} alt="img" />
    <br />
    2-1. Geben Sie den Gruppennamen ein (max. 20 Zeichen).
    <br />
    2-2. Geben Sie die Gruppenbeschreibung ein (max. 100 Zeichen).
    <br />
    2-3. Wählen Sie den CSP aus (pro Gruppe kann nur ein CSP festgelegt werden).
    <br />
    2-4. Wählen Sie die Compliance aus.
    <br />
    2-5. Wählen Sie die Assets aus, die der Gruppe hinzugefügt werden sollen.
    <br />
    2-6. Klicken Sie auf die Schaltfläche Gruppe hinzufügen.

<p>&nbsp;</p>

## Bearbeiten

1. Klicken Sie auf das `Drei-Punkte-Symbol` der Gruppe, deren Namen Sie bearbeiten möchten, und dann auf die `Schaltfläche Gruppe bearbeiten`.

    <img width="300" src={group3} alt="img" />

2. Geben Sie den Gruppennamen ein und klicken Sie auf die `Schaltfläche Bearbeiten`.

    <img width="500" src={group4} alt="img" />

<p>&nbsp;</p>

## Löschen

1. Klicken Sie auf das `Drei-Punkte-Symbol` der Gruppe, die Sie löschen möchten, und dann auf die `Schaltfläche Gruppe löschen`.

    <img width="300" src={group6} alt="img" />

2. Geben Sie den Gruppennamen ein und klicken Sie auf die `Schaltfläche Löschen`.

    <img width="600" src={group5} alt="img" />
