# Konsolenprüfung

## Ausführung

1. Klicken Sie auf den Tab `Inspektion > Inspektionsmanagement > Konsolenprüfung`, um auf die Konsolenprüfung zuzugreifen.
2. Wählen Sie die `Gruppe, die Sie prüfen möchten`, aus der Gruppenliste aus.

:::info

Konsolenprüfungen werden basierend auf der ausgewählten Gruppe durchgeführt. Bitte `erstellen Sie zuerst eine Gruppe`, bevor Sie mit der Konsolenprüfung beginnen.
[So erstellen Sie eine Gruppe](/docs/compliance/group)

:::

3. Klicken Sie auf den Tab `Konsolenprüfung`.

<img width="400" src={inspect2} alt="img" />
<br />

4. Klicken Sie auf die `Schaltfläche Inspektion`.

    <img width="200" src={compliance3} alt="img" />

5. Geben Sie einen Titel für die Inspektion ein (um den Zweck der Prüfung zu spezifizieren) und klicken Sie dann auf die `Schaltfläche Inspektion starten`. Der Titel kann in den Inspektionsdetails eingesehen und bearbeitet werden.

    <img width="400" src={compliance4} alt="img" />

<p>&nbsp;</p>

### Details der Inspektionsergebnisse

Sie können detaillierte Ergebnisse für jede Spalte in der Tabelle anzeigen. Klicken Sie auf die Spalte, die Sie überprüfen möchten.

<img width="800" src={inspect8} alt="img" />

<p>&nbsp;</p>

**Konsolenprüfung**<br/>
Zeigt die Inspektionsmethode an (z. B. wenn das Ergebnis als anfällig eingestuft wird, wird erläutert, wie das Problem zu beheben ist).

**Inspektionsergebnisse**<br/>
In den Inspektionsergebnissen bedeutet `Y` konform, `N` anfällig, `N/A` nicht prüfbar und `P` durchschnittlich.

<img width="800" src={compliance6} alt="img" />
<br />

**Zertifizierungskriterien**<br/>
Sie können die Elemente verwalten, die den jeweiligen Zertifizierungskriterien entsprechen. Im folgenden Bild sind die Kriterien beispielsweise (ISMS, ISO). Sie können die gewünschten Elemente über die Checkboxen auswählen und hinzufügen.

<img width="400" src={compliance9} alt="img" />

**Feld für Beratermeinung**<br/>
Ein Feld, in dem Berater ihre Meinung zu den Inspektionsergebnissen festhalten können.

**Detaillierte Ergebnistabelle**<br/>
In der detaillierten Ergebnistabelle können Sie alle Assets einsehen. Wenn ein anfälliges Element zu den Gesamtelementen gehört, können Sie es durch Klicken auf die Checkbox in den Tab „Anfällig“ verschieben.

**Detaillierte Ergebnisse als Bilddatei exportieren**<br/>
Klicken Sie auf die Schaltfläche „Als Bilddatei exportieren“, um die Ergebnisse als PNG-Datei zu speichern.

<img width="300" src={compliance16} alt="img" />

<p>&nbsp;</p>

:::caution

Wenn Sie die Seite verlassen, ohne nach der Bearbeitung der Details auf die Schaltfläche „Änderungen speichern“ zu klicken, **werden die Änderungen nicht übernommen.**

:::

<p>&nbsp;</p>

## Berichtserstellung

Sobald die Inspektion abgeschlossen ist, können Sie die Ergebnisse in einer Tabelle anzeigen. Die Tabelle enthält sechs Spalten: `Bereich, Elementname, Inspektionskriterien, Priorität, Inspektionsergebnis und Details zum Inspektionsergebnis`.
Weitere Informationen zu den `Inspektionskriterien` finden Sie [hier](/docs/compliance/result).
CS Checker bietet zwei Arten von Berichten an: Excel und Word.

### Excel-Bericht

1. Um die Excel-Datei herunterzuladen, klicken Sie auf die `Schaltfläche Excel-Bericht`.

    <img width="200" src={compliance12} alt="img" />

2. Wählen Sie „Compliance“ aus und klicken Sie dann auf die Schaltfläche „Generieren“.

    <img width="400" src={compliance13} alt="이미지" />

3. Öffnen Sie die Excel-Datei, um die Inspektionsdetails zu überprüfen.

    <img width="800" src={compliance17} alt="이미지" />

### Word-Bericht

1. Um die Word-Datei herunterzuladen, klicken Sie auf die `Schaltfläche Word-Bericht`.

    <img width="200" src={compliance18} alt="img" />

2. Wenn sich das Popup öffnet, geben Sie die erforderlichen Informationen ein.

    2-1. Compliance auswählen<br />
    2-2. Berichttitel eingeben<br />
    2-3. Inspektionszeitplan wählen<br />
    2-4. Prüfer eingeben<br />
    2-5. Auf Erstellen klicken

    <img width="400" src={inspect19} alt="img" />

3. Öffnen Sie die Word-Datei, um die Inspektionsdetails zu überprüfen.
    <img width="600" src={compliance20} alt="img" />

## Überprüfung des Inspektionsverlaufs

1. Klicken Sie auf die `Schaltfläche Inspektionsverlauf`.

    <img width="200" src={compliance15} alt="img" />

2. Im Inspektionsverlauf können Sie den `Inspektionstitel sowie Datum und Uhrzeit der Ausführung` überprüfen.

    <img width="400" src={inspect14} alt="img" />

:::info

Sie können auf den gewünschten Verlauf klicken, um zu den Inspektionsdetails zu navigieren. Sie können eine Inspektion auch durch Klicken auf die entsprechende Schaltfläche löschen.

:::
