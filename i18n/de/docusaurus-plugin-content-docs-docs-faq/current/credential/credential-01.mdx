# Zugangsdaten registrieren

<hr />
<br />

## Azure Zugangsdaten registrieren

Um ein Azure-Zertifikat zu registrieren, müssen Sie eine Anwendung (im Folgenden App) im `Microsoft Azure Portal` erstellen.

1. Melden Sie sich unter https://portal.azure.com an und wählen Sie `Azure Active Directory` aus. Klicken Sie im linken Menü auf `App-Registrierungen`.

2. Klicken Sie auf der Seite `App-Registrierungen` oben auf `Neu registrieren`, um eine neue App zu erstellen.

3. Wechseln Sie zur Seite der erstellten App.

4. Die `Verzeichnis-ID (Tenant-ID)` der erstellten App entspricht der `Tenant ID` des Cloud Studio-Zertifikats. Kopieren Sie die Verzeichnis-ID (Tenant-ID) und fügen Sie sie in die Tenant ID ein.

5. Die `Anwendungs-ID (Client-ID)` entspricht der `Service Principal ID` des Cloud Studio-Zertifikats. Kopieren Sie die Anwendungs-ID (Client-ID) und fügen Sie sie in die Service Principal ID ein.

6. Wählen Sie im Menü der erstellten App auf der linken Seite „Zertifikate und Geheimnisse“ aus und erstellen Sie ein neues Client-Geheimnis.

7. Der `Wert` des erstellten Client-Geheimnisses entspricht dem `Service Principal Key` in den Cloud Studio-Anmeldeinformationen.

:::caution

Bitte beachten Sie, dass das Client-Geheimnis nur einmal bei der Erstellung angezeigt wird.

:::

8. Wählen Sie anschließend im linken Menü `Abonnement` aus und überprüfen Sie die `Abonnement-ID`, die Sie verwenden möchten.

9. Die `Abonnement-ID` im Abonnement-Menü entspricht der `Subscription ID` in den Cloud Studio-Anmeldeinformationen.

10. Registrieren Sie jede dieser Informationen über die `Anmeldeinformationen-Registrierung` in Cloud Studio.

11. Danach können Sie Abfragen und Bereitstellungen über die Tenant-App durchführen.
