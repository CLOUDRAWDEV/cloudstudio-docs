# Kann man bestehende Infrastruktur in das Canvas importieren?

<hr />
<br />

Cloud-Infrastruktur kann über Anmeldeinformationen und Dateien importiert werden.

1. Wählen Sie im oberen Menü des Canvas `Datei > Importieren`.
2. Wählen Sie Aus `Infrastruktur importieren` oder `Aus Datei importieren`.

<Tabs>
    <TabItem value="infraImport" label="Aus Infrastruktur laden" default>
        Wählen Sie die registrierten Anmeldeinformationen aus und durchsuchen
        Sie die Ressourcengruppe (nach Azure-Standard), um die Ressourcen auf
        Basis der Ressourcengruppe zu laden.
    </TabItem>
    <TabItem value="fileImport" label="Aus Datei laden">
        Terraform-Dateien können direkt hochgeladen und in ein Format
        umgewandelt werden, das mit Cloud Studio kompatibel ist.
    </TabItem>
</Tabs>

:::tip

Um die bereitgestellte Cloud-Infrastruktur zu laden, müssen Anmeldedaten registriert sein.

:::
