# Wie wird das Canvas bereitgestellt?

<hr />
<br />

1. Die Canvas-Bereitstellung erfolgt über die Funktion `Validierung` im Menü Bereitstellungsmanagement. Dort wird eine Vorabprüfung durchgeführt, und nach erfolgreicher Prüfung können Sie auf `Bereitstellen` klicken, um die Bereitstellung in der CSP durchzuführen.
2. Wählen Sie im oberen Menü des Canvas `Deployment Management > Validierung aus`.
3. Wählen Sie im Validierungsmodal die Anmeldeinformationen aus und klicken Sie auf die Schaltfläche `Validierung durchführen`.
4. Im linken Menü der Validierung können Sie den Bereitstellungstest durchführen und die Ergebnisse einsehen.
5. Nachdem der Bereitstellungstest abgeschlossen ist, wählen Sie die gewünschte Umgebung aus und klicken Sie auf Bereitstellen, um die Bereitstellung im CSP durchzuführen.

:::tip

Um die im Canvas gezeichnete Cloud-Infrastruktur in den CSP bereitzustellen, müssen die Anmeldeinformationen registriert sein.

:::
