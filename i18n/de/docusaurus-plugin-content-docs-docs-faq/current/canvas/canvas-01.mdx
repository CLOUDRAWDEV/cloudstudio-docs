# Unterschied zwischen Speichern und Versionsspeicherung

<hr />
<br />

<Tabs>
    <TabItem value="save" label="Speichern" default>
        Speichern bedeutet, den aktuellen Zustand der Leinwand zu speichern.
        Durch das Speichern können Sie jedoch nicht zu einer früheren Version
        der Leinwand zurückkehren. Wenn Sie zum vorherigen Zustand der Leinwand
        zurückkehren möchten, müssen Sie die Funktion zur Versionsspeicherung
        verwenden.
    </TabItem>
    <TabItem value="versionSave" label="Versionsspeicherung">
        Versionsspeicherung bedeutet, den Zustand der Leinwand zu einem
        gewünschten Zeitpunkt zu speichern. Durch die Versionsspeicherung können
        Sie den Zustand der Leinwand zu einem bestimmten Zeitpunkt speichern und
        später diesen Zustand wiederherstellen.
    </TabItem>
</Tabs>
