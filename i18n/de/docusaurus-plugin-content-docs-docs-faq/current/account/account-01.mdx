# Ich möchte mein Profil ändern

<hr />
<br />

1. Klicken Sie im Hauptbildschirm von Cloud Studio auf das Menü `Meine Informationen` auf der linken Seite.
2. Klicken Sie unter `Kontoverwaltung` auf „Bild ändern“ und wählen Sie das gewünschte Profilbild aus.
3. Passen Sie die Bildgröße an und klicken Sie auf `Ändern`, um Ihr Profil zu aktualisieren.
