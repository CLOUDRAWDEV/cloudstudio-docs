# Ich möchte mein Konto löschen

<hr />
<br />

1. Wählen Sie im Hauptbildschirm von Cloud Studio das Menü `Meine Informationen` auf der linken Seite.
2. Klicken Sie unter `Kontoverwaltung` auf `Konto löschen`, um Ihr Konto zu löschen.

:::caution

Nach dem Löschen des Kontos können Projekte nicht wiederhergestellt werden.

:::
