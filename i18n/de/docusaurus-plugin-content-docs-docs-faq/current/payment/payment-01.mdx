# Ich möchte mein aktuelles Abonnement upgraden.

<hr />
<br />

1. Wählen Sie im Hauptbildschirm des Cloud Studios im linken Menü `Meine Informationen` aus.

2. Klicken Sie auf `Abonnementverwaltung`, um zur Seite der Abonnementpläne zu gelangen.

3. Sie können Ihr aktuelles Abonnement auf den `PRO-Plan` ändern, um das Abonnement zu upgraden.

:::info

Beim Upgrade des Abonnements wird eine Zahlung (Abonnementgebühr) durchgeführt.

:::
