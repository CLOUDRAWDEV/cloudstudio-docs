# Ich möchte mein Abonnement kündigen

<hr />
<br />

1. Wählen Sie im Hauptbildschirm des Cloud Studios im linken Menü `Meine Informationen` aus.

2. Klicken Sie auf `Abonnementverwaltung`, um zur Seite der Abonnementpläne zu gelangen.

3. Sie können Ihr aktuelles Abonnement auf den `FREE-Plan` ändern, um das Abonnement zu kündigen.

:::info

Die Kündigung des Abonnements wird ab dem nächsten Monat wirksam.

:::
