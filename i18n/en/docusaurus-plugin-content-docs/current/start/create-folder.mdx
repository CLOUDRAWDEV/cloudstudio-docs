<br />
📁 A folder is a structure used to systematically manage multiple
projects. <br />
In CloudStudio, you can create a folder and then organize and manage projects within
that folder.

<br />
<br />

<div className={styles.imgWrap}>
    <img src={createFolder} alt="createFolder" />
</div>

<br />

1. To create a new folder, click the `Add Folder icon` on the template page in CloudStudio.
2. When the folder creation popup appears, enter the `Folder Name` and `Folder Description`.<br/>The folder description is optional.<br/>
   The folder name and folder description must meet the `conditions below`.

> Folder Name

-   Must start with a letter
-   Only letters, numbers, hyphens (-), and underscores (\_) are allowed
-   Must end with a letter or number
-   Total length must be between 2 and 12 characters
-   Spaces are not allowed

> Folder Description

-   Can be up to 100 characters

3.  Click the `Create` button when you have finished entering the content in the pop-up window.
4.  You can find the list of created folders under `Templates > My Folder`.
