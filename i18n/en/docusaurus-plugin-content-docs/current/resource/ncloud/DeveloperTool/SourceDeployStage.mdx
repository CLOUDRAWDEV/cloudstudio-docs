## Resource Overview

You can add, modify, or delete Deploy Stages in a created SourceDeploy project, or create deployment targets for Deploy Stages without existing deployment targets.

## Associated Resources

### Parent Resource

-   [**SourceDeploy**](https://docs.cstudio.app/docs/resource/ncloud/DeveloperTool/SourceDeploy)

## Resource Setting Values

#### Default Settings

-   `included_source_deploy_name` : Name of the SourceDeploy project
-   `target_type` : Type of deployment target - `Server`, `AutoScalingGroup`, `DeployedAutoScalingGroup`, `KubernetesService`, `DeployedKubernetesService`, `ObjectStorage`, `DeployedObjectStorage`
-   `linked_server_list` : List of server names to connect
-   `target_server_id_list` : List of server names to connect
-   `target_resource` : Deployment target resource

#### Deployment Scenario (`scenario`)

-   `scenario.deploy_scenario_description` : SourceDeploy project description
-   `scenario.deploy_scenario_strategy` : Deployment strategy - `normal`, `blueGreen`, `rolling`, `canary`
-   `scenario.deploy_scenario_file_type` : File type of the deployment scenario - `SourceBuild`, `ObjectStorage`, `later`
-   `scenario.target_object_storage_bucket_name` : Object Storage name
-   `scenario.object_storage_object_name` : Object name
-   `scenario.linked_source_build_project` : Name of the SourceBuild project
-   `scenario.rollback` : Whether to roll back on deployment failure - `true`, `false`
-   `scenario.linked_target_group` : Name of the load balancer target group to use
-   `scenario.delete_server` : Whether to delete servers in the Auto Scaling group - `true`, `false`
-   `scenario.manifest_type` : Repository type of manifest files for Kubernetes service deployment - `SourceCommit`
-   `scenario.manifest_repository` : Repository name of manifest files for Kubernetes service deployment
-   `scenario.manifest_branch` : Branch name of manifest files for Kubernetes service deployment
-   `scenario.manifest_path` : List of paths to manifest files for Kubernetes service deployment
-   `scenario.analysis_type` : Canary analysis method for Kubernetes service deployment - `manual`, `auto`
-   `scenario.canary_count` : Number of baseline and canary pods
-   `scenario.timeout` : Maximum allowed deployment/rollback time
-   `scenario.prometheus_url` : Prometheus URL to connect
-   `scenario.baseline` : Baseline variable to use in Prometheus analysis
-   `scenario.canary` : Canary variable to use in Prometheus analysis
-   `scenario.duration` : Analysis duration
-   `scenario.delay` : Analysis delay
-   `scenario.interval` : Analysis interval
-   `scenario.step` : Metric collection interval
-   `scenario.pass_score` : Success score threshold for analysis
-   `scenario.object_storage_source_path` : Source file path when using Object Storage
-   `scenario.object_storage_deploy_path` : File deployment path when using Object Storage

#### Pre-deployment (`scenario.pre_deploy`)

-   `scenario.pre_deploy.command` : List of commands to run during pre-deployment

#### Deployment Path (`scenario.path`)

-   `scenario.path.deploy_path` : List of deployment paths

#### Post-deployment (`scenario.post_deploy`)

-   `scenario.post_deploy.command` : List of commands to run during post-deployment

#### Metric Settings (`scenario.metric`)

-   `scenario.metric.success_criteria` : Metric success criteria - `base`, `canary`
-   `scenario.metric.weight` : Weight of the metric
-   `scenario.metric.query_type` : Metric query type - `default`, `promQL`
-   `scenario.metric.metric` : Metric to use from the Prometheus URL
-   `scenario.metric.filter` : Metric filter to use
-   `scenario.metric.query` : Metric query to use in PromQL

#### Tags

-   `tag` : Tags for categorizing resources
