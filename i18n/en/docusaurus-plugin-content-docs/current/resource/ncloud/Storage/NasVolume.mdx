## Resource Overview

A storage service that connects multiple servers over a network so that multiple users can share data. It is suitable for sharing data among multiple users through network-connected storage.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### Connected Targets

-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## Resource Setting Values

#### Default Settings

-   `volume_name_postfix` : NAS volume name postfix (alphanumeric, 3 ~ 20 characters)
-   `volume_size` : Volume size (in 100GB units) - `500` ~ `10000`
-   `volume_allotment_protocol_type` : Protocol type - `NFS`, `CIFS`
-   `cifs_user_name` : User ID for CIFS authentication
-   `cifs_user_password` : Password for CIFS authentication
-   `linked_instances` : List of server instance names to attach the NAS volume
-   `is_encrypted` : Whether to enable AES-256-based volume-level encryption
