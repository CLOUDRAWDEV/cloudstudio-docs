## Resource Overview

An HDD or SSD storage service additionally provided beyond the server's default storage. It can be created quickly and immediately attached to a server, and returned immediately when no longer needed.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### Connected Targets

-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## Resource Setting Values

#### Default Settings

-   `zone` : Physical region where the Block Storage will be located - `KR-1`, `KR-2`
-   `linked_server_name` : Name of the server to attach the block storage
-   `storage_size` : Block storage size (GB) - `10` ~ `16380`
-   `storage_disk_type` : Block storage disk type - `SSD`, `HDD`
