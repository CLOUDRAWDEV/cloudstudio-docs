## Resource Overview

Object Storage is an object storage service that allows all types of data to be stored and retrieved over the internet.  
Access permissions for buckets and objects can be configured through access policies (rules).

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

## Resource Setting Values

#### Default Settings

-   `rule` : Object Storage access policy configuration - `private`, `public-read`, `public-read-write`, `authenticated-read`
