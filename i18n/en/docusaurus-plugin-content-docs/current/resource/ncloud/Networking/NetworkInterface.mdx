## Resource Overview

A service that creates network interfaces that can be assigned to servers. Servers with applied network interfaces can perform independent network communication using subnets.

## Associated Resources

### Parent Resource

-   [**Subnet**](https://docs.cstudio.app/en/docs/resource/ncloud/Networking/Subnet)

### Connected Resources

-   [**AccessControlGroup**](https://docs.cstudio.app/en/docs/resource/ncloud/Networking/AccessControlGroup)
-   [**Server**](https://docs.cstudio.app/en/docs/resource/ncloud/Compute/Server)

---

## Resource Configuration

#### Basic Settings

-   `included_subnet_name` : Name of the subnet where the network interface will be included
-   `linked_acg_names` : List of Access Control Group names to apply to the network interface
