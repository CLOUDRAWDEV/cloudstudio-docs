## Resource Overview

A service that connects multiple servers using a single public IP and blocks direct access from external sources. It allows multiple servers with private IPs to communicate with external servers while maintaining security by preventing direct external access.

## Resource Configuration

#### Basic Settings

-   `included_vpc_name` : Name of the VPC where the NAT Gateway will be created
-   `included_subnet_name` : Name of the subnet where the NAT Gateway will be created
