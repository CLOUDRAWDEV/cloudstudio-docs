## Resource Setting Values

#### Basic Settings

-   `subnet_cidr` : Subnet IP range to allocate within the VPC CIDR range
-   `zone` : Availability zone where the subnet will be located (`KR-1`, `KR-2`)
-   `subnet_type` : Subnet type (`PUBLIC`, `PRIVATE`)
-   `usage_type` : Subnet usage purpose (`General`, `LoadBalancer`, `BareMetal`, `NatGateway`)
-   `included_vpc_name` : Name of the VPC to which the subnet belongs (read-only)
-   `linked_nacl_name` : Name of the Network ACL applied to the subnet (read-only)
