## Resource Overview

Init Script is a feature that automatically executes a pre-written script when a server is created. It can be used in various scenarios, such as creating multiple servers for the same purpose in bulk, periodically creating servers with the same environment, or managing initial server environments by use case.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

## Resource Setting Values

#### Default Settings

-   `os_type` : Type of server instance to use - `LNX`, `WND`
-   `content` : Script content to be automatically executed when the server is created
-   `description` : Description of the Init Script to be created
