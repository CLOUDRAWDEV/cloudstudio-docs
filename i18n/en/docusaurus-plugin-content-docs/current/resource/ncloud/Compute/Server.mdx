## Resource Overview

A computing resource that provides the flexibility of virtualization without managing physical hardware. Servers can be created in a cloud environment, making them efficient in terms of time and cost, and suitable for cases where infrastructure operation is burdensome or a large amount of server resources is temporarily required.

## Resource Setting Values

#### Default Settings

-   `included_subnet_name` : Name of the subnet where the server will be located
-   `server_image_product_code` : Operating system image code to use - `ncloudServerImage`
-   `server_product_code` : Code for server hardware configuration - `ncloudServerType`
-   `login_key_name` : Name of the Login Key to use
-   `init_script` : Name of the Init Script to use
-   `is_encrypted_base_block_storage_volume` : Whether to encrypt the block storage - `true`, `false`
-   `linked_network_interface_names` : Network interfaces assigned to the server
