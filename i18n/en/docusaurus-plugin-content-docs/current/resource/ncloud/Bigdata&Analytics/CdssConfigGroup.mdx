## Resource Overview

Cdss Config Group is a service that manages Kafka configuration files applied to a CDSS cluster.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/en/docs/resource/ncloud/Base/Region)

### Connected Resources

-   [**CdssCluster**](https://docs.cstudio.app/en/docs/resource/ncloud/Bigdata&Analytics/CdssCluster)

---

## Resource Configuration

#### Basic Settings

-   `kafka_version_code` : Kafka version to use in the CDSS config group - `kafkaVersionCode`
-   `description` : Description of the config group
