## Resource Overview

Redis Config Group allows you to group created Redis servers and efficiently manage them by applying the same configuration values to all servers within the group.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/en/docs/resource/ncloud/Base/Region)

---

## Resource Configuration

#### Basic Settings

-   `redis_version` : Redis config group version and mode - `5.0.14-cluster`, `5.0.14-simple`, `7.0.13-cluster`, `7.0.13-simple`, `7.0.15-cluster`, `7.0.15-simple`, `7.2.6-cluster`, `7.2.6-simple`, `7.2.8-cluster`, `7.2.8-simple`
-   `description` : Description of the Redis config group
