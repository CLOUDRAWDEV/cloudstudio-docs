## Resource Overview

Azure Redis Cache is a **managed in-memory data store service that caches frequently accessed data in memory to provide high throughput and low latency for applications**.  
It is commonly used to reduce backend load and improve response times in scenarios such as session management, caching layers, and real-time data processing.

## Resource Setting Values

-   `sku_name` : Pricing tier of the Redis Cache - `Basic`, `Standard`, `Premium`, `Enterprise`
-   `cache_type` : Size and performance tier of the Redis Cache (SKU subtype)
-   `version` : Redis version - `6`
-   `enable_non_ssl_port` : Whether to enable the non-SSL port - `true`, `false`
-   `minimum_tls_version` : Minimum TLS version to apply to Redis - `1.0`, `1.1`, `1.2`
-   `public_network_access_enabled` : Whether to allow Redis access through the public network - `true`, `false`
-   `tag` : Tags for categorizing resources

#### Redis Firewall Rule (`redis_firewall_rule`)

-   `redis_firewall_rule.start_ip` : Starting IP address to allow access
-   `redis_firewall_rule.end_ip` : Ending IP address to allow access
