## Resource Overview

Azure Servicebus is a **fully managed enterprise messaging service that supports asynchronous messaging between applications**.  
Through queue and topic/subscription models, it enables reliable message delivery, reduced coupling between distributed systems, and large-scale event processing scenarios.

## Resource Setting Values

-   `sku` : Pricing tier of Service Bus - `Basic`, `Standard`, `Premium`
-   `capacity` : Capacity unit for adjusting throughput performance in the Premium SKU
-   `premium_messaging_partitions` : Number of partitions to use in the Premium messaging tier - `1`, `2`, `4`
-   `default_action` : Default action when applying network rules - `Allow`, `Deny`
-   `public_network_access_enabled` : Whether to allow Service Bus access from the public network - `true`, `false`

#### Network Rules (`network_rules`)

-   `network_rules.target_subnet_name` : Name of the target subnet to which the network rules will be applied
-   `network_rules.ignore_missing_vnet_service_endpoint` : Whether to ignore the absence of a VNet service endpoint on the subnet - `true`, `false`

#### Topic (`topic`)

-   `topic.status` : Topic status - `Active`, `Disabled`
-   `topic.enable_partitioning` : Whether to enable message partitioning - `true`, `false`

#### Subscription (`subscription`)

-   `subscription.target_topic_name` : Name of the target Topic to which the subscription is connected
-   `subscription.max_delivery_count` : Maximum number of delivery attempts for a message
