## Resource Overview

A DNS Zone is an area that hosts DNS records for a specific domain, allowing you to create and manage each DNS record.

## Related Resources

### Parent Resource

-   [**Resource Group**](https://docs.cstudio.app/en/docs/resource/azure/Base/ResourceGroup)

## Resource Configuration Values

#### A Record (`dns_a_record`)

-   `dns_a_record.ttl` : Time To Live of the DNS record (seconds) - `0` ~ `2147483647`
-   `dns_a_record.records` : List of IPv4 addresses

#### AAAA Record (`dns_aaaa_record`)

-   `dns_aaaa_record.ttl` : Time To Live of the DNS record (seconds) - `0` ~ `2147483647`
-   `dns_aaaa_record.records` : List of IPv6 addresses

#### CNAME Record (`dns_cname_record`)

-   `dns_cname_record.ttl` : Time To Live of the DNS record (seconds) - `0` ~ `2147483647`
-   `dns_cname_record.record` : Alias used to connect a subdomain to another record

#### NS Record (`dns_ns_record`)

-   `dns_ns_record.ttl` : Time To Live of the DNS record (seconds) - `0` ~ `2147483647`
-   `dns_ns_record.records` : List of name server records

#### PTR Record (`dns_ptr_record`)

-   `dns_ptr_record.ttl` : Time To Live of the DNS record (seconds) - `0` ~ `2147483647`
-   `dns_ptr_record.records` : List of domain names for pointer record types

#### TXT Record (`dns_txt_record`)

-   `dns_txt_record.ttl` : Time To Live of the DNS record (seconds) - `0` ~ `2147483647`
-   `dns_txt_record.records` : List of text-type records

#### Tags

-   `tag` : Tags used to categorize the resource - up to 512 characters, `key`:`value`
