## Resource Overview

A Private DNS Zone is an area used to manage DNS records for private domain names that are used only within an Azure virtual network.  
By linking it with a virtual network (VNet Link), secure name resolution between internal resources can be performed.

## Resource Configuration Values

#### A Record (`private_dns_a_record`)

-   `private_dns_a_record.ttl` : Time To Live of the DNS record (seconds) - `0` ~ `2147483647`
-   `private_dns_a_record.records` : List of IPv4 addresses

#### AAAA Record (`private_dns_aaaa_record`)

-   `private_dns_aaaa_record.ttl` : Time To Live of the DNS record (seconds) - `0` ~ `2147483647`
-   `private_dns_aaaa_record.records` : List of IPv6 addresses

#### CNAME Record (`private_dns_cname_record`)

-   `private_dns_cname_record.ttl` : Time To Live of the DNS record (seconds) - `0` ~ `2147483647`
-   `private_dns_cname_record.record` : Alias used to connect a subdomain to another record

#### PTR Record (`private_dns_ptr_record`)

-   `private_dns_ptr_record.ttl` : Time To Live of the DNS record (seconds) - `0` ~ `2147483647`
-   `private_dns_ptr_record.records` : List of domain names for pointer record types

#### TXT Record (`private_dns_txt_record`)

-   `private_dns_txt_record.ttl` : Time To Live of the DNS record (seconds) - `0` ~ `2147483647`
-   `private_dns_txt_record.records` : List of text-type records

#### Virtual Network Link (`vnet_link`)

-   `vnet_link.linked_vnet_name` : Name of the virtual network linked to the Private DNS Zone

#### Tags

-   `tag` : Tags used to categorize the resource - up to 512 characters, `key`:`value`
