## Resource Overview

Log Analytics is a tool used in the Azure Portal to edit and execute log queries against data stored in Azure Monitor logs.  
You can write simple queries that return record sets and then sort, filter, and analyze them using Log Analytics features.  
Alternatively, you can write advanced queries to perform statistical analysis and visualize results in charts to identify specific trends.  
Log Analytics is used to author and test queries, whether the results are processed interactively or used with other Azure Monitor features such as query alerts or workbooks.

## Resource Setting Values

-   `retention_in_days` : Number of days to retain data in the workspace - `30` ~ `730`

-   `internet_query_enabled` : Whether to enable queries over the public internet - `true`, `false`

-   `internet_ingestion_enabled` : Whether to enable data ingestion over the public internet - `true`, `false`

-   `tag` : Tags for categorizing resources - up to 512 characters, `key`:`value`
