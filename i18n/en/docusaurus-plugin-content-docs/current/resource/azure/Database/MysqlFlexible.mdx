## Resource Overview

Azure MySQL Flexible Server is a relational database service provided by MySQL Community Edition.

## Resource Configuration Values

#### Basic Settings

-   `version` : MySQL version to use – `5.7`, `8.0.21`
-   `sku_name` : MySQL pricing tier name, a combination of Tier + compute generation + number of cores
-   `storage_gb` : Storage capacity of the MySQL Server (GB)
-   `iops` : Storage IOPS for MySQL Flexible Server – `360` ~ `20000`
-   `admin_username` : Administrator username for the server when creation mode is default; alphanumeric characters allowed, no reserved words, `1` ~ `16` characters
-   `admin_password` : Administrator login password for the server when creation mode is default; must include at least three of the following: lowercase letters, uppercase letters, numbers, and special characters; cannot contain three or more consecutive alphanumeric characters from the login name; `8` ~ `128` characters
-   `auto_grow_enabled` : Enable automatic storage growth – `true`, `false`
-   `availability_zone` : Specifies the availability zone. Possible values are `1`, `2`, `3` – `1` ~ `3`
-   `enable_high_availability` : Enable high availability for MySQL Flexible Server – `true`, `false`
-   `high_availability_mode` : High availability mode for MySQL Flexible Server – `SameZone`, `ZoneRedundant`
-   `standby_availability_zone` : Specifies the availability zone for the standby server. Possible values are `1`, `2`, `3`. Cannot be the same as the primary availability zone – `1` ~ `3`
-   `backup_retention_days` : Backup retention period for MySQL Flexible Server. Possible values are `1` ~ `35` days – `1` ~ `35`
-   `public_network_access_enabled` : Allow public network access to the server – `true`, `false`
-   `delegated_subnet_name` : Name of the subnet for virtual network delegation
-   `private_dns_zone_name` : Private DNS zone used to create the MySQL Flexible Server

#### Server Configuration (`configuration`)

-   `configuration.param_value` : Value of a MySQL Flexible Server configuration parameter

#### Database (`database`)

-   `database.charset` : Character set of the MySQL database
-   `database.collation` : Collation of the MySQL database

#### Firewall Rules (`firewall_rule`)

-   `firewall_rule.start_ip_address` : Start IP address associated with the firewall rule
-   `firewall_rule.end_ip_address` : End IP address associated with the firewall rule

#### Tags

-   `tag` : Tags used to categorize the resource – up to 512 characters, `key`:`value`
