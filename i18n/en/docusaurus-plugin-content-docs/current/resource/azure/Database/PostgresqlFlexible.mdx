## Resource Overview

Azure PostgreSQL Flexible Server is a relational database service based on the open-source PostgreSQL database engine.

## Associated Resources

### Parent Resource

-   [**Resource Group**](https://docs.cstudio.app/docs/resource/azure/Base/ResourceGroup)
-   [**Subnet**](https://docs.cstudio.app/docs/resource/azure/Network/Subnet)

## Resource Setting Values

#### Basic Settings

-   `version` : PostgreSQL version to use - `11`, `12`, `13`, `14`
-   `sku_name` : PostgreSQL pricing tier name, a combination of tier + compute generation + number of cores
-   `storage_mb` : Maximum storage capacity of the PostgreSQL Flexible Server (MB)
-   `admin_username` : Administrator username of the server when creation mode is default, alphanumeric allowed, reserved words not allowed, `1` ~ `16` characters
-   `admin_password` : Administrator login password of the server when creation mode is default, must include at least 3 of lowercase, uppercase, numbers, and special characters, cannot contain 3 or more consecutive alphanumeric characters from the login name, `8` ~ `128` characters
-   `availability_zone` : Specifies the availability zone. Possible values are `1`, `2`, `3`. - `1` ~ `3`
-   `enable_high_availability` : Whether to enable high availability for the PostgreSQL Flexible Server - `true`, `false`
-   `high_availability_mode` : High availability mode for the PostgreSQL Flexible Server - `SameZone`, `ZoneRedundant`
-   `standby_availability_zone` : Specifies the availability zone of the standby server. Possible values are `1`, `2`, `3`. Cannot overlap with the primary availability zone. - `1` ~ `3`
-   `backup_retention_days` : Backup retention period (days) for the PostgreSQL Flexible Server. Possible values are `1`~`35`. - `7` ~ `35`
-   `geo_redundant_backup_enabled` : Enable geo-redundant backups - `true`, `false`
-   `public_network_access_enabled` : Allow public network access to the server - `true`, `false`
-   `delegated_subnet_name` : Subnet name for virtual network delegation
-   `private_dns_zone_name` : Private DNS zone for creating the PostgreSQL Flexible Server

#### Server Configuration (`configuration`)

-   `configuration.name` : PostgreSQL Server parameter configuration name
-   `configuration.param_value` : Value of the PostgreSQL flexible server configuration

#### Database (`database`)

-   `database.charset` : Character set of the PostgreSQL database
-   `database.collation` : Data collation method of the PostgreSQL database

#### Firewall Rules (`firewall_rule`)

-   `firewall_rule.start_ip_address` : Start IP address associated with the firewall rule
-   `firewall_rule.end_ip_address` : End IP address associated with the firewall rule

#### Tags

-   `tag` : Tags for categorizing resources - up to 512 characters, `key`:`value`
