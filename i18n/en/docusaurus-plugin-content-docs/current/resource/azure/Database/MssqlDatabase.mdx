## Resource Overview

Azure SQL Database (Microsoft SQL Database) is a fully managed PaaS database engine that handles most database management tasks such as upgrades, patching, backups, and monitoring without user intervention.

## Resource Configuration Values

#### Basic Settings

-   `included_mssql_server_name` : Name of the Microsoft SQL Server where the database will be created
-   `sku_name` : Pricing tier of the Microsoft SQL Database
-   `max_size_gb` : Maximum size of the database (GB) - `1` ~ `1024`
-   `collation` : Data collation setting of the Microsoft SQL Database
-   `license_type` : License type applied to the database - `LicenseIncluded`, `BasePrice`
-   `min_capacity` : Minimum number of vCores for autoscaling - minimum `0.5`
-   `auto_pause_delay_in_minutes` : Idle time (in minutes) before the database is automatically paused when there is no user activity - `60` ~ `10080`
-   `read_scale` : Enables offloading read-only workloads by using the compute capacity of a read-only replica - `true`, `false`
-   `zone_redundant` : Enables zone redundancy for database maintenance operations - `true`, `false`

#### Auditing Policy (`auditing_policy`)

-   `auditing_policy.enable_storage_destination` : Enable Storage Account as an auditing destination - `true`, `false`
-   `auditing_policy.linked_storage_account_name` : Name of the Storage Account
-   `auditing_policy.storage_access_key_is_second` : Use the secondary access key for the auditing Storage Account - `true`, `false`
-   `auditing_policy.storage_retention_days` : Number of days to retain audit logs in the Storage Account
-   `auditing_policy.enable_log_analytics_destination` : Enable auditing to a Log Analytics Workspace - `true`, `false`
-   `auditing_policy.linked_log_analytics_workspace_name` : Name of the Log Analytics Workspace for auditing
-   `auditing_policy.log_analytics_diagnostic_setting_name` : Diagnostic setting name for the Log Analytics Workspace

#### Tags

-   `tag` : Tags used to categorize the resource - maximum 512 characters, `key`:`value`
