## Resource Overview

Azure PolicyDefinition is a **policy definition resource that defines the rules and conditions that resources must comply with, as well as the effects applied when conditions are violated**.  
Based on policy type and evaluation mode, it enables consistent governance and compliance management across Azure resources.

## Resource Setting Values

-   `type` : Policy definition type - `Custom`, `BuiltIn`, `NotSpecified`
-   `mode` : Resource type evaluation mode for the policy
-   `display_name` : Display name of the policy definition
-   `linked_resource_group_name` : Information about the Resource Group to which the policy is applied
