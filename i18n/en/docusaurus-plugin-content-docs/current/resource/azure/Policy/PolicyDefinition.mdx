## Resource Overview

Azure PolicyDefinition is a **policy definition resource that defines the rules and conditions that resources must comply with, as well as the effects applied when those conditions are violated**.  
Based on the policy type and enforcement mode, it enables consistent management of compliance status across Azure resources.

## Resource Configuration Values

-   `type` : Type of policy definition - `Custom`, `BuiltIn`, `NotSpecified`
-   `mode` : Mode that determines the resource types evaluated by the policy
-   `display_name` : Display name of the policy definition
-   `linked_resource_group_name` : Resource Group information to which the policy is applied
