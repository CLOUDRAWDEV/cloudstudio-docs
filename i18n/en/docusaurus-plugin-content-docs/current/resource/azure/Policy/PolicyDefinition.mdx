## Resource Overview

Azure PolicyDefinition is a **policy definition resource that defines the rules and conditions that resources must comply with, and the effects applied when conditions are violated**.  
Based on the policy type and enforcement mode, it enables consistent management of compliance status across Azure resources.

## Resource Setting Values

-   `type` : Policy definition type - `Custom`, `BuiltIn`, `NotSpecified`
-   `mode` : Resource type mode for policy evaluation
-   `display_name` : Display name of the policy definition
-   `linked_resource_group_name` : Resource Group information to which the policy will be applied
