## Resource Overview

Azure PolicySetDefinition is a **policy set definition resource used to group and manage multiple Policy Definitions as a single logical unit**.  
By organizing policies with a common purpose into one unit, it enables consistent policy application and management even in large-scale environments.

## Resource Setting Values

-   `type` : Policy set definition type - `Custom`, `BuiltIn`
-   `display_name` : Display name of the policy set definition
-   `definition_names` : List of Policy Definition names included in the policy set
