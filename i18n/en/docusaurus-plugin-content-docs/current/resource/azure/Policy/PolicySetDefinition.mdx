## Resource Overview

Azure PolicySetDefinition is a **policy set definition resource used to group multiple Policy Definitions into a single logical set for centralized management**.  
By organizing policies with a common purpose into a single unit, it enables consistent policy application and management even in large-scale environments.

## Resource Configuration Values

-   `type` : Type of policy set definition - `Custom`, `BuiltIn`
-   `display_name` : Display name of the policy set definition
-   `definition_names` : List of Policy Definition names included in the policy set
