## Resource Overview

Azure PolicySetDefinition is a **policy initiative definition resource used to group and manage multiple Policy Definitions as a single logical set**.  
By organizing related policies into a unified unit, it ensures consistent policy application and management across large-scale environments.

## Resource Configuration

-   `type` : Policy set definition type - `Custom`, `BuiltIn`
-   `display_name` : Display name of the policy set definition
-   `definition_names` : List of Policy Definition names included in the policy set
