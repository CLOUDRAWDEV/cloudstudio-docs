## Resource Overview

Managed Application Definition is a resource that stores the definition of a **Managed Application** that users can deploy through Azure Marketplace or an internal organizational catalog.  
By packaging ARM templates and UI definitions together, it standardizes the input screens and permission scopes provided to users during deployment.

## Associated Resources

### Parent Resource

-   [**Resource Group**](https://docs.cstudio.app/docs/resource/azure/Base/ResourceGroup)

## Resource Setting Values

#### Basic Information

-   `description` : Description of the Managed Application Definition
-   `display_name` : Name displayed in the user interface

#### Lock Level (`lock_level`)

Defines the level of operations that users can perform on deployed resources.

-   `None` : No restrictions
-   `CanNotDelete` : Deletion not allowed
-   `ReadOnly` : Read-only

#### Package File URI (`package_file_uri`)

-   URI of the `.zip` file that contains ARM templates and metadata for deployment
-   Must include the following files
    -   `mainTemplate.json`
    -   `createUiDefinition.json`
-   `mainTemplate.json` must include at least a `parameters` section

#### Authorization (`authorization`)

Defines roles that will be automatically assigned during application deployment.

-   `authorization.service_principal_id` : ID of the Service Principal to which the role will be assigned
-   `authorization.role_definition_id` : Resource ID of the Role Definition

---

## Usage Scenarios

-   Deploying SaaS or solution packages for Azure Marketplace
-   Providing standardized internal architectures as Managed Applications
-   Delivering infrastructure to customers or internal users with restricted operational permissions
