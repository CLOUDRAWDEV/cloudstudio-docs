## Resource Overview

Azure Linux Virtual Machine Scale Set is a compute resource that allows you to create multiple Linux virtual machine instances with the same configuration and automatically scale the number of instances up or down based on demand or defined policies.  
By configuring virtual network connectivity, VM SKU, instance count, image settings, authentication methods, disk configuration, and network interface settings, you can efficiently operate large-scale workloads.

## Resource Configuration Values

-   `included_vnet_name` : Name of the Virtual Network to which the Virtual Machine Scale Set belongs

-   `orchestration_mode` : Orchestration mode that determines how VMs are managed by the Scale Set - `Uniform`, `Flexible`

-   `platform_fault_domain_count` : Number of VM groups that share a common power source and network switch

-   `vmss_sku` : Pricing tier of the Virtual Machine Scale Set

-   `instances` : Number of virtual machines in the Scale Set - `1` ~ `1000`

### Image Configuration (`source_image`)

-   `source_image.type` : Whether to use a custom image ID - `recommended`, `custom_id`, `custom_input`

-   `source_image.image_id` : ID of the image used to create the VMs

-   `source_image.image` : Image used to create the VMs

-   `source_image.publisher` : Publisher of the image used to create the VMs

-   `source_image.offer` : Offer of the image used to create the VMs

-   `source_image.sku` : SKU of the image used to create the VMs

-   `enable_ssh_key_authentication` : Whether to use SSH keys to authenticate the administrator account - `true`, `false`

-   `ssh_public_key` : Public SSH key for the VMs - up to 600 characters

-   `admin_username` : Administrator username for the VMs - 1 to 64 characters

-   `admin_password` : Administrator password for the VMs - 12 to 72 characters

-   `os_disk_caching` : Caching type for the OS disk - `ReadWrite`, `ReadOnly`, `None`

-   `storage_account_type` : Storage type for the OS disk - `Standard_LRS`, `StandardSSD_LRS`, `Premium_LRS`

-   `disk_size_gb` : Size of the OS disk (GB) - `32` ~ `11400`

### Network Interface Configuration (`network_interface`)

-   `network_interface.is_primary` : Set as the primary network interface - `true`, `false`

-   `network_interface.subnet_name` : Name of the Subnet where the network interface will be located

### IP Configuration (`network_interface.ip_configuration`)

-   `network_interface.ip_configuration.is_primary` : Set as the primary IP configuration of the network interface - `true`, `false`

-   `network_interface.ip_configuration.enabled_public_ip` : Whether to enable a public IP - `true`, `false`

-   `network_interface.ip_configuration.public_ip_name` : Name of the public IP to use

-   `cloudinit_config` : Script content to be executed automatically when the server is created

-   `tag` : Tags used to categorize the resource
