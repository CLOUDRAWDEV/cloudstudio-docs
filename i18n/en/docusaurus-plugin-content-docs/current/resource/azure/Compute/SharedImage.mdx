## Resource Overview

Azure Shared Image is a resource that allows you to centrally manage custom virtual machine images  
and share them across multiple subscriptions, tenants, and regions.  
This enables easy deployment of standardized VM images and consistent infrastructure operations at scale.

## Associated Resources

### Parent Resource

-   [**Resource Group**](https://docs.cstudio.app/docs/resource/azure/Base/ResourceGroup)

## Resource Setting Values

-   `image_gallery_description` :  
    Description of the image gallery - up to 5000 characters

### Image Definitions (`images`)

-   `images.os_type` :  
    Operating system type included in the image

    -   `Linux`
    -   `Windows`

-   `images.publisher_name` :  
    Name of the publisher that publishes the image

-   `images.offer_name` :  
    Name of the offer (product family) to which the image belongs

-   `images.sku` :  
    Detailed configuration of the image offer (SKU, Stock Keeping Unit)
