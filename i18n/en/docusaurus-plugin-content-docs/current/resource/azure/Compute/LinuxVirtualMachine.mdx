## Resource Overview

An Azure Linux Virtual Machine is a virtual machine (VM) that runs a Linux operating system on Microsoft Azure’s cloud computing platform.  
You can configure VM size (SKU), operating system image, authentication methods (password/SSH key), disk settings, network interface connections, and Cloud-init initialization scripts to run server workloads.

## Resource Configuration Values

-   `included_vnet_name` : Name of the Virtual Network to which the Virtual Machine belongs

-   `linked_availability_set_name` : Name of the Availability Set applied to the Virtual Machine

-   `size` : Virtual Machine size configuration for running workloads

### Image Configuration (`source_image`)

-   `source_image.type` : Whether to use a custom image ID - `recommended`, `custom_id`, `custom_input`

-   `source_image.image_id` : ID of the image used to create the VM

-   `source_image.image` : Image used to create the VM

-   `source_image.publisher` : Publisher of the image used to create the VM

-   `source_image.offer` : Offer ID of the image used to create the VM

-   `source_image.sku` : Pricing tier (SKU) of the image used to create the VM

### Authentication Settings

-   `enable_ssh_key_authentication` : Whether to use an SSH key for administrator authentication - `true`, `false`

-   `admin_username` : Administrator username for the VM - 1 to 64 characters

-   `admin_password` : Administrator password for the VM - 12 to 72 characters

-   `ssh_public_key` : Public SSH key for the VM - up to 600 characters

### OS Disk Settings

-   `os_disk_caching` : Caching type for the OS disk - `ReadWrite`, `ReadOnly`, `None`

-   `storage_account_type` : Storage type for the OS disk - `Standard_LRS`, `StandardSSD_LRS`, `Premium_LRS`

-   `disk_size_gb` : Size of the OS disk (GB) - `32` ~ `32767`

### Additional Disk Attachment (`disk_attachment`)

-   `disk_attachment.lun` : Logical Unit Number (LUN) of the disk

-   `disk_attachment.host_caching` : Disk caching setting - `None`, `ReadOnly`, `ReadWrite`

### Network Settings

-   `linked_network_interface_names` : List of Network Interface names

-   `primary_network_interface_name` : Name of the Network Interface attached to the Virtual Machine

### Initialization Script

-   `cloudinit_config` : Script content to be automatically executed when the server is created

### Tags

-   `tag` : Tags used to categorize the resource - maximum 512 characters, `key`:`value`
