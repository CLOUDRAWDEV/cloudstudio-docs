## Resource Overview

Azure Disk is a managed block storage resource used by Azure Virtual Machines.  
It can be used as an operating system disk (OS Disk) or a data disk (Data Disk),  
and supports multiple storage types depending on performance and cost requirements.

## Resource Configuration

-   `storage_type` :  
    Storage type used for disk backup

    -   `Standard_LRS`
    -   `StandardSSD_LRS`
    -   `Premium_LRS`

-   `size_gb` :  
    Disk size in gigabytes (GB) - `1` ~ `32767`

-   `enabled_public_network_access` :  
    Whether to allow public network access to the disk - `true`, `false`

-   `tag` :  
    Tags used to categorize resources - maximum 512 characters, `key`:`value`
