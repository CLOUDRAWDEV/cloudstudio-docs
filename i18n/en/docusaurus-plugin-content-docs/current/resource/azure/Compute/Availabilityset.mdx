## Resource Overview

Azure Availability Set is a logical grouping of virtual machines designed to increase application availability by distributing VMs across multiple fault domains and update domains.  
Virtual machines within the same Availability Set are placed on physically isolated infrastructure, helping prevent a single point of failure (SPOF) during hardware failures or maintenance operations.

## Resource Configuration Values

-   `update_domain_count` :  
    Number of update domains used to reboot groups of virtual machines simultaneously – `1` ~ `20`

-   `enabled_managed_disks` :  
    Whether to allow virtual machine creation in the Availability Set using managed disks – `true`, `false`

-   `fault_domain_count` :  
    Number of fault domains configured to share the same power source and physical network switches – `1` ~ `3`

-   `tag` :  
    Tags used to categorize the resource – up to 512 characters, `key`:`value`
