## Resource Overview

Azure Container Apps Environment is a resource that defines the networking and monitoring environment where Azure Container Apps run.  
By connecting operational environments such as Log Analytics workspaces used when Container Apps are created and executed, log collection and monitoring configurations can be applied consistently.

## Resource Setting Values

-   `linked_log_analytics_workspace` : Resource ID of the connected Log Analytics workspace
