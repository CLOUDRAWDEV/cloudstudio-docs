## Resource Overview

Azure Container Apps Environment is a resource that defines the network and monitoring environment in which Azure Container Apps run.  
By associating operational components such as a Log Analytics Workspace used when Container Apps are created and executed, it enables consistent application of logging collection and monitoring configurations.
