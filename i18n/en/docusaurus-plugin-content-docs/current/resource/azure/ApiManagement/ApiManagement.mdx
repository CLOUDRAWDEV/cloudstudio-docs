## Resource Overview

API Management is a service that provides integrated support for creating, deploying, securing, monitoring, and managing APIs.  
It exposes APIs called by internal and external clients through a single endpoint and enables stable API operations by applying authentication and authorization policies, request/response transformations, throttling, logging, and monitoring.  
In addition, APIs can be published in the form of a portal, allowing documentation and subscriber management to be handled together.

## Resource Configuration

-   `publisher_name` : The name of the publisher of the API Management service

-   `publisher_email` : The email address of the publisher

-   `sku_name` : The SKU (pricing tier) name of the API Management service – `Consumption`, `Developer`, `Basic`, `BasicV2`, `Standard`, `StandardV2`, `Premium`, `PremiumV2`

-   `sku_capacity` : Capacity (number of instances) setting for the selected SKU

-   `virtual_network_type` : The way API Management is connected to a virtual network – `None`, `External`, `Internal`

-   `target_subnet_name` : The name of the subnet where API Management will be deployed

-   `apis` : An option to specify the list of APIs to be registered or managed in the API Management service
    -   `revision` : The revision number of the API
    -   `api_type` : The type of the API – `http`, `soap`, `graphql`
    -   `display_name` : The name of the API displayed in the portal
    -   `path` : The path used to access the API endpoint
    -   `protocols` : The communication protocols supported by the API – `http`, `https`, `ws`, `wss`
