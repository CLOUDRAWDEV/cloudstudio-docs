## Resource Overview

A Service Plan is a pricing and hosting plan that defines the computing resources on which App Services run, such as server instances, CPU and memory, scaling, and the operating system.  
When deploying web apps, API apps, or backend applications to App Service, the Service Plan determines the specifications and pricing tier under which the applications will run.
