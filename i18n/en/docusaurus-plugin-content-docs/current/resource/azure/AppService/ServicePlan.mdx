## Resource Overview

A Service Plan is a pricing and hosting plan that defines the computing resources (server instances, CPU/memory, scaling, OS, etc.) on which App Service runs.  
When deploying web apps, API apps, or backend apps to App Service, the Service Plan determines the specifications and pricing tier under which the app will run.

## Resource Setting Values

-   `kind` : Operating system used by App Service - `Linux`,`Windows`
-   `sku_tier` : Pricing tier of the App Service Plan
