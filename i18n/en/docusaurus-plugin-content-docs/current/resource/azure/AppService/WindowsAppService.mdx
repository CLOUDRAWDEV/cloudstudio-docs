## Resource Overview

Windows App Service is an HTTP-based service that allows you to host web applications, REST APIs, and mobile backends in a Windows-based environment.  
It runs in conjunction with an App Service Plan and provides a stable and scalable application operating environment through authentication configuration, log management, network integration, and security protocol settings.

## Resource Configuration Values

-   `linked_service_plan_name` : Name of the Service Plan to be applied to the App Service

-   `delegated_subnet_name` : Name of the Subnet for virtual network delegation

-   `auth_settings_enabled` : Whether to enable authentication so that all communications from the app are authenticated – `true`, `false`

-   `detailed_error_messages_enabled` : Whether to include detailed error messages on the error page when HTTP errors occur – `true`, `false`

-   `failed_request_tracing_enabled` : Whether to enable logging of detailed tracing information for failed requests – `true`, `false`

-   `retention_in_days` : Number of days to retain logs related to HTTP requests – `0` ~ `99999`

-   `retention_in_mb` : Storage capacity (MB) for retaining logs related to HTTP requests – `25` ~ `100`

-   `ftps_state` : Whether to apply TLS/SSL when using FTP – `Disabled`, `FtpsOnly`, `AllAllowed`

-   `http2_enabled` : Whether to use the latest HTTP protocol (HTTP/2) – `true`, `false`

-   `tag` : Tags used to categorize the resource – up to 512 characters, `key`:`value`
