## Resource Overview

A resource group is a container that holds related resources for an Azure solution.  
A resource group can include all the resources for a solution or only those resources that you want to manage as a group.  
You decide how resources are allocated to resource groups based on what works best for your organization.  
Typically, resources that share the same lifecycle are added to the same resource group so that they can be easily deployed, updated, and deleted together.
