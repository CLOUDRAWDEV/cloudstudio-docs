## Resource Overview

Azure Security Center is an integrated security management service designed to continuously assess the security posture of cloud resources and to detect and prevent threats across the environment.  
By integrating with Microsoft Defender plans, it enables centralized management of vulnerability assessments, security recommendations, and threat protection.

## Resource Setting Values

-   `linked_log_analytics_workspace` : Name of the Log Analytics Workspace used to store security data

#### Assessment Policy (`assessment_policy`)

-   `assessment_policy.display_name` : Display name of the Security Center assessment
-   `assessment_policy.severity` : Severity level of the Security Center assessment - `Low`, `Medium`, `High`
-   `assessment_policy.description` : Description of the Security Center assessment

#### Assessment (`assessment`)

-   `assessment.policy_name` : Name of the security assessment policy applied to the resource
-   `assessment.status_code` : Assessment status code - `Healthy`, `Unhealthy`, `NotApplicable`

#### Subscription Pricing (`subscription_pricing`)

-   `subscription_pricing.pricing_tier` : Whether enhanced security features are enabled - `Free`, `Standard`
-   `subscription_pricing.pricing_resource_type` : Resource type to which enhanced security features are applied
