## Resource Overview

A Public Load Balancer is a load balancing service that receives traffic coming from external sources (the Internet) on the frontend and distributes it to backend pool instances to prevent traffic overload.

## Resource Configuration Values

#### Basic Settings

-   `sku` : Pricing tier for selecting the scale and features of the Azure Load Balancer - `Standard`, `Basic`
-   `virtual_network_name` : Name of the Virtual Network to which the Load Balancer delivers traffic

#### Frontend IP Configuration (`public_lb_frontend_ip_config`)

-   `public_lb_frontend_ip_config.linked_public_ip_name` : Name of the public IP to use

#### Backend Pool (`backend_pool`)

-   `backend_pool` : Name of the Load Balancer backend pool
-   `backend_pool.linked_virtual_machine_names` : Names of the Virtual Machines to which the Load Balancer delivers traffic (must belong to the selected Virtual Network)

#### Health Probe (`health_probe`)

-   `health_probe.protocol` : Protocol type of the backend endpoint used by the health probe - `Http`, `Https`, `Tcp`
-   `health_probe.port` : Port on which the health probe checks the backend endpoint - `0` ~ `65535`
-   `health_probe.request_path` : Path used for GET requests when using Http(s) probes
-   `health_probe.interval_in_seconds` : Interval (in seconds) at which the health probe checks the response of backend pool instances - `5` ~ `2147483646`

#### Load Balancing Rule (`rule`)

-   `rule.protocol` : Transport protocol for the external endpoint - `Tcp`, `Udp`, `All`
-   `rule.frontend_port` : Port of the external endpoint - `0` ~ `65534`
-   `rule.backend_port` : Port used for internal connections - `0` ~ `65535`
-   `rule.disable_outbound_snat` : Enables SNAT for the rule for outbound connections - `true`, `false`
-   `rule.frontend_ip_config_name` : Frontend IP configuration name of the Public Load Balancer
-   `rule.backend_pool_name` : Name of the backend address pool to which the Load Balancer delivers traffic

#### NAT Rule (`nat_rule`)

-   `nat_rule.protocol` : Transport protocol for the external endpoint - `Tcp`, `Udp`, `All`
-   `nat_rule.frontend_port` : Port of the external endpoint - `0` ~ `65534`
-   `nat_rule.backend_port` : Port used for internal connections - `0` ~ `65535`
-   `nat_rule.frontend_ip_config_name` : Frontend IP configuration name of the Public Load Balancer

#### Outbound Rule (`outbound_rule`)

-   `outbound_rule.protocol` : Transport protocol for the external endpoint - `Tcp`, `Udp`, `All`
-   `outbound_rule.frontend_ip_config_name` : Frontend IP configuration name of the Public Load Balancer
-   `outbound_rule.backend_pool_name` : Name of the backend address pool to which the Load Balancer delivers traffic

#### Tags

-   `tag` : Tags used to categorize the resource - up to 512 characters, `key`:`value`
