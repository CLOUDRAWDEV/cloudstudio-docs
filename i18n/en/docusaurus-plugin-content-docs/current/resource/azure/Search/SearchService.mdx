## Resource Overview

Azure Search Service is a **fully managed search service that provides search, filtering, and ranking capabilities for large-scale text, documents, and data**.  
It delivers fast query processing and scalable search performance based on search indexes, and allows control over service access scope through security and network access policies.

## Resource Setting Values

-   `sku_name` : Pricing tier for using Search Service - `basic`, `free`, `standard`, `standard2`, `standard3`, `storage_optimized_l1`, `storage_optimized_l2`
-   `public_network_access_enabled` : Whether to allow resource access through the public internet - `true`, `false`
-   `allowed_ips` : List of allowed IPs that permit access to the Search Service from specific IPs or CIDR ranges
-   `local_authentication_enabled` : Whether to use local authentication with API keys - `true`, `false`
-   `authentication_failure_mode` : Behavior mode that determines whether to block or partially allow requests when client authentication fails - `http401WithBearerChallenge`, `http403`
-   `partition_count` : Number of partitions to distribute and store index data - `1`, `2`, `3`, `4`, `6`, `12`
-   `replica_count` : Number of replicas to process search queries

#### Private Link (`private_link`)

-   `private_link.target_ai_service_name` : Specifies the name of the target AI Service resource for creating a Private Link connection
-   `private_link.request_message` : Description or message to be sent to the approver when requesting a Private Link connection
