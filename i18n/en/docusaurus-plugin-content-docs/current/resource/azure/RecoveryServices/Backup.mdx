## Resource Overview

Azure Backup is a **Recovery Services–based backup storage entity that stores backup data and supports recovery for various Azure services such as IaaS VMs and Azure SQL databases**.  
Backup policies define backup frequency, time, and retention, and backups are performed by registering VMs and file shares as protected items.

## Resource Setting Values

-   `sku` : Pricing tier for using the Recovery Services Vault - `Standard`, `RS0`
-   `soft_delete_enabled` : Whether to enable soft delete for the vault - `true`, `false`
-   `tag` : Tags for categorizing resources

#### VM Backup Policy (`vm_backup_policy`)

-   `vm_backup_policy.backup_frequency` : Frequency at which items are backed up - `Daily`, `Weekly`
-   `vm_backup_policy.backup_time` : Time at which items are backed up
-   `vm_backup_policy.weekly_backup_days` : List of days on which items are backed up - `Sunday`, `Monday`, `Tuesday`, `Wednesday`, `Thursday`, `Friday`, `Saturday`
-   `vm_backup_policy.timezone` : Time zone for the backup time
-   `vm_backup_policy.retention_count` : Number of daily backups to retain - `7` ~ `9999`

#### Protected VM (`protected_vm`)

-   `protected_vm.backup_policy_name` : Name of the backup policy to apply for backup

#### Share Backup Policy (`share_backup_policy`)

-   `share_backup_policy.backup_frequency` : Frequency at which items are backed up - `Daily`, `Hourly`
-   `share_backup_policy.backup_time` : Time at which items are backed up
-   `share_backup_policy.hourly_schedule` : Hourly backup interval - `4`, `6`, `8`, `12`
-   `share_backup_policy.hourly_duration` : Hourly backup duration - `4` ~ `23`
-   `share_backup_policy.timezone` : Time zone for the backup time
-   `share_backup_policy.daily_retention_count` : Number of daily backups to retain - `1` ~ `200`
-   `share_backup_policy.enabled_weekly_backup` : Whether to enable weekly backups - `true`, `false`
-   `share_backup_policy.weekly_backup_days` : List of days for weekly backups - `Sunday`, `Monday`, `Tuesday`, `Wednesday`, `Thursday`, `Friday`, `Saturday`
-   `share_backup_policy.weekly_retention_count` : Number of weekly backups to retain - `1` ~ `200`

#### Protected Share (`protected_share`)

-   `protected_share.source_storage_account_name` : Name of the Storage Account that contains the file share to back up
-   `protected_share.source_share_name` : Name of the file share to back up
-   `protected_share.backup_policy_name` : Name of the backup policy to apply for backup
