## 리소스 개요

Azure Backup은 **IaaS VM 및 Azure SQL 데이터베이스 등 다양한 Azure 서비스의 백업 데이터를 보관하고 복구를 지원하는 Recovery Services 기반 백업 스토리지 엔터티**입니다.  
백업 정책을 통해 백업 주기/시간/보존 기간을 정의하고, VM 및 파일 공유(File Share)를 보호 대상으로 등록하여 백업을 수행할 수 있습니다.

## 리소스 설정 값

-   `sku` : Recovery Services Vault 사용을 위한 가격 책정 계층 - `Standard`, `RS0`
-   `soft_delete_enabled` : Vault의 Soft delete 활성화 - `true`, `false`
-   `tag` : 리소스를 카테고리로 분류하기 위한 태그

#### VM Backup Policy (`vm_backup_policy`)

-   `vm_backup_policy.backup_frequency` : 항목이 백업되는 빈도 - `Daily`, `Weekly`
-   `vm_backup_policy.backup_time` : 항목이 백업되는 시간
-   `vm_backup_policy.weekly_backup_days` : 항목이 백업되는 요일 목록 - `Sunday`, `Monday`, `Tuesday`, `Wednesday`, `Thursday`, `Friday`, `Saturday`
-   `vm_backup_policy.timezone` : 백업 시간의 시간대
-   `vm_backup_policy.retention_count` : 일일 백업 보존 수 - `7` ~ `9999`

#### Protected VM (`protected_vm`)

-   `protected_vm.backup_policy_name` : 백업에 적용할 백업 정책 이름

#### Share Backup Policy (`share_backup_policy`)

-   `share_backup_policy.backup_frequency` : 항목이 백업되는 빈도 - `Daily`, `Hourly`
-   `share_backup_policy.backup_time` : 항목이 백업되는 시간
-   `share_backup_policy.hourly_schedule` : 시간당 백업 주기 - `4`, `6`, `8`, `12`
-   `share_backup_policy.hourly_duration` : 시간당 백업 지속시간 - `4` ~ `23`
-   `share_backup_policy.timezone` : 백업 시간의 시간대
-   `share_backup_policy.daily_retention_count` : 일일 백업 보존 수 - `1` ~ `200`
-   `share_backup_policy.enabled_weekly_backup` : 주간 백업 활성화 - `true`, `false`
-   `share_backup_policy.weekly_backup_days` : 주간 백업 요일 목록 - `Sunday`, `Monday`, `Tuesday`, `Wednesday`, `Thursday`, `Friday`, `Saturday`
-   `share_backup_policy.weekly_retention_count` : 주간 백업 보존 수 - `1` ~ `200`

#### Protected Share (`protected_share`)

-   `protected_share.source_storage_account_name` : 백업할 파일 공유의 Storage 계정 이름
-   `protected_share.source_share_name` : 백업할 파일 공유 이름
-   `protected_share.backup_policy_name` : 백업에 적용할 백업 정책 이름
