## Resource Overview

Azure Cosmos DB Mongo API is a fully managed NoSQL database service that stores and queries JSON-formatted data supported by the Mongo API.  
It provides scalability and high availability through global distribution, automatic failover, backups, and consistency policies.

## Resource Setting Values

#### Basic Settings

-   `capabilities_list` : List of Cosmos DB APIs to use
-   `enable_multiple_write_locations` : Whether to enable multi-region writes - `true`, `false`
-   `public_network_access_enabled` : Whether to enable public access to the account via public IP or service endpoints - `true`, `false`
-   `enable_automatic_failover` : Whether to enable automatic failover - `true`, `false`
-   `virtual_network_filter_enabled` : Whether to enable filtering so only specific virtual network subnets can access the account - `true`, `false`
-   `network_acl_bypass_for_azure_services` : Whether to enable ACL bypass for Azure services - `true`, `false`

#### Region Settings (`geo_location`)

-   `geo_location.failover_priority` : Failover priority of the region
-   `geo_location.zone_redundant` : Whether to enable automatic zone replication for fault tolerance - `true`, `false`

#### Consistency Policy (`consistency_policy`)

-   `consistency_policy.consistency_level` : Consistency level for database availability and performance
-   `consistency_policy.max_interval_in_seconds` : Allowed staleness interval (seconds) when consistency level is Bounded Staleness
-   `consistency_policy.max_staleness_prefix` : Maximum number of stale requests allowed when consistency level is Bounded Staleness

#### Backup Settings (`backup`)

-   `backup.type` : Backup policy type - `Continuous`, `Periodic`
-   `backup.interval_in_minutes` : Backup frequency in minutes - `60` ~ `1440`
-   `backup.retention_in_hours` : Backup retention period (hours) - `8` ~ `720`

#### Mongo Database Settings (`mongo_database`)

-   `mongo_database.throughput` : Throughput of the Mongo database - `400` ~ `1000000`
-   `mongo_database.enable_autoscale` : Whether to enable autoscale - `true`, `false`

#### Mongo Collection Settings (`mongo_collection`)

-   `mongo_collection.ttl_seconds` : Default Time To Live (TTL) for the MongoDB collection (seconds)
-   `mongo_collection.shard_key` : Key name used for MongoDB collection sharding
-   `mongo_collection.throughput` : Throughput of the MongoDB collection - `400` ~ `1000000`
-   `mongo_collection.enable_autoscale` : Whether to enable autoscale - `true`, `false`
-   `mongo_collection.included_mongo_database_name` : Name of the Mongo database where the collection will be created

#### Tags

-   `tag` : Tags for categorizing resources - up to 512 characters, `key`:`value`
