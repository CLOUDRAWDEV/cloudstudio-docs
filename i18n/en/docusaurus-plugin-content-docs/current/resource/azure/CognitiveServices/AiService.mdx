## Resource Overview

AI Service is a service that provides artificial intelligence models and analytics capabilities in the form of APIs, enabling easy integration of AI features into applications.  
It offers a secure and scalable AI service operating environment through model deployment, authentication methods, network access control, and managed identity integration.

## Resource Configuration Values

-   `sku_name` : Pricing tier for using the AI Service

    -   `F0`, `F1`, `S0`, `S`, `S1`, `S2`, `S3`, `S4`, `S5`, `S6`, `P0`, `P1`, `P2`, `E0`, `DC0`

-   `local_authentication_enabled` : Whether to enable local authentication using API keys - `true`, `false`

-   `custom_subdomain_name` : Custom subdomain name to be used for token-based authentication and endpoint URLs

-   `fqdns` : List of fully qualified domain names (FQDNs) allowed for use by the AI Service account

### Managed Identity Configuration (`identity`)

-   `identity.identity_type` : Type of managed identity to use

    -   `SystemAssigned`, `UserAssigned`, `SystemAssigned, UserAssigned`

-   `identity.identity_ids` : List of IDs for user-assigned managed identities

### Network Access Control (`network_acls`)

-   `network_acls.default_action` : Default network access control policy - `Allow`, `Deny`

-   `network_acls.ip_rules` : List of allowed IP addresses or CIDR ranges for accessing the resource

-   `outbound_network_access_restricted` : Whether to restrict outbound communication to external networks - `true`, `false`

-   `public_network_access` : Whether to allow access to the resource via the public Internet - `Enabled`, `Disabled`

### Model Deployment Configuration (`deployment`)

-   `deployment.model_name` : Name of the model to deploy

-   `deployment.model_version` : Version number of the model to use

-   `deployment.sku_name` : Type of processing capacity (SKU) assigned to the deployment

    -   `Standard`, `DataZoneBatch`, `DataZoneStandard`, `DataZoneProvisionedManaged`,  
        `GlobalBatch`, `GlobalProvisionedManaged`, `GlobalStandard`, `ProvisionedManaged`

-   `deployment.version_upgrade_option` : Model version upgrade strategy
    -   `OnceCurrentVersionExpired`, `OnceNewDefaultVersionAvailable`, `NoAutoUpgrade`
