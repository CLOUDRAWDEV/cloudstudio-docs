## Resource Overview

Azure VpnSite is a **VPN site definition resource used to connect on-premises networks to a Virtual WAN environment**.  
It defines the logical target for Site-to-Site VPN connections based on on-premises VPN device information, address spaces, and link details.

## Resource Setting Values

-   `linked_virtual_wan_name` : Name of the Virtual WAN to which the VPN Site will be connected
-   `device_vendor` : Vendor of the on-premises VPN device
-   `address_cidrs` : List of IP address ranges (CIDR) used by the VPN Site

#### Link (`link`)

-   `link.speed_in_mbps` : Maximum circuit speed of the link (Mbps)
-   `link.ip_address` : Public IP address assigned to the VPN device
-   `link.provider_name` : Name of the circuit provider
-   `link.autonomous_system_number` : ASN of the on-premises router when using BGP
-   `link.peering_address` : Local router IP address used for BGP peering
