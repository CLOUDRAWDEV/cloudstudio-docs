## Resource Overview

ExpressRoute Circuit is an Azure network resource that connects on-premises networks to the Microsoft cloud through a **private dedicated connection**.  
It provides stable connectivity without traversing the public internet and is commonly used in enterprise environments with high bandwidth, low latency, and strict security requirements.

## Associated Resources

### Parent Resource

-   [**ResourceGroup**](https://docs.cstudio.app/en/docs/resource/azure/Base/ResourceGroup)

## Resource Setting Values

-   `service_provider` : ISP provider that supplies the ExpressRoute circuit
-   `peering_location` : Peering location where the ISP provisions the circuit
-   `bandwidth_in_mbps` : Bandwidth of the ExpressRoute circuit (Mbps)
-   `sku_tier` : Pricing tier of the ExpressRoute circuit - `Basic`, `Local`, `Standard`, `Premium`
-   `sku_family` : Billing model for outbound data transfer - `MeteredData`, `UnlimitedData`
-   `authorization_names` : List of authorization names permitted to use the circuit
-   `tag` : Tags used to categorize resources - maximum 512 characters, `key`:`value`

#### Circuit Peering Settings (`circuit_peering`)

-   `circuit_peering.enabled_peering` : Whether the peering type is enabled - `true`, `false`
-   `circuit_peering.peer_asn` : ASN value used for BGP peering
-   `circuit_peering.primary_peer_address` : `/30` IPv4 subnet for the primary link
-   `circuit_peering.secondary_peer_address` : `/30` IPv4 subnet for the secondary link
-   `circuit_peering.vlan_id` : VLAN ID for peering configuration
-   `circuit_peering.advertised_public_prefixes` : List of public IPv4 address prefixes advertised through the BGP session
