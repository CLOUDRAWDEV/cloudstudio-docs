## Resource Overview

Network Interface is a network connectivity resource that enables a Virtual Machine to communicate with internal Virtual Network resources, the internet, and on-premises networks.  
It is associated with a Subnet and assigned IP addresses, and can optionally be connected to a Public IP for external communication.  
A single Network Interface can define multiple IP Configurations to support various network scenarios.

## Resource Setting Values

-   `included_subnet_name` : Name of the Subnet that contains the Network Interface

#### IP Configuration (`ip_configuration`)

-   `ip_configuration.is_primary` : Whether the primary IP Configuration is enabled - `true`, `false`
-   `ip_configuration.private_ip_address_allocation` : Private IP address allocation method - `Dynamic`, `Static`
-   `ip_configuration.private_ip_address` : Private IP address
-   `ip_configuration.enabled_public_ip` : Whether to use a Public IP - `true`, `false`
-   `ip_configuration.linked_public_ip_name` : Name of the Public IP to use

-   `tag` : Tags for categorizing resources - up to 512 characters, `key`:`value`
