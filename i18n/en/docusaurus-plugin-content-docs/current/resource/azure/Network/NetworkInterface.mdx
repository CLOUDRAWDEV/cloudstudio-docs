## Resource Overview

A Network Interface is a network connectivity resource that enables a Virtual Machine to communicate with resources inside a Virtual Network, the Internet, and on-premises networks.  
It belongs to a Subnet and is assigned an IP address, and a Public IP can be associated as needed to enable external communication.  
A single Network Interface can have multiple IP configurations, allowing it to support various networking scenarios.

## Resource Configuration Values

-   `included_subnet_name` : Name of the Subnet that includes the Network Interface

#### IP Configuration (`ip_configuration`)

-   `ip_configuration.is_primary` : Whether to enable the primary IP configuration - `true`, `false`
-   `ip_configuration.private_ip_address_allocation` : Private IP address allocation method - `Dynamic`, `Static`
-   `ip_configuration.private_ip_address` : Private IP address
-   `ip_configuration.enabled_public_ip` : Whether to use a Public IP - `true`, `false`
-   `ip_configuration.linked_public_ip_name` : Name of the Public IP to use

-   `tag` : Tags used to categorize the resource - up to 512 characters, `key`:`value`
