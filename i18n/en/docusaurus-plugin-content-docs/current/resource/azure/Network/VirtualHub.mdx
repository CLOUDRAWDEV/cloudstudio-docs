## Resource Overview

Azure Virtual Hub is a **regional hub resource responsible for centralized routing and network connectivity within a Virtual WAN environment**.  
It aggregates VPN, ExpressRoute, and VNet connections to control traffic flow and is used as a core component of a global network topology.

## Resource Configuration Values

-   `included_virtual_wan_name` : Name of the parent Virtual WAN to which the Virtual Hub is connected
-   `address_prefix` : Address space (CIDR block) used within the Virtual Hub
-   `hub_routing_preference` : Priority for selecting internet routing paths for traffic
    -   `ExpressRoute`
    -   `ASPath`
    -   `VpnGateway`

#### Connection (`connection`)

-   `connection.target_virtual_network_name` : Name of the target Virtual Network (VNet) to connect to the Virtual Hub
