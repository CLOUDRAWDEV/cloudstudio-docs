## Resource Overview

Virtual Network is a **virtual network resource** used to enable communication between Azure resources and to configure connectivity with the internet or on-premises networks.  
Based on the IP address space (Address Space), subnets, security policies, and peering can be configured to define the network structure of an Azure environment.

## Resource Setting Values

-   `vnet_address_space` : IP address space to be used by the Virtual Network

    -   One or more CIDR-formatted address ranges can be specified

-   `enable_ddos_protection` : Whether to apply a DDoS Protection Plan to the Virtual Network
    -   `true`, `false`
-   `ddos_protection_plan_name` : Name of the DDoS Protection Plan to associate with the Virtual Network

#### VNet Peering (`peering`)

Defines connection settings with other Virtual Networks.

-   `peering.linked_vnet_name` : Name of the target Virtual Network to connect (read-only)
-   `peering.allow_access_to_remote_vnet` : Whether to allow access to the remote Virtual Network
-   `peering.allow_receive_forwarded_traffic` : Whether to allow receiving forwarded traffic
-   `peering.allow_forward_traffic_to_remote_vnet` : Whether to allow forwarding traffic to the remote Virtual Network
-   `peering.allow_use_remote_gateway` : Whether to use the remote Virtual Network’s Gateway
    -   Values for each item: `true`, `false`

#### Tags

-   `tag` : Tags for categorizing resources
    -   Up to 512 characters, in `key`:`value` format
