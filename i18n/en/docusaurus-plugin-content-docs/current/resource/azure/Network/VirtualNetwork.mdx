## Resource Overview

Virtual Network is a **virtual network resource** that enables communication between Azure resources and provides connectivity to the internet or on-premises networks.  
Based on an IP address space, it allows defining subnets, security policies, and peering to structure the Azure network environment.

## Resource Setting Values

-   `vnet_address_space` : IP address space used by the Virtual Network

    -   One or more CIDR-formatted address ranges can be specified

-   `enable_ddos_protection` : Whether to apply a DDoS Protection Plan to the Virtual Network
    -   `true`, `false`
-   `ddos_protection_plan_name` : Name of the DDoS Protection Plan to associate with the Virtual Network

#### VNet Peering (`peering`)

Defines connectivity settings with other Virtual Networks.

-   `peering.linked_vnet_name` : Name of the target Virtual Network (read-only)
-   `peering.allow_access_to_remote_vnet` : Whether to allow access to the remote Virtual Network
-   `peering.allow_receive_forwarded_traffic` : Whether to allow forwarded traffic
-   `peering.allow_forward_traffic_to_remote_vnet` : Whether to allow forwarding traffic to the remote Virtual Network
-   `peering.allow_use_remote_gateway` : Whether to use the remote Virtual Network gateway
    -   Each value: `true`, `false`

#### Tags

-   `tag` : Tags used to categorize resources
    -   Maximum 512 characters, `key`:`value` format
