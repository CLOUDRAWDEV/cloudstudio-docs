## Resource Overview

A NAT Gateway is a resource that provides **outbound internet connectivity** for one or more Subnets within a Virtual Network.  
When associated with a Subnet, resources in that Subnet communicate outbound through the specified Public IP and do not expose inbound public endpoints.  
By configuring the idle connection timeout, you can maintain long-lived connections or quickly clean up unnecessary idle connections.

## Resource Configuration Values

-   `linked_subnet_names` : Names of the Subnets to associate with the NAT Gateway
-   `linked_public_ip_name` : Name of the Public IP to associate with the NAT Gateway
-   `idle_timeout_in_minutes` : Timeout (in minutes) for removing idle flows on the NAT Gateway - `4` ~ `120`
-   `tag` : Tags used to categorize the resource - up to 512 characters, `key`:`value`
