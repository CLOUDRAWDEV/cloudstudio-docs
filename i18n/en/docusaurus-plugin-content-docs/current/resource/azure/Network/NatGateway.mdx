## Resource Overview

NAT Gateway is a resource that provides **outbound internet connectivity** for one or more Subnets within a Virtual Network.  
When associated with a Subnet, resources in that Subnet communicate outbound using the specified Public IP, and no inbound public endpoints are exposed.  
By configuring the idle timeout for idle connections, long-lived connections can be maintained or unnecessary connections can be quickly cleared.

## Resource Configuration

#### Basic Settings

-   `linked_subnet_names` : Names of the Subnets to associate with the NAT Gateway
-   `linked_public_ip_name` : Name of the Public IP to associate with the NAT Gateway
-   `idle_timeout_in_minutes` : Idle flow timeout for the NAT Gateway (minutes) - `4` ~ `120`
-   `tag` : Tags used to categorize resources - maximum 512 characters, `key`:`value`
