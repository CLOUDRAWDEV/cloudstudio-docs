## Resource Overview

NAT Gateway is a resource that provides **outbound internet connectivity** for one or more Subnets within a Virtual Network.  
When connected to a Subnet, resources in that Subnet communicate externally through the specified Public IP and do not expose inbound public endpoints.
By adjusting the idle connection timeout, long-lived connections can be maintained or unnecessary connections can be cleaned up quickly.

## Resource Setting Values

-   `linked_subnet_names` : Names of the Subnets to which the Nat Gateway will be connected
-   `linked_public_ip_name` : Name of the Public IP to link to the Nat Gateway
-   `idle_timeout_in_minutes` : Time limit for removing idle flows on the Nat Gateway (minutes) - `4` ~ `120`
-   `tag` : Tags for categorizing resources - up to 512 characters, `key`:`value`
