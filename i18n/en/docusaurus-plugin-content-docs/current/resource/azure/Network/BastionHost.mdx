## Resource Overview

Bastion Host is an Azure PaaS network service that provides **secure RDP and SSH access** to virtual machines within a Virtual Network without directly exposing public IPs on the VMs.  
It supports browser-based access and enables a centralized access point without opening management ports, ensuring both security and operational convenience.

## Resource Setting Values

-   `included_subnet_name` : Name of the Subnet where the Bastion Host will be deployed
-   `sku` : SKU of the Bastion Host - `Basic`, `Standard`
-   `linked_public_ip_name` : Name of the Public IP to link to the Bastion Host
-   `ip_config_name` : Name of the IP Configuration used by the Bastion Host
-   `tag` : Tags for categorizing resources - up to 512 characters, `key`:`value`
