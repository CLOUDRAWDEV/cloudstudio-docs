## Resource Overview

A Bastion Host is an Azure PaaS networking service that provides **secure RDP and SSH access** to virtual machines within a Virtual Network without exposing public IP addresses directly to the VMs.  
It supports browser-based access and enables the creation of a centralized access point without opening management ports, ensuring both enhanced security and operational convenience.

## Resource Configuration Values

-   `included_subnet_name` : Name of the Subnet where the Bastion Host will be located
-   `sku` : SKU of the Bastion Host - `Basic`, `Standard`
-   `linked_public_ip_name` : Name of the Public IP to associate with the Bastion Host
-   `ip_config_name` : Name of the IP Configuration used by the Bastion Host
-   `tag` : Tags used to categorize the resource - up to 512 characters, `key`:`value`
