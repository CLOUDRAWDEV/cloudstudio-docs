## Resource Overview

Bastion Host is an Azure PaaS network service that provides **secure RDP and SSH access** to virtual machines within a Virtual Network without directly exposing public IPs on the VMs.  
It supports browser-based access and enables a centralized access point without opening management ports, improving both security and operational convenience.

## Resource Configuration

-   `included_subnet_name` : Name of the Subnet where the Bastion Host is deployed
-   `sku` : Bastion Host SKU - `Basic`, `Standard`
-   `linked_public_ip_name` : Name of the Public IP associated with the Bastion Host
-   `ip_config_name` : Name of the IP Configuration used by the Bastion Host
-   `tag` : Tags used to categorize resources - maximum 512 characters, `key`:`value`
