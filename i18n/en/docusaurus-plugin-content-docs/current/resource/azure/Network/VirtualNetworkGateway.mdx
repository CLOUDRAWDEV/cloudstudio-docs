## Resource Overview

Virtual Network Gateway is a network gateway that provides **encrypted traffic communication paths** between an Azure Virtual Network and an on-premises network or another Virtual Network.  
It can be connected using VPN or ExpressRoute, and is a core component for hybrid network configurations and secure dedicated connections.

## Resource Configuration Values

-   `included_subnet_name` : Name of the Subnet through which traffic is sent and received by the Virtual Network Gateway
-   `gateway_type` : Type of the Virtual Network Gateway - `Vpn`, `ExpressRoute`
-   `vpn_type` : Type of VPN connection - `RouteBased`, `PolicyBased`
-   `sku` : Pricing tier of the Virtual Network Gateway
-   `generation` : Generation of the Virtual Network Gateway - `Generation1`, `Generation2`
-   `enabled_active_active_mode` : Whether Active-Active mode is enabled
-   `enabled_configure_bgp` : Whether BGP is enabled
-   `tag` : Tags used to categorize the resource - up to 512 characters, `key`:`value`

#### IP Configuration (`ip_configuration`)

-   `ip_configuration.linked_public_ip_name` : Name of the Public IP to associate with the Virtual Network Gateway
