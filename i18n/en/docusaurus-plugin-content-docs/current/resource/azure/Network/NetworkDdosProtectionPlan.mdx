## Resource Overview

Network DDoS Protection Plan is a security service designed to protect Azure virtual network resources from large-scale distributed denial-of-service (DDoS) attacks.  
It maintains application availability through traffic analysis and automatic mitigation, and provides additional protection features when attacks occur.
