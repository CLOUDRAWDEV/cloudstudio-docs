## Resource Overview

Network DDoS Protection Plan is a security service designed to protect Azure virtual network resources from large-scale Distributed Denial of Service (DDoS) attacks.  
Through traffic analysis and automatic mitigation capabilities, it helps maintain application availability and provides additional protection features when an attack occurs.
