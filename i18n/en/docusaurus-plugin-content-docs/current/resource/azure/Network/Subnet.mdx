## Resource Overview

Subnet is a network created within a Virtual Network to deploy Azure resources.

## Resource Setting Values

-   `included_vnet_name` : Name of the Virtual Network that contains the Subnet
-   `address_prefixes` : IP address ranges for Subnet usage, specified as unique CIDR ranges within the Virtual Network address space
-   `private_link_endpoint_enabled` : Whether to allow Private Endpoint connections to the Subnet - `true`, `false`

#### Delegation Settings (`delegation`)

-   `delegation.service_name` : Name of the service to delegate
-   `delegation.actions` : List of actions to delegate
