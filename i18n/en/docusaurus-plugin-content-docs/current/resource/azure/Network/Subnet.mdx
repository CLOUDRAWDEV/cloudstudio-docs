## Resource Overview

A Subnet is a network created within a Virtual Network to deploy Azure resources into that Virtual Network.

## Resource Configuration

-   `included_vnet_name` : Name of the Virtual Network that contains the Subnet
-   `address_prefixes` : IP address range used by the Subnet, a unique address range specified in CIDR format within the Virtual Network address space
-   `private_link_endpoint_enabled` : Whether to allow Private Endpoint connections on the Subnet - `true`, `false`

#### Delegation Settings (`delegation`)

-   `delegation.service_name` : Name of the service to delegate
-   `delegation.actions` : List of actions to delegate
