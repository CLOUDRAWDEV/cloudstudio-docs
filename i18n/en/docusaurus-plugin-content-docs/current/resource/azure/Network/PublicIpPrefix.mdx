## Resource Overview

A Public IP Prefix is a network resource in Azure that allows you to reserve and manage a **contiguous range of public IP addresses** in advance.  
By allocating multiple Public IPs from a consistent address block, it provides predictability and operational convenience when managing firewall rules or integrating with external systems.

## Resource Configuration Values

-   `prefix_length` : Bit length of the Public IP Prefix - `28` ~ `31`
-   `tag` : Tags used to categorize the resource - up to 512 characters, `key`:`value`
