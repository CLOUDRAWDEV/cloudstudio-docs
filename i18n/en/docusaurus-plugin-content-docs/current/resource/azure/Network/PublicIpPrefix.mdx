## Resource Overview

Public IP Prefix is a network resource that allows you to pre-reserve and manage a **contiguous range of public IP addresses** in Azure.  
It enables allocation of multiple Public IPs from a consistent address block, improving predictability and operational efficiency for firewall rules and external integrations.

## Resource Configuration

-   `prefix_length` : Bit length of the Public IP Prefix - `28` ~ `31`
-   `tag` : Tags used to categorize resources - maximum 512 characters, `key`:`value`
