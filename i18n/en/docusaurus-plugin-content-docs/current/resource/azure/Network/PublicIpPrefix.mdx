## Resource Overview

Public IP Prefix is a network resource that allows you to **pre-reserve and manage a contiguous range of public IP addresses** in Azure.  
It enables multiple Public IPs to be allocated from a consistent address block, providing predictability and operational convenience when managing firewall rules or external integrations.

## Resource Setting Values

-   `prefix_length` : Bit length of the Public IP Prefix - `28` ~ `31`
-   `tag` : Tags for categorizing resources - up to 512 characters, `key`:`value`
