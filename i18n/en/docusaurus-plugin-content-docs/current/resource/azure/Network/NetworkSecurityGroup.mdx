## Resource Overview

Network Security Group is a security resource that controls inbound and outbound network traffic to Azure resources within a Virtual Network using rule-based filtering.
Through priority-based security rules, traffic can be allowed or denied by protocol, port, and IP address range, and applied at the Subnet or Network Interface level.
This enables precise control over network access and strengthens the overall security posture of applications.

## Resource Setting Values

-   `linked_subnet_names` : Names of the Subnets to which the Network Security Group will be linked
-   `linked_network_interface_names` : Names of the Network Interfaces to which the Network Security Group will be linked

#### Security Rules (`security_rules`)

-   `security_rules.priority` : Rule priority - `100` ~ `4096`
-   `security_rules.direction` : Traffic direction to which the rule applies - `Inbound`, `Outbound`
-   `security_rules.access` : Whether to allow or deny network traffic - `Allow`, `Deny`
-   `security_rules.protocol` : Network protocol applied by the rule - `Tcp`, `Udp`, `Icmp`, `Esp`, `Ah`, `*`
-   `security_rules.source_port_ranges` : Source port or port range - integer or `0` ~ `65535`
-   `security_rules.destination_port_ranges` : Destination port or port range - integer or `0` ~ `65535`
-   `security_rules.source_address_prefixes` : CIDR or source IP address range
-   `security_rules.destination_address_prefixes` : CIDR or destination IP address range
-   `security_rules.description` : Description of the security rule

#### Tags

-   `tag` : Tags for categorizing resources - up to 512 characters, `key`:`value`
