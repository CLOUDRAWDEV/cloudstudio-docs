## Resource Overview

Firewall Policy is a **centralized firewall policy management resource** used by Azure Firewall.  
By defining network rules, application rules, and NAT rules within a single policy, it can be consistently applied across multiple Firewall instances, improving policy reusability and operational efficiency.
