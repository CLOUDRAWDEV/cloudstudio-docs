## Resource Overview

Azure Virtual WAN is a **global network hub service** designed to centrally connect and manage network resources distributed across multiple regions.  
It enables unified management of Site-to-Site VPN, Point-to-Site VPN, and ExpressRoute connections from a single control plane, making it suitable for large-scale multi-region network architectures.
