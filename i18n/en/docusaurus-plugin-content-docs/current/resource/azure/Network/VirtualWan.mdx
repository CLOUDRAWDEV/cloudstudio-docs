## Resource Overview

Azure Virtual WAN is a **global network hub service** designed to centrally connect and manage distributed network resources across multiple regions.  
It integrates Site-to-Site VPN, Point-to-Site VPN, and ExpressRoute connections through a single control plane and is well suited for large-scale multi-region network architectures.
