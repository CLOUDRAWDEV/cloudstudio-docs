## Resource Overview

Private Endpoint is a network resource that provides **private connectivity (Private Link)** to Azure services within a Virtual Network without using public IP addresses.  
Service endpoints are exposed through Private IPs assigned to a Subnet, enabling secure communication paths that do not traverse the internet.  
By integrating with Private DNS Zones, service FQDNs can be resolved naturally within the internal network.

## Resource Setting Values

#### Basic Settings

-   `included_subnet_name` : Name of the Subnet that contains the Private IP address assigned to the Private Endpoint
-   `connection_name` : Name of the connection between the Private Endpoint and the resource
-   `linked_connection_resource_name` : Name of the resource to which the Private Endpoint is connected
-   `subresource_name` : Name of the subresource to which the Private Endpoint is connected
-   `dns_zone_group_name` : Name of the Private DNS Zone group associated with the Private Endpoint
-   `private_dns_zone_names` : List of Private DNS Zone names to associate with the Private Endpoint
-   `manual_connection` : Whether manual approval from the external resource owner is required - `true`, `false`
-   `tag` : Tags used to categorize resources - maximum 512 characters, `key`:`value`
