## Resource Overview

A Private Endpoint is a network resource that provides **private connectivity (Private Link)** to Azure services within a Virtual Network without using a public IP address.  
The service endpoint is exposed through a Private IP assigned to a Subnet, enabling a secure communication path that does not traverse the Internet.  
By integrating with a Private DNS Zone, the service FQDN can be naturally resolved within the internal network.

## Resource Configuration Values

-   `included_subnet_name` : Name of the Subnet that contains the Private IP address assigned to the Private Endpoint
-   `connection_name` : Name of the connection between the Private Endpoint and the resource
-   `linked_connection_resource_name` : Name of the resource to which the Private Endpoint will be connected
-   `subresource_name` : Name of the subresource to which the Private Endpoint will be connected
-   `dns_zone_group_name` : Name of the Private DNS Zone group to associate with the Private Endpoint
-   `private_dns_zone_names` : List of Private DNS Zone names to associate with the Private Endpoint
-   `manual_connection` : Whether manual approval by the external resource owner is required - `true`, `false`
-   `tag` : Tags used to categorize the resource - up to 512 characters, `key`:`value`
