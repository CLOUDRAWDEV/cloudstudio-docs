## Resource Overview

A Public IP is a network resource that provides a public IP address, enabling Azure resources to perform **direct inbound and outbound communication** with the Internet.  
It integrates with services such as Load Balancers, Virtual Machines, and NAT Gateways to act as an entry point for incoming traffic or an outbound egress, and its availability and behavior vary depending on the SKU and allocation method.

## Resource Configuration Values

-   `sku` : Pricing tier of the Public IP - `Standard`, `Basic`
-   `allocation_method` : Public IP address allocation method - `Static`, `Dynamic`
-   `tag` : Tags used to categorize the resource - up to 512 characters, `key`:`value`
