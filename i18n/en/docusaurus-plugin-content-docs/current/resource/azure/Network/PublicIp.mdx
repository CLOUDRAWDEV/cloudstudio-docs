## Resource Overview

Public IP is a network resource that provides a public IP address allowing Azure resources to perform **direct inbound and outbound communication** with the internet.  
It works in conjunction with services such as Load Balancer, Virtual Machine, and NAT Gateway, serving as an ingress point for external traffic or an outbound egress point.  
Availability and behavior characteristics vary depending on the SKU and allocation method.

## Resource Setting Values

-   `sku` : Pricing tier of the Public IP - `Standard`, `Basic`
-   `allocation_method` : Allocation method for the Public IP address - `Static`, `Dynamic`
-   `tag` : Tags used to categorize resources - maximum 512 characters, `key`:`value`
