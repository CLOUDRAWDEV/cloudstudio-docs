## Resource Overview

Public IP is a network resource that provides a public IP address allowing Azure resources to **communicate directly inbound and outbound with the internet**.  
It integrates with Load Balancer, Virtual Machine, NAT Gateway, and others to serve as an external traffic entry point or outbound exit, and its availability and behavior vary depending on SKU and allocation method.

## Resource Setting Values

-   `sku` : Pricing tier of the Public IP - `Standard`, `Basic`
-   `allocation_method` : Allocation method of the Public IP address - `Static`, `Dynamic`
-   `tag` : Tags for categorizing resources - up to 512 characters, `key`:`value`
