## Resource Overview

A Route Table is an Azure network resource that is applied to Subnets within a Virtual Network to **customize and control network traffic routing**.  
In addition to the default system routes, you can explicitly define traffic flows to destinations such as virtual appliances, the Internet, or gateways.

## Resource Configuration Values

-   `enable_bgp_route_propagation` : Whether to enable gateway route propagation - `true`, `false`
-   `linked_subnet_names` : List of Subnet names to associate with the Route Table
-   `tag` : Tags used to categorize the resource - up to 512 characters, `key`:`value`

#### Route Configuration (`route`)

-   `route.route_address_prefix` : IP address prefix (CIDR) that represents the route
-   `route.next_hop_type` : Type of the next hop
    -   `VirtualNetworkGateway`
    -   `VnetLocal`
    -   `Internet`
    -   `VirtualAppliance`
    -   `None`
