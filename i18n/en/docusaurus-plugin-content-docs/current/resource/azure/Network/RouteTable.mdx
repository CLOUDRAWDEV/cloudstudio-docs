## Resource Overview

Route Table is an Azure network resource applied to Subnets within a Virtual Network to **control network traffic paths in a user-defined manner**.  
In addition to default system routing, traffic flows to virtual appliances, the internet, gateways, and more can be explicitly specified.

## Resource Setting Values

-   `enable_bgp_route_propagation` : Whether gateway route propagation is enabled - `true`, `false`
-   `linked_subnet_names` : List of Subnet names to which the Route Table will be associated
-   `tag` : Tags for categorizing resources - up to 512 characters, `key`:`value`

#### Route Settings (`route`)

-   `route.route_address_prefix` : IP address prefix representing the route (CIDR)
-   `route.next_hop_type` : Type of the next hop
    -   `VirtualNetworkGateway`
    -   `VnetLocal`
    -   `Internet`
    -   `VirtualAppliance`
    -   `None`
