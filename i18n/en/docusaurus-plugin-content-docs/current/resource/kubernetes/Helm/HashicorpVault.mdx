## Resource Overview

A Helm chart for installing Hashicorp Vault.

## Associated Resources

### Parent Resource

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

## Resource Setting Values

#### Basic Settings

-   `namespace` : Namespace where the Hashicorp Vault Helm Chart resource will be deployed
-   `version` : Version of the Hashicorp Vault Helm Chart to use
-   `set` : Key-value settings used to dynamically override values of the base Hashicorp Vault Helm Chart
