## Resource Overview

A Helm chart for installing Cert-Manager.

## Associated Resources

### Parent Resource

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

## Resource Setting Values

#### Basic Settings

-   `namespace` : Namespace where the Cert Manager Helm Chart will be deployed
-   `version` : Version of the Cert Manager Helm Chart to use
-   `installCRDs` : Whether to install Custom Resource Definitions (CRDs) used by Cert Manager
