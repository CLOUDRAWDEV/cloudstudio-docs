## Resource Configuration

#### Basic Settings

-   `namespace` : Namespace where the Istiod Helm Chart resource will be deployed
-   `version` : Version of the Istiod Helm Chart to use
-   `set` : Key-value configuration used to dynamically override values of the base Istiod Helm Chart
