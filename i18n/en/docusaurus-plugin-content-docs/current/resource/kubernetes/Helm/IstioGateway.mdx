## Resource Configuration

#### Basic Settings

-   `namespace` : Namespace where the Istio Gateway Helm Chart resource will be deployed
-   `version` : Version of the Istio Ingress Helm Chart to use
-   `set` : Key-value configuration used to dynamically override values of the base Istio Ingress Helm Chart
