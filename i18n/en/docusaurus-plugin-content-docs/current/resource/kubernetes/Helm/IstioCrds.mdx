## Resource Overview

A Helm chart for Istio Custom Resource Definitions.

## Associated Resources

### Parent Resource

-   [**Namespace**](https://docs.cstudio.app/en/docs/resource/kubernetes/Core/Namespace)

## Resource Setting Values

#### Basic Settings

-   `namespace` : Namespace where the Istio CRDs Helm Chart resource will be deployed
-   `version` : Version of the Istio CRDs Helm Chart to use
-   `set` : Key-value configuration used to dynamically override values of the base Istio CRDs Helm Chart
