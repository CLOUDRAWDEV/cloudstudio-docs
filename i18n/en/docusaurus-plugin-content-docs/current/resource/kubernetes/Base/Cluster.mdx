## Resource Overview

Selects a Cluster connected to the user Credential.

## Resource Setting Values

#### Basic Settings

-   `target_cluster` : Select the Ncloud Kubernetes cluster to connect
-   `token` : Authentication token used to connect to Ncloud Kubernetes Service
