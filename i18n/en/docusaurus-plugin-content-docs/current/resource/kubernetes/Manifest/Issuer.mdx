## Resource Overview

A Kubernetes resource that accepts Certificate Signing Requests and generates signed certificates from a Certificate Authority (CA).

## Associated Resources

### Parent Resource

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

### Connected Resources

-   [**Ingress**](https://docs.cstudio.app/docs/resource/kubernetes/Networking/Ingress)

## Resource Setting Values

#### Basic Settings

-   `namespace` : Namespace where the Issuer resource will be deployed
-   `acme.server` : Endpoint address of the ACME Certificate Authority server
-   `acme.email` : Email address to receive certificate expiration and issue notifications
-   `acme.private_key_secret_ref` : Name of the Secret storing the client key used for ACME server communication
-   `dns_solvers` : Settings for using DNS-01 challenges - `AzureDNS`, `Route53`, `ACMEDNS`
-   `http_solvers.provider` : HTTP-01 challenge handling method - `Ingress`, `Gateway`
-   `http_solvers.ingress_class_name` : Name of the Ingress Class to use for HTTP-01 challenges
-   `http_solvers.gateway_parent_refs` : Gateway information referenced when configuring Gateway-based HTTP-01 challenges

#### HTTP Challenge Settings (`http_solvers`)

-   `http_solvers.provider` : HTTP-01 challenge resolution method - `Ingress`, `Gateway`
-   `http_solvers.ingress_class_name` : Name of the Ingress Class to use

##### Gateway Settings

-   `http_solvers.gateway_parent_refs.name` : Name of the Gateway resource to connect
-   `http_solvers.gateway_parent_refs.namespace` : Namespace of the Gateway resource
