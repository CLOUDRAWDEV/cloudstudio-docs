## Resource Overview

ClusterIssuer is a cluster-scoped Kubernetes resource used by cert-manager. It serves as a configuration unit for receiving Certificate Signing Requests (CSRs) and obtaining signed certificates from a Certificate Authority (CA). Unlike Issuer, it is not bound to a specific namespace and can be commonly referenced by Certificate resources across the entire cluster. It uses ACME-based Certificate Authorities (e.g., Let’s Encrypt) and verifies domain ownership through HTTP-01 or DNS-01 challenges.

## Resource Setting Values

#### Basic Settings

#### ACME Settings (`acme`)

-   `acme.server` : Endpoint address of the ACME server
-   `acme.email` : Email address for receiving notifications about certificate-related issues or expiration from Let's Encrypt
-   `acme.private_key_secret_ref` : Specifies the name of the Kubernetes Secret that stores the client key used for communication with the ACME server

#### DNS Solver Settings (`dns_solvers`)

-   `dns_solvers.provider` : DNS-01 challenge type selection - `AzureDNS`, `Route53`, `ACMEDNS`

#### ACME DNS Settings (`dns_solvers.acme_dns`)

-   `dns_solvers.acme_dns.host` : Endpoint address of the acme-dns server
-   `dns_solvers.acme_dns.account_secret_ref_name` : Specifies the name of the Kubernetes Secret that stores account information for the acme-dns server
-   `dns_solvers.acme_dns.account_secret_ref_key` : Specifies the key name to use from the Kubernetes Secret storing account information for the acme-dns server

#### Azure DNS Settings (`dns_solvers.azure_dns`)

-   `dns_solvers.azure_dns.client_id` : Client ID of the Azure Service Principal application
-   `dns_solvers.azure_dns.client_secret_name` : Specifies the name of the Kubernetes Secret containing the client secret of the Azure Service Principal application
-   `dns_solvers.azure_dns.client_secret_key` : Specifies the key name to use from the Secret
-   `dns_solvers.azure_dns.subscription_id` : ID of the Azure subscription
-   `dns_solvers.azure_dns.tenant_id` : Tenant ID of the Azure subscription
-   `dns_solvers.azure_dns.resource_group_name` : Specifies the resource group to which the Azure DNS Zone belongs
-   `dns_solvers.azure_dns.hosted_zone_name` : Specifies the hosted zone name of the Azure DNS Zone

#### Route53 Settings (`dns_solvers.route53`)

-   `dns_solvers.route53.region` : Specifies the AWS region where the Route 53 service is used
-   `dns_solvers.route53.access_key_id` : AWS access key ID
-   `dns_solvers.route53.access_key_secret_name` : Specifies the name of the Kubernetes Secret containing the AWS secret access key
-   `dns_solvers.route53.access_key_secret_key` : Specifies the key name to use from the Secret
-   `dns_solvers.route53.secret_access_key_secret_name` : Specifies the name of the Secret containing the AWS secret access key
-   `dns_solvers.route53.secret_access_key_secret_key` : Specifies the key name of the Secret containing the AWS secret access key
-   `dns_solvers.route53.role` : Specifies the AWS IAM role that can manage Route53 DNS

#### HTTP Solver Settings (`http_solvers`)

-   `http_solvers.provider` : Specifies the type for solving HTTP-01 challenges - `Ingress`, `Gateway`
-   `http_solvers.ingress_class_name` : Specifies which Ingress class to use

#### Gateway Settings (`http_solvers.gateway_parent_refs`)

-   `http_solvers.gateway_parent_refs.name` : Specifies the name of the Gateway resource to connect
-   `http_solvers.gateway_parent_refs.namespace` : Specifies the namespace of the Gateway resource to connect
