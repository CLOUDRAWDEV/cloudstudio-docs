## Resource Overview

A Kubernetes resource used to run one-time tasks.

## Resource Setting Values

#### Basic Settings

-   `namespace` : Namespace where the Job resource will be deployed
-   `restart_policy` : Handling policy after container failure or Job completion (Never / OnFailure)
-   `backoff_limit` : Number of retries before marking the Job as failed
-   `wait_for_completion` : Whether to block creation or updates until the Job completes or fails
-   `containers` : Definition of container specifications to be executed
-   `init_containers` : Definition of pre-tasks executed before the main container
-   `volume` : Volume configuration to be mounted in the container
-   `pod_security_context` : Pod-level security context configuration
-   `image_pull_secrets` : Secret references for pulling images
