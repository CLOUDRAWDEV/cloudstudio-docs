## Resource Overview

NetworkPolicy is a Kubernetes resource that selects Pods based on labels and defines allowed inbound (Ingress) and outbound (Egress) network traffic rules for those Pods. It is applied at the namespace level and is used to implement fine-grained network access control in clusters where all traffic is allowed by default.

## Resource Setting Values

#### Basic Settings

-   `annotations` : Metadata key-value pairs for the NetworkPolicy resource
-   `labels` : User-defined labels for identifying NetworkPolicy objects
-   `match_expressions` : Pod selection rules using label selector expressions
-   `match_labels` : Label conditions in key-value format for selecting Pods
-   `ingress` : Allowed rules for traffic entering selected Pods - `from IPBlock`, `NamespaceSelector`, `PodSelector`, `Port`
-   `egress` : Allowed rules for traffic leaving selected Pods - `to IPBlock`, `NamespaceSelector`, `PodSelector`, `Port`
-   `policy_types` : Types of policies to apply (Ingress, Egress)
