## Resource Overview

NetworkPolicy is a Kubernetes resource that selects Pods based on labels and defines allowed inbound (Ingress) and outbound (Egress) network traffic rules for those Pods. It is applied at the namespace level and is used to implement fine-grained network access control in clusters that allow all traffic by default.

## Resource Configuration

#### Basic Settings

-   `annotations` : Metadata key-value for the NetworkPolicy resource
-   `labels` : User-defined labels used to identify the NetworkPolicy object
-   `match_expressions` : Pod selection rules using label selector expressions
-   `match_labels` : Label conditions in key-value format used to select Pods
-   `ingress` : Allowed rules for incoming traffic to selected Pods - `from IPBlock`, `NamespaceSelector`, `PodSelector`, `Port`
-   `egress` : Allowed rules for outgoing traffic from selected Pods - `to IPBlock`, `NamespaceSelector`, `PodSelector`, `Port`
-   `policy_types` : Types of policies to apply (Ingress, Egress)
