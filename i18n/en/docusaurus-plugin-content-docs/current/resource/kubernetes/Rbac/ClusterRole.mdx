## Resource Overview

A Kubernetes resource that creates roles applied at the cluster level and across all namespaces.

## Associated Resources

### Parent Resource

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)

### Connected Resources

-   [**ClusterRoleBinding**](https://docs.cstudio.app/docs/resource/kubernetes/RBAC/ClusterRoleBinding)

## Resource Setting Values

#### Basic Settings

-   `annotations` : Key-value pairs used to specify information required by the Kubernetes system
-   `labels` : User-defined values for object identification

#### Policy Rules (`rule`)

-   `rule.rule_type` : Rule type for ClusterRole - `ApiGroup`, `ResourceUrl`
-   `rule.api_groups` : API Groups containing the resources to allow operations on
-   `rule.resources` : List of resources to which this rule applies
-   `rule.resource_names` : Specifies individual resource instances when selected
-   `rule.non_resource_urls` : Used when specifying rules for URL-formatted non-resource endpoints
-   `rule.verbs` : List of verbs applied to all resources in the rule - `get`, `list`, `create`, `update`, `patch`, `watch`, `delete`, `deletecollection`
