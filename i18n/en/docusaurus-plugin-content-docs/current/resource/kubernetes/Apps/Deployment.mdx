## Resource Overview

A Kubernetes service that ensures a specified number of Pod replicas are running at all times.

## Resource Setting Values

#### Basic Settings

-   `namespace` : Namespace where the Deployment resource will be deployed
-   `annotations` : Kubernetes system metadata key-value pairs
-   `labels` : Labels for identifying the Deployment resource
-   `template_labels` : Labels applied to the Pods to be created
-   `replicas` : Number of Pod replicas to maintain
-   `pod_security_context` : Pod-level security and permission settings
-   `init_containers` : Definitions of initialization containers executed before the main container
-   `containers` : Definitions of containers included in the Pod
-   `volume` : Volume definitions to be used by the Pod
-   `dns_policy` : Pod DNS policy
-   `enable_service_links` : Whether to automatically inject service environment variables
-   `host_network` : Whether to use the host network
-   `image_pull_secrets` : List of Secrets to use when pulling images
