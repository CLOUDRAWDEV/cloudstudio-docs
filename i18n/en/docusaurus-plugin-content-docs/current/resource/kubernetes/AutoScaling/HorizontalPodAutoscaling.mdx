## Resource Overview

A Kubernetes resource that automatically scales the number of Pods in a Deployment, ReplicaSet, or StatefulSet based on observed CPU utilization.

## Associated Resources

### Parent Resource

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

### Connected Resources

-   [**Deployment**](https://docs.cstudio.app/docs/resource/kubernetes/Apps/Deployment)
-   [**StatefulSet**](https://docs.cstudio.app/docs/resource/kubernetes/Apps/StatefulSet)

## Resource Setting Values

#### Basic Settings

-   `namespace` : Namespace where the HPA resource will be deployed
-   `annotations` : Kubernetes system metadata key-value pairs
-   `labels` : Labels for identifying the HPA resource
-   `min_replicas` : Minimum number of Pods to maintain during autoscaling
-   `max_replicas` : Maximum number of Pods to maintain during autoscaling
-   `target_cpu_utilization_percentage` : Target value for average Pod CPU utilization
-   `scale_target_ref` : Reference to the controller resource to be scaled (Deployment, StatefulSet)
