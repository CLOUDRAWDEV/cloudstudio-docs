## Resource Overview

A Kubernetes resource used to select the Ingress Controller that an Ingress will use.

## Associated Resources

### Parent Resource

-   [**Cluster**](https://docs.cstudio.app/en/docs/resource/kubernetes/Base/Cluster)

### Connected Resources

-   [**Ingress**](https://docs.cstudio.app/en/docs/resource/kubernetes/Networking/Ingress)

---

## Resource Configuration

#### Basic Settings

-   `annotations` : Metadata key-value required for IngressClass behavior in the Kubernetes system
-   `labels` : User-defined labels used to distinguish the IngressClass object
-   `controller` : Identifier of the Ingress Controller that handles this IngressClass

#### Parameter Settings (`parameters`)

-   `parameters.kind` : Referenced parameter resource type - `IngressParameter`, `ClusterIngressParameter`
-   `parameters.namespace` : Namespace of the referenced parameter resource
-   `parameters.api_group` : API Group to which the referenced parameter resource belongs
