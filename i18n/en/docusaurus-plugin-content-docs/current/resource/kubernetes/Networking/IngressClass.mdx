## Resource Overview

A Kubernetes resource used to select the Ingress Controller that an Ingress will use.

## Associated Resources

### Parent Resource

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)

### Connected Resources

-   [**Ingress**](https://docs.cstudio.app/docs/resource/kubernetes/Networking/Ingress)

## Resource Setting Values

#### Basic Settings

-   `annotations` : Metadata key-value pairs required for IngressClass behavior in the Kubernetes system
-   `labels` : User-defined labels for identifying IngressClass objects
-   `controller` : Identifier of the Ingress Controller that will handle this IngressClass

#### Parameter Settings (`parameters`)

-   `parameters.kind` : Type of parameter resource to reference - `IngressParameter`, `ClusterIngressParameter`
-   `parameters.namespace` : Namespace of the referenced parameter resource
-   `parameters.api_group` : API Group to which the referenced parameter resource belongs
