## Resource Overview

A Kubernetes resource that defines rules allowing inbound connections to reach backend-defined endpoints.

## Resource Setting Values

#### Basic Settings

-   `namespace` : Namespace where the Ingress resource will be deployed
-   `annotations` : Key-value pairs used to specify information required by the Kubernetes system
-   `labels` : User-defined values for object identification
-   `ingress_class_name` : Specifies the name of the Ingress Class to associate

#### TLS Settings (`tls`)

-   `tls.hosts` : List of hosts included in the TLS certificate
-   `tls.secret_name` : Specifies the name of the Kubernetes Secret related to the TLS certificate

#### Routing Rules (`rule`)

-   `rule.host` : Specifies the hostname address to which the routing rule applies

#### Backend Settings (`rule.backend`)

-   `rule.backend.target_service` : Target backend service
-   `rule.backend.path` : Path connected to the backend
-   `rule.backend.port` : Service port number
-   `rule.backend.path_type` : Determines path matching behavior - `ImplementationSpecific`, `Prefix`, `Exact`
