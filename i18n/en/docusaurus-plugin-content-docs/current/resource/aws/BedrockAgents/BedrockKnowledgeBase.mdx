## Resource Overview

An AWS Bedrock resource for creating and managing vector- or text-based knowledge bases.

## Resource Setting Values

#### Knowledge Base Configuration (`knowledge_base_configuration`)

-   `knowledge_base_configuration.type` : Knowledge base type - `VECTOR`
-   `knowledge_base_configuration.vector_knowledge_base_configuration.embedding_model_arn` : ARN of the model used to generate embeddings

#### Storage Configuration (`storage_configuration`)

-   `storage_configuration.type` : Storage type to use - `OPENSEARCH_SERVERLESS`, `PINECONE`, `REDIS_ENTERPRISE_CLOUD`, `RDS`

> Configure the corresponding block below based on the value of `storage_configuration.type`.

##### OpenSearch Serverless Configuration (`opensearch_serverless_configuration`)

-   `storage_configuration.opensearch_serverless_configuration.target_opensearch_collection` : ARN of the OpenSearch Serverless collection to connect
-   `storage_configuration.opensearch_serverless_configuration.vector_index_name` : Index name for storing vector data
-   `storage_configuration.opensearch_serverless_configuration.vector_field` : Field name for vector (embedding) data
-   `storage_configuration.opensearch_serverless_configuration.text_field` : Field name for original text data
-   `storage_configuration.opensearch_serverless_configuration.metadata_field` : Field name for metadata

##### Pinecone Configuration (`pinecone_configuration`)

-   `storage_configuration.pinecone_configuration.connection_string` : Pinecone index connection URL/endpoint
-   `storage_configuration.pinecone_configuration.credentials_secret_arn` : Secrets Manager ARN storing the Pinecone API key
-   `storage_configuration.pinecone_configuration.namespace` : Pinecone namespace name
-   `storage_configuration.pinecone_configuration.text_field` : Field name for original text data
-   `storage_configuration.pinecone_configuration.metadata_field` : Field name for metadata

##### RDS Configuration (`rds_configuration`)

-   `storage_configuration.rds_configuration.credentials_secret_arn` : Secrets Manager ARN storing DB connection credentials
-   `storage_configuration.rds_configuration.database_name` : Target RDS database name
-   `storage_configuration.rds_configuration.resource_arn` : ARN of the RDS instance/cluster
-   `storage_configuration.rds_configuration.table_name` : Table name for storing vector/text data
-   `storage_configuration.rds_configuration.primary_key_field` : Primary key field name
-   `storage_configuration.rds_configuration.text_field` : Field name for original text data
-   `storage_configuration.rds_configuration.vector_field` : Field name for embedding vector data
-   `storage_configuration.rds_configuration.metadata_field` : Field name for metadata

##### Redis Enterprise Cloud Configuration (`redis_enterprise_cloud_configuration`)

-   `storage_configuration.redis_enterprise_cloud_configuration.credentials_secret_arn` : Secrets Manager ARN storing access credentials
-   `storage_configuration.redis_enterprise_cloud_configuration.endpoint` : Redis Enterprise Cloud endpoint
-   `storage_configuration.redis_enterprise_cloud_configuration.vector_index_name` : Vector search index name
-   `storage_configuration.redis_enterprise_cloud_configuration.text_field` : Field name for original text data
-   `storage_configuration.redis_enterprise_cloud_configuration.metadata_field` : Field name for metadata
-   `storage_configuration.redis_enterprise_cloud_configuration.vector_field` : Field name for embedding vector data
