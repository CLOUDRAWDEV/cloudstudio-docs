## Resource Overview

A service that allows customers to privately connect to supported AWS services and VPC endpoint services.

## Resource Configuration

#### Basic Settings

-   `acceptance_required` : Whether the service owner must accept VPC endpoint connection requests - `true`, `false`
-   `load_balancer_type` : Load balancer type connected to the Endpoint Service - `network`, `gateway`
-   `linked_lb_names` : List of load balancer names connected to the Endpoint Service
-   `manual_lb_arns` : List of load balancer ARNs connected to the Endpoint Service
-   `supported_ip_address_types` : Supported IP address types - `ipv4`
-   `activate_private_dns_name` : Private DNS name configured for the service

#### Tags

-   `tag` : Tags used to categorize the resource
