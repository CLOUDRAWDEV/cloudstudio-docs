## Resource Overview

An AWS VPC (Virtual Private Cloud) Route Table is an AWS resource that defines where traffic from subnets within a VPC is directed. Every subnet in a VPC is associated with one or more route tables, and route tables specify routing rules for targets such as Internet Gateways, NAT Gateways, VPC Endpoints, or VPN connections.  
Traffic is routed according to the order of routing rules, and all traffic generated from a subnet is forwarded to its destination through the associated route table. This allows subnets within a VPC to securely communicate with the internet or other VPCs.

## Resource Setting Values

#### Basic Settings

-   `included_vpc_name` : Name of the VPC that contains the Route Table
-   `subnet_names` : List of Subnet names to associate with the Route Table

#### Routing Paths (`linked_route`)

-   `linked_route.cidr_block` : CIDR block of the destination resource
-   `linked_route.resource_type` : Destination resource type - `internet_gateway`, `ec2_instance`, `nat_gateway`, `transit_gateway`, `vpc_peering`
-   `linked_route.linked_resource_name` : Name of the destination resource

#### Tags

-   `tag` : Tags used to categorize resources
