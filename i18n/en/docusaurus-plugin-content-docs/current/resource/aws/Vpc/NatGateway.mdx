## Resource Overview

A NAT Gateway enables instances in a private subnet to connect to services outside the VPC while preventing external services from initiating connections to those instances.

## Associated Resources

### Parent Resource

-   [**Subnet**](https://docs.cstudio.app/en/docs/resource/aws/Vpc/Subnet)

### Connected Resources

-   [**Eip**](https://docs.cstudio.app/en/docs/resource/aws/Ec2/Eip)
-   [**RouteTable**](https://docs.cstudio.app/en/docs/resource/aws/Network/RouteTable)

## Resource Setting Values

#### Basic Settings

-   `included_subnet_name` : Name of the subnet associated with the NAT Gateway
-   `connectivity_type` : Connectivity type of the NAT Gateway - `public`, `private`
-   `linked_eip_name` : Name of the Elastic IP associated with the NAT Gateway

#### Tags

-   `tag` : Tags used to categorize the resource
