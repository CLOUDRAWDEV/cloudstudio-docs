## Resource Overview

A virtual private gateway is the VPN concentrator on the Amazon side of a Site-to-Site VPN connection. You create a virtual private gateway and attach it to the VPC where you want to create the Site-to-Site VPN connection.

## Resource Setting Values

#### Basic Settings

-   `linked_vpc_name` : Name of the VPC to attach the VPN gateway to
-   `dx_gateway` : Direct Connect Gateway integration settings
-   `dx_gateway.linked_dx_gateway` : Name of the Dx Gateway to connect
-   `dx_gateway.allowed_prefixes` : List of CIDR prefixes to advertise to the on-premises network

#### Tags

-   `tag` : Tags used to categorize the resource
