## Resource Overview

Amazon Virtual Private Cloud (Amazon VPC) enables you to fully control your virtual networking environment, including resource placement, connectivity, and security. Start by setting up a VPC in the AWS Management Console, then add resources such as Amazon Elastic Compute Cloud (EC2) and Amazon Relational Database Service (RDS) instances.  
Finally, define how VPCs communicate with each other across accounts, Availability Zones, or AWS Regions. In the example below, network traffic is shared between two VPCs within each Region.

## Resource Setting Values

#### Basic Settings

-   `cidr_block` : IP address range (CIDR) of the VPC
-   `enabled_dns_support` : Whether to enable DNS resolution - `true`, `false`
-   `enabled_dns_hostnames` : Whether to enable DNS hostnames - `true`, `false`

#### Tags

-   `tag` : Tags used to categorize resources
