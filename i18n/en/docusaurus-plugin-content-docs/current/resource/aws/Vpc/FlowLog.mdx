## Resource Overview

VPC Flow Logs enable you to capture information about the IP traffic going to and from network interfaces in your VPC. Flow log data can be published to Amazon CloudWatch Logs, Amazon S3, or Amazon Kinesis Data Firehose.

## Resource Configuration

#### Basic Settings

-   `linked_log_destination_type` : Destination type for log data (S3, CloudWatch Logs)
-   `linked_log_destination_name` : Destination name for log data
-   `traffic_type` : Traffic type to capture - `ALL`, `ACCEPT`, `REJECT`
-   `included_vpc_name` : Name of the VPC associated with the flow log

#### Tags

-   `tag` : Tags used to categorize the resource
