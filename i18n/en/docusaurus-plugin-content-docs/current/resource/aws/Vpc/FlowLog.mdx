## Resource Overview

VPC Flow Logs enable you to capture information about the IP traffic that is sent to and from network interfaces in your VPC. Flow log data can be published to Amazon CloudWatch Logs, Amazon S3, or Amazon Kinesis Data Firehose. After creating a flow log, you can retrieve and view flow log records in the configured log group, bucket, or delivery stream.

## Resource Setting Values

#### Basic Settings

-   `linked_log_destination_type` : Destination type for storing log data (S3, CloudWatch Logs)
-   `linked_log_destination_name` : Name of the destination where log data is stored
-   `traffic_type` : Type of traffic to capture - `ALL`, `ACCEPT`, `REJECT`
-   `traffic_type` : `ALL`
-   `included_vpc_name` : Name of the VPC to associate with the Flow Log

#### Tags

-   `tag` : Tags used to categorize resources
