## Resource Overview

An AWS service that enables you to configure protection across AWS accounts and resources within your organization.

## Resource Configuration

#### Basic Settings

-   `description` : Firewall description (maximum 256 characters)
-   `included_vpc_name` : Name of the VPC where the firewall is deployed
-   `linked_subnet_names` : List of dedicated public subnets for firewall endpoints
-   `linked_network_firewall_policy_name` : Name of the firewall policy to associate
-   `enabled_delete_protection` : Whether delete protection is enabled - `true`, `false`
-   `enabled_subnet_change_protection` : Whether subnet change protection is enabled - `true`, `false`

#### Encryption Configuration (`encryption_configuration`)

-   `encryption_configuration.enabled_custom_configuration` : Whether to use AWS managed key encryption - `true`, `false`
-   `encryption_configuration.kms_key_name` : Name of the KMS key used for encryption

#### Tags

-   `tag` : Tags used to categorize the resource
