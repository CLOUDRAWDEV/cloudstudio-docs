## Resource Overview

An AWS service that enables you to configure protection across AWS accounts and resources within an organization.

## Associated Resources

### Parent Resource

-   [**Vpc**](https://docs.cstudio.app/docs/resource/aws/Vpc/)

### Connected Resources

-   [**Network Firewall Policy**](https://docs.cstudio.app/docs/resource/aws/Vpc/NetworkFirewallPolicy)
-   [**Subnet**](https://docs.cstudio.app/docs/resource/aws/Vpc/Subnet)

## Resource Setting Values

#### Basic Settings

-   `description` : Description of the firewall (maximum 256 characters)
-   `included_vpc_name` : Name of the VPC where the firewall is located (read-only)
-   `linked_subnet_names` : List of public subnets dedicated to firewall endpoints
-   `linked_network_firewall_policy_name` : Name of the firewall policy to associate (read-only)
-   `enabled_delete_protection` : Whether to enable firewall deletion protection - `true`, `false`
-   `enabled_subnet_change_protection` : Whether to enable subnet association change protection - `true`, `false`

#### Encryption Settings (`encryption_configuration`)

-   `encryption_configuration.enabled_custom_configuration` : Whether to enable encryption using an AWS-managed key - `true`, `false`
-   `encryption_configuration.kms_key_name` : Name of the KMS Key to use for encryption

-   `tag` : Tags used to categorize resources
