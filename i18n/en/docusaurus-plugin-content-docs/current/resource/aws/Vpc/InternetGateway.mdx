## Resource Overview

An Internet Gateway is a horizontally scaled, redundant, and highly available VPC component that enables communication between a VPC and the internet. It supports both IPv4 and IPv6 traffic and does not impose availability risks or bandwidth constraints on network traffic.  
When a resource has a public IPv4 or IPv6 address, an Internet Gateway allows resources in a public subnet (for example, EC2 instances) to connect to the internet. Similarly, resources on the internet can initiate connections to resources in a subnet using public IPv4 or IPv6 addresses. For example, you can connect to an EC2 instance in AWS from your local computer using an Internet Gateway.  
An Internet Gateway provides a target in VPC route tables for internet-routable traffic. For IPv4 communication, the Internet Gateway also performs Network Address Translation (NAT). For IPv6 communication, NAT is not required because IPv6 addresses are public.
