## Resource Overview

A resource that determines whether to accept a shared transit gateway attachment from another AWS account.

## Associated Resources

### Parent Resources

-   [**Region**](https://docs.cstudio.app/en/docs/resource/aws/Base/Region)

### Connected Resources

-   [**TransitGatewayAttachment**](https://docs.cstudio.app/en/docs/resource/aws/Vpc/TransitGatewayAttachment)

---

## Resource Configuration

#### Basic Settings

-   `is_manual` : Whether to manually enter the transit gateway attachment ID - `true`, `false`
-   `transit_gateway_attachment_id` : ID of the transit gateway attachment to accept
-   `linked_transit_gateway_attachment_name` : Name of the transit gateway attachment to accept

#### Tags

-   `tag` : Tags used to categorize the resource
