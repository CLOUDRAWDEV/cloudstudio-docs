## Resource Overview

A resource that determines whether to accept a Transit Gateway attachment shared from another AWS account.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Connected Resources

-   [**Transit Gateway Attachment**](https://docs.cstudio.app/docs/resource/aws/Vpc/TransitGatewayAttachment)

## Resource Setting Values

#### Basic Settings

-   `is_manual` : Whether to manually enter the Transit Gateway Attachment ID - `true`, `false`
-   `transit_gateway_attachment_id` : Transit Gateway Attachment ID to accept
-   `linked_transit_gateway_attachment_name` : Name of the Transit Gateway Attachment to accept

#### Tags

-   `tag` : Tags used to categorize resources
