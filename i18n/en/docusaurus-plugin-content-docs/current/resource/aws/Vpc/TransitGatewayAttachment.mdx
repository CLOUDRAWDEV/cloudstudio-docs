## Resource Overview

A service used to connect a VPC with a Transit Gateway.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/en/docs/resource/aws/Base/Region)

### Connected Resources

-   [**Vpc**](https://docs.cstudio.app/en/docs/resource/aws/Vpc/)
-   [**TransitGateway**](https://docs.cstudio.app/en/docs/resource/aws/Vpc/TransitGateway)
-   [**TransitGateway Attachment Accepter**](https://docs.cstudio.app/en/docs/resource/aws/Vpc/TransitGatewayAttachmentAccepter)

## Resource Setting Values

#### Basic Settings

-   `linked_transit_gateway_name` : Name of the Transit Gateway to connect to the VPC
-   `is_manual` : Whether to manually enter the VPC ID to connect - `true`, `false`
-   `linked_vpc_name` : Name of the VPC to attach to the Transit Gateway
-   `subnet_names` : List of Subnet names to associate with the Transit Gateway

#### Manual Attachment Settings (`manual`)

-   `vpc_id` : VPC ID to attach to the Transit Gateway
-   `subnet_ids` : List of Subnet IDs within the VPC specified by `vpc_id`

#### Tags

-   `tag` : Tags used to categorize resources
