## Resource Overview

A service used to connect a VPC to an on-premises network through a Transit Gateway.

## Resource Configuration

#### Basic Settings

-   `linked_transit_gateway_name` : Name of the transit gateway to connect to the VPC
-   `is_manual` : Whether to manually enter the VPC ID to connect - `true`, `false`
-   `linked_vpc_name` : Name of the VPC to connect to the transit gateway
-   `subnet_names` : List of subnet names to attach to the transit gateway

#### Manual Attachment Settings (`manual`)

-   `vpc_id` : VPC ID to attach to the transit gateway
-   `subnet_ids` : List of subnet IDs within the VPC specified by `vpc_id`

#### Tags

-   `tag` : Tags used to categorize the resource
