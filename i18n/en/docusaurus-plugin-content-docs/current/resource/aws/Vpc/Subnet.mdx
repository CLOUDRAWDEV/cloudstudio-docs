## Resource Overview

A subnet is a range of IP addresses within a VPC. AWS resources such as EC2 instances can be launched within a specific subnet.

## Resource Setting Values

#### Basic Settings

-   `included_vpc_name` : Name of the VPC where the subnet is deployed
-   `cidr_block` : IP address range (CIDR) of the subnet
-   `availability_zone` : Availability Zone where the subnet is deployed
-   `pip_enable` : Whether to enable automatic public IP assignment - `true`, `false`

#### Tags

-   `tag` : Tags used to categorize the resource
