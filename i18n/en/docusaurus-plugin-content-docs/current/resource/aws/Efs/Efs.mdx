## Resource Overview

You can create a file system, mount the file system to EC2 instances, read data from EC2 instances, write data to the file system, or share files.

## Associated Resources

## Resource Setting Values

#### Basic Settings

-   `creation_token` : A unique name used as a reference when creating an Elastic File System to ensure file system creation
-   `availability_zone_name` : AWS Availability Zone where the file system will be created
-   `enable_encrypted` : Whether to enable file system encryption - `true`, `false`
-   `throughput_mode` : Throughput mode of the file system - `provisioned`, `elastic`, `bursting`
-   `provisioned_throughput_in_mibps` : Throughput to provision for the file system (MiB/s) - `1` ~ `3414`
-   `performance_mode` : Performance mode of the file system - `generalPurpose`, `maxIO`

#### Lifecycle Policy (`lifecycle_policy`)

-   `lifecycle_policy.transition_to_ia` : Time before transitioning files to the IA storage class - `1Day`, `7Days`, `14Days`, `30Days`, `60Days`, `90Days`, `None`
-   `lifecycle_policy.transition_to_primary_storage_class` : Policy for transitioning files back to the primary storage class - `None`, `firstAccess`

#### Mount Targets (`mount_target_subnets`)

-   `mount_target_subnets` : List of subnets to add mount targets to

#### File System Policy

-   `file_system_policy` : JSON-formatted file system policy for the EFS file system

#### Backup and Replication Settings

-   `enable_backup_policy` : Whether to enable the backup policy - `true`, `false`
-   `enable_replica` : Whether to create a replica - `true`, `false`

#### Replication Configuration (`replication_configuration`)

-   `replication_configuration.replication_region` : AWS region where the replica will be created
-   `replication_configuration.replication_region_availability_zone_name` : Availability Zone where the replica will be created
-   `replication_configuration.kms_key_name` : Name of the KMS Key to use when creating the replica

#### Access Point (`access_point`)

-   `access_point.root_directory_path` : File system path exposed as the root directory to NFS clients
-   `access_point.posix_user_uid` : POSIX user ID applied when using the access point - `0` ~ `4294967295`
-   `access_point.posix_user_gid` : POSIX group ID applied when using the access point - `0` ~ `4294967295`
-   `access_point.posix_user_secondary_gids` : List of secondary POSIX group IDs
-   `access_point.root_owner_uid` : POSIX user ID applied to the root directory - `0` ~ `4294967295`
-   `access_point.root_owner_gid` : POSIX group ID applied to the root directory - `0` ~ `4294967295`
-   `access_point.root_permissions` : POSIX permissions (octal) applied to the root directory
