## Resource Overview

AWS Direct Connect enables you to connect your on-premises network to an AWS Direct Connect location using standard Ethernet fiber-optic cables. One end of the cable is connected to your router and the other end to an AWS Direct Connect router. Through this connection, you can create virtual interfaces that bypass internet service providers on public AWS network paths to access services such as Amazon S3 or Amazon VPC. AWS Direct Connect locations provide access to AWS services in the connected region, public regions through a single connection, AWS GovCloud (US) public access, and all other AWS public region services.

## Resource Setting Values

#### Basic Settings

-   `bandwidth` : Bandwidth of the Direct Connection - `1Gbps`, `2Gbps`, `5Gbps`, `10Gbps`, `100Gbps`
-   `location` : AWS Direct Connect location where the connection is established
-   `service_provider` : Service provider that offers the connection at the location
