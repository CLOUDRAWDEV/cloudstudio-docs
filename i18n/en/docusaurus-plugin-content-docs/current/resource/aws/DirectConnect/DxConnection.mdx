## Resource Overview

AWS Direct Connect allows you to connect your on-premises network to an AWS Direct Connect location using a standard Ethernet fiber-optic cable. One end of the cable is connected to your router and the other end is connected to an AWS Direct Connect router. This connection enables you to create virtual interfaces and route traffic to AWS services such as Amazon S3 or Amazon VPC while bypassing the public internet. AWS Direct Connect locations provide access to public AWS services in the connected region, allow access to all other public AWS regions, and also provide access to AWS GovCloud (US) public services.

## Resource Setting Values

#### Basic Settings

-   `bandwidth` : Bandwidth of the Direct Connection - `1Gbps`, `2Gbps`, `5Gbps`, `10Gbps`, `100Gbps`
-   `location` : AWS Direct Connect location where the connection is established
-   `service_provider` : Service provider that offers the connection at the location

#### Tags

-   `tag` : Tags used to categorize the resource
