## Resource Overview

An endpoint service for inbound and outbound DNS queries between Amazon VPC and on-premises networks.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/en/docs/resource/aws/Base/Region)

### Connected Resources

-   [**Vpc**](https://docs.cstudio.app/en/docs/resource/aws/Vpc/)
-   [**SecurityGroup**](https://docs.cstudio.app/en/docs/resource/aws/Vpc/SecurityGroup)
-   [**ResolverRule**](https://docs.cstudio.app/en/docs/resource/aws/Route53/ResolverRule)

## Resource Setting Values

#### Basic Settings

-   `direction` : DNS query direction - `INBOUND`, `OUTBOUND`
-   `linked_vpc_name` : Name of the VPC connected to the endpoint
-   `linked_security_group_names` : List of security group names applied to the endpoint
-   `ip_address.subnet_name` : Subnet name to use
-   `ip_address.ip` : Available IP address within the subnet

#### Tags

-   `tag` : Tags used to categorize the resource
