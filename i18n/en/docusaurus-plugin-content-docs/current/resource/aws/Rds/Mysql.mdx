## Resource Overview

Building RDS with MySQL on AWS makes database operation and management easy. RDS is highly scalable, allowing you to improve performance by changing instance types as needed. It also provides automatic backup and restore capabilities for database instances to prevent data loss. In addition, AWS security features help ensure data safety.

## Resource Setting Values

#### Basic Settings

-   `database_name` : Initial database name - `1` ~ `64` alphanumeric characters
-   `engine_version` : MySQL engine version to use in RDS
-   `instance_class` : RDS DB instance type
-   `storage_type` : Storage type of the RDS instance
-   `allocated_storage` : RDS storage capacity (GB) - `20` ~ `65536`
-   `max_allocated_storage` : Maximum limit for storage auto scaling
-   `iops` : Number of I/O operations per second supported by the DB instance - `1000` ~ `40000`
-   `multi_az_enabled` : Whether to enable Multi-AZ deployment - `true`, `false`
-   `username` : RDS administrator username
-   `password` : RDS administrator password
-   `publicly_accessible` : Whether to allow public access - `true`, `false`

#### Network Settings

-   `included_subnet_names` : List of Subnet names included in the RDS Subnet Group
-   `subnet_group_name` : Subnet Group name to use for RDS
-   `linked_security_group_names` : List of security groups to apply

#### Monitoring Settings (`monitoring`)

-   `monitoring.performance_insights_enabled` : Whether to enable Performance Insights - `true`, `false`
-   `monitoring.kms_key_name` : KMS Key name to use for Performance Insights

#### Encryption Settings (`encryption`)

-   `encryption.storage_encrypted` : Whether to encrypt DB instance storage - `true`, `false`
-   `encryption.kms_key_name` : KMS Key name to use for encryption

#### Backup Settings (`backup`)

-   `backup.backup_retention_period` : Backup retention period (days) - `1` ~ `35`
-   `backup.final_snapshot_enabled` : Whether to create a final snapshot before DB deletion - `true`, `false`
-   `backup.final_snapshot_name` : Final snapshot name

#### Tags

-   `tag` : Tags used to categorize resources
