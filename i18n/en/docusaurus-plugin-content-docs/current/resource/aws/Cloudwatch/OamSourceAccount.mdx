## Resource Overview

AWS CloudWatch OAM Source Accounts configure source accounts that are shared with a central monitoring account.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/en/docs/resource/aws/Base/Region)

### Connected Resources

-   [**OamMonitoringAccount**](https://docs.cstudio.app/en/docs/resource/aws/CloudWatch/OamMonitoringAccount)

## Resource Setting Values

#### Basic Settings

-   `is_manual` : Whether to manually enter the OAM Source Account ARN to connect - `true`, `false`
-   `linked_oam_monitoring_account_name` : Name of the OAM Monitoring Account to connect
-   `oam_monitoring_account_arn` : ARN of the monitoring account that shares data
-   `resource_types` : Types of data to share with the monitoring account - `AWS::Logs::LogGroup`, `AWS::CloudWatch::Metric`, `AWS::XRay::Trace`, `AWS::ApplicationInsights::Application`
-   `label_template` : Label used to help identify the source account - `$AccountName`, `$AccountEmail`, `$AccountEmailNoDomain`

#### Tags

-   `tag` : Tags used to categorize resources
