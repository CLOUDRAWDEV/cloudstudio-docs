## Resource Overview

AWS CloudWatch OAM Monitoring Accounts is a service that monitors applications across multiple accounts by configuring a central monitoring account.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Connected Resources

-   [**OamSourceAccount**](https://docs.cstudio.app/docs/resource/aws/CloudWatch/OamSourceAccount)

---

## Resource Setting Values

#### Basic Settings

-   `oam_source_accounts` : List of source accounts that share data with the monitoring account (account ID, organization path, or organization ID)
-   `resource_types` : Types of data to share from source accounts - `AWS::Logs::LogGroup`, `AWS::CloudWatch::Metric`, `AWS::XRay::Trace`, `AWS::ApplicationInsights::Application`

#### Tag Settings

-   `tag` : List of tags used to categorize resources
