## Resource Overview

AWS ElasticSearch is a distributed search and analytics engine designed to enable fast search and data analysis. ElasticSearch is built on top of the Apache Lucene search engine and provides a fast and scalable open-source solution. It is used for various purposes such as data collection, log analysis, and monitoring. ElasticSearch can run within an Amazon VPC and integrates with AWS services such as Lambda and Kinesis. It provides AWS security and access control features and integrates with Amazon CloudWatch for monitoring and logging capabilities.

## Resource Setting Values

#### Basic Settings

-   elasticsearch_version : Elasticsearch Domain version
-   availability_zone_count : Number of Availability Zones - 2, 3
-   tls_security_policy : TLS security policy applied to HTTPS endpoint
-   engine : Elasticsearch engine configuration

#### Data Node (data_node)

-   data_node.instance_type : Data node instance type
-   data_node.instance_count : Number of data nodes
-   data_node.ebs_enabled : Whether to attach EBS to data nodes - true, false
-   data_node.ebs_volume_type : EBS volume type - gp2, gp3, io1, standard
-   data_node.ebs_volume_size : EBS volume size (GiB)
-   data_node.ebs_volume_iops : EBS IOPS
-   data_node.ebs_volume_throughput : EBS throughput (MiB/s)

#### Master Node (master_node)

-   master_node.master_node_enabled : Whether to enable dedicated master nodes - true, false
-   master_node.master_instance_type : Master node instance type
-   master_node.master_node_count : Number of master nodes

#### Custom Endpoint (custom_endpoint)

-   custom_endpoint.custom_endpoint_enabled : Whether to enable a custom endpoint - true, false
-   custom_endpoint.custom_host_name : Custom host name
-   custom_endpoint.acm_certificate_name : ACM certificate name

#### Network Settings (network)

-   network.network_type : Network access method - vpc_access, public_access
-   network.included_subnet_names : List of Subnet names where the Elasticsearch domain will be created
-   network.linked_security_group_names : List of Security Group names to link

#### Fine-Grained Access Control (fine_grained_access)

-   fine_grained_access.fine_grained_access_enabled : Whether to enable fine-grained access control - true, false
-   fine_grained_access.master_user_type : Master user type - iam_arn, master_user
-   fine_grained_access.iam_arn : Master user IAM ARN
-   fine_grained_access.master_user_name : Master user name
-   fine_grained_access.master_user_password : Master user password

#### Encryption Settings (encryption)

-   encryption.enforce_https : Whether to enforce HTTPS - true, false
-   encryption.node_to_node_encryption_enabled : Whether to enable node-to-node encryption - true, false
-   encryption.data_at_rest_encryption_enabled : Whether to enable encryption at rest - true, false
-   encryption.kms_key_name : KMS key name used for encryption
