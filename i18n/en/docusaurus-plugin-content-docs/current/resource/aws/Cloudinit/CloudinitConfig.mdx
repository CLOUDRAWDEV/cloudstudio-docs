## Resource Overview

Cloud-init is a tool used to initialize and configure virtual machine instances.

## Resource Configuration

#### Basic Settings

-   `gzip` : Whether to use data compression - `true`, `false`

#### Part Settings (`part`)

-   `part.content_type` : Type of data to insert - `text/cloud-config`, `text/x-shellscript`, `text/cloud-boothook`, `multipart/mixed`, `text/cloud-config-archive`, `text/jinja`, `text/x-include-url`, `text/part-handler`
-   `part.content` : Actual data content to insert

#### Tags

-   `tag` : Tags used to categorize the resource
