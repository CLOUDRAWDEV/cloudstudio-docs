## Resource Overview

Cloud-init is a tool that initializes and configures virtual machine instances.

## Resource Setting Values

#### Basic Settings

-   `gzip` : Whether to use a data compression algorithm - `true`, `false`

#### Part Settings (`part`)

-   `part.content_type` : Format of the data to insert - `text/cloud-config`, `text/x-shellscript`, `text/cloud-boothook`, `multipart/mixed`, `text/cloud-config-archive`, `text/jinja`, `text/x-include-url`, `text/part-handler`
-   `part.content` : Actual data content to insert

#### Tags

-   `tag` : Tags used to categorize resources
