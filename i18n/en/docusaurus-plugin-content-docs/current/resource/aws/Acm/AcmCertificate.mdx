## Resource Overview

Using the ACM Certificate resource, you can request and manage certificates in Amazon Certificate Manager.

### Parent Resource

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

## Associated Resources

#### Basic Settings

-   `enabled_import` : Whether to import a certificate - `true`, `false`
-   `domain_name` : Fully qualified domain name for the certificate
-   `validation_method` : Method to validate domain ownership - `DNS`, `EMAIL`
-   `key_algorithm` : Encryption algorithm - `RSA_2048`, `ECDSA_P256`, `ECDSA_P384`
-   `certificate_body` : PEM-encoded certificate body to import - up to `5000` characters
-   `certificate_private_key` : PEM-encoded private key of the certificate to import - up to `5000` characters
-   `certificate_chain` : PEM-encoded certificate chain to import - up to `5000` characters

#### Tags

-   `tag` : Tags used to categorize resources - up to 512 characters, `key`:`value`
