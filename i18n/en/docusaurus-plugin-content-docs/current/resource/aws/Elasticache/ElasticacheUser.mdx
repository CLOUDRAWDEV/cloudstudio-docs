## Resource Overview

AWS ElastiCache User is an IAM user required to use ElastiCache clusters. An ElastiCache User has permissions to create, modify, and delete ElastiCache clusters. ElastiCache Users are created in AWS IAM and are typically assigned to applications or developers that use ElastiCache. ElastiCache Users are responsible for security and access control for ElastiCache clusters, helping protect applications and data. ElastiCache Users can be used alongside other resources within an AWS account.

## Resource Setting Values

#### Basic Settings

-   `user_id` : Unique identifier for each user
-   `access_string` : String that defines the permissions applied to the user
-   `authentication_type` : Authentication method for user access to the cluster - `iam`, `password`, `no-password-required`
-   `passwords` : User passwords (up to 2 can be configured)
