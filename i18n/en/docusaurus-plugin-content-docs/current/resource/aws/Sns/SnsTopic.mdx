A logical access point that serves as a communication channel in AWS SNS.

## Resource Configuration

#### Basic Settings

-   `display_name` : Display name of the SNS topic
-   `type` : SNS topic type (`FIFO`, `Standard`)
-   `kms_key_name` : KMS key name used for the SNS topic

#### Tags

-   `tag` : Tags used to categorize the resource
