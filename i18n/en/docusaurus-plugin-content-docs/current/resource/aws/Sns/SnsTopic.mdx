## Resource Overview

A logical access point that acts as a communication channel in AWS SNS.

## Resource Setting Values

#### Basic Settings

-   `display_name` : Display name of the SNS Topic
-   `type` : Type of the SNS Topic (`FIFO`, `Standard`)
-   `kms_key_name` : KMS Key name to use for the SNS Topic

#### Tags

-   `tag` : Tags used to categorize resources
