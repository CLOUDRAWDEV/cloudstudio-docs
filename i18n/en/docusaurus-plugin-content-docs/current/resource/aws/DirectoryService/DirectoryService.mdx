## Resource Overview

AWS Directory Service provides several ways to use Microsoft Active Directory (AD) with other AWS services. A directory stores information about users, groups, and devices, and administrators use it to manage access to information and resources. AWS Directory Service offers multiple directory options for customers who want to use existing Microsoft AD or LDAP (Lightweight Directory Access Protocol)–aware applications in the cloud. It also provides the same options for developers who require directories to manage users, groups, devices, and access permissions.

## Resource Setting Values

#### Basic Settings

-   `password` : Password for the directory administrator or connector user
-   `type` : Type of the directory - `SimpleAD`, `MicrosoftAD`
-   `size` : Size of the directory - `Small`, `Large`
-   `edition` : MicrosoftAD edition - `Standard`, `Enterprise`
-   `included_vpc_name` : Name of the VPC where the directory resides
-   `included_subnet_names` : Names of the subnets for the directory servers

#### Tags

-   `tag` : Tags used to categorize resources
