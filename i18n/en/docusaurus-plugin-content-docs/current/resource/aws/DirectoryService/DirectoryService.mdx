## Resource Overview

AWS Directory Service provides multiple ways to use Microsoft Active Directory (AD) with other AWS services. Directories store information about users, groups, and devices, and administrators use them to manage access to information and resources. AWS Directory Service offers various directory options for customers who want to use existing Microsoft AD or LDAP (Lightweight Directory Access Protocol)-aware applications in the cloud. It also provides the same options for developers who require directories to manage users, groups, devices, and access permissions.

## Resource Configuration

#### Basic Settings

-   `password` : Password for the directory administrator or connector user
-   `type` : Directory type - `SimpleAD`, `MicrosoftAD`
-   `size` : Directory size - `Small`, `Large`
-   `edition` : MicrosoftAD edition - `Standard`, `Enterprise`
-   `included_vpc_name` : Name of the VPC where the directory is located
-   `included_subnet_names` : Subnet names for the directory servers

#### Tags

-   `tag` : Tags used to categorize the resource
