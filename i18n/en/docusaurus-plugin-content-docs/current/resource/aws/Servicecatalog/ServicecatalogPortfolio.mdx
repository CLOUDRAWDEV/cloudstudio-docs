## Resource Overview

AWS Service Catalog allows IT administrators to create and manage portfolios of approved products and distribute them to end users, who can access the products they need through a personalized portal. Typical products include servers, databases, websites, or applications deployed using AWS resources (for example, Amazon EC2 instances or Amazon RDS databases). Administrators can control which users can access specific products to enforce business standards compliance, manage product lifecycles, and enable users to confidently discover and launch products.
