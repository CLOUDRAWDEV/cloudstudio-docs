## Resource Setting Values

#### Basic Settings

-   `set_container_insights` : Whether to enable Container Insights for the cluster - `enabled`, `disabled`
-   `kms_key_name` : Name of the AWS Key Management Service key used to encrypt data between the local client and containers
-   `logging` : Log configuration used for redirecting execution command results - `OVERRIDE`, `NONE`, `DEFAULT`
-   `cloud_watch_encryption_enabled` : Whether to enable encryption for CloudWatch logs - `true`, `false`
-   `cloud_watch_log_group_name` : Name of the CloudWatch log group to send logs to
-   `capacity_providers` : Set of capacity providers to associate with the cluster

#### Service (`service`)

-   `service.computing_option` : Task distribution method for the Service - `capacity_provider_strategy`, `launch_type`
-   `service.capacity_provider_strategy.capacity_provider` : Capacity provider applied to the Service - `FARGATE`, `FARGATE_SPOT`
-   `service.capacity_provider_strategy.base` : Minimum number of tasks to run
-   `service.capacity_provider_strategy.weight` : Relative percentage of the total number of running tasks
-   `service.launch_type` : Launch type of the Service - `EC2`, `FARGATE`, `EXTERNAL`
-   `service.task_definition_name` : Name of the ECS Task Definition used by the Service
-   `service.desired_count` : Number of task definition instances to run for the Service
-   `service.linked_security_group_names` : List of Security Group names to use
-   `service.subnet_names` : List of Subnet names where the Service will run
-   `service.enabled_public_ip` : Whether to enable a public IP - `true`, `false`
