## Resource Overview

AWS CloudTrail enables you to monitor the status of AWS deployments in the cloud by recording AWS API calls for your account, including API calls made through the AWS Management Console, AWS SDKs, command line tools, and higher-level AWS services. You can also identify which users and accounts called AWS APIs for services supported by CloudTrail, which source IP addresses the calls were made from, and the time when the calls occurred. Using APIs, you can integrate CloudTrail into applications, automate trail creation for organizations, check trail status, and control how administrators enable and disable CloudTrail logging.

## Resource Setting Values

#### Basic Settings

-   `linked_s3_bucket_name` : Name of the S3 bucket to store CloudTrail log files
-   `s3_key_prefix` : S3 object key prefix to use when storing log files
-   `multi_region_enabled` : Whether to enable multi-region trails - `true`, `false`
-   `global_service_events` : Whether to include global service events such as IAM in logs - `true`, `false`

-   `tag` : Tags used to categorize resources
