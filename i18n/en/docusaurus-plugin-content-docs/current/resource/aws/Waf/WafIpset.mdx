## Resource Overview

AWS WAF IPSet is a list of IP addresses used by the Web Application Firewall in Amazon Web Services. It allows users to create and manage access rules for specified IP addresses. By using an IPSet, web application security can be enhanced by allowing or blocking requests from specific IP addresses.

## Resource Overview

AWS WAF IP Set is a resource that groups one or more IP addresses or CIDR blocks so they can be referenced in Web ACL rules. It is used to configure allow or block policies for specific IP ranges.

## Resource Setting Values

#### Basic Settings

-   `scope` : Scope in which the IP Set is applied - `REGIONAL`, `CLOUDFRONT`
-   `ip_address_version` : IP address version - `IPV4`, `IPV6`
-   `addresses` : List of IP addresses or IP address blocks specified in CIDR notation

-   `tag` : Tags used to categorize resources
