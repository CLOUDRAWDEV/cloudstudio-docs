## Resource Overview

AWS WAF IPSet is a list of IP addresses used by the Amazon Web Services Web Application Firewall. It allows users to create and manage access rules for defined IP addresses. By using IP sets, web application security can be enhanced by allowing or blocking requests from specific IP addresses.

## Resource Overview

AWS WAF IP Set is a resource that groups one or more IP addresses or CIDR blocks for reference in web ACL rules, and is used to configure allow or block policies for specific IP ranges.

## Resource Configuration

#### Basic Settings

-   `scope` : Scope to apply the IP set - `REGIONAL`, `CLOUDFRONT`
-   `ip_address_version` : IP address version - `IPV4`, `IPV6`
-   `addresses` : List of IP addresses or IP address blocks specified in CIDR notation

#### Tags

-   `tag` : Tags used to categorize the resource
