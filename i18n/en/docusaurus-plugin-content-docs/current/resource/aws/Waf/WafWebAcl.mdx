## Resource Overview

An AWS WAF Web ACL is the top-level container for a set of rules applied to a web application. Web ACLs combine multiple rule groups and rules and define the order in which web requests are evaluated. This enables enhanced web application security by allowing, blocking, or counting requests.

## Resource Setting Values

#### Basic Settings

-   `scope` : Scope where the Web ACL is applied - `REGIONAL`, `CLOUDFRONT`
-   `cloudwatch_metrics_enabled` : Whether to enable CloudWatch metrics - `true`, `false`
-   `metric_name` : CloudWatch metric name; only letters, numbers, hyphens, and underscores allowed, `1` ~ `128` characters
-   `sampled_requests_enabled` : Whether to store sampled web requests that match rules - `true`, `false`

#### Tags

-   `tag` : Tags used to categorize the resource
