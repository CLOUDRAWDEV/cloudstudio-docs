## Resource Overview

An AWS WAF Rule Group is a collection of rules used by the Web Application Firewall. By using a Rule Group, multiple rules can be grouped and applied to web applications, improving reusability and management efficiency. Rule groups control important aspects of web application security and can allow, block, or count requests.

## Resource Setting Values

#### Basic Settings

-   `scope` : Scope where the Rule Group is applied - `REGIONAL`, `CLOUDFRONT`
-   `capacity` : Web ACL capacity units (WCU) required for the rule group
-   `cloudwatch_metrics_enabled` : Whether to enable CloudWatch metrics - `true`, `false`
-   `metric_name` : CloudWatch metric name; only uppercase/lowercase letters, hyphens, and underscores are allowed, `1` ~ `128` characters
-   `sampled_requests_enabled` : Whether to store sampled web requests that match rules - `true`, `false`

-   `tag` : Tags used to categorize resources
