## Resource Overview

A serverless OpenSearch index group that allows data to be stored and searched in an automatically scaling OpenSearch cluster environment without infrastructure management.

## Resource Setting Values

#### Basic Settings

-   `shared_resource_types` : List of resource types to share
-   `transit_gateway_names` : List of Transit Gateway names to share
-   `resource_arns` : List of resource ARNs to share
-   `enabled_allow_external_principals` : Whether to allow sharing with external AWS accounts - `true`, `false`
-   `principal_arns` : List of principal ARNs or AWS account IDs allowed to share

#### Tags

-   `tag` : Tags used to categorize resources - up to 512 characters, `key`:`value`
