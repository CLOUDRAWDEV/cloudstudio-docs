## Resource Overview

A template that defines the specifications of virtual servers automatically created when server scaling is required during Auto Scaling operations.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### Connected Resources

-   [**SecurityGroup**](https://docs.cstudio.app/docs/resource/aws/Vpc/SecurityGroup)

## Resource Setting Values

#### Basic Settings

-   `image_name` : Operating system image code to use (CNTOS: CentOS, UBNTU: Ubuntu, WND: Windows / MYSQL, MARIA: Database / SVR: Server, EN: English Edition)
-   `instance_type` : Type of the EC2 instance
-   `key_name` : Name of the public login key used for encryption
-   `linked_security_group_name` : Name of the Security Group to which the instance belongs
-   `user_data` : Script or commands that run automatically when the EC2 instance starts

#### Block Device Mapping (`block_device_mapping`)

-   `block_device_mapping.volume_type` : Type of the EBS volume - `standard`, `gp2`, `gp3`, `io1`, `io2`, `sc1`, `st1`
-   `block_device_mapping.volume_size` : Size of the EBS volume (GiB)
-   `block_device_mapping.iops` : Number of input/output operations per second for the EBS volume
-   `block_device_mapping.delete_on_termination` : Whether to automatically delete the EBS volume when the instance terminates - `true`, `false`
-   `block_device_mapping.snapshot_name` : Name to assign when creating a snapshot of the EBS volume
-   `block_device_mapping.encrypted` : Whether to enable encryption for the EBS volume - `true`, `false`
-   `block_device_mapping.kms_key_name` : Name of the KMS key used to encrypt the EBS volume
