## Resource Overview

A logical networking component that represents a virtual network card in a VPC.

## Associated Resources

### Parent Resource

-   [**Subnet**](https://docs.cstudio.app/en/docs/resource/aws/Vpc/Subnet)

### Connected Resources

-   [**Eip**](https://docs.cstudio.app/en/docs/resource/aws/Ec2/Eip)
-   [**Instance**](https://docs.cstudio.app/en/docs/resource/aws/Ec2/Instance)
-   [**SecurityGroup**](https://docs.cstudio.app/en/docs/resource/aws/Vpc/SecurityGroup)

## Resource Setting Values

#### Basic Settings

-   `included_subnet_name` : Name of the subnet where the network interface is located
-   `private_ips` : List of private IP addresses
-   `linked_security_group_names` : Names of the Security Groups to use for the network interface
-   `linked_eip_names` : Names of the Elastic IPs to use

#### Tags

-   `tag` : Tags used to categorize resources
