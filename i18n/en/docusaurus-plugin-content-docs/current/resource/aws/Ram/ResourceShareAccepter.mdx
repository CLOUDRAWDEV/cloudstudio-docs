## Resource Overview

A resource that determines whether to accept a resource share invitation from another AWS account.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/en/docs/resource/aws/Base/Region)

### Connected Resources

-   [**ResourceShare**](https://docs.cstudio.app/en/docs/resource/aws/RAM/ResourceShare)

## Resource Setting Values

#### Basic Settings

-   `is_manual` : Whether to manually enter the Resource Share ARN - `true`, `false`
-   `linked_resource_share_name` : Name of the Resource Share to connect
-   `resource_share_arn` : ARN of the Resource Share to accept

#### Tags

-   `tag` : Tags used to categorize the resource - maximum 512 characters, `key`:`value`
