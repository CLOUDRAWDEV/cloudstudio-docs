## Resource Overview

Amazon Route 53 is a highly available and scalable Domain Name System (DNS) web service.

## Associated Resources

### Parent Resource

-   [**Base**](https://docs.cstudio.app/docs/resource/aws/Base)

### Connected Resources

-   [**Vpc**](https://docs.cstudio.app/docs/resource/aws/Vpc/)

## Resource Setting Values

#### Basic Settings

-   `routing_type` : Route 53 Zone routing type - `PRIVATE`, `PUBLIC`
-   `linked_vpc_names` : List of VPC names to associate with the Route 53 Zone

#### Record (`record`)

-   `record.type` : Record type - `A`, `AAAA`, `CAA`, `CNAME`, `DS`, `MX`, `NAPTR`, `NS`, `PTR`, `SOA`, `SPF`, `SRV`, `TXT`
-   `record.ttl` : Record TTL
-   `record.records` : List of record strings

#### Tags

-   `tag` : Tags used to categorize resources
