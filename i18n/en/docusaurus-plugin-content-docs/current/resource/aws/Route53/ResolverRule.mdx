## Resource Overview

A rule used by Resolver to forward queries for specified domain names to a network.

## Associated Resources

### Parent Resource

-   [**Region**](https://docs.cstudio.app/en/docs/resource/aws/Base/Region)

### Connected Resources

-   [**ResolverEndpoint**](https://docs.cstudio.app/en/docs/resource/aws/Route53/ResolverEndpoint)
-   [**Vpc**](https://docs.cstudio.app/en/docs/resource/aws/Vpc/)

## Resource Setting Values

#### Basic Settings

-   `rule_type` : Rule type - `FORWARD`, `SYSTEM`
-   `domain_name` : Domain name to which DNS queries are forwarded
-   `linked_vpc_names` : List of VPC names using the rule
-   `linked_resolver_endpoint_name` : Name of the outbound endpoint used by Resolver
-   `target_ip.ip` : Target IP address
-   `target_ip.port` : Port of the target IP address

#### Tags

-   `tag` : Tags used to categorize the resource
