## 리소스 개요

AWS Bedrock 모델의 응답을 제어하기 위해 금칙어 차단, 민감정보 보호 등 정책을 설정하는 리소스입니다.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

## 리소스 설정 값

#### 기본 메시지 설정

-   `blocked_input_messaging` : 입력이 차단될 때 사용자에게 표시할 메시지
-   `blocked_outputs_messaging` : 출력이 차단될 때 사용자에게 표시할 메시지
-   `guardrail_description` : Guardrail의 목적 및 설명
-   `kms_key_arn` : Guardrail 데이터를 암호화할 사용자 지정 KMS 키 ARN

#### 콘텐츠 정책 (`content_policy_config`)

-   `content_policy_config.type` : 콘텐츠 정책 유형 - `HATE`, `INSULTS`, `SEXUAL`, `VIOLENCE`, `MISCONDUCT`
-   `content_policy_config.input_strength` : 입력에 대한 정책 강도 - `LOW`, `MEDIUM`, `HIGH`, `NONE`
-   `content_policy_config.output_strength` : 출력에 대한 정책 강도 - `LOW`, `MEDIUM`, `HIGH`, `NONE`

#### 주제 정책 (`topic_policy_config`)

-   `topic_policy_config.definition` : 제한 또는 허용할 주제 정의
-   `topic_policy_config.type` : 정책 유형 - `DENY`, `ALLOW`
-   `topic_policy_config.examples` : 정책이 적용될 주제 예시 목록

#### 문맥 기반 검증 (`contextual_grounding_policy_config`)

-   `contextual_grounding_policy_config.threshold` : 문맥 일치 판단 임계값 (0~1)
-   `contextual_grounding_policy_config.type` : 검증 방식 - `RELEVANCE`, `GROUNDING`

#### 민감 정보 보호 (`sensitive_information_policy_config`)

-   `sensitive_information_policy_config.pii_entities_config.action` : PII 감지 시 기본 조치 - `BLOCK`, `ANONYMIZE`, `NONE`
-   `sensitive_information_policy_config.pii_entities_config.type` : 감지할 PII 유형
-   `sensitive_information_policy_config.regexes_config.action` : 정규식 감지 시 조치 - `BLOCK`, `ANONYMIZE`, `NONE`
-   `sensitive_information_policy_config.regexes_config.description` : 정규식 설명
-   `sensitive_information_policy_config.regexes_config.pattern` : 정규식 패턴

#### 단어 정책 (`word_policy_config`)

-   `word_policy_config.managed_word_lists_config.type` : 관리형 금칙어 목록 유형 - `PROFANITY`
-   `word_policy_config.words_config.text` : 사용자 정의 금칙어 또는 제한 단어

#### 버전 관리 (`versions`)

-   `versions.description` : Guardrail 버전별 변경 사항 또는 설명
