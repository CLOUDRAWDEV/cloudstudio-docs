## 리소스 개요

AWS Bedrock 에이전트가 실행할 수 있는 특정 작업을 정의하고 관리하는 리소스입니다.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

---

## 리소스 설정 값

#### 기본 설정

-   `target_bedrock_agent` : 액션 그룹이 연결될 대상 Bedrock 에이전트
-   `enable_action_group_state` : Action Group 상태 유지 기능 활성화 여부 - `ENABLED`, `DISABLED`
-   `custom_control_method` : 에이전트 동작 제어 방식 - `custom_control`, `lambda_function`
-   `target_lambda_function` : 액션 실행 시 호출할 AWS Lambda 함수

#### 함수 정의 (`functions`)

-   `functions.description` : 함수가 수행하는 작업의 목적 또는 기능 설명 (최대 5000자)

##### 함수 매개변수 (`functions.parameters`)

-   `functions.parameters.type` : 매개변수 데이터 유형 - `string`, `number`, `integer`, `boolean`, `array`
-   `functions.parameters.description` : 매개변수의 의미 또는 용도
-   `functions.parameters.required` : 필수 입력값 여부 - `true`, `false`
