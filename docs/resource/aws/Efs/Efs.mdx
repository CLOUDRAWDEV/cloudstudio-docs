## 리소스 개요

파일 시스템을 생성, EC2 인스턴스에 파일 시스템을 탑재, EC2 인스턴스에서 데이터를 읽고 파일 시스템에 작성하거나 파일을 공유할 수 있습니다.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)
-   [**Vpc**](https://docs.cstudio.app/docs/resource/aws/Network/Vpc)

### 연결 리소스

-   **Subnet** (Mount Target)

## 리소스 설정 값

#### 기본 설정

-   `creation_token` : 파일 시스템 중복 생성을 방지하기 위한 고유 식별자
-   `availability_zone_name` : 파일 시스템을 생성할 가용 영역
-   `enable_encrypted` : 파일 시스템 암호화 여부 - `true`, `false`
-   `throughput_mode` : 파일 시스템 처리량 모드 - `provisioned`, `elastic`, `bursting`
-   `provisioned_throughput_in_mibps` : 프로비저닝 처리량(MiB/s)
-   `performance_mode` : 파일 시스템 성능 모드 - `generalPurpose`, `maxIO`
-   `enable_backup_policy` : 백업 정책 사용 여부 - `true`, `false`

#### 수명 주기 정책 (`lifecycle_policy`)

-   `transition_to_ia` : IA 스토리지 클래스로 전환되는 시점 - `1Day`, `7Days`, `14Days`, `30Days`, `60Days`, `90Days`, `None`
-   `transition_to_primary_storage_class` : IA → 기본 스토리지 전환 정책 - `firstAccess`, `None`

#### 마운트 타겟

-   `mount_target_subnets` : 마운트 타겟을 생성할 서브넷 목록

#### 파일 시스템 정책

-   `file_system_policy` : EFS 파일 시스템에 적용할 JSON 형식 정책

#### 복제 설정

-   `enable_replica` : 파일 시스템 복제 생성 여부 - `true`, `false`
-   `replication_region` : 복제 대상 리전
-   `replication_region_availability_zone_name` : 복제 대상 가용 영역
-   `kms_key_name` : 복제 시 사용할 KMS Key 이름

#### 액세스 포인트

-   `root_directory_path` : 액세스 포인트 루트 디렉터리 경로
-   `posix_user_uid` : POSIX 사용자 ID
-   `posix_user_gid` : POSIX 그룹 ID
-   `posix_user_secondary_gids` : 보조 POSIX 그룹 ID 목록
-   `root_owner_uid` : 루트 디렉터리 소유자 UID
-   `root_owner_gid` : 루트 디렉터리 소유자 GID
-   `root_permissions` : 루트 디렉터리 권한(8진수)

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그
