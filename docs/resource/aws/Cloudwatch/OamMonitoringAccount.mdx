## 리소스 개요

AWS CloudWatch Oam Monitoring Accounts는 중앙 모니터링 계정을 설정하여 여러 계정의 애플리케이션을 모니터링하는 서비스입니다.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### 연결 리소스

-   [**OamSourceAccount**](https://docs.cstudio.app/docs/resource/aws/CloudWatch/OamSourceAccount)

---

## 리소스 설정 값

#### 기본 설정

-   `oam_source_accounts` : 모니터링 계정과 데이터를 공유할 소스 계정 목록(계정 ID, 조직 경로 또는 조직 ID)
-   `resource_types` : 소스 계정으로부터 공유받을 데이터 유형 - `AWS::Logs::LogGroup`, `AWS::CloudWatch::Metric`, `AWS::XRay::Trace`, `AWS::ApplicationInsights::Application`

#### 태그 설정

-   `tag` : 리소스를 분류하기 위한 태그 목록
