## 리소스 개요

AWS CloudWatch Oam Source Accounts는 중앙 모니터링 계정과 공유될 소스 계정을 구성합니다.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### 연결 리소스

-   [**OamMonitoringAccount**](https://docs.cstudio.app/docs/resource/aws/CloudWatch/OamMonitoringAccount)

## 리소스 설정 값

#### 기본 설정

-   `is_manual` : 연결할 Oam Source Account Arn를 직접 입력할지 여부 - `true`, `false`
-   `linked_oam_monitoring_account_name` : 연결할 Oam Monitoring Account 이름
-   `oam_monitoring_account_arn` : 데이터를 공유할 모니터링 계정의 Arn
-   `resource_types` : 모니터링 계정과 공유하려는 데이터 유형 - `AWS::Logs::LogGroup`, `AWS::CloudWatch::Metric`, `AWS::XRay::Trace`, `AWS::ApplicationInsights::Application`
-   `label_template` : 소스 계정을 식별하는 데 도움이 되는 레이블 - `$AccountName`, `$AccountEmail`, `$AccountEmailNoDomain`

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그
