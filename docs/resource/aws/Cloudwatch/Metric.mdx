## 리소스 개요

AWS CloudWatch Metric은 모니터링 대상 리소스에서 수집된 측정값을 나타내는 이름-값 쌍입니다. 예를 들어, EC2 인스턴스에서 CPU 사용률, 네트워크 입력 및 출력 등의 측정값을 수집할 수 있습니다. 이러한 측정값은 CloudWatch Metric으로 저장되며, 대시보드, 알림 및 분석에 사용됩니다. 또한, 사용자 정의 Metric을 생성하여 애플리케이션 및 서비스에서 수집된 데이터를 모니터링할 수도 있습니다. CloudWatch Metric은 AWS에서 제공하는 다양한 서비스와 통합되어 사용됩니다.

## 리소스 설정 값

#### 기본 설정

-   `comparison_operator` : 지표 값과 임계값을 비교할 때 사용할 비교 연산자 - `GreaterThanOrEqualToThreshold`, `GreaterThanThreshold`, `LessThanThreshold`, `LessThanOrEqualToThreshold`, `LessThanLowerOrGreaterThanUpperThreshold`, `LessThanLowerThreshold`
-   `evaluation_periods` : 지표가 임계값과 비교되는 평가 기간 수
-   `metric_name` : 알람과 연결된 CloudWatch 지표 이름
-   `namespace` : 알람과 연결된 CloudWatch 지표 네임스페이스
-   `period` : 지표가 집계되는 주기(초)
-   `statistic` : 지표에 적용할 통계 방식 - `Average`, `SampleCount`, `Sum`, `Minimum`, `Maximum`
-   `threshold` : 알람 트리거 기준이 되는 임계값
-   `alarm_description` : 알람에 대한 설명
-   `linked_sns_names` : Metric에서 사용하기 위해 연결한 SNS Topic 목록
-   `alarm_sns_names` : 지표가 임계값을 벗어났을 때 알림을 전송할 SNS Topic 목록
-   `ok_sns_names` : 지표가 정상 상태로 복구되었을 때 알림을 전송할 SNS Topic 목록
-   `insufficient_data_sns_names` : 데이터 부족 상태일 때 알림을 전송할 SNS Topic 목록

#### 태그

-   `tag` : 리소스를 분류하기 위한 태그 목록
