## 리소스 개요

조직 또는 조직 단위(OU) 내에서 지원되는 리소스 유형에 대해 AWS 계정 간 리소스를 안전하게 공유하는 서비스입니다.

## 연관 리소스

### 연결 리소스

-   [**Transit Gateway**](https://docs.cstudio.app/docs/resource/aws/Network/TransitGateway)
-   [**IAM Role**](https://docs.cstudio.app/docs/resource/aws/IAM/IamRole)

---

## 리소스 설정 값

#### 기본 설정

-   `shared_resource_types` : 공유할 리소스 종류 (체크 리스트)
-   `transit_gateway_names` : 공유할 Transit Gateway 이름 목록 (체크 리스트)
-   `resource_arns` : 공유할 리소스 ARN 목록
-   `enabled_allow_external_principals` : 외부 계정 공유 허용 여부 - `true`, `false`
-   `principal_arns` : 공유를 허용할 보안 주체 ARN 또는 계정 ID 목록
-   `tag` : 리소스 분류 태그 - `key`:`value`
