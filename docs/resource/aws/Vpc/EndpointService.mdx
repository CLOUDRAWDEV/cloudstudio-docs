## 리소스 개요

고객이 지원하는 AWS 서비스 및 VPC endpoint 서비스에 private하게 연결할 수 있는 서비스

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### 연결 리소스

-   [**Load Balancer**](https://docs.cstudio.app/docs/resource/aws/Network/LoadBalancer)
-   [**Endpoint**](https://docs.cstudio.app/docs/resource/aws/Network/Endpoint)

## 리소스 설정 값

#### 기본 설정

-   `acceptance_required` : VPC Endpoint 연결 요청을 서비스 소유자가 수락해야 하는지 여부 - `true`, `false`
-   `load_balancer_type` : Endpoint Service에 연결할 Load Balancer 유형 - `network`, `gateway`
-   `linked_lb_names` : Endpoint Service에 연결할 Load Balancer 이름 목록
-   `manual_lb_arns` : Endpoint Service에 연결할 Load Balancer ARN 목록
-   `supported_ip_address_types` : 지원되는 IP 주소 유형 목록 - `ipv4`
-   `activate_private_dns_name` : 서비스에 설정할 프라이빗 DNS 이름

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그
