## 리소스 개요

고객이 지원하는 AWS 서비스 및 VPC 엔드포인트 서비스에 프라이빗하게 연결할 수 있는 서비스

## 연관 리소스

### 상위 리소스

-   [**Vpc**](https://docs.cstudio.app/docs/resource/aws/Vpc/)

### 연결 리소스

-   [**Endpoint Service**](https://docs.cstudio.app/docs/resource/aws/Vpc/EndpointService)
-   [**Security Group**](https://docs.cstudio.app/docs/resource/aws/Vpc/SecurityGroup)
-   [**Subnet**](https://docs.cstudio.app/docs/resource/aws/Vpc/Subnet)

## 리소스 설정 값

#### 기본 설정

-   `service_range` : Endpoint 서비스를 사용할 서비스 범주 - `awsService`, `endpointService`
-   `aws_service_name` : Endpoint 서비스를 사용할 AWS 서비스 이름
-   `vpc_endpoint_type` : Endpoint 유형 - `Gateway`, `Interface`, `GatewayLoadBalancer`
-   `included_vpc_name` : Endpoint를 생성할 VPC 이름
-   `enabled_private_dns` : 프라이빗 DNS 활성화 여부 - `true`, `false`
-   `enable_private_dns_only_for_inbound_resolver_endpoint` : 인바운드 요청에 대해 프라이빗 DNS만 활성화 여부 - `true`, `false`
-   `dns_record_ip_type` : DNS 레코드 IP 유형 - `ipv4`, `dualstack`, `servicedefined`, `ipv6`
-   `ip_address_type` : Endpoint IP 주소 유형 - `ipv4`, `ipv6`, `dualstack`
-   `policy_access` : Endpoint에 연결할 정책 접근 범위 - `Full`, `Custom`
-   `custom_policy` : 서비스 접근을 제어하는 커스텀 정책

#### Endpoint Service 설정 (`endpoint_service`)

-   `endpoint_service.is_manual` : Endpoint Service ARN 직접 입력 여부 - `true`, `false`
-   `endpoint_service.service_name` : Endpoint Service 이름
-   `endpoint_service.linked_endpoint_service_name` : 연결된 Endpoint Service 이름

#### 네트워크 설정

-   `linked_security_group_names` : Endpoint에 연결할 Security Group 목록
-   `linked_subnet_names` : 네트워크 인터페이스를 생성할 Subnet 목록
-   `route_table_names` : Endpoint와 연결할 Route Table 목록

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그
