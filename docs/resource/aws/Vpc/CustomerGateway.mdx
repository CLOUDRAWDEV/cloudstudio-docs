## 리소스 개요

AWS Transit Gateway는 중앙 허브를 통해 Amazon Virtual Private Cloud(VPC)와 온프레미스 네트워크를 연결합니다. 이 연결은 복잡한 피어링 관계를 제거하여 네트워크를 간소화합니다. Transit Gateway는 고도로 확장 가능한 클라우드 라우터 역할을 합니다.

## 리소스 설정 값

#### 기본 설정

-   `bgp_asn` : 게이트웨이의 BGP ASN 값 - `1` ~ `2147483647`
-   `ip_address` : 게이트웨이 외부 인터페이스의 고정 공인 IP 주소
-   `private_certificate_arn` : AWS Private Certificate Manager 인증서 ARN

#### VPN 연결 설정 (`vpn_connection`)

-   `vpn_connection.resource_type` : Customer Gateway와 연결할 리소스 유형 - `none`, `transit_gateway`, `vpn_gateway`
-   `vpn_connection.linked_resource_name` : 연결할 리소스 이름
-   `vpn_connection.static_routes_only` : 정적 라우팅만 사용 여부 - `true`, `false`
-   `vpn_connection.outside_ip_address_type` : 외부 IP 주소 유형 - `PublicIpv4`, `PrivateIpv4`
-   `vpn_connection.dx_gateway_name` : 프라이빗 IP VPN 연결에 사용할 Transit Gateway Attachment 이름

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그
