## 리소스 개요

타 계정의 리소스 공유에 대한 허용여부를 결정하는 리소스

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/aws/Base/Region)

### 연결 리소스

-   [**Transit Gateway Attachment**](https://docs.cstudio.app/docs/resource/aws/Network/TransitGatewayAttachment)

## 리소스 설정 값

#### 기본 설정

-   `is_manual` : 연결할 Transit Gateway Attachment ID를 직접 입력할지 여부 - `true`, `false`
-   `transit_gateway_attachment_id` : 공유를 허용할 Transit Gateway Attachment ID
-   `linked_transit_gateway_attachment_name` : 공유를 허용할 Transit Gateway Attachment 이름

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그
