## 리소스 개요

AWS WAF IPSet은 Amazon Web Services의 Web Application Firewall에서 사용하는 IP 주소 목록입니다. 이를 통해, 사용자는 정의한 IP 주소들에 대한 액세스 규칙을 생성하고 관리할 수 있습니다. IPSet을 활용하면, 특정 IP 주소들로부터의 요청을 허용하거나 차단함으로써 웹 애플리케이션 보안을 강화할 수 있습니다.

## 리소스 개요

AWS WAF IP Set은 웹 ACL 규칙에서 참조할 수 있도록 하나 이상의 IP 주소 또는 CIDR 블록을 그룹화한 리소스로, 특정 IP 대역에 대한 허용 또는 차단 정책을 구성하는 데 사용됩니다.

## 리소스 설정 값

#### 기본 설정

-   `scope` : IP Set을 적용할 범위 지정 - `REGIONAL`, `CLOUDFRONT`
-   `ip_address_version` : IP 주소 버전 지정 - `IPV4`, `IPV6`
-   `addresses` : CIDR 표기법으로 지정한 IP 주소 또는 IP 주소 블록 목록

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그
