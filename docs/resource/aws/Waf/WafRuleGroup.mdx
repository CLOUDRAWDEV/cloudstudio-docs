## 리소스 개요

AWS WAF Rule Group은 Web Application Firewall에서 사용하는 규칙 모음입니다. Rule Group을 사용하여 여러 규칙을 묶어 웹 애플리케이션에 적용하고, 재사용성과 관리 효율성을 높일 수 있습니다. 규칙 그룹은 웹 애플리케이션 보안에 대한 중요한 측면을 제어하고, 요청을 허용, 차단 또는 카운트하는 기능을 수행합니다.

## 리소스 설정 값

#### 기본 설정

-   `scope` : Rule Group 적용 범위 지정 - `REGIONAL`, `CLOUDFRONT`
-   `capacity` : 규칙 그룹에 필요한 Web ACL 용량 단위(WCU)
-   `cloudwatch_metrics_enabled` : CloudWatch 지표 전송 여부 - `true`, `false`
-   `metric_name` : CloudWatch metric 이름, 영대소문자, 하이픈, 밑줄만 허용, `1` ~ `128`자
-   `sampled_requests_enabled` : 규칙과 일치하는 웹 요청 샘플링 저장 여부 - `true`, `false`

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그
