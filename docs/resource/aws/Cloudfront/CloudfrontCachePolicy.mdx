## 리소스 개요

Cloudfront Cache Policy는 Cloudfront 배포의 캐시 동작에 연결하여 CloudFront의 사용자 지정을 설정하는 캐시 정책입니다.

### 연결 리소스

-   [**CloudfrontDistribution**](https://docs.cstudio.app/docs/resource/aws/Cloudfront/CloudfrontDistribution)

## 리소스 설정 값

#### 기본 설정

-   `min_ttl` : 객체가 캐시에 유지되는 최소 시간(초)
-   `default_ttl` : 객체가 캐시에 유지되는 기본 시간(초)
-   `max_ttl` : 객체가 캐시에 유지되는 최대 시간(초)

#### 쿠키 설정 (`cookie_config`)

-   `cookie_behavior` : 쿠키 전달 방식 - `whitelist`, `all`, `none`, `allExcept`
-   `cookies_items` : 오리진으로 전달할 쿠키 목록

#### 헤더 설정 (`header_config`)

-   `header_behavior` : 헤더 기반 캐싱 방식 - `whitelist`, `none`
-   `headers_items` : 캐싱에 사용할 헤더 목록

#### 쿼리 스트링 설정 (`query_string_config`)

-   `query_string_behavior` : 쿼리 스트링 처리 방식 - `whitelist`, `all`, `none`, `allExcept`
-   `query_strings_items` : 캐싱에 사용할 쿼리 스트링 파라미터 목록
