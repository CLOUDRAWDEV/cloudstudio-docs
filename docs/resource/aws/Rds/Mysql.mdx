## 리소스 개요

AWS에서 MySQL을 사용하여 RDS를 구축하면 데이터베이스의 운영 및 관리를 쉽게 할 수 있습니다. RDS는 확장성이 뛰어나며, 필요에 따라 인스턴스 유형을 변경하여 성능을 향상시킬 수 있습니다. 또한 RDS는 데이터베이스 인스턴스에 대한 자동 백업 및 복원 기능을 제공하여 데이터 손실을 방지할 수 있습니다. 또한 AWS에서 제공하는 보안 기능으로 데이터의 안전성을 보장할 수 있습니다.

## 리소스 설정 값

#### 기본 설정

-   `server_name_prefix` : MySQL 서버 이름 접두사, 영소문자/숫자/하이픈(-) 허용, 영소문자로 시작, 영소문자 또는 숫자로 끝나야 함, `3` ~ `30`자
-   `databases` : 생성할 데이터베이스 이름 목록
-   `included_subnet_names` : MySQL이 포함될 Subnet 이름 목록
-   `image_product_code` : MySQL 서버 이미지 제품 코드
-   `product_code` : MySQL 인스턴스 서버 사양을 결정하는 제품 코드
-   `data_storage_type` : 데이터 스토리지 타입 - `SSD`, `HDD`
-   `enable_high_availability` : 고가용성 기능 사용 여부 - `true`, `false`
-   `enable_storage_encryption` : 스토리지 암호화 기능 사용 여부 - `true`, `false`
-   `port` : MySQL 접속 포트 - `3306` ~ `20000`

#### 사용자 설정 (`users`)

-   `users.password` : 사용자 패스워드
-   `users.host_ip` : 접속 허용 클라이언트 IP (`%`, `1.1.1.1`, `1.1.1.%`)
-   `users.authority` : 사용자 권한 - `DDL`, `CRUD`, `READ`

#### 백업 설정

-   `enable_backup` : 백업 기능 사용 여부 - `true`, `false`
-   `backup_file_retention_period` : 백업 파일 보관 기간(일) - `1` ~ `30`
-   `enable_automatic_backup` : 백업 자동화 기능 사용 여부 - `true`, `false`
-   `backup_time` : 사용자 지정 백업 시간
