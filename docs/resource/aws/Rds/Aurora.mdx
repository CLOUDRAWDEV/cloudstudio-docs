## 리소스 개요

Amazon Aurora(Aurora)는 MySQL 및 PostgreSQL과 호환되는 완전 관리형 관계형 데이터베이스 엔진입니다. MySQL 및 PostgreSQL이 이 고급 상용 데이터베이스의 속도와 안정성을 오픈 소스 데이터베이스의 단순성 및 비용 효율성과 어떻게 결합하는지 이미 알고 계실 것입니다. 오늘날 기존 MySQL 및 PostgreSQL 데이터베이스에 사용되는 코드, 도구 및 애플리케이션 모두 Aurora에서도 사용할 수 있습니다. 일부 워크로드의 경우 Aurora은 기존 애플리케이션을 거의 변경하지 않고도 MySQL의 처리량을 최대 5배, PostgreSQL의 처리량을 최대 3배 제공할 수 있습니다.

## 리소스 설정 값

#### 기본 설정

-   `database_name` : 초기 데이터베이스 이름, 1 ~ 64자의 영숫자
-   `engine` : RDS에 사용할 Aurora Engine 종류 - `aurora-mysql`, `aurora-postgresql`
-   `engine_version` : RDS에 사용할 Aurora Engine 버전
-   `instance_class` : RDS DB 인스턴스 타입
-   `engine_mode` : Aurora Engine 방식 - `provisioned`, `multimaster`, `parallelquery`, `serverless`
-   `multi_az_enabled` : 다중 AZ 배포 활성화 여부 - `true`, `false`
-   `master_username` : 마스터 사용자 이름
-   `master_password` : 마스터 사용자 비밀번호
-   `included_subnet_names` : RDS Subnet 그룹에 연결할 Subnet 이름 목록
-   `subnet_group_name` : RDS에 사용할 Subnet 그룹 이름
-   `linked_security_group_names` : 적용할 보안 그룹 목록

#### 모니터링 설정 (`monitoring`)

-   `monitoring.performance_insights_enabled` : 성능 인사이트 활성화 여부 - `true`, `false`
-   `monitoring.kms_key_name` : 성능 인사이트에 사용할 KMS 키 이름

#### 암호화 설정 (`encryption`)

-   `encryption.storage_encrypted` : DB 인스턴스 암호화 여부 - `true`, `false`
-   `encryption.kms_key_name` : 암호화에 사용할 KMS 키 이름

#### 백업 설정 (`backup`)

-   `backup.backup_retention_period` : 백업 데이터 보관 기간 - `1` ~ `35`
-   `backup.final_snapshot_enabled` : DB 삭제 전 최종 스냅샷 생성 여부 - `true`, `false`
-   `backup.final_snapshot_name` : 최종 스냅샷 이름

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
