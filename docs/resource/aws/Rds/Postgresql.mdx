## 리소스 개요

AWS에서 PostgreSQL을 사용하여 RDS를 구축하면 데이터베이스 운영과 관리가 쉽고, 확장성이 높습니다. 또한 RDS는 데이터베이스 인스턴스에 대한 자동 백업 및 복원 기능을 제공하여 데이터 손실을 방지할 수 있으며, AWS에서 제공하는 보안 기능으로 데이터의 안전성을 보장할 수 있습니다.

## 리소스 설정 값

#### 기본 설정

-   `database_name` : 초기 데이터베이스 이름 - `1` ~ `64`자의 영숫자
-   `engine_version` : RDS에 사용할 PostgreSQL 엔진 버전
-   `instance_class` : RDS DB 인스턴스 타입
-   `storage_type` : RDS 인스턴스 스토리지 타입 - `gp2`, `io1`, `standard`
-   `allocated_storage` : RDS 스토리지 용량(GB) - `20` ~ `65536`
-   `max_allocated_storage` : 스토리지 자동 확장 최대 한계값
-   `iops` : DB 인스턴스가 지원하는 초당 I/O 작업 수 - `1000` ~ `40000`
-   `multi_az_enabled` : 다중 AZ 배포 활성화 여부 - `true`, `false`
-   `username` : RDS 관리자 사용자 이름
-   `password` : RDS 관리자 사용자 비밀번호
-   `publicly_accessible` : 퍼블릭 액세스 허용 여부 - `true`, `false`

#### 네트워크 설정

-   `included_subnet_names` : RDS Subnet Group에 포함될 Subnet 이름 목록
-   `subnet_group_name` : RDS에 사용할 Subnet Group 이름
-   `linked_security_group_names` : 적용할 보안 그룹 목록

#### 모니터링 설정 (`monitoring`)

-   `monitoring.performance_insights_enabled` : Performance Insights 활성화 여부 - `true`, `false`
-   `monitoring.kms_key_name` : Performance Insights에 사용할 KMS Key 이름

#### 암호화 설정 (`encryption`)

-   `encryption.storage_encrypted` : DB 인스턴스 스토리지 암호화 여부 - `true`, `false`
-   `encryption.kms_key_name` : 암호화에 사용할 KMS Key 이름

#### 백업 설정 (`backup`)

-   `backup.backup_retention_period` : 백업 보관 기간(일) - `1` ~ `35`
-   `backup.final_snapshot_enabled` : DB 삭제 전 최종 스냅샷 생성 여부 - `true`, `false`
-   `backup.final_snapshot_name` : 최종 스냅샷 이름

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그
