## 리소스 개요

AWS에서 PostgreSQL을 사용하여 RDS를 구축하면 데이터베이스 운영과 관리가 쉽고, 확장성이 높습니다. 또한 RDS는 데이터베이스 인스턴스에 대한 자동 백업 및 복원 기능을 제공하여 데이터 손실을 방지할 수 있으며, AWS에서 제공하는 보안 기능으로 데이터의 안전성을 보장할 수 있습니다.

## 리소스 설정 값

#### 기본 설정

-   `server_name_prefix` : Postgresql 서버 이름 접두사
-   `included_vpc_name` : Postgresql이 포함된 VPC 이름
-   `included_subnet_name` : Postgresql이 포함된 Subnet 이름
-   `enable_high_availability` : 고가용성 기능 사용 여부 - `true`, `false`
-   `user_name` : Postgresql 사용자 접근 ID
-   `user_password` : Postgresql 사용자 접근 비밀번호
-   `image_product_code` : Postgresql 서버 이미지 제품 코드
-   `product_code` : Postgresql 서버 사양 제품 코드
-   `data_storage_type` : 데이터 스토리지 종류 - `SSD`, `HDD`
-   `is_backup` : 백업 사용 여부 - `true`, `false`
-   `backup_file_retention_period` : 백업 파일 보관 기간
-   `enable_automatic_backup` : 백업 자동화 사용 여부 - `true`, `false`
-   `backup_time` : 백업 시간
-   `port` : Postgresql 접근 포트
-   `client_cidr` : 클라이언트 IP 주소 범위
-   `database_name` : 기본 DB 이름
-   `enable_storage_encryption` : 스토리지 암호화 사용 여부 - `true`, `false`
