## 리소스 개요

SQL Server는 Microsoft에서 개발한 관계형 데이터베이스 관리 시스템입니다. Amazon RDS for SQL Server를 사용하면 클라우드에서 SQL Server 배포를 손쉽게 설정, 운영 및 확장할 수 있습니다. Amazon RDS를 사용하면 비용 효율적이고 크기 조정 가능한 컴퓨팅 파워와 함께 Express, Web, Standard, Enterprise 등 여러 버전의 SQL Server(2014, 2016, 2017 및 2019)를 몇 분 만에 배포할 수 있습니다. 또한 프로비저닝, 백업, 소프트웨어 패치, 모니터링, 하드웨어 크기 조정 같은 시간 소모적인 데이터베이스 관리 업무를 대신 처리하므로 고객은 애플리케이션 개발에만 집중할 수 있습니다.

## 리소스 설정 값

#### 기본 설정

-   `engine` : RDS에 사용할 Microsoft SQL Server 엔진 종류 - `sqlserver-ex`, `sqlserver-ee`, `sqlserver-web`, `sqlserver-se`
-   `engine_version` : RDS에 사용할 Microsoft SQL Server 버전
-   `instance_class` : RDS DB 인스턴스 타입
-   `storage_type` : RDS 인스턴스의 스토리지 타입
-   `iops` : DB 인스턴스에서 지원하는 초당 I/O 작업 수 - `1000` ~ `40000`
-   `allocated_storage` : RDS 인스턴스 스토리지 용량(GiB) - `20` ~ `65536`
-   `max_allocated_storage` : 스토리지 자동 확장 상한선
-   `multi_az_enabled` : 다중 AZ 배포 활성화 여부 - `true`, `false`
-   `username` : RDS 사용자 이름
-   `password` : RDS 사용자 비밀번호
-   `included_subnet_names` : RDS Subnet 그룹에 연결할 Subnet 이름 목록
-   `subnet_group_name` : RDS에 사용할 Subnet 그룹 이름
-   `linked_security_group_names` : 적용할 보안 그룹 목록
-   `publicly_accessible` : 퍼블릭 액세스 허용 여부 - `true`, `false`

#### 모니터링 설정 (`monitoring`)

-   `monitoring.performance_insights_enabled` : 성능 인사이트 활성화 여부 - `true`, `false`
-   `monitoring.kms_key_name` : 성능 인사이트에 사용할 KMS 키 이름

#### 암호화 설정 (`encryption`)

-   `encryption.storage_encrypted` : DB 인스턴스 암호화 여부 - `true`, `false`
-   `encryption.kms_key_name` : 암호화에 사용할 KMS 키 이름

#### 백업 설정 (`backup`)

-   `backup.backup_retention_period` : 백업 데이터 보관 기간 - `1` ~ `35`
-   `backup.final_snapshot_enabled` : DB 삭제 전 최종 스냅샷 생성 여부 - `true`, `false`
-   `backup.final_snapshot_name` : 최종 스냅샷 이름

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
