## 리소스 개요

AWS Elasticache Cluster는 클라우드 기반의 인 메모리 데이터 스토어이며, 빠르고 확장 가능한 캐싱 솔루션을 제공합니다. Elasticache Cluster는 Redis 또는 Memcached 엔진을 사용하여 클러스터 모드 또는 단일 노드 모드에서 실행할 수 있습니다. Elasticache Cluster는 애플리케이션의 성능을 향상시키는 데 사용되며, 데이터를 더 빠르게 검색하고 처리할 수 있습니다. Elasticache Cluster는 자동 백업, 복구, 확장 및 모니터링 기능을 제공하여 사용자가 안심하고 데이터를 저장할 수 있도록 도와줍니다.

## 리소스 설정 값

#### 기본 설정

-   `engine` : Cache Engine 종류 - `redis`, `memcached`
-   `engine_version` : Cache Engine 버전
-   `port` : Cache Node 연결 포트 (Redis: 6379, Memcached: 11211)
-   `parameter_group_name` : 연결할 파라미터 그룹 이름
-   `node_type` : Cache Node 인스턴스 타입
-   `num_cache_nodes` : Cache Node 개수
-   `az_mode` : 가용 영역 구성 방식 - `single-az`, `cross-az`
-   `included_subnet_names` : Subnet Group에 포함될 Subnet 이름 목록
-   `subnet_group_name` : 사용할 Subnet Group 이름
-   `snapshot_retention_limit` : 자동 스냅샷 보관 기간(일)

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그
