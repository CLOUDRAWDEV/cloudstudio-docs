## 리소스 설정 값

#### 기본 설정

-   `set_container_insights` : Container Insights를 클러스터에 할당할지 설정 - `enabled`, `disabled`
-   `kms_key_name` : 로컬 클라이언트와 컨테이너 간의 데이터를 암호화하기 위한 AWS Key Management Service 키 이름
-   `logging` : 실행 명령 결과에 대한 로그 리디렉션에 사용할 로그 설정 - `OVERRIDE`, `NONE`, `DEFAULT`
-   `cloud_watch_encryption_enabled` : CloudWatch 로그에서 암호화 활성화 여부 - `true`, `false`
-   `cloud_watch_log_group_name` : 로그를 보낼 CloudWatch 로그 그룹의 이름
-   `capacity_providers` : 클러스터와 연결할 capacity provider 집합

#### 서비스 (`service`)

-   `service.computing_option` : Service의 작업 분산 방식 - `capacity_provider_strategy`, `launch_type`
-   `service.capacity_provider_strategy.capacity_provider` : Service에 적용할 용량 공급자 - `FARGATE`, `FARGATE_SPOT`
-   `service.capacity_provider_strategy.base` : 실행할 최소한 작업 수
-   `service.capacity_provider_strategy.weight` : 실행된 총 작업 수의 상대적 백분율
-   `service.launch_type` : Service의 시작 유형 - `EC2`, `FARGATE`, `EXTERNAL`
-   `service.task_definition_name` : Service를 사용할 ECS Task Definition의 이름
-   `service.desired_count` : 서비스를 실행할 작업 정의의 인스턴스 수
-   `service.linked_security_group_names` : 사용할 Security Group 이름 목록
-   `service.subnet_names` : Service가 실행될 Subnet 이름 목록
-   `service.enabled_public_ip` : Public IP 사용 여부 - `true`, `false`

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그
