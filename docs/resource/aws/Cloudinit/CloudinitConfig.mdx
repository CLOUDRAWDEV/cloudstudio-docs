## 리소스 개요

Cloud-init은 가상 머신 인스턴스를 초기화하고 설정하는 도구입니다.

## 연관 리소스

-   [**Virtual Machine**](https://docs.cstudio.app/docs/resource/common/Compute/VirtualMachine)

## 리소스 설정 값

#### 기본 설정

-   `gzip` : 데이터 압축 알고리즘으로, 파일이나 데이터를 압축하여 크기를 줄이는 데 사용되는 옵션 - `true`, `false`

#### 파트 설정 (`part`)

-   `part.content_type` : 삽입할 데이터의 형식을 정의
    -   `text/cloud-config`
    -   `text/x-shellscript`
    -   `text/cloud-boothook`
    -   `multipart/mixed`
    -   `text/cloud-config-archive`
    -   `text/jinja`
    -   `text/x-include-url`
    -   `text/part-handler`
-   `part.content` : 삽입할 실제 데이터

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
