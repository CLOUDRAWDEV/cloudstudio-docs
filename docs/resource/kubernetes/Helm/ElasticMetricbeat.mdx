## 리소스 개요

Metricbeat를 쿠버네티스 환경에 배포하기 위한 Helm Chart 리소스입니다.  
Helm Chart 버전을 지정할 수 있으며,  
`set` 옵션을 통해 Metricbeat 기본 Helm Chart의 값을 동적으로 오버라이드할 수 있습니다.

## 연관 리소스

### 상위 리소스

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

## 리소스 설정 값

-   `namespace` : Metricbeat Helm Chart 리소스가 배포될 네임스페이스
-   `version` : 사용할 Metricbeat Helm Chart 버전
-   `set` : Metricbeat 기본 Helm Chart의 값을 동적으로 변경하기 위한 key-value 설정
