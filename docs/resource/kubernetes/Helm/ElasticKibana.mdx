## 리소스 개요

Kibana를 쿠버네티스 환경에 배포하기 위한 Helm Chart 리소스입니다.  
서비스 타입(ClusterIP, NodePort, LoadBalancer)을 지정할 수 있으며,  
`set` 옵션을 통해 Kibana Helm Chart의 기본 값을 동적으로 오버라이드할 수 있습니다.

## 연관 리소스

### 상위 리소스

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

## 리소스 설정 값

-   `namespace` : Kibana Helm Chart 리소스가 배포될 네임스페이스
-   `version` : 사용할 Kibana Helm Chart 버전
-   `service_type` : Kibana 서비스 타입  
    (`ClusterIP`, `NodePort`, `LoadBalancer`)
-   `set` : Kibana 기본 Helm Chart의 값을 동적으로 변경하기 위한 key-value 설정
