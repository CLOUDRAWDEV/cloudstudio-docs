## 리소스 개요

ElasticSearch를 쿠버네티스 환경에 배포하기 위한 Helm Chart 리소스입니다.  
클러스터의 복제본 수, 마스터 노드 구성, 기본 인증 비밀번호 등을 설정할 수 있으며,  
`set` 옵션을 통해 Helm Chart의 기본 값을 유연하게 오버라이드할 수 있습니다.

## 연관 리소스

### 상위 리소스

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

## 리소스 설정 값

-   `namespace` : ElasticSearch Helm Chart 리소스가 배포될 네임스페이스
-   `version` : 사용할 ElasticSearch Helm Chart 버전
-   `replicas` : ElasticSearch 클러스터의 복제본 노드 수
-   `minimum_master_nodes` : 마스터 노드가 정상 동작하기 위한 최소 마스터 후보 노드 수
-   `password` : 기본 사용자 인증 비밀번호
-   `set` : ElasticSearch 기본 Helm Chart의 값을 동적으로 변경하기 위한 key-value 설정
