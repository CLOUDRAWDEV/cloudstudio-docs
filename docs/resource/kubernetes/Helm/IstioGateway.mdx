## 리소스 개요

Istio Gateway 헬름 차트입니다.

## 연관 리소스

### 상위 리소스

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

## 리소스 설정 값

-   `namespace` : Istio Gateway Helm Chart 리소스가 배포될 네임스페이스
-   `version` : 사용할 Istio Ingress Helm Chart 버전
-   `set` : Istio Ingress 기본 Helm Chart의 값을 동적으로 변경하기 위한 key-value 설정
