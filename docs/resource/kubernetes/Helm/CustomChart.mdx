## 리소스 개요

기본 헬름 차트를 사용자가 원하는 값으로 설정하여 배포할 수 있는 리소스입니다.

## 연관 리소스

### 상위 리소스

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

## 리소스 설정 값

-   `namespace` : 커스텀 Helm Chart 리소스가 배포될 네임스페이스
-   `repository` : 커스텀할 Helm Chart가 저장된 저장소 주소
-   `chart` : 커스텀할 Helm Chart 이름
-   `version` : 커스텀할 Helm Chart 버전
-   `set` : 기본 Helm Chart의 값을 동적으로 변경하기 위한 key-value 설정
