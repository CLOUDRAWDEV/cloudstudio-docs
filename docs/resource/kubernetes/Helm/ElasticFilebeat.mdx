## 리소스 개요

Filebeat를 쿠버네티스 환경에 배포하기 위한 Helm Chart 리소스입니다. 노드 및 파드에서 생성되는 로그를 수집하여 Elastic Stack 등 외부 시스템으로 전달하는 경량 로그 수집기로 사용되며, `set` 옵션을 통해 Helm Chart의 기본 설정 값을 유연하게 오버라이드할 수 있습니다.

## 연관 리소스

### 상위 리소스

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

## 리소스 설정 값

-   `namespace` : Filebeat Helm Chart 리소스가 배포될 네임스페이스
-   `version` : 사용할 Filebeat Helm Chart 버전
-   `set` : Filebeat 기본 Helm Chart의 값을 동적으로 변경하기 위한 key-value 설정
