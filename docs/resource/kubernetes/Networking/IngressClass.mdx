## 리소스 개요

인그레스가 사용할 인그레스 컨트롤러를 선택하기 위한 쿠버네티스 리소스

## 연관 리소스

### 상위 리소스

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)

### 연결 리소스

-   [**Ingress**](https://docs.cstudio.app/docs/resource/kubernetes/Networking/Ingress)

## 리소스 설정 값

#### 기본 설정

-   `annotations` : 쿠버네티스 시스템에서 IngressClass 동작에 필요한 메타데이터 key-value
-   `labels` : IngressClass 객체를 구분하기 위한 사용자 정의 레이블
-   `controller` : 해당 IngressClass를 처리할 Ingress Controller의 식별자

#### 파라미터 설정 (parameters)

-   `parameters.kind` : 참조할 파라미터 리소스 유형 -`IngressParameter`, `ClusterIngressParameter`
-   `parameters.namespace` : 참조되는 파라미터 리소스의 네임스페이스
-   `parameters.api_group` : 참조되는 파라미터 리소스가 속한 API Group
