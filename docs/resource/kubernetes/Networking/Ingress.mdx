## 리소스 개요

## 리소스 설정 값

-   `namespace` : Ingress 리소스가 배포될 네임스페이스
-   `annotations` : Ingress Controller 동작을 제어하기 위한 메타데이터
-   `labels` : 리소스 식별을 위한 사용자 정의 레이블
-   `tls.hosts` : TLS 인증서가 적용될 호스트 목록
-   `tls.secret_name` : TLS 인증서가 저장된 Kubernetes Secret 이름
-   `ingress_class_name` : 트래픽을 처리할 Ingress Controller 클래스 이름
-   `rule.host` : 라우팅 규칙을 적용할 호스트명
-   `rule.backend.target_service` : 요청을 전달할 대상 Service
-   `rule.backend.path` : 백엔드와 연결될 URL 경로
-   `rule.backend.port` : 대상 Service의 포트 번호
-   `rule.backend.path_type` : 경로 매칭 방식(ImplementationSpecific, Prefix, Exact)
