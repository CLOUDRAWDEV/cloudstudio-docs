## 리소스 개요

일회성 작업을 실행하는 데 사용되는 쿠버네티스 리소스입니다.

## 연관 리소스

### 상위 리소스

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

### 연결 대상

-   [**Config Map**](https://docs.cstudio.app/docs/resource/kubernetes/Core/ConfigMap)
-   [**Secret**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Secret)

## 리소스 설정 값

#### 기본 설정

-   `namespace` : Job 리소스가 배포될 네임스페이스
-   `restart_policy` : 컨테이너 실패 또는 작업 완료 후 처리 방식 (Never / OnFailure)
-   `backoff_limit` : 작업을 실패로 처리하기 전 재시도 횟수
-   `wait_for_completion` : 작업 완료 또는 실패 시점까지 생성·업데이트 차단 여부
-   `containers` : 실행될 컨테이너 스펙 정의
-   `init_containers` : 메인 컨테이너 실행 전 선행 작업 정의
-   `volume` : 컨테이너에서 마운트할 볼륨 설정
-   `pod_security_context` : 파드 단위 보안 컨텍스트 설정
-   `image_pull_secrets` : 이미지 Pull을 위한 Secret 참조
