## 리소스 개요

일정에 따라 주기적으로 작업을 생성하는 쿠버네티스 리소스입니다.

## 연관 리소스

### 상위 리소스

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Namespace)

### 연결 대상

-   [**Config Map**](https://docs.cstudio.app/docs/resource/kubernetes/Config/ConfigMap)
-   [**Secret**](https://docs.cstudio.app/docs/resource/kubernetes/Config/Secret)

## 리소스 설정 값

#### 기본 설정

-   `namespace` : CronJob이 배포될 네임스페이스
-   `schedule` : 크론 표현식으로 정의하는 작업 실행 주기
-   `timezone` : 스케줄이 해석될 기준 시간대
-   `concurrency_policy` : 작업 동시 실행 처리 방식 (Allow / Forbid / Replace)
-   `starting_deadline_seconds` : 스케줄을 놓쳤을 때 작업 시작 허용 시간
-   `successful_jobs_history_limit` : 성공한 Job 보관 개수
-   `failed_jobs_history_limit` : 실패한 Job 보관 개수
-   `containers` : 실행될 컨테이너 스펙 정의
-   `init_containers` : 메인 컨테이너 실행 전 선행 작업 정의
-   `volume` : 컨테이너에서 마운트할 볼륨 설정
-   `pod_security_context` : 파드 단위 보안 컨텍스트 설정
-   `image_pull_secrets` : 이미지 Pull을 위한 Secret 참조
