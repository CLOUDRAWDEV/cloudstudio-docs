## 리소스 개요

DaemonSet은 모든(또는 일부) 노드가 파드(Pod) 복사본을 실행하도록 보장하는 쿠버네티스 리소스입니다. 클러스터에 노드가 추가되면 해당 노드에 파드(Pod)가 추가됩니다.

## 리소스 설정 값

#### 기본 설정

-   `namespace` : DaemonSet 리소스가 배포될 네임스페이스
-   `annotations` : 쿠버네티스 시스템에서 사용하는 메타데이터 key-value
-   `labels` : DaemonSet 리소스 식별을 위한 사용자 정의 라벨
-   `template_labels` : 생성될 Pod에 적용되는 라벨
-   `pod_security_context` : Pod 단위 보안 및 권한 설정
-   `init_containers` : 메인 컨테이너 실행 전에 수행되는 초기화 컨테이너 정의
-   `containers` : Pod에 포함될 컨테이너 정의
-   `volume` : Pod에서 사용할 볼륨 정의
-   `dns_policy` : Pod의 DNS 정책
-   `enable_service_links` : 서비스 환경 변수 자동 주입 여부
-   `host_network` : 호스트 네트워크 사용 여부
-   `image_pull_secrets` : 이미지 Pull 시 사용할 Secret 목록
