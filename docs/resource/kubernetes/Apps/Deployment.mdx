## 리소스 설정 값

#### 기본 설정

-   `namespace` : Deployment 리소스가 배포될 네임스페이스
-   `annotations` : 쿠버네티스 시스템 메타데이터 key-value
-   `labels` : Deployment 리소스 식별용 라벨
-   `template_labels` : 생성될 Pod에 적용되는 라벨
-   `replicas` : 유지할 Pod 복제본 수
-   `pod_security_context` : Pod 단위 보안 및 권한 설정
-   `init_containers` : 메인 컨테이너 실행 전 초기화 컨테이너 정의
-   `containers` : Pod에 포함될 컨테이너 정의
-   `volume` : Pod에서 사용할 볼륨 정의
-   `dns_policy` : Pod DNS 정책
-   `enable_service_links` : 서비스 환경 변수 자동 주입 여부
-   `host_network` : 호스트 네트워크 사용 여부
-   `image_pull_secrets` : 이미지 Pull 시 사용할 Secret 목록
