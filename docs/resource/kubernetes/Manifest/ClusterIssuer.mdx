## 리소스 개요

ClusterIssuer는 cert-manager에서 사용하는 클러스터 범위(Kubernetes cluster-scoped) 리소스로, 인증서 서명 요청(CSR)을 받아 인증기관(CA)으로부터 서명된 인증서를 발급받기 위한 설정 단위입니다. Issuer와 달리 특정 네임스페이스에 종속되지 않으며, 클러스터 전체의 Certificate 리소스에서 공통으로 참조할 수 있습니다. ACME 기반 인증기관(예: Let’s Encrypt)을 사용하며, HTTP-01 또는 DNS-01 챌린지를 통해 도메인 소유권을 검증합니다.

## 리소스 설정 값

#### 기본 설정

-   `namespace` : Issuer 리소스가 배포될 네임스페이스

#### ACME 설정 (`acme`)

-   `acme.server` : ACME 서버의 엔드포인트 주소
-   `acme.email` : 인증서 만료 또는 문제 발생 시 연락받을 이메일 주소
-   `acme.private_key_secret_ref` : ACME 서버와 통신에 사용될 클라이언트 키가 저장된 Kubernetes Secret 이름

#### DNS 챌린지 설정 (`dns_solvers`)

-   `dns_solvers.provider` : DNS-01 챌린지 유형 - `AzureDNS`, `Route53`, `ACMEDNS`

##### ACMEDNS 설정

-   `dns_solvers.acme_dns.host` : acme-dns 서버의 엔드포인트 주소
-   `dns_solvers.acme_dns.account_secret_ref_name` : acme-dns 계정 정보를 저장하는 Secret 이름
-   `dns_solvers.acme_dns.account_secret_ref_key` : Secret에서 사용할 키 이름

##### AzureDNS 설정

-   `dns_solvers.azure_dns.client_id` : Azure Service Principal 애플리케이션 Client ID
-   `dns_solvers.azure_dns.client_secret_name` : Client Secret이 저장된 Kubernetes Secret 이름
-   `dns_solvers.azure_dns.client_secret_key` : Secret에서 사용할 키 이름
-   `dns_solvers.azure_dns.subscription_id` : Azure 구독 ID
-   `dns_solvers.azure_dns.tenant_id` : Azure Tenant ID
-   `dns_solvers.azure_dns.resource_group_name` : Azure DNS Zone이 속한 리소스 그룹 이름
-   `dns_solvers.azure_dns.hosted_zone_name` : Azure DNS Zone 이름

##### Route53 설정

-   `dns_solvers.route53.region` : Route53 서비스가 사용되는 AWS 리전
-   `dns_solvers.route53.access_key_id` : AWS Access Key ID
-   `dns_solvers.route53.access_key_secret_name` : AWS Secret Access Key가 저장된 Secret 이름
-   `dns_solvers.route53.access_key_secret_key` : Secret에서 사용할 키 이름
-   `dns_solvers.route53.secret_access_key_secret_name` : AWS Secret Access Key Secret 이름
-   `dns_solvers.route53.secret_access_key_secret_key` : Secret에서 사용할 키 이름
-   `dns_solvers.route53.role` : Route53 DNS를 관리할 AWS IAM Role

#### HTTP 챌린지 설정 (`http_solvers`)

-   `http_solvers.provider` : HTTP-01 챌린지 해결 방식 - `Ingress`, `Gateway`
-   `http_solvers.ingress_class_name` : 사용할 Ingress Class 이름

##### Gateway 설정

-   `http_solvers.gateway_parent_refs.name` : 연결할 Gateway 리소스 이름
-   `http_solvers.gateway_parent_refs.namespace` : Gateway 리소스가 속한 네임스페이스
