## 리소스 개요

인증서 서명 요청을 수락하여 인증기관(CA)으로부터 서명된 인증서를 생성할 수 있는 쿠버네티스 리소스입니다.

### 연결 리소스

## 리소스 설정 값

#### 기본 설정

-   `namespace` : Issuer 리소스가 배포될 네임스페이스

#### ACME 설정 (`acme`)

-   `acme.server` : ACME 서버의 엔드포인트 주소
-   `acme.email` : 인증서 문제 또는 만료 시 Let's Encrypt에서 연락할 이메일 주소
-   `acme.private_key_secret_ref` : ACME 서버 통신에 사용할 클라이언트 키가 저장된 Kubernetes Secret 이름

#### DNS Solver 설정 (`dns_solvers`)

-   `dns_solvers.provider` : DNS-01 챌린지 유형 - `AzureDNS`, `Route53`, `ACMEDNS`

##### ACMEDNS 설정 (`dns_solvers.acme_dns`)

-   `dns_solvers.acme_dns.host` : acme-dns 서버 엔드포인트 주소
-   `dns_solvers.acme_dns.account_secret_ref_name` : acme-dns 계정 정보가 저장된 Kubernetes Secret 이름
-   `dns_solvers.acme_dns.account_secret_ref_key` : Secret에서 사용할 계정 정보 키 이름

##### AzureDNS 설정 (`dns_solvers.azure_dns`)

-   `dns_solvers.azure_dns.client_id` : Azure Service Principal 클라이언트 ID
-   `dns_solvers.azure_dns.client_secret_name` : client secret이 저장된 Kubernetes Secret 이름
-   `dns_solvers.azure_dns.client_secret_key` : Secret에서 사용할 client secret 키 이름
-   `dns_solvers.azure_dns.subscription_id` : Azure 구독 ID
-   `dns_solvers.azure_dns.tenant_id` : Azure Tenant ID
-   `dns_solvers.azure_dns.resource_group_name` : Azure DNS Zone이 속한 리소스 그룹
-   `dns_solvers.azure_dns.hosted_zone_name` : Azure DNS Zone 이름

##### Route53 설정 (`dns_solvers.route53`)

-   `dns_solvers.route53.region` : Route53이 사용되는 AWS 리전
-   `dns_solvers.route53.access_key_id` : AWS 액세스 키 ID
-   `dns_solvers.route53.access_key_secret_name` : AWS Secret Access Key가 저장된 Secret 이름
-   `dns_solvers.route53.access_key_secret_key` : Secret에서 사용할 키 이름
-   `dns_solvers.route53.secret_access_key_secret_name` : Secret Access Key가 저장된 Secret 이름
-   `dns_solvers.route53.secret_access_key_secret_key` : Secret Access Key의 키 이름
-   `dns_solvers.route53.role` : Route53 DNS 관리를 위한 AWS IAM Role

#### HTTP Solver 설정 (`http_solvers`)

-   `http_solvers.provider` : HTTP-01 챌린지 해결 방식 - `Ingress`, `Gateway`
-   `http_solvers.ingress_class_name` : 사용할 Ingress 클래스 이름

##### Gateway 설정 (`http_solvers.gateway_parent_refs`)

-   `http_solvers.gateway_parent_refs.name` : 연결할 Gateway 리소스 이름
-   `http_solvers.gateway_parent_refs.namespace` : Gateway 리소스가 속한 네임스페이스
