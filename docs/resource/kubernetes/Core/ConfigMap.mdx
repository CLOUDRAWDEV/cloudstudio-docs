## 리소스 개요

애플리케이션 설정 정보를 분리하여 저장하고 파드 내의 컨테이너에 전달하는 데 사용되는 쿠버네티스 리소스입니다.

## 리소스 설정 값

#### 기본 설정

-   `namespace` : ConfigMap 리소스가 배포될 네임스페이스
-   `annotations` : Kubernetes 시스템 메타데이터
-   `data` : 텍스트 기반 설정 데이터를 key-value 형태로 저장
-   `labels` : 리소스 식별 및 분류를 위한 사용자 정의 라벨
-   `binary_data` : 바이너리 형식의 데이터를 key-value 형태로 저장
