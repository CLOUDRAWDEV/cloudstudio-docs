## 리소스 개요

쿠버네티스 클러스터 내에서 애플리케이션 및 서비스가 클러스터 자원에 접근하고 사용할 수 있도록 권한을 부여하는 계정입니다.

## 연관 리소스

### 상위 리소스

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

### 연결 리소스

-   [**Secret**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Secret)

## 리소스 설정 값

#### 기본 설정

-   `namespace` : ServiceAccount 리소스가 배포될 네임스페이스
-   `annotations` : Kubernetes 시스템 메타데이터
-   `labels` : ServiceAccount 식별 및 분류용 라벨
-   `secret` : 해당 ServiceAccount를 참조하는 Pod에서 사용할 수 있도록 허용된 Secret 목록
-   `image_pull_secrets` : 이 ServiceAccount를 사용하는 Pod가 이미지를 가져올 때 사용할 Secret 목록
-   `automount_service_account_token` : Pod에 ServiceAccount 토큰을 자동으로 마운트할지 여부
