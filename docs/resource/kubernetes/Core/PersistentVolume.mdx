## 리소스 개요

클러스터에 네트워크로 연결된 저장소를 제공하는 쿠버네티스 리소스입니다.

## 연관 리소스

### 상위 리소스

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)

### 연결 리소스

-   [**Storage Class**](https://docs.cstudio.app/docs/resource/kubernetes/Storage/StorageClass)
-   [**Persistent Volume Claim**](https://docs.cstudio.app/docs/resource/kubernetes/Storage/PersistentVolumeClaim)
-   [**Secret**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Secret)

## 리소스 설정 값

#### 기본 설정

-   `annotations` : Kubernetes 시스템 메타데이터
-   `labels` : PV 식별 및 분류용 사용자 정의 라벨
-   `spec.storage_class_name` : 사용할 StorageClass 이름
-   `spec.storage_capacity` : 스토리지 용량
-   `spec.volume_driver` : CSI 기반 볼륨 드라이버
-   `spec.volume_handle` : 실제 스토리지 리소스 식별자
-   `spec.persistent_volume_reclaim_policy` : 클레임 해제 시 볼륨 처리 정책 -`Retain / Delete / Recycle`
-   `spec.read_only` : 볼륨 읽기 전용 여부
-   `spec.volume_attributes` : 드라이버별 추가 볼륨 속성
-   `spec.access_modes` : 볼륨 접근 방식 - `ReadOnlyMany, ReadWriteOnce, ReadWriteMany`
-   `spec.mount_options` : 추가 마운트 옵션
-   `node_stage_secret_ref` : 스토리지 접근 인증 정보가 담긴 Secret 참조
