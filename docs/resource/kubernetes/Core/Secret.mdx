## 리소스 개요

개별 속성이나 전체 파일 또는 JSON Blob과 같은 대략적인 항목으로 중요한 정보를 저장하는 데 사용되는 쿠버네티스 리소스입니다.

## 리소스 설정 값

-   `namespace` : Secret 리소스가 배포될 네임스페이스
-   `annotations` : Kubernetes 시스템 메타데이터
-   `labels` : Secret 식별 및 분류용 사용자 정의 라벨
-   `type` : Secret 타입 (Opaque, kubernetes.io/tls, dockerconfigjson 등)
-   `immutable` : Secret 데이터 수정 불가 여부 설정
-   `data` : Base64 인코딩된 key-value 형태의 시크릿 데이터
-   `json_data` : 사용자 이름, 비밀번호, 서버 정보 등 구조화된 시크릿 데이터
