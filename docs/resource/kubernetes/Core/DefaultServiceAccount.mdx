## 리소스 개요

쿠버네티스 클러스터 내에서 파드가 API 서버 및 클러스터 리소스에 접근할 수 있도록 권한을 부여하는 기본 ServiceAccount 리소스입니다.

## 연관 리소스

### 상위 리소스

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

### 연결 대상

-   [**Secret**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Secret)

## 리소스 설정 값

#### 기본 설정

-   `namespace` : ServiceAccount 리소스가 배포될 네임스페이스
-   `annotations` : Kubernetes 시스템 메타데이터
-   `labels` : 리소스 식별 및 분류를 위한 사용자 정의 라벨
-   `secret` : 해당 ServiceAccount를 사용하는 파드에서 참조 가능한 Secret 목록
-   `image_pull_secrets` : 파드가 이미지를 Pull 할 때 사용할 Secret 목록
-   `automount_service_account_token` : 파드에 ServiceAccount 토큰 자동 마운트 여부
