## 리소스 개요

하나 이상의 컨테이너를 함께 실행하는 가장 작은 배포 단위의 쿠버네티스 서비스입니다.

## 리소스 설정 값

-   `namespace` : Pod 리소스가 배포될 네임스페이스
-   `annotations` : Kubernetes 시스템 메타데이터
-   `labels` : Pod 식별 및 분류용 사용자 정의 라벨
-   `pod_security_context` : Pod 단위 보안 및 권한 설정
-   `init_containers` : 메인 컨테이너 실행 전 초기화 컨테이너 정의
-   `containers` : Pod에서 실행될 컨테이너 스펙 정의
-   `containers.image` : 컨테이너 이미지
-   `containers.resources` : CPU / Memory 요청 및 제한
-   `containers.probe` : startup, liveness, readiness probe 설정
-   `containers.env` : 환경 변수 정의
-   `containers.env_from` : ConfigMap / Secret 기반 환경 변수 주입
-   `containers.command` : 컨테이너 실행 명령
-   `containers.args` : 컨테이너 실행 인자
-   `containers.port` : 컨테이너에서 노출할 포트
-   `containers.volume_mount` : 컨테이너에 마운트할 볼륨 경로
-   `volume` : Pod에서 사용할 볼륨 정의
-   `dns_policy` : DNS 정책 설정
-   `enable_service_links` : 서비스 환경 변수 자동 주입 여부
-   `host_network` : 호스트 네트워크 사용 여부
-   `image_pull_secrets` : 이미지 풀에 사용할 Secret 목록
