## 리소스 개요

Cloudstudio에서 등록한 사용자 Credential을 선택합니다.

## 연관 리소스

### 그룹 대상

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)

## 리소스 설정 값

#### 기본 설정

-   `credential_id` : Kubernetes 클러스터에 접근하기 위해 사용할 사용자 자격증명 선택
