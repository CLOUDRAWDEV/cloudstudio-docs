## 리소스 개요

지정된 네임스페이스에만 적용되는 역할을 생성하는 쿠버네티스 리소스

## 연관 리소스

### 상위 리소스

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

### 연결 리소스

-   [**RoleBinding**](https://docs.cstudio.app/docs/resource/kubernetes/RBAC/RoleBinding)

## 리소스 설정 값

-   `namespace` : Role 리소스가 적용될 네임스페이스
-   `annotations` : Role 리소스에 대한 메타데이터 key-value
-   `labels` : Role 객체를 구분하기 위한 사용자 정의 라벨
-   `rule.api_groups` : 작업을 허용할 리소스가 포함된 API Group 목록
-   `rule.resources` : 해당 규칙이 적용되는 리소스 목록
-   `rule.resource_names` : 특정 리소스 인스턴스를 대상으로 제한할 경우 지정하며 비어 있으면 전체 리소스에 적용
-   `rule.verbs` : 지정된 리소스에 대해 허용할 동작(get, list, create, update, patch, watch, delete, deletecollection)
