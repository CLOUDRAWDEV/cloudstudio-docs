## 리소스 개요

특정 네임스페이스에서 적용되는 역할을 사용자에게 참조하는 쿠버네티스 리소스

## 연관 리소스

### 상위 리소스

-   [**Namespace**](https://docs.cstudio.app/docs/resource/kubernetes/Core/Namespace)

### 연결 리소스

-   [**ServiceAccount**](https://docs.cstudio.app/docs/resource/kubernetes/Core/ServiceAccount)
-   [**Role**](https://docs.cstudio.app/docs/resource/kubernetes/RBAC/Role)
-   [**ClusterRole**](https://docs.cstudio.app/docs/resource/kubernetes/RBAC/ClusterRole)

## 리소스 설정 값

#### 기본 설정

-   `namespace` : RoleBinding 리소스가 적용될 네임스페이스
-   `annotations` : RoleBinding 리소스에 대한 메타데이터 key-value
-   `labels` : RoleBinding 객체를 구분하기 위한 사용자 정의 라벨
-   `role_type` : 바인딩할 역할의 유형 - `Role`,`ClusterRole`
-   `role_name` : 주체에 바인딩할 Role 또는 ClusterRole 이름

#### 주체 설정 (subject)

-   `subject.kind` : 바인딩할 주체 유형 - `ServiceAccount`, `User`, `Group`
-   `subject.namespace` : 바인딩할 주체의 네임스페이스
-   `subject.api_group` : 승인 결정을 내리는 API Group - `rbac.authorization.k8s.io`
