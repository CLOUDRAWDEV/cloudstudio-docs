## 리소스 개요

클러스터 수준과 모든 네임스페이스에서 적용되는 역할을 생성하는 쿠버네티스 리소스

## 연관 리소스

### 상위 리소스

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)

### 연결 리소스

-   [**ClusterRoleBinding**](https://docs.cstudio.app/docs/resource/kubernetes/RBAC/ClusterRoleBinding)

## 리소스 설정 값

#### 기본 설정

-   `annotations` : ClusterRole 리소스에 대한 메타데이터 key-value
-   `labels` : ClusterRole 객체를 구분하기 위한 사용자 정의 라벨
-   `rule` : ClusterRole에 적용될 권한 규칙 정의로 rule_type -`ApiGroup, ResourceUrl`, api_groups(작업을 허용할 리소스가 포함된 API Group), resources(규칙이 적용되는 리소스 목록), resource_names(특정 리소스 인스턴스로 제한할 경우 지정하며 비어 있으면 전체 리소스 적용), non_resource_urls(리소스가 아닌 URL 단위 접근 제어로 헬스체크 URL 등 지정 가능), verbs - `get`, `list`, `create`, `update`, `patch`, `watch`, `delete`, `deletecollection`로 구성됩니다.
