## 리소스 개요

클러스터 수준과 모든 네임스페이스에서 적용되는 역할을 사용자에게 참조하는 쿠버네티스 리소스

## 연관 리소스

### 상위 리소스

-   [**Cluster**](https://docs.cstudio.app/docs/resource/kubernetes/Base/Cluster)

### 연결 리소스

-   [**ClusterRole**](https://docs.cstudio.app/docs/resource/kubernetes/RBAC/ClusterRole)

## 리소스 설정 값

-   `annotations` : ClusterRoleBinding 리소스에 대한 메타데이터 key-value
-   `labels` : ClusterRoleBinding 객체를 구분하기 위한 사용자 정의 라벨
-   `role_name` : 바인딩할 대상 ClusterRole의 이름
-   `subject` : ClusterRole을 부여할 주체로 kind(ServiceAccount, User, Group), namespace(주체가 속한 네임스페이스), api_group(rbac.authorization.k8s.io) 정보를 포함
