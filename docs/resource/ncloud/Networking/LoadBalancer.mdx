## 리소스 개요

서버의 성능과 부하량을 고려해 네트워크 트래픽을 다수의 서버로 분산해주는 장치입니다. 특정 서버에 발생한 부하를 분산해 서버 가용성, 응답 시간을 최적화함으로써 무정지 서비스를 제공할 수 있습니다.

## 리소스 설정 값

#### 기본 설정

-   `network_type` : 네트워크 타입 - `PUBLIC`, `PRIVATE`
-   `type` : 로드 밸런서 타입 - `APPLICATION`, `NETWORK`, `NETWORK_PROXY`
-   `throughput_type` : 부하 처리 성능(초당 연결 수) - `SMALL(3만)`, `MEDIUM(6만)`, `LARGE(9만)`
-   `included_subnet_names` : 로드 밸런서가 연결될 서브넷 이름 리스트

#### 리스너 (`listener`)

-   `listener.protocol` : 리스너 프로토콜 - `HTTP`, `HTTPS`, `TCP`, `TLS`
-   `listener.tls_min_version_type` : TLS 최소 지원 버전 - `TLSV10`, `TLSV11`, `TLSV12`
-   `listener.port` : 리스너 포트 번호 - `1` ~ `65534`
-   `listener.use_http2` : HTTP/2 사용 여부 - `true`, `false`
-   `listener.ssl_certificate_no` : SSL 인증서 번호
-   `listener.target_group_name` : 연결할 Target Group 이름
