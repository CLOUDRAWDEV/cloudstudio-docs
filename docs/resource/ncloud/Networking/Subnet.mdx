## 리소스 설정 값

#### 기본 설정

-   `subnet_cidr` : VPC CIDR 범위 내에서 할당할 Subnet IP 대역
-   `zone` : Subnet이 위치할 가용 영역 (`KR-1`, `KR-2`)
-   `subnet_type` : Subnet 유형 (`PUBLIC`, `PRIVATE`)
-   `usage_type` : Subnet 사용 목적 (`General`, `LoadBalancer`, `BareMetal`, `NATGateway`)
-   `included_vpc_name` : Subnet이 소속될 VPC 이름 (읽기 전용)
-   `linked_nacl_name` : Subnet에 적용할 Network ACL 이름 (읽기 전용)
