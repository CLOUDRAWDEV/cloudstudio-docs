## 리소스 개요

VPC 간 통신을 위한 VPC 피어링을 설정하는 리소스입니다.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### 연결 리소스

-   [**VPC**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

## 리소스 설정 값

#### 기본 설정

-   `linked_vpc_name_01` : 피어링 요청을 보내는 VPC 이름 (읽기 전용)
-   `linked_vpc_name_02` : 피어링 요청을 받는 VPC 이름 (읽기 전용)
