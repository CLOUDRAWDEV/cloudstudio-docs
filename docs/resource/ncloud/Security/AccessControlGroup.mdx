## 리소스 개요

서버 간 네트워크 접근 제어 및 관리를 할 수 있는 IP/Port 기반 필터링 방화벽 서비스입니다.

## 연관 리소스

### 상위 리소스

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

### 연결 대상

-   [**Network Interface**](https://docs.cstudio.app/docs/resource/ncloud/Networking/NetworkInterface)
-   [**Auto Scaling**](https://docs.cstudio.app/docs/resource/ncloud/Compute/AutoScaling)

## 리소스 설정 값

#### 기본 설정

-   `included_vpc_name` : ACG를 생성할 VPC 이름
-   `acg_description` : ACG에 대한 설명

#### 인바운드 규칙 (`inbound_rule`)

-   `inbound_rule.protocol` : 인바운드 트래픽의 프로토콜 - `TCP`, `UDP`, `ICMP`
-   `inbound_rule.rule_apply_method` : 인바운드 규칙 적용 방법 - `ip_block`, `source_name`
-   `inbound_rule.ip_block` : 인바운드 트래픽 목적지 IP 대역(CIDR 형식)
-   `inbound_rule.source_access_control_group_name` : 인바운드 트래픽 소스 ACG 이름
-   `inbound_rule.port_range` : 인바운드 규칙을 적용할 포트 범위 - `1` ~ `65535`
-   `inbound_rule.description` : 인바운드 규칙에 대한 설명

#### 아웃바운드 규칙 (`outbound_rule`)

-   `outbound_rule.protocol` : 아웃바운드 트래픽의 프로토콜 - `TCP`, `UDP`, `ICMP`
-   `outbound_rule.rule_apply_method` : 아웃바운드 규칙 적용 방법 - `ip_block`, `source_name`
-   `outbound_rule.ip_block` : 아웃바운드 트래픽 목적지 IP 대역(CIDR 형식)
-   `outbound_rule.source_access_control_group_name` : 아웃바운드 트래픽 소스 ACG 이름
-   `outbound_rule.port_range` : 아웃바운드 규칙을 적용할 포트 범위 - `1` ~ `65535`
-   `outbound_rule.description` : 아웃바운드 규칙에 대한 설명
