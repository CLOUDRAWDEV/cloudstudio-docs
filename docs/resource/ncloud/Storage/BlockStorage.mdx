## 리소스 개요

서버의 기본 스토리지 외에 추가로 제공하는 HDD 또는 SSD 스토리지 서비스입니다. 단시간에 생성하여 즉시 서버와 연결할 수 있고 필요하지 않을 경우 바로 반납할 수 있습니다.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

### 연결 대상

-   [**Server**](https://docs.cstudio.app/docs/resource/ncloud/Compute/Server)

## 리소스 설정 값

#### 기본 설정

-   `zone` : Block Storage가 위치할 물리적 지역 - `KR-1`, `KR-2`
-   `linked_server_name` : 블록 스토리지를 연결할 서버 이름
-   `storage_size` : 블록 스토리지 크기(GB) - `10` ~ `16380`
-   `storage_disk_type` : 블록 스토리지 디스크 타입 - `SSD`, `HDD`
