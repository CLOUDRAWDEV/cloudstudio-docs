## 리소스 개요

Object Storage는 모든 종류의 데이터를 인터넷상에 저장하고 검색할 수 있는 객체 스토리지 서비스입니다.  
접근 정책(rule)을 통해 버킷/오브젝트에 대한 접근 권한을 설정할 수 있습니다.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

## 리소스 설정 값

#### 기본 설정

-   `rule` : Object Storage 접근 정책 설정 - `private`, `public-read`, `public-read-write`, `authenticated-read`
