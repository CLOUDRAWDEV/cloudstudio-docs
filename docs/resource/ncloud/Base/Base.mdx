## 리소스 개요

사용자의 구독 정보를 저장하고 있는 Ncloud의 가장 최상위 그룹을 나타냅니다.

### 연결 리소스

## 리소스 설정 값

#### 기본 설정

-   `credential_id` : 사용자 Credential
-   `site` : 네이버 클라우드 종류

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그
