## 리소스 개요

생성한 SourceDeploy 프로젝트에 Deploy Stage를 추가/수정/삭제하거나 배포 타깃이 없는 배포 Stage에 배포 타깃을 생성할 수 있습니다.

## 연관 리소스

### 상위 리소스

-   [**Source Deploy**](https://docs.cstudio.app/docs/resource/navercloud/DeveloperTool/SourceDeploy)

### 연결 리소스

-   **Server**
-   **Auto Scaling**
-   **Kubernetes Cluster**
-   **Source Build**
-   **Source Commit**

## 리소스 설정 값

#### 기본 설정

-   `included_source_deploy_name` : SourceDeploy 프로젝트 이름
-   `target_type` : 배포 대상 유형 - `Server`, `AutoScalingGroup`, `DeployedAutoScalingGroup`, `KubernetesService`, `DeployedKubernetesService`, `ObjectStorage`, `DeployedObjectStorage`
-   `linked_server_list` : 연결할 서버 이름 리스트
-   `target_server_id_list` : 연결할 서버 ID 리스트
-   `target_resource` : 배포 대상 리소스 식별자

#### 배포 시나리오 (`scenario`)

-   `deploy_scenario_description` : 배포 시나리오 설명
-   `deploy_scenario_strategy` : 배포 전략 - `normal`, `blueGreen`, `rolling`, `canary`
-   `deploy_scenario_file_type` : 배포 파일 유형 - `SourceBuild`, `ObjectStorage`, `later`
-   `linked_source_build_project` : 연동할 Source Build 프로젝트 이름
-   `rollback` : 배포 실패 시 롤백 여부 - `true`, `false`
-   `pre_deploy.command` : 배포 전 실행 명령어 목록
-   `path.deploy_path` : 배포 대상 경로 리스트
-   `post_deploy.command` : 배포 후 실행 명령어 목록

#### 로드밸런서 / 오토스케일링

-   `linked_target_group` : 연결할 Load Balancer Target Group 이름
-   `delete_server` : Auto Scaling Group 서버 삭제 여부 - `true`, `false`

#### Kubernetes 배포

-   `manifest_type` : 매니페스트 저장소 유형 - `SourceCommit`
-   `manifest_repository` : 매니페스트 저장소 이름
-   `manifest_branch` : 매니페스트 브랜치 이름
-   `manifest_path` : 매니페스트 파일 경로 리스트

#### Canary 분석

-   `analysis_type` : 카나리아 분석 방식 - `manual`, `auto`
-   `canary_count` : Baseline 및 Canary 파드 수
-   `timeout` : 최대 배포/취소 허용 시간(분)
-   `prometheus_url` : Prometheus URL
-   `baseline` : Baseline 변수
-   `canary` : Canary 변수

#### Metric 설정 (`metric`)

-   `success_criteria` : Metric 성공 기준 - `base`, `canary`
-   `weight` : Metric 가중치
-   `query_type` : Metric 쿼리 타입 - `default`, `promQL`
-   `metric` : 평가할 Metric 이름
-   `filter` : Metric 필터 조건
-   `query` : PromQL 쿼리

#### 분석 환경

-   `duration` : 분석 시간(분)
-   `delay` : 분석 지연 시간(분)
-   `interval` : 분석 주기
-   `step` : Metric 수집 주기
-   `pass_score` : 분석 성공 기준 점수

#### Object Storage 배포

-   `object_storage_source_path` : Object Storage 소스 경로
-   `object_storage_deploy_path` : Object Storage 배포 경로
