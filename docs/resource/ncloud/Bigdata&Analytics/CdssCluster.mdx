## 리소스 개요

실시간 스트리밍 데이터 파이프라인 및 애플리케이션 빌드를 위한 오픈 소스 플랫폼인 Apache Kafka 클러스터를 손쉽게 배포, 보호, 운영 및 확장할 수 있는 서비스입니다.

## 연관 리소스

### 상위 리소스

-   [**Vpc**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Vpc)

### 연결 리소스

-   [**CdssConfigGroup**](https://docs.cstudio.app/docs/resource/ncloud/Bigdata&Analytics/CdssConfigGroup)

## 리소스 설정 값

#### 기본 설정

-   `included_vpc_name` : CDSS 생성할 VPC 이름
-   `kafka_version_code` : CDSS에서 사용할 Kafka 버전 - `kafkaVersionCode`
-   `linked_config_group_name` : 사용할 CDSS config group 이름
-   `os_image` : 사용할 OS 이미지 타입 - `osImage`

#### CMAK 설정 (`cmak`)

-   `cmak.user_name` : CMAK 접근 ID
-   `cmak.user_password` : CMAK 접근 비밀번호

#### 매니저 노드 설정 (`manager_node`)

-   `manager_node.manager_node_subnet_name` : 매니저 노드가 위치할 subnet 이름
-   `manager_node.manager_node_product_code` : 매니저 노드 하드웨어 제품 코드 - `managerNodeProductCode`

#### 브로커 노드 설정 (`broker_node`)

-   `broker_node.broker_node_subnet_name` : 브로커 노드가 위치할 subnet 이름
-   `broker_node.broker_node_product_code` : 브로커 노드 하드웨어 제품 코드 - `managerNodeProductCode`
-   `broker_node.broker_node_count` : 브로커 노드 수 - `3` ~ `10`
-   `broker_node.broker_node_storage_size` : 브로커 노드 저장 용량 - `100` ~ `2000`
