## 리소스 개요

elasticsearch 및 OpenSearch 클러스터를 편리하게 관리할 수 있는 환경을 제공하고, 다양한 서버 유형 및 스토리지 용량을 선택하여 클러스터를 구성하고 손쉽게 배포, 운영 및 확장할 수 있는 리소스입니다.

## 리소스 설정 값

#### 기본 설정

-   `included_vpc_name` : SES를 생성할 VPC 이름
-   `os_image_code` : 사용할 OS 타입 - `osImageName`
-   `enable_master_node` : master node 사용 여부 - `true`, `false`
-   `login_key_name` : 암호화를 위한 공용 로그인 키 이름

#### Search Engine 설정 (`search_engine`)

-   `search_engine.version_code` : 사용할 Search Engine 버전 코드 - `versionCode`
-   `search_engine.user_name` : Search Engine 사용자 이름
-   `search_engine.user_password` : Search Engine 사용자 비밀번호
-   `search_engine.dashboard_port` : Search Engine 대시보드의 포트 - `1024` ~ `65535`

#### Manager Node 설정 (`manager_node`)

-   `manager_node.enable_dual_manager` : manager node 이중화 여부 - `true`, `false`
-   `manager_node.manager_node_subnet_name` : manager node를 위치시킬 subnet 이름
-   `manager_node.manager_node_product_code` : 사용할 manager node 제품 코드 - `managerNodeProductCode`

#### Data Node 설정 (`data_node`)

-   `data_node.data_node_subnet_name` : data node를 위치시킬 subnet 이름
-   `data_node.data_node_product_code` : 사용할 data node 제품 코드 - `managerNodeProductCode`
-   `data_node.data_node_count` : data node의 수 - `3` ~ `10`
-   `data_node.data_node_storage_size` : data node 스토리지 용량 - `100` ~ `2000`

#### Master Node 설정 (`master_node`)

-   `master_node.master_node_subnet_name` : master node를 위치시킬 subnet 이름
-   `master_node.master_node_product_code` : 사용할 master node 제품 코드 - `managerNodeProductCode`
-   `master_node.master_node_count` : master node의 수 - `3` ~ `5`
