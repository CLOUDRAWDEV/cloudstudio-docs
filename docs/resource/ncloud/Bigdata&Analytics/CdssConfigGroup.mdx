## 리소스 개요

Cdss Config Group은 CDSS cluster에 적용된 Kafka 설정 파일 관리 기능을 하는 서비스입니다.

## 연관 리소스

### 상위 리소스

-   [**Vpc**](https://docs.cstudio.app/docs/resource/navercloud/Network/Vpc)

### 하위 리소스

### 연결 리소스

-   [**CdssConfigGroup**](https://docs.cstudio.app/docs/resource/navercloud/BigDataAnalytics/CdssConfigGroup)

## 리소스 설정 값

#### 기본 설정

-   `kafka_version_code` : CDSS config group에서 사용할 Kafka 버전 - `kafkaVersionCode`
-   `description` : config 그룹에 대한 설명
