## 리소스 개요

Cloud DB for Redis는 Redis 캐시를 몇 가지 설정과 클릭만으로 간편하게 구축하고 네이버의 최적화 설정을 통해 안정적으로 운영하며, 장애 발생 시 자동 복구하는 완전 관리형 클라우드 캐시 서비스입니다.

## 연관 리소스

### 상위 리소스

-   [**Subnet**](https://docs.cstudio.app/docs/resource/ncloud/Networking/Subnet)

## 리소스 설정 값

#### 기본 설정

-   `server_name_prefix` : Redis 서버 이름 (영소문자/숫자/하이픈 허용, 영소문자로 시작, 영소문자 또는 숫자로 종료, 3~15자)
-   `included_vpc_name` : Redis가 포함된 VPC 이름
-   `included_subnet_name` : Redis가 포함된 Subnet 이름
-   `redis_mode` : Redis 구성 모드 - `CLUSTER`, `SIMPLE`
-   `engine_version_code` : Redis 엔진 버전
-   `image_product_code` : Redis 서버 이미지 제품 코드
-   `product_code` : Redis 인스턴스 서버 사양 제품 코드
-   `target_config_group_name` : 연결할 Redis Config Group 이름
-   `shard_count` : 생성할 샤드 수 (master node 기준) - `3` ~ `10`
-   `shard_copy_count` : 샤드당 복제본 수 (slave node 수) - `0` ~ `4`
-   `enable_high_availability` : 고가용성 기능 사용 여부 - `true`, `false`
-   `enable_backup` : 백업 기능 사용 여부 (고가용성 사용 시 자동 활성화) - `true`, `false`
-   `backup_file_retention_period` : 백업 파일 보관 기간(일 단위) - `1` ~ `7`
-   `enable_automatic_backup` : 자동 백업 사용 여부 - `true`, `false`
-   `backup_time` : 사용자 지정 백업 시간
-   `port` : Redis 접속 포트 - `6379` ~ `20000`
