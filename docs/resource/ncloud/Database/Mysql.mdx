## 리소스 개요

Mysql은 관계형 데이터베이스 MySQL을 이용한 완전 관리형 클라우드 데이터베이스 서비스로 MySQL 데이터베이스를 손쉽게 구축, 안정적으로 운영하며, 장애 발생 시 자동으로 복구하는 서비스입니다.

## 리소스 설정 값

#### 기본 설정

-   `server_name_prefix` : MySQL 서버 이름 (영소문자/숫자/하이픈 허용, 영소문자로 시작, 영소문자 또는 숫자로 종료, 3~30자)
-   `users` : 사용자 구성 정보 (`password` : 사용자 패스워드, `host_ip` : 접속 허용 클라이언트 IP `% | 1.1.1.1 | 1.1.1.%`, `authority` : 사용자 권한 `DDL | CRUD | READ`)
-   `databases` : 생성할 데이터베이스 이름 목록
-   `included_subnet_names` : MySQL이 포함된 Subnet 이름 리스트
-   `image_product_code` : MySQL 서버 이미지 제품 코드
-   `product_code` : MySQL 인스턴스 서버 사양 제품 코드
-   `data_storage_type` : 데이터 스토리지 종류 - `SSD`, `HDD`
-   `enable_high_availability` : 고가용성 기능 사용 여부 - `true`, `false`
-   `enable_storage_encryption` : 스토리지 암호화 기능 사용 여부 - `true`, `false`
-   `enable_backup` : 백업 기능 사용 여부 - `true`, `false`
-   `backup_file_retention_period` : 백업 파일 보관 기간(일 단위) - `1` ~ `30`
-   `enable_automatic_backup` : 백업 자동화 기능 사용 여부 - `true`, `false`
-   `backup_time` : 사용자 지정 백업 시간
-   `port` : MySQL 접속 포트 - `3306` ~ `20000`
