## 리소스 개요

Redis Config Group에서는 생성한 Redis Server를 그룹핑하여 그룹에 속한 서버들에 동일한 설정값을 지정하여 효율적으로 관리할 수 있습니다.

## 연관 리소스

### 상위 리소스

-   [**Region**](https://docs.cstudio.app/docs/resource/ncloud/Base/Region)

## 리소스 설정 값

#### 기본 설정

-   `redis_version` : Redis config group 버전 및 모드 - `5.0.14-cluster`, `5.0.14-simple`, `7.0.13-cluster`, `7.0.13-simple`, `7.0.15-cluster`, `7.0.15-simple`, `7.2.6-cluster`, `7.2.6-simple`, `7.2.8-cluster`, `7.2.8-simple`
-   `description` : Redis config group에 대한 설명
