## 리소스 개요

Cloud-init은 가상 머신 인스턴스가 최초 부팅될 때 자동으로 초기 설정을 수행하기 위한 표준 초기화 도구입니다.  
운영 체제 설정, 패키지 설치, 사용자 생성, 스크립트 실행 등 다양한 초기 구성 작업을 선언적으로 정의할 수 있으며, 멀티 클라우드 및 다양한 Linux 배포판에서 널리 사용됩니다.

## 연관 리소스

### 상위 리소스

-   [**ResourceGroup**](https://docs.cstudio.app/docs/resource/azure/Base/ResourceGroup)

## 리소스 설정 값

-   `gzip` : 데이터 압축 알고리즘 사용 여부 - `true`, `false`

-   `part` : 디스크 파티셔닝 및 초기화 스크립트 설정

    -   `content_type` : 삽입할 데이터의 형식
        -   `text/cloud-config`
        -   `text/x-shellscript`
        -   `text/cloud-boothook`
        -   `multipart/mixed`
        -   `text/cloud-config-archive`
        -   `text/jinja`
        -   `text/x-include-url`
        -   `text/part-handler`
    -   `content` : 삽입할 실제 데이터

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
