## 리소스 개요

Azure PolicyDefinition은 **리소스가 준수해야 할 규칙과 조건, 그리고 조건 위반 시 적용될 효과를 정의하는 정책 정의 리소스**입니다.  
정책 유형과 적용 모드를 기반으로 Azure 리소스 전반의 규정 준수 상태를 일관되게 관리할 수 있습니다.

## 연관 리소스

### 상위 리소스

### 연결 리소스

-   [**Resource Group**](https://docs.cstudio.app/docs/resource/azure/Base/ResourceGroup)

## 리소스 설정 값

-   `type` : 정책 정의 유형 - `Custom`, `BuiltIn`, `NotSpecified`
-   `mode` : 정책 평가 대상 리소스 유형 모드
-   `display_name` : 정책 정의의 표시 이름
-   `linked_resource_group_name` : 정책을 적용할 Resource Group 정보
