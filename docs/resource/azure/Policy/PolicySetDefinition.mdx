## 리소스 개요

Azure PolicySetDefinition은 **여러 개의 Policy Definition을 하나의 논리적 집합으로 묶어 관리하기 위한 정책 집합 정의 리소스**입니다.  
공통 목적의 정책들을 단일 단위로 구성하여 대규모 환경에서도 정책 적용과 관리를 일관되게 수행할 수 있습니다.

## 리소스 설정 값

-   `type` : 정책 집합 정의 유형 - `Custom`, `BuiltIn`
-   `display_name` : 정책 집합 정의의 표시 이름
-   `definition_names` : 정책 집합에 포함될 Policy Definition 이름 목록
