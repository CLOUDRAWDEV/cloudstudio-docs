## 리소스 개요

Azure Private DNS Resolver는 **Virtual Network 내에서 Private DNS 쿼리를 처리하거나, 온프레미스 및 외부 DNS 서버로 쿼리를 전달하기 위한 관리형 DNS 리졸버 서비스**입니다.  
Inbound / Outbound 엔드포인트와 포워딩 규칙을 통해 하이브리드 DNS 해석 구조를 구성할 수 있습니다.

## 리소스 설정 값

-   `included_vnet_name` : DNS Resolver가 적용될 Virtual Network 이름

#### Inbound Resolver (`inbound`)

-   `inbound.linked_inbound_subnet_name` : 인바운드 리졸버 엔드포인트가 배치될 서브넷 이름
-   `inbound.private_ip_allocation_method` : 인바운드 엔드포인트의 IP 할당 방식 - `Dynamic`, `Static`
-   `inbound.private_ip_address` : 인바운드 엔드포인트에서 사용할 프라이빗 IP 주소

#### Outbound Resolver (`outbound`)

-   `outbound.linked_outbound_subnet_name` : 아웃바운드 리졸버 엔드포인트가 배치될 서브넷 이름

-   `target_outbound_endpoints` : DNS 쿼리 전달 시 사용할 아웃바운드 리졸버 엔드포인트 목록

#### DNS Forwarding Rule (`rule`)

-   `rule.domain_name` : 규칙이 적용될 도메인 이름
-   `rule.enable_forwarding_rule` : DNS 포워딩 규칙 활성화 여부 - `true`, `false`

##### Target DNS Servers (`rule.target_dns_servers`)

-   `rule.target_dns_servers.ip_address` : DNS 쿼리를 전달할 대상 DNS 서버 IP 주소
-   `rule.target_dns_servers.port` : DNS 서버가 수신 대기 중인 포트 번호
