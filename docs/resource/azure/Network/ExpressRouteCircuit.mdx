## 리소스 개요

ExpressRoute Circuit은 온-프레미스 네트워크를 Microsoft 클라우드와 **사설 전용 회선**으로 연결하기 위한 Azure 네트워크 리소스입니다.  
공용 인터넷을 거치지 않는 안정적인 연결을 제공하며, 대역폭·지연 시간·보안 요구사항이 높은 엔터프라이즈 환경에서 주로 사용됩니다.

## 리소스 설정 값

-   `service_provider` : ExpressRoute 회선을 제공하는 ISP 공급자
-   `peering_location` : ISP가 회선을 프로비저닝하는 Peering 위치
-   `bandwidth_in_mbps` : ExpressRoute 회선의 대역폭(Mbps)
-   `sku_tier` : ExpressRoute 회로의 가격 책정 계층 - `Basic`, `Local`, `Standard`, `Premium`
-   `sku_family` : 아웃바운드 데이터 전송을 위한 과금 모델 - `MeteredData`, `UnlimitedData`
-   `authorization_names` : 회로 사용을 허용할 인증 이름 목록
-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`

#### 회로 피어링 설정 (`circuit_peering`)

-   `circuit_peering.enabled_peering` : 해당 Peering 타입 활성화 여부 - `true`, `false`
-   `circuit_peering.peer_asn` : BGP 피어링에 사용할 ASN 값
-   `circuit_peering.primary_peer_address` : 기본 링크에 대한 `/30` IPv4 서브넷
-   `circuit_peering.secondary_peer_address` : 보조 링크에 대한 `/30` IPv4 서브넷
-   `circuit_peering.vlan_id` : 피어링 설정을 위한 VLAN ID
-   `circuit_peering.advertised_public_prefixes` : BGP 세션을 통해 광고할 공용 IPv4 주소 접두사 목록
