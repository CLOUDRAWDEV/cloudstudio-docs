## 리소스 개요

Bastion Host는 공용 IP를 VM에 직접 노출하지 않고도 Virtual Network 내부의 가상 머신에 대해 **보안된 RDP 및 SSH 접속**을 제공하는 Azure PaaS 네트워크 서비스입니다.  
브라우저 기반 접근을 지원하며, 관리 포트 개방 없이 중앙 집중식 접속 지점을 구성할 수 있어 보안성과 운영 편의성을 동시에 확보할 수 있습니다.

## 리소스 설정 값

-   `included_subnet_name` : Bastion Host가 위치할 Subnet 이름
-   `sku` : Bastion Host의 SKU - `Basic`, `Standard`
-   `linked_public_ip_name` : Bastion Host에 연결할 Public IP 이름
-   `ip_config_name` : Bastion Host에서 사용할 IP Configuration 이름
-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
