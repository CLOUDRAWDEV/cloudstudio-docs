## 리소스 개요

Azure Virtual WAN은 여러 지역에 분산된 네트워크 리소스를 중앙에서 연결하고 관리하기 위한 **글로벌 네트워크 허브 서비스**입니다.  
Site-to-Site VPN, Point-to-Site VPN, ExpressRoute 연결을 단일 제어 지점에서 통합 관리할 수 있으며, 대규모 멀티 리전 네트워크 아키텍처에 적합합니다.

### 하위 리소스

### 연결 리소스

-   [**Vpn Site**](https://docs.cstudio.app/docs/resource/azure/Network/VpnSite)

## 리소스 설정 값

-   `type` : Virtual WAN의 유형
    -   `Basic`
    -   `Standard`
