## 리소스 개요

Private Endpoint는 공용 IP 주소를 사용하지 않고 Virtual Network 내부에서 Azure 서비스에 **사설 연결(Private Link)** 을 제공하는 네트워크 리소스입니다.  
서비스 엔드포인트가 Subnet에 할당된 Private IP를 통해 노출되어, 인터넷을 경유하지 않는 안전한 통신 경로를 구성할 수 있습니다.  
Private DNS Zone과 연동하여 서비스 FQDN을 내부 네트워크에서 자연스럽게 해석하도록 구성할 수 있습니다.

## 리소스 설정 값

-   `included_subnet_name` : Private Endpoint에 할당될 Private IP 주소를 가진 Subnet 이름
-   `connection_name` : Private Endpoint와 리소스 간 연결 이름
-   `linked_connection_resource_name` : Private Endpoint가 연결될 리소스 이름
-   `subresource_name` : Private Endpoint가 연결될 Subresource 이름
-   `dns_zone_group_name` : Private Endpoint와 연결할 Private DNS Zone 그룹 이름
-   `private_dns_zone_names` : Private Endpoint와 연결할 Private DNS Zone 이름 목록
-   `manual_connection` : 외부 리소스 소유자의 수동 승인 필요 여부 - `true`, `false`
-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
