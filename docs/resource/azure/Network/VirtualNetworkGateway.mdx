## 리소스 개요

Virtual Network Gateway는 Azure Virtual Network와 온-프레미스 네트워크 또는 다른 Virtual Network 간에 **암호화된 트래픽 통신 경로를 제공하는 네트워크 게이트웨이**입니다.  
VPN 또는 ExpressRoute 방식으로 연결할 수 있으며, 하이브리드 네트워크 구성과 안전한 전용 연결을 위한 핵심 구성 요소입니다.

## 리소스 설정 값

-   `included_subnet_name` : Virtual Network Gateway를 통해 트래픽을 송수신할 Subnet 이름
-   `gateway_type` : Virtual Network Gateway 유형 - `Vpn`, `ExpressRoute`
-   `vpn_type` : VPN 연결 형식 - `RouteBased`, `PolicyBased`
-   `sku` : Virtual Network Gateway의 가격 책정 계층
-   `generation` : Virtual Network Gateway 세대 - `Generation1`, `Generation2`
-   `enabled_active_active_mode` : Active-Active 모드 활성화 여부
-   `enabled_configure_bgp` : BGP 활성화 여부
-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`

#### IP 구성 (`ip_configuration`)

-   `ip_configuration.linked_public_ip_name` : Virtual Network Gateway에 연결할 Public IP 이름
