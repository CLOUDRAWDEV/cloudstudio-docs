## 리소스 개요

Network Interface는 Virtual Machine이 Virtual Network 내부 리소스, 인터넷, 온-프레미스 네트워크와 통신할 수 있도록 하는 네트워크 연결 리소스입니다.  
Subnet에 소속되어 IP 주소를 할당받으며, 필요에 따라 Public IP를 연결해 외부 통신을 구성할 수 있습니다.  
하나의 Network Interface에는 여러 IP Configuration을 정의할 수 있어 다양한 네트워크 시나리오를 지원합니다.

## 리소스 설정 값

-   `included_subnet_name` : Network Interface가 포함된 Subnet 이름

#### IP 구성 (`ip_configuration`)

-   `ip_configuration.is_primary` : 기본 IP Configuration 활성화 여부 - `true`, `false`
-   `ip_configuration.private_ip_address_allocation` : 개인 IP 주소 할당 방식 - `Dynamic`, `Static`
-   `ip_configuration.private_ip_address` : 개인 IP 주소
-   `ip_configuration.enabled_public_ip` : Public IP 사용 여부 - `true`, `false`
-   `ip_configuration.linked_public_ip_name` : 사용할 Public IP 이름

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
