## 리소스 개요

Firewall Policy는 Azure Firewall에서 사용하는 **중앙 집중식 방화벽 정책 관리 리소스**입니다.  
네트워크 규칙, 애플리케이션 규칙, NAT 규칙을 하나의 정책으로 정의하여 여러 Firewall 인스턴스에 일관되게 적용할 수 있으며, 보안 정책의 재사용성과 운영 효율성을 높입니다.
