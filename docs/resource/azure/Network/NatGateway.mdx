## 리소스 개요

NAT Gateway는 Virtual Network 내 하나 이상의 Subnet에 대해 **아웃바운드(Outbound) 인터넷 연결**을 제공하는 리소스입니다.  
Subnet에 연결하면 해당 Subnet의 리소스는 지정한 Public IP를 통해 외부로 통신하며, 인바운드(Inbound) 공개 엔드포인트를 제공하지 않습니다.
유휴(Idle) 연결의 타임아웃을 조절하여 장시간 연결을 유지하거나, 불필요한 연결을 빠르게 정리할 수 있습니다.

## 리소스 설정 값

-   `linked_subnet_names` : Nat Gateway를 연결할 Subnet의 이름
-   `linked_public_ip_name` : Nat Gateway 연결할 Public Ip 이름
-   `idle_timeout_in_minutes` : Nat Gateway에서 유휴 흐름을 제거하는 시간 제한(분) - `4` ~ `120`
-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
