## 리소스 개요

Virtual Network는 Azure 리소스 간 통신을 가능하게 하고, 인터넷 또는 온-프레미스 네트워크와의 연결을 구성하기 위한 **가상 네트워크 리소스**입니다.  
IP 주소 공간(Address Space)을 기반으로 서브넷, 보안 정책, 피어링 등을 구성하여 Azure 환경의 네트워크 구조를 정의할 수 있습니다.

## 리소스 설정 값

-   `vnet_address_space` : Virtual Network가 사용할 IP 주소 공간

    -   CIDR 형식의 주소를 1개 이상 지정 가능

-   `enable_ddos_protection` : Virtual Network에 DDoS Protection Plan 적용 여부
    -   `true`, `false`
-   `ddos_protection_plan_name` : Virtual Network에 연결할 DDoS Protection Plan 이름

#### VNet 피어링 (`peering`)

다른 Virtual Network와의 연결 설정을 정의합니다.

-   `peering.linked_vnet_name` : 연결 대상 Virtual Network 이름 (읽기 전용)
-   `peering.allow_access_to_remote_vnet` : 원격 Virtual Network 접근 허용 여부
-   `peering.allow_receive_forwarded_traffic` : 전달된 트래픽 수신 허용 여부
-   `peering.allow_forward_traffic_to_remote_vnet` : 원격 Virtual Network로 트래픽 전달 허용 여부
-   `peering.allow_use_remote_gateway` : 원격 Virtual Network의 Gateway 사용 여부
    -   각 항목 값: `true`, `false`

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그
    -   최대 512자, `key`:`value` 형식
