## 리소스 개요

Network DDoS Protection Plan은 대규모 분산 서비스 거부(DDoS) 공격으로부터 Azure 가상 네트워크 리소스를 보호하기 위한 보안 서비스입니다.  
트래픽 분석과 자동 완화 기능을 통해 애플리케이션 가용성을 유지하고, 공격 발생 시 추가적인 보호 기능을 제공합니다.
