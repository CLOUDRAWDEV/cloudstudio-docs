## 리소스 개요

Public IP Prefix는 Azure에서 **연속된 공용 IP 주소 범위**를 미리 예약하여 관리할 수 있는 네트워크 리소스입니다.  
여러 개의 Public IP를 일관된 주소 블록으로 할당할 수 있어, 방화벽 규칙 관리나 외부 연동 시스템 구성 시 예측 가능성과 운영 편의성을 제공합니다.

## 연관 리소스

### 상위 리소스

-   [**Resource Group**](https://docs.cstudio.app/docs/resource/azure/Base/ResourceGroup)

## 리소스 설정 값

-   `prefix_length` : Public IP Prefix의 비트 길이 - `28` ~ `31`
-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
