## 리소스 개요

Subnet은 Azure 리소스를 Virtual Network에 배포하기 위해 Virtual Network 내에 생성하는 네트워크입니다.

## 리소스 설정 값

-   `included_vnet_name` : Subnet이 포함된 Virtual Network 이름
-   `address_prefixes` : Subnet 사용을 위한 IP 주소 범위, Virtual Network의 주소 공간 내에 CIDR 형식으로 지정된 고유한 주소 범위
-   `private_link_endpoint_enabled` : Subnet에 Private Endpoint를 연결할 것인지 설정 - `true`, `false`

#### 위임 설정 (`delegation`)

-   `delegation.service_name` : 위임할 서비스의 이름
-   `delegation.actions` : 위임할 액션 목록
