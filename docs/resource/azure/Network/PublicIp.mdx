## 리소스 개요

Public IP는 Azure 리소스가 인터넷과 **직접 인바운드/아웃바운드 통신**을 할 수 있도록 공용 IP 주소를 제공하는 네트워크 리소스입니다.  
Load Balancer, Virtual Machine, NAT Gateway 등과 연동되어 외부 트래픽 수신 지점 또는 아웃바운드 출구 역할을 수행하며, SKU와 할당 방식에 따라 가용성 및 동작 특성이 달라집니다.

## 리소스 설정 값

-   `sku` : Public IP의 가격 책정 계층 - `Standard`, `Basic`
-   `allocation_method` : Public IP 주소 할당 방식 - `Static`, `Dynamic`
-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
