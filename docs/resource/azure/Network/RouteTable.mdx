## 리소스 개요

Route Table은 Virtual Network 내 Subnet에 적용되어 **네트워크 트래픽의 경로를 사용자 정의 방식으로 제어**하는 Azure 네트워크 리소스입니다.  
기본 시스템 라우팅 외에도, 가상 어플라이언스, 인터넷, 게이트웨이 등으로의 트래픽 흐름을 명시적으로 지정할 수 있습니다.

## 연관 리소스

### 상위 리소스

-   [**ResourceGroup**](https://docs.cstudio.app/docs/resource/azure/Base/ResourceGroup)

### 연결 리소스

-   [**Subnet**](https://docs.cstudio.app/docs/resource/azure/Network/Subnet)

## 리소스 설정 값

-   `enable_bgp_route_propagation` : 게이트웨이 경로 전파 활성화 여부 - `true`, `false`
-   `linked_subnet_names` : Route Table을 연결할 Subnet 이름 리스트
-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`

#### 경로 설정 (`route`)

-   `route.route_address_prefix` : 경로를 나타내는 IP 주소 접두사(CIDR)
-   `route.next_hop_type` : 다음 홉 유형
    -   `VirtualNetworkGateway`
    -   `VnetLocal`
    -   `Internet`
    -   `VirtualAppliance`
    -   `None`
