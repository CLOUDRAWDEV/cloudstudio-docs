## 리소스 개요

Azure Front Door는 전 세계에 분산된 Microsoft 글로벌 엣지 네트워크를 활용하여 사용자에게 웹 콘텐츠를 빠르고 안정적으로 제공하는 글로벌 애플리케이션 가속 서비스입니다.  
트래픽 라우팅, 로드 밸런싱, 헬스 프로브, TLS 종료 및 보안 통신을 지원하며, 다중 오리진 환경에서도 고가용성과 낮은 지연 시간을 제공합니다.

## 리소스 설정 값

### 기본 설정

-   `sku` : Front Door 프로필에 대한 SKU - `Standard_AzureFrontDoor`, `Premium_AzureFrontDoor`

-   `endpoint_names` : 사용할 엔드포인트의 이름 목록

### Origin Group 설정 (`origin_group`)

-   `restore_traffic_time_in_minutes` : 엔드포인트 장애 또는 신규 엔드포인트 추가 시 트래픽 전환 전 대기 시간(분) - `0` ~ `50`

-   `session_affinity_enabled` : 세션 선호도(Session Affinity) 활성화 여부 - `true`, `false`

-   `health_probe_path` : 오리진 상태 확인에 사용할 상대 경로

-   `health_probe_protocol` : 상태 프로브에 사용할 프로토콜 - `Http`, `Https`

-   `health_probe_method` : 상태 프로브 요청 방식 - `HEAD`, `GET`

-   `health_probe_interval_in_seconds` : 상태 프로브 실행 간격(초)

-   `load_balancing_latency_in_milliseconds` : 최저 지연 시간 버킷에 포함될 추가 지연 시간(ms)

-   `load_balancing_sample_size` : 로드 밸런싱 판단을 위한 샘플 수

-   `load_balancing_sample_required` : 성공으로 간주되기 위해 필요한 샘플 수

### Origin 설정 (`origin`)

-   `origin_group_name` : 오리진이 포함되는 그룹 이름

-   `host_name` : 오리진의 호스트 이름 (IPv4, IPv6 또는 도메인)

-   `origin_host_header` : 오리진으로 전달되는 Host Header 값

-   `certificate_name_check_enabled` : 인증서 이름 검사 활성화 여부 - `true`, `false`

-   `enabled` : 오리진 활성화 여부 - `true`, `false`

-   `priority` : 오리진 우선 순위 - `1` ~ `5`

-   `weight` : 로드 밸런싱 가중치 - `1` ~ `1000`

-   `http_port` : HTTP 포트 번호 - `1` ~ `65535`

-   `https_port` : HTTPS 포트 번호 - `1` ~ `65535`

### Route 설정 (`route`)

-   `endpoint_name` : 라우트를 적용할 Front Door 엔드포인트 이름

-   `origin_group_name` : 트래픽을 전달할 오리진 그룹 이름

-   `patterns_to_match` : 라우팅 경로 패턴 목록

-   `supported_protocols` : Front Door에서 허용할 프로토콜 - `Http`, `Https`

-   `forwarding_protocol` : 백엔드로 트래픽 전달 시 사용할 프로토콜 - `HttpOnly`, `HttpsOnly`, `MatchRequest`
