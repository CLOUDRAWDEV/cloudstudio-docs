## 리소스 개요

Azure Cosmos DB Cassandra는 Apache Cassandra API와 호환되는 분산형 NoSQL 데이터베이스 서비스입니다.  
전 세계 분산, 자동 확장, 고가용성 및 다양한 일관성 모델을 제공하며, Cassandra API 기반 애플리케이션을 Azure 환경에서 손쉽게 운영할 수 있습니다.

## 리소스 설정 값

-   `capabilities_list` : 사용할 Cosmos DB 기능(API) 목록
-   `enable_multiple_write_locations` : 다중 지역 쓰기 활성화 여부
-   `public_network_access_enabled` : 공용 네트워크를 통한 계정 접근 허용 여부
-   `enable_automatic_failover` : 자동 장애 조치 활성화 여부
-   `virtual_network_filter_enabled` : 특정 가상 네트워크 Subnet만 접근하도록 제한 여부
-   `network_acl_bypass_for_azure_services` : Azure 서비스에 대한 ACL 우회 허용 여부

#### 지역 설정 (`geo_location`)

-   `geo_location.failover_priority` : 지역의 장애 조치 우선순위
-   `geo_location.zone_redundant` : 가용 영역(Zone) 중복 배포 활성화 여부

#### 일관성 정책 (`consistency_policy`)

-   `consistency_policy.consistency_level` : Cassandra DB의 일관성 수준
-   `consistency_policy.max_interval_in_seconds` : Bounded Staleness 사용 시 허용되는 최대 지연 시간(초)
-   `consistency_policy.max_staleness_prefix` : Bounded Staleness 사용 시 허용되는 최대 Stale 요청 수

#### 백업 설정 (`backup`)

-   `backup.type` : 백업 정책 유형 (`Continuous`, `Periodic`)
-   `backup.interval_in_minutes` : 백업 수행 주기(분)
-   `backup.retention_in_hours` : 백업 보관 기간(시간)

#### Cassandra 키스페이스 (`cassandra_keyspace`)

-   `cassandra_keyspace.throughput` : Cassandra 키스페이스의 처리량
-   `cassandra_keyspace.enable_autoscale` : 처리량 자동 확장 활성화 여부

#### Cassandra 테이블 (`cassandra_table`)

-   `cassandra_table.throughput` : Cassandra 테이블의 처리량
-   `cassandra_table.column` : 컬럼 이름과 타입 목록 (`이름:타입` 형식)
-   `cassandra_table.partition_key` : 파티션 키 이름
-   `cassandra_table.cluster_key_name` : 클러스터 키 이름
-   `cassandra_table.cluster_key_order` : 클러스터 키 정렬 기준
-   `cassandra_table.enable_autoscale` : 테이블 처리량 자동 확장 여부
-   `cassandra_table.included_cosmosdb_keyspace_name` : 테이블이 생성될 Cassandra 키스페이스 이름

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
