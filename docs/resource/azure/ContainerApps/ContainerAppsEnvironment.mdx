## 리소스 개요

Azure Container Apps Environment는 Azure Container Apps가 실행되는 네트워크 및 모니터링 환경을 정의하는 리소스입니다.  
Container Apps가 생성·실행될 때 사용할 Log Analytics 작업공간과 같은 운영 환경을 연결하여, 로그 수집 및 모니터링 구성을 일관되게 적용할 수 있습니다.

## 연관 리소스

### 상위 리소스

-   [**Resource Group**](https://docs.cstudio.app/docs/resource/azure/Base/ResourceGroup)

### 하위 리소스

-   [**Container Apps**](https://docs.cstudio.app/docs/resource/azure/ContainerApps/ContainerApps)

### 연결 리소스

-   [**Log Analytics Workspace**](https://docs.cstudio.app/docs/resource/azure/Monitor/LogAnalyticsWorkspace)

## 리소스 설정 값

-   `linked_log_analytics_workspace` : 연결된 Log Analytics 작업공간의 리소스 ID
