## 리소스 개요

Private DNS Zone은 Azure 가상 네트워크 내부에서만 사용되는 프라이빗 도메인 이름에 대한 DNS 레코드를 관리하기 위한 영역입니다.  
가상 네트워크와 연결(VNet Link)하여 내부 리소스 간 이름 해석을 안전하게 수행할 수 있습니다.

## 리소스 설정 값

#### A 레코드 (`private_dns_a_record`)

-   `private_dns_a_record.ttl` : DNS Record의 Time To Live(초) - `0` ~ `2147483647`
-   `private_dns_a_record.records` : IPv4 주소의 목록

#### AAAA 레코드 (`private_dns_aaaa_record`)

-   `private_dns_aaaa_record.ttl` : DNS Record의 Time To Live(초) - `0` ~ `2147483647`
-   `private_dns_aaaa_record.records` : IPv6 주소의 목록

#### CNAME 레코드 (`private_dns_cname_record`)

-   `private_dns_cname_record.ttl` : DNS Record의 Time To Live(초) - `0` ~ `2147483647`
-   `private_dns_cname_record.record` : 하위 도메인을 다른 레코드에 연결하기 위한 별칭

#### PTR 레코드 (`private_dns_ptr_record`)

-   `private_dns_ptr_record.ttl` : DNS Record의 Time To Live(초) - `0` ~ `2147483647`
-   `private_dns_ptr_record.records` : 포인터 레코드 유형의 도메인 이름 목록

#### TXT 레코드 (`private_dns_txt_record`)

-   `private_dns_txt_record.ttl` : DNS Record의 Time To Live(초) - `0` ~ `2147483647`
-   `private_dns_txt_record.records` : 텍스트 유형의 레코드 목록

#### 가상 네트워크 연결 (`vnet_link`)

-   `vnet_link.linked_vnet_name` : Private DNS Zone에 연결된 가상 네트워크 이름

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
