## 리소스 개요

DNS Zone은 특정 도메인에 대한 DNS 레코드를 호스트하여 각 DNS 레코드를 생성하고 관리할 수 있는 영역입니다.

## 연관 리소스

### 상위 리소스

-   [**ResourceGroup**](https://docs.cstudio.app/docs/resource/azure/Base/ResourceGroup)

## 리소스 설정 값

#### A 레코드 (`dns_a_record`)

-   `dns_a_record.ttl` : DNS Record의 Time To Live(초) - `0` ~ `2147483647`
-   `dns_a_record.records` : IPv4 주소의 목록

#### AAAA 레코드 (`dns_aaaa_record`)

-   `dns_aaaa_record.ttl` : DNS Record의 Time To Live(초) - `0` ~ `2147483647`
-   `dns_aaaa_record.records` : IPv6 주소의 목록

#### CNAME 레코드 (`dns_cname_record`)

-   `dns_cname_record.ttl` : DNS Record의 Time To Live(초) - `0` ~ `2147483647`
-   `dns_cname_record.record` : 하위 도메인을 다른 레코드에 연결하기 위한 별칭

#### NS 레코드 (`dns_ns_record`)

-   `dns_ns_record.ttl` : DNS Record의 Time To Live(초) - `0` ~ `2147483647`
-   `dns_ns_record.records` : 이름 서버 레코드 목록

#### PTR 레코드 (`dns_ptr_record`)

-   `dns_ptr_record.ttl` : DNS Record의 Time To Live(초) - `0` ~ `2147483647`
-   `dns_ptr_record.records` : 포인터 레코드 유형의 도메인 이름 목록

#### TXT 레코드 (`dns_txt_record`)

-   `dns_txt_record.ttl` : DNS Record의 Time To Live(초) - `0` ~ `2147483647`
-   `dns_txt_record.records` : 텍스트 유형의 레코드 목록

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
