## 리소스 개요

Azure Security Center는 **클라우드 리소스 전반의 보안 상태를 지속적으로 평가하고 위협을 탐지·차단하기 위한 통합 보안 관리 서비스**입니다.  
Microsoft Defender 계획과 연동하여 취약점 평가, 보안 권장 사항, 위협 보호를 중앙에서 관리할 수 있습니다.

-   [**Subscription**](https://docs.cstudio.app/docs/resource/azure/Base/Subscription)

## 리소스 설정 값

-   `linked_log_analytics_workspace` : 보안 데이터를 저장할 Log Analytics Workspace 이름

#### Assessment Policy (`assessment_policy`)

-   `assessment_policy.display_name` : Security Center Assessment의 표시 이름
-   `assessment_policy.severity` : Security Center Assessment의 심각도 - `Low`, `Medium`, `High`
-   `assessment_policy.description` : Security Center Assessment에 대한 설명

#### Assessment (`assessment`)

-   `assessment.policy_name` : 리소스에 적용할 보안 평가 정책 이름
-   `assessment.status_code` : 평가 상태 코드 - `Healthy`, `Unhealthy`, `NotApplicable`

#### Subscription Pricing (`subscription_pricing`)

-   `subscription_pricing.pricing_tier` : 향상된 보안 기능 적용 여부 - `Free`, `Standard`
-   `subscription_pricing.pricing_resource_type` : 향상된 보안 기능을 적용할 리소스 유형
