## 리소스 개요

Public Load Balancer는 트래픽 부하 방지를 위해 외부(인터넷)에서 유입되는 트래픽을 프런트엔드로 수신하고, 백엔드 풀 인스턴스로 분산하는 부하 분산 장치입니다.

## 리소스 설정 값

#### 기본 설정

-   `sku` : Azure Load Balancer의 규모 및 기능 선택을 위한 가격 책정 계층 - `Standard`, `Basic`
-   `virtual_network_name` : Load Balancer가 트래픽을 전달할 Virtual Network 이름

#### 프런트엔드 IP 구성 (`public_lb_frontend_ip_config`)

-   `public_lb_frontend_ip_config.linked_public_ip_name` : 사용할 공용 IP 이름

#### 백엔드 풀 (`backend_pool`)

-   `backend_pool` : Load Balancer의 Backend Pool 이름
-   `backend_pool.linked_virtual_machine_names` : Load Balancer가 트래픽을 전달할 Virtual Machine 이름(선택한 Virtual Network에 속한)

#### 상태 프로브 (`health_probe`)

-   `health_probe.protocol` : 상태 프로브가 사용하는 백엔드 엔드포인트의 프로토콜 타입 - `Http`, `Https`, `Tcp`
-   `health_probe.port` : 상태 프로브가 백엔드 엔드포인트를 확인하는 포트 - `0` ~ `65535`
-   `health_probe.request_path` : Http(s) 프로브를 사용할 때 GET에 사용할 경로
-   `health_probe.interval_in_seconds` : 상태 프로브가 백엔드 풀 인스턴스의 응답을 확인하는 간격(초) - `5` ~ `2147483646`

#### 부하 분산 규칙 (`rule`)

-   `rule.protocol` : 외부 Endpoint를 위한 전송 Protocol - `Tcp`, `Udp`, `All`
-   `rule.frontend_port` : 외부 Endpoint의 Port - `0` ~ `65534`
-   `rule.backend_port` : 내부 Connection에 사용할 Port - `0` ~ `65535`
-   `rule.disable_outbound_snat` : 아웃바운드 연결을 위해 Rule에 대한 SNAT 활성화 - `true`, `false`
-   `rule.frontend_ip_config_name` : Public Load Balancer의 Frontend IP Configuration Name
-   `rule.backend_pool_name` : Load Balancer가 트래픽을 전달할 Backend Address Pool의 이름

#### NAT 규칙 (`nat_rule`)

-   `nat_rule.protocol` : 외부 Endpoint를 위한 전송 Protocol - `Tcp`, `Udp`, `All`
-   `nat_rule.frontend_port` : 외부 Endpoint의 Port - `0` ~ `65534`
-   `nat_rule.backend_port` : 내부 Connection에 사용할 Port - `0` ~ `65535`
-   `nat_rule.frontend_ip_config_name` : Public Load Balancer의 Frontend IP Configuration Name

#### 아웃바운드 규칙 (`outbound_rule`)

-   `outbound_rule.protocol` : 외부 Endpoint를 위한 전송 Protocol - `Tcp`, `Udp`, `All`
-   `outbound_rule.frontend_ip_config_name` : Public Load Balancer의 Frontend IP Configuration Name
-   `outbound_rule.backend_pool_name` : Load Balancer가 트래픽을 전달할 Backend Address Pool의 이름

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
