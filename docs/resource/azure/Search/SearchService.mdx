## 리소스 개요

Azure Search Service는 **대규모 텍스트·문서·데이터에 대해 검색, 필터링, 랭킹 등의 기능을 제공하는 완전관리형 검색 서비스**입니다.  
검색 인덱스를 기반으로 빠른 질의 처리와 확장 가능한 검색 성능을 제공하며, 보안 및 네트워크 접근 정책을 통해 서비스 접근 범위를 제어할 수 있습니다.

## 리소스 설정 값

-   `sku_name` : Search Service 사용을 위한 가격 책정 계층 - `basic`, `free`, `standard`, `standard2`, `standard3`, `storage_optimized_l1`, `storage_optimized_l2`
-   `public_network_access_enabled` : 공용 인터넷을 통한 리소스 접근 허용 여부 - `true`, `false`
-   `allowed_ips` : 특정 IP 또는 CIDR 대역에서 Search Service에 접근을 허용하는 IP 허용 목록
-   `local_authentication_enabled` : API 키를 이용한 로컬 인증을 사용할지 여부 - `true`, `false`
-   `authentication_failure_mode` : 클라이언트 인증 실패 시 요청을 차단할지 또는 제한적으로 허용할지를 결정하는 동작 모드 - `http401WithBearerChallenge`, `http403`
-   `partition_count` : 색인 데이터를 분산 저장하기 위한 파티션 수를 지정 - `1`, `2`, `3`, `4`, `6`, `12`
-   `replica_count` : 검색 쿼리를 처리할 복제본 수를 지정

#### Private Link (`private_link`)

-   `private_link.target_ai_service_name` : Private Link 연결을 생성할 대상 AI Service 리소스의 이름을 지정
-   `private_link.request_message` : Private Link 연결 요청 시 승인자에게 전달할 설명 또는 메시지
