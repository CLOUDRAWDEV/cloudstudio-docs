## 리소스 개요

Azure Redis Cache는 **애플리케이션에서 빈번하게 접근하는 데이터를 메모리에 캐싱하여 높은 처리량과 낮은 지연 시간을 제공하는 관리형 인메모리 데이터 저장 서비스**입니다.  
세션 관리, 캐시 계층, 실시간 데이터 처리와 같은 시나리오에서 백엔드 부하를 줄이고 응답 속도를 향상시키는 데 사용됩니다.

## 리소스 설정 값

-   `sku_name` : Redis 캐시의 가격 책정 계층 - `Basic`, `Standard`, `Premium`, `Enterprise`
-   `cache_type` : Redis 캐시의 크기 및 성능 등급(SKU 세부 타입)
-   `version` : Redis 버전 - `6`
-   `enable_non_ssl_port` : Non-SSL 포트 사용 여부 - `true`, `false`
-   `minimum_tls_version` : Redis에 적용할 최소 TLS 버전 - `1.0`, `1.1`, `1.2`
-   `public_network_access_enabled` : 공용 네트워크를 통한 Redis 접근 허용 여부 - `true`, `false`
-   `tag` : 리소스를 카테고리로 분류하기 위한 태그

#### Redis Firewall Rule (`redis_firewall_rule`)

-   `redis_firewall_rule.start_ip` : 접근을 허용할 시작 IP 주소
-   `redis_firewall_rule.end_ip` : 접근을 허용할 종료 IP 주소
