## 리소스 개요

Azure Windows Virtual Machine Scale Set은 Windows 가상 머신 인스턴스를 여러 대 생성하고,
요구 또는 정의된 일정에 따라 인스턴스 수를 자동으로 늘리거나 줄일 수 있는 리소스입니다.
VM 크기(SKU), 운영체제 이미지, 관리자 계정 정보, OS 디스크 구성, 네트워크 인터페이스 구성 등을 설정하여
동일한 구성의 Windows VM을 규모에 맞게 운영할 수 있습니다.

## 리소스 설정 값

-   `included_vnet_name` : Virtual Machine Scale Set이 속하는 Virtual Network 이름

-   `orchestration_mode` : Scale Set에 의해 VM이 관리되는지 결정하는 오케스트레이션 방식 - `Uniform`, `Flexible`

-   `platform_fault_domain_count` : 공통 전원 및 네트워크 스위치를 공유하는 VM의 그룹 수

-   `vmss_sku` : Virtual Machine Scale Set의 가격 책정 계층

-   `instances` : Scale Set의 가상머신 수 - `1` ~ `1000`

-   `computer_name_prefix` : Virtual Machines의 이름으로 사용할 Prefix

-   `admin_username` : VM에 대한 관리자 사용자 이름 - 1 ~ 64자

-   `admin_password` : VM에 대한 관리자 암호 - 12 ~ 72자

-   `os_disk_caching` : 내부 OS Disk 사용을 위한 Caching 유형 - `ReadWrite`, `ReadOnly`, `None`

-   `storage_account_type` : 내부 OS Disk를 백업하기 위한 스토리지 유형 - `Standard_LRS`, `StandardSSD_LRS`, `Premium_LRS`

-   `disk_size_gb` : 내부 OS Disk의 크기(GB) - `32` ~ `11400`

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`

### 이미지 설정 (`source_image`)

-   `source_image.type` : 사용자 이미지 ID 사용 유무 - `recommended`, `custom_id`, `custom_input`

-   `source_image.image_id` : VM 생성을 위해 사용하는 이미지의 ID

-   `source_image.image` : VM 생성을 위해 사용하는 이미지

-   `source_image.publisher` : VM 생성을 위해 사용하는 이미지의 공급자

-   `source_image.offer` : VM 생성을 위해 사용하는 이미지 Offer

-   `source_image.sku` : VM 생성을 위해 사용하는 이미지 SKU

### 네트워크 설정 (`network_interface`)

-   `network_interface.is_primary` : 기본 IP Configuration으로 설정 - `true`, `false`

-   `network_interface.subnet_name` : Network Interface가 위치할 Subnet 이름

### IP 구성 (`network_interface.ip_configuration`)

-   `network_interface.ip_configuration.is_primary` : 네트워크 인터페이스의 기본 IP Configuration으로 설정 - `true`, `false`

-   `network_interface.ip_configuration.enabled_public_ip` : Public Ip 사용 여부 - `true`, `false`

-   `network_interface.ip_configuration.public_ip_name` : 사용할 Public Ip 이름
