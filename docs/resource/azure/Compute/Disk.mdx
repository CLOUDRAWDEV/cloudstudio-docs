## 리소스 개요

Azure Disk는 Azure Virtual Machine에서 사용하는 관리형 블록 스토리지 리소스입니다.  
운영체제 디스크(OS Disk) 또는 데이터 디스크(Data Disk)로 활용할 수 있으며,  
스토리지 성능과 비용 요구사항에 따라 다양한 스토리지 유형을 선택할 수 있습니다.

## 리소스 설정 값

-   `storage_type` :  
    디스크를 백업하기 위한 스토리지 유형

    -   `Standard_LRS`
    -   `StandardSSD_LRS`
    -   `Premium_LRS`

-   `size_gb` :  
    디스크의 크기(GB) - `1` ~ `32767`

-   `enabled_public_network_access` :  
    디스크에 대해 퍼블릭 네트워크 접근을 허용할지 여부 - `true`, `false`

-   `tag` :  
    리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
