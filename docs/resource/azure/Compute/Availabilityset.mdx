## 리소스 개요

Azure Availability Set은 가상 머신을 여러 장애 도메인(Fault Domain)과 업데이트 도메인(Update Domain)에 분산 배치하여  
하드웨어 장애 또는 유지보수 작업 시에도 애플리케이션의 가용성을 높이기 위한 논리적 VM 그룹입니다.  
동일한 Availability Set에 포함된 VM들은 물리적으로 분리된 인프라에 배치되어 단일 장애 지점(SPOF)을 방지합니다.

## 리소스 설정 값

-   `update_domain_count` :  
    가상 머신 그룹을 동시에 다시 부팅하기 위한 업데이트 도메인의 수 - `1` ~ `20`

-   `enabled_managed_disks` :  
    관리 디스크(Managed Disk)를 사용하여 Availability Set에 가상 머신 생성을 허용할지 여부 - `true`, `false`

-   `fault_domain_count` :  
    동일한 전원 및 물리적 네트워크 스위치를 공유하도록 구성되는 장애 도메인의 수 - `1` ~ `3`

-   `tag` :  
    리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
