## 리소스 개요

Azure Servicebus는 **애플리케이션 간 비동기 메시징을 지원하는 완전관리형 엔터프라이즈 메시징 서비스**입니다.  
큐(Queue) 및 토픽/구독(Topic/Subscription) 모델을 통해 안정적인 메시지 전달, 분산 시스템 간 결합도 감소, 대규모 이벤트 처리 시나리오를 지원합니다.

### 상위 리소스

## 리소스 설정 값

-   `sku` : Service Bus의 가격 책정 계층 - `Basic`, `Standard`, `Premium`
-   `capacity` : Premium SKU에서 처리 성능을 조절하는 용량 단위
-   `premium_messaging_partitions` : Premium 메시징 계층에서 사용할 파티션 수 - `1`, `2`, `4`
-   `default_action` : 네트워크 규칙 적용 시 기본 동작 - `Allow`, `Deny`
-   `public_network_access_enabled` : 공용 네트워크에서 Service Bus 접근 허용 여부 - `true`, `false`

#### Network Rules (`network_rules`)

-   `network_rules.target_subnet_name` : 네트워크 규칙이 적용될 대상 서브넷 이름
-   `network_rules.ignore_missing_vnet_service_endpoint` : 서브넷에 VNet 서비스 엔드포인트가 없을 경우 무시 여부 - `true`, `false`

#### Topic (`topic`)

-   `topic.status` : Topic 활성화 상태 - `Active`, `Disabled`
-   `topic.enable_partitioning` : 메시지 파티셔닝 사용 여부 - `true`, `false`

#### Subscription (`subscription`)

-   `subscription.target_topic_name` : 구독이 연결된 대상 Topic 이름
-   `subscription.max_delivery_count` : 메시지 재전송 최대 시도 횟수
