## 리소스 개요

Azure SQL Database(Microsoft SQL Database)는 사용자 개입 없이 업그레이드, 패치, 백업, 모니터링 같은 대부분의 데이터베이스 관리 기능을 처리하는 완전 관리형 PaaS 데이터베이스 엔진입니다.

## 리소스 설정 값

#### 기본 설정

-   `included_mssql_server_name` : 데이터베이스가 생성될 Microsoft SQL 서버 이름
-   `sku_name` : Microsoft SQL 데이터베이스의 가격 책정 계층
-   `max_size_gb` : 데이터베이스의 최대 용량(GB) - `1` ~ `1024`
-   `collation` : Microsoft SQL 데이터베이스의 데이터 정렬 방식
-   `license_type` : 데이터베이스에 적용할 라이센스 유형 - `LicenseIncluded`, `BasePrice`
-   `min_capacity` : 자동 스케일링의 최소 vCore 수 - 최소 `0.5`
-   `auto_pause_delay_in_minutes` : 사용자 활동이 없을 때 데이터베이스를 자동으로 일시 중지하기까지의 대기 시간(분 단위) - `60` ~ `10080`
-   `read_scale` : 읽기 전용 복제본 중 하나의 컴퓨팅 용량을 사용하여 읽기 전용 워크로드를 오프로드하기 위한 기능 활성화 - `true`, `false`
-   `zone_redundant` : 데이터베이스 유지 관리 작업을 위한 영역 중복성 활성화 - `true`, `false`

#### 감사 정책 (`auditing_policy`)

-   `auditing_policy.enable_storage_destination` : Storage 계정 활성화 여부 - `true`, `false`
-   `auditing_policy.linked_storage_account_name` : Storage 계정 이름
-   `auditing_policy.storage_access_key_is_second` : 감사 Storage 계정에 사용하는 액세스 키를 보조키로 활성화 - `true`, `false`
-   `auditing_policy.storage_retention_days` : Storage 계정에 로그 보관일 수
-   `auditing_policy.enable_log_analytics_destination` : Log analytics workspace으로 감사 정책 활성화 - `true`, `false`
-   `auditing_policy.linked_log_analytics_workspace_name` : Log analytics workspace 감사 정책 이름
-   `auditing_policy.log_analytics_diagnostic_setting_name` : Log analytics workspace 이름

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
