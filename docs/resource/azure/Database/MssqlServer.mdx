## 리소스 개요

Azure SQL Server(Microsoft SQL Server)는 사용자 개입 없이 업그레이드, 패치, 백업, 모니터링 같은 대부분의 데이터베이스 관리 기능을 처리하는 완전 관리형 PaaS 데이터베이스 엔진입니다.

## 리소스 설정 값

#### 기본 설정

-   `version` : 사용할 Microsoft SQL 서버 버전 - `2.0`, `12.0`
-   `admin_username` : 서버의 관리자 사용자 이름, 영숫자 허용, 영어로 시작, 예약어 사용 불가
-   `admin_password` : 서버의 관리자 로그인 암호, 소문자/대문자/숫자/특수문자 중 3가지 포함, 로그인 이름에서 3개 이상의 연속된 영숫자를 포함할 수 없음, `8` ~ `128`자
-   `minimum_tls_version` : 서버에 지원되는 최소 TLS 버전 - `1.2`, `Disabled`
-   `public_network_access_enabled` : 서버에 퍼블릭 네트워크 접근 허용 - `true`, `false`

#### 방화벽 규칙 (`firewall_rule`)

-   `firewall_rule.start_ip_address` : 방화벽 Rule에 연결된 시작 IP 주소
-   `firewall_rule.end_ip_address` : 방화벽 Rule에 연결된 종료 IP 주소

#### 보안 경고 정책 (`security_alert_policy`)

-   `security_alert_policy.alert_policy_state` : 적용할 정책의 활성화 상태 - `Enabled`, `Disabled`
-   `security_alert_policy.disabled_alerts` : 비활성화할 보안 경고 목록
-   `security_alert_policy.alert_retention_days` : 위협 탐지 감사 로그의 보관일 수 - `0` ~ `3265`
-   `security_alert_policy.alert_email_account_admins` : 이메일에 보안 경고 전송 활성화 - `true`, `false`
-   `security_alert_policy.alert_email_addresses` : 보안 경고를 받을 이메일 주소 목록

#### 감사 정책 (`auditing_policy`)

-   `auditing_policy.enable_storage_destination` : Storage 계정 활성화 여부 - `true`, `false`
-   `auditing_policy.linked_storage_account_name` : Storage 계정 이름
-   `auditing_policy.storage_access_key_is_second` : 감사 대상에 사용하는 액세스 키를 보조키로 활성화 - `true`, `false`
-   `auditing_policy.storage_retention_days` : Storage 계정에 로그 보관일 수
-   `auditing_policy.enable_log_analytics_destination` : Log analytics workspace으로 감사 정책 활성화 - `true`, `false`
-   `auditing_policy.linked_log_analytics_workspace_name` : Log analytics workspace 감사 정책 이름
-   `auditing_policy.log_analytics_diagnostic_setting_name` : Log analytics workspace 이름

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
