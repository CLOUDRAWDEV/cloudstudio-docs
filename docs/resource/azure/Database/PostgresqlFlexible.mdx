## 리소스 개요

Azure PostgreSQL Flexible Server는 오픈 소스 Postgres 데이터베이스 엔진을 기반으로 한 관계형 데이터베이스 서비스입니다.

## 연관 리소스

### 상위 리소스

-   [**Resource Group**](https://docs.cstudio.app/docs/resource/azure/Base/ResourceGroup)
-   [**Subnet**](https://docs.cstudio.app/docs/resource/azure/Network/Subnet)

## 리소스 설정 값

#### 기본 설정

-   `version` : 사용할 Postgresql 버전 - `11`, `12`, `13`, `14`
-   `sku_name` : Postgresql 가격 책정 계층 이름, Tier + 컴퓨팅 세대 + 코어 수의 조합
-   `storage_mb` : Postgresql Flexible Server의 최대 용량(MB)
-   `admin_username` : Creation mode가 default인 경우 Server의 관리자 사용자 이름, 영숫자 허용, 예약어 불포함, `1` ~ `16`자
-   `admin_password` : Creation mode가 default인 경우 Server의 관리자 로그인 암호, 소문자/대문자/숫자/특수문자 중 3가지 포함, 로그인 이름에서 3개 이상의 연속된 영숫자를 포함할 수 없음, `8` ~ `128`자
-   `availability_zone` : 가용 영역을 지정합니다. 가능한 값은 `1`, `2`, `3`입니다. - `1` ~ `3`
-   `enable_high_availability` : Postgresql Flexible Server의 고가용성 활성화 여부 - `true`, `false`
-   `high_availability_mode` : Postgresql Flexible Server의 고가용성 모드 - `SameZone`, `ZoneRedundant`
-   `standby_availability_zone` : 대기 서버의 가용 영역을 지정합니다. 가능한 값은 `1`, `2`, `3`입니다. 가용 영역과 중복될 수 없습니다. - `1` ~ `3`
-   `backup_retention_days` : Postgresql Flexible Server의 백업 보존 일수입니다. 가능한 값은 `1`~`35`일입니다. - `7` ~ `35`
-   `geo_redundant_backup_enabled` : 지역 중복 백업 활성화 상태 - `true`, `false`
-   `public_network_access_enabled` : Server에 퍼블릭 네트워크 접근 허용 - `true`, `false`
-   `delegated_subnet_name` : 가상 네트워크 위임을 위한 Subnet 이름
-   `private_dns_zone_name` : Postgresql Flexible Server를 생성하기 위한 프라이빗 DNS 영역

#### 서버 구성 (`configuration`)

-   `configuration.name` : PostgreSQL Server 매개변수 설정 이름
-   `configuration.param_value` : Postgresql 유연한 서버 구성의 값

#### 데이터베이스 (`database`)

-   `database.charset` : Postgresql Database의 문자 집합
-   `database.collation` : Postgresql Database의 데이터 정렬 방식

#### 방화벽 규칙 (`firewall_rule`)

-   `firewall_rule.start_ip_address` : 방화벽 Rule에 연결된 시작 IP 주소
-   `firewall_rule.end_ip_address` : 방화벽 Rule에 연결된 종료 IP 주소

#### 태그

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
