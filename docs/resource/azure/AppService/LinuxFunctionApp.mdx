## 리소스 개요

Linux Function App은 이벤트 기반 서버리스 코드를 Linux 환경에서 실행할 수 있도록 제공되는 완전관리형 Function App 서비스입니다.  
HTTP 요청, 타이머, 메시지 큐, 이벤트 스트림 등 다양한 트리거를 기반으로 코드를 실행할 수 있으며, 인프라 관리 없이 애플리케이션 로직에만 집중할 수 있도록 지원합니다.

## 리소스 설정 값

-   `linked_service_plan_name` : 함수 앱이 실행될 Service Plan의 이름

-   `delegated_subnet_name` : 가상 네트워크 위임을 위한 Subnet 이름

-   `target_storage_account_name` : Function App 실행에 필요한 파일, 로그, 메타데이터를 저장할 스토리지 계정 이름

-   `https_only` : 암호화 및 인증된 보안 연결을 위해 HTTPS 접근만 허용 여부 - `true`, `false`

-   `auth_settings_enabled` : Function App에 대한 인증/인가 기능 활성화 여부 - `true`, `false`

-   `http2_enabled` : HTTP/2 프로토콜 사용 여부 - `true`, `false`

-   `target_content_safety_name` : 연동할 Azure Content Safety 리소스의 이름

-   `target_ai_service_name` : 연동할 Azure AI Service 리소스 이름

-   `target_search_service_name` : 연동할 Azure Search Service 리소스의 이름
