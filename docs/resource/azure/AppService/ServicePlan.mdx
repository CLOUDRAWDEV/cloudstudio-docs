## 리소스 개요

Service Plan은 App Service가 실행되는 컴퓨팅 리소스(서버 인스턴스, CPU/메모리, 스케일링, OS 등)를 정의하는 요금제/호스팅 플랜입니다.  
웹 앱, API 앱, 백엔드 앱 등을 App Service로 배포할 때, 해당 앱이 어떤 사양과 가격 계층에서 실행될지 Service Plan을 통해 결정합니다.

## 연관 리소스

### 상위 리소스

-   [**ResourceGroup**](https://docs.cstudio.app/docs/resource/azure/Base/ResourceGroup)

### 연결 리소스

## 리소스 설정 값

-   `kind` : App Service가 사용할 운영 체제- `Linux`,`Windows`
-   `sku_tier` : App Service 요금제의 가격 책정 계층
