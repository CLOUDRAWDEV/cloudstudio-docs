## 리소스 개요

Linux App Service는 Linux 기반 환경에서 웹 애플리케이션, REST API 및 모바일 백엔드를 호스팅할 수 있는 HTTP 기반 서비스입니다.  
App Service Plan과 연동되어 실행되며, 인증 설정, 로그 관리, 네트워크 통합, 보안 프로토콜 설정 등을 통해 안정적이고 확장 가능한 애플리케이션 운영 환경을 제공합니다.

## 리소스 설정 값

-   `linked_service_plan_name` : App Service에 적용할 Service Plan 이름

-   `delegated_subnet_name` : 가상 네트워크 위임을 위한 Subnet 이름

-   `auth_settings_enabled` : App에서 발생하는 모든 통신이 인증되도록 Authentication 활성화 여부 - `true`, `false`

-   `detailed_error_messages_enabled` : HTTP 오류 발생 시 오류 페이지에 자세한 오류 메시지 포함 여부 - `true`, `false`

-   `failed_request_tracing_enabled` : 실패한 요청에 대한 상세 추적 정보 로깅 활성화 여부 - `true`, `false`

-   `retention_in_days` : HTTP 요청과 관련된 로그 기록 보관 일 수(일) - `0` ~ `99999`

-   `retention_in_mb` : HTTP 요청과 관련된 로그 기록 보관 용량(MB) - `25` ~ `100`

-   `ftps_state` : FTP 사용 시 TLS/SSL 적용 여부 - `Disabled`, `FtpsOnly`, `AllAllowed`

-   `http2_enabled` : 최신 HTTP 프로토콜(HTTP/2) 사용 여부 - `true`, `false`

-   `tag` : 리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
