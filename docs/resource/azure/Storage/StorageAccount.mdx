## 리소스 개요

Azure Storage Account는 **Blob, File, Queue, Table 등의 스토리지 서비스를 단일 계정에서 제공하는 기본 저장소 리소스**입니다.  
확장 가능한 데이터 저장, 고가용성, 보안 네트워크 접근 제어를 통해 다양한 애플리케이션 워크로드를 지원합니다.

## 리소스 설정 값

-   `account_kind` : Storage Account의 유형 - `StorageV2`, `Storage`
-   `account_tier` : Storage Account 사용을 위한 성능 계층 - `Standard`, `Premium`
-   `account_replication_type` : Storage Account의 데이터 복제 타입 - `LRS`, `GRS`, `RAGRS`, `ZRS`, `GZRS`, `RAGZRS`
-   `access_tier` : 데이터 사용 패턴 계층 - `Hot`, `Cool`
-   `min_tls_version` : Storage Account에 대해 지원되는 최소 TLS 버전 - `TLS1_0`, `TLS1_1`, `TLS1_2`
-   `enable_https_traffic_only` : HTTPS를 통한 접근만 허용 여부 - `true`, `false`
-   `tag` : 리소스를 카테고리로 분류하기 위한 태그

#### Networking (`networking`)

-   `networking.public_network_access` : Public Network Access 정책 - `All`, `Selected`, `Disabled`
-   `networking.ip_rules` : Network Rules을 적용할 IP 주소 범위 목록
-   `networking.bypass` : 트래픽 우회 대상 - `AzureServices`, `Logging`, `Metrics`

#### Storage Container (`storage_container`)

-   `storage_container.container_access_type` : Storage Container 접근 레벨 - `private`, `blob`, `container`

#### Storage Queue (`storage_queue`)

-   `storage_queue.name` : Queue 이름

#### Storage Share (`storage_share`)

-   `storage_share.quota` : 파일 공유의 최대 용량 (GB)

#### Storage Table (`storage_table`)

-   `storage_table.name` : Table 이름
