## 리소스 개요

AI Service는 인공지능 모델과 분석 기능을 API 형태로 제공하여 애플리케이션에 AI 기능을 손쉽게 통합할 수 있도록 지원하는 서비스입니다.  
모델 배포, 인증 방식, 네트워크 접근 제어, 관리 ID 연동 등을 통해 보안성과 확장성을 갖춘 AI 서비스 운영 환경을 제공합니다.

## 연관 리소스

### 상위 리소스

-   [**Resource Group**](https://docs.cstudio.app/docs/resource/azure/Base/ResourceGroup)

## 리소스 설정 값

-   `sku_name` : AI Service 사용을 위한 가격 책정 계층

    -   `F0`, `F1`, `S0`, `S`, `S1`, `S2`, `S3`, `S4`, `S5`, `S6`, `P0`, `P1`, `P2`, `E0`, `DC0`

-   `local_authentication_enabled` : API 키를 이용한 로컬 인증 사용 여부 - `true`, `false`

-   `custom_subdomain_name` : 토큰 기반 인증 및 엔드포인트 URL에 사용할 사용자 지정 서브도메인 이름

-   `fqdns` : AI Service 계정에서 사용을 허용하는 완전한 도메인 이름(FQDN) 목록

### 관리 ID 설정 (`identity`)

-   `identity.identity_type` : 사용할 관리 ID 유형

    -   `SystemAssigned`, `UserAssigned`, `SystemAssigned, UserAssigned`

-   `identity.identity_ids` : 사용자 할당 관리 ID의 ID 목록

### 네트워크 접근 제어 (`network_acls`)

-   `network_acls.default_action` : 네트워크 액세스 제어의 기본 정책 - `Allow`, `Deny`

-   `network_acls.ip_rules` : 특정 IP 또는 CIDR 대역에서의 리소스 접근을 허용하기 위한 IP 허용 목록

-   `outbound_network_access_restricted` : 외부 네트워크로의 아웃바운드 통신 제한 여부 - `true`, `false`

-   `public_network_access` : 공용 인터넷을 통한 리소스 접근 허용 여부 - `Enabled`, `Disabled`

### 모델 배포 설정 (`deployment`)

-   `deployment.model_name` : 배포할 모델의 이름

-   `deployment.model_version` : 사용할 모델의 버전 번호

-   `deployment.sku_name` : 배포에 할당할 처리 용량(SKU) 종류

    -   `Standard`, `DataZoneBatch`, `DataZoneStandard`, `DataZoneProvisionedManaged`,  
        `GlobalBatch`, `GlobalProvisionedManaged`, `GlobalStandard`, `ProvisionedManaged`

-   `deployment.version_upgrade_option` : 모델 버전 업그레이드 방식
    -   `OnceCurrentVersionExpired`, `OnceNewDefaultVersionAvailable`, `NoAutoUpgrade`
