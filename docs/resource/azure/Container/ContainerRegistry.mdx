## 리소스 개요

Azure Container Registry는 컨테이너 이미지와 OCI 아티팩트를 안전하게 저장하고 관리하기 위한  
프라이빗 컨테이너 레지스트리 서비스입니다.  
Docker 및 Kubernetes 기반 워크로드와 긴밀하게 연동되며,  
보안, 성능, 네트워크 접근 제어를 세밀하게 설정할 수 있습니다.

## 리소스 설정 값

-   `sku` :  
    Container Registry의 성능 및 확장성을 위한 SKU 유형

    -   `Basic`
    -   `Standard`
    -   `Premium`

-   `admin_enabled` :  
    관리자 계정 사용 여부 - `true`, `false`

-   `public_network_access_enabled` :  
    Public 네트워크 접근 허용 여부 - `true`, `false`

### 네트워크 규칙 설정 (`network_rule_set`)

> SKU가 `Premium`인 경우에만 설정 가능합니다.

-   `network_rule_set.default_action` :  
    Rule과 일치하지 않는 요청에 대한 기본 동작

    -   `Allow`
    -   `Deny`

-   `network_rule_set.ip_ranges` :  
    Rule과 일치하는 요청의 IP 주소 CIDR 목록

### 태그

-   `tag` :  
    리소스를 카테고리로 분류하기 위한 태그 - 최대 512자, `key`:`value`
