그룹관리

last update: 2026.02.01

그룹관리를 위해 점검>점검 관리를 클릭합니다. 점검을 하려면 그룹을 필수적으로 생성해야 합니다.

생성​

  1. 그룹 생성을 위해 그룹 추가 아이콘을 클릭합니다.

  2. 그룹 정보를 입력합니다.


    2-1. 그룹 이름을 입력합니다. (20자 이내)
    2-2. 그룹 설명을 입력합니다. (100자 이내)
    2-3. CSP를 선택합니다. (한 그룹에는 한 CSP를 설정할 수 있습니다.)
    2-4. 컴플라이언스를 선택합니다.
    2-5. 그룹에 추가할 자산을 선택합니다.
    2-6. 그룹 추가하기 버튼을 클릭합니다.

 

수정​

  1. 그룹명을 수정하려는 그룹의 점 세개 아이콘을 클릭한 후 그룹 수정 버튼을 클릭합니다.

  1. 그룹명을 입력한 후 수정하기 버튼을 클릭합니다.

     

삭제​

  1. 삭제하려는 그룹의 점 세개 아이콘을 클릭한 후 그룹 삭제 버튼을 클릭합니다.

  2. 그룹 이름을 입력한 후 삭제하기 버튼을 클릭합니다.
