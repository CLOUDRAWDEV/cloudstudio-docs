캔버스는 리소스를 Drag & Drop 방식으로 배치하여 클라우드 인프라를 설계하고,<br/>
버전 관리부터 배포까지 수행할 수 있는 <highlight color="#206FD6">CloudStudio의 핵심 서비스</highlight>입니다.<br/>
캔버스를 통해 구성한 인프라는 시각적인 아키텍처로 활용할 수 있으며,
리소스별 옵션 설정과 자동으로 생성되는 IaC 코드를 기반으로 원하는 CSP 환경에 직접 배포할 수도 있습니다.

## 리소스 Drag & Drop {#drag-drop}

`Drag & Drop`은 캔버스를 구성할 수 있는 가장 기본적인 방식입니다.
좌측의 `리소스 리스트`에서 원하는 리소스를 선택하여 캔버스 영역으로 배치할 수 있습니다.
서로 연결할 수 없는 리소스의 경우, 빨간색 표시와 함께 연결이 제한됩니다.

</div>

<br />

`리소스 리스트`는 캔버스 좌측에 있는 리소스들을 모아놓은 패널입니다.

:::

## 리소스 연결하기 {#resource-connect}

이러한 연결은 리소스 간 특정 옵션 설정이나 관계를 정의하는 데 활용됩니다.

## 리소스 옵션 편집 {#option-edit}

리소스를 `더블 클릭`하면 리소스 설정 값을 변경할 수 있는 `편집 창`을 열 수 있습니다.
`상세히 보기`아이콘을 클릭하여 해당 리소스에 대한 설명을 확인할 수 있습니다.<br/>
각 옵션에 있는 `물음표 아이콘`에 마우스를 올리면 각 옵션에 대한 설명이 표시됩니다.
제공되는 설명을 참고하여 필요한 값을 설정할 수 있습니다.

    <img src={optionEdit} alt="옵션 편집 이미지" />
</div>

## 오류 수정하기 {#error-correction}

🔴 빨간 점은 해당 리소스에 오류가 있음을 나타내는 표시입니다. <highlight color="#FF7272">오류가 있을 경우, 캔버스를 저장 및 배포할 수 없습니다.</highlight>
오류를 해결하기 위해 캔버스에서 오류가 발생한 리소스를 `더블 클릭`하여 캔버스 오류 창을 열 수 있습니다.
캔버스 오류 창에서 수정하려는 특정 오류를 더블 클릭하면 오류가 발생한 위치로 이동하며, 표시되는 오류 원인을 참고하여 문제를 수정할 수 있습니다.

<div className={styles.imgWrap}>
    <img src={error} alt="오류 수정 이미지" />
</div>

<p>&nbsp;</p>

### 오류의 종류

| 종류  | 설명                                                  |
| ----- | ----------------------------------------------------- |
| value | 입력값이 잘못된 경우 발생하는 오류                    |
| group | 어떠한 그룹에 속해있지 않은 경우 발생하는 오류        |
| line  | 필요한 리소스가 연결되어 있지 않은 경우 발생하는 오류 |
