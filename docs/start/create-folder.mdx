📁 폴더는 여러 프로젝트를 체계적으로 관리하기 위한 구조입니다. <br />
CloudStudio에서는 폴더를 생성한 후, 해당 폴더 내에 프로젝트를 구성하여 관리할 수
있습니다.

<br />
<br />

<div className={styles.imgWrap}>
    <img src={createFolder} alt="createFolder" />
</div>

<br />

1. 새로운 폴더를 생성하기 위해 클라우드 스튜디오 내 템플릿 페이지에서 `폴더 추가 아이콘`을 클릭합니다.
2. 폴더 추가 팝업이 표시되면 `폴더명`과 `폴더 설명`을 입력합니다.<br/>폴더 설명은 생략할 수 있습니다.<br/>
   폴더명과 폴더 설명은 `아래의 조건`을 만족해야 합니다.

> 폴더명

-   영문자로 시작
-   영문자, 숫자, 하이픈(-), 언더스코어(\_)만 사용 가능
-   영문자 또는 숫자로 끝나야 함
-   전체 길이 2~12자
-   공백 사용 불가

> 폴더 설명

-   최대 100자까지 입력 가능

3. 팝업창 내용 작성이 끝나면 `생성하기` 버튼을 클릭합니다.
4. 생성된 폴더 목록은 `템플릿 > 내 폴더`에서 확인할 수 있습니다.
